4. 노트북에 수업 내용 정리하기

코드 셀에 자료형을 하나씩 적어 봐요

[1]

# 정수형 자료형

age = 25

 

# 실수 자료형

pi = 3.14

 

# 불리언 자료형(Boolean)

is_alive = True

 

# 문자열 자료형

user_name = "kim"

 

# 리스트 (다른 언어의 배열과 비슷해요)

grade_type = [1, 2, 3, 4, 5]

Python

25

정수

int

소수점 없는 숫자

3.14

실수

float

소수점 있는 숫자

True

불리언

bool

True 또는 False 두 값만

"kim"

문자열

str

따옴표로 감싼 글자

[1, 2, 3, 4, 5]

리스트

list

여러 값을 순서대로. 배열과 비슷해요

# 뒤는 설명이라 실행하지 않아요. 값은 출력 없이 커널이 기억해요.

수업에서 보여 주는 기본 자료형 다섯 가지를 한 셀에 적었어요. 줄마다 # 주석으로 무슨 자료형인지 적어 두면 노트북만 다시 열어도 복습이 돼요. 변수 이름은 앞 장의 스네이크 표기법을 따라 is_alive, user_name, grade_type처럼 적었어요. 대괄호로 묶은 [1, 2, 3, 4, 5]는 파이썬에서 리스트라고 불러요. 다른 언어에서 배열(Array)이라고 부르는 것과 비슷해요. True와 False는 첫 글자를 대문자로 써요. 이 셀은 값을 기억만 해서 출력이 없어요.
