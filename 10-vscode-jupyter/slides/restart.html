Restart 전

x = 12

name = 'kim'

↻ Restart

Restart 뒤

비어 있어요

NameError: name 'x' is not defined

2번 셀만 실행하면 x를 몰라서 오류가 나요. 번호도 [1]부터 다시 세요.

해결

▷ Run All

맨 위 셀부터 차례로 실행해서 x = 10부터 다시 기억해요.

뭔가 꼬였으면 Restart 뒤 Run All. 위에서부터 깨끗하게 다시 실행해요.

Restart는 커널을 껐다 켜요. 커널이 기억하던 x와 name이 모두 사라져요. 화면의 코드와 예전 출력은 그대로 남아 있어서 헷갈리기 쉬워요. 이 상태에서 2번 셀만 실행하면 NameError가 나요. 출력은 run_nb.py가 새 커널에서 2번 셀만 실행한 실제 결과예요. 오류 위에 Traceback 몇 줄이 더 나오는데 마지막 줄만 옮겼어요. 해결은 Run All이에요. 맨 위 셀부터 차례로 다시 실행해서 값을 다시 만들어요. 이미 불러온 패키지를 uv add로 바꾼 뒤에도 Restart를 눌러요.
