같은 셀을 다시 실행하면 번호도 값도 바뀌어요

[1]

x = 10

Python

[2]

print(x * 2)

Python

20

[3]

name = "kim"

f"안녕하세요, {name}"

Python

'안녕하세요, kim'

[5]

x = x + 1

x

Python

12

커널이 기억하는 값

x = 12

name = 'kim'

[4]가 [5]로, 11이 12로 바뀌었어요. 화면 순서가 아니라 누른 순서대로 실행돼요.

숫자가 1, 2, 3 차례가 아니면 위에서부터 다시 실행해 봐요.

같은 셀을 다시 실행하면 새 번호 [5]가 붙고, x는 11에서 1이 더 커져 12가 돼요. 노트북은 화면에 보이는 위아래 순서가 아니라 내가 누른 순서대로 실행해요. 그래서 셀을 이리저리 실행하다 보면 같은 코드인데 결과가 달라져요. 번호가 뒤죽박죽이면 다음 장의 Restart와 Run All로 위에서부터 다시 실행해요. 출력은 run_nb.py로 같은 셀을 두 번 실행한 실제 결과예요.
