2

A, B, M을 눌러도 아무 일이 없어요

편집 모드거나 한글 입력 상태예요

Esc, 한/영 키

3

▷ Run All

4

SyntaxError: invalid syntax

명령 모드에서 M

5

셀이 끝나지 않고 계속 돌아요

오래 걸리거나 끝나지 않는 코드예요

□ Interrupt

6

Mac에서 Cmd+Enter로 실행이 안 돼요

Mac 실행 키는 control이에요

control+Enter

1번과 2번은 모드를 헷갈려서 나요. 셀 테두리와 커서로 지금 모드를 봐요. 한글 입력 상태에서는 명령 모드 글자 키가 먹지 않을 수 있어서 한/영 키로 영문으로 바꿔요. 3번은 Restart 장에서 본 오류예요. 4번 출력은 '오늘 배운 것'을 코드 셀에서 실행한 실제 결과예요. 실제로는 괄호 안에 임시 파일 이름과 줄 번호가 더 붙어요. 5번은 셀 왼쪽에 도는 표시가 계속 보일 때예요. 6번은 다른 프로그램의 Jupyter와 VS Code 기본 설정이 다른 곳이에요. 커널이 .venv가 아니라서 나는 ModuleNotFoundError는 09의 29쪽을 봐요.
