Mac의 실행 키는 Cmd가 아니라 control이에요.

앞에서 본 키를 한 장에 모았어요. Windows의 Ctrl은 Mac에서 보통 Cmd가 되지만, 노트북 실행 키는 예외예요. VS Code 기본 설정에서 Mac의 셀 실행은 control+Enter예요. Alt 자리는 Mac의 option 키예요. 셀 옮기기는 아래로 옮길 때 ↓를 눌러요. 단축키는 VS Code 버전이나 다른 확장 설정에 따라 바뀔 수 있어요. 안 먹으면 명령 팔레트에서 Preferences: Open Keyboard Shortcuts를 열고 notebook으로 검색해 지금 키를 확인해요.
