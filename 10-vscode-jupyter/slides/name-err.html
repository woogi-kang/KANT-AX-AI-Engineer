4. 마크다운 셀로 규칙 정리하기

규칙을 어기면 SyntaxError가 나요

숫자로 시작

1st_name = "kim"

SyntaxError: invalid decimal literal

이렇게

first_name

공백

my name = "kim"

SyntaxError: invalid syntax

이렇게

my_name

하이픈

my-name = "kim"

SyntaxError: cannot assign to expression here.

이렇게

my_name

예약어

class = "kim"

SyntaxError: invalid syntax

이렇게

class_name

띄어쓰기와 하이픈 자리에는 밑줄(_)을 써요. 예약어는 뒤에 단어를 붙여요.

네 셀을 hello-uv 커널로 실제로 실행한 오류의 마지막 줄이에요. 괄호 안의 임시 파일 이름과 줄 번호는 뺐어요. 하이픈 오류는 뒤에 Maybe you meant '==' instead of '='? 가 더 붙어요. 파이썬이 my-name을 my 빼기 name이라는 계산으로 읽어서 나는 오류예요. 예약어는 if, for, class, True, None처럼 파이썬이 이미 쓰는 단어예요. 셀에서 import keyword 뒤 keyword.kwlist를 실행하면 전체 목록이 나와요. 오류 메시지 글자는 파이썬 버전에 따라 조금 다를 수 있어요.
