3. 명령 모드와 편집 모드

셀에는 두 가지 모드가 있어요

명령 모드

[ ]

x = 10

Python

왼쪽 막대만

셀 자체를 다뤄요
추가, 삭제, 종류 바꾸기

편집 모드

[ ]

x = 10|

Python

왼쪽 막대 + 셀 테두리 + 커서

셀 안의 글자를 고쳐요
코드 치기, 지우기

Enter

Esc

셀 안을 클릭하면 편집 모드, 셀 왼쪽 빈 곳을 클릭하면 명령 모드예요.
Enter와 Esc는 Windows와 Mac이 같아요.

A, B, M 같은 글자 단축키는 명령 모드에서만 동작해요.

노트북 셀에는 두 가지 모드가 있어요. 명령 모드는 셀 하나를 통째로 다루는 상태예요. 왼쪽에 막대만 보여요. 편집 모드는 셀 안에 커서가 깜빡이는 상태예요. 막대와 함께 셀 테두리가 진해져요. 편집 모드에서 Esc를 치면 명령 모드, 명령 모드에서 Enter를 치면 편집 모드로 가요. 명령 모드에서 B를 치면 셀이 생기고, 편집 모드에서 B를 치면 글자 b가 들어가요. 같은 키가 모드에 따라 다르게 동작해서 처음에 많이 헷갈려요. 실제 색은 VS Code 테마에 따라 달라요.
