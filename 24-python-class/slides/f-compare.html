재료를 빠뜨리면

쓸 때 KeyError

찍을 때 바로 TypeError

어울리는 곳

잠깐 담아 두는 값

같은 모양을 여러 개 찍을 때

클래스는 값과 할 일을 한 틀에 두고, 재료가 모자라면 찍는 순간 알려 줘요. 1파트의 딕셔너리 방식과 비교해요. 딕셔너리는 값만 담고 할 일은 밖의 함수가 해요. 클래스는 값과 할 일이 한 틀에 같이 있어요. 값을 꺼낼 때는 대괄호와 따옴표 대신 점을 써요. 가장 큰 차이는 재료를 빠뜨렸을 때예요. 딕셔너리는 나중에 쓸 때 KeyError가 나지만, 클래스는 찍는 순간 재료가 모자라다고 알려 줘요. 잠깐 값을 담아 둘 때는 딕셔너리가 편하고, 같은 모양을 여러 개 찍어 쓸 때는 클래스가 좋아요.
