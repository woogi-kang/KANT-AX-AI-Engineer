2. 가장 작은 틀

빈 틀을 만들고 붕어빵 두 개를 찍어요

[1]

class Bread:

pass

 

a = Bread()

b = Bread()

print(type(a))

Python

<class '__main__.Bread'>

← 틀 이름, 첫 글자는 대문자

← 아직 빈 틀

← 괄호를 붙이면 한 개 찍혀요

← 이 노트북(__main__)의 Bread

a

빈 붕어빵

b

빈 붕어빵

a와 b는 같은 틀로 찍은 서로 다른 붕어빵이에요.

class 이름:과 pass만 있으면 틀이 되고, 이름 뒤에 괄호를 붙이면 붕어빵이 찍혀요. class 뒤에 틀 이름을 적고 콜론을 붙여요. 틀 이름은 첫 글자를 대문자로 적는 게 약속이에요. 틀 안에 아직 넣을 게 없으면 pass라고 적어요. 아무것도 안 적으면 오류가 나서 자리를 채우는 말이에요. Bread()처럼 틀 이름 뒤에 괄호를 붙이면 붕어빵이 하나 찍혀요. a와 b는 같은 틀로 찍었지만 서로 다른 붕어빵이에요. type(a)를 보면 지금 노트북에서 만든 Bread 틀의 객체라고 나와요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
