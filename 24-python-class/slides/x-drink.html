class Drink:

def __init__(self, name, price, size="M"):

self.name = name

self.price = price

self.size = size

 

def label(self):

return f"{self.name}({self.size}) {self.price:,}원"

 

d1 = Drink("latte", 5000)

d2 = Drink("tea", 4000, "L")

print(d1.label())

print(d2.label())

카페 음료 틀을 만들어요. __init__에도 20에서 배운 기본값을 쓸 수 있어요. 사이즈를 안 넣으면 M이 들어가요. label 메서드는 13의 f-string과 천 단위 콤마로 메뉴 이름표 글자를 만들어 return해요. 메서드 안에서 print하지 않고 글자를 돌려주면, 밖에서 찍을 수도 있고 영수증이나 메뉴판에 다시 쓸 수도 있어요. 19에서 본 print와 return의 차이와 같아요. 출력은 실제로 실행한 결과예요.
