5. 오류와 함정

붕어빵을 print하면 이상한 글자가 나와요

[4]

class Bread:

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

 

a = Bread("팥", 1000)

print(a)

Python

<__main__.Bread object at 0x7f440c2dbb60>

← 오류는 아니에요

<__main__.Bread object at 0x7f440c2dbb60>

이 노트북의 Bread 틀의

객체(붕어빵)

컴퓨터 안의 자리. 실행할 때마다 달라요

지금은 a.flavor처럼 칸을 꺼내 찍고, 25의 __str__로 보기 좋게 바꿔요.

붕어빵을 통째로 print하면 오류는 아니지만 알아보기 힘든 글자가 나와요. 지금 노트북에서 만든 Bread 틀의 객체이고, 컴퓨터 안의 어느 자리에 있다는 뜻이에요. 0x로 시작하는 주소는 실행할 때마다 달라서 내 화면과 슬라이드가 달라도 괜찮아요. 파이썬은 우리가 만든 붕어빵을 글자로 어떻게 보여 줄지 몰라요. 지금은 a.flavor처럼 칸을 꺼내 찍고, 다음 챕터에서 __str__로 보기 좋게 바꿔요. 출력은 실제로 실행한 결과예요.
