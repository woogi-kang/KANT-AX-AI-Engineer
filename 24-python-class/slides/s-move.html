3. self와 __init__

그 함수를 틀 안에 넣으면 __init__이에요

 

def setup(bread, flavor, price):

bread.flavor = flavor

bread.price = price

 

a = Bread()

setup(a, "팥", 1000)

Python

팥 1000

class Bread:

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

 

 

a = Bread("팥", 1000)

Python

팥 1000

밖에 둔 함수

틀 안의 __init__

① 들여쓰기

class 아래로 넣어요

② setup → __init__

찍을 때 저절로 불리는 약속된 이름

③ bread → self

이름만 바뀌고 하는 일은 같아요

④ Bread("팥", 1000)

a를 넘기지 않아요. 파이썬이 넣어 줘요

setup 함수를 틀 안에 넣고 이름을 __init__으로 바꾸면 찍을 때 저절로 불려요. 왼쪽은 앞 장의 setup 함수, 오른쪽은 같은 일을 틀 안에 넣은 모양이에요. 다른 점은 네 가지예요. 첫째, 함수를 class 아래로 들여 써서 틀 안에 넣었어요. 둘째, 이름을 __init__으로 바꿨어요. 이 이름은 파이썬과 약속된 이름이라, 붕어빵을 찍을 때 저절로 불려요. 셋째, 첫 번째 칸 이름이 bread에서 self로 바뀌었어요. 이름만 바뀌었고 어느 붕어빵에 붙일지 정하는 칸인 건 같아요. 넷째, 부를 때 a를 넘기지 않아요. 파이썬이 방금 찍은 붕어빵을 첫 칸에 넣어 줘요. 두 셀의 결과는 똑같아요. 출력은 실제로 실행한 결과예요.
