5. 오류와 함정

밑줄을 하나만 적으면 takes no arguments

[3]

class Bread:

def _init_(self, flavor, price):

self.flavor = flavor

self.price = price

 

a = Bread("팥", 1000)

Python

TypeError: Bread() takes no arguments

_init_

읽는 법

Bread 틀은 재료를 받지 않는다는 뜻이에요. 약속된 이름 __init__을 찾지 못했어요.

고치기

앞뒤로 밑줄 두 개씩 __init__. __int__처럼 글자가 빠져도 같은 오류가 나요.

__init__의 밑줄을 하나씩만 적었어요. 파이썬은 앞뒤 밑줄 두 개짜리 __init__이라는 이름만 찾아요. 이름이 다르면 그냥 평범한 메서드라서 찍을 때 불리지 않아요. 그래서 Bread 틀은 재료를 받지 않는다는 TypeError가 나요. 밑줄이 두 개인지, init 글자가 맞는지 확인해요. VS Code에서는 밑줄 두 개가 붙어 보여서 놓치기 쉬워요. 출력은 실제로 실행한 결과예요.
