5. 오류와 함정

재료 수가 모자라면 missing argument

[1]

class Bread:

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

 

def intro():

print("붕어빵")

 

a = Bread("팥")

Python

TypeError: Bread.__init__() missing 1 required positional argument: 'price'

← 재료가 하나뿐

읽는 법: __init__에 꼭 필요한 칸 price가 1개 모자라요

✕

a = Bread("팥")

✓

a = Bread("팥", 1000)

self는 파이썬이 채우니까, self를 뺀 칸 수만큼 재료를 넣어요.

missing argument는 찍을 때 재료가 모자라다는 뜻이에요. 붕어빵을 찍을 때 맛만 넣고 가격을 빠뜨렸어요. __init__에 꼭 필요한 칸 price가 하나 모자라다는 TypeError예요. self는 파이썬이 채우니까 self를 뺀 칸 수만큼 재료를 넣으면 돼요. 1파트의 딕셔너리는 나중에 쓸 때 오류가 났지만, 클래스는 찍는 순간 알려 줘요. 틀 안의 intro에는 일부러 실수를 넣어 뒀어요. 다음 장에서 봐요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
