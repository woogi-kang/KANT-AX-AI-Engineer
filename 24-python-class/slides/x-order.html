[1]

class Bread:

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

 

def intro(self):

print(self.flavor, "붕어빵", self.price, "원")

 

order = [Bread("팥", 1000), Bread("슈크림", 1200), Bread("팥", 1000)]

for b in order:

b.intro()

total = sum([b.price for b in order])

print("합계", total, "원")

배운 것을 섞어 붕어빵 가게 주문을 처리해요. 손님이 주문한 붕어빵 세 개를 찍어서 바로 리스트에 담았어요. 객체도 숫자나 글자처럼 값이라 리스트에 담을 수 있어요. for로 하나씩 꺼내 b.intro()를 부르면 붕어빵마다 자기 맛과 가격으로 소개해요. 합계는 23의 컴프리헨션으로 b.price만 모아 sum에 넘겼어요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
