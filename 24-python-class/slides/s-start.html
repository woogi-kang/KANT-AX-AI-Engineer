3. self와 __init__

재료로 받지 않는 칸도 만들 수 있어요

[5]

class Bread:

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

self.baked = False

 

a = Bread("팥", 1000)

print(a.flavor, a.price, a.baked)

도장 0개, 판매 0개처럼 모두 같은 값으로 시작하는 칸에 써요.

재료로 받지 않고 처음 값을 정해 둔 칸도 만들 수 있어요. baked 칸은 괄호로 받지 않고 처음부터 False로 정했어요. 찍은 붕어빵은 모두 아직 안 구운 상태로 시작해요. 도장 카드의 도장 개수, 가게의 판매 개수처럼 처음엔 모두 같은 값으로 시작하는 칸에 써요. 6파트의 도장 카드 실습에서 이 모양을 다시 써요. 출력은 실제로 실행한 결과예요.
