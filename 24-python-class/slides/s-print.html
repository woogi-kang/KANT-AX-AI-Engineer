3. self와 __init__

__init__은 찍는 순간 저절로 불려요

[3]

class Bread:

def __init__(self, flavor, price):

print("반죽 붓는 중:", flavor)

self.flavor = flavor

self.price = price

 

a = Bread("팥", 1000)

b = Bread("슈크림", 1200)

print(a.flavor, b.flavor)

확인용

찍을 때마다

직접 부르지 않아요

a.__init__()이라고 치지 않았는데, 찍는 줄마다 한 번씩 출력됐어요.

언제 쓰나요

붕어빵마다 꼭 있어야 하는 값을 찍는 순간 넣어 둘 때 써요.

__init__이 정말 저절로 불리는지 print를 넣어 확인해 봐요. __init__ 첫 줄에 반죽 붓는 중이라는 출력을 넣었어요. 우리는 __init__을 부르는 줄을 한 번도 적지 않았어요. 그런데 Bread를 찍는 두 줄마다 한 번씩 출력이 나왔어요. 파이썬이 찍을 때마다 __init__을 찾아서 불러 준 거예요. 붕어빵마다 꼭 있어야 하는 값을 찍는 순간 넣어 두고 싶을 때 __init__을 써요. 확인이 끝나면 print 줄은 지워도 돼요. 출력은 실제로 실행한 결과예요.
