4. 메서드

틀 안의 함수가 메서드예요

[1]

class Bread:

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

 

def intro(self):

print(self.flavor, "붕어빵", self.price, "원")

 

a = Bread("팥", 1000)

b = Bread("슈크림", 1200)

a.intro()

b.intro()

Python

팥 붕어빵 1000 원

슈크림 붕어빵 1200 원

← 메서드. 첫 칸은 self

← 그 붕어빵의 맛과 가격

← 붕어빵에게 시켜요

intro(b1)처럼 넘기지 않고 a.intro()로 시켜요.

틀 안의 함수가 메서드이고, a.intro()처럼 붕어빵에게 시켜요. __init__ 아래에 def intro를 같은 깊이로 들여 썼어요. 틀 안에 있는 함수를 메서드라고 불러요. 메서드의 첫 칸도 self예요. 그래서 안에서 self.flavor, self.price로 그 붕어빵의 값을 꺼낼 수 있어요. 부를 때는 a.intro()처럼 붕어빵 이름 뒤에 점을 찍어요. 1파트에서는 intro(b1)처럼 딕셔너리를 함수에 넘겼는데, 이제는 붕어빵에게 직접 시켜요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
