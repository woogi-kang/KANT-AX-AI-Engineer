도장 카드: 처음 0개에서 손님마다 따로 쌓기

[3]

class Card:

def __init__(self, name):

self.name = name

self.stamps = 0

 

def add(self):

self.stamps = self.stamps + 1

 

kim = Card("kim")

lee = Card("lee")

kim.add()

kim.add()

kim.add()

lee.add()

print(kim.name, kim.stamps)

print(lee.name, lee.stamps)

같은 틀, 카드마다 칸이 따로

같은 틀로 찍어도 카드마다 칸이 따로라서 도장이 섞이지 않아요. 카페 도장 카드를 만들어요. 3파트에서 본 것처럼 stamps 칸은 재료로 받지 않고 0에서 시작해요. add 메서드는 자기 도장을 하나 늘려요. kim.add()를 세 번 부르면 self는 매번 kim이라서 kim의 도장만 3개가 돼요. lee는 따로 1개예요. 같은 틀로 찍었지만 카드마다 칸이 따로 있어서 서로 섞이지 않아요. 26에서 이 카드에 가게 이름처럼 모두가 같이 쓰는 값을 더해요. 출력은 실제로 실행한 결과예요.
