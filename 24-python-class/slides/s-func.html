3. self와 __init__

먼저 19에서 배운 함수로 한 번에 붙여 봐요

[1]

class Bread:

pass

 

def setup(bread, flavor, price):

bread.flavor = flavor

bread.price = price

 

a = Bread()

setup(a, "팥", 1000)

print(a.flavor, a.price)

Python

팥 1000

붙이는 함수

setup(a, "팥", 1000)

bread ← a

어느 붕어빵에 붙일지

flavor ← "팥"

넣을 맛

price ← 1000

넣을 가격

bread.flavor = flavor

a에 맛 칸을 붙이는 것과 같아요.

__init__으로 바로 가기 전에, 이미 아는 함수로 같은 일을 해 봐요. setup 함수는 붕어빵 하나와 맛, 가격을 받아요. 19에서 배운 대로 인자는 순서대로 들어가요. 첫 번째 칸 bread에는 a가, flavor에는 팥이, price에는 1000이 들어가요. 함수 안의 bread.flavor = flavor는 a에 맛 칸을 붙이는 것과 같아요. 첫 번째 칸이 어느 붕어빵에 붙일지 정한다는 것을 기억해 두세요. 이 칸이 곧 self가 돼요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
