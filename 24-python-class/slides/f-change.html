class Bread:

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

 

def discount(self, won):

self.price = self.price - won

 

def total(self, qty):

return self.price * qty

 

a = Bread("팥", 1000)

b = Bread("슈크림", 1200)

a.discount(200)

print(a.price, b.price)

print(a.total(3))

a.discount(200)의 self는 a예요. b의 가격은 그대로예요.

메서드에도 self 뒤에 매개변수를 더 둘 수 있어요. discount는 깎을 금액을 받아서 자기 가격에서 빼요. a.discount(200)을 부르면 self는 a라서 a의 가격만 800원이 되고 b는 1200원 그대로예요. 붕어빵마다 칸이 따로 있다는 게 이거예요. total은 개수를 받아 가격을 곱한 값을 return해요. 19에서 배운 대로 return한 값은 print로 찍거나 변수에 담아 써요. 출력은 실제로 실행한 결과예요.
