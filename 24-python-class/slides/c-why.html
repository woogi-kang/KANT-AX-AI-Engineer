1. 왜 필요한가

붕어빵을 딕셔너리로 담으면 값과 할 일이 따로 놀아요

[1]

b1 = {"flavor": "팥", "price": 1000}

b2 = {"flavor": "슈크림", "price": 1200}

 

def intro(bread):

print(bread["flavor"], "붕어빵", bread["price"], "원")

 

intro(b1)

intro(b2)

Python

팥 붕어빵 1000 원

슈크림 붕어빵 1200 원

[2]

b3 = {"flavr": "피자", "price": 1500}

intro(b3)

Python

KeyError: 'flavor'

값은 딕셔너리, 할 일은 함수

붕어빵 정보와 붕어빵 소개 함수가 서로 다른 곳에 있어요.

키를 틀려도 모르고 넘어가요

b3를 만들 때는 아무 말이 없다가, 소개할 때 KeyError가 나요.

값과 할 일을 한 틀에 묶어 두는 방법이 클래스예요.

지금까지 배운 것으로 붕어빵 가게를 만들어 봐요. 붕어빵 하나를 맛과 가격이 든 딕셔너리로 담고, 소개하는 일은 함수로 따로 만들었어요. 잘 돌아가지만 붕어빵 정보와 소개하는 함수가 서로 다른 곳에 있어요. 2번 셀처럼 키를 flavr로 잘못 적어도 만들 때는 아무 말이 없어요. 한참 뒤 소개할 때 KeyError가 나요. 값과 할 일을 한 틀에 묶어 두고, 찍을 때 재료를 꼭 넣게 하는 방법이 클래스예요. 출력은 실제로 실행한 결과예요.
