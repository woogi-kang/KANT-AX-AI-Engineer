3. self와 __init__

self.를 빼면 재료가 붕어빵에 안 붙어요

[4]

class Bread:

def __init__(self, flavor, price):

flavor = flavor

price = price

 

a = Bread("팥", 1000)

print(a.flavor)

Python

AttributeError: 'Bread' object has no attribute 'flavor'

← 자기 자신에 다시 넣었을 뿐

a

붙은 칸이 없어요

✕

flavor = flavor

✓

self.flavor = flavor

붕어빵에 남길 값은 꼭 self.이름 = 값으로 적어요.

self.를 빼면 값이 붕어빵에 붙지 않아서 AttributeError가 나요. flavor = flavor는 들어온 재료를 자기 자신에게 다시 넣었을 뿐이에요. 붕어빵에는 아무 칸도 붙지 않았어요. 그래서 a.flavor를 꺼내면 그런 속성이 없다는 AttributeError가 나요. 20에서 함수 안에서 만든 변수는 함수가 끝나면 사라진다고 배웠어요. __init__도 함수라서 똑같아요. 붕어빵에 남기려면 꼭 self.이름 = 값으로 적어요. 출력은 실제로 실행한 결과예요.
