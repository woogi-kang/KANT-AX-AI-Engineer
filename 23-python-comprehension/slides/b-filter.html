2. 만들기와 고르기

뒤에 if를 붙이면 골라 담아요

[2]

big = []

for p in prices:

if p >= 5000:

big.append(p)

print(big)

print(list(filter(lambda p: p >= 5000, prices)))

print([p for p in prices if p >= 5000])

← 17의 골라 담기

← 21의 filter

← if를 뒤에 붙여요

[p for p in prices if p >= 5000]

← p는 그대로, 조건이 True인 p만 모여요

for 뒤에 if를 붙이면 조건이 True인 값만 골라 담아요. 17에서 for 안의 if로 골라 담던 일이고, 21에서는 filter로 썼어요. 이번에는 값을 바꾸지 않고 고르기만 해서 넣을 값 자리에 p를 그대로 적어요. p for p in이 같은 말을 되풀이하는 것 같지만, 앞의 p는 넣을 값이고 뒤의 p는 꺼낸 이름이에요. 세 방법 모두 [5000, 6500]이에요. 출력은 실제로 실행한 결과예요.
