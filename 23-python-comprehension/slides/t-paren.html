5. 오류와 함정

소괄호로 감싸면 리스트가 아니에요

[3]

prices = [4500, 5000, 6500, 3000]

print((p + 500 for p in prices))

print(list(p + 500 for p in prices))

Python

<generator object <genexpr> at 0x7f2ba871b440>

[5000, 5500, 7000, 3500]

← 튜플이 아니에요

← list로 감싸야 보여요

읽는 법: 소괄호는 달라고 하면 값을 하나씩 꺼내 주는 묶음이에요. 21의 map object와 비슷해요.

✕

(p + 500 for p in prices)

✓

[p + 500 for p in prices]

0x 뒤 숫자는 메모리 위치라서 화면마다 달라요.

컴프리헨션을 소괄호로 감싸면 리스트도 튜플도 아니에요. 찍어 보면 generator object가 나와요. 21의 map object처럼 달라고 하면 값을 하나씩 꺼내 주는 묶음이에요. list로 감싸야 결과가 보여요. 이번 챕터에서는 이 묶음을 따로 다루지 않아요. 리스트가 필요하면 대괄호로 써요. 0x 뒤 숫자는 메모리 위치라서 화면마다 달라요. 출력은 실제로 실행한 결과예요.
