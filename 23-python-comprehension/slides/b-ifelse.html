넣을 값 자리에 한 줄 if else를 넣으면 모든 값을 조건에 따라 바꿔 적어요. 17에서 배운 값1 if 조건 else 값2는 값 하나로 계산돼서 넣을 값 자리에 들어가요. 4500은 조건이 False라 보통, 5000은 True라 비쌈이 모여요. 고르지 않으니 개수는 네 개 그대로예요. 21에서 lambda에 한 줄 if else를 넣었던 것과 같은 이유예요. 출력은 실제로 실행한 결과예요.
