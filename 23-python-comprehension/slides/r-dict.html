3. 여러 데이터에 쓰기

중괄호와 키: 값으로 딕셔너리도 만들어요

[3]

menu = {"coffee": 4500, "latte": 5000, "cake": 6500}

print({m: p * 11 // 10 for m, p in menu.items()})

stock = {"coffee": 3, "latte": 0, "cake": 2}

print({m: n for m, n in stock.items() if n > 0})

print([m for m in stock if stock[m] == 0])

← 값을 10% 올린 딕셔너리

← 재고 있는 것만 남기기

← 키만 필요하면 리스트

{m: p * 11 // 10 for m, p in menu.items()}

← 키: 값을 앞에 적어요

{키: 값 for ...}는 딕셔너리, [값 for ...]는 리스트예요.

중괄호 안 넣을 값 자리에 키: 값을 적으면 딕셔너리가 만들어져요. 딕셔너리 컴프리헨션이라고 해요. 15의 items()로 메뉴 이름 m과 가격 p를 꺼내고, 키는 m 그대로, 값은 10% 올린 가격으로 적었어요. if를 붙이면 재고가 있는 메뉴만 남긴 딕셔너리가 돼요. 21의 filter는 키만 남겼는데, 이번에는 재고 숫자까지 같이 남아요. 키만 필요하면 마지막 줄처럼 리스트로 만들어요. 출력은 실제로 실행한 결과예요.
