가장 짧은 컴프리헨션: 값마다 10 더하기

[2]

numbers = [1, 2, 3]

print([x + 10 for x in numbers])

Python

[11, 12, 13]

← 21의 list(map(lambda x: x + 10, numbers))와 같아요

[넣을 값 for 이름 in 리스트]는 값마다 계산한 새 리스트예요.

[x + 10 for x in numbers]는 numbers의 값마다 10을 더한 새 리스트예요. numbers에서 x를 하나씩 꺼내 x + 10을 계산하고, 그 값을 모아요. 그림처럼 1은 11, 2는 12, 3은 13이 돼요. 결과는 21의 list(map(lambda x: x + 10, numbers))와 같아요. list와 lambda가 없어서 소리 내어 읽는 순서와 거의 같아요. 출력은 실제로 실행한 결과예요.
