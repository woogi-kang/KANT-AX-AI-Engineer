list(map(lambda x: x + 10, numbers))와 같아요. list도 lambda도 없어요.

읽는 법

numbers에서 x를 하나씩 꺼내, x + 10을 모은 리스트예요.

[넣을 값 for 이름 in 리스트]는 값마다 계산한 새 리스트예요.

21의 첫 예제를 컴프리헨션으로 써요. 대괄호 안에 x + 10 for x in numbers라고 적어요. numbers에서 x를 하나씩 꺼내 x + 10을 계산하고, 그 값을 모아 새 리스트를 만들어요. 결과는 21의 list(map(lambda x: x + 10, numbers))와 같은 [11, 12, 13]이에요. list와 lambda가 없어서 소리 내어 읽은 순서와 거의 같아요. 출력은 실제로 실행한 결과예요.
