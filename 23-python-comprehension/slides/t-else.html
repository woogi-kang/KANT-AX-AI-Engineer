5. 오류와 함정

뒤의 if에 else를 붙이면 SyntaxError가 나요

[1]

prices = [4500, 5000, 6500, 3000]

print([p for p in prices if p >= 5000 else 0])

Python

SyntaxError: invalid syntax

뒤의 if에 else

읽는 법: for 뒤의 if는 고르기라서 else를 받지 않아요.

고르기만 하려면 else를 빼요

✕

[p for p in prices if p >= 5000 else 0]

✓

[p for p in prices if p >= 5000]

모두 바꾸려면 if else를 for 앞으로 옮겨요

✕

[p for p in prices if p >= 5000 else 0]

✓

[p if p >= 5000 else 0 for p in prices]

SyntaxError는 실행 전에 나서 첫 줄 prices도 만들어지지 않아요.

for 뒤의 if에 else를 붙이면 invalid syntax가 나요. 2파트의 두 자리를 섞으면 나는 오류예요. for 뒤의 if는 고르기라서 else를 받지 않아요. 고르고 싶으면 else를 빼고, 모든 값을 바꾸고 싶으면 if else를 for 앞으로 옮겨요. SyntaxError는 셀을 실행하기 전에 나서 같은 셀의 첫 줄 prices도 만들어지지 않아요. 메시지 끝의 파일 이름과 줄 번호는 셀마다 달라서 그 부분은 빼고 옮겼어요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
