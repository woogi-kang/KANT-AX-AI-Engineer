5. 오류와 함정

뒤의 if에 else를 붙이면 SyntaxError가 나요

[1]

prices = [4500, 5000, 6500, 3000]

print([p for p in prices if p >= 5000 else 0])

Python

SyntaxError: invalid syntax

뒤에는 else 없음

else는 앞에서만

for 뒤의 if는 고르기라서 else를 받지 않아요. 바꾸려면 if else를 앞으로 옮겨요.

이렇게 고쳐요

고르기 또는 바꾸기

[p for p in prices if p >= 5000]

[p if p >= 5000 else 0 for p in prices]

오류 끝 괄호는 뺐어요

SyntaxError 끝의 (1234.py, line 2)는 셀마다 달라서 슬라이드에서 뺐어요.

셀 전체가 실행되지 않아요

SyntaxError는 실행 전에 나서 첫 줄 prices도 만들어지지 않아요.

2파트의 두 자리를 섞으면 나는 오류예요. 고르는 if 뒤에 else 0을 붙였더니 invalid syntax가 나요. for 뒤의 if는 고르기라서 else를 받지 않아요. 고르고 싶으면 else를 빼고, 모든 값을 바꾸고 싶으면 if else를 for 앞으로 옮겨요. SyntaxError는 셀을 실행하기 전에 나서 같은 셀의 첫 줄 prices도 만들어지지 않아요. 메시지 끝의 파일 이름과 줄 번호는 셀마다 달라서 뺐어요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
