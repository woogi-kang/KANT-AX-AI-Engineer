막히면 오류의 마지막 줄을 봐요

1

SyntaxError: invalid syntax

뒤의 if에 else를 붙였어요

else는 for 앞으로

2

NameError: name 'x' is not defined

앞과 뒤의 이름이 달라요

같은 이름으로

3

[None, None]이 같이 나와요

대괄호 안에서 print를 했어요

찍기는 for로

4

<generator object ...>가 나와요

소괄호로 감쌌어요

대괄호로

5

개수가 줄었어요

for 뒤에 if를 붙여 골랐어요

바꾸려면 if else를 앞에

6

한 줄이 너무 길어요

조건이나 할 일이 많아요

for나 def로 나누기

7

집합 순서가 슬라이드와 달라요

집합은 순서가 없어요

sorted()로 찍기

헷갈리면 같은 일을 for 문으로 먼저 써 보고 세 조각을 옮겨요.

이번 챕터에서 자주 만나는 일을 모았어요. 1번과 5번은 if 자리 때문에 생겨요. 뒤의 if는 고르기, 앞의 if else는 바꾸기예요. 2번은 이름이 어긋났을 때, 3번과 4번은 컴프리헨션을 리스트 만들기 말고 다른 데 쓰려다 생겨요. 6번처럼 한 줄이 길어지면 for나 def로 나누는 게 더 좋아요. 막히면 for 문으로 먼저 써 보고 넣을 값, for, if 세 조각을 대괄호 안으로 옮기면 돼요.
