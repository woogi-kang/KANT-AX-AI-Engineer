3. 여러 데이터에 쓰기

길이, 글자, range로도 만들어요

[1]

names = ["latte", "tea", "coffee"]

print([len(m) for m in names])

print([m[0] for m in names])

print([n * n for n in range(1, 6)])

Python

[5, 3, 6]

['l', 't', 'c']

[1, 4, 9, 16, 25]

← 함수도 불러요. 21의 map(len, names)

← 13의 글자 꺼내기

← 18의 range로 숫자 만들기

in 뒤에는 for로 돌 수 있는 것이면 다 와요.

넣을 값에는 함수 호출도, in 뒤에는 range도 올 수 있어요. len(m)을 적으면 이름마다 길이를 모아요. 21의 map(len, names)와 같은 결과예요. m[0]은 13에서 배운 글자 꺼내기라서 첫 글자만 모여요. in 뒤에는 for에 쓰던 것이면 무엇이든 와요. 18의 range(1, 6)을 넣으면 1부터 5까지 제곱한 리스트가 돼요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
