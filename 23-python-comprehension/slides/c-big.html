1. 왜 필요한가

for의 세 조각을 대괄호 안으로 옮겨 적어요

for로 쓰면

컴프리헨션으로 쓰면

up = []

for p in prices:

    if p >= 5000:

        up.append(p + 500)

up = [p + 500

      for p in prices

      if p >= 5000]

← ① 넣을 값

← ② 꺼내기

← ③ 고르기

빈 리스트와 append는 대괄호가 맡고, for와 if의 콜론은 빼요.

for 문의 세 조각을 대괄호 안으로 옮기면 컴프리헨션이 돼요. 초록색은 append 괄호 안의 넣을 값, 청록색은 하나씩 꺼내는 for, 빨간색은 고르는 if예요. 넣을 값을 맨 앞에 적고, 그 뒤에 for와 if를 콜론 없이 이어 적어요. 빈 리스트와 append는 대괄호가 대신해요. if 조각은 고를 때만 붙여요. 한 줄로 적어도 되는데 그림에서는 조각이 보이게 세 줄로 나눴어요.
