1. 왜 필요한가

for는 길고, map은 lambda까지 읽어야 해요

[1]

prices = [4500, 5000, 6500]

up = []

for p in prices:

up.append(p + 500)

print(up)

print(list(map(lambda p: p + 500, prices)))

Python

← 세 줄을 매번 적어요

← 괄호를 풀어 가며 읽어요

[p + 500 for p in prices]

← 한 줄인데 for처럼 읽혀요

for는 세 줄을 매번 적고, map은 lambda까지 풀어 읽어야 해요. 21의 장면으로 돌아가 모든 가격에 500원을 더해요. for와 append로 쓰면 읽기는 쉬운데 빈 리스트, for, append를 매번 적어요. map과 lambda로 쓰면 한 줄이지만 list 안의 map, map 안의 lambda를 차례로 풀어야 해요. 아래 줄처럼 대괄호 안에 for를 넣으면 한 줄로 쓰면서 for처럼 읽혀요. 이 모양이 리스트 컴프리헨션이에요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
