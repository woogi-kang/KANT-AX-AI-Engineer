print([p for p in prices if p >= 5000])

for보다 뒤인지 앞인지만 보면 돼요.

for 뒤의 if는 고르기, for 앞의 if else는 바꾸기예요. if가 들어갈 자리가 두 곳이라 헷갈리기 쉬워요. for 뒤에 붙은 if는 조건에 맞는 값만 남겨서 개수가 줄고, else를 쓰지 않아요. 넣을 값 자리에 들어간 if else는 모든 값을 바꿔 적어서 개수가 그대로이고, else가 꼭 있어야 해요. 자리를 바꿔 쓰면 생기는 오류는 5파트에서 봐요. 출력은 실제로 실행한 결과예요.
