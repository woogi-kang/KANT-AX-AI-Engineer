2. 만들기와 고르기

if가 뒤에 있으면 고르기, 앞에 있으면 바꾸기

[5]

print([p for p in prices if p >= 5000])

print([p if p >= 5000 else 0 for p in prices])

Python

[5000, 6500]

[0, 5000, 6500, 0]

뒤의 if

고르기

[p for p in prices if p >= 5000]

# [5000, 6500]

앞의 if else

바꾸기

[p if p >= 5000 else 0 for p in prices]

# [0, 5000, 6500, 0]

조건에 맞는 값만 남아요

else를 쓰지 않고, 개수가 줄어요.

모든 값을 바꿔 적어요

else가 꼭 있어야 하고, 개수가 그대로예요.

자리로 구분해요

for보다 뒤인지 앞인지 봐요.

if가 들어갈 자리가 두 곳이라 헷갈리기 쉬워요. for 뒤에 붙은 if는 고르기예요. 조건에 맞는 값만 남아서 개수가 줄고, else를 쓰지 않아요. 넣을 값 자리, 곧 for 앞에 들어간 if else는 바꾸기예요. 모든 값을 조건에 따라 바꿔 적어서 개수가 그대로이고, else가 꼭 있어야 해요. 5000원 미만을 0으로 바꾼 결과와 골라낸 결과를 비교해 보세요. 자리를 바꿔 쓰면 생기는 오류는 5파트에서 봐요. 출력은 실제로 실행한 결과예요.
