집합을 찍는 순서는 실행할 때마다 달라질 수 있어요.

중괄호 안에 키: 값 대신 값 하나만 적으면 집합이 만들어져요. 주문 기록에서 손님 이름만 모았어요. kim이 두 번 주문했지만 16의 집합 규칙대로 한 번만 남아서 3명이에요. 집합을 그대로 찍으면 순서가 실행할 때마다 다를 수 있어서 22의 sorted로 줄 세워 찍었어요. 괄호 모양으로 무엇을 만드는지 구분해요. 대괄호는 리스트, 값만 든 중괄호는 집합, 키: 값이 든 중괄호는 딕셔너리예요. orders는 앞 셀에서 만들었어요. 출력은 실제로 실행한 결과예요.
