대괄호 안에 넣을 값, for, if 순서로 적어요. 뒤의 if는 고르기, 앞의 if else는 바꾸기예요. 튜플은 꺼내 담기로 이름을 붙이고, 중괄호로 딕셔너리와 집합도 만들어요. 만든 리스트는 sum, max, sorted에 바로 넘겨요. 찍기만 하거나 여러 줄을 할 때는 for가 더 좋아요. 24에서는 클래스로 값과 할 일을 한 틀에 묶어요.
