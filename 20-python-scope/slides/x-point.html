적립 함수: get과 기본값으로 포인트 쌓기

[4]

def add_point(points, name, amount, rate=5):

points[name] = points.get(name, 0) + amount * rate // 100

 

points = {"kim": 300}

add_point(points, "kim", 9000)

add_point(points, "lee", 6500)

add_point(points, "lee", 10000, rate=10)

print(points)

포인트 딕셔너리를 넘겨, 적립률 기본값과 get으로 손님별 포인트를 쌓아요. 적립률 rate는 기본값 5%이고, 행사 때만 rate=10으로 넣어요. 처음 온 lee는 딕셔너리에 키가 없어서 15에서 배운 get(name, 0)으로 0에서 시작해요. kim은 300에 9000원의 5%인 450을 더해 750이 돼요. 받은 딕셔너리에 바로 넣으니 return 없이도 밖의 points에 쌓여요. 출력은 실제로 실행한 결과예요.
