def 줄에서 칸 = 값으로 기본값을 정해요

[4]

def order(menu_name, size="M"):

print(f"{menu_name} {size} 사이즈")

 

order("latte")

order("latte", "L")

Python

latte M 사이즈

latte L 사이즈

← 기본값

← size를 뺐어요

← size에 "L"을 넣었어요

← 기본값 M

← 넣은 값 L

괄호 안의 =는 앞뒤를 띄우지 않고 size="M"처럼 붙여 써요.

def 줄의 칸 뒤에 = 값을 적으면 그 칸의 기본값이 돼요. order("latte")처럼 size를 빼고 부르면 size에 "M"이 들어가요. order("latte", "L")처럼 넣으면 넣은 "L"이 들어가요. 기본값이 없는 menu_name은 19처럼 꼭 넣어야 해요. 괄호 안의 =는 앞뒤를 띄우지 않고 붙여 쓰는 게 관례예요. 출력은 실제로 실행한 결과예요.
