키워드 인자는 칸 이름을 적어서 넣어요. 순서를 외우지 않아도 돼요.

칸 이름을 붙여 넣으면 순서를 바꿔도 제자리를 찾아가요. size="L"을 먼저 적어도 size 칸에, menu_name="tea"는 menu_name 칸에 들어가요. qty는 넣지 않았으니 기본값 1이에요. 19에서 order(2, "latte")로 순서가 바뀌어 이상하게 찍혔던 문제를 이렇게 피할 수 있어요. 적은 순서대로 들어가는 인자는 위치 인자, 이름을 붙인 인자는 키워드 인자라고 해요. 둘을 같이 쓸 때는 위치 인자를 앞에 적어요. 출력은 실제로 실행한 결과예요.
