5. 리스트와 딕셔너리 넘기기

원본을 지키려면 copy()로 새로 만들어 돌려줘요

[4]

def with_item(cart, name):

new_cart = cart.copy()

new_cart.append(name)

return new_cart

 

my_cart = ["coffee"]

big_cart = with_item(my_cart, "cake")

print(my_cart)

print(big_cart)

Python

['coffee']

['coffee', 'cake']

복사본

my_cart

coffee

big_cart

coffee

cake

언제 어느 쪽?

원본을 고치는 게 목적이면 앞 장들처럼 바로 고쳐요. 원본은 두고 결과만 받고 싶으면 copy()로 새로 만들어 return해요.

함수가 받은 리스트를 고칠지, 새로 만들어 돌려줄지 정해서 써요.

원본 장바구니는 그대로 두고 하나 더한 장바구니를 따로 받고 싶을 때가 있어요. 함수 안에서 13의 copy로 복사본을 만들고, 복사본에 append한 뒤 return해요. my_cart는 coffee만 그대로이고 big_cart는 cake까지 들어 있어요. 원본을 바꾸는 게 목적이면 앞에서처럼 바로 고치고, 원본을 지키고 싶으면 복사본을 만들어 돌려줘요. 출력은 실제로 실행한 결과예요.
