함수 안에서는 밖이 보이고, 밖에서는 안이 보이지 않아요.

오늘 배울 두 가지를 그림 한 장에 담았어요. 왼쪽은 기본값이에요. def 줄에서 size 칸에 "M"을 미리 넣어 두면 부를 때 빼도 M이 들어가요. 오른쪽은 변수가 보이는 범위예요. 노트북에서 함수 밖에 만든 변수는 전역 변수, 함수 몸통에서 만든 변수와 매개변수는 지역 변수라고 해요. 함수 안에서는 바깥 변수를 읽을 수 있지만, 바깥에서는 함수 안의 변수를 볼 수 없어요. 함수가 끝나면 안쪽 상자가 통째로 사라지기 때문이에요.
