영수증 함수: 함수 안에서 함수 부르기

[2]

menu = {"coffee": 4500, "latte": 5000, "cake": 6500}

 

def calc_total(cart, menu):

total = 0

for name, qty in cart.items():

total += menu[name] * qty

return total

 

def print_receipt(cart, menu, rate=0):

total = calc_total(cart, menu)

sale = total * rate // 100

for name, qty in cart.items():

print(f"{name:<7}{qty}개 {menu[name] * qty:>7,}원")

print(f"할인 {rate:>2}% {sale:>7,}원")

print(f"결제 {total - sale:>7,}원")

Python

← 위에서 만든 함수

cart1 = {"coffee": 2, "cake": 1}

할인이 없으면 rate를 빼고, 있을 때만 rate=10처럼 넣어요.

합계 함수를 영수증 함수 안에서 불러, 할인율 기본값과 함께 영수증을 찍어요. 17에서 쓴 장바구니 딕셔너리를 그대로 써요. calc_total은 합계만 돌려주고, print_receipt는 그 함수를 불러 합계를 받은 뒤 할인과 결제 금액을 찍어요. 할인율 rate는 기본값 0이라서 할인이 없으면 빼고 불러요. 둘째 손님만 rate=10으로 키워드 인자를 넣었어요. 한글은 두 칸을 차지해서 13에서 본 것처럼 할인, 결제 뒤 빈칸 수를 맞췄어요. 출력은 실제로 실행한 결과예요.
