기억할 것

기본값

def f(a, b="M"):

기본값 칸은 def 줄 뒤쪽에

키워드 인자

f(1, b=2)

키워드 인자는 부를 때 뒤쪽에

지역 변수

total = 9000

함수 안에서 만들고, 끝나면 사라져요

전역 변수

shop = "KANT"

함수 밖에서 만들고, 안에서 읽어요

바깥 값 바꾸기

x = f(x)

global보다 return으로 돌려받아 바꿔요

리스트, 딕셔너리

cart.append(x)

넘긴 리스트는 원본이 바뀌어요

원본 지키기

cart.copy()

원본을 지키려면 복사해서 써요

다음 21에서는 함수를 값처럼 넘기는 lambda를 배워요.

함수 안에서 = 로 넣은 이름은 지역 변수이고, 바깥 값을 바꿀 땐 global보다 인자와 return을 써요. 기본값 칸은 def 줄 뒤쪽에 두고, 키워드 인자는 부를 때 뒤쪽에 적어요. 밖에서 만든 변수는 전역 변수라서 함수 안에서 읽을 수 있어요. 리스트와 딕셔너리는 넘긴 원본이 바뀐다는 점을 기억해요. 19와 20으로 함수를 마쳤고, 21에서는 함수를 값처럼 다른 함수에 넘기는 lambda를 봐요.
