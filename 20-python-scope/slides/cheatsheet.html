이번 챕터에서 쓴 모양을 한 장에 모았어요. 기본값 칸은 def 줄 뒤쪽에 두고, 키워드 인자는 부를 때 뒤쪽에 적어요. 함수 안에서 만든 변수와 매개변수는 지역 변수, 밖에서 만든 변수는 전역 변수예요. 바깥 값을 바꿔야 하면 global보다 인자로 넣고 return으로 돌려받는 쪽을 써요. 리스트와 딕셔너리는 넘긴 원본이 바뀐다는 점을 기억해요. 19와 20으로 함수를 마쳤어요.
