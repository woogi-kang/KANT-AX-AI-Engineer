2. 기본값과 키워드 인자

기본값과 키워드 인자는 뒤에 적어요

만들 때

[3]

def order(size="M", menu_name):

print(menu_name, size)

Python

SyntaxError: parameter without a default follows parameter with a default

✕

def order(size="M", menu_name):

✓

def order(menu_name, size="M"):

부를 때

[4]

order(size="L", "tea")

Python

SyntaxError: positional argument follows keyword argument

✕

order(size="L", "tea")

✓

order("tea", size="L")

두 오류 모두 실행하기 전에 SyntaxError로 알려 줘요.

기본값 칸은 def 줄 뒤쪽에, 키워드 인자는 부를 때 뒤쪽에 적어요. 함수를 만들 때 기본값이 있는 칸을 앞에 두면 SyntaxError가 나요. 기본값 없는 칸을 앞에, 기본값 있는 칸을 뒤에 둬요. 부를 때는 키워드 인자 뒤에 이름 없는 값을 적으면 SyntaxError가 나요. 이름 없는 값을 먼저 적어요. 두 오류는 실행하기 전에 문법 검사에서 걸려요. 실제 메시지 끝에는 셀마다 다른 파일 이름과 줄 번호가 괄호로 붙는데, 그 부분은 빼고 옮겼어요. 출력은 실제로 실행한 결과예요.
