4. 전역 변수

함수 밖에서 만든 변수는 안에서 읽을 수 있어요

[1]

shop = "KANT 카페"

 

def hello():

print(f"{shop}에 어서 오세요")

 

hello()

Python

KANT 카페에 어서 오세요

밖 (전역 변수)

hello() 안

안에 없으면 밖에서 찾아요

가게 이름처럼 바뀌지 않는 값은 밖에 두고 안에서 읽어도 괜찮아요.

함수 안에서 이름을 찾을 땐 먼저 안을 보고, 없으면 밖을 봐요. shop은 함수 밖에서 만들었어요. 이런 변수를 전역 변수라고 해요. hello 안에는 shop이 없지만 찍어 보면 KANT 카페가 잘 나와요. 그래서 함수 안에서 전역 변수를 읽을 수 있어요. 가게 이름처럼 바뀌지 않는 값은 전역 변수로 두고 읽기만 해도 괜찮아요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
