2. 기본값과 키워드 인자

기본값이 여러 개면 앞에서부터 채워요

[1]

def order(menu_name, size="M", qty=1):

print(f"{menu_name} {size} {qty}잔")

 

order("latte")

order("latte", "L")

order("latte", "L", 2)

order("latte", qty=3)

qty만 바꾸고 싶으면

순서대로 넣으면 size를 먼저 적어야 해요. qty=3처럼 칸 이름을 붙이면 size는 기본값으로 두고 qty만 바꿔요.

넣은 값은 앞 칸부터

"L"은 둘째 칸 size에, 2는 셋째 칸 qty에 들어가요. 넣지 않은 칸만 기본값이에요.

칸 이름 = 값으로 넣으면 원하는 칸만 고를 수 있어요.

기본값 칸이 두 개예요. 인자를 순서대로 넣으면 앞 칸부터 채우고, 넣지 않은 칸만 기본값을 써요. order("latte", "L", 2)는 size에 L, qty에 2가 들어가요. 그런데 잔 수만 3으로 바꾸고 싶을 땐 어떻게 할까요? 순서대로라면 size도 적어야 해요. 마지막 줄처럼 qty=3으로 칸 이름을 붙여 넣으면 size는 기본값 M으로 두고 qty만 바꿀 수 있어요. 이렇게 이름을 붙여 넣는 인자를 키워드 인자라고 해요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
