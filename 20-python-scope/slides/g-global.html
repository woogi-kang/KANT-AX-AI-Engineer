global을 적으면 바깥 변수를 바꿔요

count = 0

 

def visit():

global count

count = count + 1

global은 있다는 것만 알아 둬요. 다음 장에서 더 나은 방법을 봐요.

함수 첫 줄에 global count를 적으면 그 함수 안의 count는 바깥 count라는 뜻이 돼요. 그래서 세 번 부르면 바깥 count가 3이 돼요. 이런 방법이 있다는 것만 알아 두면 돼요. 함수가 여러 개인데 모두 바깥 값을 바꾸면, 값이 이상해졌을 때 어느 함수가 바꿨는지 찾기 어려워요. 다음 장에서 return으로 푸는 방법과 비교해요. 출력은 실제로 실행한 결과예요.
