정리

막히면 오류의 마지막 줄을 봐요

1

SyntaxError: parameter without a default follows ...

def 줄에서 기본값 칸을 앞에 뒀어요

기본값 칸을 뒤로

2

SyntaxError: positional argument follows keyword argument

부를 때 이름 없는 값을 뒤에 적었어요

위치 인자를 앞으로

3

NameError: name 'total' is not defined

함수 안의 지역 변수를 밖에서 썼어요

return으로 돌려받기

4

UnboundLocalError: cannot access local variable

함수 안에서 바깥 변수를 읽다가 바꿨어요

인자로 받고 return

5

함수 안에서 바꿨는데 밖이 그대로예요

안에서 = 로 새 지역 변수를 만들었어요

x = 함수(x)로 받기

6

함수에 넘긴 리스트가 바뀌었어요

받은 리스트를 append로 고쳤어요

copy()로 복사해 쓰기

7

부를 때마다 값이 처음으로 돌아가요

지역 변수는 부를 때마다 새로 생겨요

값을 밖에 두고 넘기기

헷갈리면 함수 안과 밖에서 print로 같은 변수를 찍어 비교해 봐요.

이번 챕터에서 자주 만나는 일을 모았어요. 1번과 2번은 기본값과 키워드 인자의 순서 규칙이에요. 3번과 4번은 지역 변수와 전역 변수를 섞어 쓸 때 나요. 5번부터 7번은 오류 없이 결과만 이상한 경우예요. 함수 안과 밖에서 같은 변수를 찍어 보면 어느 상자의 값인지 보여요.
