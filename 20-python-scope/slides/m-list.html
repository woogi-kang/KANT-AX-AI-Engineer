5. 리스트와 딕셔너리 넘기기

리스트를 넘기고 안에서 append하면 원본이 바뀌어요

[1]

def add_item(cart, name):

cart.append(name)

 

my_cart = ["coffee"]

add_item(my_cart, "cake")

add_item(my_cart, "latte")

print(my_cart)

이름 두 개, 리스트 하나

← return 없이도 바뀌었어요

my_cart와 cart는 리스트 하나를 같이 가리켜요.

리스트를 함수에 넘기면 복사본이 아니라 같은 리스트가 들어가서, 안에서 고치면 원본이 바뀌어요. 장바구니 리스트를 함수에 넘기고 안에서 append했어요. return이 없는데도 밖에서 my_cart를 찍으면 cake과 latte가 들어 있어요. my_cart와 cart는 이름만 둘이고 리스트는 하나예요. 그래서 cart로 고치면 my_cart로 봐도 바뀌어 있어요. 원본을 지키는 방법은 22쪽에서 봐요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
