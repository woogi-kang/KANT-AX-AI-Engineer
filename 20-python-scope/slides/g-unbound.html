4. 전역 변수

읽다가 바꾸면 UnboundLocalError가 나요

[3]

count = 0

 

def visit():

count = count + 1

 

visit()

Python

① = 로 넣으니 지역 변수예요

② 오른쪽 count부터 읽어요

UnboundLocalError: cannot access local variable 'count' where it is not associated with a value

③ 지역 count에는 아직 값이 없어요

앞 장 규칙 그대로예요. 안에서 = 로 넣는 이름은 처음부터 지역 변수예요.

함수 안에 count = 이 있으면 count는 처음부터 지역 변수라서, 바깥 count를 읽지 못해요. 방문자 수를 세려고 함수 안에서 count = count + 1을 했는데 UnboundLocalError가 나요. 파이썬은 실행하기 전에 함수 몸통을 훑어서 = 로 값을 넣는 이름을 지역 변수로 정해요. 그래서 count는 지역 변수가 됐어요. 오른쪽 count + 1을 계산하려고 지역 count를 읽는데, 아직 아무 값도 없어요. 메시지가 그 뜻이에요. 앞 장의 규칙이 그대로 적용된 거예요. 출력은 실제로 실행한 결과예요.
