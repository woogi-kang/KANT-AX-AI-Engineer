4. 전역 변수

읽다가 바꾸면 UnboundLocalError가 나요

[3]

count = 0

 

def visit():

count = count + 1

 

visit()

Python

UnboundLocalError: cannot access local variable 'count' where it is not associated with a value

count는 지역 변수로 정해짐

1

count = ... 이 함수 안에 있어요

그래서 count는 이 함수의 지역 변수예요

2

오른쪽 count + 1을 먼저 계산해요

지역 count를 읽으려는데

3

지역 count에는 아직 값이 없어요

UnboundLocalError

앞 장과 같은 규칙이에요

함수 안에서 = 로 넣는 이름은 지역 변수예요. 읽기만 하면 바깥을 보지만, 넣는 순간 지역 변수가 돼요.

방문자 수를 세려고 함수 안에서 count = count + 1을 했어요. 바깥에 count가 있는데도 UnboundLocalError가 나요. 메시지는 지역 변수 count에 아직 값이 없어서 읽을 수 없다는 뜻이에요. 파이썬은 실행하기 전에 함수 몸통을 훑어서 = 로 값을 넣는 이름을 지역 변수로 정해요. 그래서 count는 지역 변수가 됐고, 오른쪽 count + 1을 계산하려고 지역 count를 읽는데 아직 아무 값도 없어요. 앞 장의 규칙이 그대로 적용된 거예요. 출력은 실제로 실행한 결과예요.
