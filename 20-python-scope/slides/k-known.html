2. 기본값과 키워드 인자

키워드 인자는 이미 써 봤어요

[5]

print("coffee", "latte", sep=" / ")

print("coffee", end=" ")

print("latte")

print(sorted([5000, 4500, 6500], reverse=True))

Python

coffee / latte

coffee latte

[6500, 5000, 4500]

← 13 · 기본값은 빈칸 하나

← 13 · 기본값은 줄바꿈

← 16 · 기본값은 False

print()만 쳐도 빈 줄이 찍히는 것도 end의 기본값이 줄바꿈이라서예요.

print의 sep, end와 sorted의 reverse가 이미 써 본 키워드 인자예요. 13에서 print의 sep과 end를, 16에서 sorted의 reverse=True를 썼어요. 셋 다 기본값이 있는 칸이라 평소에는 빼고 썼어요. sep의 기본값은 빈칸 하나라서 값 사이가 한 칸씩 띄워졌고, end의 기본값은 줄바꿈이라서 print마다 줄이 바뀌었어요. 18의 구구단에서 print()로 줄을 바꾼 것도 이 기본값 덕분이에요. 출력은 실제로 실행한 결과예요.
