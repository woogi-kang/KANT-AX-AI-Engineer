주문 함수: 기본값과 재고 딕셔너리

[1]

def take_order(stock, name, qty=1):

if stock[name] < qty:

print(f"{name} {qty}개: 재고가 {stock[name]}개뿐이에요")

return False

stock[name] -= qty

print(f"{name} {qty}개 나갔어요")

return True

 

stock = {"coffee": 3, "latte": 1, "cake": 2}

take_order(stock, "coffee", 2)

take_order(stock, "latte")

take_order(stock, "latte")

take_order(stock, "cake", qty=3)

print(stock)

Python

coffee 2개 나갔어요

latte 1개 나갔어요

latte 1개: 재고가 0개뿐이에요

cake 3개: 재고가 2개뿐이에요

{'coffee': 1, 'latte': 0, 'cake': 2}

← 기본값: 한 개 주문은 빼고 불러요

← 모자라면 여기서 끝나요

← 받은 딕셔너리 칸을 줄여요

← 밖의 stock이 줄었어요

기본값, 딕셔너리 넘기기, return을 모아 주문 함수를 만들어요. qty는 기본값 1이라 한 개 주문은 빼고 불러요. 재고가 모자라면 안내를 찍고 return False로 바로 나가요. 19에서 본 return을 만나면 함수가 끝나는 성질이에요. 재고가 있으면 받은 딕셔너리 칸을 줄이고 True를 돌려줘요. 마지막에 밖에서 stock을 찍으면 실제로 줄어 있어요. 돌려준 True, False는 이 셀에서는 쓰지 않았지만, 19의 can_order처럼 if 뒤에 바로 쓸 수 있어요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
