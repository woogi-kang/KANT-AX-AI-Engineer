[2]

price = 5000

print("안:", price)

 

set_price()

print("밖:", price)

Python

안: 5000

밖: 4500

새 지역 변수

밖 price

4500

안 price

5000

이름만 같은 다른 상자예요

함수 안에서 price = 5000처럼 값을 넣으면 안쪽에 price를 새로 만들어요. 바깥 price는 손대지 않아요. 함수가 끝나면 안쪽 price만 사라져요.

가격을 바꾸려던 거라면

바깥 price는 그대로 4500이에요. 바깥 값을 바꾸는 법은 두 장 뒤에 봐요.

함수 안에서 = 로 값을 넣으면 그 이름은 지역 변수가 돼요.

바깥에 price 4500이 있어요. set_price 안에서 price = 5000을 넣고 찍으면 5000이 나와요. 그런데 밖에서 다시 찍으면 4500 그대로예요. 함수 안에서 = 로 값을 넣으면 바깥 변수를 바꾸는 게 아니라 같은 이름의 지역 변수를 새로 만들기 때문이에요. 이름만 같고 서로 다른 상자 두 개예요. 바깥 값을 바꾸고 싶었다면 이 방법으로는 안 돼요. 출력은 실제로 실행한 결과예요.
