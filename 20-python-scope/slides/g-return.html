4. 전역 변수

바깥 값을 바꿀 땐 return으로 돌려받아요

global로 바꾸기

[4]

count = 0

 

def visit():

global count

count = count + 1

 

visit()

visit()

visit()

print(count)

Python

3

← count가 바뀌는지 안 보여요

return으로 돌려받기

[5]

def visit(count):

return count + 1

 

count = 0

count = visit(count)

count = visit(count)

count = visit(count)

print(count)

Python

3

← 바뀌는 줄이 보여요

함수는 받은 값으로 계산해서 돌려주기만 해요. 이쪽을 권해요.

바깥 값을 바꿔야 하면 global보다 인자로 넣고 return으로 돌려받는 쪽을 권해요. 같은 방문자 세기를 두 가지로 썼어요. 왼쪽은 global로 함수 안에서 바깥 count를 직접 바꿔요. visit()만 보면 count가 바뀌는지 알 수 없어요. 오른쪽은 count를 인자로 넣고, 1 더한 값을 돌려받아 다시 count에 담아요. count가 바뀌는 줄이 밖에 그대로 보여요. 함수는 받은 값으로 계산해서 돌려주기만 하니까 따로 떼어 확인하기도 쉬워요. 출력은 실제로 실행한 결과예요.
