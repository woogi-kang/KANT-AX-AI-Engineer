return으로 돌려받기

[5]

def visit(count):

return count + 1

 

count = 0

count = visit(count)

count = visit(count)

count = visit(count)

print(count)

Python

3

바뀌는 곳이 보여요

return 쪽을 권해요

count가 바뀌는 줄이 count = visit(count)로 눈에 보여요. 함수는 받은 값으로 계산해서 돌려주기만 해요.

같은 방문자 세기를 두 가지로 썼어요. 왼쪽은 global로 함수 안에서 바깥 count를 직접 바꿔요. visit()만 보면 count가 바뀌는지 알 수 없어요. 오른쪽은 count를 인자로 넣고, 1 더한 값을 돌려받아 다시 count에 담아요. count가 바뀌는 줄이 밖에 그대로 보여요. 함수는 받은 값으로 계산해서 돌려주기만 하니까 따로 떼어 확인하기도 쉬워요. 실무에서는 오른쪽처럼 return으로 돌려받는 쪽을 권해요. 출력은 실제로 실행한 결과예요.
