from sklearn.linear_model import LogisticRegression

 

# 표준화된 학습 데이터 + 정답

model = LogisticRegression(max_iter=1000)

model.fit(X_train_scaled, y_train)

m100 = LogisticRegression()

m100.fit(X_train_scaled, y_train)

print("기본값 100:", m100.coef_[0].round(3), m100.n_iter_)

Python

기본값 100: [ 0.873 -0.37 0.877] [6]

실제로 걸은 횟수

6번

한도 1000이든 기본값 100이든 6번에 멈춰서 결과가 같아요.

수업 노트북의 셀 4예요. LogisticRegression 괄호 안의 max_iter는 최대 반복 횟수예요. 49에서 경사 하강법이 조금씩 고쳐 가며 걸었던 걸음 수의 한도예요. 1000이라고 적으면 1000번까지 걸어도 된다는 뜻이에요. fit에는 51처럼 표준화한 학습용 표를 먼저, 정답 y_train을 나중에 넣어요. 아래 셀은 max_iter를 빼고 기본값 100으로 학습한 거예요. n_iter_는 실제로 걸은 횟수인데 6번이에요. 6번 만에 더 고칠 곳이 없어서 멈췄어요. 그래서 가중치가 똑같아요. 학생이 7명뿐이라 금방 끝나요. 데이터가 크면 100번으로 모자랄 때가 있어서 수업처럼 넉넉히 적어 둬요. 출력은 실제로 실행한 결과예요.
