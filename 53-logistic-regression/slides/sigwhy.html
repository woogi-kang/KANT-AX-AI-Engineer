4. 확률 구하기

합계가 아무리 커도 1을, 아무리 작아도 0을 넘지 않아요

[14]

import numpy as np

 

for z in [-10, -5, -2, 0, 2, 5, 10]:

e = np.exp(-z)

print(f"합계 {z:3}: np.exp(-z) = {e:10.4f}, 확률 = {1 / (1 + e):.4f}")

Python

합계 -10: np.exp(-z) = 22026.4658, 확률 = 0.0000

합계 -5: np.exp(-z) = 148.4132, 확률 = 0.0067

합계 -2: np.exp(-z) = 7.3891, 확률 = 0.1192

합계 0: np.exp(-z) = 1.0000, 확률 = 0.5000

합계 2: np.exp(-z) = 0.1353, 확률 = 0.8808

합계 5: np.exp(-z) = 0.0067, 확률 = 0.9933

합계 10: np.exp(-z) = 0.0000, 확률 = 1.0000

회색 두 줄은 곡선의 식이에요. 참고, 읽기만 해요.

합계가 아주 작으면

np.exp(-z)는 아주 큰 수

1 ÷ (1 + 아주 큰 수)

0에 가까워요

합계가 아주 크면

np.exp(-z)는 0에 가까운 수

1 ÷ (1 + 0에 가까운 수)

1에 가까워요

합계가 0이면

np.exp(-z)는 1

1 ÷ (1 + 1)

딱 0.5

1을 늘 1보다 큰 수로 나누니 1을 못 넘고, 양수끼리 나누니 0 밑으로 안 가요.

S자 곡선이 왜 0과 1 밖으로 못 나가는지 숫자로 확인해 봐요. 곡선은 1을 '1 더하기 np.exp(-z)'로 나눠요. np.exp(-z)는 합계가 클수록 작아지고, 작을수록 커지는 수예요. 0보다 작아지지는 않아요. 합계가 -10처럼 아주 작으면 np.exp(-z)가 2만이 넘어서, 1을 아주 큰 수로 나눈 확률은 0에 가까워요. 합계가 10처럼 아주 크면 np.exp(-z)가 0에 가까워서, 1을 1보다 아주 조금 큰 수로 나눈 확률은 1에 가까워요. 나누는 수가 늘 1보다 크니 1을 넘지 못하고, 결과가 마이너스가 될 일도 없어요. 출력의 0.0000과 1.0000은 소수 넷째 자리에서 반올림해서 그렇게 보일 뿐, 실제로 0이나 1이 되지는 않아요. 직선과 달리 이 곡선은 확률로 읽을 수 있어요. 식은 참고로만 읽어요. 이 셀은 이해를 도우려고 더했어요. 출력은 실제로 실행한 결과예요.
