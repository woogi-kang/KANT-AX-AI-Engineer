4. 확률 구하기

predict는 답을 배열로 줘요. 한 명이라 [0]으로 꺼내요

predict = model.predict(new_scaled)[0]

학생 여러 명을 받아 답도 여러 개

0번 칸 하나

[False]

배열 (답 1개)

[0]

False

값 하나

"합격" if predict else "불합격"

불합격

17의 한 줄 if: False라서 else 쪽

모델은 합격 확률 48.37%가 0.5보다 작아서 False라고 답했어요.

predict는 학생 여러 명을 한꺼번에 받을 수 있어서 답도 배열로 돌려줘요. 오늘은 한 명만 넣었으니 칸이 하나인 배열 [False]가 나와요. 뒤에 대괄호 0을 붙이면 그 칸의 값 False 하나가 꺼내져요. 수업 코드는 이 값을 predict라는 변수에 담고, 17에서 배운 한 줄 if로 글자를 골랐어요. predict가 True면 '합격', 아니면 '불합격'이에요. False라서 불합격이 찍혔어요. 모델이 False라고 답한 이유는 합격 확률 48.37%가 기준 0.5보다 작기 때문이에요. 확률은 다음 장에서 꺼내요. 출력은 실제로 실행한 결과예요.
