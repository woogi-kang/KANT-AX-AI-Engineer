3. 모델 학습하기

LogisticRegression은 이름은 회귀지만 분류 모델이에요

from sklearn.linear_model import LogisticRegression

패키지 (48)

모듈: 선형 모델 서랍

클래스: 대문자로 시작 (51)

linear_model 서랍 안

LinearRegression

맞히는 것: 점수 같은 숫자

48, 50

SGDRegressor

맞히는 것: 숫자, 조금씩 고쳐 가며

49, 51

LogisticRegression

맞히는 것: True, False와 그 확률

오늘

세 모델 모두 가중치를 곱해 더해요. 그래서 같은 서랍에 있어요.

오늘 모델은 48에서 LinearRegression을 꺼낸 linear_model 서랍에 함께 들어 있어요. 이름은 LogisticRegression, 로지스틱 회귀예요. Regression, 회귀라는 말이 붙어 있지만 점수 같은 숫자를 맞히지 않아요. True와 False 중 하나를 고르는 분류 모델이에요. 앞의 Logistic은 S자 곡선의 이름인 로지스틱 함수에서 왔어요. 세 모델 모두 열마다 가중치를 곱해 더하는 계산을 해서 같은 서랍에 있어요. 51에서 본 것처럼 대문자로 시작하니 클래스예요. 괄호로 모델 객체를 만들어 써요.
