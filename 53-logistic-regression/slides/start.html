import pandas as pd

 

df = pd.DataFrame({

"study_hours": [1, 2, 3, 4, 5, 2, 3, 5, 4, 1],

"sleep_hours": [6, 8, 5, 7, 8, 5, 8, 6, 6, 8],

"practice_count": [10, 15, 20, 25, 30, 12, 28, 22, 32, 8],

"score": [47, 58, 60, 76, 87, 49, 73, 77, 79, 52],

})

 

X = df[["study_hours", "sleep_hours", "practice_count"]]

y = df["score"] >= 60

 

print(f"학생 {len(X)} 명, X : {X.shape[1]}개")

print(df[["score"]].assign(passed=y).head())

Python

← 50, 51과 같은 학생 10명

← 문제 X: 열 셋은 그대로

← 정답 y: 점수 대신 합격, 불합격

← 출력은 2파트에서 읽어요

50의 y는 점수였어요. 오늘의 y는 60점을 넘었는지예요.

새 노트북 맨 위 셀은 수업 노트북 05의 셀 1이에요. 덱에서 수업 셀 몇이라고 부르면 수업 노트북의 셀 번호예요. 셀 왼쪽 대괄호 숫자는 이 덱의 셀을 위에서부터 차례로 실행했을 때의 번호예요. 학생 10명의 공부 시간, 수면 시간, 연습 횟수, 점수 표는 50, 51과 똑같아요. 문제 X도 같은 세 열이에요. 달라진 곳은 정답 y 한 줄이에요. 50에서는 y가 점수 그 자체였는데, 오늘은 점수가 60점 이상인지를 담아요. 출력 두 줄은 2파트에서 하나씩 읽어요.
