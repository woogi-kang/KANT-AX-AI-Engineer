4. 확률 구하기

predict_proba는 두 칸을 줘요. classes_ 순서대로 불합격, 합격

[15]

print(model.predict(new_scaled))

print(model.predict_proba(new_scaled))

Python

[16]

print(model.predict_proba(new_scaled)[0])

print(model.predict_proba(new_scaled)[0, 1])

Python

[0.51633177 0.48366823]

0.48366823060259606

← [0]: 0번 줄

[0, 1]: 0번 줄의 1번 칸 (iloc처럼 줄 번호, 칸 번호)

predict_proba 결과 (1줄, 2칸)

0번 칸: False

0.5163

불합격 확률

1번 칸: True

0.4837

합격 확률

classes_가 [False, True]라서 이 순서예요 (3파트)

f"{pass_proba:.2%}"

100을 곱해 소수 둘째 자리까지, 끝에 % (13의 :.2f와 비슷해요)

48.37%

두 칸을 더하면 1이에요. 합격 확률은 1번 칸이라 [0, 1]로 꺼내요.

predict_proba는 확률을 꺼내요. proba는 probability, 확률의 줄임말이에요. 결과는 대괄호가 두 겹인 표 모양이에요. 학생 한 명이라 줄은 하나, 보기가 둘이라 칸은 둘이에요. 칸 순서는 3파트에서 본 classes_ 순서라서 0번 칸이 False, 곧 불합격 확률 0.5163이고 1번 칸이 True, 합격 확률 0.4837이에요. 대괄호 0만 쓰면 줄 하나가 통째로 나와요. 대괄호 안에 0, 1을 쓰면 0번 줄의 1번 칸, 합격 확률 하나가 나와요. 셀 2의 iloc처럼 줄 번호, 칸 번호 순서예요. 이 값을 f-string에서 :.2%로 찍으면 100을 곱해 소수 둘째 자리까지 퍼센트로 보여 줘서 48.37%가 돼요. 출력은 실제로 실행한 결과예요.
