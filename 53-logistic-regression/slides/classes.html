3. 모델 학습하기

classes_는 보기 두 개를 정렬한 순서예요. False가 0번, True가 1번

model.classes_.tolist()  →  [False, True]

False

True

0번 칸

False

불합격

1번 칸

True

합격

False는 0, True는 1이라서(12) 작은 쪽인 False가 먼저 서요.

4파트의 predict_proba가 이 순서로 두 칸을 줘요. 1번 칸이 합격 확률이에요.

수업 셀 4의 첫 출력은 classes_예요. 모델이 y_train에서 본 보기를 정렬해서 담아요. 우리 y는 True와 False 두 가지라서 False, True 순서예요. 12에서 True는 1, False는 0으로 계산된다고 배웠죠. 작은 False가 0번 칸, True가 1번 칸이에요. tolist()는 배열을 리스트로 바꿔 찍으려고 붙였어요. 이 순서가 왜 중요한지는 4파트에서 봐요. predict_proba가 확률 두 개를 이 순서대로 줘서, 1번 칸이 합격 확률이 돼요. 출력은 실제로 실행한 결과예요.
