$ uv --version

uv 0.11.32 (x86_64-unknown-linux-gnu)

uv 설치는 컴퓨터마다 한 번만 해요. Mac은 터미널에서 brew install uv를 쳐요. brew --version에 버전이 나오면 Homebrew가 이미 있어요. Windows는 시작 메뉴에서 PowerShell을 열어 winget 명령을 치고, 약관 동의를 물으면 Y를 쳐요. 설치가 끝나면 터미널을 새로 열어야 uv 명령을 찾아요. uv --version에 버전이 나오면 준비가 끝났어요. 숫자는 설치한 날에 따라 달라요. brew와 winget 설치 화면은 버전과 컴퓨터마다 달라서 옮기지 않았고, uv --version은 실제로 실행한 결과예요.

pyproject.toml은 이 프로젝트가 무엇이고 무엇이 필요한지 적은 설명서예요. name은 프로젝트 이름, requires-python은 쓸 수 있는 파이썬 버전이에요. dependencies는 이 프로젝트가 쓰는 패키지 목록이고, 지금은 비어 있어요. 이 파일은 손으로 고치지 않고 uv add, uv remove로 바꿔요. .python-version은 이 폴더에서 쓸 파이썬 버전이에요. main.py는 uv가 만들어 준 연습용 코드이고 다음 장에서 실행해요.

인터넷 자료나 옛 강의에 왼쪽 명령이 나오면 오른쪽 uv 명령으로 바꿔 쳐요. 예전에는 왼쪽 여섯 단계를 순서대로 직접 챙겼고, 하나라도 빼먹으면 ModuleNotFoundError가 났어요. uv로는 init, add, run, sync만 쳐요. 가장 자주 만나는 건 pip install 패키지예요. pip로 넣으면 pyproject.toml과 uv.lock에 적히지 않아서 다른 컴퓨터에서 uv sync로 받을 수 없어요. 뺄 때도 차이가 나요. pip uninstall fastapi는 fastapi 하나만 지우고 따라온 10개를 남기고, uv remove는 11개를 모두 빼요. 예전 방식은 따라 치지 않고 눈으로만 봐요. 예전 방식의 남은 10개는 tools/demo.sh로 실제로 실행한 결과예요.
