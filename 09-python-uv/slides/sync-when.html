6. 다른 컴퓨터에서 그대로

uv sync는 이럴 때 쳐요

1

clone한 직후

git clone 주소

cd 폴더

uv sync

2

pull로 uv.lock이 바뀐 뒤

git pull origin main

uv sync

3

uv run도 먼저 맞춰요

uv run main.py

실행 전에 sync를 알아서 해요

팀원이 패키지를 넣고 push했으면, pull 뒤 uv sync로 내 .venv를 맞춰요.

1번은 다른 사람 프로젝트를 처음 받을 때예요. 2번은 팀원이 uv add로 패키지를 넣고 push한 경우예요. pull로 pyproject.toml과 uv.lock은 바뀌었지만 내 .venv에는 아직 그 패키지가 없어요. uv sync가 .venv를 uv.lock에 맞춰요. 3번은 uv run도 실행 전에 같은 일을 해서, sync를 잊어도 uv run이면 돌아간다는 뜻이에요. 그래도 처음 받을 땐 uv sync로 설치가 끝났는지 눈으로 확인해요.
