6. 다른 컴퓨터에서 그대로

uv sync는 이럴 때 쳐요

언제

치는 명령

왜

1

clone한 직후

git clone 주소
cd 폴더
uv sync

받은 폴더에는 .venv가 없어요

2

pull로 uv.lock이 바뀐 뒤

git pull origin main
uv sync

목록은 바뀌었지만 내 .venv는 그대로예요

3

잊었다면

uv run main.py

uv run이 실행 전에 sync를 알아서 해요

uv sync는 받은 프로젝트를 처음 열 때와 팀원이 패키지를 바꿨을 때 쳐요. 1번은 다른 사람 프로젝트를 처음 받았을 때예요. 2번은 팀원이 uv add로 패키지를 넣고 push한 경우예요. pull로 pyproject.toml과 uv.lock은 바뀌었지만 내 .venv에는 아직 그 패키지가 없어요. 3번처럼 uv run도 실행 전에 같은 일을 해서, sync를 잊어도 uv run이면 돌아가요. 그래도 처음 받을 땐 uv sync로 설치가 끝났는지 눈으로 확인해요. 34쪽에서 2번을 실제로 해 봐요.
