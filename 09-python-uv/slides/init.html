← 파이썬이 없어서 받았어요

uv init 뒤에 적은 이름으로 프로젝트 폴더가 생겨요. 수업 저장소 hello-git 안이 아니라 홈 폴더에서 시작해요. 컴퓨터에 파이썬이 없어서 uv가 3.14.6을 받았어요. 파이썬이 이미 있는 컴퓨터는 Downloading 줄이 없고 있던 버전을 써요. uv init은 git init까지 해 줘서 .git도 생겨요. 출력은 tools/demo.sh로 실제로 실행한 결과이고, 긴 줄은 화면 폭에 맞춰 두 줄로 나눴으며 ls -a 출력은 오른쪽 그림과 같아서 뺐어요.
