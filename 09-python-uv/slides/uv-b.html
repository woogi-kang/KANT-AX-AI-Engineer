3. uv는 무엇이 다른가

uv 하나가 네 가지를 다 해요

uv

파이썬 설치

필요하면 알아서 받아요

가상환경

uv run이 만들고 켜요

패키지 설치

uv add

목록 적기

uv.lock에 자동으로

명령은 uv 하나로 시작해요. 가상환경을 켜고 끄는 일은 없어요.

uv는 Astral이라는 회사가 만든 파이썬 프로젝트 관리 도구예요. 파이썬이 없으면 알아서 받고, 실행할 때 .venv를 만들고 켜는 일도 대신해요. 패키지를 넣으면 목록 파일도 같이 고쳐요. 그래서 기억할 건 uv로 시작하는 명령 몇 개예요. 속도도 pip보다 빨라요. 한 번 받은 패키지는 캐시에 두고 다시 받지 않아요.
