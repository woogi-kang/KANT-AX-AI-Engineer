9. 막힐 때

노트북과 pull에서 막힐 때

ipykernel을 설치하라는 알림이 떠요

알림의 Install은 pip로 넣어서 pyproject.toml에 안 적혀요.

uv add --dev ipykernel

커널 목록에 .venv가 없어요

hello-uv 폴더 자체를 열었는지 봐요. 그다음 VS Code를 다시 열어요.

uv sync

셀에서 ModuleNotFoundError

커널이 .venv가 아니에요. 오른쪽 위 커널 이름을 눌러 바꿔요.

.venv 고르기

fatal: Need to specify how to reconcile divergent branches.

pull 설정이 없어요. 한 번만 설정하면 돼요(06).

git config --global pull.rebase false

노트북 문제는 대부분 커널이 .venv가 아니어서 생겨요. 1번은 ipykernel 없이 셀을 실행하면 VS Code가 띄우는 알림이에요. Install 버튼은 pip로 설치해서 pyproject.toml과 uv.lock에 적히지 않으니, 알림을 닫고 터미널에서 uv add --dev ipykernel을 쳐요. 2번은 hello-uv의 부모 폴더를 열었거나, clone 뒤 uv sync를 안 해서 .venv가 없을 때 나요. 3번은 컴퓨터에 원래 있던 파이썬을 커널로 고른 경우예요. 4번은 내 컴퓨터와 GitHub에 서로 다른 커밋이 있을 때 git pull에서 나요. 06에서 본 대로 git config --global pull.rebase false를 한 번 치고 다시 pull해요. fatal 메시지는 tools/demo.sh로 실제로 실행한 결과예요.
