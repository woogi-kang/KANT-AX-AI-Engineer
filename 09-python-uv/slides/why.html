lee 컴퓨터

$ git clone https://github.com/kim/hello-uv.git

Cloning into 'hello-uv'...

done.

$ cd hello-uv

$ ls -a

. .. .git .gitignore .python-version README.md main.py pyproject.toml uv.lock

$ python3 main.py

Traceback (most recent call last):

  File "/home/lee/hello-uv/main.py", line 1, in <module>

    import fastapi

ModuleNotFoundError: No module named 'fastapi'

fastapi는 kim 컴퓨터에만 있어요

코드와 목록 파일은 받았는데, 코드가 쓰는 패키지는 따라오지 않았어요.

kim이 만든 프로젝트를 lee가 GitHub에서 받아 바로 실행했더니 ModuleNotFoundError가 났어요. main.py 첫 줄이 fastapi라는 패키지를 불러오는데, lee 컴퓨터에는 fastapi가 없어요. 패키지는 kim 컴퓨터의 가상환경 안에만 설치돼 있고 GitHub에는 올라가지 않아요. 예전에는 lee가 가상환경을 만들고 패키지를 하나씩 설치해야 했어요. 오늘 배우는 uv로는 uv sync 한 번이면 끝나요. 22쪽에서 같은 장면을 uv로 다시 봐요. 출력은 tools/demo.sh로 실제로 실행한 결과이고, ls -a는 터미널 창에서 보이는 대로 한 줄로 적었어요.
