2. 예전 방식과 비교

uv가 대신 해 주는 세 가지

파이썬을 받아요

파이썬이 없으면 uv가 받아서 써요.

설치 순서를 몰라도 돼요

가상환경을 켜고 꺼요

uv run이 실행할 때만 .venv를 써요.

켜는 걸 잊을 일이 없어요

목록을 적어요

uv add, uv remove가 pyproject.toml과 uv.lock을 고쳐요.

다른 컴퓨터는 uv sync 한 번

한 번 받은 패키지는 캐시에 두고 다시 받지 않아서 설치도 빨라요.

uv는 Astral이라는 회사가 만든 파이썬 프로젝트 관리 도구예요. 예전에 python.org, venv, pip, requirements.txt로 따로 하던 일을 uv 하나가 해요. 세 칸 모두 5파트와 6파트에서 직접 확인해요. 속도도 pip보다 빨라요. 같은 패키지를 다시 넣을 때 0.01초 만에 끝나는 것을 5파트에서 봐요.
