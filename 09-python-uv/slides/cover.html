uv로
파이썬 시작하기

예전 방식과 비교하고,
자주 쓰는 명령 익히기

$ uv init hello-uv

프로젝트 만들기

$ uv add requests

패키지 넣기

$ uv run main.py

실행하기

$ uv sync

다른 컴퓨터에서 그대로

오늘부터 파이썬을 시작해요. 파이썬 프로젝트는 uv라는 도구 하나로 만들고 실행해요. 먼저 예전에는 어떻게 했는지 짧게 보고, uv로 바꾸면 무엇이 편해지는지 비교해요. 그다음 uv init, uv run, uv add, uv remove, uv sync를 순서대로 쳐 봐요.
