uv로
파이썬 시작하기

프로젝트를 만들고, 패키지를 넣고,
다른 컴퓨터에서 그대로 받기

$ uv init hello-uv

Initialized project `hello-uv`

$ cd hello-uv

$ uv add fastapi

Installed 11 packages in 5ms

$ uv run main.py

fastapi 버전: 0.162.2

$ uv sync

Resolved 12 packages in 1ms

오늘부터 파이썬 프로젝트는 uv 하나로 만들고 실행해요. 먼저 받은 프로젝트가 왜 남의 컴퓨터에서 안 돌아가는지 봐요. 그다음 uv init, uv run, uv add, uv remove, uv sync를 순서대로 쳐 봐요. VS Code에서 Jupyter 노트북을 여는 준비까지 마쳐요. 마지막에 실제로 자주 만나는 상황 세 가지를 풀어요.
