4. 프로젝트 만들고 실행하기

가상환경을 직접 켤 수도 있어요

macOS, Linux

터미널

source .venv/bin/activate

Windows

Git Bash

source .venv/Scripts/activate

Windows

PowerShell

.venv\Scripts\activate

끄기

모든 터미널

deactivate

$ source .venv/bin/activate

(hello-uv) $ which python

/home/kim/hello-uv/.venv/bin/python

(hello-uv) $ python --version

Python 3.14.6

(hello-uv) $ python main.py

Hello from hello-uv!

(hello-uv) $ deactivate

$

켜면 프롬프트 앞에 (hello-uv)가 붙고, python으로 바로 실행돼요. 수업은 uv run을 기본으로 써요.

uv가 만든 .venv도 예전 방식과 같은 가상환경이라 activate로 켤 수 있어요. 켜면 프롬프트 앞에 프로젝트 이름 (hello-uv)가 붙어요. which python으로 보면 .venv 안의 python을 쓰고 있어요. 켠 상태에서는 uv run 없이 python main.py로 실행해도 돼요. Mac은 python3, Windows는 python으로 부르던 차이도 켠 터미널에서는 python 하나로 같아요. Windows Git Bash는 bin 대신 Scripts 폴더예요. PowerShell에서 스크립트 실행이 막혔다는 오류가 나면 Git Bash에서 쳐요. 다 쓰면 deactivate로 꺼요. 켜는 걸 잊어도 uv run은 늘 동작하니 수업 실습은 uv run으로 적어요. 출력의 폴더 주소는 01처럼 /home/kim으로 바꿨어요.
