uv.lock에 적힌 버전 그대로 설치돼서 kim과 lee의 환경이 같아요.

06의 팀 레포처럼 kim이 프로젝트를 GitHub에 올리고 lee가 clone했어요. GitHub에는 .venv가 없으니 lee 컴퓨터에도 없어요. lee는 uv sync 한 번으로 .python-version의 파이썬을 받고, .venv를 만들고, uv.lock에 적힌 버전 그대로 패키지를 설치해요. 예전에는 venv 만들기, activate, pip install -r requirements.txt 세 단계였어요.
