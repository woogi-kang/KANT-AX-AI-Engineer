4. 프로젝트 만들고 실행하기

pyproject.toml은 프로젝트 설명서예요

pyproject.toml

[project]

name = "hello-uv"

version = "0.1.0"

description = "Add your description here"

readme = "README.md"

requires-python = ">=3.14"

dependencies = []

프로젝트 이름

쓸 수 있는 파이썬 버전

쓰는 패키지, 아직 없어요

.python-version

3.14

이 폴더에서 쓸 파이썬 버전이에요. uv가 이 버전을 받아서 써요.

pyproject.toml은 이 프로젝트가 무엇이고 무엇이 필요한지 적은 설명서예요. name은 프로젝트 이름, requires-python은 쓸 수 있는 파이썬 버전이에요. dependencies는 이 프로젝트가 쓰는 패키지 목록이고, 지금은 비어 있어요. 이 파일은 손으로 고치지 않고 uv add, uv remove로 바꿔요. .python-version은 이 폴더에서 쓸 파이썬 버전이에요. main.py는 uv가 만들어 준 연습용 코드이고 다음 장에서 실행해요.
