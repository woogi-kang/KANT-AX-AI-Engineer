4. 프로젝트 만들고 실행하기

pyproject.toml은 프로젝트 설명서예요

pyproject.toml

[project]

name = "hello-uv"

◀ 프로젝트 이름

version = "0.1.0"

description = "Add your description here"

readme = "README.md"

requires-python = ">=3.14"

◀ 쓸 수 있는 파이썬 버전

dependencies = []

◀ 쓰는 패키지, 아직 없어요

.python-version

3.14

main.py

def main():

print("Hello from hello-uv!")

 

 

if __name__ == "__main__":

main()

pyproject.toml은 이 프로젝트가 무엇이고 무엇이 필요한지 적은 파일이에요. 예전의 requirements.txt가 하던 일도 여기 dependencies 칸이 해요. 이 파일은 손으로 고치지 않고 uv add, uv remove로 바꿔요. .python-version은 이 폴더에서 쓸 파이썬 버전이에요. main.py는 uv가 만들어 준 연습용 코드예요. 맨 아래 두 줄은 이 파일을 직접 실행할 때 main()을 부르라는 뜻이에요. 지금은 그대로 둬요.
