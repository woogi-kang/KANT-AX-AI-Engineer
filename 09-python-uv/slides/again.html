5. 패키지 넣고 빼기

다시 넣으면 받지 않고 바로 들어가요

$ uv add fastapi

Resolved 12 packages in 8ms

Installed 11 packages in 2ms

 + annotated-doc==0.0.5

 + annotated-types==0.8.0

 + anyio==4.16.0

   … 7줄 생략 …

 + typing-inspection==0.4.5

$ uv run main.py

fastapi 버전: 0.162.2

11개가 0.002초 만에

처음 넣을 때 있던 줄

Prepared 11 packages in 437ms

한 번 받은 패키지는 uv 캐시에 있어서 다시 받지 않아요.

앞에서 뺀 fastapi를 다시 넣었어요. 처음 넣을 때는 인터넷에서 받아 준비하는 Prepared 줄이 있었어요. 이번엔 uv 캐시라는 보관함에 있어서 받지 않고 바로 설치했어요. 프로젝트를 여러 개 만들어도 같은 패키지는 한 번만 받아요. 다시 넣었으니 main.py도 다시 동작해요. 출력은 tools/demo.sh로 실제로 실행한 결과이고, 설치 목록 가운데 7줄은 뺐어요.
