5. 패키지 넣고 빼기

다시 넣으면 바로 들어가요

$ uv add fastapi

Resolved 12 packages in 7ms

Installed 11 packages in 7ms

 + annotated-doc==0.0.5

 + annotated-types==0.8.0

 + anyio==4.15.1

 + fastapi==0.162.0

   ... 6줄 생략 ...

 + typing-inspection==0.4.4

$ uv run main.py

fastapi 버전: 0.162.0

uv 캐시

한 번 받은 패키지를 컴퓨터에 보관해요.
다른 프로젝트에서도 다시 받지 않아요.

처음 넣을 때 있던 줄

Prepared 11 packages in 88ms

이번엔 받을 게 없어서 이 줄이 없어요.

uv가 빠른 이유 중 하나예요. 패키지 11개가 0.007초 만에 들어갔어요.

앞에서 뺀 fastapi를 다시 넣었어요. 처음 넣을 때는 인터넷에서 받아 준비하는 Prepared 줄이 있었어요. 이번엔 캐시에 있어서 받지 않고 바로 설치했어요. 프로젝트를 여러 개 만들어도 같은 패키지는 한 번만 받아요. 다시 넣었으니 main.py도 다시 동작해요. 설치 목록 가운데 6줄은 뺐어요.
