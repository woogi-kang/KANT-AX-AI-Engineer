셀 하나씩 실행하고 결과를 바로 아래에서 봐요. 머신러닝 수업에서 데이터를 조금씩 확인할 때 써요.

Jupyter 노트북은 확장자가 .ipynb인 파일이에요. 코드를 셀이라는 칸으로 나누고, 셀마다 따로 실행해요. 실행 결과는 그 셀 바로 아래에 남아요. 앞 셀에서 만든 값은 뒤 셀에서 그대로 써요. 그래서 데이터를 읽고 모양을 보고, 고치고 다시 보는 머신러닝 실습에 잘 맞아요. VS Code 안에서 노트북을 열 수 있어서 따로 프로그램을 설치하지 않아요. 그림 속 셀 내용은 예시예요.
