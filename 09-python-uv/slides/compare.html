8. 예전 방식과 비교

인터넷 자료의 예전 명령은 이렇게 바꿔 쳐요

할 일

예전 (따라 치지 않아요)

uv

파이썬 설치

python.org에서 받아 설치

없으면 uv가 받아요

가상환경 만들기

python3 -m venv .venv

uv init 이름

가상환경 켜기

source .venv/bin/activate

uv run이 알아서 켜요

패키지 넣기

pip install fastapi

uv add fastapi

목록 적기

pip freeze > requirements.txt

uv add가 알아서 적어요

받은 프로젝트 맞추기

pip install -r requirements.txt

uv sync

실행

python main.py

uv run main.py

패키지 빼기

pip uninstall fastapi (10개 남아요)

uv remove fastapi (11개 다 빠져요)

인터넷 자료나 옛 강의에 왼쪽 명령이 나오면 오른쪽 uv 명령으로 바꿔 쳐요. 예전에는 왼쪽 여섯 단계를 순서대로 직접 챙겼고, 하나라도 빼먹으면 ModuleNotFoundError가 났어요. uv로는 init, add, run, sync만 쳐요. 가장 자주 만나는 건 pip install 패키지예요. pip로 넣으면 pyproject.toml과 uv.lock에 적히지 않아서 다른 컴퓨터에서 uv sync로 받을 수 없어요. 뺄 때도 차이가 나요. pip uninstall fastapi는 fastapi 하나만 지우고 따라온 10개를 남기고, uv remove는 11개를 모두 빼요. 예전 방식은 따라 치지 않고 눈으로만 봐요. 예전 방식의 남은 10개는 tools/demo.sh로 실제로 실행한 결과예요.
