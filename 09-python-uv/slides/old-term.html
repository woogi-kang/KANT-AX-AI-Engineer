2. 예전 방식

예전 방식을 실제로 쳐 보면

$ python3 main.py

ModuleNotFoundError: No module named 'fastapi'

$ python3 -m venv .venv

$ source .venv/bin/activate

(.venv) $ pip install fastapi uvicorn

Collecting fastapi

  ... 중간 줄 생략 ...

Successfully installed annotated-doc-0.0.5 annotated-types-0.8.0 anyio-4.15.1 click-8.5.0 …

(.venv) $ pip freeze > requirements.txt

(.venv) $ python main.py

INFO: Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)

가상환경을 켜면 프롬프트 앞에 (.venv)가 붙어요. 켠 상태에서만 패키지가 보여요.

main.py는 fastapi로 만든 작은 웹 서버예요(5파트에서 자세히 봐요). 처음엔 패키지가 없어서 ModuleNotFoundError가 나요. venv를 만들고 activate로 켜면 프롬프트 앞에 (.venv)가 붙어요. 그 상태에서 pip install로 넣고, pip freeze로 설치된 목록을 requirements.txt에 적어 둬요. 다른 사람은 이 파일을 보고 pip install -r requirements.txt로 같은 패키지를 받아요. Traceback 줄, pip가 받는 중간 줄, 서버 출력 앞뒤 줄은 뺐어요. Successfully installed 줄은 실제로 패키지 14개가 이어져요.
