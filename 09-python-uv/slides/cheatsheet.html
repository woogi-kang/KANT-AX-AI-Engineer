이럴 때

이렇게

새 프로젝트를 만들 때

uv init 이름

코드를 실행할 때

uv run main.py

패키지를 넣을 때 (pip install 대신)

uv add 패키지

패키지를 뺄 때

uv remove 패키지

받은 프로젝트를 맞출 때 (clone, pull 뒤)

uv sync

노트북 커널을 넣을 때

uv add --dev ipykernel

GitHub에 올려요 pyproject.toml uv.lock .python-version

올리지 않아요 .venv

다음 챕터: 10 · VS Code에서 Jupyter 노트북 쓰기. 오늘 만든 hello-uv 노트북을 손에 익혀요.

파이썬 프로젝트에서 치는 uv 명령은 거의 이 여섯 개예요. 새 프로젝트는 uv init, 실행은 uv run, 패키지는 uv add와 uv remove, 받은 프로젝트는 uv sync예요. 인터넷 자료에 pip install이 보이면 uv add로 바꿔 쳐요. GitHub에는 목록 파일 세 개를 올리고 .venv는 올리지 않아요. 다음 10챕터에서는 오늘 만든 hello-uv의 노트북을 손에 익혀요.
