uv run main.py

가상환경에서 실행

uv add 패키지

패키지 넣기

uv remove 패키지

패키지 빼기

uv sync

uv.lock대로 맞추기

uv tree

GitHub에 올려요 pyproject.toml uv.lock .python-version

올리지 않아요 .venv uv init이 .gitignore에 적어 둬요

노트북 uv add --dev ipykernel 뒤 커널로 .venv 고르기

파이썬 프로젝트에서 치는 명령은 거의 이 여섯 개예요. 새 프로젝트는 uv init, 실행은 uv run, 패키지는 uv add와 uv remove, 받은 프로젝트는 uv sync예요. pip install이 보이면 uv add로 바꿔 쳐요.
