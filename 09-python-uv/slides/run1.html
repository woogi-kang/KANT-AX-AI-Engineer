처음 실행할 때 .venv와 uv.lock이 생겨요. activate는 치지 않아요.

uv run 뒤에 실행할 파일 이름을 적어요. 처음 실행하면 uv가 가상환경 .venv를 만들고, 그 안의 파이썬으로 main.py를 실행해요. 예전에 직접 치던 가상환경 만들기와 켜기를 uv run이 대신했어요. uv.lock은 패키지의 정확한 버전을 적는 파일이에요. 지금은 패키지가 없어서 거의 비어 있어요. main.py 맨 아래 두 줄은 이 파일을 직접 실행할 때 main()을 부르라는 뜻이고, 지금은 그대로 둬요.
