5. 패키지 넣고 빼기

uv remove로 패키지를 빼요

$ uv remove requests

Resolved 1 package in 3ms

Uninstalled 5 packages in 5ms

 - certifi==2026.10.23

 - charset-normalizer==3.5.2

 - idna==3.20

 - requests==2.34.2

 - urllib3==2.8.0

$ uv run main.py

ModuleNotFoundError: No module named 'requests'

pyproject.toml

내가 고른 패키지

dependencies = []

uv.lock

따라온 것까지 정확한 버전

프로젝트만 남아요

따라왔던 4개도 지워요

.venv

실제로 설치된 패키지

패키지 5개 삭제

딸린 패키지까지 같이 빠져요

뺄 때도 세 곳이 함께 바뀌어요. 예전 pip uninstall과 달리 하나도 남지 않아요.

uv remove는 uv add를 거꾸로 해요. pyproject.toml에서 지우고, uv.lock과 .venv에서도 빼요. 함께 들어왔던 4개도 다른 패키지가 쓰지 않으면 같이 빠져요. 코드는 아직 requests를 쓰고 있어서 실행하면 ModuleNotFoundError가 나요. Traceback 줄은 뺐어요. 다음 장에서 다시 넣어요.
