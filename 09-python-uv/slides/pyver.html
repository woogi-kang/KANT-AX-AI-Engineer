4. 프로젝트 만들고 실행하기

파이썬 버전은 .python-version이 정해요

$ cd ~

$ uv init --python 3.13 hello-313

Initialized project `hello-313` at `/home/kim/hello-313`

$ cd hello-313

$ cat .python-version

3.13

$ uv run python --version

Downloading cpython-3.13.14-linux-x86_64-gnu (download) (33.2MiB)

 Downloaded cpython-3.13.14-linux-x86_64-gnu (download)

Using CPython 3.13.14

Creating virtual environment at: .venv

Python 3.13.14

버전을 정해서 만들어요

없는 버전은 uv가 받아요

보기만 해도 되는 장이에요. 수업 프로젝트는 uv init 이름으로 만들면 돼요. 회사나 강의에서 파이썬 버전을 정해 줄 때 --python 버전을 붙여요. 이 컴퓨터에 3.13이 없어서 uv가 받아 왔어요. 폴더마다 버전이 달라도 그 폴더에서 uv run을 치면 그 폴더의 버전으로 실행돼요. 출력은 tools/demo.sh로 실제로 실행한 결과예요.
