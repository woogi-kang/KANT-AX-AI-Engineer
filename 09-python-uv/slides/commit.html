6. 다른 컴퓨터에서 그대로

GitHub에는 무엇을 올리나요

$ git status --short

?? .gitignore

?? .python-version

?? README.md

?? main.py

?? pyproject.toml

?? uv.lock

$ git add .

$ git commit -m "feat: hello-uv 프로젝트 만들기"

[main (root-commit) 749f4de] feat: hello-uv 프로젝트 만들기

hello-uv/

.gitignore

.python-version

.venv

README.md

main.py

pyproject.toml

uv.lock

.gitignore가 막아요

.venv는 올리지 않아요. pyproject.toml과 uv.lock만 있으면 똑같이 다시 만들어요.

git status에 .venv가 없어요. uv init이 만든 .gitignore에 .venv가 적혀 있어서예요(04). .venv는 컴퓨터마다 다시 만들 수 있고 크기도 커서 올리지 않아요. 대신 pyproject.toml, uv.lock, .python-version을 꼭 같이 올려요. 이 세 파일이 다른 컴퓨터에서 같은 환경을 만드는 설명서예요. git add .는 지금 폴더의 바뀐 파일을 모두 올린다는 뜻이에요.
