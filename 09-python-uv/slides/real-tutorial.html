10. 실제 상황 예제

튜토리얼에 pip install이 나오면 uv add로 바꿔요

인터넷 튜토리얼

카페 주문 프로그램을 만들어 봅시다. 먼저 가상환경을 만들고 requests를 설치하세요.

python3 -m venv .venv

source .venv/bin/activate

pip install requests

python main.py

uv init과 uv run이 대신해요

$ uv init cafe-order

Initialized project `cafe-order` at `/home/kim/cafe-order`

$ cd cafe-order

$ uv add requests

Using CPython 3.14.6

Creating virtual environment at: .venv

Resolved 6 packages in 223ms

Prepared 4 packages in 309ms

Installed 5 packages in 4ms

 + requests==2.34.2 + urllib3==2.8.0 …

$ uv run main.py

requests 버전: 2.34.2

main.py

import requests

 

print("requests 버전:", requests.__version__)

이렇게 넣으면 pyproject.toml에 requests가 적혀서 팀원도 uv sync로 받아요.

인터넷 튜토리얼에 pip install 패키지가 나오면 우리 프로젝트에서는 uv add 패키지로 바꿔 쳐요. 튜토리얼의 네 줄 가운데 가상환경 만들기와 켜기는 uv init과 uv run이 대신해요. pip install requests는 uv add requests로 바꿔요. requests는 인터넷에서 데이터를 받아 오는 패키지이고, 함께 따라온 4개까지 5개가 들어왔어요. python main.py는 uv run main.py로 실행해요. 이렇게 넣으면 pyproject.toml에 requests가 적혀서 팀원도 uv sync로 받을 수 있어요. 출력은 tools/demo.sh로 실제로 실행한 결과이고, 설치 목록 5줄은 한 줄로 줄였어요.
