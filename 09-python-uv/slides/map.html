예전 명령은 이렇게 바뀌었어요

python.org에서 설치

없으면 uv가 받아요

python3 -m venv .venv

uv run, uv sync가 만들어요

source .venv/bin/activate

필요 없어요

pip install requests

uv add requests

pip uninstall requests

uv remove requests

pip install -r requirements.txt

uv sync

python main.py

uv run main.py

인터넷 자료나 옛 강의에 왼쪽 명령이 나오면 오른쪽으로 바꿔 쳐요. 특히 pip install 패키지는 uv add 패키지로 바꿔요. pip로 넣으면 pyproject.toml과 uv.lock에 적히지 않아서 다른 컴퓨터에서 uv sync로 받을 수 없어요.
