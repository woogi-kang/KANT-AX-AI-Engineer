2. 큰 그림

uv가 파이썬, 가상환경, 패키지 목록을 챙겨요

hello-uv/

.python-version

이 버전의 파이썬을 받아요

.venv

만들고, 실행할 때 켜요

main.py

내가 쓰는 코드

pyproject.toml

넣은 패키지를 적어요

uv.lock

정확한 버전까지 적어요

PyPI

패키지 창고

uv

이 목록만 있으면 다른 컴퓨터에서도 같은 .venv를 다시 만들어요.

uv는 파이썬 프로젝트에 필요한 세 가지를 한 번에 챙기는 도구예요. 첫째, 프로젝트가 쓸 파이썬이 없으면 받아요. 둘째, 가상환경 .venv를 만들고 실행할 때 켜요. 셋째, 넣은 패키지를 pyproject.toml과 uv.lock에 적어요. 이 목록 파일만 있으면 다른 컴퓨터에서도 같은 .venv를 다시 만들어요. 1장에서 lee가 막힌 문제가 셋째 덕분에 풀려요. uv는 Astral이라는 회사가 만든 무료 도구예요.
