1. 파이썬은 어떻게 실행되나

파이썬 코드는 python이 읽고 실행해요

hello.py

print("안녕하세요")

python

안녕하세요

$ python3 hello.py

안녕하세요

.py 파일은 글자일 뿐이에요. python 프로그램이 한 줄씩 읽어서 실행해요.

hello.py는 메모장으로도 열 수 있는 글자 파일이에요. 이 파일을 읽어서 실제로 움직이게 하는 프로그램이 python이에요. 그래서 파이썬을 쓰려면 먼저 컴퓨터에 python 프로그램이 있어야 해요. Mac과 Linux는 python3, Windows는 python이라는 이름으로 부르는 경우가 많아요. 출력은 uv가 받은 Python 3.14.6에서 실행한 결과예요.
