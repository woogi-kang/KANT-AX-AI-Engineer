파이썬 프로그램

읽을 파일

실행 결과

파이썬 코드는 python이라는 프로그램이 한 줄씩 읽어서 실행해요. hello.py는 메모장으로도 열 수 있는 글자 파일이에요. 터미널에서 python3 뒤에 파일 이름을 적으면 python이 그 파일을 읽고 결과를 보여 줘요. 그래서 파이썬을 쓰려면 먼저 컴퓨터에 python 프로그램이 있어야 해요. Mac과 Linux는 python3, Windows는 python이라는 이름으로 부르는 경우가 많아요. 출력은 uv가 받은 Python 3.14.6에서 실제로 실행한 결과예요.
