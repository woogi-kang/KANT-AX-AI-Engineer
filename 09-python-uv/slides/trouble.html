정리

이런 메시지가 나와요

1

bash: uv: command not found

설치 뒤 터미널을 새로 열지 않았어요

터미널 닫고 다시 열기

2

error: No `pyproject.toml` found in current directory or any parent directory

프로젝트 폴더 밖에서 쳤어요

cd hello-uv

3

ModuleNotFoundError: No module named 'fastapi'

패키지를 안 넣었거나 python3로 실행했어요

uv add "fastapi[standard]"
uv run main.py

4

error: Project is already initialized in `...`

이미 만든 프로젝트 안에서 uv init을 쳤어요

uv init은 처음 한 번만

1번은 설치 직후에 가장 많이 나요. Mac 기본 터미널은 zsh라서 zsh: command not found: uv로 보여요. 2번은 홈 폴더처럼 pyproject.toml이 없는 곳에서 uv add를 친 경우예요. pwd로 위치를 보고 프로젝트 폴더로 cd 해요. 3번은 가상환경을 켜지 않고 python3 main.py로 실행했거나, uv add를 안 한 경우예요. 서버는 uv run fastapi dev main.py로 켜요. 4번은 폴더 주소가 들어간 메시지예요. 이미 pyproject.toml이 있어서 다시 만들 필요가 없어요.
