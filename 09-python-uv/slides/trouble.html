9. 막힐 때

uv에서 자주 만나는 메시지

bash: uv: command not found

설치 뒤 터미널을 새로 열지 않았어요

터미널 닫고 다시 열기

error: No `pyproject.toml` found in current directory or any parent directory

프로젝트 폴더 밖에서 쳤어요

cd hello-uv

ModuleNotFoundError: No module named 'fastapi'

패키지를 안 넣었거나 python3로 실행했어요

uv add fastapi
uv run main.py

error: Project is already initialized in `/home/kim/hello-uv`

이미 만든 프로젝트 안에서 uv init을 쳤어요

uv init은 처음 한 번만

uv를 쓰다 막히면 메시지에서 밑줄 친 부분을 먼저 읽어요. 1번은 설치 직후에 가장 많이 나요. Mac 기본 터미널은 zsh라서 zsh: command not found: uv로 보여요. 2번은 홈 폴더처럼 pyproject.toml이 없는 곳에서 uv add를 친 경우예요. pwd로 위치를 보고 프로젝트 폴더로 cd 해요. 3번은 uv add를 안 했거나, 가상환경을 켜지 않고 python3 main.py로 실행한 경우예요. 4번은 이미 pyproject.toml이 있는 폴더라 다시 만들 필요가 없어요. 메시지는 tools/demo.sh로 실제로 실행한 결과예요.
