lee 컴퓨터에는 파이썬도 패키지도 없는 상태에서 시작했어요. uv sync가 파이썬 3.14.6을 받고, .venv를 만들고, 패키지 11개를 설치했어요. 버전은 kim 컴퓨터와 똑같아요. 1장에서 실패했던 uv run main.py가 이제 fastapi 버전을 찍어요. 출력은 tools/demo.sh로 실제로 실행한 결과이고, clone 출력과 pydantic-core를 받는 줄, 설치 목록 10줄은 뺐어요.
