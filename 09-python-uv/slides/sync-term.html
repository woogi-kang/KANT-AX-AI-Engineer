6. 다른 컴퓨터에서 그대로

$ git clone https://github.com/kim/hello-uv.git

$ cd hello-uv

$ uv sync

$ uv run main.py

lee 컴퓨터에는 파이썬도 패키지도 없는 상태에서 시작했어요. uv sync가 파이썬 3.14.6을 받고, .venv를 만들고, 패키지 다섯 개를 설치했어요. 버전은 kim 컴퓨터와 똑같아요. 설치 목록은 화면 폭 때문에 한 줄로 줄였고, 실제로는 다섯 줄이에요. clone 출력의 done. 줄은 뺐어요.
