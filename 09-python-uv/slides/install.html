3. uv 설치하기

명령 한 줄로 uv를 설치해요

컴퓨터

여는 곳

치는 명령

macOS

터미널

brew install uv

Windows

PowerShell

winget install --id=astral-sh.uv -e

Homebrew가 없으면 brew.sh의 설치 명령을 먼저 쳐요. winget은 Windows 10, 11에 들어 있어요.

!

설치가 끝나면 터미널을 닫았다가 새로 열어요. Windows는 Git Bash를 새로 열어요.

$ uv --version

uv 0.11.32 (x86_64-unknown-linux-gnu)

uv 설치는 컴퓨터마다 한 번만 해요. Mac은 터미널에서 brew install uv를 쳐요. brew --version에 버전이 나오면 Homebrew가 이미 있어요. Windows는 시작 메뉴에서 PowerShell을 열어 winget 명령을 치고, 약관 동의를 물으면 Y를 쳐요. 설치가 끝나면 터미널을 새로 열어야 uv 명령을 찾아요. uv --version에 버전이 나오면 준비가 끝났어요. 숫자는 설치한 날에 따라 달라요. brew와 winget 설치 화면은 버전과 컴퓨터마다 달라서 옮기지 않았고, uv --version은 실제로 실행한 결과예요.
