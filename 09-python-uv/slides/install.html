3. uv는 무엇이 다른가

uv 설치하기

macOS, Linux

터미널에 붙여 넣기

curl -LsSf https://astral.sh/uv/install.sh | sh

Windows

PowerShell에 붙여 넣기

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

3

터미널을 닫았다가 새로 열어요. Windows는 Git Bash를 새로 열어요.

$ uv --version

uv 0.11.32 (x86_64-unknown-linux-gnu)

설치는 컴퓨터마다 한 번만 해요. Mac은 터미널, Windows는 시작 메뉴에서 PowerShell을 열어 붙여 넣어요. 설치 프로그램이 출력하는 줄은 버전과 컴퓨터마다 달라서 옮기지 않았어요. 설치가 끝나면 터미널을 새로 열어야 uv 명령을 찾아요. uv --version에 버전이 나오면 준비가 끝났어요. 숫자는 설치한 날에 따라 달라요.
