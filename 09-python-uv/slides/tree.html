fastapi가 쓰는 패키지까지 uv가 함께 넣어요. 뺄 때도 함께 빠져요.

uv tree는 어떤 패키지가 어떤 패키지 때문에 들어왔는지 나무 모양으로 보여 줘요. 01에서 본 폴더 지도와 같은 모양이에요. --depth 2는 두 단계까지만 보여 달라는 뜻이에요. 빼고 치면 pydantic 아래 pydantic-core처럼 더 깊은 단계까지 나와서 화면이 길어져요. fastapi는 데이터 검사를 pydantic에, 웹 요청 처리를 starlette에 맡겨요. extra: standard가 붙은 줄은 [standard]를 붙여서 들어온 도구예요. fastapi-cli는 fastapi dev 명령을, uvicorn은 그 명령이 켜는 서버 엔진이에요. 코드에서 직접 부르지는 않아요. pyproject.toml에는 내가 고른 fastapi[standard] 하나만 적혀요.
