큰따옴표까지 그대로 쳐요

Mac 터미널(zsh)은 대괄호 [ ]를 특별한 글자로 읽어요.
따옴표로 감싸면 Mac, Windows 모두 같은 명령이에요.

명령 하나로 세 곳이 함께 바뀌어요.

hello-uv 폴더에서 쳐요. fastapi[standard]는 fastapi에 서버를 켜는 도구까지 함께 넣으라는 뜻이에요. Mac 터미널(zsh)은 대괄호를 특별한 글자로 읽어서 큰따옴표로 감싸요. Windows에서도 같은 명령을 그대로 쳐요. uv add는 세 가지를 한 번에 해요. pyproject.toml의 dependencies 칸에 적고, uv.lock에 정확한 버전을 적고, .venv에 설치해요. 예전의 pip install과 pip freeze를 합친 일이에요. >=0.162.0은 0.162.0 이상이면 된다는 뜻이에요. 크기가 큰 패키지를 받는 Downloading 여섯 줄과 설치 목록 가운데 54줄은 뺐어요. 실제로 쓸 버전은 uv.lock이 정해요.
