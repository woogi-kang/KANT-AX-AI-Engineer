hello-uv 폴더에서 쳐요. uv add는 세 가지를 한 번에 해요. pyproject.toml에 requests를 적고, uv.lock에 정확한 버전을 적고, .venv에 설치해요. 예전의 pip install과 pip freeze를 합친 일이에요. >=2.34.2는 2.34.2 이상이면 된다는 뜻이에요. 실제로 쓸 버전은 uv.lock이 정해요.
