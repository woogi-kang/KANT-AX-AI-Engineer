uv run으로 실행하면 바로 써요

uv add는 명령 하나로 세 곳을 함께 바꿔요. pyproject.toml의 dependencies 칸에 fastapi를 적고, uv.lock에 정확한 버전을 적고, .venv에 설치해요. 예전의 pip install과 목록 적기를 합친 일이에요. >=0.162.2는 0.162.2 이상이면 된다는 뜻이고, 실제로 쓸 버전은 uv.lock이 정해요. Downloading pydantic-core 줄은 크기가 큰 패키지를 받을 때만 보여요. hello-uv 폴더에서 쳐요. 출력은 tools/demo.sh로 실제로 실행한 결과예요.
