2. 예전 방식

예전에는 이 순서를 직접 챙겼어요

1

파이썬 설치

python.org에서 받아 설치

python

2

가상환경 만들기

python3 -m venv .venv

venv

3

가상환경 켜기

source .venv/bin/activate

venv

4

패키지 설치

pip install fastapi uvicorn

pip

5

목록 적어 두기

pip freeze > requirements.txt

requirements.txt

6

실행

python main.py

python

uv가 나오기 전에 많이 쓰던 순서예요. 오른쪽 칸이 그 단계에서 쓰는 도구예요. 파이썬 설치, venv, pip, requirements.txt를 따로 배우고 순서도 직접 기억해야 했어요. Windows Git Bash에서는 3번이 source .venv/Scripts/activate예요. 오늘은 따라 치지 않고 눈으로만 봐요.
