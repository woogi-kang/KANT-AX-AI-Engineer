3. uv는 무엇이 다른가

할 일마다 비교해 봐요

할 일

예전

uv

파이썬 설치

python.org에서 받아 직접 설치

없으면 uv가 받아요

가상환경

python3 -m venv .venv 뒤 activate

uv run이 알아서 만들고 켜요

패키지 넣기

pip install, 그다음 pip freeze

uv add requests

패키지 빼기

pip uninstall, 딸린 패키지는 남아요

uv remove requests

다른 컴퓨터

pip install -r requirements.txt

uv sync

실행

켠 상태에서 python main.py

uv run main.py

왼쪽은 앞 파트에서 본 예전 방식, 오른쪽은 이번 챕터에서 칠 uv 명령이에요. 오른쪽 칸 명령은 모두 uv로 시작해요. 예전 방식은 몰라도 uv를 쓰는 데 문제없어요. 다만 인터넷 자료에 pip install이 아직 많이 나와서 읽을 수 있을 만큼 알아 두면 좋아요. 자료에 pip install 패키지가 나오면 우리 프로젝트에서는 uv add 패키지로 바꿔 쳐요.
