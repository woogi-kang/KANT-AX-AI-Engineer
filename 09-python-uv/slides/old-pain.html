2. 예전 방식

예전 방식에서 자주 막히는 곳

켜는 걸 잊으면

deactivate 뒤에 python3 main.py

ModuleNotFoundError

목록은 손으로

pip install 뒤 pip freeze를 잊으면

requirements.txt가 옛날 그대로

빼도 남아요

pip uninstall fastapi uvicorn 뒤에도

pydantic, starlette 같은 12개가 남아요

파이썬은 따로

설치와 버전 맞추기는 직접

python, python3 이름도 컴퓨터마다 달라요

네 가지 모두 실제로 쳐서 확인했어요. 1번은 가상환경을 끈 뒤 python3로 실행하면 컴퓨터 파이썬에는 fastapi가 없어서 나요. 2번은 pip가 requirements.txt를 고쳐 주지 않아서 생겨요. 3번은 pip uninstall이 적은 두 개만 지우고, 함께 들어온 pydantic, starlette, anyio 같은 12개는 남겨요. 4번은 Mac, Windows마다 설치 방법과 명령 이름이 달라서 수업 첫날 가장 많이 막히는 곳이에요.
