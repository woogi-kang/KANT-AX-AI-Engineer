requests 버전: 2.34.2

같은 셀을 다시 실행해요

셀은 노트북에서, 패키지는 터미널에서 넣어요. VS Code 알림의 Install 버튼은 누르지 않아요.

노트북 셀에서 ModuleNotFoundError가 나면 VS Code 터미널에서 uv add로 패키지를 넣고 같은 셀을 다시 실행해요. 커널은 hello-uv의 .venv라서, uv add로 .venv에 넣으면 노트북에서도 바로 불러와요. idna는 fastapi와 함께 이미 들어와 있어서 이번엔 4개만 설치됐어요. 알림의 Install이나 pip install은 목록 파일에 적히지 않아서 쓰지 않아요. 노트북 출력은 tools/demo.sh가 커널 하나에서 셀, uv add, 같은 셀 순서로 실제로 실행한 결과예요.
