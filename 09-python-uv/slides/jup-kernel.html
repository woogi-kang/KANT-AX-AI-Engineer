uv add --dev ipykernel로 커널을 넣어요

$ cd ~/hello-uv

$ uv add --dev ipykernel

pyproject.toml

dependencies = [

"fastapi>=0.162.2",

]

 

[dependency-groups]

dev = [

"ipykernel>=7.4.0",

]

--dev로 넣은 도구는 [dependency-groups]의 dev 칸에 따로 적혀요.

커널은 노트북 셀을 실행하는 파이썬이에요. 노트북도 .venv 안의 파이썬으로 실행하려고 ipykernel을 .venv에 넣어요.

노트북의 셀은 커널이라는 파이썬 프로그램이 실행해요. VS Code가 hello-uv의 .venv를 커널로 쓰려면 .venv 안에 ipykernel 패키지가 있어야 해요. --dev를 붙이면 dependencies가 아니라 dependency-groups의 dev 칸에 적혀요. main.py 실행에 꼭 필요한 패키지와 개발할 때만 쓰는 도구를 나눠 두는 거예요. uv sync는 dev 칸도 함께 설치해서, lee 컴퓨터에서도 uv sync 한 번이면 노트북을 열 수 있어요. 출력은 tools/demo.sh로 실제로 실행한 결과이고, 받는 줄과 설치 목록 가운데는 뺐어요.
