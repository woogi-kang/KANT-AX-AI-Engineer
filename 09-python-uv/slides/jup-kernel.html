7. VS Code에서 Jupyter 쓰기

uv add --dev ipykernel로 커널을 넣어요

$ cd ~/hello-uv

$ uv add --dev ipykernel

Resolved 93 packages in 219ms

  ... Downloading 줄 생략 ...

Prepared 28 packages in 820ms

Installed 28 packages in 56ms

 + asttokens==3.0.2

 + comm==0.2.3

   ... 25줄 생략 ...

 + wcwidth==0.9.4

pyproject.toml

dependencies = [

"fastapi[standard]>=0.162.0",

]

 

[dependency-groups]

dev = [

"ipykernel>=7.4.0",

]

커널 = 노트북 셀을 실행하는 파이썬

--dev는 개발할 때만 쓰는 도구라는 표시예요.
서버를 켜는 데는 필요 없어서 따로 적혀요.

노트북도 .venv 안의 파이썬으로 실행해요. 그래서 ipykernel을 .venv에 넣어요.

노트북의 셀은 커널이라는 파이썬 프로그램이 실행해요. VS Code가 hello-uv의 .venv를 커널로 쓰려면 .venv 안에 ipykernel 패키지가 있어야 해요. --dev를 붙이면 pyproject.toml의 dependencies가 아니라 dependency-groups의 dev 칸에 적혀요. 서버를 켜는 데 꼭 필요한 패키지와, 내가 개발할 때만 쓰는 도구를 나눠 두는 거예요. uv sync는 dev 칸도 함께 설치해서, lee 컴퓨터에서도 uv sync 한 번이면 노트북을 열 수 있어요. 받는 줄과 설치 목록 가운데는 뺐어요. 실제로는 28개가 설치돼요.
