5. 패키지 넣고 빼기

넣은 패키지로 웹 서버를 켜요

main.py

from fastapi import FastAPI

import uvicorn

 

app = FastAPI()

 

 

@app.get("/")

def home():

return {"message": "안녕하세요"}

 

 

if __name__ == "__main__":

uvicorn.run(app)

http://127.0.0.1:8000

{"message":"안녕하세요"}

브라우저 주소창에 http://127.0.0.1:8000

$ uv run main.py

INFO: Started server process [448]

INFO: Waiting for application startup.

INFO: Application startup complete.

INFO: Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)

INFO: 127.0.0.1:45266 - "GET / HTTP/1.1" 200 OK

서버는 Ctrl+C로 끌 때까지 켜져 있어요.

위 두 줄로 fastapi와 uvicorn을 불러와요. @app.get("/")는 주소 / 로 들어오면 아래 home()의 대답을 돌려준다는 뜻이에요. 맨 아래 uvicorn.run(app)이 서버를 켜요. 터미널에 Uvicorn running 줄이 보이면 브라우저로 http://127.0.0.1:8000을 열어요. 열 때마다 터미널에 GET / 200 OK 줄이 하나씩 생겨요. 서버는 켜진 채로 기다려서 프롬프트가 돌아오지 않아요. Ctrl+C로 꺼요. 코드 문법은 다음 수업부터 하나씩 배워요. 오늘은 넣은 패키지를 uv run으로 실행하면 쓸 수 있다는 것만 확인해요. 서버 번호 [448]과 GET 줄의 숫자는 실행할 때마다 달라요.
