5. 패키지 넣고 빼기

넣은 패키지로 웹 서버를 켜요

main.py

from fastapi import FastAPI

 

app = FastAPI()

 

 

@app.get("/")

def home():

return {"message": "안녕하세요"}

http://127.0.0.1:8000

{"message":"안녕하세요"}

브라우저 주소창에 http://127.0.0.1:8000

$ uv run fastapi dev main.py

 ⚡️ Starting FastAPI in development mode

 🌐 Server started at http://127.0.0.1:8000

    Documentation at http://127.0.0.1:8000/docs

INFO: Application startup complete.

INFO: 127.0.0.1:56432 - "GET / HTTP/1.1" 200 OK

서버는 Ctrl+C로 끌 때까지 켜져 있어요.

main.py를 이 여덟 줄로 바꿔 저장해요. 첫 줄은 fastapi를 불러오고, app = FastAPI()가 웹 서버 앱을 만들어요. @app.get("/")는 주소 / 로 들어오면 아래 home()의 대답을 돌려준다는 뜻이에요. 서버는 uv run fastapi dev main.py로 켜요. uv run 뒤에 파일 이름 대신 uv add로 들어온 fastapi 명령을 적은 거예요. dev는 개발용 모드라서 main.py를 고쳐 저장하면 서버가 알아서 다시 켜져요. Server started 줄이 보이면 브라우저로 http://127.0.0.1:8000을 열어요. 열 때마다 터미널에 GET / 200 OK 줄이 하나씩 생겨요. 서버는 켜진 채로 기다려서 프롬프트가 돌아오지 않아요. Ctrl+C로 꺼요. 코드 문법은 다음 수업부터 하나씩 배워요. 서버 출력의 빈 줄과 INFO 줄 몇 개는 뺐어요. GET 줄의 숫자는 실행할 때마다 달라요.
