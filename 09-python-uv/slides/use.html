5. 패키지 넣고 빼기

넣은 패키지를 코드에서 써요

main.py

import requests

 

 

def main():

r = requests.get("https://api.github.com")

print("상태 코드:", r.status_code)

 

 

if __name__ == "__main__":

main()

$ uv run main.py

상태 코드: 200

200

요청이 잘 됐다는 뜻이에요.
GitHub 서버가 대답했어요.

VS Code에서 main.py를 이렇게 고쳐 저장하고 uv run으로 실행해요.

첫 줄 import requests로 패키지를 불러와요. requests.get은 적은 주소로 요청을 보내고, status_code는 서버가 돌려준 숫자예요. 200이면 성공이에요. 인터넷이 연결돼 있어야 해요. 코드 문법은 다음 수업부터 하나씩 배워요. 오늘은 넣은 패키지를 uv run으로 실행하면 쓸 수 있다는 것만 확인해요.
