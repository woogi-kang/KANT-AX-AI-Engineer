5. 패키지 넣고 빼기

넣은 패키지를 코드에서 불러와요

main.py

import fastapi

 

print("fastapi 버전:", fastapi.__version__)

$ uv run main.py

fastapi 버전: 0.162.0

uv run main.py

.venv 안의 파이썬

fastapi 찾아서 불러오기

uv add로 넣은 패키지는 uv run으로 실행하면 바로 불러와요.

main.py를 이 세 줄로 바꿔 저장해요. import fastapi는 .venv에 설치된 fastapi를 불러오라는 뜻이에요. 불러온 fastapi의 버전을 print로 찍어 봤어요. uv run이 .venv 안의 파이썬으로 실행하니까 fastapi를 찾아요. fastapi로 웹 서버를 만들고 켜는 건 뒤 수업에서 해요. 오늘은 넣은 패키지를 코드에서 쓸 수 있다는 것만 확인해요.
