4. 프로젝트 만들고 실행하기

두 번째부터는 바로 실행돼요

$ uv run main.py

Hello from hello-uv!

1

켜요

.venv 안의 파이썬을 골라요

2

실행해요

main.py를 읽고 실행해요

3

꺼요

끝나면 원래대로 돌아와요

uv run 한 줄이 이 세 가지를 해요. 프롬프트에 (hello-uv)가 붙지 않아서 끄는 걸 잊을 일이 없어요.

uv run은 .venv를 켜고, 실행하고, 끄는 일을 한 번에 해요. .venv가 이미 있어서 이번엔 결과만 나와요. 실행할 때만 .venv의 파이썬을 쓰고 끝나면 원래대로 돌아와서 프롬프트가 바뀌지 않아요. main.py를 고친 뒤에도 같은 명령으로 다시 실행해요. 출력은 tools/demo.sh로 실제로 실행한 결과예요.
