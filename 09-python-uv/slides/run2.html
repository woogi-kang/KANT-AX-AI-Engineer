4. 프로젝트 만들고 실행하기

두 번째부터는 바로 실행돼요

$ uv run main.py

Hello from hello-uv!

uv run main.py

.venv 안의 파이썬

main.py 실행

예전

source .venv/bin/activate
python main.py

uv

uv run main.py

uv run은 켜고, 실행하고, 끄는 일을 한 번에 해요.

.venv가 이미 있어서 바로 결과만 나와요. uv run은 실행할 때만 .venv의 파이썬을 쓰고 끝나면 원래대로 돌아와요. 그래서 프롬프트에 (.venv)가 붙지 않고, 끄는 걸 잊을 일도 없어요. main.py를 고친 뒤에도 같은 명령으로 다시 실행해요. uv run python --version처럼 쓰면 이 프로젝트의 파이썬 버전을 볼 수 있어요.
