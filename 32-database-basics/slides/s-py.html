2. SQL 네 문장 맛보기

파이썬 리스트로 하던 일을 SQL로 하면 이렇게 돼요

하는 일

파이썬 (15, 23)

SQL

담을 곳 만들기

orders = []

CREATE TABLE orders (…);

하나 넣기

orders.append({"id": 1, …})

INSERT INTO orders VALUES (1, …);

모두 보기

print(orders)

SELECT * FROM orders;

골라 보기

[o for o in orders if o["id"] == 2]

SELECT * FROM orders WHERE id = 2;

넣는 값

아무 값이나 들어가요

열 타입에 맞는 값만 들어가요

프로그램을 끄면

사라져요

서버에 남아요

넣고 꺼내는 일은 같고, 담는 곳이 메모리에서 서버로 바뀌어요.

파이썬 리스트로 하던 일을 SQL로 하면 이렇게 돼요. 담을 곳을 만드는 일은 빈 리스트 대신 CREATE TABLE이에요. 하나 넣기는 append 대신 INSERT, 모두 보기는 print 대신 SELECT 별표예요. 23에서 배운 리스트 컴프리헨션으로 id가 2인 주문을 고르던 일은 WHERE 한 줄이면 돼요. 다른 점도 두 가지예요. 리스트에는 아무 값이나 들어가지만 표의 열은 정한 타입만 받아요. 그리고 리스트는 프로그램을 끄면 사라지지만 표는 서버에 남아요.
