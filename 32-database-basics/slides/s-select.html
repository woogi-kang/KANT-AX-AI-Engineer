2. SQL 네 문장 맛보기

SELECT 뒤에 열을 고르고, WHERE로 행을 골라요

MySQL 8.4

mysql> SELECT menu, qty FROM orders;

+-----------+------+

| menu      | qty  |

+-----------+------+

| latte     |    2 |

| americano |    1 |

| cake      |    1 |

+-----------+------+

3 rows in set (0.00 sec)

 

mysql> SELECT * FROM orders WHERE id = 2;

+----+-----------+------+

| id | menu      | qty  |

+----+-----------+------+

|  2 | americano |    1 |

+----+-----------+------+

1 row in set (0.00 sec)

PostgreSQL 18

cafe=# SELECT menu, qty FROM orders;

  menu    | qty

-----------+-----

latte     |   2

americano |   1

cake      |   1

(3 rows)

 

cafe=# SELECT * FROM orders WHERE id = 2;

id |   menu    | qty

----+-----------+-----

 2 | americano |   1

(1 row)

menu, qty 열만

id가 2인 행만

WHERE 뒤에 조건을 적어요. 같다는 파이썬의 ==와 달리 = 하나예요.

SELECT 뒤에 열을 고르고, WHERE로 행을 골라요. 별표 대신 열 이름을 쉼표로 적으면 그 열만 꺼내요. 첫 문장은 menu와 qty 두 열만 꺼냈어요. 두 번째 문장은 끝에 WHERE id = 2를 붙였어요. WHERE 뒤에 조건을 적으면 조건에 맞는 행만 나와요. 17에서 배운 if와 비슷해요. 다만 같다를 파이썬은 등호 두 개로 쓰고, SQL은 하나로 써요. 작다, 크다는 파이썬처럼 부등호를 써요. 4파트 예제에서 써 봐요. 행이 몇 개 나왔는지는 MySQL은 rows in set, PostgreSQL은 괄호 안 rows로 알려 줘요. SQL 출력은 tools/demo.py로 실제 MySQL 8.4와 PostgreSQL 18에서 실행한 결과예요.
