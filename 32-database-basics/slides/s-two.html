자동 번호는 1, 2, 3을 서버가 붙여 주는 기능이에요. 이 챕터에서는 번호를 직접 넣어요.

\c, \l처럼 역슬래시로 시작하는 것은 SQL이 아니라 psql 프로그램의 명령이에요.

MySQL과 PostgreSQL은 SQL이 같고, 프로그램 명령 몇 개가 달라요. 오늘 본 네 문장과 WHERE, 열 타입 INT와 VARCHAR, PRIMARY KEY는 두 서버에서 그대로 같아요. 다른 것은 아래 표예요. 프롬프트 모양이 다르고, 데이터베이스를 고르는 명령과 목록을 보는 명령이 달라요. 결과 끝 줄의 모양도 조금 달라요. 번호를 자동으로 붙이는 방법도 달라요. MySQL은 AUTO_INCREMENT, PostgreSQL은 SERIAL이라고 적어요. 이 챕터에서는 번호를 직접 넣으니 이름만 알아 두면 돼요. 서버가 기다리는 기본 포트는 3306과 5432예요. 33에서 컨테이너로 켤 때 다시 봐요. 수업에서 강사님이 두 서버를 오가도 SQL 부분은 그대로 따라가면 돼요.
