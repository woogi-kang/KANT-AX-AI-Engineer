2. SQL 네 문장 맛보기

CREATE TABLE로 열 이름, 타입, 기본 키를 정해요

MySQL 8.4

mysql> CREATE TABLE orders (

->  id INT PRIMARY KEY,

->  menu VARCHAR(20),

->  qty INT

-> );

Query OK, 0 rows affected (0.01 sec)

표 이름 orders

정수 · 기본 키

글자 20자까지

정수

;가 나와야 실행해요

길면 줄을 나눠 써도 돼요.
이어지는 줄의 프롬프트는 ->, cafe(#로 바뀌어요.

만든 표는 아직 행이 없는 빈 표예요.

CREATE TABLE로 열 이름, 타입, 기본 키를 정해요. 표 이름 orders 뒤 괄호 안에 열을 쉼표로 나눠 적어요. 열마다 이름, 타입 순서예요. id는 정수이고, 뒤에 PRIMARY KEY를 붙여서 기본 키로 정했어요. menu는 20자까지의 글자, qty는 정수예요. 문장이 길어서 줄을 나눠 쳤어요. 세미콜론이 나오기 전까지는 서버가 실행하지 않고 다음 줄을 기다려요. 그래서 이어지는 줄의 프롬프트가 MySQL은 화살표, PostgreSQL은 cafe 괄호 샵으로 바뀌어요. 오른쪽 PostgreSQL도 같은 문장이에요. 다 만들면 열 이름과 타입만 있고 행은 없는 빈 표가 생겨요. SQL 출력은 tools/demo.py로 실제 MySQL 8.4와 PostgreSQL 18에서 실행한 결과예요.
