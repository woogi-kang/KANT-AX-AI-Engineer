2. SQL 네 문장 맛보기

열 이름을 적으면 순서가 보이고, 여러 행을 한 번에 넣어요

INSERT INTO orders VALUES (1, 'latte', 2);

INSERT INTO orders (id, menu, qty)
VALUES (2, 'americano', 1), (3, 'cake', 1);

MySQL 8.4

mysql> INSERT INTO orders (id, menu, qty) VALUES (2, 'americano', 1), (3, 'cake', 1);

Query OK, 2 rows affected (0.01 sec)

Records: 2  Duplicates: 0  Warnings: 0

PostgreSQL 18

cafe=# INSERT INTO orders (id, menu, qty) VALUES (2, 'americano', 1), (3, 'cake', 1);

INSERT 0 2

두 행이 들어갔어요

뒤의 2가 넣은 행 수

괄호 묶음을 쉼표로 이어 적으면 한 문장으로 여러 행이 들어가요.

열 이름을 적으면 순서가 보이고, 여러 행을 한 번에 넣어요. 앞 장의 문장에 두 가지를 더했어요. 표 이름 뒤에 열 이름을 괄호로 적으면 값이 어느 열에 들어가는지 한눈에 보여요. 표의 열 순서를 외우지 않아도 돼요. VALUES 뒤에는 괄호 묶음을 쉼표로 이어 적어서 2번, 3번 주문을 한 번에 넣었어요. MySQL은 2 rows affected, PostgreSQL은 INSERT 0 2로 두 행이 들어갔다고 알려 줘요. MySQL의 Records 줄은 넣은 행과 겹친 행, 경고 수를 보여 줘요. SQL 출력은 tools/demo.py로 실제 MySQL 8.4와 PostgreSQL 18에서 실행한 결과예요.
