5000원보다 싼 메뉴만

메뉴판을 보고 menu 표를 설계해요. 표를 만들기 전에 열 세 가지를 정해요. 메뉴마다 겹치지 않는 번호를 새로 붙여서 id로 두고 기본 키로 정해요. 메뉴 이름은 글자라서 VARCHAR(20), 가격은 원 단위 정수라서 INT예요. 설계가 끝나면 CREATE TABLE, INSERT, SELECT 세 문장을 보내요. 이번에는 PostgreSQL 화면이에요. WHERE price < 5000으로 5000원보다 싼 메뉴만 골랐어요. 숫자 비교라서 따옴표가 없어요. 같은 세 문장을 MySQL에 보내도 같은 두 행이 나와요. 1파트에서 본 것처럼 주문 표에 메뉴 번호만 적고 가격은 이 표에서 찾는 방법은 다음에 배워요. SQL 출력은 tools/demo.py로 실제 MySQL 8.4와 PostgreSQL 18에서 실행한 결과예요.
