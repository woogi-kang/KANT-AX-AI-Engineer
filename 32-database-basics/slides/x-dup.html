3. 자주 나는 오류

이미 있는 기본 키를 또 넣으면 서버가 막아요

MySQL 8.4

mysql> INSERT INTO orders VALUES (1, 'tea', 1);

ERROR 1062 (23000): Duplicate entry '1' for key 'orders.PRIMARY'

PostgreSQL 18

cafe=# INSERT INTO orders VALUES (1, 'tea', 1);

ERROR:  duplicate key value violates unique constraint "orders_pkey"

DETAIL:  Key (id)=(1) already exists.

1번은 라테 주문이 이미 쓰고 있어요. 아직 안 쓴 번호로 바꿔요.

INSERT INTO orders VALUES (4, 'tea', 1);

같은 1번이라 들어가지 않아요

이미 있는 기본 키를 또 넣으면 서버가 막아요. 1번 행이 있는데 id가 1인 티 주문을 넣었어요. MySQL은 Duplicate entry 1, PostgreSQL은 duplicate key value라고 알려 줘요. 둘 다 기본 키가 겹쳤다는 뜻이에요. 1파트에서 본 기본 키 규칙을 서버가 지켜 준 거예요. 오류가 나면 행은 하나도 들어가지 않아요. 아직 안 쓴 번호로 바꿔서 다시 넣어요. PostgreSQL은 DETAIL 줄에 어느 열의 어느 값이 겹쳤는지까지 보여 줘요. SQL 출력은 tools/demo.py로 실제 MySQL 8.4와 PostgreSQL 18에서 실행한 결과예요.
