2. SQL 네 문장 맛보기

CREATE DATABASE로 cafe를 만들고, 그 안으로 들어가요

MySQL 8.4

mysql> CREATE DATABASE cafe;

Query OK, 1 row affected (0.00 sec)

 

mysql> USE cafe;

Database changed

PostgreSQL 18

postgres=# CREATE DATABASE cafe;

CREATE DATABASE

postgres=# \c cafe

You are now connected to database "cafe" as user "postgres".

만드는 문장은 같아요

들어가는 명령은 달라요

같은 일, 다른 모양

프롬프트도 바뀌어요. PostgreSQL은 지금 있는 데이터베이스 이름을 앞에 보여 줘요.

CREATE DATABASE로 cafe를 만들고, 그 안으로 들어가요. 위가 MySQL, 아래가 PostgreSQL 화면이에요. 첫 줄 CREATE DATABASE cafe;는 두 서버에서 똑같아요. 서버 안에 cafe라는 빈 데이터베이스가 생겨요. 다음은 이제부터 cafe에서 일하겠다고 알리는 명령이에요. MySQL은 USE cafe;, PostgreSQL은 역슬래시 c cafe를 써요. 하는 일은 같고 모양만 달라요. 역슬래시 c는 SQL이 아니라 psql 프로그램의 명령이라서 끝에 세미콜론이 없어요. PostgreSQL의 프롬프트는 postgres=#에서 cafe=#로 바뀌어요. 지금 있는 데이터베이스 이름이 앞에 나와요. SQL 출력은 tools/demo.py로 실제 MySQL 8.4와 PostgreSQL 18에서 실행한 결과예요.
