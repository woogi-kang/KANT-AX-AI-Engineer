4. 실제 상황 예제

예제 1 · 오늘 들어온 주문을 넣고, 라테 주문만 골라 봐요

주문서 · 진동벨 4번

latte 1잔

주문서 · 진동벨 5번

tea 2잔

MySQL 8.4

mysql> INSERT INTO orders VALUES (4, 'latte', 1), (5, 'tea', 2);

Query OK, 2 rows affected (0.00 sec)

Records: 2  Duplicates: 0  Warnings: 0

 

mysql> SELECT * FROM orders WHERE menu = 'latte';

+----+-------+------+

| id | menu  | qty  |

+----+-------+------+

|  1 | latte |    2 |

|  4 | latte |    1 |

+----+-------+------+

2 rows in set (0.00 sec)

주문서 두 장이 두 행으로

1번과 오늘 넣은 4번

PostgreSQL 18

cafe=# SELECT * FROM orders WHERE menu = 'latte';

id | menu  | qty

----+-------+-----

 1 | latte |   2

 4 | latte |   1

(2 rows)

오늘 들어온 주문서 두 장을 표에 넣고, 라테 주문만 골라 봐요. 진동벨 번호를 id로 쓰면 기본 키가 겹치지 않아요. INSERT 한 문장에 괄호 묶음 두 개를 이어 적어서 4번, 5번 주문을 한 번에 넣었어요. 그다음 WHERE menu = latte로 메뉴가 라테인 행만 골랐어요. 글자 값이라 작은따옴표로 감쌌어요. 아침에 넣은 1번과 지금 넣은 4번이 나와요. 왼쪽 아래는 PostgreSQL에 같은 두 문장을 보낸 결과에서 SELECT 부분만 옮긴 거예요. 결과가 같아요. SQL 출력은 tools/demo.py로 실제 MySQL 8.4와 PostgreSQL 18에서 실행한 결과예요.
