프로그램은 데이터 파일을 직접 만지지 않아요. 서버가 부탁을 차례대로 받아 대신 읽고 써요.

프로그램은 데이터베이스 서버에 SQL로 부탁해요. 왼쪽은 데이터를 쓰고 싶은 프로그램들이에요. 터미널의 mysql, psql 프로그램, 주문을 받는 파이썬 앱, 매장의 키오스크예요. 가운데가 데이터베이스 서버예요. 데이터베이스를 관리해 주는 프로그램이라서 DBMS, 데이터베이스 관리 시스템이라고 불러요. MySQL과 PostgreSQL이 많이 쓰는 두 가지예요. 수업에서는 둘을 번갈아 써도 오늘 배우는 내용은 같아요. 프로그램이 SQL이라는 말로 부탁하면, 서버가 부탁을 차례대로 받아서 디스크의 데이터 파일을 대신 읽고 써요. 여럿이 동시에 써도 데이터가 꼬이지 않는 이유예요.
