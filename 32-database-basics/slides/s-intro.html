2. SQL 네 문장 맛보기

SQL은 서버에 보내는 부탁 문장이에요

1

CREATE DATABASE

데이터베이스를 만들어요  CREATE DATABASE cafe;

2

CREATE TABLE

표를 만들고 열과 타입을 정해요  CREATE TABLE orders (…);

3

INSERT

표에 행을 넣어요  INSERT INTO orders VALUES (…);

4

SELECT

표에서 행을 꺼내요  SELECT * FROM orders;

읽을 때 알아 둘 세 가지

문장은 ;로 끝나요.
;가 나와야 서버가 실행해요.

SQL 낱말은 대문자로 쓰는 게 약속이에요.
소문자로 써도 돌아가요.

글자 값은 'latte'처럼
작은따옴표로 감싸요.

이 챕터에서는 화면을 읽기만 해요.
서버를 켜고 직접 치는 건 33, 34에서 해요.

SQL은 서버에 보내는 부탁 문장이에요. 오늘은 네 문장만 봐요. CREATE DATABASE로 데이터베이스를 만들고, CREATE TABLE로 표를 만들어요. INSERT로 표에 행을 넣고, SELECT로 꺼내요. 이 네 문장은 MySQL과 PostgreSQL에서 글자 하나 안 바꾸고 똑같이 돌아요. 읽을 때 알아 둘 것이 세 가지 있어요. 문장은 세미콜론으로 끝나요. SQL 낱말은 대문자로 쓰는 게 약속이지만 소문자로 써도 돼요. 글자 값은 작은따옴표로 감싸요. 이 챕터에서는 실제로 실행한 화면을 읽기만 하고, 서버를 켜고 직접 치는 건 33, 34에서 해요.
