3. 자주 나는 오류

데이터베이스를 고르지 않으면 표를 못 찾아요

MySQL 8.4

mysql> SELECT * FROM orders;

ERROR 1046 (3D000): No database selected

PostgreSQL 18

postgres=# SELECT * FROM orders;

ERROR:  relation "orders" does not exist

LINE 1: SELECT * FROM orders;

                     ^

지금 postgres 안이에요

먼저 들어갈 데이터베이스를 골라요

USE cafe;

\c cafe

표는 데이터베이스 안에 있어서, 어느 데이터베이스인지부터 정해야 해요.

데이터베이스를 고르지 않으면 표를 못 찾아요. 서버에 막 들어온 상태에서 바로 SELECT를 쳤어요. MySQL은 No database selected, 고른 데이터베이스가 없다고 해요. PostgreSQL은 처음 들어가면 postgres 데이터베이스 안에 있어서, 거기서 orders를 찾다가 없다고 해요. 프롬프트가 postgres=#인 걸 보면 알 수 있어요. 1파트에서 본 것처럼 표는 데이터베이스 안에 있어요. 먼저 USE cafe; 나 역슬래시 c cafe로 들어간 다음 SELECT를 쳐요. SQL 출력은 tools/demo.py로 실제 MySQL 8.4와 PostgreSQL 18에서 실행한 결과예요.
