SQL 한 줄을 보내면 서버가 표를 돌려줘요

SELECT * FROM orders ;

꺼내 줘요

모든 열을

orders 표에서

여기서 끝

MySQL 8.4

mysql> SELECT * FROM orders;

+----+-----------+------+

| id | menu      | qty  |

+----+-----------+------+

|  1 | latte     |    2 |

|  2 | americano |    1 |

|  3 | cake      |    1 |

+----+-----------+------+

3 rows in set (0.00 sec)

PostgreSQL 18

cafe=# SELECT * FROM orders;

id |   menu    | qty

----+-----------+-----

 1 | latte     |   2

 2 | americano |   1

 3 | cake      |   1

(3 rows)

두 서버가 같은 문장을 알아듣고 같은 세 행을 줘요. 표를 그리는 모양만 조금 달라요.

SQL 한 줄을 보내면 서버가 표를 돌려줘요. 오늘 배울 것 중 가장 짧은 문장이에요. SELECT는 꺼내 달라는 말이고, 별표는 모든 열, FROM orders는 orders 표에서라는 뜻이에요. 끝의 세미콜론이 문장이 끝났다는 표시예요. 왼쪽은 MySQL, 오른쪽은 PostgreSQL에 같은 문장을 보낸 화면이에요. 둘 다 주문 세 행을 표로 돌려줘요. 테두리 모양과 마지막 줄만 조금 달라요. 이 표가 어떻게 생겼고 어떻게 만드는지 차례로 봐요. SQL 출력은 tools/demo.py로 실제 MySQL 8.4와 PostgreSQL 18에서 실행한 결과예요.
