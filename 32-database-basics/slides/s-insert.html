2. SQL 네 문장 맛보기

INSERT로 표에 행을 하나 넣어요

MySQL 8.4

mysql> INSERT INTO orders VALUES (1, 'latte', 2);

Query OK, 1 row affected (0.01 sec)

PostgreSQL 18

cafe=# INSERT INTO orders VALUES (1, 'latte', 2);

INSERT 0 1

1행이 들어갔어요

뒤의 1이 넣은 행 수

orders

id

menu

qty

1

latte

2

VALUES (1, 'latte', 2)

괄호 안의 값이 열 순서대로 들어가요.

id, menu, qty 순서로 만들었으니
1, 'latte', 2 순서로 적어요.
글자 값만 작은따옴표로 감싸요.

INSERT로 표에 행을 하나 넣어요. INSERT INTO orders는 orders 표에 넣겠다는 말이고, VALUES 뒤 괄호 안이 넣을 값이에요. 값은 표를 만들 때 정한 열 순서대로 들어가요. id, menu, qty 순서였으니 1, latte, 2로 적어요. latte는 글자라서 작은따옴표로 감쌌어요. 넣으면 빈 표에 행이 하나 생겨요. MySQL은 Query OK, 1 row affected, PostgreSQL은 INSERT 0 1이라고 알려 줘요. 둘 다 행 하나가 들어갔다는 뜻이에요. PostgreSQL의 앞 숫자 0은 이 챕터에서는 신경 쓰지 않아도 돼요. SQL 출력은 tools/demo.py로 실제 MySQL 8.4와 PostgreSQL 18에서 실행한 결과예요.
