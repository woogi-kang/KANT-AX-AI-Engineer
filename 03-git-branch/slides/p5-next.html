최신 main에서 새로 따요

새 브랜치를 pull 하기 전의 main에서 따면 방금 합친 로그인 버튼 커밋이 없는 채로 시작해요. 그러면 나중에 충돌이 날 가능성이 커져요. 그래서 PR이 합쳐질 때마다 git checkout main, git fetch origin, git pull origin main 순서로 맞춘 뒤 다음 브랜치를 만들어요. 이 흐름이 그다음 장의 GitHub Flow예요.
