GitHub에서 함께

팀에서는 이 순서로 일해요

1

브랜치 만들기

git checkout
-b feature/
login-button

2

작업하고 커밋

add, commit

3

브랜치 올리기

git push origin
feature/
login-button

4

합쳐 달라고 요청

Pull Request

5

확인하고 합치기

리뷰 → Merge

6

내 main 맞추기

git checkout main
git fetch origin
git pull origin main

내 컴퓨터

GitHub 웹사이트

내 컴퓨터

main에는 직접 push하지 않아요. 6번을 마치면 다음 브랜치는 1번부터 다시 시작해요.

Pull Request(PR)는 "내 브랜치를 main에 합쳐 주세요"라는 요청서예요. 팀원이 바뀐 코드를 보고 의견을 남긴 뒤 합쳐요. 혼자 하는 프로젝트에서도 PR로 합치면 무엇을 언제 바꿨는지 기록이 깔끔하게 남아요.
