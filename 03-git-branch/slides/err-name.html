에러 1 · 브랜치 이름

옮기려는데, 만들려는데 안 돼요

없는 브랜치로 옮김

$ git checkout feat/nope
error: pathspec 'feat/nope' did not match any file(s) known to git

이름 오타이거나 아직 안 만든 브랜치예요

git branch

git checkout -b feat/nope

이미 있는 이름으로 만듦

$ git checkout -b feat/a
fatal: a branch named 'feat/a' already exists

같은 이름이 벌써 있어요. -b 없이 옮겨 가요

git checkout feat/a

pathspec 에러는 Git이 브랜치도 파일도 못 찾았다는 뜻이에요. git branch로 목록을 보고 철자를 확인해요. 새로 만들 생각이었다면 -b를 붙여요. already exists는 반대로 이미 있는 이름에 -b를 붙였을 때 나요.
