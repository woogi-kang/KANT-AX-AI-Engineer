1

받을 브랜치로 이동

git checkout main

2

가져올 브랜치 이름을 적어요

git merge feat/greeting

02에서 본 git pull origin main도 받아 온 커밋을 이 방식으로 merge해요.

git merge 이름은 그 이름의 커밋을 지금 내가 있는 브랜치로 가져와요. 그래서 순서가 중요해요. 먼저 받을 쪽(main)으로 checkout하고, 그다음 가져올 브랜치 이름을 적어요. 반대로 feat/greeting에 있는 채로 git merge main을 치면 main의 커밋이 feat/greeting으로 들어가요. 02에서 git pull origin main을 배울 때 merge는 03에서 본다고 했죠. pull은 GitHub의 main을 받아 온 뒤 지금 브랜치로 merge해요.
