에러 3 · 브랜치 지우기

브랜치가 안 지워져요

아직 합치지 않은 커밋이 있음

$ git branch -d feat/a
error: the branch 'feat/a' is not fully merged.
If you are sure you want to delete it, run 'git branch -D feat/a'

지우면 그 커밋을 잃을 수 있어서 Git이 멈췄어요

git checkout main

git merge feat/a

git branch -d feat/a

합치고 지우는 게 기본이에요. 정말 버릴 작업일 때만 대문자 -D로 강제로 지워요. GitHub에서 PR을 merge했는데도 이 에러가 나면, 먼저 git checkout main 후 git pull origin main으로 내 main을 최신으로 맞추고 다시 지워 봐요.
