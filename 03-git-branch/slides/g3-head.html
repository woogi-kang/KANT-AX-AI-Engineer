브랜치란? · 그래프 읽기

HEAD는 지금 내가 있는 곳이에요

$ git log --oneline

d6b044a (HEAD -> main, origin/main) docs: README 추가

5ec913c feat: 인사말 추가

9e6cce4 feat: 인사 파일 추가

커밋하면 HEAD가 붙은 이름표가 앞으로 가요.

9e6cce4

5ec913c

d6b044a

main

◀ HEAD

HEAD는 지금 내가 서 있는 브랜치를 가리켜요. git log의 HEAD -> main은 지금 main에 있다는 뜻이에요. 이 덱의 모든 장면은 이름표와 HEAD가 어디로 가는지만 보면 돼요.
