충돌 풀기

헷갈리면 merge 전으로 돌아가요

$ git merge feature/login-email

CONFLICT (content): Merge conflict in login.md

Automatic merge failed; fix conflicts and then commit the result.

$ git merge --abort

$ git status

On branch main

nothing to commit, working tree clean

merge --abort는 합치기 전 모습으로 돌려놔요. 천천히 다시 해도 돼요.

충돌을 풀다 꼬였거나 지금 풀 시간이 없으면 git merge --abort를 쳐요. 출력은 없고, git status가 깨끗해져요. pull 하다 난 충돌도 똑같이 git merge --abort로 돌아가요. 이 화면은 시나리오 2의 충돌이에요. 출력 중 Auto-merging 줄은 뺐어요.
