세 칸 모두 42209fe 전 모습으로 돌아갔어요. 일반 커밋은 이 변경을 가진 브랜치가 따로 없어서 --hard로 지우면 파일에서 되찾기 어려워요. 02에서 본 git reflog로 해시를 찾는 방법만 남아요. 작업 폴더에 커밋하지 않은 다른 변경이 있었다면 그것도 같이 사라져요. 그래서 --hard 앞에는 git status를 봐요. git status 출력의 On branch main 줄은 뺐어요.
