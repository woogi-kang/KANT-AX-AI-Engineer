GitHub에서 Merge pull request를 누르면 GitHub에 merge 커밋(878b202, 메시지 Merge pull request #1 from kim/feat/emoji)이 생겨요. 내 컴퓨터는 아직 모르니 main으로 돌아가 pull로 받아요. pull 출력의 From, FETCH_HEAD 줄은 뺐어요. 로컬 브랜치는 -d로 지워요. origin/feat/emoji 이름표는 GitHub에서 브랜치를 지운 뒤에도 내 컴퓨터에 남아 있어요. git fetch origin --prune 하면 정리돼요.
