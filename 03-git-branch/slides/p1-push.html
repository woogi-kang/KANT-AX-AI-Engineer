GitHub에도 생긴 브랜치

git push origin 브랜치이름으로 브랜치째 GitHub에 올려요. 보라색 origin/ 이름표는 GitHub에 있는 브랜치 위치예요. 우리 과정 규칙대로 -u는 쓰지 않아요. 출력 앞부분(Enumerating objects..., remote: Create a pull request...)은 뺐어요.
