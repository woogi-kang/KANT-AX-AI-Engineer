PR이 합쳐졌으면 먼저 합친 쪽 브랜치인 main으로 옮겨 가요. fetch는 GitHub의 새 커밋을 받아서 origin/main 이름표만 옮기고, 내 main과 작업 폴더는 건드리지 않아요. 점선 0e04baf는 받아 왔지만 아직 내 main에 합치지 않은 커밋이에요. 출력의 From 줄은 뺐어요.
