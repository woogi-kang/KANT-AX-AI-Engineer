merge 되돌리기

언제 무엇으로 되돌릴까?

충돌이 나서 merge가 멈췄어요

git merge --abort

합치기 전으로 돌아가요

merge를 끝냈고, 아직 push 전이에요

git reset --hard HEAD~1

git status가 깨끗한지 먼저 봐요

merge하고 push까지 했어요

혼자 되돌리지 않아요

팀에 먼저 알리고 함께 정해요

merge를 되돌릴 일이 없을 때 브랜치를 지워요.

merge를 되돌릴 땐 --hard가 가장 깔끔해요. 브랜치에 작업이 그대로 있으니 다시 merge하면 되기 때문이에요. 단, 작업 폴더에 커밋하지 않은 변경이 있으면 같이 지워지니 git status부터 봐요. 이미 push한 merge를 reset으로 지우면 팀원 기록과 어긋나서 push가 거절돼요. 그때는 강사나 팀과 먼저 이야기해요.
