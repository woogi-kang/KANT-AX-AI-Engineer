타입은 커밋 메시지(feat, fix, docs …)와 같은 말을 써요.

앞부분 타입은 커밋 메시지 규칙과 같은 말이라 브랜치 이름만 봐도 무슨 작업인지 알 수 있어요. 팀에 정해진 규칙이 있으면 그걸 따라요.
