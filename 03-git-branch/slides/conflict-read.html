<<<<<<<, =======, >>>>>>> 줄이 남은 채로 커밋하지 않아요.

HEAD는 지금 서 있는 브랜치예요. 위쪽이 내 것, 아래쪽이 가져오려는 것이에요. VS Code로 열면 Accept Current Change(내 것), Accept Incoming Change(가져온 것), Accept Both Changes(둘 다) 버튼이 떠서 클릭으로 골라도 돼요. 고른 뒤에도 저장하고 add, commit 하는 건 똑같아요.
