만들고 옮기기

브랜치만 옮기는 명령, git switch

git checkout

git switch

브랜치로 옮겨 가기

git checkout 이름

git switch 이름

만들고 바로 옮겨 가기

git checkout -b 이름

git switch -c 이름

$ git switch feature/login

Switched to branch 'feature/login'

$ git switch -c feature/login-button

Switched to a new branch 'feature/login-button'

하는 일과 출력은 같아요. 이 덱은 checkout으로 보여 주고, switch로 쳐도 돼요.

git switch는 Git 2.23(2019년)에 생긴 명령이에요. checkout은 브랜치를 옮기는 일 말고 파일을 예전 모습으로 되돌리는 일도 해서 헷갈리기 쉬워요. 그래서 브랜치를 옮기는 일만 따로 떼어 switch를 만들었어요. -c는 create(만들기)의 첫 글자예요. 내 Git이 오래돼서 switch가 없다고 나오면 git --version으로 버전을 확인해요. 팀 자료나 인터넷 글에는 두 명령이 섞여 나오니 둘 다 읽을 수 있으면 돼요.
