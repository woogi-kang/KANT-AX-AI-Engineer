충돌 시나리오 5 · pull 할 때

처음 한 번만 설정해요

git config --global pull.rebase false

git pull

pull은 두 단계예요

= fetch

GitHub 커밋을 받아 오고

+ merge

내 main과 합쳐요

pull.rebase false는 pull할 때 merge로 합치라는 뜻이에요. 설정한 뒤 다시 pull해요.

출력은 없어요. --global이라 내 컴퓨터의 모든 저장소에 한 번에 적용돼요. rebase는 이 과정에서 다루지 않아요. 02의 처음 설정(user.name, user.email)과 같이 해 두면 좋아요.
