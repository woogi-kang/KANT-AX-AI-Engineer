commit -am은 이미 아는 파일(bye.md)의 add와 commit을 한 번에 하는 옵션이에요. 새 파일엔 안 돼요. push할 때 main 대신 브랜치 이름을 적어요. 우리 과정 규칙대로 -u는 쓰지 않아요. GitHub이 Pull Request를 만들 주소를 알려 줘요. push 출력 앞부분(Enumerating objects...)은 뺐어요.
