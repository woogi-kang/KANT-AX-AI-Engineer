충돌 시나리오 3 · 지움 vs 고침

지울지 남길지 골라요

$ git status

Unmerged paths:

(use "git add/rm <file>..." as appropriate to mark resolution)

    deleted by them: old-login.md

지우기로 하면

git rm old-login.md

git commit -m "..."

남기기로 하면

git add old-login.md

git commit -m "..."

deleted by them은 합치려는 브랜치(them)가 지웠다는 뜻이에요.

git status 앞뒤 안내 줄은 뺐어요. 이번 실습에서는 git rm old-login.md로 지우기를 골랐고 출력은 rm 'old-login.md'였어요. 이어서 git commit -m "chore: 옛 로그인 화면 삭제 반영"을 하면 [main 7e68b90] chore: 옛 로그인 화면 삭제 반영이 나와요. 내가 지운 쪽이면 deleted by us로 보여요.
