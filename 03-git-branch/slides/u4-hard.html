세 칸 모두 merge 전 모습이에요. 작업 폴더에 커밋하지 않은 다른 변경이 있었다면 그것도 같이 사라지고 되찾을 수 없어요. 그래서 --hard 앞에는 꼭 git status를 봐요. 로그인 안내 커밋 29bd96c는 docs/login-guide 이름표가 아직 가리키고 있어서 잃어버리지 않았어요. git status 출력의 On branch main 줄은 뺐어요.
