편집기가 vim이면 :wq 로 저장하고 닫아요

양쪽에 새 커밋이 있으니 Git이 둘을 합친 새 커밋(merge 커밋)을 만들어요. 이 커밋은 부모가 둘이에요. 편집기에 Merge branch 'docs/usage'라는 메시지가 미리 적혀 있어요. 그대로 저장하고 닫으면 돼요. vim이 열리면 Esc를 누른 뒤 :wq 와 Enter를 쳐요. 합친 뒤 docs/usage는 지웠어요. 그래서 그래프에서 docs/usage 이름표가 사라졌어요. 커밋 d92e18b는 main 기록 안에 그대로 남아요.
