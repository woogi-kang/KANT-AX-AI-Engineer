$ git pull origin main

CONFLICT (content): Merge conflict in login.md

# 로그인하기

# Login

$ git add login.md

$ git commit -m

"fix: 팀원과 로그인 제목 충돌 해결"

$ git push origin main

82b872c..1ebdd15 main -> main

pull 충돌은 아래쪽 이름이 브랜치 대신 커밋 해시예요. 푸는 법은 같아요.

설정한 뒤 다시 pull하면 시나리오 1과 같은 충돌 표시가 나와요. GitHub에서 받아 온 커밋은 브랜치 이름이 없어서 >>>>>>> 뒤에 해시가 나와요. 위쪽 HEAD가 내 것, 아래쪽이 팀원 것이에요. 고치고 add, commit 한 다음 push하면 이번엔 올라가요. pull, commit, push 출력 일부는 뺐어요.
