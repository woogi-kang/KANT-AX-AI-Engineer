충돌 시나리오

메시지로 충돌 종류를 알아봐요

CONFLICT (content)

같은 줄, 옆 줄

고르고, 표시 지우고, add, commit

CONFLICT (modify/delete)

지움 vs 고침

git rm 또는 git add, commit

CONFLICT (add/add)

같은 이름 새 파일

고르고, 표시 지우고, add, commit

fatal: Need to specify how to reconcile ...

갈라진 채 pull

git config --global pull.rebase false

This branch has conflicts ...

PR 충돌

내 브랜치에서 pull origin main, 풀고 push

어떤 충돌이든 막히면 git merge --abort로 처음으로 돌아갈 수 있어요.

메시지 첫 단어만 봐도 무엇을 할지 알 수 있어요. 충돌을 푼 뒤에는 git status로 남은 충돌 파일이 없는지 확인하고 커밋해요.
