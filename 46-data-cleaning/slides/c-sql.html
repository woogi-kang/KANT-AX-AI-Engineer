5. 그래프와 오류

SQL로 하던 정리를 pandas 한 줄로 해요

할 일

pandas (오늘)

SQL (36~43)

빈칸 세기

df["age"].isnull().sum()

SELECT COUNT(*) FROM t WHERE age IS NULL

빈칸 행 보기

df.loc[df["age"].isnull(), 열]

SELECT 열 FROM t WHERE age IS NULL

빈칸 채우기

df["age"] = df["age"].fillna(29.7)

UPDATE t SET age = 29.7 WHERE age IS NULL

값마다 세기

df["town"].value_counts()

SELECT town, COUNT(*) FROM t GROUP BY town

행 지우기

df = df[df["fare"] < 512]

DELETE FROM t WHERE fare >= 512

가운데 값

df["fare"].quantile(0.5)

다루지 않았어요

SQL은 서버의 표를 바꾸고, pandas는 메모리의 표를 다시 담아요.

오늘 한 정리는 SQL에서도 해 본 일이에요. 빈칸 세기는 36의 IS NULL과 COUNT, 채우기는 36의 UPDATE와 WHERE, 값마다 세기는 39의 GROUP BY, 행 지우기는 36의 DELETE예요. 차이는 결과를 다루는 방식이에요. SQL은 데이터베이스의 표를 바로 바꾸고, pandas는 새 열이나 새 표를 돌려줘서 df에 다시 담아야 바뀌어요. 표에서 t와 town은 줄여 적은 이름이에요.
