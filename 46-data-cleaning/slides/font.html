import platform

import matplotlib.pyplot as plt

 

os_name = platform.system()

if os_name == "Windows":

plt.rcParams["font.family"] = "Malgun Gothic"

elif os_name == "Darwin":

plt.rcParams["font.family"] = "AppleGothic"

기본 글꼴 DejaVu Sans에 한글이 없어서 네모로 나와요.

Windows는 맑은 고딕, Mac은 AppleGothic을 골라요.

matplotlib의 기본 글꼴에는 한글이 없어서 제목과 축 이름이 네모로 깨져요. 셀 아래에는 글자를 못 찾았다는 UserWarning이 글자마다 나와요. platform.system은 지금 컴퓨터가 Windows인지 Mac인지 이름을 돌려줘요. Mac은 Darwin이라고 나와요. 17의 if와 elif로 Windows면 맑은 고딕, Mac이면 AppleGothic을 rcParams에 정해요. 한 번 실행하면 그 노트북의 그래프에 계속 적용돼요. 오른쪽 그림은 리눅스에서 만들어서 맑은 고딕 대신 나눔고딕으로 그렸어요. 왼쪽은 글꼴을 정하지 않은 같은 그래프예요. 출력은 실제로 실행한 결과예요.
