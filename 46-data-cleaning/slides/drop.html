4. 튀는 값과 중복

튀는 값 중 512만 지우고, 표[조건]을 다시 담아요

[21]

df["fare"].sort_values(ascending=False).head(5)

Python

737 512.3292

679 512.3292

258 512.3292

438 263.0000

88 263.0000

Name: fare, dtype: float64

← 세 명이 똑같이 512

[22]

before = len(df)

df = df[df["fare"] < 512].copy()

print(before, "=>", len(df))

Python

891 => 888

← 512 미만만 남겨서 df에 다시 담아요

← 세 줄이 빠졌어요

튀는 116명을 다 지우면
1등석 승객이 거의 사라져요.
수업에서는 혼자 동떨어진
512만 지웠어요.

튀는 값이라고 다 지우지는 않아요. 116명 중 104명이 1등석이라 비싼 요금이 틀린 값이 아니에요. 6파트에서 다시 봐요. 요금을 큰 순서로 보면 512.33이 세 명이고 그다음은 263이라 512만 동떨어져 있어요. 그래서 수업에서는 512 미만인 행만 남겨서 df에 다시 담았어요. 지운다는 건 남길 행을 골라 다시 담는 거예요. 891행이 888행이 됐어요. 뒤의 .copy()는 고른 표를 새 표로 떼어 두는 메서드예요. pandas 3부터는 빼도 경고가 나지 않지만, 수업 코드처럼 붙여 두면 예전 버전에서도 안전해요. 출력은 실제로 실행한 결과예요.
