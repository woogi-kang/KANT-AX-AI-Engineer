5. 그래프와 오류

fillna 결과를 다시 담지 않으면 빈칸이 그대로예요

[2]

df["age"].fillna(29.7)

df["age"].isnull().sum()

Python

np.int64(177)

← 그대로 177

[3]

df["age"].fillna(29.7, inplace=True)

df["age"].isnull().sum()

Python

ChainedAssignmentError: A value is being set

on a copy of a DataFrame or Series through

chained assignment using an inplace method.

np.int64(177)

← 여전히 177

fillna는 새 열을 돌려줄 뿐이에요. inplace=True도 열 하나에 쓰면 원본을 못 바꿔요 (pandas 3).

✕

df["age"].fillna(29.7)

✓

df["age"] = df["age"].fillna(29.7)

고친 셀은 np.int64(0)이 나와요. 다시 세어서 확인해요.

가장 흔한 실수는 fillna만 치고 다시 담지 않는 거예요. fillna는 채운 새 열을 돌려줄 뿐이라 df는 그대로라서 빈칸이 177로 남아요. 인터넷 예제에 자주 나오는 inplace=True도 pandas 3에서는 열 하나에 쓰면 원본을 못 바꿔요. 셀 아래에 ChainedAssignmentError 경고가 나고 여전히 177이에요. 실제 경고는 더 길어서 첫 문장만 옮겼어요. 경고는 오류와 달리 셀이 멈추지 않아요. 왼쪽에 df["age"] =를 붙여 다시 담으면 0이 돼요. 이 셀만 새 노트북에서 실행해서 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
