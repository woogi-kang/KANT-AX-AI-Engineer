패키지는 늘 uv add로 넣어요. VS Code 알림의 Install 버튼은 누르지 않아요.

45에서 만든 ml-basics 프로젝트를 그대로 써요. 터미널에서 uv add seaborn matplotlib을 치면 두 패키지와 그림 저장용 pillow 같은 도우미가 같이 들어와요. seaborn은 그래프 도구인데 연습용 데이터를 내려받는 load_dataset도 있어요. matplotlib은 6파트에서 나이 그래프를 그려요. VS Code에서 titanic.ipynb를 만들고 커널은 .venv로 골라요. 첫 셀이 데이터를 인터넷에서 받아 오니 연결된 채로 실행해요. 출력 가운데 줄은 줄였어요. 버전 숫자는 실행한 날에 따라 달라요. 출력은 실제로 실행한 결과예요.
