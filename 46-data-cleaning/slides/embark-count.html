3. 빈칸 채우기

value_counts(dropna=False)로 빈칸까지 같이 세요

[9]

df["embark_town"].value_counts()

Python

embark_town

Southampton 644

Cherbourg 168

Queenstown 77

Name: count, dtype: int64

[10]

df["embark_town"].value_counts(dropna=False)

Python

embark_town

Southampton 644

Cherbourg 168

Queenstown 77

NaN 2

Name: count, dtype: int64

← 빈칸 2

← 빈칸은 안 보여요

Southampton

Cherbourg

Queenstown

← 가장 많아요: 최빈값

글자 열은 평균을 낼 수 없어서 가장 많이 나온 값으로 채워요. 먼저 값마다 몇 번 나왔는지 세요. 45의 value_counts는 빈칸을 빼고 세서 왼쪽처럼 NaN이 안 보여요. dropna=False를 넣으면 빈칸도 한 줄로 세어 줘요. dropna는 빈칸을 뺀다는 뜻이고 False로 끄는 거예요. 탑승 항구는 Southampton이 644번으로 가장 많고 빈칸은 2개예요. 가장 많이 나온 값을 최빈값이라고 해요. 출력은 실제로 실행한 결과예요.
