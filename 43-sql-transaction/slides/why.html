WHERE를 빠뜨린 UPDATE는 ROLLBACK을 쳐도 안 돌아와요

kant_shop=# UPDATE courses SET fee = 0;

UPDATE 14

kant_shop=# ROLLBACK;

WARNING:  there is no transaction in progress

ROLLBACK

kant_shop=# SELECT course_name, fee FROM courses ORDER BY course_id LIMIT 4;

  course_name    | fee

------------------+-----

수영 초급 아침반 |   0

수영 초급 저녁반 |   0

수영 중급 새벽반 |   0

수영 고급반      |   0

(4 rows)

WHERE course_id = 5를 빠뜨렸어요

14줄이 모두 0원

되돌릴 거리가 없대요

psql은 문장을 치는 순간 저장해요. 그래서 ROLLBACK을 쳐도 돌아갈 곳이 없어요.

아쿠아로빅 하나만 고치려다 WHERE를 빠뜨렸다고 해 봐요. UPDATE 14가 나왔어요. 강좌 14개의 수강료가 모두 0원이 됐어요. 급하게 ROLLBACK을 쳐 봤지만 WARNING이 나와요. 진행 중인 트랜잭션이 없다는 뜻이에요. 다시 SELECT해 보면 여전히 0원이에요. psql은 문장 하나를 칠 때마다 바로 저장하기 때문이에요. 오늘은 문장을 치기 전에 BEGIN으로 저장 지점을 만들어서, 이런 실수를 ROLLBACK 한 번으로 되돌려요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
