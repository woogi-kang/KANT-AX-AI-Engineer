02와 07에서 배운 Git과 나란히 놓아 봐요. 파일을 고쳤지만 커밋하기 전인 상태가 BEGIN 뒤에 UPDATE를 친 상태와 닮았어요. git commit이 COMMIT, git restore로 고친 것을 버리는 것이 ROLLBACK이에요. 다른 점도 있어요. Git은 git push를 해야 다른 사람에게 보이지만, 데이터베이스는 COMMIT하는 순간 다른 창에 보여요. 가장 큰 차이는 마지막 줄이에요. Git은 커밋 기록이 남아서 예전 커밋으로 돌아갈 수 있지만, 데이터베이스는 COMMIT한 뒤에 돌아갈 기록이 없어요. 원래 값을 알아서 다시 UPDATE해야 해요.
