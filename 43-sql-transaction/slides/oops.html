숫자가 다르면 COMMIT하지 말고 ROLLBACK해요

kant_shop=# SELECT COUNT(*) FROM enrollments WHERE enroll_month = '2026-11' AND status = '취소';

count

-------

    6

(1 row)

kant_shop=# BEGIN;

BEGIN

kant_shop=*# DELETE FROM enrollments WHERE enroll_month = '2026-11' OR status = '취소';

DELETE 77

kant_shop=*# ROLLBACK;

ROLLBACK

kant_shop=# SELECT COUNT(*) FROM enrollments;

count

-------

  187

(1 row)

지울 줄은 6줄

AND를 OR로 잘못 쳤어요

한 줄도 안 지워졌어요

이번에는 같은 일을 하다가 AND를 OR로 잘못 쳤어요. OR는 둘 중 하나만 맞아도 골라서, 11월 신청 전부와 다른 달 취소까지 지워요. 처음에 센 숫자는 6인데 DELETE 뒤의 숫자는 훨씬 커요. 숫자가 다르면 COMMIT하지 않아요. ROLLBACK을 치고 전체를 세어 보면 187줄이 그대로예요. BEGIN이 없었다면 이 줄들은 그대로 사라졌어요. 38에서 본 AND와 OR의 차이가 이런 사고로 이어져요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
