BEGIN을 먼저 치면 같은 실수도 ROLLBACK 한 번으로 살려요

kant_shop=# BEGIN;

BEGIN

kant_shop=*# UPDATE courses SET fee = 0;

UPDATE 14

kant_shop=*# SELECT course_name, fee FROM courses ORDER BY course_id LIMIT 3;

  course_name    | fee

------------------+-----

수영 초급 아침반 |   0

수영 초급 저녁반 |   0

수영 중급 새벽반 |   0

(3 rows)

kant_shop=*# ROLLBACK;

ROLLBACK

kant_shop=# SELECT course_name, fee FROM courses ORDER BY course_id LIMIT 3;

  course_name    |  fee

------------------+-------

수영 초급 아침반 | 70000

수영 초급 저녁반 | 70000

수영 중급 새벽반 | 80000

(3 rows)

저장 지점을 먼저 만들어요

같은 실수, 14줄이 0원

BEGIN 때로 돌아가요

앞 장과 같은 실수를 이번에는 BEGIN 다음에 해 봤어요. 먼저 BEGIN을 쳤어요. 그러자 프롬프트가 kant_shop=*#으로 바뀌었어요. 별표는 지금 트랜잭션 안에 있다는 표시예요. UPDATE 14가 나왔고, SELECT해 보면 이 창에서는 정말 0원으로 보여요. 이번에는 ROLLBACK이 경고 없이 끝나요. 별표도 사라졌어요. 다시 SELECT하면 7만 원, 7만 원, 8만 원이 그대로 있어요. 오늘 배울 세 명령이 이 화면에 다 있어요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
