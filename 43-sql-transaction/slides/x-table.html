5. 비교와 오류

트랜잭션에서 자주 만나는 메시지와 상황

이런 게 보이면

이렇게 해요

WARNING: there is no transaction in progress

BEGIN 없이 ROLLBACK, COMMIT을 쳤어요

이미 저장됐어요. 다음엔 BEGIN부터

WARNING: there is already a transaction in progress

BEGIN 상태에서 BEGIN을 또 쳤어요

그대로 이어서 쳐요

ERROR: current transaction is aborted, …

앞 문장 오류로 트랜잭션이 실패했어요 (!#)

ROLLBACK 뒤 처음부터

COMMIT을 쳤는데 ROLLBACK

실패한 트랜잭션은 확정이 안 돼요

오류를 고쳐 다시 해요

다른 창의 UPDATE가 대답이 없어요

BEGIN한 창이 같은 줄을 잡고 있어요

그 창에서 COMMIT이나 ROLLBACK

나갔다 오니 바꾼 값이 없어요

COMMIT 없이 \q로 나갔어요

끝내기 전에 * 확인

오늘 본 메시지와 상황을 모았어요. 위의 두 줄은 WARNING이에요. BEGIN 없이 ROLLBACK을 치면 이미 저장된 뒤라서 되돌릴 수 없어요. 다음부터 BEGIN을 먼저 쳐요. BEGIN을 두 번 치면 그냥 이어서 쓰면 돼요. 셋째와 넷째는 트랜잭션 안에서 오류가 난 경우예요. 프롬프트가 느낌표로 바뀌고, 무엇을 쳐도 무시돼요. COMMIT을 쳐도 ROLLBACK이 돼요. ROLLBACK하고 고쳐서 다시 해요. 다섯째, 다른 창의 UPDATE가 대답이 없으면 BEGIN한 창이 같은 줄을 고치는 중이에요. 여섯째, COMMIT 없이 나가면 바꾼 값은 사라져요.
