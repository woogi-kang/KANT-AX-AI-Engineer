3. 모두 되거나 모두 안 되거나

중간에 오류가 나면 *가 !로 바뀌고 ROLLBACK만 받아요

kant_shop=# BEGIN;

BEGIN

kant_shop=*# UPDATE enrollments SET status = '취소', pay_amount = 0 WHERE enrollment_id = 184;

UPDATE 1

kant_shop=*# INSERT INTO enrollments VALUES (187, 11, 9, '2026-11', '신청', 75000);

ERROR:  duplicate key value violates unique constraint "enrollments_pkey"

DETAIL:  Key (enrollment_id)=(187) already exists.

kant_shop=!# SELECT * FROM enrollments WHERE enrollment_id = 184;

ERROR:  current transaction is aborted, commands ignored until end of transaction block

kant_shop=!# ROLLBACK;

ROLLBACK

kant_shop=# SELECT * FROM enrollments WHERE enrollment_id = 184;

enrollment_id | member_id | course_id | enroll_month | status | pay_amount

---------------+-----------+-----------+--------------+--------+------------

          184 |        11 |        13 | 2026-11      | 신청   |     150000

(1 row)

187번은 이미 있어요

①도 같이 되돌려요

이번에는 둘째 문장에서 번호를 187로 잘못 적었어요. 187번은 이미 있어서 기본 키 오류가 나요. 37에서 본 duplicate key 오류예요. 그러자 프롬프트가 kant_shop=!#으로 바뀌었어요. 느낌표는 이 트랜잭션이 실패했다는 표시예요. 이 상태에서는 SELECT를 쳐도 current transaction is aborted가 나오고 아무 문장도 실행되지 않아요. 트랜잭션을 끝낼 때까지 무시한다는 뜻이에요. ROLLBACK을 치면 느낌표가 사라지고, 첫째 문장의 취소도 같이 되돌아가요. 184번은 다시 신청, 15만 원이에요. 번호를 고쳐서 처음부터 다시 하면 돼요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
