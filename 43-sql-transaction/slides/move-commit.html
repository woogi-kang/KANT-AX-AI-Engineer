3. 모두 되거나 모두 안 되거나

오류 뒤에 COMMIT을 쳐도 ROLLBACK이라고 대답해요

kant_shop=# BEGIN;

BEGIN

kant_shop=*# UPDATE enrollments SET status = '취소', pay_amount = 0 WHERE enrollment_id = 184;

UPDATE 1

kant_shop=*# INSERT INTO enrollments VALUES (187, 11, 9, '2026-11', '신청', 75000);

ERROR:  duplicate key value violates unique constraint "enrollments_pkey"

DETAIL:  Key (enrollment_id)=(187) already exists.

kant_shop=!# COMMIT;

ROLLBACK

kant_shop=# SELECT enrollment_id, status, pay_amount FROM enrollments WHERE enrollment_id = 184;

enrollment_id | status | pay_amount

---------------+--------+------------

          184 | 신청   |     150000

(1 row)

COMMIT을 쳤는데 ROLLBACK

실패한 트랜잭션은 확정할 수 없어요. 대답이 COMMIT인지 ROLLBACK인지 꼭 읽어요.

앞 장과 같은 오류가 난 뒤에 이번에는 COMMIT을 쳐 봤어요. 그런데 psql이 ROLLBACK이라고 대답해요. 오류 메시지도 없어서 그냥 지나치기 쉬워요. 느낌표가 붙은 트랜잭션은 확정할 수 없어서, COMMIT을 쳐도 PostgreSQL이 알아서 되돌려요. 첫째 문장의 취소도 저장되지 않았어요. 그래서 COMMIT을 친 뒤에는 대답이 정말 COMMIT인지 읽어 봐요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
