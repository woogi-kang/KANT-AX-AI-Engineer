6. 실제 상황

실제 상황 1 · 수강료 5% 인상을 미리 해 보고 되돌려요

kant_shop=# BEGIN;

BEGIN

kant_shop=*# UPDATE courses SET fee = fee * 1.05 WHERE sport_id = 3

kant_shop-*# RETURNING course_name, fee;

course_name |  fee

-------------+-------

아침 요가   | 68250

요가 중급   | 78750

(2 rows)

UPDATE 2

kant_shop=*# ROLLBACK;

ROLLBACK

kant_shop=# SELECT course_name, fee FROM courses WHERE sport_id = 3;

course_name |  fee

-------------+-------

아침 요가   | 65000

요가 중급   | 75000

(2 rows)

원래 값 그대로

첫 번째 실제 상황이에요. 센터장이 요가 수강료를 5% 올리면 얼마가 되는지 묻는다고 해 봐요. BEGIN을 치고 요가 강좌에 fee = fee * 1.05를 해 봤어요. RETURNING으로 새 수강료가 바로 보여요. 아침 요가는 68250원, 요가 중급은 78750원이에요. 숫자만 확인했으니 ROLLBACK으로 되돌려요. 다시 읽어 보면 원래 수강료 그대로예요. 계산 결과를 보기만 할 때도 BEGIN과 ROLLBACK을 미리보기처럼 쓸 수 있어요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
