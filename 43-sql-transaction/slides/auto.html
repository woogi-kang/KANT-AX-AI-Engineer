1. BEGIN, COMMIT, ROLLBACK

BEGIN이 없으면 문장 하나하나가 바로 저장돼요

kant_shop=# UPDATE courses SET fee = 65000 WHERE course_id = 5;

UPDATE 1

kant_shop=# SELECT course_name, fee FROM courses WHERE course_id = 5;

course_name |  fee

-------------+-------

아쿠아로빅  | 65000

(1 row)

이 순간 저장돼요

psql이 문장마다 몰래 하는 일

BEGIN

UPDATE …;

COMMIT

BEGIN

SELECT …;

COMMIT

이것을 자동 커밋(autocommit)이라고 해요. 그래서 치자마자 되돌릴 수 없어요.

BEGIN을 치지 않으면 psql은 문장 하나를 치는 순간 바로 저장해요. 이것을 자동 커밋, 오토커밋이라고 해요. 오른쪽 그림처럼 문장마다 앞에 BEGIN, 뒤에 COMMIT을 몰래 붙여서 실행한다고 생각하면 돼요. 그래서 UPDATE 1이 나온 순간 아쿠아로빅 수강료는 이미 65000원으로 확정됐어요. 35부터 41까지 친 문장도 모두 이렇게 바로 저장됐어요. 그동안은 편했지만 실수도 바로 저장돼요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
