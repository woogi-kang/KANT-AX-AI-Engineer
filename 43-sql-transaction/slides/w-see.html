2. 다른 창에서 보면

COMMIT하기 전에는 다른 창에서 바뀐 값이 안 보여요

창 1 · 데스크

창 2 · 강사

kant_shop=# BEGIN;

BEGIN

kant_shop=*# UPDATE courses SET fee = 65000 WHERE course_id = 5;

UPDATE 1

kant_shop=*# SELECT fee FROM courses WHERE course_id = 5;

 fee

-------

65000

(1 row)

kant_shop=*# COMMIT;

COMMIT

kant_shop=# SELECT fee FROM courses WHERE course_id = 5;

 fee

-------

60000

(1 row)

kant_shop=# SELECT fee FROM courses WHERE course_id = 5;

 fee

-------

65000

(1 row)

창 1에서는 65000

창 2는 아직 60000

COMMIT 뒤에 보여요

확정하지 않은 변경은 바꾼 창에서만 보여요. COMMIT을 잊으면 다른 사람은 계속 옛 값을 봐요.

psql 창을 두 개 띄웠어요. 데스크 직원과 강사가 같은 데이터베이스에 붙은 장면이에요. 창 1에서 BEGIN을 치고 아쿠아로빅 수강료를 65000원으로 바꿨어요. 창 1에서 SELECT하면 65000원이 보여요. 이때 창 2에서 같은 줄을 읽으면 아직 60000원이에요. 확정하지 않은 변경은 바꾼 창에서만 보여요. 창 1에서 COMMIT을 친 뒤에 창 2에서 다시 읽으면 그제야 65000원이 보여요. BEGIN만 치고 COMMIT을 잊으면 다른 사람은 계속 옛 값을 봐요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요. 두 창 화면은 tools/duo.py로 psql 두 개를 동시에 띄워 실제로 친 결과예요.
