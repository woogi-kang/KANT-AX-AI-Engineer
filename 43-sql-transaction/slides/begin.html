1. BEGIN, COMMIT, ROLLBACK

BEGIN을 치면 프롬프트에 *가 붙고, COMMIT하면 사라져요

kant_shop=# BEGIN;

BEGIN

kant_shop=*# UPDATE courses SET fee = 65000 WHERE course_id = 5;

UPDATE 1

kant_shop=*# SELECT course_name, fee FROM courses WHERE course_id = 5;

course_name |  fee

-------------+-------

아쿠아로빅  | 65000

(1 row)

kant_shop=*# COMMIT;

COMMIT

kant_shop=# SELECT course_name, fee FROM courses WHERE course_id = 5;

course_name |  fee

-------------+-------

아쿠아로빅  | 65000

(1 row)

* : 지금 트랜잭션 안이에요

여기서 확정, 저장돼요

*가 사라졌어요

같은 UPDATE를 이번에는 BEGIN 다음에 쳤어요. BEGIN을 치면 psql은 BEGIN이라고 대답하고, 프롬프트가 kant_shop=*#으로 바뀌어요. 별표가 보이는 동안은 트랜잭션 안에 있어요. 이 창에서 SELECT하면 65000원으로 보이지만 아직 확정된 값은 아니에요. COMMIT을 치면 COMMIT이라고 대답하고 그때 저장돼요. 프롬프트의 별표도 사라져요. 별표가 보이면 아직 확정하지 않은 변경이 있다고 기억해요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
