1. BEGIN, COMMIT, ROLLBACK

COMMIT한 뒤에는 ROLLBACK으로 돌아가지 않아요

kant_shop=# BEGIN;

BEGIN

kant_shop=*# UPDATE courses SET fee = 65000 WHERE course_id = 5;

UPDATE 1

kant_shop=*# COMMIT;

COMMIT

kant_shop=# ROLLBACK;

WARNING:  there is no transaction in progress

ROLLBACK

kant_shop=# SELECT course_name, fee FROM courses WHERE course_id = 5;

course_name |  fee

-------------+-------

아쿠아로빅  | 65000

(1 row)

이미 확정했어요

되돌릴 트랜잭션이 없어요

확정한 값을 되돌리려면 원래 값으로 UPDATE를 한 번 더 쳐요. 그래서 COMMIT 전에 꼭 확인해요.

COMMIT은 되돌릴 수 없는 확정이에요. COMMIT 다음에 ROLLBACK을 치면 첫 장에서 본 WARNING이 그대로 나와요. 진행 중인 트랜잭션이 없다는 뜻이에요. 수강료도 65000원 그대로예요. 확정한 값을 되돌리려면 UPDATE courses SET fee = 60000 WHERE course_id = 5처럼 원래 값을 알고 다시 고쳐야 해요. 그래서 COMMIT을 치기 전에 SELECT로 결과를 한 번 보는 습관을 들여요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
