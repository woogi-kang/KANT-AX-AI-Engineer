4. SGD로 세 열 배우기

크기를 맞춘 표로 SGD를 학습하면 채점용 R²가 0.95예요

[20]

sgd = SGDRegressor(

loss="squared_error",

learning_rate="constant",

eta0=0.01,

max_iter=3000,

random_state=42

)

 

sgd.fit(X_train_scaled, y_train)

 

sgd_pred = sgd.predict(X_test_scaled)

 

print(f"MAE: {mean_absolute_error(y_test, sgd_pred):.4f}")

print(f"MSE: {mean_squared_error(y_test, sgd_pred):.4f}")

print(f"R2: {r2_score(y_test, sgd_pred):.4f}")

Python

MAE: 2.8169

MSE: 8.5966

R2: 0.9456

← 손실은 MSE (49)

← 보폭을 바꾸지 않아요 (49)

← 보폭(학습률) 0.01

← 최대 3000 epoch까지

← 섞는 순서 고정

← 바꾼 학습용

← 바꾼 채점용

[21]

print("반복한 epoch:", sgd.n_iter_)

print("기울기 w:", sgd.coef_.round(2))

print("절편 b:", sgd.intercept_.round(2))

Python

반복한 epoch: 197

기울기 w: [9.37 3.47 3.86]

절편 b: [67.43]

3000까지 가지 않고 197번째에 멈췄어요. 손실이 거의 줄지 않으면 스스로 멈춰요.

절편 67.43은 학습용 7명의 평균 점수와 거의 같아요. 바꾼 값이 모두 0인 학생, 곧 평균 학생의 점수예요.

수업 셀 55예요. 49에서 배운 SGDRegressor를 세 열에 써요. loss는 MSE, learning_rate는 constant로 보폭을 바꾸지 않고, eta0는 보폭 0.01이에요. max_iter는 epoch를 최대 몇 번까지 돌지예요. 이번에는 fit에 바꾼 학습용 표를, predict에 바꾼 채점용 표를 넣었어요. 채점용 R제곱은 0.9456이에요. 오른쪽 셀을 보면 3000번을 다 돌지 않고 197번째 epoch에서 멈췄어요. 손실이 더 줄지 않으면 스스로 멈추는 설정이 기본으로 켜져 있어서예요. 절편 67.43은 바꾼 값이 모두 0인 학생, 곧 세 열 모두 평균인 학생의 예측 점수예요. 수업 셀의 주석은 두 줄이 서로 바뀌어 있어서 빼고 이 장의 설명으로 대신했어요. 오른쪽 셀은 이해를 도우려고 더했어요. 출력은 실제로 실행한 결과예요.
