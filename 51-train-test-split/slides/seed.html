2. 나눠서 채점하기

random_state를 빼면 실행할 때마다 다른 학생이 채점용이 돼요

random_state 없이 두 번

[8]

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3)

print("채점용 학생:", list(X_test.index))

Python

채점용 학생: [4, 7, 5]

[9]

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3)

print("채점용 학생:", list(X_test.index))

Python

채점용 학생: [1, 2, 3]

random_state=42로 두 번

[10]

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

print("채점용 학생:", list(X_test.index))

Python

채점용 학생: [8, 1, 5]

[11]

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

print("채점용 학생:", list(X_test.index))

Python

채점용 학생: [8, 1, 5]

섞는 순서가 매번 달라서 결과가 달라요. 여러분 화면의 위 두 줄은 이것과 다를 수 있어요.

번호를 정해 두면 몇 번을 실행해도 같은 3명이에요. 47의 default_rng(42)와 같은 생각이에요.

42는 약속일 뿐이에요. 0이든 7이든 같은 숫자를 쓰면 같은 결과가 나와요.

random_state를 빼고 같은 셀을 두 번 실행했어요. 처음엔 4번, 7번, 5번이, 두 번째엔 1번, 2번, 3번이 채점용이 됐어요. 섞는 순서가 실행할 때마다 달라서예요. 채점용이 바뀌면 점수도 바뀌니까, 어제와 오늘 결과를 비교할 수가 없어요. random_state에 숫자를 주면 섞는 순서가 고정돼요. 47에서 난수를 만들 때 default_rng(42)로 시드를 정한 것과 같은 생각이에요. 42에 특별한 뜻은 없고 많이 쓰는 약속일 뿐이에요. 다른 숫자를 써도 같은 숫자면 같은 결과가 나와요. random_state가 없는 두 줄은 여러분 화면과 다를 수 있어요. 출력은 실제로 실행한 결과예요.
