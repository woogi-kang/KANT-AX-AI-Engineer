리스트

[ ]

순서대로 쌓고 번호로 꺼낼 때

예: 하루 주문 orders

튜플

( )

바뀌지 않는 묶음

예: (메뉴, 가격, 수량) 한 줄

딕셔너리

{키: 값}

이름으로 값을 찾을 때

예: 메뉴판 menu

집합

{값}

중복 없애기, 있는지 묻기, 겹침 찾기

예: 팔린 메뉴 종류, 두 반 명단

섞어 써도 돼요. 4파트처럼 리스트를 집합으로 바꿔 비교하고 딕셔너리로 가격을 찾아요.

지금까지 배운 네 그릇을 언제 쓰는지 정리해요. 순서가 중요하고 같은 값이 여러 번 나와도 되면 리스트예요. 바뀌지 않는 한 묶음은 튜플이에요. 이름으로 값을 찾으면 딕셔너리예요. 중복을 없애거나, 들어 있는지 묻거나, 두 목록에서 겹치는 것을 찾으면 집합이에요. 실제로는 앞 장처럼 섞어 써요. 주문은 리스트로 쌓고, 비교할 때만 집합으로 바꾸고, 가격은 딕셔너리에서 찾아요.
