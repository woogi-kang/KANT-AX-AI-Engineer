a = {1, 2, 3, 4}

b = {3, 4, 5, 6}

b

a = {1, 2, 3, 4}

b = {3, 4, 5, 6}

print(a | b)

print(a.union(b))

Python

{1, 2, 3, 4, 5, 6}

{1, 2, 3, 4, 5, 6}

← 겹친 3, 4는 하나씩

a | b

또는

a.union(b)

| 는 세로줄이에요. 보통 Enter 위 키를 Shift와 함께 눌러요.

합집합은 두 집합 중 어느 쪽에든 있는 값을 모두 모은 거예요. 파이썬에서는 세로줄 | 로 써요. 두 원 전체를 칠한 것과 같아요. 겹친 3과 4는 한 번씩만 들어가서 값은 6개예요. 같은 일을 a.union(b)처럼 메서드 이름으로도 쓸 수 있어요. 기호가 헷갈리면 이름으로 적어도 결과는 같아요. 세로줄은 보통 키보드 Enter 위, 원화 기호나 역슬래시 키에 Shift와 함께 있어요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
