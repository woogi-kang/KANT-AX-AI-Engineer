빼기는 앞뒤를 바꾸면 결과가 달라요. 앞에 적은 쪽이 기준이에요.

차집합은 앞 집합에서 뒤 집합에 있는 값을 뺀 거예요. 빼기 기호 - 로 써요. a - b는 a에서 3과 4를 빼서 1, 2만 남아요. 숫자 빼기처럼 앞뒤를 바꾸면 결과가 달라요. b - a는 b에서 3과 4를 빼서 5, 6이에요. 그림에서는 앞에 적은 원에서 겹친 곳을 뺀 부분만 칠해요. 메서드 이름은 difference예요. 출력은 실제로 실행한 결과예요.
