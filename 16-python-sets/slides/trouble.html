정리

막히면 오류의 마지막 줄을 봐요

1

AttributeError: 'dict' object has no attribute 'add'

빈 집합을 {}로 만들었어요

set()

2

TypeError: 'set' object is not subscriptable

집합에 번호를 붙였어요

sorted(menus)[0]

3

KeyError: 'juice'

없는 값을 remove했어요

discard("juice")

4

TypeError: unhashable type: 'list'

집합에 리스트를 넣었어요

튜플로 바꾸기

5

{'b', 'a', 'n'}

set()에 문자열을 넣어 글자로 쪼개졌어요

{"banana"}

6

print 순서가 슬라이드와 달라요

집합은 순서가 없어요. 틀린 게 아니에요

sorted(menus)

오류가 안 나도 결과가 이상하면 문자열을 그대로 set()에 넣지 않았는지 봐요.

1번부터 4번은 오류 메시지가 나는 경우예요. 오류 마지막 줄을 보면 어떤 값이 문제인지 나와요. 1번은 {}가 딕셔너리라서, 2번은 집합에 번호가 없어서, 3번은 없는 값을 remove해서, 4번은 리스트를 집합에 넣어서 나요. 5번과 6번은 오류는 안 나지만 결과가 생각과 다른 경우예요. 집합을 print한 순서가 슬라이드와 다른 것은 정상이에요. 모두 hello-uv 커널에서 실제로 실행한 결과예요.
