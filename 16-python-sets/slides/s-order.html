집합은 순서를 기억하지 않아요

처음 실행

[3]

menus = {"coffee", "latte", "cake"}

print(menus)

print(sorted(menus))

Python

{'latte', 'cake', 'coffee'}

['cake', 'coffee', 'latte']

Restart 하고 이 셀만 다시 실행

[1]

menus = {"coffee", "latte", "cake"}

print(menus)

print(sorted(menus))

Python

{'coffee', 'cake', 'latte'}

['cake', 'coffee', 'latte']

print(menus) 순서는 바뀔 수 있어요

적은 순서는 coffee, latte, cake인데 다르게 나왔어요. 커널을 다시 켜면 또 달라질 수 있어요. 내 화면이 슬라이드와 달라도 괜찮아요.

순서가 필요하면 sorted()

13에서 배운 sorted()에 넣으면 abc 순서 리스트가 나와요. 몇 번을 실행해도 ['cake', 'coffee', 'latte']예요.

집합에는 순서가 없으니 sorted()로 줄 세워서 봐요.

글자를 담은 집합을 print로 찍으면 적은 순서와 다르게 나와요. 커널을 다시 시작하고 같은 셀을 실행하면 또 다른 순서가 나올 수 있어요. 파이썬이 집합 안에서 값을 빨리 찾으려고 자기 방식대로 놓기 때문이에요. 그래서 수강생 화면의 순서가 슬라이드와 달라도 틀린 게 아니에요. 순서가 필요하면 13에서 배운 sorted()에 넣어요. 결과는 리스트라 대괄호로 나오고, 언제나 abc 순서예요. 왼쪽과 오른쪽 모두 실제로 실행한 결과예요. 슬라이드를 다시 만들 때 같은 출력이 나오도록 demo.sh는 커널마다 PYTHONHASHSEED를 고정했어요.
