set(orders)는 for와 add를 한 줄로 줄인 거예요

줄여 쓰면

kinds = set(orders)

for와 add로 길게 쓰면

[6]

kinds = set()

for o in orders:

kinds.add(o)

print(sorted(kinds))

참고 · 집합이 없으면

if는 17에서 배워요. 읽기만 해요.

kinds = []

for o in orders:

if o not in kinds:

kinds.append(o)

print(kinds)

coffee, latte를 또 넣어도 하나씩

set(orders) 한 줄은 빈 집합에서 시작해 하나씩 add하는 반복을 줄인 거예요. 빈 집합 kinds에서 시작해 for로 주문을 하나씩 꺼내 add해요. 2파트에서 볼 add는 이미 있는 값이면 아무 일도 하지 않아서, 겹친 주문은 하나만 남아요. 결과는 set(orders)와 같아요. 집합이 없으면 리스트에 담으면서 아직 없을 때만 넣기를 직접 물어야 해요. 그때 쓰는 if는 17에서 배우니 아래 참고 칸은 읽기만 해요. 리스트는 처음 나온 순서를 지켜서 coffee, latte, cake 순서예요. 한 줄짜리 기능의 원래 모양을 알면 결과를 읽기 쉬워요. 왼쪽 셀과 참고 코드 모두 실제로 실행한 결과예요.
