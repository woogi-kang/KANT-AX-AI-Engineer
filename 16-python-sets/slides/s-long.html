1. 집합이 뭔가요

set(리스트)는 긴 반복을 한 줄로 줄인 거예요

줄여 쓴 방법

kinds = set(orders)

for와 add로 길게 쓰면

[5]

kinds = set()

for o in orders:

kinds.add(o)

print(sorted(kinds))

Python

['cake', 'coffee', 'latte']

결과는 같아요

빈 주머니에서 시작해 하나씩 add해요. add는 이미 있으면 그대로라서 겹친 주문이 하나만 남아요.

참고 · 집합이 없으면 이렇게

kinds = []

for o in orders:

if o not in kinds:

kinds.append(o)

print(kinds)

['coffee', 'latte', 'cake']

if는 다음에 배워요. 따라 치지 말고 읽기만 해요.

리스트로는 하나씩 물어봐야 해요

아직 없을 때만 append해요. 집합은 그 일을 알아서 해요.

한 줄짜리 기능은 이런 반복을 대신해 줘요. 원래 모양을 알면 결과를 읽기 쉬워요.

set(orders) 한 줄이 실제로 하는 일을 길게 풀어 봐요. 빈 집합 kinds에서 시작해 for로 주문을 하나씩 꺼내 add해요. 2파트에서 볼 add는 이미 있는 값이면 아무 일도 하지 않아서, 겹친 주문은 하나만 남아요. 결과는 set(orders)와 같아요. 집합이 없으면 리스트에 담으면서 '아직 없을 때만 넣기'를 직접 물어야 해요. 그때 쓰는 if는 아직 배우지 않았으니 오른쪽은 읽기만 해요. 리스트는 처음 나온 순서를 지켜서 coffee, latte, cake 순서예요. 왼쪽 셀과 오른쪽 참고 코드 모두 실제로 실행한 결과예요.
