3. 집합 연산

연산 기호도 for를 줄인 거예요

a | b

를 for와 add로 길게 쓰면

[5]

c = set(a)

for x in b:

c.add(x)

print(c)

Python

{1, 2, 3, 4, 5, 6}

← a를 복사해 담고

← b를 하나씩 꺼내서

← 넣어요. 겹친 3, 4는 그대로

& 와 - 는 b에 있는지 물어서 담을지 정해요.
그때 if가 필요해서 오른쪽은 읽기만 해요.

참고 · a & b

if는 17에서 배워요. 읽기만 해요.

both = set()

for x in a:

if x in b:

both.add(x)

print(both)

{3, 4}

참고 · a - b

if는 17에서 배워요. 읽기만 해요.

only_a = set()

for x in a:

if x not in b:

only_a.add(x)

print(only_a)

{1, 2}

실제로 쓸 때는 기호 한 줄로 적어요.

연산 기호 하나는 for로 하나씩 담는 반복을 줄인 거예요. 합집합은 a를 그대로 담은 새 집합에 b의 값을 하나씩 add하면 돼요. 이건 지금까지 배운 것만으로 쓸 수 있어서 셀로 실행해요. 교집합과 차집합은 b에 있는지, 없는지 물어서 담을지 정해야 해서 if가 필요해요. if는 17에서 배우니 오른쪽 두 칸은 읽기만 해요. 결과는 각각 {3, 4}, {1, 2}로 & 와 - 결과와 같아요. 긴 코드는 기호가 무슨 일을 하는지 이해하는 데 써요. 출력은 실제로 실행한 결과예요.
