3. 컨테이너 안에서 작업하기

컨테이너 안을 보는 방법은 세 가지예요

~/kant-shop $ docker exec -it my-pg bash

root@0f29903380a9:/# ls /tmp

kant_shop.sql

root@0f29903380a9:/# exit

exit

 

~/kant-shop $ docker exec my-pg ls /tmp

kant_shop.sql

 

~/kant-shop $ docker exec -it my-pg psql -U postgres -d kant_shop

kant_shop=# \dt

          List of tables

Schema |  Name   | Type  |  Owner

--------+---------+-------+----------

public | product | table | postgres

(1 row)

docker exec -it 이름 bash

들어가서 여러 명령을 쳐요. exit로 나와요.

docker exec 이름 명령

명령 하나만 실행하고 바로 끝나요.

docker exec -it 이름 psql …

psql을 바로 열어요. \q로 나와요.

컨테이너 안을 보는 방법은 세 가지예요. 첫 번째는 docker exec -it 이름 bash예요. 컨테이너 안의 bash가 열려서 ls처럼 여러 명령을 차례로 칠 수 있어요. 앞의 표시가 root@로 바뀌면 컨테이너 안이에요. exit로 나와요. 두 번째는 -it 없이 명령 하나만 붙이는 방법이에요. 31에서 nginx -t를 칠 때 썼어요. 실행하고 바로 내 터미널로 돌아와요. 세 번째는 psql을 바로 여는 방법이에요. -d로 데이터베이스를 고르면 앞의 표시가 kant_shop=#이 돼요. 백슬래시 dt를 치면 kant_shop.sql이 만든 product 표가 보여요. 이 화면은 다음 장에서 파일을 실행한 뒤에 찍었어요. 터미널 출력은 tools/demo.py로 실제 Docker와 postgres:18 이미지를 실행한 결과예요.
