인터넷 자료에는 같은 명령의 긴 이름도 나와요

수업에서 쓰는 이름

같은 명령 (긴 이름)

docker ps

docker container ls

docker images

docker image ls

docker rm my-pg

docker container rm my-pg

docker rmi postgres:18

docker image rm postgres:18

docker exec -it my-pg bash

docker container exec -it my-pg bash

docker cp …

docker container cp …

~/kant-shop $ docker container ls

CONTAINER ID   IMAGE         COMMAND                  CREATED         STATUS         PORTS                    NAMES

b64cc6816076   postgres:18   "docker-entrypoint.s…"   2 seconds ago   Up 2 seconds   0.0.0.0:5432->5432/tcp   my-pg

docker ps와 똑같은 표가 나와요. 어느 쪽을 쳐도 돼요.

인터넷의 치트시트나 공식 문서에는 같은 명령이 긴 이름으로 나오기도 해요. docker ps는 docker container ls, docker images는 docker image ls와 똑같아요. 무엇에 대한 명령인지 container, image를 앞에 붙인 이름이에요. 아래는 docker container ls를 친 실제 화면이에요. docker ps와 같은 표가 나와요. 수업에서는 짧은 이름을 쓰고, 긴 이름이 보이면 이 표로 짝을 찾아요. 각 명령의 --help 맨 아래 Aliases 줄에 같은 명령 목록이 나와요. 표의 짝은 Docker 29.9.2의 --help에서 확인했어요. 터미널 출력은 tools/demo.py로 실제 Docker와 postgres:18 이미지를 실행한 결과예요.
