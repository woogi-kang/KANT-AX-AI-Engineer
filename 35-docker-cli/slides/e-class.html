6. 오류와 실제 상황

예제 1. 수업 흐름 그대로: 켜고, 넣고, 실행하고, 확인해요

1. 켜기

docker run -d \ --name my-pg \ -e POSTGRES_PASSWORD=admin1234 \ -p 5432:5432 postgres:18

2. 넣기

docker cp kant_shop.sql \ my-pg:/tmp/kant_shop.sql

3. 실행하기

docker exec -it my-pg \ psql -U postgres \ -f /tmp/kant_shop.sql

4. 확인하기

docker exec -it my-pg \ psql -U postgres -d kant_shop \ -c "SELECT * FROM product"

~/kant-shop $ docker exec -it my-pg psql -U postgres -d kant_shop -c "SELECT * FROM product"

2, 3 대신 docker exec -i my-pg psql -U postgres < kant_shop.sql 한 줄로 해도 돼요.

예제 1은 오늘 수업 순서 그대로예요. 네 단계로 정리했어요. 첫째, docker run으로 my-pg를 켜요. 둘째, docker cp로 kant_shop.sql을 컨테이너의 /tmp에 넣어요. 셋째, psql -f로 그 파일을 실행해요. 넷째, -d kant_shop과 -c로 SELECT를 실행해서 상품 다섯 개가 들어갔는지 확인해요. 아래가 마지막 단계의 실제 결과예요. 둘째와 셋째 단계는 3파트에서 본 방법 2, docker exec -i와 꺾쇠로 한 번에 할 수도 있어요. 카드의 명령은 백슬래시로 줄을 나눠 적었어요. 그대로 복사해서 쳐도 돼요. 터미널 출력은 tools/demo.py로 실제 Docker와 postgres:18 이미지를 실행한 결과예요.
