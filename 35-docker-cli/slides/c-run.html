네트워크, 볼륨, 컨테이너를 한 번에 만들어요

SERVICE 칸에 서비스 이름 db

컨테이너 이름 my-pg로도 돼요

compose exec 뒤에는 서비스 이름

docker compose up -d로 켜고, ps로 보고, exec로 들어가요. up -d는 compose.yaml을 읽어서 네트워크, 볼륨, 컨테이너를 한 번에 만들고 켜요. docker compose ps는 이 폴더의 compose.yaml로 켠 컨테이너만 보여 줘요. SERVICE 칸에 서비스 이름 db가 보여요. container_name을 my-pg로 적어서, 3파트의 docker exec -i my-pg 명령을 그대로 써도 돼요. docker compose exec도 있어요. 이건 컨테이너 이름이 아니라 서비스 이름 db를 적어요. compose exec는 -it를 안 붙여도 들어가서 칠 수 있어요. 터미널 출력은 tools/demo.py로 실제 Docker와 postgres:18 이미지를 실행한 결과예요.
