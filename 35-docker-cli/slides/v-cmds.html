4. 볼륨

볼륨은 create로 만들고 ls로 보고 inspect로 자세히 봐요

~/kant-shop $ docker volume create pgdata

pgdata

~/kant-shop $ docker volume ls

DRIVER    VOLUME NAME

local     pgdata

~/kant-shop $ docker volume inspect pgdata

[

   {

       "CreatedAt": "2026-11-13T04:44:54Z",

       "Driver": "local",

       "Labels": null,

       "Mountpoint": "/var/lib/docker/volumes/pgdata/_data",

       "Name": "pgdata",

       "Options": null,

       "Scope": "local"

   }

]

이름

docker volume create pgdata

이름 붙여 만들기

docker volume ls

볼륨 목록

docker volume inspect pgdata

자세히 보기 (어디에 저장되는지)

docker volume rm pgdata

지우기 (쓰는 컨테이너가 없을 때)

Mountpoint는 Docker가 데이터를 두는 곳이에요. 직접 열지 않고 컨테이너로 읽어요.

볼륨은 붕어빵 밖 보관함이에요. 30에서는 docker run에 -v를 쓰면 볼륨이 저절로 생겼어요. 수업에서는 docker volume create pgdata로 먼저 만들어 두는 방법도 봤어요. 결과는 같아요. docker volume ls로 목록을 보면 pgdata가 보여요. docker volume inspect는 볼륨 하나를 자세히 보여 줘요. Name은 이름, Mountpoint는 Docker가 실제로 데이터를 두는 폴더예요. 이 폴더는 Docker가 관리하는 곳이라 직접 열어서 고치지 않고, 볼륨을 붙인 컨테이너로 읽고 써요. 지울 때는 docker volume rm이에요. 쓰는 컨테이너가 있으면 지워지지 않는데, 두 장 뒤에서 봐요. 터미널 출력은 tools/demo.py로 실제 Docker와 postgres:18 이미지를 실행한 결과예요.
