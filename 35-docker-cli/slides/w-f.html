상품 다섯 줄

-f 파일은 파일 안의 SQL을 위에서부터 차례로 실행해요. 파일은 컨테이너 안에 있어야 해요.

방법 1은 수업 자료의 첫 번째 방법이에요. docker cp로 넣어 둔 /tmp/kant_shop.sql을 psql -f로 실행해요. -f는 file, 파일이라는 뜻이에요. 파일 안의 SQL을 위에서부터 차례로 실행하고, 문장마다 결과를 한 줄씩 보여 줘요. 첫 줄 NOTICE는 kant_shop이 아직 없어서 DROP을 건너뛰었다는 알림이에요. 오류가 아니에요. You are now connected는 백슬래시 c 줄의 결과이고, INSERT 0 5는 다섯 줄이 들어갔다는 뜻이에요. 아래는 -c로 SELECT 한 문장을 실행해서 상품 다섯 개를 확인한 화면이에요. 이 방법은 파일이 컨테이너 안에 있어야 해서, 먼저 docker cp를 해야 해요. 터미널 출력은 tools/demo.py로 실제 Docker와 postgres:18 이미지를 실행한 결과예요.
