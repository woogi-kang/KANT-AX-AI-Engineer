치트시트

docker compose 명령 한 장

compose.yaml

켜고 보기

docker compose config

파일을 읽은 그대로 보기, YAML 오류 확인

docker compose up -d

만들고 켜기 (뒤에서)

docker compose ps

이 폴더의 컨테이너

docker compose ps -a

꺼진 것까지

docker compose ls

compose 프로젝트 목록

docker compose pull

이미지 미리 받기

다루고 끄기

docker compose exec db \ psql -U postgres -d kant_shop

서비스 이름 db로 들어가기

docker compose logs --tail 3

마지막 3줄 (-f는 계속)

docker compose stop

끄기 (지우지 않아요)

docker compose start

다시 켜기

docker compose restart

껐다가 바로 켜기

docker compose down

지우기, 볼륨은 남아요

docker compose down -v

볼륨까지 지우기

모든 compose 명령은 compose.yaml이 있는 폴더(~/kant-shop)에서 쳐요.

services: db: image: postgres:18 container_name: my-pg environment: POSTGRES_PASSWORD: admin1234 ports: - "5432:5432" volumes: - pgdata:/var/lib/postgresql volumes: pgdata:

2칸 들여쓰기 · 쌍점 뒤 한 칸 · 탭 금지
container_name을 빼면 이름은 kant-shop-db-1

docker compose 명령을 한 장에 모았어요. 왼쪽은 수업에서 쓰는 compose.yaml 모양이에요. 2칸 들여쓰기, 쌍점 뒤 한 칸, 탭은 쓰지 않아요. 가운데는 켜고 보는 명령이에요. up 하기 전에 config로 파일을 먼저 확인하면 YAML 오류를 일찍 찾아요. 오른쪽은 다루고 끄는 명령이에요. compose exec 뒤에는 컨테이너 이름이 아니라 서비스 이름 db를 적어요. down은 볼륨을 남기고 down -v는 볼륨까지 지워요. 모든 compose 명령은 compose.yaml이 있는 폴더에서 쳐요.
