예제 2. compose로 같은 일을 해요: 파일 두 개, 명령 세 줄

~/kant-shop

kant_shop.sql

compose.yaml

services: db: image: postgres:18 container_name: my-pg environment: POSTGRES_PASSWORD: admin1234 ports: - "5432:5432" volumes: - pgdata:/var/lib/postgresql volumes: pgdata:

내일은 docker compose up -d 한 줄이면 돼요. down만 했다면 상품도 그대로 있어요.

예제 2는 같은 일을 compose로 해요. 폴더에 kant_shop.sql과 compose.yaml 두 파일을 둬요. 첫째, docker compose up -d로 켜요. 긴 docker run이 compose.yaml에 들어 있어요. 둘째, docker exec -i my-pg psql -U postgres 꺾쇠 kant_shop.sql로 파일을 넘겨요. container_name을 my-pg로 적어서 수업 명령을 그대로 쓸 수 있어요. 셋째, SELECT로 확인해요. 다음 날에는 docker compose up -d 한 줄로 다시 켜요. 전날 down만 했다면 볼륨이 남아 있어서 상품도 그대로예요. 친구에게 이 폴더를 넘기면 친구도 같은 명령 세 줄로 똑같이 만들 수 있어요. 터미널 출력은 tools/demo.py로 실제 Docker와 postgres:18 이미지를 실행한 결과예요.
