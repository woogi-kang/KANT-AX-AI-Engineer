1. 명령 읽는 법

긴 명령은 줄 끝에 \를 붙여 여러 줄로 나눠요

~/kant-shop $ docker run -d --name my-pg \

> -e POSTGRES_PASSWORD=admin1234 \

> -p 5432:5432 postgres:18

48d1c194469c97d81d48c27d4b50f3a34ea926ed98d99eb8c4245d057a0dc59f

\ 는 "다음 줄도 같은 명령"이라는 표시예요.

Enter를 쳐도 실행하지 않고 > 를 띄워 다음 줄을 기다려요. 한 줄로 친 것과 똑같이 실행돼요.

~/kant-shop $ docker run -d --name my-pg \

> -e POSTGRES_PASSWORD=admin1234 \

> -p 5432:5432 postgres:18

docker: invalid reference format

 

Run 'docker run --help' for more information

bash: line 2: -e: command not found

\ 뒤에 띄어쓰기가 있으면 줄이 끊겨요

Mac 터미널과 Windows Git Bash에서 써요. 수업 자료의 두 가지 쓰는 법은 결과가 같아요.

긴 명령은 줄 끝에 백슬래시를 붙여 여러 줄로 나눠 쳐요. 수업 자료에도 docker run을 한 줄로 쓴 것과 세 줄로 나눈 것이 같이 있었어요. 백슬래시는 다음 줄도 같은 명령이라는 표시예요. Enter를 쳐도 바로 실행하지 않고 꺾쇠를 띄워서 다음 줄을 기다려요. 마지막 줄에서 Enter를 치면 한 줄로 친 것과 똑같이 실행돼요. 조심할 게 하나 있어요. 백슬래시 뒤에 띄어쓰기가 하나라도 있으면 그 줄에서 명령이 끝나요. 아래 화면이 그 경우예요. docker run은 이미지 이름이 없어서 invalid reference format이 나오고, 다음 줄의 -e는 명령으로 읽혀서 command not found가 나와요. 줄 끝은 백슬래시로 끝나야 해요. 터미널 출력은 tools/demo.py로 실제 Docker와 postgres:18 이미지를 실행한 결과예요.
