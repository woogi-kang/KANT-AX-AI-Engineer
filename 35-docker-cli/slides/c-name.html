5. YAML과 compose

container_name을 빼면 이름이 "폴더-서비스-1"로 붙어요

~/kant-shop $ docker compose up -d

[+] up 3/3

✔ Network kant-shop_default Created                                        0.0s

✔ Container kant-shop-db-1  Started                                        0.2s

~/kant-shop $ docker compose ps

NAME             IMAGE         COMMAND                  SERVICE   CREATED                  STATUS                  PORTS

kant-shop-db-1   postgres:18   "docker-entrypoint.s…"   db        Less than a second ago   Up Less than a second   0.0.0.0:5432->5432/tcp

~/kant-shop $ docker exec my-pg ls /tmp

Error response from daemon: No such container: my-pg

그 밖의 compose 명령

docker compose ls

compose로 켠 프로젝트 목록

kant-shop running(1)

docker compose pull

compose.yaml의 이미지를 미리 받기

✔ Image postgres:18 Pulled

container_name을 빼면 이름이 폴더-서비스-1로 붙어요. compose.yaml에서 container_name 한 줄만 지우고 켰어요. 컨테이너 이름이 kant-shop-db-1이 됐어요. 폴더 이름 kant-shop, 서비스 이름 db, 그리고 첫 번째라는 뜻의 1이에요. 31에서 본 cafe-web-1과 같은 규칙이에요. 이때 docker exec my-pg를 치면 No such container, 그런 컨테이너가 없다는 오류가 나요. container_name을 적었는지에 따라 쓸 이름이 달라져요. 헷갈리면 docker compose exec db처럼 서비스 이름으로 들어가면 늘 돼요. 아래 두 개는 가끔 쓰는 명령이에요. compose ls는 compose로 켠 프로젝트 목록, compose pull은 compose.yaml에 적은 이미지를 미리 받아요. 터미널 출력은 tools/demo.py로 실제 Docker와 postgres:18 이미지를 실행한 결과예요.
