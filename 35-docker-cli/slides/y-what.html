# 설명

주석, 실행 안 해요

YAML은 이름: 값을 한 줄에 하나씩 적는 설정 파일 형식이에요. compose.yaml의 yaml이 이 형식이라는 뜻이에요. 수업에서 쓸 모양 그대로 적었어요. 맨 위 services는 실행할 컨테이너 목록이라 꼭 있어야 해요. 그 아래 db는 서비스 이름이고 직접 정해요. db 안에 image, container_name, environment, ports, volumes를 적어요. docker run의 옵션과 하나씩 짝이 맞아요. ports는 따옴표로 감싸는 게 좋아요. 쌍점이 들어간 숫자를 YAML이 다른 값으로 읽지 않게 하려고요. 맨 아래 volumes는 이 파일에서 쓸 볼륨 이름을 적어 두는 자리예요. 아래 세 가지 모양만 알면 compose.yaml을 읽을 수 있어요. 쌍점 뒤에는 한 칸을 띄우고, 하이픈은 목록의 한 칸, 샵 뒤는 주석이에요.
