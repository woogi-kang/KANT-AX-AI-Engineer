치트시트

docker 명령 한 장

이미지

docker pull postgres:18

Docker Hub에서 받기

docker images

받은 이미지 목록

docker rmi postgres:18

지우기 (쓰는 컨테이너 먼저 지우기)

컨테이너

docker run -d --name my-pg \ -e POSTGRES_PASSWORD=admin1234 \ -p 5432:5432 postgres:18

뒤에서 켜기, 이름, 환경 변수, 포트

docker ps / docker ps -a

켜진 것 / 꺼진 것까지

docker stop my-pg

끄기

docker start my-pg

다시 켜기

docker restart my-pg

껐다가 바로 켜기

docker logs --tail 3 my-pg

마지막 3줄 (-f는 계속, Ctrl+C)

docker rm my-pg

지우기 (끈 다음에)

안에서 작업

docker exec -it my-pg bash

들어가기, exit로 나오기

docker exec my-pg ls /tmp

명령 하나만 실행

docker exec -it my-pg \ psql -U postgres -d kant_shop

psql 열기, \q로 나오기

docker cp kant_shop.sql \ my-pg:/tmp/kant_shop.sql

내 파일을 컨테이너로

docker exec -i my-pg \ psql -U postgres < kant_shop.sql

파일 내용 넘기기 (-it 말고 -i)

볼륨

docker volume create pgdata

만들기

docker volume ls

목록

docker volume inspect pgdata

자세히 보기

-v pgdata:/var/lib/postgresql

run에 붙여 연결

docker volume rm pgdata

지우기 (쓰는 컨테이너 먼저)

Windows Git Bash에서 docker cp, psql -f처럼 컨테이너 안 경로를 쓰기 전에 export MSYS_NO_PATHCONV=1을 먼저 쳐요.

docker 명령을 한 장에 모았어요. 왼쪽부터 이미지, 컨테이너, 컨테이너 안에서 작업하기, 볼륨이에요. 모든 예시는 오늘 수업 이름 그대로예요. 컨테이너는 my-pg, 비밀번호는 admin1234, 데이터베이스는 kant_shop, 볼륨은 pgdata예요. 긴 명령은 백슬래시로 줄을 나눠 적었으니 그대로 복사해도 돼요. 지우는 명령에는 무엇을 먼저 지워야 하는지 같이 적었어요. 실습할 때 이 장을 열어 두고 옆에서 봐요.
