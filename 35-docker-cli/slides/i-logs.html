2. 이미지와 컨테이너

logs --tail은 마지막 몇 줄만, -f는 새 기록을 계속 보여 줘요

~/kant-shop $ docker logs --tail 3 my-pg

… LOG:  checkpoint starting: end-of-recovery immediate wait

… LOG:  checkpoint complete: wrote 0 buffers (0.0%), wrote 3 SLRU buffers; 0 WAL file(s) added, 0 removed, 0

recycled; write=0.001 s, sync=0.001 s, total=0.003 s; sync files=2, longest=0.001 s, average=0.001 s;

distance=0 kB, estimate=0 kB; lsn=0/1774018, redo lsn=0/1774018

… LOG:  database system is ready to accept connections

~/kant-shop $ docker logs -f --tail 1 my-pg

… LOG:  database system is ready to accept connections

^C

3줄만 나오고 끝나요

Ctrl+C를 눌러야 멈춰요

Ctrl+C

줄 앞의 날짜와 번호는 화면에서 … 로 줄였어요.

docker logs는 컨테이너 안 프로그램이 남긴 기록을 보여 줘요. 34에서 ready to accept connections를 찾을 때 썼어요. PostgreSQL은 기록이 길어서 그냥 치면 화면이 넘쳐요. --tail 3을 붙이면 마지막 세 줄만 보여 주고 끝나요. -f는 follow, 따라가기라는 뜻이에요. 기록을 보여 준 뒤 끝나지 않고 새 줄이 생길 때마다 계속 보여 줘요. 서버가 다 켜지기를 기다리거나 접속 기록을 지켜볼 때 써요. 멈출 때는 Ctrl+C를 눌러요. 컨테이너는 그대로 켜져 있어요. 화면에서는 줄 앞의 날짜와 번호를 줄였어요. 터미널 출력은 tools/demo.py로 실제 Docker와 postgres:18 이미지를 실행한 결과예요.
