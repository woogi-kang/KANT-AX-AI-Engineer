다 받았어요

docker pull postgres:18

받기

docker images

받은 목록

docker rmi postgres:18

지우기 (쓰는 컨테이너가 없을 때)

태그 18은 PostgreSQL 18이에요. 숫자로 적어 두면 모두 같은 버전을 받아요.

이미지는 pull로 받고 images로 보고 rmi로 지워요. 29에서 배운 세 명령이에요. docker pull postgres:18을 치면 이미지를 여러 층으로 나눠 받아요. 층마다 한 줄씩 나와서 화면에서는 줄였어요. Status 줄이 나오면 다 받은 거예요. docker images에 postgres:18이 보여요. docker rmi는 이미지를 지워요. 이 이미지로 만든 컨테이너가 남아 있으면 지워지지 않는데, 이 파트 끝에서 실제 오류를 봐요. 태그 18은 PostgreSQL 18 버전이라 숫자로 적어 두면 모두 같은 버전을 받아요. 터미널 출력은 tools/demo.py로 실제 Docker와 postgres:18 이미지를 실행한 결과예요.
