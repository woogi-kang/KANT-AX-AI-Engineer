6. 오류와 실제 상황

오늘 만난 오류 여덟 가지를 한 장에 모았어요

이런 글이 보이면

이렇게 해요

Conflict. The container name "/my-pg" is already in use

같은 이름의 컨테이너가 있어요

docker rm my-pg 뒤 다시

Bind for 0.0.0.0:5432 failed: port is already allocated

5432번을 다른 컨테이너가 써요

하나 끄거나 -p 5433:5432

invalid reference format / -e: command not found

줄 끝 \ 뒤에 띄어쓰기가 있어요

\로 줄을 끝내기

cannot attach stdin to a TTY-enabled container

< 파일과 -it를 같이 썼어요

-i만 쓰기

lstat …/kant_shop.sq: no such file or directory

보낼 파일 이름이 틀렸거나 다른 폴더예요

ls로 이름 확인

No such container: my-pg

container_name을 안 적어서 이름이 달라요

docker compose ps로 이름 보기

volume is in use

그 볼륨을 쓰는 컨테이너가 있어요

stop, rm 뒤 volume rm

go-yaml load error … at L3.C1

YAML에 탭, 어긋난 칸, 쌍점 뒤 띄어쓰기

docker compose config로 확인

오늘 만난 오류 여덟 가지를 모았어요. 앞 넷은 docker run과 3파트에서, 뒤 넷은 볼륨과 compose에서 봤어요. 이름 겹침과 포트 겹침은 29에서도 본 오류예요. invalid reference format과 command not found가 같이 나오면 줄 끝 백슬래시 뒤에 띄어쓰기가 있는지 봐요. cannot attach stdin은 꺾쇠로 파일을 넘기면서 -it를 쓴 경우예요. lstat no such file은 docker cp로 보낼 파일을 못 찾았다는 뜻이에요. 이름 오타이거나 다른 폴더에서 쳤을 때 나요. No such container는 compose에서 container_name을 안 적었을 때 자주 봐요. volume is in use가 나오면 그 볼륨을 쓰는 컨테이너를 먼저 지워요. go-yaml로 시작하면 compose.yaml의 YAML 오류예요. 줄과 칸 번호를 보고 config로 다시 확인해요. 터미널 출력은 tools/demo.py로 실제 Docker와 postgres:18 이미지를 실행한 결과예요.
