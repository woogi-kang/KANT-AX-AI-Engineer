⇥ image: postgres:18

3

4

5

탭으로 들여썼어요

go-yaml load error in scanner (while scanning for the next token) at L3.C1: found character that cannot start any token

L3.C1 = 3번째 줄 1번째 칸에 탭

db:

2

image: postgres:18

3

container_name: my-pg

4

environment:

5

한 줄만 2칸이에요

go-yaml load error in scanner at L5.C16: mapping values are not allowed in this context

L5.C16 = 4번째 줄이 어긋나서 다음 줄에서 오류

db:

2

image:postgres:18

3

container_name: my-pg

4

environment:

5

image: 뒤에 띄어쓰기가 없어요

go-yaml load error in scanner at L4.C19: mapping values are not allowed in this context

L4.C19 = 위 줄이 값 하나로 읽혀서 다음 줄에서 오류

YAML 오류는 세 가지가 가장 많아요. 첫 번째는 탭이에요. 화면에서는 탭 자리를 빨간 화살표로 보이게 그렸어요. 실제 편집기에서는 띄어쓰기와 똑같아 보여서 찾기 어려워요. 오류의 L3.C1은 3번째 줄 1번째 칸이라는 뜻이에요. 두 번째는 한 줄만 칸이 어긋난 경우예요. 4번째 줄을 2칸만 들여서 YAML이 5번째 줄에서 헷갈렸다고 알려 줘요. 세 번째는 쌍점 뒤에 띄어쓰기를 빠뜨린 경우예요. image:postgres:18 전체가 글자 하나로 읽혀서 다음 줄에서 오류가 나요. 두 번째와 세 번째처럼 오류 줄 번호는 실제로 틀린 줄의 다음 줄일 때가 많아요. 알려 준 줄과 그 바로 위 줄을 같이 봐요. 터미널 출력은 tools/demo.py로 실제 Docker와 postgres:18 이미지를 실행한 결과예요.
