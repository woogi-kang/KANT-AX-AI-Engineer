명령마다 무엇을 움직이는지 보면 덜 헷갈려요.

오늘 볼 명령을 한 지도에 놓았어요. 왼쪽 위 Docker Hub에서 docker pull로 이미지를 받아요. 이미지는 붕어빵 틀이에요. docker run으로 틀에서 붕어빵, 컨테이너 my-pg를 찍어요. 컨테이너를 켜고 끄고 지우는 명령, 기록을 보는 logs가 2파트예요. 청록색은 3파트예요. 컨테이너 안에 들어가거나, 내 폴더의 SQL 파일을 컨테이너로 넣는 명령이에요. 주황색 볼륨은 4파트예요. 컨테이너를 지워도 데이터가 남는 보관함이에요. 마지막 보라색은 5파트의 compose예요. 긴 docker run을 compose.yaml 파일에 적어 두고 up과 down으로 한 번에 켜고 꺼요.
