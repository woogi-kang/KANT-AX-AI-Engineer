docker 다음은 할 일, 그 뒤에 옵션과 이름이 와요

docker run -d --name my-pg -e POSTGRES_PASSWORD=admin1234 -p 5432:5432 postgres:18

할 일이 두 단어일 때도 있어요. volume create, compose up처럼요.

docker 명령은 모양이 정해져 있어요. docker 다음에 할 일이 오고, 그 뒤에 옵션, 마지막에 이름이 와요. 위 줄은 수업에서 친 docker run이에요. run이 할 일이고, -d, --name, -e, -p는 옵션, 마지막 postgres:18은 이미지 이름이에요. 아래 표처럼 다른 명령도 같은 순서예요. docker exec는 이름 뒤에 컨테이너 안에서 실행할 명령이 하나 더 붙어요. docker cp는 이름 자리에 보낼 파일과 받을 곳 두 개가 와요. volume create, compose up처럼 할 일이 두 단어인 명령도 있어요. 처음 보는 명령도 이 순서로 끊어 읽으면 뜻이 보여요.
