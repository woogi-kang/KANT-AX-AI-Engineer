2. 이미지와 컨테이너

run으로 켜고 ps로 켜진 컨테이너를 봐요

~/kant-shop $ docker run -d --name my-pg -e POSTGRES_PASSWORD=admin1234 -p 5432:5432 postgres:18

b64cc6816076fd241aa3b34121f80f477313a530b3931baf5b0b2e622c154793

 

~/kant-shop $ docker ps

CONTAINER ID   IMAGE         COMMAND                  CREATED         STATUS         PORTS                    NAMES

b64cc6816076   postgres:18   "docker-entrypoint.s…"   2 seconds ago   Up 2 seconds   0.0.0.0:5432->5432/tcp   my-pg

컨테이너 ID

앞 12자리예요

STATUS Up

켜져 있어요

NAMES

--name으로 붙인 이름

ps는 켜진 것만, ps -a는 꺼진 것까지 보여 줘요.

docker run으로 켜고 docker ps로 켜진 컨테이너를 봐요. 수업 명령 그대로 my-pg라는 이름으로 postgres:18을 켰어요. -d로 뒤에서 켜서 화면에는 긴 컨테이너 ID 한 줄만 나와요. docker ps를 치면 표가 나와요. 맨 앞은 컨테이너 ID 앞 12자리예요. STATUS가 Up이면 켜져 있다는 뜻이고, PORTS에 5432번이 이어져 있어요. 맨 끝 NAMES가 --name으로 붙인 이름이에요. 다른 명령에는 ID 대신 이 이름을 적으면 돼요. ps는 켜진 컨테이너만 보여 주고, 꺼진 것까지 보려면 ps -a를 쳐요. 터미널 출력은 tools/demo.py로 실제 Docker와 postgres:18 이미지를 실행한 결과예요.
