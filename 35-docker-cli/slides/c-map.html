5. YAML과 compose

docker run의 옵션이 compose.yaml의 칸으로 옮겨 가요

docker run -d

services: db:

한 줄 명령

compose.yaml (db 안쪽, 4칸 들여쓰기는 줄였어요)

--name my-pg

container_name: my-pg

-e POSTGRES_PASSWORD=admin1234

environment: POSTGRES_PASSWORD: admin1234

-p 5432:5432

ports: - "5432:5432"

-v pgdata:/var/lib/postgresql

volumes: - pgdata:/var/lib/postgresql

postgres:18

image: postgres:18

-d는 docker compose up -d에 붙여요. 옵션 하나가 칸 하나예요.

docker run의 옵션이 compose.yaml의 칸으로 옮겨 가요. 왼쪽은 수업에서 친 긴 docker run을 옵션별로 끊은 거예요. 오른쪽은 같은 내용을 compose.yaml의 db 안에 적은 거예요. --name은 container_name, -e는 environment, -p는 ports, -v는 volumes, 맨 끝 이미지 이름은 image로 가요. -d는 파일에 적지 않고 docker compose up -d처럼 명령에 붙여요. 옵션과 칸이 하나씩 짝이 맞아서, 긴 docker run을 compose.yaml로 바꾸거나 거꾸로 읽을 때 이 표를 보면 돼요.
