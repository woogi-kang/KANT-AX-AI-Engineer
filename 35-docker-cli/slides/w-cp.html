docker cp는 내 폴더와 컨테이너 사이에서 파일을 복사해요. 쓰는 모양은 리눅스의 cp와 같아요. 보낼 파일을 먼저 쓰고, 받을 곳을 뒤에 써요. 컨테이너 안의 경로는 컨테이너 이름, 쌍점, 경로로 적어요. my-pg:/tmp/kant_shop.sql은 my-pg 컨테이너 안의 /tmp 폴더에 kant_shop.sql이라는 이름으로 두라는 뜻이에요. 복사하기 전에 docker exec로 /tmp를 보면 비어 있고, 복사한 뒤에는 파일이 보여요. 앞뒤를 바꿔 쓰면 컨테이너 안의 파일을 내 폴더로 꺼내요. 아래쪽은 같은 파일을 copy.sql이라는 이름으로 꺼낸 화면이에요. Windows Git Bash에서는 30에서 배운 export MSYS_NO_PATHCONV=1을 먼저 쳐 두면 경로가 바뀌지 않아요. 터미널 출력은 tools/demo.py로 실제 Docker와 postgres:18 이미지를 실행한 결과예요.
