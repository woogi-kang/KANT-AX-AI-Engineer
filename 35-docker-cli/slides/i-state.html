껐다가 바로 켜기

~/kant-shop $ docker stop my-pg

my-pg

~/kant-shop $ docker ps -a

CONTAINER ID   IMAGE         COMMAND                  CREATED         STATUS                              PORTS     NAMES

b64cc6816076   postgres:18   "docker-entrypoint.s…"   3 seconds ago   Exited (0) Less than a second ago             my-pg

 

~/kant-shop $ docker start my-pg

my-pg

~/kant-shop $ docker ps -a

CONTAINER ID   IMAGE         COMMAND                  CREATED          STATUS                  PORTS                    NAMES

b64cc6816076   postgres:18   "docker-entrypoint.s…"   14 seconds ago   Up Less than a second   0.0.0.0:5432->5432/tcp   my-pg

꺼져도 ps -a에 남아 있어요. 다시 켜면 안의 데이터도 그대로예요.

stop, start, restart는 상태만 바꾸고, rm이 컨테이너를 지워요. 위 그림처럼 컨테이너는 켜짐과 꺼짐 사이를 오가요. docker stop으로 끄면 docker ps에서는 안 보이지만 ps -a에는 STATUS가 Exited로 남아 있어요. docker start로 다시 켜면 Up이 돼요. docker restart는 껐다가 바로 켜는 명령이에요. 설정을 바꾼 뒤에 다시 읽게 할 때 써요. 꺼졌다 켜져도 컨테이너 안에 만든 데이터는 그대로 있어요. 지우는 건 docker rm뿐이에요. rm으로 지운 컨테이너는 다시 켤 수 없고, 안의 데이터도 같이 사라져요. 터미널 출력은 tools/demo.py로 실제 Docker와 postgres:18 이미지를 실행한 결과예요.
