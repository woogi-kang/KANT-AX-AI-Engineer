< 로 넘길 때 -it를 쓰면 거절돼요

~/kant-shop $ docker exec -it my-pg psql -U postgres < kant_shop.sql

cannot attach stdin to a TTY-enabled container because stdin is not a terminal

 

~/kant-shop $ docker exec -i my-pg psql -U postgres < kant_shop.sql

DROP DATABASE

CREATE DATABASE

…

-i

입력을 이어요

키보드든 파일이든 받아요

-t

화면(터미널)을 이어요

키보드로 칠 때만 써요

직접 칠 때는 -it, 파일을 넘길 때는 -i예요.

꺾쇠로 파일을 넘길 때 -it를 쓰면 거절돼요. 앞에서 psql을 열 때는 늘 -it를 써서 습관처럼 붙이기 쉬워요. 오류 문장은 stdin is not a terminal, 입력이 터미널이 아니라는 뜻이에요. -it는 -i와 -t 두 옵션을 붙여 쓴 거예요. -i는 입력을 이어 주고, -t는 키보드로 치는 화면을 이어 줘요. 꺾쇠로 파일을 넘기면 입력이 키보드가 아니라 파일이라서 -t를 붙일 수 없어요. 그래서 -i만 써요. 직접 칠 때는 -it, 파일을 넘길 때는 -i, 이렇게 기억해요. 터미널 출력은 tools/demo.py로 실제 Docker와 postgres:18 이미지를 실행한 결과예요.
