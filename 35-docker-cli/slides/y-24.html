compose.yaml은 2칸으로 적어요. VS Code에서는 Tab 키를 눌러도 띄어쓰기로 들어가요.

2칸이든 4칸이든, 같은 단계끼리 칸이 맞으면 똑같이 읽혀요. 왼쪽 파일을 한 단계에 네 칸씩 들어가게 바꿨어요. 이 파일로 docker compose up -d를 쳐도 아무 문제 없이 켜져요. YAML이 보는 건 칸 수 자체가 아니라, 어떤 줄이 위 줄보다 더 들어갔는지, 같은 칸에서 시작하는지예요. 파이썬은 28에서 4칸으로 배웠고, YAML은 보통 2칸으로 적어요. Docker 공식 문서와 수업 자료도 2칸이에요. 한 파일 안에서는 한 가지로 맞춰요. Tab 키는 눌러도 괜찮아요. VS Code는 YAML 파일에서 Tab 키를 누르면 띄어쓰기 2칸을 넣어 줘요. 문제가 되는 건 파일 안에 들어간 진짜 탭 문자예요. 메모장처럼 탭 문자를 그대로 넣는 편집기나, 다른 곳에서 복사해 온 글에서 섞여 들어와요. 다음 장에서 실제 오류를 봐요. 터미널 출력은 tools/demo.py로 실제 Docker와 postgres:18 이미지를 실행한 결과예요.
