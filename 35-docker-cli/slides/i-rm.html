2. 이미지와 컨테이너

켜진 컨테이너는 못 지우고, 쓰는 이미지도 못 지워요

~/kant-shop $ docker rm my-pg

Error response from daemon: cannot remove container "my-pg": container is running: stop the container before

removing or force remove

 

~/kant-shop $ docker rmi postgres:18

Error response from daemon: conflict: unable to delete postgres:18 (must be forced) - container b64cc6816076 is

using its referenced image b9f6b8ff03b6

지울 때는 이 순서예요

1. 끄고

docker stop my-pg

2. 컨테이너를 지우고

docker rm my-pg

3. 이미지를 지워요

docker rmi postgres:18

켜진 컨테이너는 바로 못 지우고, 컨테이너가 쓰고 있는 이미지도 못 지워요. 첫 번째 오류는 container is running이에요. 켜진 채로 docker rm을 쳐서 먼저 끄라고 알려 줘요. 두 번째 오류는 이미지를 지우려 했는데 컨테이너가 그 이미지를 쓰고 있다는 뜻이에요. 꺼진 컨테이너도 남아 있으면 같은 오류가 나요. 29에서도 본 오류예요. 지울 때는 아래 순서로 해요. stop으로 끄고, rm으로 컨테이너를 지우고, 마지막에 rmi로 이미지를 지워요. 강제로 지우는 옵션도 있지만 수업에서는 이 순서로 해요. 터미널 출력은 tools/demo.py로 실제 Docker와 postgres:18 이미지를 실행한 결과예요.
