    소프트웨어와 API

  • 30Docker 2 (컨테이너 안에 들어가기, 볼륨, compose)

    켜 둔 컨테이너 안에 들어가고, 볼륨과 compose로 지워도 남는 컨테이너를 띄워요

    운영과 관측성

    nginx로 파일을 내주고, 리버스 프록시로 앱 여러 개를 80번 포트 하나로 묶어요

    소프트웨어와 API운영과 관측성
  • 32데이터베이스 기초 (표, 타입, 기본 키, SQL 맛보기)

    표, 행, 열, 타입, 기본 키를 익히고 SQL 네 문장을 MySQL과 PostgreSQL에서 나란히 읽어요

    보안과 개인정보
  • 34Docker 4 (PostgreSQL 컨테이너로 데이터베이스 쓰기)

    PostgreSQL을 컨테이너로 켜고 psql로 데이터베이스와 표를 만든 뒤, 볼륨으로 데이터를 지켜요

  • 35Docker 5 (명령어 한눈에 보기)

    흩어진 docker 명령과 compose 명령을 수업 예제로 다시 실행해 보고 치트시트 두 장으로 모아요

    운영과 관측성

SQL

36~44 · 9개
  • 36SQL 1 (골라 보기, 고치기, 자료형)

    열마다 자료형을 고르고, 표에서 필요한 줄만 골라 보고 고치고 지워요

    소프트웨어와 API
  • 37SQL 2 (제약 조건으로 표 설계하기)

    표에 NOT NULL, UNIQUE, CHECK, 기본 키, 외래 키를 붙여 잘못된 행이 들어오는 순간 PostgreSQL이 막게 해요

    보안과 개인정보
  • 38SQL 3 (조건 조합과 CASE)

    AND와 OR를 괄호로 묶고, CASE로 줄마다 값을 붙이고, 기준 여러 개와 빈칸 자리까지 정해 줄을 세워요

  • 39SQL 4 (집계 함수와 GROUP BY)

    여러 줄을 COUNT, SUM, AVG로 접고, GROUP BY로 묶어 묶음마다 세고, HAVING으로 묶음을 골라요

    평가와 테스트
  • 40SQL 5 (UNION과 JOIN으로 결과 합치기)

    결과 두 개를 UNION으로 위아래로 잇고, 두 표를 JOIN으로 옆에 붙여 신청 번호 옆에 회원 이름과 강좌 이름을 보여 줘요

  • 41SQL 6 (서브쿼리)

    괄호 안 SELECT가 먼저 값, 목록, 표가 되게 해서 평균과 비교하고 목록으로 고르고 임시 표로 다시 묶어요

  • 42SQL 7 (다른 표를 보고 넣고, 고치고, 지우기)

    SELECT로 고른 줄을 INSERT, UPDATE, DELETE에 붙이고 EXISTS로 다른 표에 있는지 물어서 넣고 고치고 지워요

  • 43SQL 8 (트랜잭션)

    문장 여러 개를 BEGIN으로 묶고 COMMIT으로 확정하거나 ROLLBACK으로 한꺼번에 되돌려서, 실수한 UPDATE와 DELETE를 살려요

    보안과 개인정보
  • 44파이썬에서 PostgreSQL 쓰기 (psycopg)

    파이썬 프로그램이 psycopg로 kant_shop에 접속해서 강좌 목록을 받아 찍고, %s로 값을 넘겨 수강 신청을 저장해요

    소프트웨어와 API도구 호출과 MCP보안과 개인정보
