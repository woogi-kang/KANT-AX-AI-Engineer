SQL 1 (골라 보기, 고치기, 자료형)

열마다 자료형을 고르고, 표에서 필요한 줄만 골라 보고 고치고 지워요

크게 보기PDF 받기

배우는 것

1글자(CHAR, VARCHAR, TEXT), 정수(SMALLINT, INTEGER, BIGINT), 소수(NUMERIC, REAL, DOUBLE PRECISION), BOOLEAN, 날짜와 시간 자료형의 차이를 말하고 열에 맞게 골라요.
2INSERT로 여러 줄을 한 번에 넣고, 안 적은 열이 NULL(모름)로 비는 것을 봐요.
3WHERE에 비교(=, <>, >=), AND, OR, IN, BETWEEN, LIKE, ILIKE, IS NULL을 써서 줄을 골라요.
4AS로 결과 열에 새 이름을 붙이고, price * 3처럼 계산한 값을 열로 꺼내요.
5DISTINCT로 겹치는 줄을 하나만 남기고, COUNT(*)로 맞는 줄이 몇 개인지 세요.
6ORDER BY로 줄을 세우고 LIMIT, OFFSET으로 잘라요.
7UPDATE ... SET ... WHERE로 값을 고치고 DELETE FROM ... WHERE로 줄을 지워요.
8RETURNING으로 바뀐 줄을 바로 보고, DROP ... IF EXISTS로 오류 없이 지워요.
9WHERE를 빼면 모든 줄이 바뀌거나 지워진다는 것을 알고, 고치기 전에 같은 WHERE로 SELECT부터 해요.
