4. 자주 나는 오류와 함정

WHERE에서는 AS로 붙인 이름을 못 써요

kant_shop=# SELECT name, CASE WHEN birth_year <= 1960 THEN '할인' ELSE '일반' END AS 요금

kant_shop-# FROM members WHERE 요금 = '할인';

ERROR:  column "요금" does not exist

LINE 2: FROM members WHERE 요금 = '할인';

                          ^

kant_shop=# SELECT name, birth_year FROM members WHERE birth_year <= 1960 ORDER BY birth_year;

원래 열로 조건을 적었어요

FROM

표 고르기

WHERE

요금이 아직 없어요

SELECT

여기서 요금이 생겨요

ORDER BY

요금을 쓸 수 있어요

WHERE에서는 AS로 붙인 이름을 못 써요. 요금이 할인인 회원만 고르려고 WHERE 요금 = '할인'을 적었더니 요금이라는 열이 없다는 오류가 났어요. 들어가기에서 본 처리 순서를 떠올려요. WHERE는 SELECT보다 먼저 처리돼요. 요금은 SELECT에서 CASE로 만들어지니까, WHERE가 돌 때는 아직 없어요. 반대로 ORDER BY는 SELECT 다음이라 앞 파트에서 이번달이라는 이름으로 세울 수 있었어요. 고칠 때는 CASE가 쓰던 원래 열 birth_year로 조건을 적어요. 이름을 그대로 쓰는 방법은 41의 서브쿼리에서 배워요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
