5. 실제 상황 예제

문자 보낼 명단: 할인이나 청소년 회원 중 전화번호가 있는 사람만

kant_shop=# SELECT name, birth_year, phone,

kant_shop-#       CASE WHEN birth_year <= 1960 THEN '할인' ELSE '청소년' END AS 안내

kant_shop-# FROM members

kant_shop-# WHERE (birth_year <= 1960 OR birth_year >= 2000)

kant_shop-#  AND phone IS NOT NULL

kant_shop-# ORDER BY birth_year DESC, name;

괄호로 OR를 먼저 묶어서 할인이나 청소년 중에서 골라요.

2

전화번호가 없는 황민서, 고은채는 빠졌어요.

3

어린 회원부터, 1960년생 둘은 이름순이에요.

세 번째 실제 상황이에요. 할인이나 청소년 요금을 받는 회원에게 문자로 안내하려고 해요. 문자를 보내려면 전화번호가 있어야 해요. WHERE에서 괄호로 OR를 먼저 묶어서 1960년 이전이거나 2000년 이후인 회원을 고르고, AND로 phone IS NOT NULL을 이었어요. 괄호가 없으면 AND가 먼저 묶여서 전화번호 없는 할인 회원까지 섞여요. 황민서와 고은채는 2000년 이후 출생이지만 전화번호가 없어서 빠졌어요. 어린 회원부터 세우고, 1960년생 강시우와 한수아는 이름순으로 섰어요. 1, 2, 3파트에서 배운 걸 한 문장에 다 썼어요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
