SELECT 한 문장 안에서 오늘 배울 곳은 세 군데예요

SELECT name, birth_year,

      CASE WHEN birth_year <= 1960 THEN '할인'

           ELSE '청소년' END AS 안내

FROM members

WHERE (birth_year <= 1960 OR birth_year >= 2000)

 AND phone IS NOT NULL

ORDER BY birth_year DESC, name;

1파트 · 조건 섞기 AND, OR, 괄호, NOT

2파트 · CASE 조건에 따라 값을 붙인 새 열

3파트 · 줄 세우기 기준 여러 개, NULL 자리

적는 순서와 처리 순서가 달라요. WHERE가 SELECT보다 먼저라서 생기는 오류를 4파트에서 봐요.

SELECT 한 문장 안에서 오늘 배울 곳은 세 군데예요. 1파트는 WHERE 자리예요. AND와 OR를 섞고, 괄호로 순서를 정하고, NOT으로 뒤집어요. 2파트는 SELECT 자리의 CASE예요. 줄마다 조건을 따져서 할인이나 청소년 같은 값을 붙인 새 열을 만들어요. 3파트는 ORDER BY 자리예요. 기준을 여러 개 적고, 비어 있는 NULL이 어디에 설지 정해요. 아래는 PostgreSQL이 이 문장을 처리하는 순서예요. 적을 때는 SELECT가 맨 앞이지만, 실제로는 FROM으로 표를 고르고 WHERE로 줄을 거른 뒤 SELECT에서 열을 만들고 마지막에 줄을 세워요. 이 순서는 4파트의 오류 하나를 이해할 때 다시 써요.
