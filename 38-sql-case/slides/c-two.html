2. CASE로 값 붙이기

CASE는 줄마다 조건을 따져서 값 하나를 새 열로 붙여요

kant_shop=# SELECT course_name, fee,

kant_shop-#       CASE WHEN fee >= 100000 THEN '고가' ELSE '일반' END AS 가격대

kant_shop-# FROM courses

kant_shop-# WHERE sport_id IN (2, 4);

  course_name    |  fee   | 가격대

------------------+--------+--------

헬스 PT 입문     | 120000 | 고가

헬스 근력 중급   | 100000 | 고가

테니스 입문      |  90000 | 일반

테니스 중급 레슨 | 110000 | 고가

테니스 고급 레슨 | 130000 | 고가

(5 rows)

새로 생긴 열

줄마다 이렇게 물어요

fee >= 100000 ?

예

'고가'

아니요

'일반'

다섯 줄 모두 이 질문을 거쳐서 가격대 칸이 채워져요.

17의 한 줄 if와 같은 모양이에요

파이썬

label = "고가" if fee >= 100000 else "일반"

SQL

CASE WHEN fee >= 100000 THEN '고가' ELSE '일반' END

CASE는 줄마다 조건을 따져서 값 하나를 새 열로 붙여요. 헬스와 테니스 강좌에 가격대를 붙였어요. 수강료가 10만 원 이상이면 고가, 아니면 일반이에요. CASE부터 END까지가 한 덩어리이고, AS로 가격대라는 열 이름을 붙였어요. 표에 없던 가격대 열이 결과에 생겼어요. 테니스 입문만 9만 원이라 일반이에요. 표 자체는 바뀌지 않고 보여 줄 때만 붙여요. 아래는 17에서 배운 한 줄 if와 나란히 놓은 거예요. 같은 색끼리 짝이에요. 파이썬은 참일 때 값을 앞에 적고, SQL은 WHEN 조건 뒤 THEN에 적어요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
