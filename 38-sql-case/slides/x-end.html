4. 자주 나는 오류와 함정

END를 빼면 AS 앞에서 syntax error가 나요

kant_shop=# SELECT name,

kant_shop-#       CASE WHEN birth_year <= 1960 THEN '할인' ELSE '일반' AS 요금

kant_shop-# FROM members;

ERROR:  syntax error at or near "AS"

LINE 2: ...CASE WHEN birth_year <= 1960 THEN '할인' ELSE '일반' AS 요금

                                                               ^

고친 줄

CASE WHEN birth_year <= 1960 THEN '할인' ELSE '일반' AS 요금
CASE WHEN birth_year <= 1960 THEN '할인' ELSE '일반' END AS 요금

화살표(^)는 PostgreSQL이 이상하다고 느낀 자리예요. 빠진 END는 그 바로 앞에 넣어요.

END를 빼면 AS 앞에서 syntax error가 나요. CASE를 열었으면 END로 닫아야 해요. END 없이 AS를 적으면 PostgreSQL은 CASE 안에 AS가 왜 있는지 몰라서 AS 근처가 이상하다고 알려 줘요. 오류 아래 화살표가 AS를 가리켜요. 화살표는 PostgreSQL이 이상하다고 느낀 자리예요. 실수는 그 바로 앞에 있을 때가 많아요. ELSE 값 뒤, AS 앞에 END를 넣으면 돼요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
