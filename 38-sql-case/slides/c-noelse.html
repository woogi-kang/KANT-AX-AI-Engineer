2. CASE로 값 붙이기

ELSE를 빼면 어느 WHEN에도 안 맞는 줄은 빈칸(NULL)이에요

kant_shop=# SELECT name, birth_year,

kant_shop-#       CASE WHEN birth_year <= 1960 THEN '할인'

kant_shop-#            WHEN birth_year >= 2000 THEN '청소년'

kant_shop-#       END AS 요금

kant_shop-# FROM members

kant_shop-# WHERE region = '마포구'

kant_shop-# ORDER BY birth_year, name;

ELSE 줄이 없어요

빈칸 = NULL

?

36에서 본 NULL(모름)이에요. 오류 없이 칸만 비어요.

빈칸이 생기면 안 되는 열이면 ELSE를 꼭 적어요.

      WHEN birth_year >= 2000 THEN '청소년'

      ELSE '일반'

 END AS 요금

이 한 줄이 있으면 여섯 명 모두 일반이 돼요.

ELSE를 빼면 어느 WHEN에도 안 맞는 줄은 빈칸이에요. 앞 장의 요금 CASE에서 ELSE 줄만 지웠어요. 할인과 청소년은 그대로 나오지만, 1975년생부터 1998년생까지 여섯 명은 요금 칸이 비었어요. 이 빈칸이 36에서 본 NULL이에요. PostgreSQL은 ELSE가 없으면 ELSE NULL로 읽어요. 오류가 나지 않아서 놓치기 쉬워요. 빈칸이 생기면 안 되는 열이면 ELSE를 꼭 적어요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
