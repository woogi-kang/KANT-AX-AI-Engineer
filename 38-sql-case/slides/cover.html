CASE로 등급 붙이기

PostgreSQL · AND와 OR와 괄호, NOT,
CASE WHEN, 여러 기준 정렬, NULL 자리

kant_shop=# SELECT name, birth_year,

kant_shop-#       CASE WHEN birth_year <= 1960 THEN '할인'

kant_shop-#            WHEN birth_year >= 2000 THEN '청소년'

kant_shop-#            ELSE '일반'

kant_shop-#       END AS 요금

kant_shop-# FROM members

kant_shop-# WHERE region = '마포구'

kant_shop-# ORDER BY birth_year, name;

38 챕터는 SQL 3이에요. 36에서 WHERE로 줄을 고르고 ORDER BY로 세웠어요. 오늘은 조건 여러 개를 섞을 때 괄호가 왜 필요한지 보고, CASE로 줄마다 할인이나 청소년 같은 등급을 붙이고, 기준 여러 개로 줄을 세워요. 오른쪽은 마포구 회원에게 요금 등급을 붙인 화면이에요. 예제는 수업에서 쓴 체육 센터 데이터베이스예요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
