2. CASE로 값 붙이기

THEN 뒤에는 글자뿐 아니라 계산한 값도 와요

kant_shop=# SELECT course_name, start_time, fee,

kant_shop-#       CASE WHEN start_time < '09:00' THEN fee - 10000 ELSE fee END AS 이번달

kant_shop-# FROM courses

kant_shop-# WHERE sport_id IN (1, 3)

kant_shop-# ORDER BY 이번달 DESC;

AS로 붙인 이름으로 세울 수 있어요

THEN과 ELSE 값이 모두 숫자라서 이번달 열도 숫자예요. 그래서 큰 값부터 세울 수 있어요.

THEN 뒤에는 글자뿐 아니라 계산한 값도 와요. 이번 달에 아침 9시 전 강좌는 1만 원을 깎아 주기로 했어요. 시작 시각이 9시 전이면 fee에서 10000을 뺀 값을, 아니면 fee를 그대로 써요. 36에서 본 price 곱하기 3 같은 계산 열과 같아요. 새벽반, 아침반, 아침 요가 세 줄이 1만 원씩 줄었어요. 마지막 줄 ORDER BY에는 AS로 붙인 이번달이라는 이름을 그대로 썼어요. ORDER BY는 SELECT 다음에 처리되니까 새 이름을 알아요. THEN과 ELSE 값이 모두 숫자라 이번달 열도 숫자로 세워졌어요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
