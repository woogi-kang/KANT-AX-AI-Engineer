할인

SELECT name, birth_year,

CASE WHEN birth_year <= 1960 THEN '할인'

WHEN birth_year >= 2000 THEN '청소년'

ELSE '일반'

END AS 요금

FROM members;

17에서 배운 if, elif, else와 CASE를 나란히 놓아요. 같은 색끼리 짝이에요. 파이썬의 if가 첫 WHEN, elif가 두 번째 WHEN, else가 ELSE예요. 위에서부터 처음 맞는 하나만 고르는 것도 같아요. 다른 점은 아래 표예요. 파이썬 코드는 birth_year 값 하나를 한 번 따져서 할인을 출력해요. CASE는 members 표의 줄마다 한 번씩 따져서 요금 열을 통째로 만들어요. 그래서 CASE에는 END와 AS가 붙어요. SQL 결과와 파이썬 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
