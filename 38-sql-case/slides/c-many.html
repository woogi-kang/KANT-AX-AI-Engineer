2. CASE로 값 붙이기

WHEN이 여러 개면 위에서부터 처음 맞는 하나만 골라요

kant_shop=# SELECT name, birth_year,

kant_shop-#       CASE WHEN birth_year <= 1960 THEN '할인'

kant_shop-#            WHEN birth_year >= 2000 THEN '청소년'

kant_shop-#            ELSE '일반'

kant_shop-#       END AS 요금

kant_shop-# FROM members

kant_shop-# WHERE region = '마포구'

kant_shop-# ORDER BY birth_year, name;

위에서부터 따지다가 처음 예가 나오면 그 THEN 값을 쓰고 나머지 WHEN은 안 봐요. 17의 elif와 같아요.

WHEN이 여러 개면 위에서부터 처음 맞는 하나만 골라요. 수업에서 본 요금 등급이에요. 1960년 이전에 태어났으면 할인, 2000년 이후면 청소년, 나머지는 일반이에요. 마포구 회원 11명에게 붙였어요. 오른쪽 표에서 세 사람을 따라가 봐요. 전소율은 1958년생이라 첫 WHEN에서 바로 예가 나와서 할인이에요. 두 번째 WHEN은 보지도 않아요. 고은채는 첫 WHEN이 아니요, 두 번째가 예라서 청소년이에요. 최지아는 둘 다 아니요라서 ELSE의 일반이에요. 17에서 배운 if, elif, else와 똑같이 움직여요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
