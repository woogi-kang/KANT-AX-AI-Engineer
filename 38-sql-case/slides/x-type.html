4. 자주 나는 오류와 함정

THEN과 ELSE 값은 같은 자료형이어야 해요

kant_shop=# SELECT course_name,

kant_shop-#       CASE WHEN fee >= 100000 THEN '고가' ELSE 0 END AS 가격대

kant_shop-# FROM courses;

ERROR:  invalid input syntax for type integer: "고가"

LINE 2:        CASE WHEN fee >= 100000 THEN '고가' ELSE 0 END AS 가...

                                           ^

kant_shop=# SELECT course_name,

kant_shop-#       CASE WHEN fee >= 100000 THEN '고가' ELSE '-' END AS 가격대

kant_shop-# FROM courses WHERE sport_id = 2;

헬스 PT 입문   | 고가

헬스 근력 중급 | 고가

둘 다 글자로

한 열에는 한 자료형만 담겨요. 숫자 0을 '0'처럼 작은따옴표로 감싸도 돼요.

THEN과 ELSE 값은 같은 자료형이어야 해요. 고가 아니면 0을 적었더니 오류가 났어요. 결과는 열 하나라서 한 가지 자료형만 담을 수 있어요. PostgreSQL은 숫자 0을 보고 이 열을 정수 열로 정한 뒤, 고가라는 글자를 정수로 바꾸려다 실패했어요. 그래서 integer에 고가를 넣을 수 없다는 오류예요. 36에서 본 invalid input syntax와 같은 오류예요. ELSE에도 글자를 적으면 돼요. 숫자를 보여 주고 싶으면 '0'처럼 작은따옴표로 감싸요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
