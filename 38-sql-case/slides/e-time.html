5. 실제 상황 예제

시간표 만들기: 시작 시각으로 새벽, 오전, 오후, 저녁을 붙여요

kant_shop=# SELECT course_name, start_time,

kant_shop-#       CASE WHEN start_time < '07:00' THEN '새벽'

kant_shop-#            WHEN start_time < '12:00' THEN '오전'

kant_shop-#            WHEN start_time < '18:00' THEN '오후'

kant_shop-#            ELSE '저녁'

kant_shop-#       END AS 시간대

kant_shop-# FROM courses

kant_shop-# ORDER BY start_time;

점 하나가 강좌 하나예요. 12시부터 18시 사이에는 강좌가 없어요. 오후 반을 새로 열면 좋겠다는 걸 바로 알 수 있어요.

두 번째 실제 상황이에요. 센터 게시판에 붙일 시간표를 만들어요. 시작 시각으로 7시 전은 새벽, 12시 전은 오전, 18시 전은 오후, 나머지는 저녁을 붙였어요. WHEN을 위에서부터 따지니까 두 번째 WHEN에 7시보다 크거나 같다는 조건을 따로 적지 않아도 돼요. 첫 WHEN에서 7시 전은 이미 걸러졌어요. 시작 시각 순서로 세웠어요. 오른쪽 그림은 이 결과를 시간 줄 위에 점으로 찍은 거예요. 12시부터 18시 사이에는 강좌가 하나도 없어요. 오후 반을 새로 열면 좋겠다는 걸 바로 알 수 있어요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
