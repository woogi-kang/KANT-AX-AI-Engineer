고치는 법

CASE WHEN birth_year <= 1960 THEN '할인'

    WHEN birth_year < 2000 THEN '일반'

    ELSE '청소년' END

좁은 조건부터 적어요.

넓은 조건을 먼저 쓰면 뒤의 WHEN까지 오지 않아요. 이번에는 2000년보다 앞이면 일반이라는 조건을 맨 위에 적었어요. 1958년생 전소율도 2000년보다 앞이라 첫 WHEN에서 예가 나와요. 그래서 바로 일반이 되고, 할인을 주는 두 번째 WHEN은 보지도 않아요. 오류는 안 나고 결과만 틀려요. 이런 실수가 더 위험해요. 고칠 때는 범위가 좁은 조건부터 적어요. 1960년 이하를 먼저 묻고, 그다음에 2000년 미만을 물으면 할인 회원이 제대로 나와요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
