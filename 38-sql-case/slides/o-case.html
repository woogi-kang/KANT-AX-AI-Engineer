3. 여러 기준으로 줄 세우기

난이도 순서는 CASE로 번호를 매겨서 세워요

ORDER BY level, fee;

ORDER BY CASE WHEN level = '초급' THEN 1

             WHEN level = '중급' THEN 2

             ELSE 3 END, fee, course_name;

가나다 순이라 고급이 맨 앞
초급 1, 중급 2, 고급 3 순서
난이도 순서는 CASE로 번호를 매겨서 세워요. 수영과 테니스 강좌 8개를 세웠어요. 왼쪽처럼 level로 세우면 가나다 순이라 고급이 맨 앞에 와요. 오른쪽은 ORDER BY에 CASE를 적었어요. 초급이면 1, 중급이면 2, 나머지는 3이라는 번호를 줄마다 매기고 그 번호로 세워요. 번호는 화면에 나오지 않고 순서를 정할 때만 써요. 같은 난이도 안에서는 수강료, 그다음 이름 순서예요. CASE는 SELECT뿐 아니라 ORDER BY에도 쓸 수 있어요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
