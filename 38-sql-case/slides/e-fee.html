5. 실제 상황 예제

회원 요금 안내: 영등포구 회원에게 요금 등급을 붙여요

kant_shop=# SELECT name, birth_year,

kant_shop-#       CASE WHEN birth_year <= 1960 THEN '할인'

kant_shop-#            WHEN birth_year >= 2000 THEN '청소년'

kant_shop-#            ELSE '일반'

kant_shop-#       END AS 요금

kant_shop-# FROM members

kant_shop-# WHERE region = '영등포구'

kant_shop-# ORDER BY birth_year, name;

등급별로 몇 명인지 SQL로 세는 GROUP BY는 39에서 배워요.

첫 번째 실제 상황이에요. 영등포구 회원에게 다음 달 요금 안내문을 보내려고 해요. 수업 코드 그대로 1960년 이전 출생은 할인, 2000년 이후 출생은 청소년, 나머지는 일반이에요. 나이 순서로 보려고 birth_year로 세우고, 같은 해에 태어나면 이름순으로 세웠어요. 할인 2명, 일반 7명, 청소년 3명이에요. 지금은 눈으로 셌지만, 등급별로 몇 명인지 SQL로 세는 방법은 39에서 GROUP BY로 배워요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
