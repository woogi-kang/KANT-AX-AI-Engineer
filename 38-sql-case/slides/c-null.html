2. CASE로 값 붙이기

WHEN에는 IS NULL, AND, IN 같은 조건을 그대로 써요

kant_shop=# SELECT name, email, phone,

kant_shop-#       CASE WHEN email IS NOT NULL THEN '이메일'

kant_shop-#            WHEN phone IS NOT NULL THEN '문자'

kant_shop-#            ELSE '연락처 없음'

kant_shop-#       END AS 연락

kant_shop-# FROM members

kant_shop-# WHERE region = '마포구';

WHEN 순서가 곧 연락 우선순위예요.

WHEN에는 IS NULL, AND, IN 같은 조건을 그대로 써요. 마포구 회원에게 연락할 방법을 정했어요. 이메일이 있으면 이메일, 이메일은 없지만 전화번호가 있으면 문자, 둘 다 없으면 연락처 없음이에요. 첫 WHEN은 email IS NOT NULL이에요. WHERE에서 쓰던 조건이 WHEN에도 그대로 들어가요. 최지아는 전화번호가 없어도 이메일이 있어서 이메일이에요. 임준서와 황민서는 둘 다 비어서 연락처 없음이에요. WHEN을 적은 순서가 곧 어떤 방법을 먼저 쓸지 정하는 순서예요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
