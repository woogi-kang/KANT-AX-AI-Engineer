5. 자주 나는 오류와 함정

별명을 붙였으면 표 이름 대신 별명을 써요. JOIN에는 ON이 꼭 있어야 해요

kant_shop=# SELECT members.name FROM members m WHERE m.member_id = 1;

ERROR:  invalid reference to FROM-clause entry for table "members"

LINE 1: SELECT members.name FROM members m WHERE m.member_id = 1;

              ^

HINT:  Perhaps you meant to reference the table alias "m".

kant_shop=# SELECT * FROM courses c JOIN instructors i;

ERROR:  syntax error at or near ";"

LINE 1: SELECT * FROM courses c JOIN instructors i;

                                                 ^

FROM members m이라고 적는 순간 그 문장에서 members는 m이 돼요. HINT가 m을 쓰라고 알려 줘요.

세미콜론 앞에서 문법 오류가 나요. ON 조건을 빼먹은 거예요.

JOIN instructors i ON c.instructor_id = i.instructor_id;

어떤 줄끼리 짝지을지 ON 뒤에 적어야 문장이 끝나요.

별명을 붙였으면 표 이름 대신 별명을 써요. JOIN에는 ON이 꼭 있어야 해요. 첫 번째는 FROM members m으로 별명을 붙여 놓고 SELECT에서 members 점 name이라고 적었어요. 별명을 붙인 순간 그 문장 안에서 members는 m으로 불러야 해서, invalid reference, 잘못 가리켰다는 오류가 나요. HINT 줄이 별명 m을 쓰려던 거냐고 알려 줘요. 두 번째는 JOIN 뒤에 ON을 빼먹었어요. PostgreSQL은 ON이 와야 문장이 끝난다고 읽어서 세미콜론에서 문법 오류를 내요. 아래처럼 ON 조건을 붙이면 돼요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
