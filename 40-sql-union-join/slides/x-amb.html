5. 자주 나는 오류와 함정

두 표에 다 있는 열 이름을 그냥 쓰면 어느 표 것인지 몰라요

kant_shop=# SELECT member_id, name

kant_shop-# FROM enrollments e

kant_shop-# JOIN members m ON e.member_id = m.member_id

kant_shop-# WHERE e.course_id = 6 AND e.enroll_month = '2026-11';

ERROR:  column reference "member_id" is ambiguous

LINE 1: SELECT member_id, name

              ^

고치기: 어느 표의 열인지 별명을 붙여요

SELECT e.member_id, m.name

ambiguous는 '애매하다'예요. member_id가 enrollments에도 members에도 있어서 PostgreSQL이 고르지 못해요.

name은 members에만 있어서 별명이 없어도 돼요. 그래도 다 붙여 두면 읽기 쉬워요.

두 표에 다 있는 열 이름을 그냥 쓰면 어느 표 것인지 몰라요. SELECT에 member_id만 적었더니 column reference member_id is ambiguous, 열 이름이 애매하다는 오류가 났어요. JOIN으로 붙인 두 표에 member_id가 둘 다 있어서 어느 쪽을 보여 줄지 PostgreSQL이 고를 수 없는 거예요. 앞에 e 점이나 m 점을 붙여서 표를 정해 주면 돼요. 이 경우는 짝이 맞는 줄이라 둘 다 값이 같지만 그래도 정해 줘야 해요. name처럼 한 표에만 있는 열은 별명 없이도 되지만, 다 붙여 두면 나중에 읽기 쉬워요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
