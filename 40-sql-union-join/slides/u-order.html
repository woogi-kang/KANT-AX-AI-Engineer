합친 결과

합친 결과 전체를 한 번에 세워요. 김민준이 강사 두 명 앞으로 왔어요.

ORDER BY는 마지막 SELECT 뒤에 한 번만 적어요. 첫 번째처럼 위 SELECT 안에 ORDER BY를 넣으면 UNION 근처에서 문법 오류가 나요. PostgreSQL은 ORDER BY가 나오면 문장이 끝나 간다고 읽는데, 그 뒤에 UNION이 와서 헷갈린 거예요. 두 번째처럼 맨 끝에 적으면 세 사람을 합친 다음 이름 순으로 세워요. 회원 김민준이 강사 정민재, 한지우 앞에 왔어요. 위아래 결과를 따로 세우는 게 아니라 합친 결과 전체를 세운다는 점을 기억해요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
