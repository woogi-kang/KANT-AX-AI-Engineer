5. 자주 나는 오류와 함정

LEFT JOIN 뒤 WHERE에서 오른쪽 표 열을 비교하면 NULL 줄이 사라져요

kant_shop=# SELECT c.course_name, i.name

kant_shop-# FROM courses c

kant_shop-# LEFT JOIN instructors i ON c.instructor_id = i.instructor_id

kant_shop-# WHERE i.name <> '박서연' AND c.sport_id = 1;

두 번째에는 있어요

아쿠아로빅이 빠졌어요

강사가 NULL인데 NULL <> '박서연'은 참이 아니에요. 36에서 = NULL이 0줄이던 것과 같은 이유예요.

NULL 줄도 남기려면

OR i.name IS NULL

조건에 IS NULL을 더해요. 38에서 배운 괄호로 AND와 OR를 묶어요.

LEFT JOIN 뒤 WHERE에서 오른쪽 표 열을 비교하면 NULL 줄이 사라져요. 수영 강좌 중 박서연 강사가 아닌 강좌를 보려고 WHERE에 i.name이 박서연이 아니다를 적었어요. 이도윤 강좌 두 개만 나오고, 강사가 없는 아쿠아로빅이 사라졌어요. 강사 이름이 NULL이면 박서연과 다른지 비교한 결과도 참이 아니라서 WHERE에서 걸러져요. 36에서 = NULL로 찾으면 0줄이던 것과 같은 이유예요. 아래처럼 WHERE를 빼면 아쿠아로빅이 NULL로 남아 있어요. NULL 줄도 남기려면 괄호로 묶어서 OR i.name IS NULL을 더해요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
