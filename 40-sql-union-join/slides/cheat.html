오늘 친 문장 모양

위아래로 쌓기

SELECT 열1, 열2 FROM 표A

UNION ALL -- UNION

SELECT 열1, 열2 FROM 표B

ORDER BY 열1; -- 맨 끝에 한 번

옆으로 붙이기

SELECT e.열, m.열

FROM 표A e

JOIN 표B m ON e.키 = m.키

JOIN 표C c ON e.키2 = c.키2;

짝 없는 줄 남기기와 찾기

FROM 표A a

LEFT JOIN 표B b ON a.키 = b.키

-- FULL JOIN: 양쪽 다

WHERE b.키 IS NULL; -- 짝 없음

막히면

열 이름이 애매하다

별명을 붙여요 e.member_id

별명을 붙였는데 표 이름을 썼다

별명 m으로 바꿔요

JOIN 뒤 ; 에서 문법 오류

ON 조건을 적어요

결과가 이상하게 NULL투성이

ON에 같은 뜻의 열끼리

UNION 열 개수, 자료형 오류

위아래 SELECT 모양을 맞춰요

LEFT JOIN인데 NULL 줄이 없다

WHERE의 오른쪽 열 조건을 봐요

오늘 친 문장 모양을 모았어요. 위아래로 쌓을 때는 모양이 같은 SELECT 사이에 UNION ALL이나 UNION을 적고, ORDER BY는 맨 끝에 한 번만 적어요. 옆으로 붙일 때는 FROM 표에 별명을 붙이고 JOIN 표 ON 조건을 적어요. 표가 세 개면 JOIN을 한 번 더 적어요. 짝이 없는 줄도 남기려면 LEFT JOIN이나 FULL JOIN을 쓰고, 짝이 없는 줄만 찾으려면 WHERE에 IS NULL을 걸어요. 오른쪽은 막혔을 때 볼 곳이에요.
