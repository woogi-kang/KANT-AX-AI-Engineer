1. 위아래로 쌓기 (UNION)

위아래로 붙이려면 열 개수와 자료형이 같아야 해요

kant_shop=# SELECT name, phone FROM instructors

kant_shop-# UNION ALL

kant_shop-# SELECT name FROM members;

ERROR:  each UNION query must have the same number of columns

LINE 3: SELECT name FROM members;

              ^

kant_shop=# SELECT name FROM instructors

kant_shop-# UNION ALL

kant_shop-# SELECT birth_year FROM members;

ERROR:  UNION types character varying and integer cannot be matched

LINE 3: SELECT birth_year FROM members;

              ^

kant_shop=# SELECT name AS 이름 FROM instructors WHERE sport_id = 4

kant_shop-# UNION ALL

kant_shop-# SELECT course_name FROM courses WHERE sport_id = 4;

아래 SELECT의 course_name은 이름 열 아래로 들어가요.

위아래로 붙이려면 열 개수와 자료형이 같아야 해요. 첫 번째는 위 SELECT가 열 두 개, 아래 SELECT가 열 한 개라서 each UNION query must have the same number of columns, 열 개수가 같아야 한다는 오류가 나요. 두 번째는 개수는 하나씩 같지만 위는 글자, 아래는 정수예요. 같은 자리에 놓일 값의 자료형이 달라서 맞출 수 없다는 오류예요. 열 이름은 같지 않아도 돼요. 세 번째처럼 결과의 열 이름은 첫 SELECT를 따라요. 강사 이름 아래로 강좌 이름이 이름이라는 열 하나에 들어갔어요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
