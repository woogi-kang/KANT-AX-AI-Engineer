4. 앞에서 배운 것과 비교

파이썬으로 하던 리스트 잇기, 집합 합치기, 딕셔너리 찾기와 같아요

앞에서 배운 것

파이썬 코드

결과

UNION ALL

13 리스트 +

[27, 17] + [11, 17]

[27, 17, 11, 17]

UNION

16 집합 |

{27, 17} | {11, 17}

{27, 17, 11}

JOIN

15 딕셔너리 찾기

names[3]

'박도현'

LEFT JOIN

15 get()

names.get(40)

None

names는 회원 번호를 키로, 이름을 값으로 담은 딕셔너리예요. 없는 키를 get()으로 꺼내면 None이 나오듯이, LEFT JOIN은 짝이 없으면 NULL을 채워요.

파이썬으로 하던 리스트 잇기, 집합 합치기, 딕셔너리 찾기와 같아요. UNION ALL은 13에서 배운 리스트 더하기처럼 그대로 이어 붙여서 17이 두 번 남아요. UNION은 16의 집합 합집합처럼 겹친 값을 하나만 남겨요. JOIN은 15의 딕셔너리에서 키로 값을 찾는 것과 같아요. 회원 번호를 키로 이름을 담은 names에서 3을 찾으면 박도현이 나오죠. JOIN은 신청 한 줄마다 이 찾기를 해 줘요. LEFT JOIN은 get과 비슷해요. 없는 키 40을 get으로 꺼내면 오류 대신 None이 나오듯, 짝이 없으면 NULL을 채워요. 파이썬과 달리 SQL은 표가 커도 한 문장이면 돼요.
