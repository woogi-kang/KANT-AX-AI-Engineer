3. 자주 나는 오류

80번을 다른 프로그램이 쓰고 있으면 8080:80으로 바꿔요

~/cafe $ docker compose up -d

cafe-web-1 (26dd5e71a1ab78cb9fa0629ac56fcf253601f54710e311c7c43e7a23cf794e66): Bind for 0.0.0.0:80 failed: port is already allocated

compose.yaml

web:

image: nginx

ports:

- "8080:80"

localhost:8080/menu/

주소에 :8080만 붙이면 나머지는 그대로예요.

Windows의 IIS나 Mac의 다른 웹 서버가 80번을 쓰고 있을 수 있어요.

29에서 본 포트 겹침 오류가 80번에서도 나요. 다른 컨테이너나 프로그램이 이미 80번을 쓰고 있으면 web만 켜지지 못하고 port is already allocated가 나와요. menu와 order는 켜졌는데 web만 Starting에서 멈췄어요. 먼저 docker ps로 80번을 쓰는 컨테이너가 있는지 보고 꺼요. 컨테이너가 아닌 프로그램이 쓰고 있으면 compose.yaml의 ports를 8080:80으로 바꾸고 다시 docker compose up -d를 쳐요. 주소에 :8080만 붙이면 /menu/, /order/는 그대로예요. 이 출력은 80번에 nginx 컨테이너 하나를 먼저 띄워서 만들었어요. 긴 오류 줄은 화면 폭에 맞춰 줄만 바꿨어요. 터미널 출력은 tools/demo.py로 실제 Docker와 nginx를 실행한 결과예요.
