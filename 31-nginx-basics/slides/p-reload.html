설정을 고치면 nginx -t로 검사하고 reload로 다시 읽혀요

conf/default.conf

location /menu/ {

proxy_pass http://menu/;

}

 

location /order/ {

proxy_pass http://order/;

}

/order/ 상자를 더하고 저장했어요

~/cafe $ curl localhost/order/

<html>

~/cafe $ docker exec cafe-web-1 nginx -s reload

저장만 하면 아직 몰라요

다시 읽은 뒤

1

설정 파일 고치고 저장

2

docker exec cafe-web-1 nginx -t

3

docker exec cafe-web-1 nginx -s reload

주문 앱도 붙여 봐요. 설정 파일에 /order/ 상자를 더하고 저장해요. 그런데 바로 curl을 치면 404가 나와요. nginx는 켜질 때 한 번 읽은 설정을 계속 쓰기 때문이에요. 먼저 nginx -t로 설정 파일에 틀린 곳이 없는지 검사해요. syntax is ok와 test is successful이 나오면 통과예요. 그다음 nginx -s reload로 설정을 다시 읽게 해요. 컨테이너를 끄지 않아서 다른 손님의 요청은 끊기지 않아요. 둘 다 1파트에서 본 docker exec로 컨테이너 안에서 실행해요. cafe-web-1은 compose가 지은 web 컨테이너 이름이에요. 이제 curl을 치면 order 앱이 답해요. 404 출력은 앞의 네 줄, 마지막 답은 첫 줄만 옮겼어요. 터미널 출력은 tools/demo.py로 실제 Docker와 nginx를 실행한 결과예요.
