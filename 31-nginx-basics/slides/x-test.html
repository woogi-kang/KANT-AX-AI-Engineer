10번 줄에 ;가 없어서 11번 줄의 }에서 걸렸어요. 알려 준 줄과 바로 윗줄을 같이 봐요.

서비스 이름 오타

proxy_pass http://menuu/;

~/cafe $ docker exec cafe-web-1 nginx -t

nginx: [emerg] host not found in upstream "menuu" in /etc/nginx/conf.d/default.conf:10

nginx: configuration file /etc/nginx/nginx.conf test failed

compose.yaml의 서비스 이름과 똑같이 적어요. test failed가 나오면 reload하지 말고 먼저 고쳐요.

설정 파일을 고친 뒤 reload 전에 nginx -t를 치는 이유예요. 첫 번째는 proxy_pass 줄 끝의 세미콜론을 빼먹었을 때예요. 오류는 11번 줄의 닫는 중괄호에서 났다고 나와요. 10번 줄이 끝나지 않은 채로 다음 줄까지 읽었기 때문이에요. 알려 준 줄과 바로 윗줄을 같이 봐요. 두 번째는 서비스 이름을 menuu로 잘못 적었을 때예요. host not found in upstream은 그런 이름의 서비스를 못 찾았다는 뜻이에요. compose.yaml의 서비스 이름과 똑같이 적어요. test failed가 나오면 reload하지 말고 먼저 고쳐요. 틀린 설정으로 nginx를 새로 켜면 nginx가 켜지지 않아요. 첫 줄의 시각이 찍힌 줄은 같은 내용이라 뺐어요. 터미널 출력은 tools/demo.py로 실제 Docker와 nginx를 실행한 결과예요.
