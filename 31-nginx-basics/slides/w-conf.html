1. nginx로 파일 내주기

nginx가 할 일은 설정 파일 default.conf에 적혀 있어요

~/cafe $ docker exec web cat /etc/nginx/conf.d/default.conf

server {

   listen       80;

   server_name  localhost;

 

   #access_log  /var/log/nginx/host.access.log  main;

 

   location / {

       root   /usr/share/nginx/html;

       index  index.html index.htm;

   }

docker exec 이름 명령

컨테이너 안에서 명령 하나만 실행하고 돌아와요.

nginx가 어느 포트에서 기다리고, 어느 폴더에서 파일을 찾을지는 설정 파일에 적혀 있어요. 컨테이너 안의 /etc/nginx/conf.d/default.conf예요. 30에서는 docker exec -it web bash로 안에 들어갔어요. 이번처럼 bash 대신 cat 같은 명령을 적으면 그 명령 하나만 안에서 실행하고 돌아와요. listen 80은 80번 포트에서 요청을 기다린다는 뜻이에요. -p 8080:80의 뒤쪽 80이 여기와 맞아요. location / 상자 안의 root가 파일을 찾는 폴더예요. 아래에는 #으로 시작하는 주석이 많아서 앞의 열 줄만 옮겼어요. 터미널 출력은 tools/demo.py로 실제 Docker와 nginx를 실행한 결과예요.
