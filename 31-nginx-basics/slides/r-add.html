4. 실제 상황 예제

예제 2 · 이벤트 앱을 붙여도 다른 주소는 그대로예요

compose.yaml

depends_on:

...

- event

...

event:

image: traefik/whoami

command: --name event

conf/default.conf

location /event/ {

proxy_pass http://event/;

}

~/cafe $ docker compose up -d

그대로 돌아요

새로 켜요

새 주소

다 쓰면 docker compose down으로 넷을 한 번에 지워요.

이번 주 이벤트를 보여 줄 앱 하나를 새로 붙여요. 할 일은 두 파일에 몇 줄씩이에요. compose.yaml에 event 서비스 세 줄과 depends_on 한 줄을 더하고, 설정 파일에 /event/ 상자를 더해요. docker compose up -d를 다시 치면 바뀐 event만 새로 켜고 나머지는 Running 그대로 둬요. nginx -t로 검사하고 reload로 다시 읽히면 localhost/event/가 열려요. 이 사이에 손님이 보던 /menu/, /order/는 끊기지 않았어요. 다 쓰면 docker compose down으로 넷을 한 번에 지워요. reload 출력과 답의 나머지 줄은 …로 줄였어요. 터미널 출력은 tools/demo.py로 실제 Docker와 nginx를 실행한 결과예요.
