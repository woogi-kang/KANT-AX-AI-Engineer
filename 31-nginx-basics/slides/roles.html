FastAPI 서버를 켜는 법은 아직 배우지 않았어요. 오늘은 받은 요청을 그대로 적어 돌려주는 연습용 앱 서버 traefik/whoami를 대신 써요.

서버라는 말이 두 가지로 쓰여요. nginx 같은 웹 서버는 요청받은 파일을 폴더에서 찾아 만든 그대로 보내요. 손대지 않으니 아주 빨라요. FastAPI로 만드는 앱 서버는 요청이 오면 파이썬 코드를 실행해서 그때그때 답을 만들어요. 로그인한 사람마다 다른 주문 목록을 보여 주는 일은 앱 서버가 해요. 보통은 두 가지를 같이 써요. nginx를 앞에 두고 파일은 nginx가 바로 주고, 앱의 일은 뒤의 앱 서버에 넘겨요. FastAPI 서버 켜기는 아직 배우지 않았으니, 오늘은 연습용 앱 서버인 whoami를 대신 써요.
