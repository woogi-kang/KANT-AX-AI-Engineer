포트 번호 없이 localhost/menu/로 menu 앱에 들어가요. ~/cafe 폴더에서 docker compose up -d를 쳐요. depends_on에 적은 대로 menu와 order가 먼저 켜지고 web이 켜져요. 이제 포트 번호 없이 curl localhost/menu/를 쳐요. 주소에 포트를 안 적으면 80번으로 가요. 80번에서 기다리던 nginx가 /menu/ 상자를 보고 menu 앱에 넘겼어요. 답에 Name: menu가 찍혀 있어요. 앱이 받은 요청은 GET /예요. proxy_pass 끝에 /를 붙여서 nginx가 앞의 /menu/를 떼고 넘겼어요. Host가 menu인 것도 nginx가 보낸 요청이라서예요. 브라우저 주소창에 localhost/menu/를 쳐도 같은 글자가 나와요. 터미널 출력은 tools/demo.py로 실제 Docker와 nginx를 실행한 결과예요.
