2. 리버스 프록시

연습용 앱 whoami는 받은 요청을 글자로 돌려줘요

~/cafe $ docker run -d --name menu -p 8001:80 traefik/whoami --name menu

2331288aea06…

~/cafe $ curl localhost:8001

Name: menu

Hostname: 2331288aea06

IP: 127.0.0.1

IP: 172.17.0.2

RemoteAddr: 172.17.0.1:33812

GET / HTTP/1.1

Host: localhost:8001

User-Agent: curl/8.5.0

Accept: */*

--name으로 붙인 이름

받은 요청과 경로

요청에 적힌 주소

traefik/whoami

리버스 프록시 프로그램 Traefik을 만든 Traefik Labs가 올린 연습용 이미지예요.

인증 마크는 없지만 4천만 번 넘게 받았어요.

앱이 무엇을 받았는지 그대로 보여 줘서, nginx가 무엇을 넘겼는지 확인하기 좋아요.

FastAPI 앱 대신 쓸 연습용 앱 서버 whoami예요. 이미지 이름 뒤의 --name menu는 이 앱이 스스로를 menu라고 소개하게 하는 옵션이에요. docker run의 --name과 이름은 같지만, 이쪽은 이미지 뒤에 붙어서 whoami 프로그램에 전해져요. curl로 열면 받은 요청을 글자로 그대로 돌려줘요. Name은 붙인 이름이고, GET / HTTP/1.1은 경로 /를 달라는 요청이에요. Host는 요청에 적힌 주소예요. 29의 Docker Hub 마크 기준으로 보면 인증 마크는 없어요. 리버스 프록시 프로그램 Traefik을 만든 Traefik Labs가 올렸고, 4천만 번 넘게 받은 이미지예요. 터미널 출력은 tools/demo.py로 실제 Docker와 nginx를 실행한 결과예요.
