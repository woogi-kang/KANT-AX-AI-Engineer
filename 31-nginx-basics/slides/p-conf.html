server {

listen 80;

 

location / {

root /usr/share/nginx/html;

index index.html;

}

 

location /menu/ {

proxy_pass http://menu/;

}

}

/menu/로 시작하는 주소면

menu라는 서비스로 넘겨요

http:// 뒤는 주소, 끝의 / 는 3파트에서 봐요

위의 location / 상자는 그대로 둬요. nginx는 주소와 가장 길게 맞는 location을 골라요.

1파트에서 만든 conf/default.conf에 location 상자를 하나 더 써요. location /menu/는 /menu/로 시작하는 주소에 이 상자의 규칙을 쓰겠다는 뜻이에요. 상자 안의 proxy_pass가 리버스 프록시 줄이에요. http:// 뒤에 적은 곳으로 요청을 넘겨요. menu는 다음 장의 compose.yaml에 적을 서비스 이름이에요. compose로 함께 띄운 컨테이너끼리는 서비스 이름으로 서로를 찾아요. localhost/menu/는 /로도 시작하고 /menu/로도 시작해요. nginx는 더 길게 맞는 /menu/ 상자를 골라요. 그래서 위의 location / 상자를 그대로 둬도 돼요. 끝의 슬래시 하나는 3파트 함정에서 봐요.
