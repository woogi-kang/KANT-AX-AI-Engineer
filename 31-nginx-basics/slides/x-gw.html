3. 자주 나는 오류

502, 504는 nginx가 뒤의 앱에 닿지 못했다는 뜻이에요

localhost를 적었어요

proxy_pass http://localhost:8001/;

~/cafe $ curl localhost/menu/

<head><title>502 Bad Gateway</title></head>

…

~/cafe $ docker compose logs web

web-1  | … connect() failed (111: Connection refused) while connecting to upstream

컨테이너 안의 localhost는 nginx 자신이에요

proxy_pass http://menu/;

menu 앱이 꺼져 있어요

docker compose stop menu

~/cafe $ curl localhost/menu/

<head><title>504 Gateway Time-out</title></head>

…

~/cafe $ docker compose logs web

web-1  | … upstream timed out (110: Connection timed out) while connecting to upstream

1분쯤 기다린 뒤에 나와요

docker compose start menu

5로 시작하는 Gateway 오류는 nginx는 살아 있는데 뒤의 앱에 닿지 못했다는 뜻이에요. 첫 번째는 proxy_pass에 localhost:8001을 적었을 때예요. 컨테이너 안에서 localhost는 nginx 컨테이너 자신이라, 그 안에는 8001번에서 기다리는 앱이 없어요. 기록에 connect() failed, Connection refused가 남아요. 서비스 이름 menu로 적어요. 두 번째는 menu 앱이 꺼져 있을 때예요. nginx가 1분쯤 기다리다 504 Gateway Time-out을 돌려주고, 기록에 upstream timed out이 남아요. docker compose start menu로 다시 켜요. docker compose logs web은 compose의 web 서비스 기록을 보여 줘요. 29의 docker logs와 같아요. HTML은 제목 줄, 기록은 마지막 오류 줄만 옮겼어요. 터미널 출력은 tools/demo.py로 실제 Docker와 nginx를 실행한 결과예요.
