{ }는 상자, 줄 끝의 ;는 한 줄이 끝났다는 표시예요.

기본 설정에서 주석과 꼭 필요하지 않은 줄을 빼면 이만큼 남아요. 오늘 쓸 내 설정 파일이에요. 중괄호는 상자예요. 28에서 들여쓰기를 상자 안의 상자로 읽었던 것처럼, server 상자 안에 location 상자가 들어 있어요. server 상자 하나가 웹사이트 하나예요. listen 80은 80번 포트에서 기다린다는 뜻이에요. location /는 /로 시작하는 주소, 곧 모든 주소에 이 상자의 규칙을 쓰겠다는 뜻이에요. root는 파일을 찾을 폴더, index는 파일 이름 없이 오면 줄 파일이에요. 줄 끝의 세미콜론을 빼먹으면 오류가 나요. 3파트에서 봐요.
