services:

web:

image: nginx

ports:

- "80:80"

volumes:

- ./site:/usr/share/nginx/html

- ./conf:/etc/nginx/conf.d

depends_on:

- menu

- order

menu:

image: traefik/whoami

command: --name menu

order:

image: traefik/whoami

command: --name order

밖으로 여는 문은 nginx 하나

1파트의 내 설정 폴더

menu, order를 먼저 켜고 web을 켜요

이미지 뒤에 붙이던 --name menu

ports가 없어요. 밖에서는 못 들어와요

서비스 이름 = proxy_pass의 menu

compose.yaml에 nginx와 앱 두 개, 서비스 세 개를 적어요. 30에서는 서비스를 하나만 적었어요. web은 nginx예요. ports로 80번을 열고, volumes로 site 폴더와 conf 폴더를 연결해요. depends_on은 menu와 order를 먼저 켠 뒤에 web을 켜라는 뜻이에요. nginx는 켜질 때 proxy_pass에 적은 menu를 찾는데, 그때 menu가 없으면 켜지지 않아요. menu와 order는 whoami 이미지예요. command에는 docker run에서 이미지 뒤에 붙이던 --name menu를 적어요. 둘에는 ports가 없어요. 밖에서 바로 들어오는 문을 열지 않고 nginx를 거쳐서만 들어오게 해요. 서비스 이름 menu가 proxy_pass에 적은 menu와 같아야 해요.
