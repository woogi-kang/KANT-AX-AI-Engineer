4. getter와 setter

꺼내는 문은 getter, 넣는 문은 setter예요

[1]

class Secret:

def __init__(self):

self.__password = 1234

 

def get_password(self):

return self.__password

 

def set_password(self, new):

if 1000 <= new <= 9999:

self.__password = new

else:

print("비밀번호는 네 자리 숫자예요")

 

mypass = Secret()

print(mypass.get_password())

1234

getter: 값을 꺼내 돌려줘요

setter: 검사하고 넣어요

밖에서는 문으로

칸을 감췄으니 밖에서 꺼내고 넣을 문이 필요해요. 꺼내 주는 메서드를 getter, 넣어 주는 메서드를 setter라고 불러요. 이름은 보통 get_칸이름, set_칸이름으로 지어요. get_password는 비밀번호를 돌려줘요. set_password는 새 번호가 네 자리 숫자인지 if로 검사하고, 맞을 때만 칸을 바꿔요. 밖의 코드는 mypass.get_password()로 1234를 꺼냈어요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.

이번 챕터를 한 장에 모았어요. 밑줄 하나는 안에서만 쓰자는 약속, 밑줄 두 개는 이름이 바뀌어 숨는 칸이에요. 바뀐 이름을 알면 밖에서도 꺼낼 수 있으니 자물쇠는 아니에요. 밖에서 꺼내고 넣을 일이 있으면 getter와 setter로 문을 만들고, setter에서 값을 검사해요. property를 쓰면 같은 문을 칸처럼 쓸 수 있고, setter를 안 만들면 읽기만 열려요. 24부터 27까지 클래스 네 챕터를 마쳤어요.
→ Space다음 (애니메이션을 하나씩)
←이전
숫자 뒤 Enter그 장으로 가기
R지금 장 애니메이션 다시 보기
A애니메이션 끄고 켜기
N발표자 노트
F전체 화면
?이 안내 열고 닫기

화면 양옆 화살표 버튼은 남은 애니메이션을 건너뛰고 바로 넘겨요.
노트 카드는 위쪽을 끌면 옮겨지고, 가장자리를 끌면 크기가 바뀌어요.
