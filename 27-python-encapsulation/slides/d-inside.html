3. 밑줄 두 개 __

클래스 안의 메서드는 self.__password를 그대로 써요

[2]

class Secret:

def __init__(self):

self.__password = 1234

 

def check(self, pw):

return self.__password == pw

 

mypass = Secret()

print(mypass.check(1234))

print(mypass.check(1111))

True

False

← 안에서는 이름 그대로 읽혀요

← 1234가 맞아요

← 1111은 틀려요

밖에는 맞는지 틀린지만 알려 주고, 비밀번호는 보여 주지 않아요.

같은 클래스 안의 메서드에서는 self.__password가 문제없이 읽혀요. check는 넣은 번호가 비밀번호와 같은지 True나 False로 돌려줘요. 밖의 코드는 비밀번호를 직접 보지 않고, check라는 문으로 맞는지만 물어봐요. 이게 캡슐화의 모양이에요. 칸은 안에 있고, 밖에는 꼭 필요한 문만 열려 있어요. 출력은 실제로 실행한 결과예요.
