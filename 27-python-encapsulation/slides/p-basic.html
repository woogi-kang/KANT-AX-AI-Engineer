4. getter와 setter

@property를 붙이면 괄호 없이 꺼내요

[3]

class Secret:

def __init__(self):

self.__password = 1234

 

@property

def password(self):

return self.__password

 

mypass = Secret()

print(mypass.password)

1234

← def 바로 위에 붙이는 표시

← getter와 같은 일, 이름은 칸 이름

← 괄호 없이 칸처럼 읽어요

꺼내는 코드가 이렇게 짧아져요

mypass.get_password()

mypass.password

getter를 더 짧게 쓰는 방법이에요. 메서드 이름을 칸 이름 password로 짓고, def 바로 위에 @property라는 표시를 붙여요. 그러면 밖에서 mypass.password처럼 괄호 없이 칸을 읽듯 꺼내요. 안에서는 getter와 같이 감춰 둔 __password를 돌려줘요. 아래 줄에서 get_와 괄호가 빠지는 걸 보세요. @ 표시가 어떻게 동작하는지는 이 과정에서 다루지 않고, 쓰는 모양만 기억해요. 출력은 실제로 실행한 결과예요.
