[1]

class Card:

def __init__(self, name):

self.name = name

self.stamps = 0

 

def add(self):

self.stamps = self.stamps + 1

 

kim = Card("kim")

kim.add()

kim.stamps = 100

print(kim.name, kim.stamps)

kim 100

[2]

kim.stamps = -5

print(kim.name, kim.stamps)

kim -5

← 도장은 add()로 한 개씩

← 직접 100을 넣었어요

← 음수도 들어가요
