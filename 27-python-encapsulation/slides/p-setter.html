4. getter와 setter

@password.setter를 붙이면 = 으로 넣어도 검사해요

[4]

class Secret:

def __init__(self):

self.__password = 1234

 

@property

def password(self):

return self.__password

 

@password.setter

def password(self, new):

if 1000 <= new <= 9999:

self.__password = new

else:

print("비밀번호는 네 자리 숫자예요")

 

mypass = Secret()

mypass.password = 12

print(mypass.password)

mypass.password = 5678

print(mypass.password)

비밀번호는 네 자리 숫자예요

1234

5678

← set_password와 같은 검사

← = 으로 넣어도 setter가 불려요

← 통과

같은 일, 두 가지 모양

꺼내기

get_password()

password

넣기

set_password(5678)

password = 5678

둘 다 같은 일을 해요 밖에서 칸처럼 쓰고 싶으면 property를 골라요

넣는 문도 property로 만들 수 있어요. 같은 이름 password로 메서드를 하나 더 적고, 위에 @password.setter를 붙여요. 안의 검사는 set_password와 똑같아요. 이제 밖에서 mypass.password = 12처럼 칸에 넣듯 적어도 setter가 불려서 검사해요. 12는 막히고 5678은 들어가요. 오른쪽처럼 getter, setter 메서드와 property는 같은 일을 하는 두 가지 모양이에요. 밖에서 칸처럼 쓰고 싶으면 property를 골라요. 출력은 실제로 실행한 결과예요.
