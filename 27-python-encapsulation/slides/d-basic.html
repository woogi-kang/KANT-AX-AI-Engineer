3. 밑줄 두 개 __

밑줄 두 개로 시작하는 칸은 밖에서 이름으로 못 찾아요

[1]

class Secret:

def __init__(self):

self.__password = 1234

 

mypass = Secret()

print(mypass.__password)

AttributeError: 'Secret' object has no attribute '__password'

← 칸 이름 앞에 _ 두 개

mypass

Secret

??

1234

칸은 분명히 있어요 그런데 이름이 __password가 아니에요

안에 1234가 있는데 왜 못 찾을까요? 두 장 뒤에서 봐요.

이번에는 금고 Secret을 만들어요. 비밀번호 칸 이름 앞에 밑줄을 두 개 붙였어요. 밖에서 mypass.__password로 꺼내려 하니 AttributeError가 나요. Secret 객체에 __password라는 이름이 없다는 뜻이에요. 분명히 __init__에서 1234를 넣었는데 말이에요. 칸은 있지만 이름이 바뀌어 있어서 그래요. 무슨 이름으로 바뀌었는지는 두 장 뒤에서 봐요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
