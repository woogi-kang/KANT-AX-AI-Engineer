키오스크 비밀번호 ①: 옛 번호를 알아야 바꿔요

[3]

class Kiosk:

def __init__(self, password):

self.__password = password

 

def login(self, pw):

if pw == self.__password:

print("관리자 화면을 열어요")

else:

print("비밀번호가 틀렸어요")

 

def change(self, old, new):

if old == self.__password:

self.__password = new

print("비밀번호를 바꿨어요")

else:

print("지금 비밀번호가 틀려서 못 바꿔요")

← 재료로 받은 번호를 감춰요

← 맞는지만 확인해요

← 옛 번호가 맞을 때만 바꿔요

이 셀도 출력이 없어요

카페 키오스크의 관리자 비밀번호를 금고처럼 만들어요. 만들 때 받은 번호를 밑줄 두 개로 감춰요. getter는 일부러 만들지 않았어요. 비밀번호는 밖에서 꺼내 볼 일이 없으니까요. login은 맞는지만 확인하고, change는 지금 번호를 맞혀야 새 번호로 바꿔요. setter에 검사를 넣은 것과 같은 생각이에요. 이 셀도 틀만 만들어서 출력이 없어요.
