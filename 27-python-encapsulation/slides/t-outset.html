5. 오류와 함정

밖에서 mypass.__password = 0 이라고 적으면 새 칸이 생겨요

[1]

class Secret:

def __init__(self):

self.__password = 1234

 

def check(self, pw):

return self.__password == pw

 

mypass = Secret()

mypass.__password = 0

print(mypass.check(1234))

print(mypass.__dict__)

True

{'_Secret__password': 1234, '__password': 0}

← 비밀번호를 0으로 바꾼 줄 알았어요

← 1234가 아직 맞아요

'_Secret__password': 1234

'__password': 0

진짜 비밀번호 칸

밖에서 새로 붙은 칸

이름 바꾸기는 클래스 안에서만 일어나요. 밖에서 적은 __password는 그냥 새 칸이에요.

밖에서 mypass.__password = 0이라고 적었어요. 오류가 안 나니까 비밀번호가 바뀐 것 같지만, check(1234)는 여전히 True예요. __dict__를 보면 칸이 두 개예요. 이름 바꾸기는 클래스 안에 적은 이름에만 일어나요. 밖에서 적은 __password는 바뀌지 않고, 24에서 점으로 칸을 붙인 것처럼 새 칸이 하나 생겨요. 26의 a.shop = 함정과 비슷해요. 비밀번호를 바꾸려면 setter를 써요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
