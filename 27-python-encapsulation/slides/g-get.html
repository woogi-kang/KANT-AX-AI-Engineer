4. getter와 setter

꺼내는 문은 getter, 넣는 문은 setter예요

[1]

class Secret:

def __init__(self):

self.__password = 1234

 

def get_password(self):

return self.__password

 

def set_password(self, new):

if 1000 <= new <= 9999:

self.__password = new

else:

print("비밀번호는 네 자리 숫자예요")

 

mypass = Secret()

print(mypass.get_password())

1234

getter: 값을 꺼내 돌려줘요

setter: 검사하고 넣어요

밖에서는 문으로

칸을 감췄으니 밖에서 꺼내고 넣을 문이 필요해요. 꺼내 주는 메서드를 getter, 넣어 주는 메서드를 setter라고 불러요. 이름은 보통 get_칸이름, set_칸이름으로 지어요. get_password는 비밀번호를 돌려줘요. set_password는 새 번호가 네 자리 숫자인지 if로 검사하고, 맞을 때만 칸을 바꿔요. 밖의 코드는 mypass.get_password()로 1234를 꺼냈어요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
