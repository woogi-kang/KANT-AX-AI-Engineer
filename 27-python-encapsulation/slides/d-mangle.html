3. 밑줄 두 개 __

파이썬이 __password를 _Secret__password로 바꿔 둬요

[3]

print(mypass.__dict__)

{'_Secret__password': 1234}

← 객체 속 칸을 딕셔너리로 보여 줘요

클래스 안에 적은 이름

self.__password

self._Secret__password

앞에 _클래스이름을 붙여서 저장해요

mypass.__password

그런 이름은 없어요

AttributeError

mypass._Secret__password

바뀐 이름 그대로 적으면

1234

객체에 붙은 칸은 __dict__로 딕셔너리처럼 들여다볼 수 있어요. 키가 _Secret__password예요. 클래스 안에서 밑줄 두 개로 시작하는 이름을 적으면, 파이썬이 앞에 밑줄과 클래스 이름을 붙여서 저장해요. 이걸 이름 바꾸기, 영어로 name mangling이라고 해요. 그래서 밖에서 __password로 찾으면 없다고 하고, 안의 메서드에서는 파이썬이 같은 규칙으로 바꿔 읽어서 잘 찾아요. __dict__는 들여다볼 때만 쓰고 실습 코드에는 쓰지 않아요. 출력은 실제로 실행한 결과예요.
