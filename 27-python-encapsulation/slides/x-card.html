도장 카드 ①: 열 개에서 멈추고, 읽기만 열어 두기

[1]

class Card:

goal = 10

 

def __init__(self, name):

self.name = name

self.__stamps = 0

 

def add(self):

if self.__stamps < Card.goal:

self.__stamps = self.__stamps + 1

 

@property

def stamps(self):

return self.__stamps

 

def __str__(self):

return f"{self.name}: 도장 {self.__stamps}/{Card.goal}"

← 도장 칸은 밑줄 두 개로 감춰요

← 문 안에서 열 개를 넘지 않게 검사

← 읽기만: setter는 일부러 안 만들어요

출력 없이 틀만 만드는 셀이에요

도장 카드를 캡슐화해서 완성해요. 도장 칸은 밑줄 두 개로 감췄어요. add는 25에서 배운 것처럼 if로 막아서, 목표 열 개를 넘으면 더 찍지 않아요. 도장 수는 property로 읽기만 열어 두고 setter는 만들지 않았어요. __str__은 25처럼 카드를 글자로 보여 줘요. 이 셀은 틀만 만들어서 출력이 없어요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요.
