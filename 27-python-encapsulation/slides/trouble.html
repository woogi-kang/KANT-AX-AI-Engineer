정리

막히면 오류의 마지막 줄을 봐요

1

AttributeError: 'Secret' object has no attribute '__password'

밑줄 두 개짜리 칸을 밖에서 이름으로 찾았어요

getter, property

2

AttributeError: ... no attribute '_VipCard__stamps'

자식 틀에서 부모의 __칸을 썼어요

밑줄 하나 _stamps

3

TypeError: 'int' object is not callable

property에 괄호를 붙였어요

kim.stamps

4

AttributeError: property 'stamps' of 'Card' object has no setter

읽기만 연 property에 넣었어요

@stamps.setter, 메서드

5

밖에서 __password = 0 했는데 안 바뀌어요

밖에서는 이름이 안 바뀌어서 새 칸이 생겼어요

setter로 바꾸기

6

_stamps를 밖에서 바꿨더니 값이 이상해요

약속을 어기고 검사를 건너뛰었어요

add() 같은 메서드로

헷갈리면 __dict__로 실제 저장된 이름을 들여다봐요.

이번 챕터에서 자주 만나는 일을 모았어요. 1번은 감춘 칸을 밖에서 찾을 때예요. getter나 property를 만들어 꺼내요. 2번은 자식 틀에서 부모의 밑줄 두 개짜리 칸을 쓸 때예요. 같이 쓰는 칸은 밑줄 하나로 둬요. 3번과 4번은 property에서 나요. 5번과 6번은 오류가 없어서 더 찾기 어려워요. 헷갈리면 __dict__로 실제로 어떤 이름이 저장됐는지 들여다봐요.
