5. 오류와 함정

property에 괄호를 붙이면 'int' object is not callable

[3]

class Card:

def __init__(self, name):

self.name = name

self.__stamps = 0

 

@property

def stamps(self):

return self.__stamps

 

kim = Card("kim")

print(kim.stamps())

TypeError: 'int' object is not callable

← 메서드처럼 괄호를 붙였어요

← kim.stamps가 벌써 0이라서 0()이 돼요

✕

print(kim.stamps())

✓

print(kim.stamps)

property로 만든 stamps에 메서드처럼 괄호를 붙였어요. kim.stamps는 이미 메서드가 불려서 숫자 0이 돼요. 그 뒤에 괄호가 붙으니 0()처럼 숫자를 함수처럼 부른 셈이라 TypeError가 나요. callable은 괄호로 부를 수 있다는 뜻이에요. property는 괄호 없이 kim.stamps로 써요. 출력은 실제로 실행한 결과예요.
