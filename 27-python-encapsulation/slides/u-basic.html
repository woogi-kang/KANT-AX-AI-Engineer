2. 밑줄 하나 _

밑줄 하나로 시작하는 칸은 안에서만 써요

[1]

class Card:

def __init__(self, name):

self.name = name

self._stamps = 0

 

def add(self):

self._stamps = self._stamps + 1

 

def count(self):

return self._stamps

 

kim = Card("kim")

kim.add()

kim.add()

print(kim.count())

밖의 코드는 _stamps를 직접 적지 않았어요

칸 이름 앞에 밑줄을 하나 붙였어요. 파이썬에서 밑줄 하나로 시작하는 이름은 클래스 안에서만 쓰겠다는 표시예요. 카드 안의 메서드는 self._stamps를 평소처럼 읽고 바꿔요. 밖에서 쓸 수 있게 add와 count 두 메서드를 문으로 열어 뒀어요. 밖의 코드는 kim.add()와 kim.count()만 써서 도장 수 2를 꺼냈어요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
