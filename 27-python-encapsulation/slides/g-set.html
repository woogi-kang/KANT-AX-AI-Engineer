4. getter와 setter

setter가 검사해서 틀린 값은 안 넣어요

[2]

mypass.set_password(12)

print(mypass.get_password())

mypass.set_password(5678)

print(mypass.get_password())

비밀번호는 네 자리 숫자예요

1234

5678

mypass

Secret

_Secret__password

5678

← 12는 네 자리가 아니에요

← 그대로 1234

← 검사를 통과해요

← 5678로 바뀌었어요

검사 없이 칸을 그대로 열어 두면 (참고)

mypass = Secret()

mypass.password = 12

print(mypass.password)

12

← 12가 그대로 들어가요

실행 막대를 따라 한 줄씩 봐요. set_password(12)는 네 자리가 아니라서 안내 문구만 찍고 칸을 그대로 둬요. 그래서 get_password()는 아직 1234예요. set_password(5678)은 검사를 통과해서 칸이 5678로 바뀌어요. 아래는 비밀번호를 그냥 self.password로 열어 둔 금고예요. 이때는 12도 검사 없이 들어가요. setter를 두는 이유가 이 검사예요. 비밀번호 규칙이 바뀌어도 setter 한 곳만 고치면 돼요. 출력은 실제로 실행한 결과예요.
