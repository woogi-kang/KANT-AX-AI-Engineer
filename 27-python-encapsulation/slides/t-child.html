5. 오류와 함정

자식 틀에서 부모의 __stamps를 쓰면 이름이 달라서 못 찾아요

[2]

class Card:

def __init__(self, name):

self.name = name

self.__stamps = 0

 

def add(self):

self.__stamps = self.__stamps + 1

 

class VipCard(Card):

def add(self):

self.__stamps = self.__stamps + 2

 

lee = VipCard("lee")

lee.add()

AttributeError: 'VipCard' object has no attribute '_VipCard__stamps'

← Card 안: _Card__stamps로 저장

← VipCard 안: _VipCard__stamps를 찾아요

부모와 자식이 같이 쓰는 칸은 밑줄 하나로

✕

self.__stamps

✓

self._stamps

고친 뒤 lee.add() 하면 lee._stamps는 2 (실행 결과)

26의 VIP 카드처럼 Card를 물려받아 add를 덮어썼어요. 부모 Card 안에 적은 __stamps는 _Card__stamps로 저장돼요. 자식 VipCard 안에 적은 __stamps는 _VipCard__stamps로 바뀌어서, 그런 칸이 없다는 AttributeError가 나요. 밑줄 두 개는 원래 자식 틀이 같은 이름을 써도 서로 부딪히지 않게 하려고 만든 거라서 그래요. 부모와 자식이 같이 쓰는 칸은 밑줄 하나로 적어요. 고치고 다시 실행하면 lee._stamps가 2예요. 출력은 실제로 실행한 결과예요.
