2. 목록과 IN

여러 줄이 나오는 서브쿼리는 = 뒤에 못 둬요

kant_shop=# SELECT member_id FROM enrollments WHERE course_id = 13 AND enroll_month = '2026-11';

member_id

-----------

       11

       25

(2 rows)

kant_shop=# SELECT name FROM members

kant_shop-# WHERE member_id = (SELECT member_id FROM enrollments WHERE course_id = 13 AND enroll_month = '2026-11');

ERROR:  more than one row returned by a subquery used as an expression

안쪽만 쳐 보면 두 줄이에요

member_id = 11, 25

= 는 값 하나와만 비교해요. 11이랑 같은지, 25랑 같은지 정할 수 없어요.

member_id IN (11, 25)

IN은 목록 중 하나와 같은지 물어요. 36에서 배웠어요.

목록이 나오는 서브쿼리는 = 대신 IN 괄호 안에 넣어요.

결과가 여러 줄인 서브쿼리는 등호 뒤에 못 둬요. 11월에 필라테스 기구 초급, 13번 강좌를 신청한 회원 번호를 안쪽만 따로 쳐 보면 11과 25, 두 줄이 나와요. 이걸 member_id = 뒤에 넣으면 ERROR가 나요. 오류 문장은 식으로 쓰인 서브쿼리가 한 줄보다 많이 돌려줬다는 뜻이에요. 등호는 값 하나와만 비교하니까 11과 같은지 25와 같은지 정할 수 없어요. 이럴 때는 36에서 배운 IN을 써요. IN은 괄호 안 목록 중 하나와 같은지 물어요. 다음 장에서 IN 괄호 안에 서브쿼리를 넣어요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
