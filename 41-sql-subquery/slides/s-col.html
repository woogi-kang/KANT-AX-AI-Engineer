4. SELECT 칸에 넣기

SELECT 칸에 넣으면 모든 줄 옆에 같은 값이 붙어요

kant_shop=# SELECT

kant_shop-#    course_name,

kant_shop-#    fee,

kant_shop-#    (SELECT ROUND(AVG(fee), 2) FROM courses) AS 전체평균,

kant_shop-#    fee - (SELECT ROUND(AVG(fee), 2) FROM courses) AS 평균과차이

kant_shop-# FROM courses;

전체평균

안쪽 쿼리가 한 번 계산한 97857.14가 14줄 모두에 붙어요.

평균과차이

fee에서 평균을 빼요. 양수면 평균보다 비싼 강좌, 음수면 싼 강좌예요.

값 하나만 돼요

SELECT 칸 하나에는 값 하나만 들어가요. 그래서 1줄 1칸이 나오는 서브쿼리만 넣어요.

서브쿼리는 SELECT의 열 자리에도 넣을 수 있어요. 오늘 수업에서 친 스칼라 서브쿼리예요. 스칼라는 값 하나라는 뜻이에요. 전체평균 열에는 안쪽 쿼리가 구한 평균 97857.14가 14줄 모두에 똑같이 붙었어요. 평균과차이 열은 각 강좌의 fee에서 그 평균을 뺀 값이에요. 양수면 평균보다 비싸고, 음수면 평균보다 싸요. 집계 함수만 쓰면 결과가 한 줄로 줄어드는데, 서브쿼리로 넣으면 모든 줄을 그대로 두고 옆에 평균을 붙일 수 있어요. 열 하나에는 값 하나만 들어가니까 1줄 1칸이 나오는 서브쿼리만 넣어요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
