실제 상황 1 · 11월 강좌마다 남은 자리를 계산해요

kant_shop=# SELECT c.course_name, c.capacity AS 정원, n.cnt AS 신청, c.capacity - n.cnt AS 남은자리

kant_shop-# FROM courses c

kant_shop-# JOIN (

kant_shop(#    SELECT course_id, COUNT(*) AS cnt

kant_shop(#    FROM enrollments

kant_shop(#    WHERE enroll_month = '2026-11' AND status <> '취소'

kant_shop(#    GROUP BY course_id

kant_shop(# ) AS n ON c.course_id = n.course_id

kant_shop-# ORDER BY 남은자리, c.course_name

kant_shop-# LIMIT 5;

임시 표 n: 강좌별 11월 신청 수

강좌 표와 이어요

자리가 가장 적게 남은 강좌

신청 수를 먼저 세고(FROM 서브쿼리), 정원이 있는 강좌 표와 이어서 뺄셈했어요.

첫 번째 실제 상황이에요. 데스크 직원이 11월 강좌마다 자리가 몇 개 남았는지 묻는다고 해 봐요. 정원은 courses 표에, 신청은 enrollments 표에 있어요. 먼저 괄호 안에서 11월 신청 중 취소를 뺀 신청 수를 강좌별로 셌어요. 이 결과에 n이라는 이름을 붙이고, 강좌 표 c와 JOIN했어요. 그러면 한 줄에 정원과 신청 수가 같이 있어서 c.capacity - n.cnt로 남은 자리를 계산할 수 있어요. 남은 자리가 적은 순으로 다섯 개만 봤어요. 테니스 고급 레슨은 정원 6명에 3명이 신청해서 3자리 남았어요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
