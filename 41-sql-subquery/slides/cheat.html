한 장 요약

값 하나

WHERE fee > (SELECT AVG(fee) FROM courses)

평균보다 비싼 강좌

WHERE fee = (SELECT MAX(fee) FROM courses)

가장 비싼 강좌

(SELECT COUNT(*) FROM members) AS 전체

SELECT 칸, 모든 줄에 같은 값

목록

WHERE member_id IN (SELECT member_id FROM …)

목록에 있는 회원

WHERE member_id NOT IN (SELECT …)

목록에 없는 회원

같은 결과: JOIN … ON …

두 표의 열을 같이 볼 때

표

FROM (SELECT … GROUP BY …) AS paid

임시 표에 이름 붙이기

WHERE paid.total_paid >= 600000

합계로 거르기

SELECT AVG(total_paid) FROM (…) AS paid

집계를 두 번

막히면

more than one row …

= 대신 IN

must return only one column

열 하나만

not allowed in WHERE

HAVING이나 FROM 서브쿼리

missing FROM-clause entry

AS 이름 붙이기

오늘 쓴 것을 결과 모양 세 가지로 모았어요. 값 하나가 나오는 서브쿼리는 WHERE의 비교 기호 뒤나 SELECT 칸에 둬요. 목록이 나오는 서브쿼리는 IN, NOT IN 괄호 안에 둬요. 두 표의 열을 같이 봐야 하면 JOIN으로 바꿔요. 표가 나오는 서브쿼리는 FROM 자리에 두고 AS로 이름을 붙여요. 합계로 거르거나 합계의 평균처럼 집계를 두 번 할 때 써요. 아래는 자주 만나는 오류와 고치는 법이에요. 막히면 안쪽 SELECT만 따로 쳐서 모양부터 봐요.
