6. 오류와 실제 상황

서브쿼리에서 자주 만나는 오류 여섯 가지

ERROR: 뒤에 이런 글이 보이면

이렇게 해요

more than one row returned by a subquery used as an expression

= 뒤 서브쿼리가 여러 줄을 돌려줬어요

IN (…)으로 바꿔요

subquery must return only one column

SELECT 칸 서브쿼리가 열 두 개를 꺼냈어요

열마다 서브쿼리 하나

aggregate functions are not allowed in WHERE

WHERE에 SUM, COUNT를 썼어요

HAVING이나 FROM 서브쿼리

aggregate function calls cannot be nested

AVG(SUM(…))처럼 겹쳐 썼어요

안쪽 집계를 FROM 서브쿼리로

missing FROM-clause entry for table "paid"

FROM 서브쿼리에 AS 이름을 안 붙였어요

) AS paid

syntax error at or near "SELECT"

서브쿼리를 괄호로 안 감쌌어요

( )로 감싸요

서브쿼리에서 자주 만나는 오류 여섯 가지예요. 첫째, 등호 뒤 서브쿼리가 여러 줄을 돌려주면 more than one row 오류가 나요. IN으로 바꿔요. 둘째, SELECT 칸 서브쿼리가 열을 두 개 꺼내면 only one column 오류가 나요. 셋째, WHERE에 SUM이나 COUNT를 쓰면 not allowed in WHERE가 나요. HAVING이나 FROM 서브쿼리를 써요. 넷째, AVG 안에 SUM을 겹쳐 쓰면 cannot be nested가 나요. 다섯째, FROM 서브쿼리에 AS 이름을 안 붙이고 paid 점 열 이름으로 부르면 paid라는 표를 못 찾는다고 나와요. 여섯째, 괄호 없이 SELECT를 바로 쓰면 SELECT 근처에서 문법 오류가 나요. 다섯째와 여섯째는 다음 장에서 실제 화면으로 봐요.
