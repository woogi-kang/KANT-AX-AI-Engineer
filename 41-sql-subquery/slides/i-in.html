2. 목록과 IN

IN 괄호 안에 서브쿼리를 넣으면 목록이 들어가요

kant_shop=# SELECT name, phone FROM members WHERE member_id IN (11, 25);

손현우 | 010-3925-6325

kant_shop=# SELECT name, phone

kant_shop-# FROM members

kant_shop-# WHERE member_id IN (

kant_shop(# );

같은 두 사람

손으로 적은 목록을

WHERE member_id IN (11, 25)

WHERE member_id IN (

SELECT member_id

FROM enrollments

WHERE course_id = 13

AND enroll_month = '2026-11'

)

PostgreSQL이 목록을 그때그때 구해서 넣어 줘요. 신청자가 바뀌어도 쿼리는 그대로예요.

IN 괄호 안에 서브쿼리를 넣으면 목록이 들어가요. 왼쪽 첫 쿼리는 회원 번호 11과 25를 손으로 적었어요. 오른쪽 위 카드처럼 이 목록 자리에 앞 장의 안쪽 쿼리를 그대로 넣으면 아래 카드가 돼요. 안쪽 쿼리가 먼저 실행돼서 11, 25 목록이 되고, 바깥 쿼리는 그 목록에 든 회원의 이름과 전화번호를 꺼내요. 결과는 같은 두 사람이에요. 두 결과의 순서가 다른 것은 ORDER BY를 안 붙였기 때문이에요. 순서가 중요하면 ORDER BY를 붙여요. 신청자가 늘거나 줄어도 쿼리는 고칠 필요가 없어요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
