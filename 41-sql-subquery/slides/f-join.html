임시 표 paid를 회원 표와 JOIN해서 이름을 붙여요

kant_shop=# SELECT

kant_shop-#    paid.member_id  AS 회원번호,

kant_shop-#    m.name          AS 회원명,

kant_shop-#    paid.total_paid AS 매출액

kant_shop-# FROM (

kant_shop(#    SELECT member_id, SUM(pay_amount) AS total_paid

kant_shop(#    FROM enrollments

kant_shop(#    GROUP BY member_id

kant_shop(# ) AS paid

kant_shop-# LEFT JOIN members m ON paid.member_id = m.member_id

kant_shop-# WHERE paid.total_paid >= 600000

kant_shop-# ORDER BY paid.total_paid DESC, paid.member_id;

이름이 붙은 6명

오늘 수업에서 친 FROM 서브쿼리예요. 기준만 60만 원으로 바꿨어요. 괄호 안에서 회원별 합계를 만들고 paid라고 이름을 붙였어요. paid에는 회원 번호와 합계만 있고 이름이 없어요. 그래서 40에서 배운 LEFT JOIN으로 회원 표 members를 붙였어요. ON paid.member_id = m.member_id로 같은 회원끼리 이어요. 오른쪽 그림처럼 paid의 한 줄에 회원 표의 이름이 붙어요. SELECT에서는 AS로 회원번호, 회원명, 매출액이라는 한글 열 이름을 붙였어요. 임시 표도 이름이 있으니 진짜 표처럼 JOIN, WHERE, ORDER BY를 다 붙일 수 있어요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
