23에서 배운 컴프리헨션으로 같은 일을 해 봐요. 파이썬에서는 수강료 목록의 평균을 먼저 구해서 변수 avg에 담고, 다음 줄에서 avg보다 큰 값만 골랐어요. 결과는 SQL과 같은 여섯 개 수강료예요. 파이썬은 평균을 변수에 담아 두고 다음 줄에서 써요. SQL에는 변수가 없으니, 평균을 구하는 SELECT를 쓸 자리에 괄호로 바로 넣어요. 두 줄이 한 문장이 된 거예요. 색칠한 부분끼리 같은 일을 해요. 파이썬 출력은 fees.py를 실제로 실행한 결과예요.
