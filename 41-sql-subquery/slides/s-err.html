4. SELECT 칸에 넣기

SELECT 칸 서브쿼리가 열 두 개를 돌려주면 막혀요

kant_shop=# SELECT course_name, (SELECT AVG(fee), MAX(fee) FROM courses) FROM courses;

ERROR:  subquery must return only one column

LINE 1: SELECT course_name, (SELECT AVG(fee), MAX(fee) FROM courses)...

                           ^

열마다 서브쿼리를 하나씩 둬요

SELECT course_name,

(SELECT AVG(fee) FROM courses) AS 평균,

(SELECT MAX(fee) FROM courses) AS 최고

FROM courses;

SELECT 칸에 넣은 서브쿼리가 열 두 개를 돌려주면 ERROR가 나요. 평균과 최고 수강료를 한 괄호 안에서 같이 꺼냈어요. 오류 문장은 서브쿼리가 열을 하나만 돌려줘야 한다는 뜻이에요. SELECT 칸 하나에는 값 하나만 들어가요. 두 값이 필요하면 아래처럼 칸마다 서브쿼리를 하나씩 두고 각각 AS로 이름을 붙여요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
