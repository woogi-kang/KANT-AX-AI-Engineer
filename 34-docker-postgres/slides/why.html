MySQL 명령을 그대로 치면 PostgreSQL에서는 안 돼요

~ $ docker run -d --name pg -e POSTGRES_PASSWORD=cafe1234 -p 5432:5432 postgres:18

b0771208641d…

 

~ $ docker exec -it pg mysql -u root -p

OCI runtime exec failed: exec failed: unable to start container process: exec: "mysql": executable file not found in $PATH

같은 일, 다른 이름

33 MySQL

34 PostgreSQL

이미지

mysql:8.4

postgres:18

들어가는 프로그램

mysql -u root -p

psql -U postgres

포트

3306

5432

켜고, 표를 만들고, 볼륨으로 남기는 순서는 33과 같아요. 이름과 명령만 바꿔 익혀요.

MySQL 명령을 그대로 치면 PostgreSQL에서는 안 돼요. 33에서 배운 대로 컨테이너를 켜고 들어가려고 mysql -u root -p를 쳤어요. 그런데 이 컨테이너는 postgres:18 이미지로 켰어요. 안에 mysql이라는 프로그램이 없어서 executable file not found, 실행 파일을 찾을 수 없다는 오류가 나요. 수업이나 자료에서 MySQL로 보여 주다가 PostgreSQL로 넘어가면 이런 데서 막혀요. 아래 표처럼 이미지, 들어가는 프로그램, 포트가 달라요. 켜고, 표를 만들고, 볼륨으로 남기는 순서는 33과 똑같아요. 오늘은 그 순서대로 PostgreSQL에서 쓰는 이름과 명령을 익혀요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
