2. 데이터베이스와 표 만들기

CREATE TABLE로 표를 만들고 \dt, \d로 확인해요

~ $ docker exec -it pg psql -U postgres -d shop

shop=# CREATE TABLE orders (id INT PRIMARY KEY, menu VARCHAR(20), qty INT);

CREATE TABLE

shop=# \dt

          List of tables

(1 row)

 

shop=# \d orders

INT

VARCHAR(20)

id가 기본 키예요

INT는 integer, VARCHAR는 character varying으로, 긴 이름으로 보여 줘요.

CREATE TABLE로 표를 만들고 백슬래시 dt, 백슬래시 d로 확인해요. 이번에는 -d shop을 붙여 처음부터 shop으로 들어갔어요. CREATE TABLE 문장은 32와 33에서 쓴 것과 글자까지 같아요. id는 정수이면서 기본 키, menu는 20자까지의 글자, qty는 정수예요. CREATE TABLE이라고 답하면 표가 생긴 거예요. 백슬래시 dt는 지금 데이터베이스의 표 목록이에요. orders가 보여요. Schema 칸의 public은 표를 담는 기본 칸인데, 지금은 넘어가요. 백슬래시 d orders는 표의 열과 타입을 보여 줘요. INT는 integer, VARCHAR(20)은 character varying(20)으로, 같은 타입을 긴 이름으로 보여 줘요. 맨 아래 PRIMARY KEY 줄은 id가 기본 키라는 뜻이에요. 기본 키라서 id 칸은 비워 둘 수 없다고 not null이 붙었어요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
