psql을 나와 내 터미널로 돌아와요. 컨테이너는 계속 돌아요.

docker exec -it로 컨테이너 안의 psql을 열어요. 30에서 docker exec -it로 bash를 열었던 것과 같아요. 이번에는 bash 대신 PostgreSQL에 접속하는 프로그램 psql을 열어요. -U postgres는 postgres 계정으로 들어간다는 뜻이에요. 33의 mysql -u root처럼 계정 이름을 적는 자리인데, 대문자 U인 것만 달라요. 비밀번호는 묻지 않고 바로 들어가요. 이유는 3파트에서 봐요. 맨 위 두 줄은 psql 버전과 도움말 안내예요. 그 아래 postgres=# 표시가 나오면 들어온 거예요. 앞의 postgres는 지금 들어와 있는 데이터베이스 이름이에요. 이 뒤에 SQL을 쳐요. 백슬래시 q를 치면 psql을 나와 내 터미널로 돌아와요. 컨테이너는 계속 돌아요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
