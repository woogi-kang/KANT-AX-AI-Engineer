다 만들었다는 답이에요

데이터베이스 목록

postgres는 처음부터 있던 것, template0과 template1은 PostgreSQL이 새 데이터베이스를 만들 때 쓰는 틀이에요.

CREATE DATABASE로 만들고 백슬래시 l로 목록을 봐요. 서버 안에는 데이터베이스를 여러 개 둘 수 있어요. 카페 주문을 담을 shop을 새로 만들어요. CREATE DATABASE shop 뒤에 세미콜론을 붙이고 Enter를 치면 CREATE DATABASE라고 짧게 답해요. 잘 만들었다는 뜻이에요. 백슬래시 l을 치면 데이터베이스 목록이 표로 나와요. Name 칸에 shop이 새로 생겼어요. postgres는 처음부터 있던 데이터베이스예요. template0과 template1은 새 데이터베이스를 만들 때 PostgreSQL이 베껴 쓰는 틀이라 건드리지 않아요. 오른쪽 칸들은 글자 규칙과 권한이라 지금은 넘어가요. 이 표는 넓어서, 터미널 창이 좁으면 목록 보기 화면이 열려요. 그럴 땐 q를 누르면 닫혀요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
