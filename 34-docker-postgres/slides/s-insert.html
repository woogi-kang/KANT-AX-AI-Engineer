2. 데이터베이스와 표 만들기

INSERT로 행을 넣고 SELECT로 꺼내 봐요

~ $ docker exec -it pg psql -U postgres -d shop

shop=# INSERT INTO orders VALUES (1, 'latte', 2);

INSERT 0 1

shop=# INSERT INTO orders VALUES (2, 'americano', 1);

INSERT 0 1

shop=# SELECT * FROM orders;

id |   menu    | qty

----+-----------+-----

 1 | latte     |   2

 2 | americano |   1

(2 rows)

 

shop=# SELECT menu, qty FROM orders;

  menu    | qty

-----------+-----

latte     |   2

americano |   1

(2 rows)

값은 표를 만들 때 적은 열 순서대로 넣어요. 글자는 '작은따옴표'로 감싸요.

*는 모든 열이에요. 열 이름을 적으면 그 열만 나와요.

INSERT로 행을 넣고 SELECT로 꺼내 봐요. INSERT INTO orders VALUES 뒤 괄호에 값을 적어요. 값은 표를 만들 때 적은 열 순서대로예요. id, menu, qty 순서라서 1, 'latte', 2는 1번 주문, 라테 2잔이에요. 글자는 작은따옴표로 감싸고 숫자는 그대로 써요. PostgreSQL은 INSERT 0 1이라고 답해요. 뒤의 1이 넣은 행의 수예요. 앞의 0은 지금은 신경 쓰지 않아도 돼요. 두 번 넣었으니 오른쪽 표처럼 행이 두 개예요. SELECT 별표 FROM orders는 모든 열을 꺼내요. 결과 표 아래 2 rows는 행이 두 개라는 뜻이에요. 별표 대신 menu, qty처럼 열 이름을 적으면 그 열만 나와요. 33 MySQL에서 친 문장과 똑같고, 결과 표 모양만 테두리 없이 조금 달라요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
