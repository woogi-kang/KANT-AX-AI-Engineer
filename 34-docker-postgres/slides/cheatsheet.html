한 장 요약

켜고 들어가기

docker run -d --name pg -e POSTGRES_PASSWORD=… -p 5432:5432

관리자 비밀번호를 주고 켜기

docker logs pg

ready 두 번 보기

docker exec -it pg psql -U postgres

관리자로 들어가기

-d shop / -c "…"

데이터베이스 고르기 / 한 문장만

psql 안에서

\l \c shop

목록 보기 / 옮기기

\dt \d orders

표 목록 / 표 모양

\du

계정 목록

\q

나가기

데이터 지키기

-v pg-data:/var/lib/postgresql

18부터 이 자리

docker compose up -d / down

볼륨은 남아요

docker compose down -v

볼륨까지 지우기

./init:/docker-entrypoint-initdb.d

처음 켤 때 SQL 실행

SQL은 MySQL과 같아요. 목록 명령과 계정, 데이터 자리만 챙기면 돼요.

나중에는 파이썬 코드에서 이 데이터베이스에 붙어 주문을 넣고 꺼내 봐요.

오늘 쓴 것을 세 묶음으로 모았어요. 왼쪽은 켜고 들어가기예요. docker run에 POSTGRES_PASSWORD를 꼭 주고, logs에서 ready를 본 뒤 docker exec -it pg psql -U postgres로 들어가요. 가운데는 psql 안에서 쓰는 백슬래시 명령이에요. 오른쪽은 데이터를 지키는 방법이에요. 18부터는 볼륨을 /var/lib/postgresql에 붙여요. compose down으로는 볼륨이 남고, down -v를 쳐야 볼륨까지 지워져요. init 폴더의 SQL 파일은 처음 켤 때 한 번 실행돼요. SQL 문장은 33 MySQL과 같으니, 목록 명령과 계정, 데이터 자리만 챙기면 돼요. 나중에는 파이썬 코드에서 이 데이터베이스에 붙어 볼 거예요.
