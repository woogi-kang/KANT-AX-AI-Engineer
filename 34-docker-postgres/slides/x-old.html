예전 글처럼 /var/lib/postgresql/data에 붙이면 18은 켜지지 않아요. 인터넷의 PostgreSQL 컨테이너 글은 대부분 17 이전 기준이라 볼륨을 /var/lib/postgresql/data에 붙여요. 같은 명령을 postgres:18에 치면 docker run은 ID를 찍고 끝나지만, docker ps -a에서 Exited (1)로 바로 꺼진 게 보여요. docker logs pg의 첫 줄이 Error: in 18+예요. 18부터는 데이터를 버전 번호 폴더에 넣도록 바뀌었다는 설명이에요. 아래쪽에 /var/lib/postgresql/data에 볼륨이 붙어 있는데 쓰지 않는다고 나와요. 마지막 문단이 고치는 법이에요. 18부터는 /var/lib/postgresql 한 곳에 붙이라고 알려 줘요. 꺼진 pg는 docker rm pg로 지우고, 4파트처럼 -v pg-data:/var/lib/postgresql로 다시 켜요. 예전 글을 따라 할 때는 이미지 버전을 먼저 봐요. logs는 길어서 필요한 줄만 옮겼어요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
