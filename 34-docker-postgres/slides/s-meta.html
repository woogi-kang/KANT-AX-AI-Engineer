2. 데이터베이스와 표 만들기

psql에는 SQL과 백슬래시 명령, 두 가지를 쳐요

SQL

데이터베이스에 시키는 말이에요. 33 MySQL에서도 같아요. 끝에 ;를 붙여야 실행돼요.

CREATE DATABASE shop;

CREATE TABLE orders (…);

INSERT INTO orders VALUES (…);

SELECT * FROM orders;

DROP TABLE orders;

백슬래시 명령

psql이 알아듣는 짧은 명령이에요. \로 시작하고 ;를 안 붙여요.

\l

데이터베이스 목록

\c shop

shop으로 이동

\dt

표 목록

\d orders

표 구조

\du

계정 목록

\q

나가기

psql에는 SQL과 백슬래시 명령, 두 가지를 쳐요. 왼쪽 SQL은 데이터베이스에 시키는 말이에요. 32에서 읽어 본 CREATE TABLE, INSERT, SELECT가 여기에 들어가고, 33 MySQL에서 친 문장과 글자까지 같아요. SQL은 끝에 세미콜론을 붙여야 실행돼요. 오른쪽은 psql이 알아듣는 짧은 명령이에요. 백슬래시로 시작하고 세미콜론을 붙이지 않아요. 데이터베이스 목록은 백슬래시 l, 이동은 백슬래시 c, 표 목록은 백슬래시 dt예요. MySQL에서는 SHOW DATABASES 같은 SQL로 하던 일인데, PostgreSQL은 이런 일을 psql 명령으로 해요. 이 파트에서 하나씩 쳐 봐요. 맨 끝에 MySQL 명령과 나란히 놓은 표도 있어요.
