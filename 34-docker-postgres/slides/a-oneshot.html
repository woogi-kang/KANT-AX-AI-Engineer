docker exec pg psql -U postgres -c "SELECT version();"

-it가 없어서 psql 화면에 들어가지 않아요. 결과만 찍고 내 터미널로 돌아와요.

-c를 붙이면 SQL 한 문장만 실행하고 바로 나와요. 31에서 docker exec 이름 명령으로 nginx -t 하나만 실행했던 것과 같아요. 이번에는 -it를 빼고, psql 뒤에 -c와 큰따옴표로 감싼 문장을 적었어요. SELECT version()은 PostgreSQL 버전을 알려 주는 문장이에요. psql 화면에 들어가지 않고 결과 표만 찍고 내 터미널로 돌아와요. 백슬래시 명령도 -c로 실행할 수 있어요. 아래는 백슬래시 l을 실행한 결과예요. 33 MySQL에서는 같은 일을 mysql -e로 했어요. 한두 문장만 확인할 때나, 나중에 명령을 스크립트에 적어 둘 때 써요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
