~ $ docker run -d --name pg2 -e POSTGRES_USER=cafe -e POSTGRES_PASSWORD=cafe1234 -p 5433:5432 postgres:18

~ $ docker exec -it pg2 psql -U cafe

cafe가 관리자

관리자라서 돼요

33 MySQL의 MYSQL_USER

일반 계정을 하나 더 만들어요. root는 그대로 있어요.

34 PostgreSQL의 POSTGRES_USER

관리자 이름을 바꿔요. postgres 계정은 안 생겨요.

POSTGRES_USER를 주면 그 이름이 관리자가 되고 postgres는 없어요. 33 MySQL과 반대라서 헷갈리기 쉬운 곳이에요. 컨테이너 pg2를 -e POSTGRES_USER=cafe로 켰어요. pg가 5432번을 쓰고 있어서 내 컴퓨터 쪽 포트만 5433으로 바꿨어요. 그 뒤 33에서 하던 대로 -U postgres로 들어가면 role postgres does not exist, postgres라는 계정이 없다는 오류가 나요. POSTGRES_USER가 관리자 이름 자체를 바꿨기 때문이에요. -U cafe로 들어가면 표시가 cafe=#이에요. 데이터베이스 이름도 POSTGRES_DB를 안 줘서 관리자 이름과 같은 cafe예요. 백슬래시 du를 보면 cafe가 Superuser이고, CREATE DATABASE도 그대로 돼요. MySQL의 MYSQL_USER는 root 옆에 일반 계정을 하나 더 만들어서 CREATE DATABASE가 막혔어요. PostgreSQL에서 권한이 작은 계정이 필요하면 앞 장처럼 CREATE USER로 만들어요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
