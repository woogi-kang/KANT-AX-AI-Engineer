init 폴더에 SQL 파일을 두면 처음 켤 때 메뉴가 들어가요. 매번 메뉴 표를 손으로 만들기는 번거로워요. ~/cafe-pg 안에 init 폴더를 만들고 menu.sql에 CREATE TABLE과 INSERT 세 줄을 적어 뒀어요. compose.yaml의 volumes에 ./init:/docker-entrypoint-initdb.d 한 줄을 더해요. 30에서 배운 내 폴더 연결이에요. 앞 장 끝에서 down -v로 볼륨을 지웠으니 데이터 폴더가 비어 있어요. up -d로 켜고 logs를 보면 running docker-entrypoint-initdb.d/menu.sql 다음에 CREATE TABLE과 INSERT가 찍혀요. POSTGRES_DB로 정한 cafe 안에 실행돼요. 들어가서 백슬래시 dt와 SELECT를 치면 메뉴 세 개가 들어 있어요. 이 폴더도 5파트에서 본 비밀번호처럼 데이터 폴더가 비어 있을 때 처음 한 번만 실행해요. menu.sql을 고쳐서 다시 넣고 싶으면 down -v로 볼륨을 지우고 up -d를 쳐요. 33 MySQL에서도 같은 폴더 이름을 썼어요. logs는 필요한 줄만 옮겼고, 앞의 긴 경로는 …로 줄였어요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
