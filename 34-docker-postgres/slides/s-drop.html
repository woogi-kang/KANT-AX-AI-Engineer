2. 데이터베이스와 표 만들기

DROP으로 지워요. 들어가 있는 데이터베이스는 못 지워요

~ $ docker exec -it pg psql -U postgres -d shop

shop=# DROP TABLE orders;

DROP TABLE

shop=# \dt

Did not find any tables.

shop=# DROP DATABASE shop;

ERROR:  cannot drop the currently open database

shop=# \c postgres

You are now connected to database "postgres" as user "postgres".

postgres=# DROP DATABASE shop;

DROP DATABASE

표가 없어요

cannot drop the currently open database

지금 들어가 있는 데이터베이스라서 못 지운다는 뜻이에요.

\c postgres로 다른 데이터베이스에 옮긴 뒤 지워요.

DROP은 되돌릴 수 없어요. 안의 표와 행도 같이 지워져요. 연습용에서만 쳐요.

DROP으로 지워요. 들어가 있는 데이터베이스는 못 지워요. DROP TABLE orders는 표를 통째로 지워요. 백슬래시 dt로 보면 Did not find any tables, 표가 하나도 없다고 나와요. 이어서 DROP DATABASE shop을 치면 오류가 나요. cannot drop the currently open database, 지금 열려 있는 데이터베이스는 지울 수 없다는 뜻이에요. 표시가 shop=#인 걸 보면 지금 shop 안에 있어요. 백슬래시 c postgres로 옮긴 다음 다시 치면 DROP DATABASE라고 답하고 지워져요. 33 MySQL은 들어가 있는 데이터베이스도 지워지는데, PostgreSQL은 이렇게 막아 줘요. DROP은 되돌릴 수 없고 안의 표와 행이 모두 지워지니, 연습용 데이터베이스에서만 쳐요. 마지막에 친 백슬래시 l 결과는 앞 장과 같아서 뺐어요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
