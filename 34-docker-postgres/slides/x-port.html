5. 자주 나는 오류

5432번을 이미 쓰고 있으면 port is already allocated가 나요

~ $ docker run -d --name pg3 -e POSTGRES_PASSWORD=cafe1234 -p 5432:5432 postgres:18

e18a2c2ced77…

docker: Error response from daemon: failed to set up container networking: driver failed programming external

connectivity on endpoint pg3 (aefa57cd7ba24e64d17bfc3b31c0ae4eb0b7713a9145ae62afc4c453e74eeb37): Bind for

0.0.0.0:5432 failed: port is already allocated

 

Run 'docker run --help' for more information

 

~ $ docker ps -a

CONTAINER ID   IMAGE         COMMAND                  CREATED                  STATUS          PORTS                    NAMES

e18a2c2ced77   postgres:18   "docker-entrypoint.s…"   Less than a second ago   Created                                  pg3

4087ba29a61a   postgres:18   "docker-entrypoint.s…"   5 seconds ago            Up 4 seconds    0.0.0.0:5433->5432/tcp   pg2

b0771208641d   postgres:18   "docker-entrypoint.s…"   44 seconds ago           Up 43 seconds   0.0.0.0:5432->5432/tcp   pg

앞의 pg가 5432번을 쓰는 중이에요. 하나를 끄거나, 내 컴퓨터 쪽 번호만 -p 5433:5432로 바꿔요.

5432번을 이미 쓰고 있으면 port is already allocated가 나요. 29에서 본 포트 겹침이 PostgreSQL에서도 나요. pg가 5432번을 쓰는 중에 pg3을 같은 포트로 켜려고 하니, 컨테이너는 만들어졌지만 켜지지 못하고 오류가 났어요. docker ps -a로 보면 pg3은 Created에 머물러 있고, 5432번은 pg가 쓰고 있어요. PostgreSQL을 컴퓨터에 직접 설치해 둔 사람도 같은 오류를 만나요. 설치한 PostgreSQL이 5432번을 쓰고 있어서예요. 안 쓰는 쪽을 끄거나, 둘 다 써야 하면 3파트의 pg2처럼 -p 5433:5432로 내 컴퓨터 쪽 번호만 바꿔요. 컨테이너 안의 PostgreSQL은 그대로 5432에서 기다려요. Created로 남은 pg3은 docker rm pg3으로 지워요. 긴 오류 줄은 화면 폭에 맞춰 줄만 바꿨어요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
