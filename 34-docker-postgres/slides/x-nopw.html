5. 자주 나는 오류

비밀번호 -e를 빠뜨리면 켜지자마자 꺼져요

~ $ docker run -d --name pg postgres:18

37d52c826c5d…

 

~ $ docker ps -a

CONTAINER ID   IMAGE         COMMAND                  CREATED         STATUS                     PORTS     NAMES

37d52c826c5d   postgres:18   "docker-entrypoint.s…"   3 seconds ago   Exited (1) 2 seconds ago             pg

 

~ $ docker logs pg

Error: Database is uninitialized and superuser password is not specified.

      You must specify POSTGRES_PASSWORD to a non-empty value for the

      superuser. For example, "-e POSTGRES_PASSWORD=password" on "docker run".

…

이름 pg가 남아 있어요. docker rm pg로 지우고 -e POSTGRES_PASSWORD를 붙여 다시 켜요.

비밀번호 -e를 빠뜨리면 켜지자마자 꺼져요. docker run은 컨테이너 ID를 찍고 끝나서 잘 켜진 것처럼 보여요. 그런데 docker ps -a로 보면 STATUS가 Exited (1)이에요. 몇 초 만에 꺼진 거예요. docker logs pg로 이유를 보면, 데이터베이스가 아직 없는데 관리자 비밀번호가 없다고 나와요. POSTGRES_PASSWORD를 비어 있지 않은 값으로 달라는 뜻이에요. 꺼진 컨테이너도 이름 pg를 차지하고 있어서, 29에서 배운 대로 docker rm pg로 먼저 지우고 다시 켜요. logs의 아래 줄에는 비밀번호 없이 들어오게 하는 방법도 적혀 있는데, 권하지 않는다고 적혀 있으니 쓰지 않아요. logs는 앞의 세 줄만 옮겼어요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
