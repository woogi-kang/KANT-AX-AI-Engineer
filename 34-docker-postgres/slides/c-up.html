서비스 이름 pg, POSTGRES_DB로 만든 cafe

docker compose up -d로 켜고, 서비스 이름 pg로 들어가요. ~/cafe-pg 폴더에서 up -d를 치면 네트워크, 볼륨, 컨테이너가 차례로 만들어져요. 볼륨 이름이 cafe-pg_pg-data예요. compose는 폴더 이름을 앞에 붙여서 다른 폴더의 볼륨과 겹치지 않게 해요. docker compose ps로 보면 컨테이너 이름은 cafe-pg-pg-1이에요. 긴 이름을 칠 필요 없이 docker compose exec 뒤에 서비스 이름 pg를 적으면 돼요. -d cafe로 들어가면 POSTGRES_DB로 만든 cafe 데이터베이스예요. 2파트와 같은 SQL이 그대로 돌아가요. 처음 켤 때는 1파트처럼 몇 초 기다렸다가 들어가요. CREATE TABLE의 열 목록은 앞과 같아서 …로 줄였어요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
