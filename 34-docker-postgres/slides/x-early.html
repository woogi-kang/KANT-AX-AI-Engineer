5. 자주 나는 오류

켜자마자 들어가면 아직 준비 중이라 접속이 안 돼요

~ $ docker run -d --name pg -e POSTGRES_PASSWORD=cafe1234 -p 5432:5432 postgres:18

b0771208641d…

~ $ docker exec -it pg psql -U postgres

psql: error: connection to server on socket "/var/run/postgresql/.s.PGSQL.5432" failed: No such file

or directory

Is the server running locally and accepting connections on that socket?

~ $ docker logs pg

…

PostgreSQL init process complete; ready for start up.

…

… LOG:  database system is ready to accept connections

이 줄이 보이면 다시 들어가요

켜자마자 들어가면 아직 준비 중이라 접속이 안 돼요. docker run 바로 뒤에 psql로 들어가면 connection to server failed, No such file or directory가 나와요. 서버에 붙는 통로 파일을 못 찾았다는 뜻이에요. 1파트에서 본 것처럼 처음 켤 때는 데이터 파일을 만들고 준비용 서버를 켰다 끄느라 몇 초 걸려요. 그동안에는 들어갈 서버가 없어요. docker logs pg를 보고 init process complete 다음의 ready to accept connections가 나오면 다시 들어가요. 33 MySQL의 ERROR 2002와 같은 상황이에요. 볼륨에 이미 데이터가 있으면 준비가 짧아서 금방 돼요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
