1. PostgreSQL 컨테이너 켜기

docker run 한 줄로 PostgreSQL 서버를 켜요

docker run -d --name pg -e POSTGRES_PASSWORD=cafe1234 -p 5432:5432 postgres:18

뒤에서 켜기

이름 pg

관리자 비밀번호
(꼭 있어야 해요)

5432번 문 열기

새로 나온 건 -e 하나예요. 나머지는 29의 docker run 그대로예요.

docker run 한 줄로 PostgreSQL 서버를 켜요. 대부분 29에서 배운 옵션이에요. -d로 뒤에서 켜고, --name으로 이름을 pg로 붙이고, -p로 포트를 열어요. PostgreSQL은 5432번 포트에서 접속을 기다려서 5432:5432로 열어요. 새로 나온 건 -e예요. -e POSTGRES_PASSWORD는 관리자 계정의 비밀번호를 정해요. 이 값이 없으면 켜지자마자 꺼지는데, 5파트에서 실제로 봐요. 터미널에는 긴 컨테이너 ID 한 줄만 나와요. docker ps로 보면 STATUS가 Up이고 PORTS에 5432번이 열려 있어요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
