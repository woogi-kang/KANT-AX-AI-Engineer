2. 데이터베이스와 표 만들기

\c shop으로 옮기면 앞의 이름이 shop=#로 바뀌어요

~ $ docker exec -it pg psql -U postgres

postgres=# \c shop

You are now connected to database "shop" as user "postgres".

shop=# \q

표는 데이터베이스 안에 만들어져요. 표를 만들기 전에 어디에 있는지 봐요.

postgres=#
shop=#

psql을 새로 열 때 -d shop을 붙이면 처음부터 shop으로 들어가요.

docker exec -it pg psql -U postgres -d shop

백슬래시 c shop으로 옮기면 앞의 이름이 shop=#로 바뀌어요. psql은 한 번에 데이터베이스 하나에 들어가 있어요. 처음에는 postgres에 있어서 표시가 postgres=#였어요. 백슬래시 c 뒤에 shop을 적으면 You are now connected to database shop, shop에 연결했다는 답이 나오고 표시가 shop=#로 바뀌어요. 표는 지금 있는 데이터베이스 안에 만들어지니, 표를 만들기 전에 이 표시를 꼭 봐요. 33 MySQL의 USE shop과 같은 일이에요. psql을 새로 열 때부터 shop으로 들어가려면 끝에 -d shop을 붙여요. d는 데이터베이스예요. 다음 장부터는 이렇게 들어가요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
