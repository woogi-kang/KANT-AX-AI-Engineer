오늘은 비밀번호만 건네요. 관리자는 postgres, 데이터베이스도 postgres로 시작해요.

POSTGRES_USER와 POSTGRES_DB는 3파트와 4파트에서 직접 써 봐요.

-e로 건네는 이름 세 개가 계정과 데이터베이스를 정해요. 이런 값을 환경 변수라고 해요. 프로그램이 켜질 때 읽는 이름=값 쪽지예요. POSTGRES_PASSWORD는 관리자 비밀번호로, 꼭 적어야 해요. POSTGRES_USER는 관리자 이름인데, 안 적으면 postgres예요. POSTGRES_DB는 처음 만들 데이터베이스 이름인데, 안 적으면 관리자 이름과 같아요. 오늘은 비밀번호만 건넸으니 관리자도 postgres, 데이터베이스도 postgres로 시작해요. 오른쪽은 31에서 배운 docker exec 이름 명령으로 env를 실행한 결과예요. 우리가 건넨 POSTGRES_PASSWORD가 들어 있어요. PGDATA는 데이터를 저장하는 폴더인데 4파트에서 다시 봐요. 맨 위 PATH 줄은 길어서 뺐어요. cafe1234는 연습용 비밀번호예요. 실제 서비스에서는 긴 비밀번호를 쓰고 GitHub에 올리지 않아요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
