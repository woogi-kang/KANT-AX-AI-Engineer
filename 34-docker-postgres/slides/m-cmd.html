데이터베이스 목록

SHOW DATABASES;

다른 데이터베이스로

USE shop;

\c shop

한 문장만 실행

mysql … -e "…"

psql … -c "…"

덜 끝난 문장 표시

->

-#

PostgreSQL의 목록 명령은 \로 시작하고 ;가 없어요.

SQL은 같고, 목록을 보는 명령만 달라요. 왼쪽 문장들은 33과 34에서 글자 하나 다르지 않게 쳤어요. CREATE DATABASE, CREATE TABLE, INSERT, SELECT, DROP은 SQL이라는 같은 언어라서 그래요. 끝에 세미콜론을 붙이는 것도 같아요. 다른 건 오른쪽 표예요. MySQL은 SHOW DATABASES, USE처럼 SQL 모양의 명령을 쓰고, PostgreSQL의 psql은 백슬래시 l, 백슬래시 c처럼 백슬래시로 시작하는 짧은 명령을 써요. 백슬래시 명령은 psql이 직접 처리해서 세미콜론이 없어요. 한 문장만 실행할 때 MySQL은 -e, psql은 -c예요. 문장이 덜 끝났을 때 MySQL은 화살표, psql은 -#를 보여 줘요. 두 데이터베이스를 오갈 때 이 표만 기억하면 돼요.
