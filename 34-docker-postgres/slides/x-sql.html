5. 자주 나는 오류

psql에서 자주 하는 실수 두 가지예요

1. 세미콜론을 빠뜨렸어요

shop=# SELECT * FROM orders

shop-# ;

id |   menu    | qty

----+-----------+-----

 1 | latte     |   2

 2 | americano |   1

(2 rows)

=#가 -#로 바뀌면 문장이 아직 안 끝났다는 뜻이에요. ;만 치고 Enter를 눌러요.

2. 데이터베이스 이름을 잘못 썼어요

postgres=# \c shopp

connection to server on socket

"/var/run/postgresql/.s.PGSQL.5432" failed:

FATAL:  database "shopp" does not exist

Previous connection kept

없는 이름이라 못 옮기고, 원래 있던 postgres에 그대로 남아요. \l로 이름을 보고 다시 쳐요.

psql에서 자주 하는 실수 두 가지예요. 왼쪽은 SELECT 끝의 세미콜론을 빠뜨리고 Enter를 친 모습이에요. 실행되지 않고 표시가 shop=#에서 shop-#로 바뀌었어요. 문장이 아직 안 끝났으니 더 치라는 뜻이에요. 세미콜론만 치고 Enter를 누르면 앞 줄과 이어서 실행돼요. 33 MySQL에서 화살표 표시가 나온 것과 같아요. 오른쪽은 백슬래시 c 뒤에 shop을 shopp로 잘못 친 모습이에요. database shopp does not exist, 그런 데이터베이스가 없다는 오류가 나고, Previous connection kept, 원래 연결을 그대로 둔다고 나와요. 표시가 여전히 postgres=#예요. 백슬래시 l로 이름을 확인하고 다시 쳐요. 백슬래시 명령에는 세미콜론이 필요 없다는 것도 같이 기억해요. 긴 오류 줄은 화면 폭에 맞춰 줄만 바꿨어요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
