막히면 이렇게 풀어요

이런 글이 보이면

이렇게 해요

connection to server on socket … failed

켜는 중이라 아직 서버가 없어요

logs에서 ready 보고 다시

password authentication failed

비밀번호가 틀렸거나 볼륨의 처음 비밀번호예요

처음 정한 비밀번호로

Exited (1), POSTGRES_PASSWORD

-e POSTGRES_PASSWORD가 빠졌어요

docker rm pg 뒤 -e 붙이기

Error: in 18+

17까지 쓰던 /var/lib/postgresql/data에 붙였어요

-v pg-data:/var/lib/postgresql

port is already allocated

5432번을 다른 것이 쓰고 있어요

하나 끄거나 -p 5433:5432

permission denied to create database

일반 계정은 데이터베이스를 못 만들어요

-U postgres로 들어가기

표시가 -#로 바뀜

문장 끝 ;가 빠졌어요

;만 치고 Enter

무엇이든 막히면 docker ps -a로 켜져 있는지 보고, docker logs pg를 먼저 읽어요.

오늘 만난 오류를 모았어요. connection to server on socket은 켜는 중이라 아직 서버가 없다는 뜻이에요. logs에서 ready to accept connections를 보고 다시 들어가요. password authentication failed는 비밀번호가 틀렸다는 뜻인데, 볼륨을 다시 쓰고 있다면 처음 켤 때 정한 비밀번호가 맞는 비밀번호예요. 켜자마자 Exited (1)이 되면 logs를 봐요. POSTGRES_PASSWORD가 보이면 -e가 빠진 거고, Error: in 18+가 보이면 예전 자리에 볼륨을 붙인 거예요. 5432 포트 겹침은 29에서 본 것과 같아요. 일반 계정으로 데이터베이스를 만들려고 하면 permission denied가 나요. 표시가 -#로 바뀌면 세미콜론만 치면 돼요. 무엇이든 막히면 docker ps -a와 docker logs pg부터 봐요.
