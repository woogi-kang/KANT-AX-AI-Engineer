Docker Hub의 공식 이미지 postgres:18을 받아요. 29에서 배운 docker pull이에요. postgres는 Docker Official Image 마크가 붙은 공식 이미지라 이것부터 골라요. 태그 18은 PostgreSQL 18 버전이에요. latest로 받으면 새 버전이 나올 때마다 바뀌어서, 수업에서는 18로 적어 모두 같은 버전을 써요. 4파트에서 보겠지만 18은 데이터 폴더 자리가 17까지와 달라서, 버전을 꼭 적는 게 좋아요. docker images postgres로 받은 이미지를 확인해요. 650MB라 처음에는 조금 걸려요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
