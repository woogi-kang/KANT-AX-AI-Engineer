오늘 쓴 것을 세 묶음으로 모았어요. 왼쪽은 켜고 들어가기예요. docker run에 POSTGRES_PASSWORD를 꼭 주고, logs에서 ready를 본 뒤 docker exec -it pg psql -U postgres로 들어가요. 가운데는 psql 안에서 쓰는 백슬래시 명령이에요. 오른쪽은 데이터를 지키는 방법이에요. 18부터는 볼륨을 /var/lib/postgresql에 붙여요. compose down으로는 볼륨이 남고, down -v를 쳐야 볼륨까지 지워져요. init 폴더의 SQL 파일은 처음 켤 때 한 번 실행돼요.
