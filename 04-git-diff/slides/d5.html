3 insertions(+), 1 deletion(-)은 diff의 + 줄 3개, - 줄 1개예요.

커밋하고 나면 git diff와 git diff --staged 모두 빈 화면이에요. 커밋 출력의 3 insertions(+), 1 deletion(-)은 diff의 + 줄 3개, - 줄 1개와 같은 숫자예요. 방금 커밋한 내용을 다시 보려면 다음 장의 git show를 써요.
