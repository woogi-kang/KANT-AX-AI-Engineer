이미 커밋한 파일은 .gitignore로 숨겨지지 않아요

*.log를 적었는데 계속 나와요

기록에서만 빠져요

$ echo "*.log" >> .gitignore

$ echo "error" >> app.log

$ git status

Changes not staged for commit:

modified: .gitignore

modified: app.log

$ git rm --cached app.log

rm 'app.log'

$ git status

Changes to be committed:

deleted: app.log

Changes not staged for commit:

modified: .gitignore

$ git add .gitignore

$ git commit -m "chore: 로그 파일을 기록에서 빼기"

.gitignore는 Git이 아직 모르는 파일에만 통해요

이미 커밋한 파일은 기록 대상에서 빼요.

git rm --cached 파일

내 폴더의 파일은 그대로 있어요.
그다음 .gitignore와 같이 add, commit 해요.

Git은 이미 기록하던 파일은 .gitignore에 적어도 계속 지켜봐요. app.log를 먼저 커밋한 뒤에 *.log를 적은 상황이에요. git rm --cached는 파일은 내 폴더에 두고 Git 기록에서만 빼요. 그래서 .gitignore는 프로젝트 처음에 만드는 게 좋아요. 비밀 값을 이미 push했다면 키를 새로 발급받아요. status 안내 줄과 On branch main 줄은 화면 때문에 뺐어요.
