한눈에 비교

status를 보고 어떤 diff를 칠지 골라요

언제

status에 보이는 것

칠 명령

비교하는 두 곳

add 전

빨간 글씨 파일

git diff

① 작업 폴더 ↔ ② 대기실

commit 전

초록 글씨 파일

git diff --staged

② 대기실 ↔ ③ 마지막 커밋

commit 뒤

nothing to commit

git show

마지막 커밋 ↔ 바로 전 커밋

merge 전

브랜치가 두 개

git diff main 브랜치

두 브랜치의 마지막 커밋

빈 화면은 오류가 아니라 비교한 두 곳이 같다는 뜻이에요.

무엇을 칠지 헷갈리면 먼저 git status를 봐요. 빨간 글씨면 git diff, 초록 글씨면 git diff --staged, 깨끗하면 git show를 써요. merge 전에는 받을 쪽을 앞에 써서 git diff main 브랜치이름이에요. 수업에서는 이 장을 띄워 두고 상황마다 학생이 명령을 말해 보게 하세요.
