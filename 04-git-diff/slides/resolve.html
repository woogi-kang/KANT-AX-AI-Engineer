실제 상황 1 · merge 전에 충돌 미리 보기

고친 뒤 add하고, 커밋 전에 --staged로 한 번 더 봐요

# login.md에서 # 로그인하기만 남기고 표시 세 줄을 지움

$ git add login.md

$ git diff --staged

diff --git a/login.md b/login.md

index cea7b97..14b3837 100644

--- a/login.md

+++ b/login.md

@@ -1,5 +1,6 @@

-# 로그인 페이지

+# 로그인하기

+비밀번호 찾기

$ git commit -m "fix: 로그인 제목 충돌 해결"

[main c36ee83] fix: 로그인 제목 충돌 해결

커밋 전에 볼 것

2

3

main에 들어올 줄이 이게 다인가

--staged는 main의 마지막 커밋과 비교해요. 이 merge 커밋에 들어갈 내용이에요.

충돌을 풀고 add한 뒤 git diff --staged를 보면 이 merge 커밋으로 main에 들어올 변경이 나와요. 브랜치 비교에서 본 것과 같은 내용이에요. 충돌 표시가 남아 있으면 여기서 + 줄로 보여요. 확인이 끝나면 커밋해요.
