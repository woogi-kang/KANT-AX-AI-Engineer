.gitignore

.gitignore에 이름을 적으면 Git이 못 본 척해요

① 작업 폴더 hello-git/

login.md

커밋됨 · 바뀐 것 없음

.env

무시됨 · status에 안 나와요

.gitignore

새 파일 · 커밋해서 같이 써요

.env가 목록에서 빠졌어요

$ echo ".env" > .gitignore

$ git status

On branch main

Untracked files:

.gitignore

$ git add .gitignore

$ git commit -m "chore: .env를 gitignore에 추가"

[main 0e35512] chore: .env를 gitignore에 추가

.env 파일은 그대로 있고 Git만 못 본 척해요.
.gitignore는 커밋해서 팀원도 같은 규칙을 써요.

.gitignore에 이름을 적은 파일은 status에도 add에도 잡히지 않아요. .gitignore는 저장소 맨 위 폴더에 두고 한 줄에 하나씩 적어요. .env 파일 자체는 지워지지 않아요. status 출력의 안내 줄은 화면 때문에 뺐어요.
