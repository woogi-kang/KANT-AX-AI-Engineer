고친 게 사라진 게 아니에요

add하고 나서 git diff를 치면 아무것도 나오지 않아요. 고친 내용이 없어진 게 아니라 작업 폴더와 대기실이 같아진 거예요. 이제 커밋될 내용은 다음 장의 git diff --staged로 봐요.
