한 줄을 고치면 - 한 줄과 + 한 줄이 짝으로 나와요. 예전 줄을 지우고 새 줄을 넣은 걸로 보여 줘요.

diff 출력은 위에서부터 파일, 위치, 바뀐 줄 순서로 읽어요. 처음엔 diff --git 줄의 파일 이름만 봐도 돼요. index 줄의 숫자는 Git이 파일 내용에 붙인 번호라서 몰라도 돼요. 줄 맨 앞의 기호 한 칸은 파일 내용이 아니라 diff가 붙인 표시예요. 터미널에서는 빼기 줄이 빨강, 더하기 줄이 초록으로 나와요.
