막힐 때

git diff에 아무것도 안 나와요

1

이미 git add 했어요

대기실에 올린 건 --staged로 봐요

git diff --staged

2

새로 만든 파일이에요

Untracked 파일은 git diff에 안 나와요. add한 뒤에 봐요

git add 파일
git diff --staged

3

이미 commit 했어요

커밋한 내용은 git show로 봐요

git show

가장 많이 나오는 질문이에요. 빈 화면은 오류가 아니라 비교한 두 칸이 같다는 뜻이에요. 먼저 git status를 보고 빨간 글씨면 git diff, 초록 글씨면 git diff --staged, 둘 다 없으면 git show를 써요. 새 파일은 git diff에 안 나오는 게 처음엔 가장 헷갈려요.
