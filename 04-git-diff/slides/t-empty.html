막힐 때

git diff에 아무것도 안 나와요

1

이미 git add 했어요

대기실에 올린 건 --staged로 봐요

git diff --staged

2

새로 만든 파일이에요

Untracked 파일은 git diff에 안 나와요. add한 뒤에 봐요

git add 파일
git diff --staged

3

이미 commit 했어요

커밋한 내용은 git show로 봐요

git show

셋 다 아니면 git status부터 봐요. 고친 파일이 없으면 diff도 비어요.

git diff가 빈 화면이면 비교한 두 곳이 같다는 뜻이고, 세 경우 중 하나예요. 새 파일이 git diff에 안 나오는 게 처음엔 가장 헷갈려요. Git이 아직 모르는 파일이라 비교할 예전 모습이 없어서예요.
