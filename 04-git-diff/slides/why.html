diff란?

status는 파일 이름만, diff는 바뀐 줄까지 보여 줘요

어느 파일이 바뀌었는지만 알려 줘요

$ git status

Changes not staged for commit:

modified: login.md

어느 줄이 어떻게 바뀌었는지까지- 지운 줄, + 넣은 줄

$ git diff

diff --git a/login.md b/login.md

index ef88ce3..7d67f3e 100644

--- a/login.md

+++ b/login.md

@@ -1,3 +1,4 @@

# 로그인

아이디

-비밀번호

+비밀번호 (8자 이상)

+로그인 버튼

git status는 어느 파일이 바뀌었는지만 알려 주고, 그 안의 어느 줄인지는 git diff가 알려 줘요. 커밋 메시지를 쓸 때도 diff를 보면 무엇을 했는지 바로 적을 수 있어요. status 출력의 안내 문장 줄은 화면 때문에 뺐어요. 출력은 tools/demo.sh로 실제로 실행한 결과예요.
