.gitignore

자주 적는 이름은 정해져 있어요

.env

비밀 값

API 키, 비밀번호

node_modules/

받은 패키지

다시 받으면 돼요

__pycache__/

파이썬 임시 파일

실행하면 저절로 생겨요

.venv/

파이썬 가상환경

uv sync로 다시 만들어요

*.log

로그 파일

* 는 아무 이름

.DS_Store

macOS 폴더 설정

Finder가 만들어요

.gitignore 파일 안

.env

node_modules/

__pycache__/

.venv/

*.log

.DS_Store

끝에 / 를 붙이면 폴더, * 는 아무 글자, # 으로 시작하면 메모 줄이에요.

프로젝트를 만들 때 처음부터 .gitignore에 이 이름들을 적어 두면 편해요. GitHub에서 새 저장소를 만들 때 Add .gitignore 메뉴로 Python 같은 템플릿을 고를 수도 있어요. .venv는 09에서 uv가 만든 가상환경 폴더예요. 한 줄에 하나, 끝에 /는 폴더, *는 아무 글자, #은 메모라는 것만 알면 돼요.
