.gitignore

자주 적는 것들

.env

비밀 값

API 키, 비밀번호

node_modules/

받은 패키지

npm install로 다시 받아요

__pycache__/

파이썬 임시 파일

실행하면 저절로 생겨요

.venv/

파이썬 가상 환경

내 컴퓨터에서만 써요

*.log

로그 파일

* 는 아무 이름

.DS_Store

macOS 폴더 설정

Finder가 만들어요

.gitignore 파일 예

# 비밀 값

.env

# 패키지, 임시 파일

node_modules/

__pycache__/

.venv/

*.log

.DS_Store

끝에 / 를 붙이면 폴더, # 으로 시작하면 메모 줄이에요.

프로젝트를 만들 때 처음부터 .gitignore를 두면 편해요. GitHub에서 새 저장소를 만들 때 Add .gitignore 메뉴로 Python, Node 같은 템플릿을 고를 수도 있어요. 공통 규칙은 이 정도만 알면 돼요. 한 줄에 하나, 끝에 /는 폴더, *는 아무 글자, #은 메모예요.
