git add . 한 번이면 .env까지 올라가요.
GitHub에 올라간 키는 누구나 볼 수 있어요.

.env는 API 키 같은 비밀 값을 적어 두는 파일이라 GitHub에 올리면 안 돼요. 수업에서 AI API를 쓸 때 자주 만들어요. status에 계속 빨간 글씨로 나오고, git add .을 치면 같이 올라가요. 한 번 push한 키는 지워도 기록에 남아서 키를 새로 발급받아야 해요. status 출력의 안내 줄은 화면 때문에 뺐어요.
