q를 누르면 나와요. Space는 다음 화면이에요.

파일 이름과 줄 수만 볼 때

$ git diff --stat main feature/login

login.md | 3 ++-

1 file changed, 2 insertions(+),

1 deletion(-)

+, - 개수로 얼마나 바뀌었는지 봐요.
git diff, --staged, git show에 모두 붙여요.

출력이 한 화면보다 길면 Git이 보기 프로그램으로 한 화면씩 보여 줘서 멈춘 것처럼 보여요. q로 나와요. 파일이 많을 때는 --stat으로 먼저 훑고, 궁금한 파일만 git diff 파일이름으로 봐요.
