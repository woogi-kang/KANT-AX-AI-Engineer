화면이 안 끝나거나, 너무 길어요

아래에 : 나 (END)가 보이고 멈춰요

+로그인 버튼

+아이디 저장

(END)

출력이 길면 한 화면씩 보여 줘요.
Space는 다음 화면, q는 나가기예요.

q

파일 이름과 줄 수만 보고 싶어요

$ git diff --stat main feature/login

login.md | 3 ++-

1 file changed, 2 insertions(+), 1 deletion(-)

--stat은 어떤 명령에도 붙여요.
+, - 개수로 얼마나 바뀌었는지 봐요.

--stat

Git은 출력이 한 화면보다 길면 less라는 보기 프로그램으로 보여 줘요. 화살표나 Space로 내려가고 q로 나와요. 터미널이 멈춘 게 아니에요. --stat은 git diff, git diff --staged, git show에 모두 붙일 수 있어요. 파일이 많을 때 먼저 --stat으로 훑고, 궁금한 파일만 git diff 파일이름으로 봐요.
