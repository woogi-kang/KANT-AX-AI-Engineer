번호 찾기

git show는 커밋 하나를 열어 봐요. 위에는 커밋 번호, 만든 사람, 날짜, 메시지가 나오고 아래에는 바로 전 커밋과 비교한 diff가 나와요. 해시 없이 쓰면 HEAD, 즉 지금 브랜치의 마지막 커밋을 보여 줘요. 다른 커밋은 git log --oneline에서 번호를 찾아 git show 번호로 봐요. 팀원이 올린 커밋이 무엇을 바꿨는지 볼 때도 써요. 출력이 길면 q로 나와요.
