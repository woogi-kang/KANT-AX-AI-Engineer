git show

git show는 커밋 하나를 열어서 위에는 커밋 정보, 아래에는 바로 전 커밋과 비교한 diff를 보여 줘요. 번호 없이 쓰면 지금 브랜치의 마지막 커밋을 보여 줘요. 팀원이 올린 커밋이 무엇을 바꿨는지 볼 때도 써요. 출력이 길면 q로 나와요.
