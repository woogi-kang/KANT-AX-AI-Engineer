br3 상태에서 git merge feature/login을 쳐서 충돌이 났어요. 첫 줄 Auto-merging login.md는 화면 때문에 뺐어요. 충돌 중에 git diff를 치면 diff --cc라는 모양으로 충돌 난 부분만 보여 줘요. 앞에 기호가 두 칸 붙는 건 두 브랜치와 각각 비교해서예요. 지금은 ++ 줄이 충돌 표시이고 그 사이 위아래가 양쪽 내용이라는 것만 기억하면 돼요. 푸는 순서는 03과 같아요.
