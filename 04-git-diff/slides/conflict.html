실제 상황 1 · merge 전에 충돌 미리 보기

충돌이 나면 git diff로 충돌 난 곳만 봐요

↑ 위: main(HEAD) 쪽

↓ 아래: feature/login 쪽

++ 로 시작하는 줄이 충돌 표시

$ git merge feature/login

Auto-merging login.md

CONFLICT (content): Merge conflict in login.md

Automatic merge failed; fix conflicts and then commit the result.

$ git diff

diff --cc login.md

index cea7b97,14b3837..0000000

--- a/login.md

+++ b/login.md

@@@ -1,4 -1,4 +1,8 @@@

++<<<<<<< HEAD

+# 로그인 페이지

++=======

+ # 로그인하기

++>>>>>>> feature/login

아이디

비밀번호 (8자 이상)

로그인 버튼

파일이 여러 개여도 git diff 하나로 충돌 표시가 남은 곳을 모두 찾아요.

충돌 중에 git diff를 치면 충돌 난 부분만 diff --cc 모양으로 보여 줘요. 앞에 기호가 두 칸 붙는 건 두 브랜치와 각각 비교해서예요. 지금은 ++ 줄이 충돌 표시이고 그 사이 위아래가 양쪽 내용이라는 것만 기억하면 돼요. 푸는 순서는 03과 같아요.
