diff란?

diff는 두 칸을 골라 나란히 놓고 비교해요

① 작업 폴더

지금 고치는 파일

② 대기실

add로 올린 모습

③ 내 저장소

commit한 기록

add

commit

커밋끼리도 비교해요

git diff

status의 빨간 글씨 파일

git diff --staged

status의 초록 글씨 파일

git diff는 ① 작업 폴더와 ② 대기실, git diff --staged는 ② 대기실과 ③ 마지막 커밋을 비교해요. status에서 빨간 글씨로 나온 파일은 git diff로, 초록 글씨로 나온 파일은 git diff --staged로 내용을 봐요. ③ 안의 커밋끼리 비교하는 git show와 브랜치 비교는 4부에서 봐요. ④ 원격 저장소는 이번 챕터에서 쓰지 않아서 그림에서 뺐어요. --staged 대신 --cached라고 써도 같아요.
