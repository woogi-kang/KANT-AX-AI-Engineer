diff란?

diff는 언제나 두 칸을 비교해요

① 작업 폴더

지금 고치는 파일

② 대기실

add로 올린 모습

③ 내 저장소

commit한 기록

④ 원격 저장소

이번엔 쓰지 않아요

git diff

git diff --staged

git diff

add 전에 고친 줄

status의 빨간 글씨 = 여기 나와요

git diff --staged

commit될 줄

status의 초록 글씨 = 여기 나와요

git diff main feature/login

두 브랜치의 차이

merge 전에 미리 보기

02의 네 칸 그림이에요. git diff는 ①과 ②, git diff --staged는 ②와 ③을 비교해요. status에서 빨간 글씨로 나온 파일은 git diff로, 초록 글씨로 나온 파일은 git diff --staged로 내용을 본다고 외우면 쉬워요. 브랜치 비교는 ③ 안에서 커밋 두 개를 비교하는 거예요. --staged 대신 --cached라고 써도 같아요.
