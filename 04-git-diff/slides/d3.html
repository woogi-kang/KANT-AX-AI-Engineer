git diff --staged

커밋 메시지를 쓰기 전에 한 번 보면 무엇을 했는지 바로 적을 수 있어요.

git diff --staged는 지금 commit하면 들어갈 내용을 보여 줘요. 대기실과 마지막 커밋을 비교하기 때문이에요. 실습 1과 같은 출력이 나온 건 고친 걸 그대로 다 올렸기 때문이에요. --cached라고 써도 똑같이 동작해요.
