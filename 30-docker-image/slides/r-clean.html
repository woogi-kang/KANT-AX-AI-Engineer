~/cafe $ docker ps -a

CONTAINER ID   IMAGE     COMMAND   CREATED   STATUS    PORTS     NAMES

~/cafe $ docker volume ls

local     site

~/cafe $ docker volume rm cafe-html site

cafe-html

site

~/cafe $ docker volume ls

DRIVER    VOLUME NAME

~/cafe $ docker images

nginx:latest   165ddde8751e        243MB         66.8MB        

1 남은 컨테이너가 없어요

2 볼륨 (보관함) 지우기

3 nginx 틀은 31에서 또 써요

붕어빵부터 지우고 보관함을 지워요. 볼륨은 지우면 되돌릴 수 없으니 이름을 한 번 더 봐요.

실습이 끝나면 쌓인 것을 정리해요. 먼저 docker ps -a로 남은 컨테이너가 없는지 봐요. 오늘은 compose down과 rm으로 이미 다 지웠어요. 남은 게 있으면 29에서 배운 docker rm 이름으로 지워요. 그다음 docker volume ls로 볼륨을 보고, 2파트의 cafe-html과 4파트에서 잘못 생긴 site를 docker volume rm으로 지워요. 이름은 여러 개를 띄어 쓰면 한 번에 지워져요. 컨테이너가 붙어 있는 볼륨은 지울 수 없으니 붕어빵부터 지워요. 볼륨을 지우면 안의 파일도 같이 사라져서 되돌릴 수 없어요. 내 컴퓨터의 site 폴더는 그대로 남아요. nginx 이미지는 31에서 다시 쓰니 남겨 둬요. 터미널 출력은 tools/demo.py로 실제 Docker를 실행한 결과예요.
