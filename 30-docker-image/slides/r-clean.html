예제 3 · 다 쓴 컨테이너, 이미지, 볼륨을 정리해요

~/shopping-cart $ docker ps -a

~/shopping-cart $ docker rmi cart

~/shopping-cart $ docker volume rm cafe-html site

cafe-html

site

1 컨테이너 (붕어빵)

2 이미지 (틀)

3 볼륨 (보관함)

붕어빵부터 지우고 틀과 보관함을 지워요. 지우면 되돌릴 수 없으니 이름을 한 번 더 봐요.

실습이 끝나면 쌓인 것을 정리해요. docker ps -a로 남은 컨테이너를 보고 NAMES 칸의 이름으로 지워요. 이름은 여러 개를 띄어 쓰면 한 번에 지워져요. 그다음 docker rmi cart로 이미지를 지워요. 마지막으로 2파트와 5파트에서 만든 볼륨 두 개를 docker volume rm으로 지워요. 컨테이너가 붙어 있는 이미지와 볼륨은 지울 수 없으니 붕어빵부터 지워요. 볼륨을 지우면 안의 파일도 같이 사라져서 되돌릴 수 없어요. 내 컴퓨터의 site 폴더와 shopping-cart 폴더는 그대로 남아요. 컨테이너 이름은 Docker가 아무렇게나 지어서 실습할 때마다 달라요. 터미널 출력은 tools/demo.py로 실제 Docker를 실행한 결과예요.
