3. Dockerfile로 이미지 만들기

RUN은 틀을 만들 때 한 번, CMD는 찍을 때마다 실행돼요

docker build

틀 만들 때 한 번

RUN uv sync

docker run

붕어빵 찍을 때마다

CMD ["uv", "run", "main.py"]

이미지 cart

RUN uv sync 결과 (.venv)

… COPY . .

결과가 틀 안에
구워져요

컨테이너 cart

uv run main.py

1번째 실행

컨테이너 cart

uv run main.py

2번째 실행

컨테이너 cart

uv run main.py

3번째 실행

CMD는 틀에 적어만 뒀다가 붕어빵을 찍을 때마다 실행해요.

RUN과 CMD는 둘 다 명령을 적지만 실행되는 때가 달라요. RUN uv sync는 docker build로 틀을 만드는 동안 딱 한 번 실행되고, 그 결과(.venv)가 틀 안에 구워져요. CMD는 틀에 적어만 둬요. docker run으로 붕어빵을 찍을 때마다 그 명령이 실행돼요. 붕어빵을 세 개 찍으면 uv run main.py가 세 번 돌아요. CMD는 대괄호 안에 명령을 낱말마다 따옴표로 나눠 적어요. 파이썬 리스트와 모양이 같아요.
