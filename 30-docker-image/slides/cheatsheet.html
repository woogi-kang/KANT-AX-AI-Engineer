한 장 요약

안에 들어가기, 남기기

docker exec -it 이름 bash

실행 중인 컨테이너 안으로

-v 볼륨이름:경로

지워도 남는 보관함

-v ./폴더:경로

내 폴더 연결

docker volume ls / rm

볼륨 보기, 지우기

이미지 만들기

FROM WORKDIR COPY RUN CMD

Dockerfile 다섯 줄

docker build -t 이름 .

틀 굽기 (코드 고치면 다시)

docker run --rm 이름

찍고 끝나면 지우기

.dockerignore

.venv __pycache__ .git

compose

compose.yaml

image, ports, volumes

docker compose up -d

켜기

docker compose ps

이 폴더 것만 보기

docker compose down

끄고 지우기

이미지는 틀, 컨테이너는 붕어빵, 볼륨은 붕어빵 밖 보관함이에요.

오늘 만든 cart 이미지를 친구 컴퓨터에서도 돌려 봐요.

오늘 쓴 명령을 세 묶음으로 모았어요. 실행 중인 컨테이너에는 exec로 들어가고, 지워도 남길 것은 볼륨에, 고치면서 볼 파일은 폴더 연결로 둬요. 내 프로그램은 Dockerfile 다섯 줄과 docker build로 이미지를 만들고, 코드를 고치면 build부터 다시 해요. 긴 run 명령은 compose.yaml에 적어 두고 up과 down으로 켜고 꺼요. 오늘 만든 cart 이미지를 친구 컴퓨터에서도 돌려 보세요.
