docker start 이름

-v ./폴더:경로

내 폴더 연결

docker volume ls

볼륨 보기

docker volume rm 이름

볼륨 지우기 (되돌릴 수 없어요)

compose

compose.yaml

image, ports, volumes

docker compose up -d

켜기

docker compose ps

이 폴더 것만 보기

docker compose down

끄고 지우기

이미지는 틀, 컨테이너는 붕어빵, 볼륨은 붕어빵 밖 보관함이에요.

다음 31에서는 같은 ~/cafe 폴더와 compose로 nginx를 더 깊이 써요.

오늘 쓴 명령을 세 묶음으로 모았어요. 실행 중인 컨테이너에는 exec로 들어가고, exit로 나와도 컨테이너는 계속 돌아요. 지워도 남길 것은 볼륨에, 고치면서 볼 파일은 폴더 연결로 둬요. 긴 run 명령은 compose.yaml에 적어 두고 up과 down으로 켜고 꺼요. 이미지는 오늘처럼 Docker Hub의 공식 이미지를 받아서 써요. 31에서는 같은 ~/cafe 폴더에서 nginx 설정을 바꿔 봐요.
