오늘 자주 만나는 일을 모았어요. 1번부터 4번은 5파트에서 실제로 본 오류예요. 5번은 오류 없이 결과만 옛날 그대로인 경우예요. 이미지는 build할 때의 코드를 담고 있으니 다시 build해요. 6번은 Windows Git Bash에서만 나요. -v 뒤의 /usr/share/nginx/html이 C:/Program Files/Git/usr/share/nginx/html처럼 바뀌어 들어가면 그 창에서 export MSYS_NO_PATHCONV=1을 치고 다시 해요. 6번 메시지는 이 자료를 만든 환경에서 실행할 수 없어서 원문을 옮기지 않았어요.
