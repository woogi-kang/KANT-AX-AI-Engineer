오늘 자주 만나는 일을 모았어요. 1번부터 4번은 4파트에서 실제로 본 오류와 함정이에요. 5번은 1파트에서 본 장면이에요. exec로 고친 파일은 컨테이너와 같이 지워지니, 남길 파일은 -v로 볼륨이나 내 폴더에 둬요. 6번은 Windows Git Bash에서만 나요. -v 뒤의 /usr/share/nginx/html이 C:/Program Files/Git/usr/share/nginx/html처럼 바뀌어 들어가면 그 창에서 export MSYS_NO_PATHCONV=1을 치고 다시 해요. 6번 메시지는 이 자료를 만든 환경에서 실행할 수 없어서 원문을 옮기지 않았어요.
