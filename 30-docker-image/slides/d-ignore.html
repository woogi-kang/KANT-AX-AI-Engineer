COPY . .은 폴더의 모든 파일을 넣어요. 그런데 .venv는 내 컴퓨터의 파이썬에 맞춰 만든 가상환경이라 리눅스인 이미지 안에서는 못 써요. .git과 __pycache__도 프로그램 실행에 필요 없어요. shopping-cart 폴더 맨 위에 .dockerignore 파일을 만들고 넣지 않을 이름을 한 줄에 하나씩 적어요. 04의 .gitignore와 같은 모양이에요. 왼쪽 목록에는 .git과 __pycache__가 들어가 있고, 오른쪽 목록에서는 빠졌어요. 이미지 안의 .venv는 RUN uv sync가 새로 만든 거예요. build할 때 Docker에 보내는 재료도 수십 kB에서 수백 B로 줄었어요. .venv를 넣으면 uv sync가 Ignoring existing virtual environment라는 경고를 내고 새로 만들어요. 터미널 출력은 tools/demo.py로 실제 Docker를 실행한 결과예요.
