바뀐 COPY부터 다시

이제 3개

main.py에서 텀블러를 3개로 고치고 바로 docker run cart를 쳐요. 영수증은 여전히 2개예요. 틀인 이미지에는 build할 때 복사한 옛 main.py가 들어 있기 때문이에요. 그래서 코드를 고치면 docker build -t cart .부터 다시 쳐요. 두 번째 build는 빨라요. 바뀌지 않은 WORKDIR 줄은 CACHED로 전에 만든 층을 그대로 쓰고, 파일이 바뀐 COPY 줄부터 다시 만들어요. 다시 run 하면 이제 3개가 담겨요. 출력은 줄여서 앞부분만 옮겼어요. 터미널 출력은 tools/demo.py로 실제 Docker를 실행한 결과예요.
