FROM 뒤에는 시작할 이미지를 적어요. 29에서 본 이름:태그 모양 그대로예요. astral/uv는 uv를 만든 회사 Astral이 Docker Hub에 올린 이미지예요. 29에서 Docker Official Image 인증 마크를 먼저 보라고 했는데, 이 이미지에는 마크가 없어요. 대신 uv를 만든 회사가 직접 올렸고 uv 공식 문서도 이 이미지를 쓰라고 안내해요. 마크가 없는 이미지는 이렇게 누가 올렸는지 확인하고 써요. 태그의 python3.14는 이미지에 든 파이썬 버전, bookworm-slim은 리눅스 종류예요. 28 프로젝트의 .python-version 숫자와 맞춰요. 내 파일이 3.13이면 python3.13으로 바꿔요.
