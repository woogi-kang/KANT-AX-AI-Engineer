5. 자주 나는 오류

build 오류는 마지막 ERROR 줄부터 읽어요

~/shopping-cart $ docker build -t cart

ERROR: docker: 'docker buildx build' requires 1 argument

끝의 점(.)을 빼먹었어요

docker build -t cart .

~ $ docker build -t cart .

ERROR: failed to build: failed to solve: failed to read dockerfile: open Dockerfile: no such file or directory

Dockerfile이 없는 폴더에서 쳤어요

cd shopping-cart

~/shopping-cart $ docker build -t cart .

  1 | >>> FROM astral/uv:python3.14-bookwrom-slim

ERROR: failed to build: failed to solve: astral/uv:python3.14-bookwrom-slim: failed to resolve source metadata for docker.io/astral/

uv:python3.14-bookwrom-slim: docker.io/astral/uv:python3.14-bookwrom-slim: not found

FROM의 이미지 이름이나 태그에 오타가 있어요

bookwrom → bookworm

build가 실패하면 출력 맨 아래 ERROR 줄을 먼저 읽어요. 첫 번째는 끝의 점을 빼먹었을 때예요. requires 1 argument는 재료 폴더를 하나 적으라는 뜻이에요. 두 번째는 Dockerfile이 없는 홈 폴더에서 쳤을 때예요. open Dockerfile: no such file or directory가 나오면 pwd로 위치를 보고 cd shopping-cart로 들어가요. 세 번째는 FROM의 태그에 오타가 있을 때예요. 몇 번째 줄이 틀렸는지 >>> 표시로 보여 주고, Hub에 없는 이름이라 not found가 나와요. 긴 줄은 터미널 창 너비에 따라 꺾이는 자리가 달라요. 세 번째는 줄 표시와 ERROR 줄만 옮겼어요. 터미널 출력은 tools/demo.py로 실제 Docker를 실행한 결과예요.
