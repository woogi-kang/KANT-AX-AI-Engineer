1파트와 같은 순서를 볼륨을 붙여서 다시 해요. 차이는 docker run 뒤에 붙인 -v cafe-html:/usr/share/nginx/html 하나예요. cafe-html이라는 볼륨을 nginx가 페이지를 읽는 폴더에 붙였어요. 볼륨이 없으면 Docker가 처음에 만들어 줘요. exec로 들어가서 index.html을 바꾸고, stop과 rm으로 지워요. 세미콜론(;)은 두 명령을 한 줄에 이어 친 거예요. 같은 -v를 붙여 다시 만들면 브라우저에 KANT Cafe가 그대로 나와요. 긴 ID는 화면에 맞추려고 앞 12글자만 적었어요. 터미널 출력은 tools/demo.py로 실제 Docker를 실행한 결과예요.
