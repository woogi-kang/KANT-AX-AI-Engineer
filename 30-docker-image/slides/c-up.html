4. docker compose 맛보기

docker compose up -d로 켜고 down으로 지워요

~/cafe $ docker compose up -d

[+] up 2/2

✔ Network cafe_default Created                                             0.0s

✔ Container cafe-web-1 Started                                             0.2s

 

~/cafe $ docker compose ps

NAME         IMAGE     COMMAND                  SERVICE   CREATED        STATUS                  PORTS

cafe-web-1   nginx     "/docker-entrypoint.…"   web       1 second ago   Up Less than a second   0.0.0.0:8080->80/tcp

 

~/cafe $ docker compose down

[+] down 2/2

✔ Container cafe-web-1 Removed                                             0.2s

✔ Network cafe_default Removed                                             0.2s

-d 그대로, 뒤에서 돌아요

compose.yaml이 있는 ~/cafe 폴더에서 docker compose up -d를 쳐요. -d는 29의 docker run -d처럼 뒤에서 돌게 하는 옵션이에요. docker compose ps는 이 폴더의 compose가 띄운 컨테이너만 보여 줘요. 이름 cafe-web-1은 폴더 이름 cafe, 서비스 이름 web, 첫 번째라는 1을 이은 거예요. 브라우저에는 2파트의 메뉴 페이지가 그대로 나와요. 다 쓰면 docker compose down으로 멈추고 지워요. Network 줄은 compose가 컨테이너끼리 이어 주려고 만든 연결망인데, 이 챕터에서는 다루지 않아요. 터미널 출력은 tools/demo.py로 실제 Docker를 실행한 결과예요.
