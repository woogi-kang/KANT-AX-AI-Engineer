--rm으로 찍은 붕어빵은 목록에 늘지 않아요. 영수증처럼 찍고 끝나는 프로그램에 붙여요.

docker ps -a로 보면 docker run cart를 칠 때마다 만든 컨테이너가 Exited 상태로 쌓여 있어요. 29에서 본 것처럼 run은 매번 새 붕어빵을 찍기 때문이에요. 이름은 --name을 안 줘서 Docker가 아무렇게나 지었어요. IMAGE 칸이 글자 대신 ID인 줄은 다시 build하기 전의 옛 cart로 찍은 컨테이너예요. docker run --rm cart처럼 --rm을 붙이면 프로그램이 끝날 때 컨테이너도 같이 지워져요. 다시 ps -a를 쳐도 목록이 늘지 않았어요. 쌓인 세 개는 6파트 정리 예제에서 지워요. 터미널 출력은 tools/demo.py로 실제 Docker를 실행한 결과예요.
