2. 볼륨으로 남기기

볼륨은 컨테이너 밖에 두는 보관함이에요

컨테이너 web

실행 중

/usr/share/nginx/html

index.html

50x.html

볼륨 cafe-html

index.html

50x.html

-v cafe-html:/usr/share/nginx/html

점선 칸에 보이는 파일은
사실 볼륨에 있어요

rm으로 지워요

컨테이너 web

새로 만든 컨테이너

/usr/share/nginx/html

index.html

50x.html

새 컨테이너에 같은 볼륨을 붙이면
파일이 그대로 보여요

볼륨은 Docker가 컨테이너 밖에 따로 만들어 두는 저장 공간이에요. docker run에 -v 볼륨이름:컨테이너 안 경로를 붙이면, 그 경로에 넣는 파일이 실제로는 볼륨에 들어가요. 그래서 컨테이너를 rm으로 지워도 볼륨은 그대로 남아요. 새 컨테이너를 만들 때 같은 볼륨을 다시 붙이면 파일이 그대로 보여요. 처음 붙일 때 볼륨이 비어 있으면, Docker가 이미지 안 그 폴더의 파일(index.html, 50x.html)을 볼륨으로 복사해 줘요.
