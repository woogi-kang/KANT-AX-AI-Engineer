29에서 친 명령 그대로 nginx 컨테이너를 web이라는 이름으로 띄워요. 29 실습 뒤 nginx 이미지를 지웠다면 Unable to find image가 나오고 Docker Hub에서 다시 받아요. 이미지가 남아 있으면 이 줄 없이 바로 켜져요. 받는 줄의 숫자와 글자는 받는 날마다 달라요. 마지막 줄의 긴 글자는 컨테이너 ID예요. 앞 12글자를 기억해 두세요. 다음 장에서 다시 나와요. 브라우저로 localhost:8080을 열면 nginx 환영 페이지가 보여요. 브라우저 화면은 단순하게 그린 그림이에요. 터미널 출력은 tools/demo.py로 실제 Docker를 실행한 결과예요.
