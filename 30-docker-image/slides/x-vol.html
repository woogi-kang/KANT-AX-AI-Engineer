5. 자주 나는 오류

-v에서 ./를 빼면 폴더가 아니라 새 볼륨이 생겨요

~/cafe $ docker run -d --name web -p 8080:80 -v site:/usr/share/nginx/html nginx

be746d49b581…

 

~/cafe $ docker volume ls

DRIVER    VOLUME NAME

local     cafe-html

local     site

site라는 볼륨이 생겼어요

localhost:8080

Welcome to nginx!

If you see this page, nginx is successfully installed and working.

메뉴 대신 nginx 환영 페이지가 나와요.

-v ./site:/usr/share/nginx/html

./를 붙여 다시 만들고, 잘못 생긴 볼륨은
docker volume rm site로 지워요.

~ $ docker compose up -d

no configuration file provided: not found

yaml 없는 폴더

오류 메시지가 없는 함정이라 더 헷갈려요. -v site:처럼 ./ 없이 이름만 적으면 Docker는 site라는 볼륨을 새로 만들어 붙여요. 빈 볼륨이라 nginx의 기본 파일이 복사되고, 브라우저에는 메뉴 대신 환영 페이지가 나와요. docker volume ls로 보면 site라는 볼륨이 생겨 있어요. ./를 붙여 다시 만들고, 잘못 생긴 볼륨은 지워요. 오른쪽 아래는 compose.yaml이 없는 폴더에서 docker compose up을 쳤을 때예요. no configuration file provided가 나오면 cd cafe로 compose.yaml이 있는 폴더에 들어가요. 터미널 출력은 tools/demo.py로 실제 Docker를 실행한 결과예요.
