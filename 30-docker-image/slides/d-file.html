3. Dockerfile로 이미지 만들기

Dockerfile은 다섯 줄이에요

Dockerfile

FROM astral/uv:python3.14-bookworm-slim

WORKDIR /app

COPY . .

RUN uv sync

CMD ["uv", "run", "main.py"]

어떤 틀 위에서 시작할까 파이썬과 uv가 든 이미지

안에서 일할 폴더 없으면 만들고 cd 해요

내 파일을 넣기 지금 폴더를 /app으로

만들 때 한 번 실행 패키지 맞추기

찍을 때마다 실행 켜지면 칠 명령

파일 이름은 확장자 없이 Dockerfile, D는 대문자예요.

shopping-cart 폴더 맨 위, main.py 옆에 VS Code로 새 파일을 만들어요.

shopping-cart 폴더 맨 위에 Dockerfile이라는 새 파일을 만들어 다섯 줄을 적어요. 확장자는 없고 첫 글자 D는 대문자예요. 위에서부터 한 줄씩 읽어요. FROM은 어떤 이미지 위에서 시작할지예요. WORKDIR은 이미지 안에서 일할 폴더예요. COPY는 내 폴더의 파일을 이미지 안으로 넣어요. RUN은 이미지를 만드는 동안 한 번 실행할 명령이고, CMD는 이 이미지로 컨테이너를 찍을 때마다 실행할 명령이에요. 다음 장부터 한 줄씩 자세히 봐요.
