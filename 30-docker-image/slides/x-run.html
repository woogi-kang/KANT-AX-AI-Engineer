4. 자주 나는 오류

오류 메시지 끝부분에 원인이 적혀 있어요

~/cafe $ docker exec -it web bash

Error response from daemon: container 0828f05b4674… is not running

멈춘 컨테이너에는 못 들어가요

docker start web

~/cafe $ docker run -d --name web -p 8080:80 nginx

docker: Error response from daemon: … Bind for 0.0.0.0:8080 failed: port is already allocated

8080을 다른 컨테이너가 쓰고 있어요

docker compose down 또는 -p 8081:80

~ $ docker compose up -d

no configuration file provided: not found

compose.yaml이 없는 폴더에서 쳤어요

cd cafe

첫 번째는 stop으로 멈춘 컨테이너에 exec로 들어가려 할 때예요. is not running이 나오면 docker start로 다시 켜고 들어가요. 두 번째는 compose로 띄운 cafe-web-1이 8080을 쓰는 동안 docker run으로 8080을 또 쓰려 할 때예요. port is already allocated가 나오면 먼저 띄운 쪽을 끄거나 다른 포트를 써요. 이때 web 컨테이너는 만들어진 채 남으니 docker rm web으로 지워요. 세 번째는 compose.yaml이 없는 홈 폴더에서 docker compose up을 쳤을 때예요. no configuration file provided가 나오면 pwd로 위치를 보고 cd cafe로 들어가요. 긴 ID와 설명은 …로 줄였어요. 터미널 출력은 tools/demo.py로 실제 Docker를 실행한 결과예요.
