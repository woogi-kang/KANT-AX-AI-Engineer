5. 자주 나는 오류

run과 exec 오류는 원인이 한 줄에 다 적혀 있어요

~/shopping-cart $ docker run --rm cart

error: Failed to spawn: `mian.py`

 Caused by: No such file or directory (os error 2)

CMD의 파일 이름 오타 (mian.py)

Dockerfile 고치고 다시 build

~/cafe $ docker exec -it web bash

Error response from daemon: container b0ed4b95660e… is not running

멈춘 컨테이너에는 못 들어가요

docker start web

~/cafe $ docker run -d --name web -p 8080:80 nginx

docker: Error response from daemon: … Bind for 0.0.0.0:8080 failed: port is already allocated

8080을 다른 컨테이너가 쓰고 있어요

docker compose down 또는 -p 8081:80

첫 번째는 CMD에 main.py를 mian.py로 잘못 적고 build한 이미지를 run 했을 때예요. uv가 mian.py라는 파일을 못 찾아요. Dockerfile을 고치고 build부터 다시 해요. 두 번째는 stop으로 멈춘 컨테이너에 exec로 들어가려 할 때예요. is not running이 나오면 docker start로 다시 켜고 들어가요. 세 번째는 compose로 띄운 cafe-web-1이 8080을 쓰는 동안 docker run으로 8080을 또 쓰려 할 때예요. port is already allocated가 나오면 먼저 띄운 쪽을 끄거나 다른 포트를 써요. 이때 web 컨테이너는 만들어진 채 남으니 docker rm web으로 지워요. 첫 번째 출력은 cart-typo라는 이름으로 만든 이미지에서 옮겼고, 두 번째와 세 번째의 긴 ID와 설명은 …로 줄였어요. 터미널 출력은 tools/demo.py로 실제 Docker를 실행한 결과예요.
