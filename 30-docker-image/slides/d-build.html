끝나면 FINISHED

이름이 cart

shopping-cart 폴더에서 docker build -t cart .를 쳐요. -t cart는 만들 이미지에 cart라는 이름을 붙이는 옵션이에요. 맨 끝의 점은 재료가 있는 폴더, 곧 지금 폴더예요. 점을 빼먹으면 오류가 나요. 출력의 [1/4]부터 [4/4]가 Dockerfile의 FROM, WORKDIR, COPY, RUN 줄이에요. CMD는 적어만 두는 줄이라 단계에 없어요. 처음에는 FROM의 astral/uv 이미지를 받느라 시간이 조금 걸려요. => => 로 시작하는 세부 줄은 빼고 옮겼어요. 숫자와 시간은 컴퓨터마다 달라요. 터미널 출력은 tools/demo.py로 실제 Docker를 실행한 결과예요.
