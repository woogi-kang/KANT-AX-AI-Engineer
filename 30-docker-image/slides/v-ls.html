2. 볼륨으로 남기기

docker volume ls로 남아 있는 볼륨을 봐요

~/cafe $ docker volume ls

DRIVER    VOLUME NAME

local     cafe-html

-v에 적은 이름

docker volume ls

볼륨 목록 보기

docker volume rm 이름

볼륨 지우기 (붙은 컨테이너를 먼저 지워요)

Docker Desktop 왼쪽
Volumes 메뉴에서도 보여요.

docker volume ls는 지금 남아 있는 볼륨 목록이에요. 앞 장에서 -v에 적은 cafe-html이 보여요. DRIVER의 local은 내 컴퓨터 안에 저장한다는 뜻이에요. 컨테이너를 지워도 볼륨은 남으니, 안 쓰는 볼륨은 docker volume rm 이름으로 지워요. 컨테이너가 붙어 있으면 지울 수 없어서 컨테이너부터 지워요. 29처럼 Docker Desktop 화면의 Volumes 메뉴에서도 확인할 수 있어요. 명령은 터미널에서 쳐요. 터미널 출력은 tools/demo.py로 실제 Docker를 실행한 결과예요.
