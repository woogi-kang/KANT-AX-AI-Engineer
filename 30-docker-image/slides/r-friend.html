친구 컴퓨터에 없어도 되는 것

python

이미지 안에 있어요

uv

이미지 안에 있어요

.venv

build할 때 만들어요

Dockerfile과 .dockerignore도 코드처럼 커밋해서 GitHub에 올려요. 02에서 배운 대로 git add 파일, git commit -m, git push origin main 순서예요. 친구는 clone하고 폴더에 들어가 docker build와 docker run 두 줄만 치면 같은 영수증을 봐요. 친구 컴퓨터에 파이썬도 uv도 없어도 돼요. .venv는 .gitignore에 있어서 GitHub에 안 올라가고, build할 때 이미지 안에서 새로 만들어져요. 레포 주소는 예시라 kim 자리에 내 아이디를 적어요. clone 출력은 02와 같아서 빼고, build 출력은 앞에서 봤으니 줄였어요. 터미널 출력은 tools/demo.py로 실제 Docker를 실행한 결과예요.
