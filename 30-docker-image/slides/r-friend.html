compose.yaml과 site 폴더를 코드처럼 커밋해서 GitHub에 올려요. 02에서 배운 대로 git add 파일, git commit -m, git push origin main 순서예요. 친구는 clone하고 폴더에 들어가 docker compose up -d 한 줄만 치면 같은 메뉴판을 봐요. 친구 컴퓨터에 nginx 이미지가 없으면 Image nginx Pulled 줄처럼 Docker Hub에서 먼저 받아요. 친구는 docker run 옵션을 몰라도 돼요. compose.yaml에 다 적혀 있어요. 레포 주소는 예시라 kim 자리에 내 아이디를 적어요. clone 출력은 02와 같아서 뺐어요. 터미널 출력은 tools/demo.py로 실제 Docker를 실행한 결과예요.
