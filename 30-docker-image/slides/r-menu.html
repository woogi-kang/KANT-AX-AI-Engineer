2파트와 3파트를 합친 예제예요. 카페 메뉴판 페이지를 띄워 두고 메뉴를 고쳐 봐요. ~/cafe 폴더에서 docker compose up -d로 켜요. compose.yaml에 ./site 폴더 연결을 적어 뒀으니, VS Code에서 site/index.html에 메뉴 한 줄을 더하고 저장해요. 브라우저를 새로 고치면 바로 보여요. 컨테이너를 다시 만들 필요가 없어요. 다 쓰면 docker compose down으로 지워요. site 폴더는 내 폴더라 지워지지 않아요. 직접 메뉴를 하나 더 넣어 보세요.
