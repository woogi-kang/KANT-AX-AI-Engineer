실습 폴더 하나를 준비해요

~ $ mkdir cafe

~ $ cd cafe

~/cafe $ mkdir site

오늘 실습은 모두 이 폴더에서

~/

cafe/

site/

Windows Git Bash는 새 창을 열 때마다 이 줄을 먼저 쳐요.

~ $ export MSYS_NO_PATHCONV=1

Git Bash가 /usr/share 같은 컨테이너 경로를
Windows 경로로 바꿔 버리는 것을 막아요.

Mac은 치지 않아도 돼요

홈 폴더에 cafe 폴더와 그 안의 site 폴더를 만들어요. 오늘 실습은 모두 cafe 폴더에서 nginx 웹 페이지를 띄우면서 해요. site 폴더는 2파트에서 내 웹 페이지 파일을 넣을 곳이에요. Windows의 Git Bash는 /로 시작하는 글자를 Windows 경로로 바꾸는 버릇이 있어요. 오늘은 -v 뒤에 컨테이너 안 경로를 적으니, 새 Git Bash 창을 열 때마다 export MSYS_NO_PATHCONV=1을 먼저 쳐요. Mac은 치지 않아도 돼요.
