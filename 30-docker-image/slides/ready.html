Windows Git Bash는 새 창을 열 때마다 이 줄을 먼저 쳐요.

~ $ export MSYS_NO_PATHCONV=1

Git Bash가 /usr/share 같은 컨테이너 경로를
Windows 경로로 바꿔 버리는 것을 막아요.

실습 폴더는 두 개예요. 홈 폴더에 cafe 폴더와 그 안의 site 폴더를 만들어요. 1, 2, 4파트에서 nginx 웹 페이지를 띄울 때 써요. 3파트는 28에서 만든 shopping-cart 폴더를 그대로 써요. main.py가 28 마지막 실습의 주문 코드인지 확인해요. Windows의 Git Bash는 /로 시작하는 글자를 Windows 경로로 바꾸는 버릇이 있어요. 오늘은 -v 뒤에 컨테이너 안 경로를 적으니, 새 Git Bash 창을 열 때마다 export MSYS_NO_PATHCONV=1을 먼저 쳐요. Mac은 치지 않아도 돼요. 터미널 출력은 tools/demo.py로 실제 Docker를 실행한 결과예요.
