28에서 친 명령과 비교

uv run main.py

내 컴퓨터의 파이썬과 uv로

docker run cart

이미지 안의 파이썬과 uv로

출력이 한 글자도 다르지 않아요.

docker images로 보면 cart:latest가 생겼어요. 태그를 안 적으면 latest가 붙는 건 29와 같아요. 이제 docker run cart를 치면 CMD에 적은 uv run main.py가 컨테이너 안에서 실행되고 28 실습의 영수증이 그대로 나와요. nginx처럼 계속 도는 프로그램이 아니라 영수증을 찍고 끝나는 프로그램이라 -d와 -p는 붙이지 않아요. 내 컴퓨터에서 uv run main.py를 친 결과와 비교해 보세요. 출력이 똑같아요. 다른 점은 파이썬과 uv가 내 컴퓨터가 아니라 이미지 안에 있다는 것뿐이에요. 터미널 출력은 tools/demo.py로 실제 Docker를 실행한 결과예요.
