돌면서 같은 리스트를 지우면 하나를 놓쳐요

[1]

orders = ["tea", "tea", "coffee", "tea", "cake"]

for o in orders:

if o == "tea":

orders.remove(o)

print(orders)

[2]

orders = ["tea", "tea", "coffee", "tea", "cake"]

keep = []

for o in orders:

if o != "tea":

keep.append(o)

print(keep)

Python

['coffee', 'cake']

← 남길 것만 새 리스트에 (17의 골라 담기)

돌고 있는 리스트는 지우지 않아요. 새 리스트에 모아요.

돌고 있는 리스트를 지우면 당겨진 값을 건너뛰어서 하나를 놓쳐요. 주문에서 tea를 모두 지우려고 돌면서 remove했어요. 그런데 tea 하나가 남았어요. 0번 tea를 지우면 뒤의 값이 한 칸씩 앞으로 당겨져서 둘째 tea가 0번 자리로 와요. for는 이미 0번을 봤으니 다음 차례인 1번으로 넘어가요. 오류가 나지 않아서 놓치기 쉬워요. 원래 리스트는 그대로 두고 남길 것만 새 리스트에 모아요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
