6. 함정과 실습

들여쓰기 한 단계 차이로 결과가 달라져요

[3]

total = 0

for p in [4500, 5000, 6500]:

total += p

print(total)

Python

4500

9500

16000

print가 for 안

돌 때마다 찍어요

[4]

total = 0

for p in [4500, 5000, 6500]:

total += p

print(total)

Python

16000

print가 for 밖

다 돈 뒤 한 번

[5]

for p in [4500, 5000, 6500]:

total = 0

total += p

print(total)

Python

6500

total = 0이 for 안

돌 때마다 0으로 돌아가요

쌓을 변수는 for 위에서 0으로, 결과는 for 아래에서 찍어요.

들여쓰기 한 단계 차이로 결과가 달라지고, 셋 다 오류는 나지 않아요. 첫째는 print가 for 안이라 돌 때마다 지금까지의 합계를 찍어요. 둘째는 print를 for 밖으로 뺐어요. 다 돈 뒤에 16000을 한 번만 찍어요. 셋째는 total = 0을 for 안에 넣었어요. 돌 때마다 0으로 돌아가서 마지막 가격 6500만 남아요. 오류가 없어서 결과를 보고 찾아야 해요. 쌓을 변수는 반복 위, 결과는 반복 아래가 기본이에요. 출력은 실제로 실행한 결과예요.
