4. break와 continue

while True와 break로 "될 때까지" 돌아요

[5]

left = 3

n = 0

while True:

if left == 0:

print("재고가 떨어졌어요")

break

left -= 1

n += 1

print(f"{n}번째 주문, 남은 재고 {left}")

Python

1번째 주문, 남은 재고 2

2번째 주문, 남은 재고 1

3번째 주문, 남은 재고 0

재고가 떨어졌어요

← 늘 True라 스스로는 끝나지 않아요

여기로만 나가요

← 재고가 0이 되면 나가요

while True:를 쓰면 break가 나가는 문이에요.

while True:는 조건이 늘 True라서 안쪽의 break가 유일한 출구예요. 재고가 0이 되면 재고가 떨어졌어요를 찍고 break로 나가요. 화살표가 가리키는 마지막 줄 아래, 반복 밖으로 나가요. while left > 0으로도 쓸 수 있어요. 멈출 조건을 반복 중간에 확인하고 싶을 때나, 맞힐 때까지처럼 끝을 미리 정하기 어려울 때 이 모양을 써요. break를 빼먹으면 3파트의 무한 반복이 되니 꼭 확인해요. 출력은 실제로 실행한 결과예요.
