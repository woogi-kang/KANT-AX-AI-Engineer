3. while

while은 묻기, 실행, 값 바꾸기를 돌아요

[1]

count = 1

while count <= 3:

print(f"{count}번째")

count += 1

print("끝, count는", count)

Python

1번째

2번째

3번째

끝, count는 4

← ① 시작값

← ② 묻기

← ③ 실행

← ④ 값 바꾸기

← 4 <= 3이 False라서 멈춘 뒤의 값

while에는 시작값, 조건, 값 바꾸기 세 가지가 꼭 있어야 해요.

while에는 시작값, 조건, 값 바꾸기 세 가지가 꼭 있어야 해요. 먼저 반복 전에 시작값을 정해요. count는 1이에요. 다음으로 조건을 물어요. True면 들여쓴 줄을 실행해요. 마지막 줄에서 count에 1을 더해 값을 바꿔요. 그리고 화살표처럼 다시 조건으로 돌아가 물어요. 4가 되면 4 <= 3이 False라서 반복을 끝내요. 끝난 뒤에도 count는 4로 남아 있어요. 셋 중 하나라도 빠지면 반복이 아예 안 돌거나 끝나지 않아요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
