언제 continue가 편한가요

건너뛸 경우를 맨 위에서 먼저 걸러 두면 아래 줄을 else 안에 넣지 않아도 돼요. 아래 할 일이 길수록 들여쓰기 한 단계가 줄어서 읽기 쉬워요.

continue는 "이 경우는 빼고"를 맨 위에 적는 방법이에요.

continue 없이 17의 if, else로 써도 결과가 같아요. 품절이면 건너뛴다고 찍고, 아니면 else에서 주문을 받아요. 오른쪽은 셀 [2]의 continue 버전이에요. 차이는 모양이에요. continue는 건너뛸 경우를 맨 위에서 걸러 내서, 아래 할 일을 else 안에 넣지 않아도 돼요. 주문 받기가 여러 줄로 길어지면 들여쓰기가 한 단계 얕아서 읽기 쉬워요. 처음에는 if, else로 적어도 괜찮아요. 출력은 실제로 실행한 결과예요.
