scores = [[90, 85, 77],

[70, 95, 88],

[60, 75, 99]]

for i in range(len(scores)):

for j in range(len(scores[i])):

if scores[i][j] < 70:

print(f"{i}행 {j}열: {scores[i][j]}점")

2차원 리스트는 바깥 for가 행, 안쪽 for가 열이에요.

2차원 리스트는 바깥 for가 행 번호, 안쪽 for가 열 번호를 돌아요. 14에서는 for row in scores로 행을 통째로 꺼냈어요. 이번에는 번호도 알고 싶어서 range(len())을 두 번 겹쳤어요. 안쪽 길이는 그 행의 길이 len(scores[i])예요. 70점 아래인 칸을 찾으면 몇 행 몇 열인지 찍어요. 2행 0열의 60점 하나예요. 14에서 본 [행][열] 순서 그대로예요. 출력은 실제로 실행한 결과예요.
