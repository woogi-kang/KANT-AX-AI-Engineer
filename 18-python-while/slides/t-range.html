range(len())에 1을 더하면 칸을 넘어가요

[6]

menus = ["coffee", "latte", "cake"]

for i in range(len(menus) + 1):

print(menus[i])

latte

3번 없음

번호는 0부터 len - 1까지

menus는 3칸이라 번호는 0, 1, 2예요. range(len(menus))가 딱 맞아요. + 1을 하면 없는 3번 칸을 꺼내다 오류가 나요.

1부터 5까지는 range(1, 6)

range(1, 5)는 4에서 끝나요. 끝 숫자는 늘 빠져요.

IndexError가 나면 range의 끝 숫자부터 봐요.

마지막 칸까지 꼭 돌고 싶어서 len에 1을 더하는 실수를 자주 해요. menus는 3칸이라 번호는 0, 1, 2이고 len은 3이에요. range(3)이 이미 0, 1, 2라서 딱 맞아요. 1을 더하면 3번 칸을 꺼내려다 IndexError가 나요. 오류가 나기 전까지 coffee, latte, cake는 찍혀요. 반대로 1부터 5까지 돌고 싶은데 range(1, 5)라고 적으면 4에서 끝나요. 끝 숫자는 늘 빠진다는 2파트의 규칙을 떠올려요. 출력은 실제로 실행한 결과예요.
