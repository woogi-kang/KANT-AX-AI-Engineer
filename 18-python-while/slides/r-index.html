2. range와 번호

번호와 값을 같이 쓰려면 range(len())

[4]

menus = ["coffee", "latte", "cake"]

for i in range(len(menus)):

print(i, menus[i])

Python

0 coffee

1 latte

2 cake

[5]

i = 0

for m in menus:

print(i, m)

i += 1

Python

0 coffee

1 latte

2 cake

3

len(menus)

0, 1, 2

range(3)

번호로 꺼내기

menus[i]

번호로 값을 꺼내요

i가 번호라서 값은 13처럼 menus[i]로 꺼내요. 리스트 길이가 바뀌어도 len이 맞춰 줘요.

아래는 번호를 직접 세는 방법

i를 0에서 시작해 돌 때마다 1씩 더해요.

번호가 필요하면 range(len(리스트))로 돌고 [i]로 꺼내요.

값과 함께 몇 번째인지도 필요할 때가 있어요. range(len(menus))는 range(3)이라 0, 1, 2를 돌아요. i가 번호라서 값은 menus[i]로 꺼내요. 아래 셀은 같은 일을 번호를 직접 세며 한 거예요. i를 0으로 두고 한 번 돌 때마다 1을 더해요. 두 방법 다 결과가 같아요. 다음 장에서 이 둘을 한 줄로 줄인 enumerate를 봐요. 출력은 실제로 실행한 결과예요.
