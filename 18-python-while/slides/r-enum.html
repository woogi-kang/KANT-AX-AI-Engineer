2. range와 번호

enumerate는 번호와 값을 한 쌍씩 줘요

[6]

for i, m in enumerate(menus):

print(i, m)

for i, m in enumerate(menus, 1):

print(f"{i}. {m}")

Python

0 coffee

1 latte

2 cake

1. coffee

2. latte

3. cake

← 번호는 i, 값은 m에

← 둘째 자리 1: 번호를 1부터

[7]

print(list(enumerate(menus)))

Python

[(0, 'coffee'), (1, 'latte'), (2, 'cake')]

← (번호, 값) 튜플

같은 결과, 세 가지 모양

enumerate(menus)

줄인 방법

range(len(menus))

앞 장

i = 0 … i += 1

직접 세기

번호와 값이 둘 다 필요하면 enumerate를 써요.

enumerate는 번호와 값을 한 쌍씩 줘요. 앞 장의 두 방법을 한 줄로 줄인 모양이에요. list()로 찍어 보면 (번호, 값) 튜플의 리스트예요. 그래서 13에서 튜플 리스트를 돌 때처럼 for i, m in으로 두 이름에 나눠 담아요. 괄호 안 둘째 자리에 1을 넣으면 번호가 1부터 시작해서 메뉴판 번호를 찍기 좋아요. 처음에는 range(len())이 이해하기 쉽고, 익숙해지면 enumerate를 써요. 출력은 실제로 실행한 결과예요.
