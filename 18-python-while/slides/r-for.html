리스트 대신 range를 넣어요

13에서는 for o in orders처럼 리스트를 돌았어요. range(3)을 넣으면 0, 1, 2를 하나씩 i에 넣어요. 그래서 세 번 돌아요.

사람에게 보일 번호는 1부터

range(1, 4)로 1, 2, 3을 만들어요. i + 1로 적어도 돼요.

i는 그냥 이름이에요

번호(index)의 앞 글자 i를 많이 써요. n, k로 적어도 돼요.

"n번 반복"은 for i in range(n): 이에요.

for 뒤에 리스트 대신 range를 넣으면 정한 횟수만큼 돌아요. range(3)은 0, 1, 2라서 세 번 돌고, i에는 차례로 0, 1, 2가 들어가요. 손님 번호처럼 사람에게 보일 번호는 1부터 세는 게 자연스러워서 range(1, 4)로 1, 2, 3을 만들어요. i는 정해진 이름이 아니에요. 번호라는 뜻의 index 앞 글자를 관례로 많이 써요. 1파트의 [1, 2, 3] 리스트도 range(1, 4)로 바꿔 쓸 수 있어요. 출력은 실제로 실행한 결과예요.
