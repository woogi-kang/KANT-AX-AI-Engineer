숫자 맞히기, 맞히면 멈춰요

[11]

answer = 37

guesses = [50, 25, 37, 40]

tries = 0

for g in guesses:

tries += 1

if g == answer:

print(f"{g}: 정답이에요. {tries}번 만에 맞혔어요")

break

elif g > answer:

print(f"{g}: 더 작아요")

else:

print(f"{g}: 더 커요")

25: 더 커요

안 봄

guesses를 바꾸면 끝까지 못 맞히고 힌트만 찍혀요.

17의 elif로 힌트를 주고, 맞히면 break로 끝내요. 입력은 아직 배우지 않아서 추측을 리스트에 미리 적었어요. 추측마다 시도 횟수를 1 늘리고 17의 if, elif, else로 비교해요. 같으면 정답이라고 찍고 break해요. 크면 더 작다, 작으면 더 크다고 힌트를 줘요. 셋째 추측 37에서 맞혀서 넷째 40은 보지 않아요. guesses를 [10, 90, 50]처럼 바꿔 끝까지 못 맞히는 경우도 실행해 봐요. 출력은 실제로 실행한 결과예요.
