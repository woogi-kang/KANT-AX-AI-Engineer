[3]

stock = 0

while stock > 0:

stock -= 1

print("주문 받았어요")

print("품절이에요")

Python

품절이에요

← 처음부터 0 > 0은 False

← 한 번도 실행하지 않아요

조건은 반복할 때마다 처음에 물어요.

while은 들여쓴 줄을 실행하기 전에 매번 조건부터 물어요. 재고 3개에서 시작해 주문을 받을 때마다 하나씩 줄여요. 오른쪽 표처럼 3, 2, 1일 때는 조건이 True라서 주문을 받아요. 0이 되면 0 > 0이 False라서 반복을 끝내고 품절이에요를 찍어요. 아래 셀은 재고가 처음부터 0이에요. 조건을 처음 물을 때 이미 False라서 들여쓴 줄은 한 번도 실행하지 않아요. 출력은 실제로 실행한 결과예요.
