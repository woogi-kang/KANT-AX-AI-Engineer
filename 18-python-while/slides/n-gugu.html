5. 쌓기와 겹친 반복

반복 안에 반복을 넣으면 표를 만들어요

[5]

for dan in range(2, 4):

for i in range(1, 4):

print(f"{dan} x {i} = {dan * i}")

print("---")

바깥이 한 번 돌 때 안쪽은 세 번

← 4칸, 단마다 한 번

바깥 2번 × 안쪽 3번 = 모두 6번 실행해요.

반복 안에 반복을 넣으면 바깥이 한 번 돌 때 안쪽이 처음부터 끝까지 돌아요. 17에서 if 안에 if를 넣은 것과 같아요. 바깥 for가 dan에 2를 넣으면 안쪽 for가 i를 1, 2, 3까지 다 돌아요. 그다음에 바깥이 3으로 바뀌고 안쪽이 다시 처음부터 돌아요. 시계의 시침이 한 칸 갈 때 분침이 한 바퀴 도는 것과 같아요. 그래서 2 곱하기 3, 모두 6줄이 찍혀요. 안쪽 print는 8칸, 바깥의 대시 줄은 4칸 들여써서 단마다 한 번씩 찍혀요. 출력은 실제로 실행한 결과예요.
