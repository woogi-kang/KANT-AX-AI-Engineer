4. break와 continue

break는 반복을 그 자리에서 끝내요

[1]

orders = ["coffee", "cake", "latte", "tea", "cake"]

soldout = ["latte"]

for o in orders:

if o in soldout:

print(f"{o} 품절, 주문을 멈춰요")

break

print(f"{o} 주문 받았어요")

print("끝")

break는 "여기서 그만". 남은 차례를 버리고 반복 아래 줄로 가요.

break를 만나면 반복을 그 자리에서 끝내고 반복 아래 줄로 가요. 주문 리스트를 하나씩 받다가 품절 메뉴를 만나면 그만 받아요. orders에 다섯 주문이 있고, latte가 품절이에요. coffee와 cake는 품절이 아니라 주문 받았어요를 찍어요. latte에서 if가 True고, 품절이라고 찍은 뒤 break를 만나요. break는 빨간 화살표처럼 for 밖의 다음 줄, print 끝으로 가요. 뒤에 남은 tea와 cake는 보지도 않아요. break 아래의 주문 받았어요 줄도 실행하지 않아요. break를 if 없이 쓰면 첫 주문에서 바로 끝나서, 멈출 때를 if로 적어요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
