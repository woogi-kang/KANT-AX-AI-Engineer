for i in range(1, 6):

if i == 3:

break

print(i)

print("---")

for i in range(1, 6):

if i == 3:

continue

print(i)

break는 반복 전체를 끝내고, continue는 한 차례만 넘겨요.

1부터 5까지 돌면서 3에서 break와 continue를 써 봐요. break는 3을 만나면 반복을 끝내서 1, 2만 찍혀요. 4와 5는 돌지도 않아요. continue는 3일 때 아래 print만 건너뛰고 4로 넘어가서 1, 2, 4, 5가 찍혀요. 둘 다 if 안에 두는 게 보통이에요. 헷갈리면 이 그림의 회색 칸과 빨간 칸을 떠올려요. 출력은 실제로 실행한 결과예요.
