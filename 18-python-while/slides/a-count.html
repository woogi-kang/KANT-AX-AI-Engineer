← 모은 리스트의 len이 개수

세기는 n += 1, 모으기는 append예요. 둘 다 if 안에 둬요.

조건에 맞는 것은 if 안에서 n += 1로 세거나 append로 모아요. 가격이 5000원 이상인 메뉴가 몇 개인지 세요. n을 0으로 두고 조건이 True일 때만 1을 더해요. 5000과 6500, 두 개예요. 아래 줄의 13의 count는 5000과 같은 값 하나만 세서 1이 나와요. count는 5000 이상처럼 범위가 붙은 조건에는 못 써요. 오른쪽은 같은 조건으로 값을 모은 거예요. 17의 골라 담기 모양이에요. 모은 리스트의 len을 보면 개수도 알 수 있어요. 값도 필요하면 모으고, 개수만 필요하면 세요. 출력은 실제로 실행한 결과예요.
