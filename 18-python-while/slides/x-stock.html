재고가 모자랄 때까지 주문을 받아요

[8]

stock = 5

orders = [2, 1, 3, 1]

sold = 0

i = 0

while i < len(orders):

want = orders[i]

if want > stock:

print(f"{i + 1}번 손님 {want}잔: 재고가 {stock}잔뿐이에요")

break

stock -= want

sold += want

print(f"{i + 1}번 손님 {want}잔, 남은 재고 {stock}")

i += 1

print(f"판매 {sold}잔, 남은 재고 {stock}")

배운 것을 섞었어요

while과 번호 i로 손님을 차례로 받아요. if로 재고를 확인하고, 모자라면 break해요. 번호 i는 0부터라 손님에게는 i + 1로 보여 줘요.

멈출 조건이 두 개면 하나는 while에, 하나는 if와 break로 적어요.

재고 5잔으로 손님 주문을 차례로 받아요. 손님이 원하는 잔 수는 orders 리스트에 있어요. while은 i가 손님 수보다 작은 동안 돌아요. 손님마다 원하는 잔 수가 재고보다 많으면 재고가 모자란다고 알리고 break해요. 아니면 재고에서 빼고 판매에 더하고, i를 1 늘려 다음 손님으로 가요. 3번 손님은 3잔을 원하는데 2잔뿐이라 멈춰요. 멈추는 이유가 두 가지라서 하나는 while 조건에, 하나는 if와 break로 적었어요. 출력은 실제로 실행한 결과예요.
