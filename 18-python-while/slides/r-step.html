2. range와 번호

시작, 끝, 간격을 정할 수 있어요

[2]

print(list(range(1, 6)))

print(list(range(0, 10, 2)))

print(list(range(5, 0, -1)))

print(list(range(3, 3)))

Python

[1, 2, 3, 4, 5]

[0, 2, 4, 6, 8]

[5, 4, 3, 2, 1]

[]

← 1부터 6 앞까지

← 0부터 2씩 건너뛰기

← 간격 -1이면 거꾸로, 0 앞까지

← 시작과 끝이 같으면 비어요

range(시작, 끝, 간격)

끝은 늘 빠져요

13의 자르기 [시작:끝:간격]과 같은 순서

1부터 5까지는 range(1, 6)이에요.

range는 시작, 끝, 간격 순서로 숫자를 받아요. 숫자를 두 개 넣으면 시작과 끝이에요. range(1, 6)은 1부터 6 바로 앞인 5까지예요. 세 개를 넣으면 셋째가 간격이에요. range(0, 10, 2)는 0부터 2씩 건너뛰어 짝수만 나와요. 간격을 -1로 하면 거꾸로 세요. 이때는 시작 5가 끝 0보다 커야 해요. 시작과 끝이 같으면 빈 줄이에요. 13의 자르기 [시작:끝:간격]과 순서도, 끝이 빠지는 규칙도 같아요. 출력은 실제로 실행한 결과예요.
