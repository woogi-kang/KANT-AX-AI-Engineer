5. 자주 나는 오류

켜지자마자 들어가면 아직 준비 중이라 접속이 안 돼요

~ $ docker run -d --name db -e MYSQL_ROOT_PASSWORD=cafe1234 -e MYSQL_DATABASE=cafe -p 3306:3306 mysql:8.4

f761cbba159d…

~ $ docker exec -it db mysql -u root -p

Enter password:

ERROR 2002 (HY000): Can't connect to local MySQL server through socket '/var/run/mysqld/mysqld.sock' (2)

ERROR 2002는 MySQL 서버를 못 찾았다는 뜻이에요. 처음 켤 때 10초쯤 준비하는 동안 나와요.

docker logs db에서 마지막 ready for connections 줄에 port: 3306이 보일 때 다시 들어가요.

port: 3306

port: 0이 나온 줄은 임시 서버라서 아직이에요.

켜지자마자 들어가면 아직 준비 중이라 접속이 안 돼요. docker run 바로 뒤에 docker exec로 들어가면 ERROR 2002가 나와요. 컨테이너 안의 MySQL 서버를 찾지 못했다는 뜻이에요. 1파트에서 본 것처럼 처음 켤 때는 데이터 파일을 만들고 임시 서버로 준비하느라 10초쯤 걸려요. 그동안에는 서버가 없거나 꺼졌다 켜지는 중이에요. docker logs db를 보고 port: 3306이 찍힌 줄이 나오면 다시 들어가요. port: 0이 나온 줄은 임시 서버라서 아직이에요. 볼륨에 이미 데이터가 있으면 준비가 짧아서 몇 초면 돼요. 터미널 출력은 tools/demo.py로 실제 Docker와 MySQL을 실행한 결과예요.
