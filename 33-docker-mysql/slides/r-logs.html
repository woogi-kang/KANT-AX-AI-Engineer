1  데이터 파일을 만들어요

2  잠깐 켠 임시 서버(port: 0)로 cafe를 만들어요

3  진짜 서버를 3306번 포트로 켜요

처음 켤 때는 10초쯤 걸려요. 그 전에 들어가면 오류가 나요. 5파트에서 봐요.

docker logs에 port: 3306이 찍히면 다 켜진 거예요. MySQL은 처음 켤 때 할 일이 많아서 기록이 길어요. 크게 세 단계예요. 먼저 데이터 파일을 만들어요. 다음에 밖에서 못 들어오는 임시 서버를 잠깐 켜서 비밀번호를 정하고 cafe 데이터베이스를 만들어요. 그래서 ready for connections가 port: 0으로 한 번 나와요. 마지막으로 진짜 서버를 3306번 포트로 켜요. 마지막 줄에 port: 3306이 보이면 들어가도 돼요. 처음에는 10초쯤 걸려요. 줄이 길어서 앞의 시각과 중간 줄을 …로 줄였어요. 터미널 출력은 tools/demo.py로 실제 Docker와 MySQL을 실행한 결과예요.
