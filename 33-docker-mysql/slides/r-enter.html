1. MySQL 컨테이너 켜기

docker exec -it로 컨테이너 안의 mysql 프로그램에 들어가요

~ $ docker exec -it db mysql -u root -p

Enter password:

Welcome to the MySQL monitor.  Commands end with ; or \g.

…

Server version: 8.4.13 MySQL Community Server - GPL

…

mysql> exit

Bye

~ $  

cafe1234를 쳐요. 화면에 안 보여요

SQL을 칠 차례예요

내 터미널로 돌아왔어요

30에서는

exec -it web bash

오늘은

exec -it db mysql

bash 대신 MySQL에 접속하는 프로그램 mysql을 열어요.

-u root -p

-u는 사용자 이름, -p는 비밀번호를 물어보라는 뜻이에요.

docker exec -it로 컨테이너 안의 mysql 프로그램에 들어가요. 30에서는 bash를 열었는데, 이번에는 MySQL에 접속하는 프로그램 mysql을 열어요. -u root는 관리자 root로 들어간다는 뜻이고, -p는 비밀번호를 물어보라는 뜻이에요. Enter password:가 나오면 cafe1234를 치고 Enter를 눌러요. 비밀번호는 쳐도 화면에 아무것도 안 보이는 게 정상이에요. 환영 문구가 나오고 mysql> 표시가 보이면 SQL을 칠 차례예요. exit를 치면 Bye가 나오고 내 터미널로 돌아와요. 컨테이너는 계속 돌고 있어요. 환영 문구의 저작권 안내 줄은 …로 줄였어요. 터미널 출력은 tools/demo.py로 실제 Docker와 MySQL을 실행한 결과예요.
