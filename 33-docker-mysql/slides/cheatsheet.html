한 장 요약

켜고 들어가기

-e MYSQL_ROOT_PASSWORD=…

비밀번호 · 꼭

-e MYSQL_DATABASE=cafe

처음 만들 데이터베이스

docker logs db

port: 3306이면 준비 끝

docker exec -it db mysql -u root -p cafe

접속, 나올 땐 exit

SQL

CREATE DATABASE shop; · USE shop;

데이터베이스 만들고 들어가기

CREATE TABLE 표 (열 타입, …);

빈 표 · SHOW TABLES, DESCRIBE로 확인

INSERT INTO 표 VALUES (…);

행 넣기 · SELECT로 꺼내기

DROP TABLE 표; · DROP DATABASE 이름;

지우기 · 되돌릴 수 없어요

남기기

-v cafe-data:/var/lib/mysql

지워도 남는 표

compose.yaml environment

-e 자리

docker compose down

볼륨은 남겨요

docker compose down -v

볼륨까지 지워요 · 연습할 때만

데이터베이스는 이미지 하나, 환경 변수 몇 개, 볼륨 하나로 켜고 지켜요.

34에서는 같은 순서로 PostgreSQL을 켜고 둘을 비교해요.

오늘 쓴 것을 세 묶음으로 모았어요. MySQL 컨테이너는 -e로 비밀번호와 데이터베이스 이름을 건네서 켜고, logs에서 port: 3306을 확인한 뒤 exec로 들어가요. SQL은 CREATE DATABASE와 USE로 데이터베이스를 만들고 들어갔어요. CREATE TABLE로 표를 만들고 SHOW TABLES와 DESCRIBE로 확인했어요. INSERT로 넣고 SELECT로 꺼내고, DROP으로 지웠어요. 앱에는 MYSQL_USER로 만든 계정을 줘요. 데이터를 남기려면 /var/lib/mysql에 이름 있는 볼륨을 붙이고, compose.yaml에 적어 두면 껐다 켜도 이어져요. 34에서는 같은 순서로 PostgreSQL을 켜 봐요.
