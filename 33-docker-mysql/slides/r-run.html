-e 두 개만 새로 나왔어요. 다음 장에서 봐요.

docker run 한 줄로 MySQL 서버를 켜요. 길어 보이지만 대부분 29에서 배운 옵션이에요. -d로 뒤에서 켜고, --name으로 이름을 db로 붙이고, -p로 포트를 열어요. MySQL은 3306번 포트에서 접속을 기다려서 3306:3306으로 열어요. 오늘은 컨테이너 안에서 접속해서 -p가 없어도 되지만, 나중에 내 컴퓨터의 파이썬 앱이 붙을 때 필요해서 미리 열어 둬요. 새로 나온 건 -e 두 개예요. MYSQL_ROOT_PASSWORD는 관리자 root의 비밀번호, MYSQL_DATABASE는 처음 켤 때 만들 데이터베이스 이름이에요. 앱이 쓸 계정을 만드는 -e 두 개는 3파트에서 더해요. 터미널에는 긴 컨테이너 ID 한 줄만 나와요. 터미널 출력은 tools의 demo 스크립트로 실제 Docker와 MySQL을 실행한 결과예요.
