5. 자주 나는 오류

3306번을 이미 쓰고 있으면 3307:3306으로 바꿔요

~ $ docker run -d --name db2 -e MYSQL_ROOT_PASSWORD=x -p 3306:3306 mysql:8.4

dd81d7a75daafa42dd5a3510f000873f04ce51e574ba75bb7220f54edaf0f3f0

endpoint db2 (f15e51cca32ad170b0b5c5b5d23b9d21891b4817dc2933f0308ddc8af4289260): Bind for 0.0.0.0:3306 failed: port is already

Run 'docker run --help' for more information

앞의 db가 3306번을 쓰는 중이라 db2가 못 켜졌어요. 내 컴퓨터에 MySQL을 직접 설치해 둬도 같은 오류가 나요.

-p 3307:3306

내 컴퓨터 쪽만 바꿔요

컨테이너 안 MySQL은 그대로

먼저 docker ps로 3306번을 쓰는 컨테이너가 있는지 보고, 안 쓰는 것이면 꺼요.

29에서 본 포트 겹침이 3306번에서도 나요. 앞의 db가 3306번을 쓰는 중에 db2를 같은 포트로 켜려고 하니 port is already allocated가 나왔어요. 이미 MySQL을 컴퓨터에 직접 설치해 둔 사람도 같은 오류를 만나요. 설치한 MySQL이 3306번을 쓰고 있어서예요. 먼저 docker ps로 3306번을 쓰는 컨테이너가 있는지 보고 안 쓰는 것이면 꺼요. 둘 다 써야 하면 -p 3307:3306처럼 앞쪽, 내 컴퓨터 쪽 번호만 바꿔요. 컨테이너 안의 MySQL은 그대로 3306에서 기다려요. 긴 오류 줄은 화면 폭에 맞춰 줄만 바꿨어요. 터미널 출력은 tools/demo.py로 실제 Docker와 MySQL을 실행한 결과예요.
