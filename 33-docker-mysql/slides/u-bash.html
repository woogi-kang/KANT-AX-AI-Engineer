3. 계정과 접속 방법

bash로 먼저 들어가서 mysql을 열어도 돼요

~ $ docker exec -it db bash

bash-5.1# mysql -u root -p cafe

Enter password:

…

 

mysql> SHOW TABLES;

bash에서도 나와요

내 터미널

~ $

컨테이너 안 bash

bash-5.1#

MySQL

mysql>

exit

exit

컨테이너 안의 파일도 같이 볼 때 써요. 나올 때는 exit를 두 번 쳐요.

접속하는 방법이 하나 더 있어요. 30에서 배운 docker exec -it db bash로 컨테이너 안에 먼저 들어가요. 표시가 bash-5.1#로 바뀌어요. 그 안에서 mysql -u root -p cafe를 치면 앞에서처럼 mysql>이 나와요. 오른쪽 그림처럼 상자 안에 상자로 들어간 거예요. 그래서 나올 때도 두 번이에요. mysql에서 exit를 치면 bash로, bash에서 exit를 한 번 더 치면 내 터미널로 돌아와요. 컨테이너 안의 파일이나 로그를 같이 살펴볼 때 이 방법을 써요. 터미널 출력은 tools의 demo 스크립트로 실제 Docker와 MySQL을 실행한 결과예요.
