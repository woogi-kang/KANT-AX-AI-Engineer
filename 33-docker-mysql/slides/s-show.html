문장 끝에 ;

-e MYSQL_DATABASE로 만든 것

MySQL이 스스로 쓰는 것

SQL 문장 쓰는 법

끝에 ;를 붙여야 실행돼요

SQL 낱말은 대문자로 쓰는 게 약속이에요. 소문자도 돼요

표와 데이터베이스 이름은 소문자로 써요

SQL 첫 문장이에요. SHOW DATABASES;는 서버 안의 데이터베이스 목록을 보여 줘요. 문장 끝의 세미콜론은 여기서 문장이 끝났다는 표시예요. 세미콜론을 쳐야 MySQL이 실행해요. 결과는 표 모양으로 나와요. cafe는 -e MYSQL_DATABASE로 만든 데이터베이스예요. 나머지 넷은 32에서 본 것처럼 MySQL이 스스로 쓰는 데이터베이스예요. SQL 낱말은 대문자로 쓰는 게 약속이에요. 소문자로 써도 돌아가지만, 대문자로 쓰면 내가 지은 이름과 구별이 잘 돼요. 터미널 출력은 tools의 demo 스크립트로 실제 Docker와 MySQL을 실행한 결과예요.
