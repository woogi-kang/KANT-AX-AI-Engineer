폴더 이름이 앞에 붙은 볼륨

컨테이너 이름 대신 서비스 이름

docker compose exec 서비스 명령은 31의 docker exec와 같은 일을 해요.

docker compose up -d로 켜고, 서비스 이름 db로 들어가요. ~/cafe-db 폴더에서 up -d를 치면 네트워크, 볼륨, 컨테이너가 차례로 만들어져요. 볼륨 이름이 cafe-db_cafe-data예요. compose는 폴더 이름을 앞에 붙여서 다른 폴더의 볼륨과 겹치지 않게 해요. docker compose ps로 보면 컨테이너 이름은 cafe-db-db-1이에요. 이 긴 이름을 칠 필요 없이 docker compose exec 뒤에 서비스 이름 db를 적으면 돼요. 31에서 docker exec cafe-web-1로 친 것과 같은 일을 더 짧게 하는 거예요. 처음 켤 때는 앞에서처럼 10초쯤 기다렸다가 들어가요. 터미널 출력은 tools/demo.py로 실제 Docker와 MySQL을 실행한 결과예요.
