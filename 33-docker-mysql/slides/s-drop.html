2. 데이터베이스와 표 만들기

DROP으로 표와 데이터베이스를 지워요

~ $ docker exec -it db mysql -u root -p shop

Enter password:

…

mysql> CREATE TABLE test (id INT);

Query OK, 0 rows affected (0.00 sec)

 

mysql> SHOW TABLES;

+----------------+

| Tables_in_shop |

+----------------+

| test           |

+----------------+

1 row in set (0.01 sec)

 

mysql> DROP TABLE test;

Query OK, 0 rows affected (0.01 sec)

 

mysql> SHOW TABLES;

Empty set (0.00 sec)

test 표를 지워요

표가 없어졌어요

mysql> DROP DATABASE shop;

Query OK, 0 rows affected (0.00 sec)

 

mysql> SHOW DATABASES;

+--------------------+

| Database           |

+--------------------+

| cafe               |

| information_schema |

| mysql              |

| performance_schema |

| sys                |

+--------------------+

5 rows in set (0.00 sec)

shop을 통째로

shop이 없어요

DROP은 묻지 않고 바로 지우고, 되돌릴 수 없어요.

안에 든 행까지 다 사라져요. 연습할 때는 지워도 되는 것에만 쳐요.

DROP으로 표와 데이터베이스를 지워요. 이번에는 mysql -u root -p 뒤에 shop을 적어서 shop에 바로 들어갔어요. 연습용 test 표를 하나 만들고 DROP TABLE test;로 지웠어요. SHOW TABLES로 보면 다시 Empty set이에요. DROP DATABASE shop;은 데이터베이스를 안의 표까지 통째로 지워요. SHOW DATABASES 목록에서 shop이 빠졌어요. DROP은 정말 지울지 묻지 않아요. 지운 표와 행은 되돌릴 수 없으니, 연습할 때는 지워도 되는 것에만 쳐요. 터미널 출력은 tools/demo.py로 실제 Docker와 MySQL을 실행한 결과예요.
