1. MySQL 컨테이너 켜기

-e로 컨테이너에 설정값(환경 변수)을 건네요

~ $ docker exec db env

PATH=…

HOSTNAME=f761cbba159d

MYSQL_DATABASE=cafe

MYSQL_ROOT_PASSWORD=cafe1234

GOSU_VERSION=1.19

MYSQL_MAJOR=8.4

MYSQL_VERSION=8.4.13-1.el9

MYSQL_SHELL_VERSION=8.4.10-1.el9

HOME=/root

-e로 건넨 값

환경 변수는 프로그램이 켜질 때 읽는 이름=값 쪽지예요.

MySQL 이미지는 처음 켜질 때 이 쪽지를 읽고 비밀번호와 데이터베이스를 만들어요. 쓸 수 있는 이름은 Docker Hub의 mysql 설명 페이지 Environment Variables에 적혀 있어요.

cafe1234는 연습용이에요

실제 서비스는 긴 비밀번호를 쓰고, 비밀번호를 적은 파일은 GitHub에 올리지 않아요.

-e로 컨테이너에 설정값을 건네요. 이런 값을 환경 변수라고 불러요. 프로그램이 켜질 때 읽는 이름=값 쪽지라고 생각하면 돼요. 31에서 배운 docker exec 이름 명령으로 env를 실행하면 컨테이너 안의 환경 변수가 나와요. 우리가 -e로 건넨 두 줄이 그대로 들어 있어요. MySQL 이미지는 처음 켜질 때 이 값을 읽고 root 비밀번호를 정하고 cafe 데이터베이스를 만들어요. 어떤 이름을 쓸 수 있는지는 Docker Hub의 mysql 설명 페이지에 나와 있어요. cafe1234는 연습용이에요. 실제 서비스에서는 긴 비밀번호를 쓰고, 비밀번호를 적은 파일은 GitHub에 올리지 않아요. 터미널 출력은 tools/demo.py로 실제 Docker와 MySQL을 실행한 결과예요.
