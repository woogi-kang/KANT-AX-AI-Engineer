Docker Hub의 공식 이미지 mysql:8.4를 받아요. 29에서 배운 docker pull이에요. mysql은 Docker Official Image 마크가 붙은 공식 이미지예요. 태그 8.4는 오래 고쳐 주는 LTS 버전이에요. latest로 받으면 새 버전이 나올 때마다 바뀌니, 수업에서는 8.4로 적어서 모두 같은 MySQL을 써요. docker images mysql로 받은 이미지를 확인해요. 1GB가 넘어서 처음에는 몇 분 걸릴 수 있어요. 터미널 출력은 tools의 demo 스크립트로 실제 Docker와 MySQL을 실행한 결과예요.
