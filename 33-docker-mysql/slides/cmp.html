30, 31 · nginx

33 · MySQL

설정 건네기

설정 파일을 -v ./conf로

-e 환경 변수로

볼륨에 담는 것

./site의 html 파일 (내가 고쳐요)

/var/lib/mysql 표 파일 (MySQL만 고쳐요)

들어가기

docker exec -it web bash

docker exec -it db mysql -u root -p

켜졌는지 보기

curl localhost

logs의 port: 3306, SHOW DATABASES;

기다리는 포트

80

3306

run, ps, logs, stop, rm, exec, compose는 그대로예요. 이미지에 따라 옵션만 달라져요.

30, 31에서 쓴 nginx 컨테이너와 비교해 봐요. nginx는 설정 파일을 -v로 연결해서 건넸고, MySQL은 -e 환경 변수로 건네요. 볼륨에 담는 것도 달라요. nginx의 site 폴더는 내가 VS Code로 고치는 파일이었지만, /var/lib/mysql의 표 파일은 MySQL만 고쳐요. 그래서 내 폴더 대신 이름 있는 볼륨을 붙이고 손대지 않아요. 들어갈 때는 bash 대신 mysql을 열고, 켜졌는지는 curl 대신 logs와 SHOW DATABASES로 봐요. 포트는 80 대신 3306이에요. run, ps, logs, stop, rm, exec, compose는 다 그대로예요. 이미지가 달라지면 옵션만 달라져요.
