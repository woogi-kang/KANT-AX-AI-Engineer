MySQL을 직접 설치하면 켜고 지우고 버전 맞추기가 번거로워요

컴퓨터에 직접 설치

1  설치 파일을 받아 설치 마법사를 넘겨요

2  컴퓨터를 켤 때마다 뒤에서 늘 돌아요

3  지우려면 프로그램과 데이터 폴더를 따로 찾아요

4  프로젝트마다 다른 버전을 쓰기 어려워요

Docker 컨테이너

1  docker run 한 줄로 켜요

2  쓸 때만 켜고 docker stop으로 꺼요

3  docker rm으로 깨끗이 지워요

4  mysql:8.4처럼 태그로 버전을 골라요

32에서 읽어 본 표와 SQL을 오늘은 컨테이너로 켠 MySQL에서 직접 쳐 봐요.

실제 회사에서도 개발할 때는 데이터베이스를 컨테이너로 띄워 쓰는 경우가 많아요.

MySQL을 컴퓨터에 직접 설치하면 번거로운 일이 많아요. 설치 파일을 받아 마법사를 넘겨야 하고, 설치하고 나면 컴퓨터를 켤 때마다 뒤에서 늘 돌아요. 지울 때도 프로그램과 데이터 폴더를 따로 찾아 지워야 해요. 프로젝트마다 다른 버전이 필요하면 더 곤란해요. 29부터 써 온 Docker로 켜면 docker run 한 줄로 켜고, 쓸 때만 켜고, docker rm으로 깨끗이 지워요. 버전은 mysql:8.4처럼 태그로 골라요. 32에서 표와 SQL을 읽어 봤으니, 오늘은 컨테이너로 켠 MySQL에서 직접 쳐 봐요.
