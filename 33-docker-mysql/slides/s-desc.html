2. 데이터베이스와 표 만들기

SHOW TABLES로 표 목록을, DESCRIBE로 열을 봐요

mysql> SHOW TABLES;

Empty set (0.00 sec)

 

mysql> CREATE TABLE orders (…);

Query OK, 0 rows affected (0.01 sec)

 

mysql> SHOW TABLES;

+----------------+

| Tables_in_cafe |

+----------------+

| orders         |

+----------------+

1 row in set (0.00 sec)

아직 없어요

생겼어요

mysql> DESCRIBE orders;

+-------+-------------+------+-----+---------+-------+

| Field | Type        | Null | Key | Default | Extra |

+-------+-------------+------+-----+---------+-------+

| id    | int         | NO   | PRI | NULL    |       |

| menu  | varchar(20) | YES  |     | NULL    |       |

| qty   | int         | YES  |     | NULL    |       |

+-------+-------------+------+-----+---------+-------+

3 rows in set (0.01 sec)

Field
열 이름
Type
열의 타입 · 32에서 본 INT, VARCHAR
Null
비워 둬도 되는지 · 기본 키는 NO
Key
PRI는 기본 키(PRIMARY KEY)
표를 만들었으면 잘 만들어졌는지 확인해요. SHOW TABLES;는 지금 데이터베이스 안의 표 목록이에요. cafe에 처음 들어가면 Empty set으로 비어 있어요. CREATE TABLE을 친 뒤에 다시 보면 orders가 나와요. DESCRIBE orders;는 표의 열을 한 줄씩 보여 줘요. Field는 열 이름, Type은 타입이에요. Null은 그 칸을 비워 둬도 되는지예요. 기본 키 id는 비울 수 없어서 NO예요. Key의 PRI는 기본 키라는 뜻이에요. 왼쪽의 CREATE TABLE은 앞 장과 같은 문장이라 괄호 안을 …로 줄였어요. 터미널 출력은 tools/demo.py로 실제 Docker와 MySQL을 실행한 결과예요.
