한 줄로 쳐도 되고, 여러 줄로 나눠 쳐도 돼요. 쉼표로 열을 나눠요.

CREATE TABLE로 빈 표를 만들어요. 이번에는 mysql -u root -p 뒤에 cafe를 적었어요. 그러면 cafe 데이터베이스 안으로 바로 들어가요. CREATE TABLE 다음에 표 이름 orders를 쓰고, 괄호 안에 열을 쉼표로 나눠 적어요. 열마다 이름과 타입을 써요. 32에서 본 그대로 id는 정수이면서 기본 키, menu는 20자까지의 글자, qty는 정수예요. Query OK, 0 rows affected는 잘 만들었고 바뀐 행은 0개라는 뜻이에요. 표는 생겼지만 아직 행이 없어요. 아래처럼 여러 줄로 나눠 적어도 돼요. 터미널 출력은 tools의 demo 스크립트로 실제 Docker와 MySQL을 실행한 결과예요.
