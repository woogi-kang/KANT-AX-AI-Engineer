5. 자주 나는 오류

SQL을 칠 때 자주 하는 실수 두 가지예요

1 끝에 ;를 빠뜨렸어요

mysql> SELECT * FROM orders

-> ;

 

+----+-----------+------+

| id | menu      | qty  |

…

아직 안 끝났대요

->가 나오면 ;만 치고 Enter를 눌러요.

2 표 이름을 잘못 썼어요

Enter password:

ERROR 1064 (42000): You have an error in your SQL

syntax; check the manual that corresponds to your

MySQL server version for the right syntax to use

near 'order' at line 1

SQL을 직접 칠 때 자주 하는 실수 두 가지예요. 첫째, 32에서 읽은 것처럼 끝의 세미콜론을 빠뜨리면 Enter를 쳐도 실행되지 않고 화살표 표시가 나와요. 아직 문장이 안 끝났으니 더 치라는 뜻이에요. 세미콜론만 치고 Enter를 누르면 실행돼요. 둘째, 표 이름 orders를 order로 잘못 쓰면 ERROR 1064가 나와요. order는 SQL에서 정렬할 때 쓰는 낱말이라 문법이 틀렸다고 해요. near 뒤에 적힌 곳 근처를 보면 돼요. 32에서 본 같은 id 넣기, 수량에 글자 넣기도 이렇게 ERROR 번호와 이유가 나와요. 터미널 출력은 tools의 demo 스크립트로 실제 Docker와 MySQL을 실행한 결과예요.
