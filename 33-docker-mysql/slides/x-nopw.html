5. 자주 나는 오류

비밀번호 -e를 빠뜨리면 켜지자마자 꺼져요

~ $ docker run -d --name db mysql:8.4

f0cee30f63a8…

~ $ docker ps -a

CONTAINER ID   IMAGE       COMMAND                  CREATED         STATUS                     PORTS     NAMES

f0cee30f63a8   mysql:8.4   "docker-entrypoint.s…"   4 seconds ago   Exited (1) 3 seconds ago             db

~ $ docker logs db

…

[ERROR] [Entrypoint]: Database is uninitialized and password option is not specified

   You need to specify one of the following as an environment variable:

   - MYSQL_ROOT_PASSWORD

   - MYSQL_ALLOW_EMPTY_PASSWORD

   - MYSQL_RANDOM_ROOT_PASSWORD

docker rm db로 꺼진 컨테이너를 지우고, -e MYSQL_ROOT_PASSWORD를 붙여 다시 켜요.

비밀번호 -e를 빠뜨리면 켜지자마자 꺼져요. docker run은 컨테이너 ID를 찍고 끝나서 잘 켜진 것처럼 보여요. 그런데 docker ps -a로 보면 STATUS가 Exited (1)이에요. 몇 초 만에 꺼진 거예요. docker logs db로 이유를 보면, 데이터베이스를 처음 만드는데 비밀번호 옵션이 없다고 나와요. 아래 세 이름 중 하나를 환경 변수로 달라는 뜻이에요. 우리는 MYSQL_ROOT_PASSWORD를 써요. 꺼진 컨테이너도 이름 db를 차지하고 있어서, 29에서 배운 대로 docker rm db로 먼저 지우고 다시 켜요. 터미널 출력은 tools/demo.py로 실제 Docker와 MySQL을 실행한 결과예요.
