3. 계정과 접속 방법

-e로 SQL 한 문장만 실행하고 바로 나와요

~ $ docker exec db mysql -u root -pcafe1234 cafe -e "SHOW TABLES;"

Tables_in_cafe

orders

mysql: [Warning] Using a password on the command line interface can be insecure.

결과만 받고 끝나요

결과를 받기만 하니 키보드로 칠 일이 없어서 -it를 빼요. 31의 docker exec 이름 명령과 같아요.

~ $ docker exec -it db mysql -u root -pcafe1234 cafe

mysql: [Warning] Using a password on the command line interface can be insecure.

…

mysql> exit

Bye

비밀번호를 묻지 않아요

-p 바로 뒤에 띄우지 않고 붙이면 비밀번호를 묻지 않아요

비밀번호가 명령 기록에 남아서 Warning이 나와요. 연습할 때만 써요.

언제 어떤 방법?

docker exec -it db mysql -u root -p
SQL을 여러 개 칠 때 · 기본
docker exec -it db bash
컨테이너 안도 같이 볼 때
docker exec db mysql … -e "SQL"
한 문장만 확인할 때
SQL 한 문장만 확인하고 싶을 때는 들어가지 않고 바로 실행해요. mysql 뒤에 -e와 따옴표로 감싼 SQL을 적으면, 그 문장만 실행하고 결과를 찍고 끝나요. 결과는 표 테두리 없이 줄만 나와요. 받기만 하니 키보드로 칠 일이 없어서 -it를 뺐어요. 31에서 배운 docker exec 이름 명령과 같은 모양이에요. 이번에는 -p 바로 뒤에 비밀번호를 붙여 썼어요. 그러면 비밀번호를 묻지 않아요. 아래처럼 -it로 들어갈 때도 똑같아요. 띄어 쓰면 비밀번호가 아니라 데이터베이스 이름으로 읽혀요. 비밀번호가 명령 기록에 남아서 Warning이 나와요. 그래서 연습할 때만 쓰고, 평소에는 -p만 적고 물어볼 때 쳐요. 오른쪽은 지금까지 본 세 가지 접속 방법이에요. 터미널 출력은 tools/demo.py로 실제 Docker와 MySQL을 실행한 결과예요.
