볼륨 · 표가 여기 있어요

docker rm db

컨테이너만 지워져요

새 컨테이너에 같은 볼륨을 붙이면 예전 표를 그대로 읽어요.

mysql 이미지는 -v를 안 붙여도 이름 없는 볼륨을 스스로 만들어요. 다만 새 컨테이너는 새 이름 없는 볼륨을 받아서 예전 표를 못 찾아요. docker volume ls에 긴 이름이 쌓이는 게 이 볼륨이에요.

표는 컨테이너 안 /var/lib/mysql 폴더에 저장돼요. MySQL은 데이터베이스와 표를 이 폴더에 파일로 남겨요. 볼륨이 없으면 이 폴더가 컨테이너 안에만 있어서, docker rm으로 컨테이너를 지울 때 폴더째 같이 지워져요. 30에서 nginx 안에서 고친 파일이 사라진 것과 같은 이유예요. 오른쪽처럼 30에서 배운 이름 있는 볼륨 cafe-data를 /var/lib/mysql 자리에 붙이면, 표는 붕어빵 밖 보관함인 볼륨에 저장돼요. 컨테이너를 지워도 볼륨은 남고, 새 컨테이너에 같은 볼륨을 붙이면 예전 표를 그대로 읽어요. 사실 mysql 이미지는 -v를 안 붙여도 이름 없는 볼륨을 만들어요. 하지만 새 컨테이너는 새 볼륨을 받아서 예전 것을 못 찾아요. 그래서 꼭 이름을 붙여요.
