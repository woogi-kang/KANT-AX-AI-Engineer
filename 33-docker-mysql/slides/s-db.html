2. 데이터베이스와 표 만들기

CREATE DATABASE로 만들고 USE로 들어가요

mysql> CREATE DATABASE shop;

Query OK, 1 row affected (0.00 sec)

 

mysql> SHOW DATABASES;

+--------------------+

| Database           |

+--------------------+

| cafe               |

| information_schema |

| mysql              |

| performance_schema |

| shop               |

| sys                |

+--------------------+

6 rows in set (0.00 sec)

 

mysql> USE shop;

Database changed

mysql> SHOW TABLES;

Empty set (0.00 sec)

새로 만든 빈 데이터베이스

USE shop · 지금 여기

mysql, sys처럼 MySQL이 스스로 쓰는 데이터베이스는 그림에서 뺐어요.

32에서 읽은 CREATE DATABASE와 USE를 직접 쳐요. 32에서 본 것처럼 서버 안에 데이터베이스가 여러 개 들어가요. root로 들어가서 CREATE DATABASE shop;을 치면 shop이 생겨요. SHOW DATABASES로 다시 보면 목록에 shop이 더해져 있어요. USE shop;은 이제부터 shop 안에서 일하겠다는 뜻이에요. Database changed가 나오면 들어간 거예요. SHOW TABLES;는 지금 데이터베이스 안의 표 목록이에요. 방금 만든 shop은 비어 있어서 Empty set이 나와요. shop은 연습용이라 2파트 끝에서 지워요. 터미널 출력은 tools의 demo 스크립트로 실제 Docker와 MySQL을 실행한 결과예요.
