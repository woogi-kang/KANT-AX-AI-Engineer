5. 자주 나는 오류

비밀번호를 잘못 치면 Access denied가 나와요

~ $ docker exec -it db mysql -u root -p

Enter password:

ERROR 1045 (28000): Access denied for user 'root'@'localhost' (using password: YES)

cafe123을 쳤어요. 4가 빠졌어요

화면에 안 보여서 잘못 치기 쉬워요

천천히 다시 쳐요

using password: YES

비밀번호를 받긴 했는데 틀렸다는 뜻이에요

기억이 안 나면

docker exec db env로 MYSQL_ROOT_PASSWORD를 봐요

비밀번호를 잘못 치면 Access denied가 나와요. 이번에는 cafe1234 대신 cafe123을 쳤어요. 비밀번호는 쳐도 화면에 안 보여서 하나 빠뜨려도 모르고 넘어가기 쉬워요. 메시지 끝의 using password: YES는 비밀번호를 받긴 했는데 맞지 않았다는 뜻이에요. 천천히 다시 치면 돼요. 정한 비밀번호가 기억나지 않으면 1파트에서 본 docker exec db env로 MYSQL_ROOT_PASSWORD 값을 확인해요. 볼륨을 붙였다면 다음다음 장의 함정도 같이 봐요. 터미널 출력은 tools의 demo 스크립트로 실제 Docker와 MySQL을 실행한 결과예요.
