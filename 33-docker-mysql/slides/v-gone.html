4. 볼륨과 compose

볼륨 없이 켠 컨테이너를 지우면 표도 같이 사라져요

~ $ docker stop db

db

~ $ docker rm db

db

~ $ docker run -d --name db -e MYSQL_ROOT_PASSWORD=cafe1234 -e MYSQL_DATABASE=cafe -p 3306:3306 mysql:8.4

c7cd14188b94…

~ $ docker exec -it db mysql -u root -p cafe

Enter password:

…

mysql> SELECT * FROM orders;

ERROR 1146 (42S02): Table 'cafe.orders' doesn't exist

앞 장까지 쓰던 db를 지우고

orders 표가 없대요. 표 안의 주문도 같이 사라졌어요.

cafe 데이터베이스는 -e로 다시 만들어졌지만, 그 안은 텅 비어 있어요.

볼륨 없이 켠 컨테이너를 지우면 표도 같이 사라져요. orders 표를 만들어 둔 db를 docker stop, docker rm으로 지웠어요. 그리고 똑같은 docker run 명령으로 다시 켰어요. 들어가서 SELECT를 치면 ERROR 1146, orders 표가 없다는 오류가 나요. 표 안의 주문도 같이 없어졌어요. cafe 데이터베이스는 -e MYSQL_DATABASE 덕분에 새로 만들어졌지만 그 안은 비어 있어요. 실제 카페라면 하루 주문이 다 날아간 거예요. 왜 그런지 다음 장에서 그림으로 봐요. 터미널 출력은 tools의 demo 스크립트로 실제 Docker와 MySQL을 실행한 결과예요.
