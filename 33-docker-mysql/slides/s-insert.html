INSERT INTO로 행을 한 줄씩 넣어요. INSERT INTO orders VALUES 뒤 괄호에 값을 적어요. 값은 표를 만들 때 적은 열 순서대로예요. id, menu, qty 순서라서 1, 'latte', 2는 1번 주문, 라테, 2잔이에요. 글자는 작은따옴표로 감싸고 숫자는 그대로 써요. Query OK, 1 row affected는 행 하나가 들어갔다는 뜻이에요. 두 번 넣었으니 표에 행이 두 개 생겼어요. 같은 id를 또 넣거나 qty에 글자를 넣으면 막혀요. 32에서 본 오류예요. 터미널 출력은 tools/demo.py로 실제 Docker와 MySQL을 실행한 결과예요.
