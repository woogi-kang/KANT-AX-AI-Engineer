2. 데이터베이스와 표 만들기

SELECT로 표를 꺼내 봐요

mysql> SELECT * FROM orders;

+----+-----------+------+

| id | menu      | qty  |

+----+-----------+------+

|  1 | latte     |    2 |

|  2 | americano |    1 |

+----+-----------+------+

2 rows in set (0.00 sec)

mysql> SELECT menu, qty FROM orders;

+-----------+------+

| menu      | qty  |

+-----------+------+

| latte     |    2 |

| americano |    1 |

+-----------+------+

2 rows in set (0.00 sec)

* = 모든 열

적은 열만 꺼내요

FROM 뒤에 어느 표에서 꺼낼지 적어요. 조건으로 고르는 WHERE, 고치는 UPDATE, 지우는 DELETE는 다음에 배워요.

SELECT로 표를 꺼내 봐요. 왼쪽 SELECT * FROM orders;의 별표는 모든 열이라는 뜻이에요. FROM 뒤에 어느 표에서 꺼낼지 적어요. 넣은 두 행이 표 모양으로 나와요. 아래 줄은 행이 몇 개인지와 걸린 시간이에요. 오른쪽처럼 별표 대신 menu, qty처럼 열 이름을 쉼표로 적으면 그 열만 꺼내요. 조건을 붙여서 원하는 행만 고르는 WHERE, 고치는 UPDATE, 행을 지우는 DELETE는 다음에 배워요. 터미널 출력은 tools/demo.py로 실제 Docker와 MySQL을 실행한 결과예요.
