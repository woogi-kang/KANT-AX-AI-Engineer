맨 아래 volumes:는 이 파일에서 쓸
이름 있는 볼륨을 적는 칸이에요.

30에서 쓴 ports, volumes에 environment가 하나 더 생겼어요. -e 자리예요.

길어진 docker run을 compose.yaml에 옮겨 적어요. 30에서 배운 compose 그대로예요. 새 폴더 ~/cafe-db를 만들고 그 안에 compose.yaml을 둬요. 서비스 이름은 db, 이미지는 mysql:8.4예요. -e 두 개는 environment 아래에 이름: 값 모양으로 적어요. -p는 ports, -v는 volumes 자리예요. 30과 다른 점은 맨 아래 volumes: 칸이에요. 이름 있는 볼륨을 compose에서 쓰려면 이 칸에 이름을 한 번 적어 둬야 해요. 들여쓰기는 30처럼 2칸씩이에요.
