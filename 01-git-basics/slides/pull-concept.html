개념 정리

pull = fetch + merge

GitHub의 main

origin/main

내 main + 파일

①

git fetch origin

받아만 오기

②

git merge origin/main

내 것과 합치기

git pull origin main

=

① + ② 한 번에

pull을 두 단계로 나눠 보여주세요. fetch는 GitHub 소식을 받아 origin/main만 옮기고 내 파일은 건드리지 않아요. merge가 그걸 내 main과 작업 폴더에 합쳐요. 나도 팀원도 새 커밋이 있으면 merge 커밋이 새로 생기고, 같은 줄을 둘 다 고쳤다면 충돌(CONFLICT)이 나요. 그땐 파일을 열어 남길 내용을 고른 뒤 add, commit 해요.
