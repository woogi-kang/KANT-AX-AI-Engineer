용어 ① 파일의 상태

상태뜻git status에 보이는 말
Untracked처음 보는 새 파일Untracked files:
Modified고쳤지만 add 전Changes not staged for commit:
Staged대기실에 올라감Changes to be committed:
Committed마지막 커밋과 같음working tree clean

빨간 글씨 = 대기실 밖

초록 글씨 = 대기실 안

Untracked와 Modified는 둘 다 빨간색이지만 달라요. Untracked는 Git이 처음 보는 파일, Modified는 이미 아는 파일이 바뀐 것. 둘 다 git add로 대기실에 올려요. 한 번이라도 커밋된 파일을 Tracked(추적 중)라고 불러요.
