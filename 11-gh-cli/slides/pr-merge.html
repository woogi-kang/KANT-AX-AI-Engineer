5. 자주 쓰는 gh 명령

gh pr merge · 합치고 main 받아 오기

~/kant/team-intro $ gh pr merge 2 --merge

✓ Merged pull request kim/team-intro#2 (feat: kim 취미 추가)

~/kant/team-intro $ git checkout main

Switched to branch 'main'

Your branch is up to date with 'origin/main'.

~/kant/team-intro $ git pull origin main

…

1baff03..5487d25 main -> origin/main

Updating 1baff03..5487d25

Fast-forward

~/kant/team-intro $ git log --oneline

5487d25 Merge pull request #2 from kim/feature/kim-hobby

8039736 feat: kim 취미 추가

1baff03 feat: kim 소개 추가

a2a187e docs: README 추가

--merge = Create a merge commit

08에서 본 PR Merge 버튼 세 가지 중 첫째예요. squash, rebase 옵션도 있으니 팀이 정한 방식을 써요.

합친 뒤에는 지금까지처럼 git pull origin main으로 받아 와요.

리뷰가 끝난 PR은 gh pr merge로 합쳐요. --merge는 08에서 본 PR Merge 버튼 세 가지 중 Create a merge commit과 같아요. --squash, --rebase 옵션도 있으니 팀이 정한 방식을 골라요. 합친 것은 GitHub의 main이라 내 컴퓨터는 아직 그대로예요. git checkout main, git pull origin main으로 받아 와요. pull 출력은 위쪽 받는 과정을 …로 줄였어요. 오른쪽 git log 맨 위에 Merge pull request #2 커밋이 생겼어요. 화면에 맞추려고 이름표 괄호는 줄였어요.
