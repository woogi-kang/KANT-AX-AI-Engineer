3. 새 레포 만들기

옵션을 잊었으면 gh repo create만 쳐요

~/kant $ gh repo create

? What would you like to do? [Use arrows to move, type to filter]

> Create a new repository on github.com from scratch

Create a new repository on github.com from a template repository

Push an existing local repository to github.com

빈 레포를 새로

Create a new repository … from scratch

템플릿에서

… from a template repository

내 폴더를 올리기

Push an existing local repository …

질문에 답하면 앞 장의 옵션을 gh가 채워요. 화살표와 Enter로 골라요.

옵션이 기억나지 않으면 gh repo create만 쳐도 돼요. 무엇을 할지부터 하나씩 물어봐요. 첫 질문의 세 번째 Push an existing local repository가 앞 장에서 한 일이에요. 그다음 폴더 위치, 레포 이름, 공개 여부, origin 이름을 차례로 물어요. 마지막에 지금 push 할지도 묻는데, 거기서는 No를 고르고 git push origin main으로 직접 올려요. 첫 질문 화면은 실제로 실행한 출력이에요.
