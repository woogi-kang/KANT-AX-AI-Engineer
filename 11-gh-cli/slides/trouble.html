정리

gh에서 막히면

1

gh: command not found

설치 직후 터미널이 gh를 몰라요

터미널 껐다 켜기

2

You are not logged into any GitHub hosts

아직 로그인 전이에요

gh auth login

3

needs the "delete_repo" scope

지우기 권한이 없어요

gh auth refresh -h github.com -s delete_repo

4

failed to run git: fatal: not a git repository

레포 폴더 밖에서 쳤어요

pwd 뒤 cd 레포 폴더

5

Where should we push the 'feature/…' branch?

브랜치를 push하기 전에 PR을 만들었어요

Ctrl+C 뒤 git push origin 브랜치

6

브라우저가 안 열려요

주소를 직접 열어요

github.com/login/device

1번은 설치 직후 자주 나요. 터미널을 껐다 켜면 새로 설치한 gh를 찾아요. 2번은 로그인 전이라는 뜻이에요. 3번은 4파트에서 본 권한 에러예요. 4번은 레포 폴더 밖에서 gh repo view, gh pr list처럼 지금 레포를 쓰는 명령을 쳤을 때예요. pwd로 위치를 보고 레포 폴더로 들어가요. 5번은 브랜치를 push하기 전에 gh pr create를 쳤을 때 나오는 질문이에요. Ctrl+C로 멈추고 git push origin 브랜치이름을 친 뒤 다시 해요. 6번은 브라우저가 저절로 안 열릴 때예요. 터미널의 코드를 보고 주소를 직접 열어요. 4번은 실제로 (or any of the parent directories): .git이 뒤에 더 붙어요. 5번 질문의 선택지 중 Cancel을 골라도 멈춰요.
