Where should we push the 'feature/…' branch?

브랜치를 push하기 전에 PR을 만들었어요

브라우저가 안 열려요

주소를 직접 열어요

github.com/login/device

첫 줄은 설치 직후 자주 나요. 터미널을 껐다 켜면 새로 설치한 gh를 찾아요. 둘째 줄은 로그인 전이라는 뜻이에요. 셋째 줄은 4파트에서 본 권한 에러예요. 넷째 줄은 레포 폴더 밖에서 gh repo view, gh pr list처럼 지금 레포를 쓰는 명령을 쳤을 때예요. pwd로 위치를 보고 레포 폴더로 들어가요. 다섯째 줄은 브랜치를 push하기 전에 gh pr create를 쳤을 때 나오는 질문이에요. Ctrl+C로 멈추고 git push origin 브랜치이름을 친 뒤 다시 해요. 여섯째 줄은 브라우저가 저절로 안 열릴 때예요. 터미널의 코드를 보고 주소를 직접 열어요. 넷째 줄은 실제로 뒤에 (or any of the parent directories): .git이 더 붙어요. 다섯째 줄 질문의 선택지 중 Cancel을 골라도 멈춰요.
