1. 설치하고 로그인하기

gh 설치하기

Mac

brew install gh

09에서 uv를 설치한 Homebrew로 설치해요.

Windows

winget install --id GitHub.cli -e

설치가 끝나면 Git Bash를 껐다 다시 열어요.

설치됐는지 확인

~ $ gh --version

gh version 2.89.0 (2026-03-26)

https://github.com/cli/cli/releases/tag/v2.89.0

버전이 나오면 설치 끝이에요. 숫자는 설치한 날에 따라 달라요.

Mac은 09에서 uv를 설치할 때 쓴 Homebrew로 brew install gh를 쳐요. Windows는 winget으로 설치해요. 대소문자까지 GitHub.cli 그대로 적어요. 설치 직후 Git Bash가 gh를 못 찾으면 창을 닫고 다시 열어요. 설치 화면은 이 자료를 만든 환경에서 실행할 수 없어서 옮기지 않았어요. gh --version 출력은 실제로 실행한 결과예요. 버전 숫자는 설치한 날에 따라 달라요.
