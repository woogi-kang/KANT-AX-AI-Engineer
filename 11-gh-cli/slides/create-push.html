3. 새 레포 만들기

push는 git으로 · 그리고 목록 확인

~/kant/my-notes $ git remote -v

origin https://github.com/kim/my-notes.git (fetch)

origin https://github.com/kim/my-notes.git (push)

~/kant/my-notes $ git push origin main

Enumerating objects: 3, done.

Counting objects: 100% (3/3), done.

Writing objects: 100% (3/3), 230 bytes | 230.00 KiB/s, done.

Total 3 (delta 0), reused 0 (delta 0), pack-reused 0

To https://github.com/kim/my-notes.git

* [new branch] main -> main

~ $ gh repo list

 

Showing 3 of 3 repositories in @kim

 

NAME DESCRIPTION INFO UPDATED

kim/hello-git

kim/my-notes

kim/team-intro

로그인 창 없이 push가 끝났어요. 질문 3의 Yes 덕분이에요.

git remote -v로 origin이 https://github.com/kim/my-notes.git인지 보고, git push origin main으로 올려요. 비밀번호나 토큰을 묻지 않고 바로 올라가요. 1파트 질문 3에서 Yes를 골라 git이 gh 로그인을 쓰기 때문이에요. 오른쪽 gh repo list에 kim/my-notes가 한 줄 늘었어요. 오른쪽 목록은 화면에 맞추려고 UPDATED 칸을 잘랐어요.
