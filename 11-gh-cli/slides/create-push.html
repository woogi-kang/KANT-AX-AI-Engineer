3. 새 레포 만들기

push는 git으로 하고, gh repo list로 확인해요

~/kant/my-notes $ git remote -v

origin    https://github.com/kim/my-notes.git (fetch)

origin    https://github.com/kim/my-notes.git (push)

~/kant/my-notes $ git push origin main

…

To https://github.com/kim/my-notes.git

* [new branch]      main -> main

로그인 창 없이 올라갔어요

~ $ gh repo list

NAME

kim/hello-git

kim/my-notes

kim/team-intro

질문 3에서 Yes를 고른 덕분이에요.

git remote -v로 origin이 https://github.com/kim/my-notes.git인지 보고, git push origin main으로 올려요. 비밀번호나 토큰을 묻지 않고 바로 올라가요. 1파트 질문 3에서 Yes를 골라 git이 gh 로그인을 쓰기 때문이에요. 오른쪽 gh repo list에 kim/my-notes가 한 줄 늘었어요. push 출력 가운데는 …로 줄였고, 오른쪽 목록은 화면에 맞추려고 뒤 칸을 잘랐어요.
