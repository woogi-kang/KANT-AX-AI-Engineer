2. 이미 있는 레포 연결하기

받은 폴더는 git clone과 똑같아요

~/kant $ cd team-intro

~/kant/team-intro $ git remote -v

origin https://github.com/kim/team-intro.git (fetch)

origin https://github.com/kim/team-intro.git (push)

~/kant/team-intro $ git log --oneline

1baff03 (HEAD -> main, origin/main, origin/HEAD) feat: kim 소개 추가

a2a187e docs: README 추가

origin도 그대로

gh가 origin 이름으로 https 주소를 등록했어요. git push origin main, git pull origin main을 지금까지처럼 쳐요.

git으로 받은 폴더도 OK

06에서 git clone으로 받은 폴더에서도 gh를 바로 쓸 수 있어요. gh는 origin 주소를 보고 어느 레포인지 알아요.

받은 폴더에 들어가서 git remote -v를 쳐요. origin이 https://github.com/kim/team-intro.git으로 등록돼 있어요. git clone으로 받았을 때와 같아요. 그래서 push, pull 명령도 그대로예요. 반대로 06에서 git clone으로 받은 폴더에서도 gh 명령을 바로 쓸 수 있어요. 다음 장에서 보는 gh repo view는 origin 주소를 읽고 어느 레포인지 알아내요.
