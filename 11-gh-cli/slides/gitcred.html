1. 설치하고 로그인하기

질문 3의 Yes가 바꾼 것 · git도 gh로 로그인해요

~ $ cat ~/.gitconfig

…

[pull]

rebase = false

[credential "https://github.com"]

helper =

helper = !/usr/local/bin/gh auth git-credential

…

git push origin main

git이 gh에게 출입증을 물어요

GitHub에 바로 올라가요

02의 첫 push에서 뜨던 로그인 창, 토큰 입력 창이 이제 안 떠요.

이 줄은 gh가 넣었어요. 직접 고치지 않아요.

질문 3에서 Yes를 고르면 gh가 git 설정 파일(~/.gitconfig)에 두 줄을 넣어요. credential은 로그인 정보라는 뜻이에요. github.com에 push 할 때 로그인 정보는 gh auth git-credential에게 물어보라는 설정이에요. 그래서 git push origin main을 치면 git이 gh에게 출입증을 받아서 바로 올려요. 위쪽 [pull] rebase = false는 06에서 넣은 pull 설정이에요. helper = 처럼 빈 줄도 gh가 일부러 넣은 거라 지우지 않아요. 파일 내용은 tools/demo.sh에서 실제로 실행한 결과고, 위아래는 …로 줄였어요. Windows는 /usr/local/bin 자리에 설치 경로가 달라요.
