gh repo create my-notes --public --source=. --remote=origin

~/kant/my-notes $ gh repo create my-notes --public --source=. --remote=origin

✓ Created repository kim/my-notes on github.com

 https://github.com/kim/my-notes

✓ Added remote https://github.com/kim/my-notes.git

GitHub에 만들었어요

origin으로 연결했어요

--push 옵션은 붙이지 않아요. push는 다음 장에서 직접 쳐요.

my-notes 폴더 안에서 gh repo create를 쳐요. 옵션은 네 개예요. 레포 이름, 공개 여부, 지금 폴더를 쓴다는 --source=., 원격 이름 --remote=origin이에요. 출력의 Created repository는 GitHub에 kim/my-notes 레포를 만들었다는 뜻이고, Added remote는 origin으로 연결했다는 뜻이에요. gh repo create에는 --push 옵션도 있어요. 그런데 --push는 이 과정에서 쓰지 않기로 한 push 설정까지 같이 바꿔요. 그래서 붙이지 않고, push는 지금까지처럼 직접 쳐요.
