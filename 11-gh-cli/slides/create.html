3. 새 레포 만들기

gh repo create · 만들고 origin 연결까지

~/kant/my-notes $ gh repo create my-notes --public --source=. --remote=origin

✓ Created repository kim/my-notes on github.com1

https://github.com/kim/my-notes

✓ Added remote https://github.com/kim/my-notes.git2

my-notes

GitHub에 만들 레포 이름

--public

누구나 볼 수 있게. 나만 보려면 --private

--source=.

지금 폴더(.)를 레포로 써요

--remote=origin

origin 이름으로 연결해요

--push 옵션은 붙이지 않아요. push는 다음 장에서 git push origin main으로 직접 쳐요.

my-notes 폴더 안에서 gh repo create를 쳐요. 1번 줄은 GitHub에 kim/my-notes 레포를 만들었다는 뜻이고, 2번 줄은 origin으로 연결했다는 뜻이에요. 옵션은 네 개예요. 레포 이름, 공개 여부, 지금 폴더를 쓴다는 --source=., 원격 이름 --remote=origin이에요. gh repo create에는 --push 옵션도 있어요. 그런데 --push는 우리가 이 과정에서 쓰지 않기로 한 push 설정까지 같이 바꿔요. 그래서 붙이지 않고, push는 지금까지처럼 직접 쳐요.
