4. 레포 지우기와 권한 추가

권한 목록에 delete_repo가 생겼어요

~ $ gh auth status

github.com

✓ Logged in to github.com account kim (/home/kim/.config/gh/hosts.yml)

- Active account: true

- Git operations protocol: https

- Token: gho_*********

- Token scopes: 'gist', 'read:org', 'repo', 'workflow'

- Token scopes: 'delete_repo', 'gist', 'read:org', 'repo', 'workflow'

위 회색 줄은 refresh 전, 노란 줄이 지금이에요.

repo

read:org

gist

workflow

delete_repo

이제 지우기를 다시 해 봐요.

gh auth status를 다시 쳐서 확인해요. Token scopes 맨 앞에 delete_repo가 생겼어요. 회색 줄은 비교하려고 refresh 전 줄을 같이 적은 거고, 실제 화면에는 노란 줄 하나만 나와요. 출입증에 다섯 번째 칸이 생겼으니 이제 지우기를 다시 해 봐요.
