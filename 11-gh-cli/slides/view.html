2. 이미 있는 레포 연결하기

레포 폴더 안에서는 gh repo view, gh browse만 쳐도 돼요

~/kant/team-intro $ gh repo view

kim/team-intro

No description provided

 

 

 # team-intro

 

 우리 팀 소개 페이지예요.

 

 

View this repository on GitHub: https://github.com/kim/team-intro

origin을 보고 알아냈어요

github.com/kim/team-intro

kim / team-intro

team-intro

우리 팀 소개 페이지예요.

~/kant/team-intro $ gh browse

Opening https://github.com/kim/team-intro

in your browser.

레포 폴더 안에서 gh repo view를 치면 레포 이름, 설명, README 내용을 터미널에 보여 줘요. 설명을 안 적은 레포라 No description provided가 나와요. gh browse는 같은 레포를 브라우저 새 탭으로 열어요. 웹에서 할 일이 있을 때 주소를 찾지 않아도 돼요. 두 명령 모두 주인/이름을 적지 않았어요. 지금 폴더의 origin을 보고 kim/team-intro라고 알아낸 거예요. gh browse 출력은 화면에 맞추려고 두 줄로 나눴어요. 브라우저 화면은 단순하게 그린 그림이에요.
