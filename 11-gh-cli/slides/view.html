레포 폴더 안에서 gh repo view를 치면 레포 이름, 설명, README 내용을 터미널에 보여 줘요. 설명을 안 적은 레포라 No description provided가 나와요. gh browse는 같은 레포를 브라우저 새 탭으로 열어요. 웹에서 할 일이 있을 때 주소를 찾지 않아도 돼요. 두 명령 모두 주인/이름을 적지 않았어요. 지금 폴더의 origin을 보고 kim/team-intro라고 알아낸 거예요.
