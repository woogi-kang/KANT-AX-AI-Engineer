5. 자주 쓰는 gh 명령

gh pr create · 브랜치 push 뒤 PR 만들기

~/kant/team-intro $ git checkout -b feature/kim-hobby

Switched to a new branch 'feature/kim-hobby'

~/kant/team-intro $ echo '취미: 등산' >> kim.md

~/kant/team-intro $ git add kim.md

~/kant/team-intro $ git commit -m 'feat: kim 취미 추가'

[feature/kim-hobby 8039736] feat: kim 취미 추가

1 file changed, 1 insertion(+)

~/kant/team-intro $ git push origin feature/kim-hobby

…

* [new branch] feature/kim-hobby -> feature/kim-hobby

~/kant/team-intro $ gh pr create --title "feat: kim 취미 추가" --body "kim.md에 취미를 적었어요"

 

Creating pull request for feature/kim-hobby into main in kim/team-intro

 

https://github.com/kim/team-intro/pull/2

브랜치를 git push origin 브랜치로 먼저 올리고, 그다음 gh pr create예요.

03에서 브랜치를 만들어 push한 뒤 웹에서 Compare & pull request 버튼으로 PR을 열었어요. 위쪽은 03과 같은 순서예요. 브랜치를 만들고, 고치고, 커밋하고, git push origin feature/kim-hobby로 올려요. 아래 gh pr create가 웹 버튼을 대신해요. --title은 PR 제목, --body는 내용이에요. 꼭 push를 먼저 해요. push 전에 gh pr create를 치면 gh가 브랜치를 어디에 push할지 되물어요. push 출력의 가운데는 …로 줄였어요.
