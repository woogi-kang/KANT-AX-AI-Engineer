3. 새 레포 만들기

먼저 내 컴퓨터에 저장소와 커밋 하나를 만들어요

~/kant $ mkdir my-notes

~/kant $ cd my-notes

~/kant/my-notes $ git init

Initialized empty Git repository in /home/kim/kant/my-notes/.git/

~/kant/my-notes $ echo '# my-notes' > README.md

~/kant/my-notes $ git add README.md

~/kant/my-notes $ git commit -m 'docs: README 추가'

[main (root-commit) f5c3a4c] docs: README 추가

1 file changed, 1 insertion(+)

create mode 100644 README.md

이 커밋을 GitHub에 올려요

새 레포는 내 컴퓨터 폴더에서 시작해요. 01의 mkdir, cd로 my-notes 폴더를 만들고 들어가요. 02에서 한 대로 git init, README.md 만들기, git add, git commit -m까지 쳐요. 커밋이 있어야 다음 장에서 GitHub에 올릴 내용이 생겨요. 출력은 tools/demo.sh에서 실제로 실행한 결과고, 커밋 해시는 칠 때마다 달라요.
