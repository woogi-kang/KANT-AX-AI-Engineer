5. 자주 쓰는 gh 명령

gh issue · 할 일을 이슈로 남기기

~/kant/team-intro $ gh issue create --title "소개 페이지에 사진 넣기" --body "각자 사진 한 장씩 넣어요"

 

Creating issue in kim/team-intro

 

https://github.com/kim/team-intro/issues/1

~/kant/team-intro $ gh issue list

 

Showing 1 of 1 open issue in kim/team-intro

 

ID TITLE LABELS UPDATED

#1 소개 페이지에 사진 넣기 less than a minute ago

--title은 제목, --body는 내용이에요. 빼면 gh가 하나씩 물어봐요.

이슈는 레포에 남기는 할 일 메모예요. 웹에서는 Issues 탭의 New issue 버튼으로 만들어요. gh issue create에 --title로 제목, --body로 내용을 적으면 바로 만들어지고 주소를 알려 줘요. 둘을 빼고 gh issue create만 치면 제목과 내용을 하나씩 물어봐요. gh issue list는 열려 있는 이슈 목록이에요. #1이 이슈 번호예요. 출력은 tools/demo.sh에서 실제로 실행한 결과예요.
