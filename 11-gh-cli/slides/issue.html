5. 자주 쓰는 gh 명령

gh issue create로 할 일을 이슈로 남겨요

gh issue create --title "소개 페이지에 사진 넣기" --body "각자 사진 한 장씩"

제목

내용

~/kant/team-intro $ gh issue create --title "소개 페이지에 사진 넣기" --body "각자 사진 한 장씩 넣어요"

Creating issue in kim/team-intro

 

https://github.com/kim/team-intro/issues/1

 

~/kant/team-intro $ gh issue list

#1  소개 페이지에 사진 넣기          less than a minute ago

만든 이슈 주소

이슈 번호

--title, --body를 빼면 gh가 하나씩 물어봐요.

이슈는 레포에 남기는 할 일 메모예요. 웹에서는 Issues 탭의 New issue 버튼으로 만들어요. gh issue create에 --title로 제목, --body로 내용을 적으면 바로 만들어지고 주소를 알려 줘요. 둘을 빼고 gh issue create만 치면 제목과 내용을 하나씩 물어봐요. gh issue list는 열려 있는 이슈 목록이에요. #1이 이슈 번호예요. 위쪽 명령 그림은 내용을 줄여 적었어요. 출력은 tools/demo.sh로 실제 gh를 실행한 결과예요.
