4. 레포 지우기와 권한 추가

브라우저에서 한 번 더 허락하면 권한이 더해져요

~ $ gh auth refresh -h github.com -s delete_repo

 

! First copy your one-time code: 8F2A-71C4

Press Enter to open https://github.com/login/device in your browser...

✓ Authentication complete.

권한 추가 끝

github.com/login/device

Authorize GitHub CLI

Repositories

Organizations

Delete repositories

Authorize github

새로 더해지는 권한이에요.
코드 넣기는 로그인 때와 같아요.

에러가 알려 준 명령을 그대로 쳐요. 1파트 로그인 때처럼 코드가 나오고, Enter를 누르면 브라우저가 열려요. 코드를 넣고 Continue를 누르면 허락 화면이 나와요. 이번 허락 화면에는 레포 지우기 권한(Delete repositories)이 새로 들어 있어요. Authorize github를 누르고 터미널에 Authentication complete가 나오면 끝이에요. 질문 네 개는 다시 묻지 않아요. 코드는 칠 때마다 달라요. 브라우저 화면은 단순하게 그린 그림이에요.
