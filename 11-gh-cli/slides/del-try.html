4. 레포 지우기와 권한 추가

gh repo delete · 첫 시도는 막혀요

~ $ gh repo delete kim/my-notes

 

? Type kim/my-notes to confirm deletion: kim/my-notes1

HTTP 403: Must have admin rights to Repository. (https://api.github.com/repos/kim/my-notes)

This API operation needs the "delete_repo" scope. To request it, run:2

gh auth refresh -h github.com -s delete_repo

1 · 이름을 한 번 더 쳐요

실수로 지우지 않게 주인/이름을 그대로 다시 쳐야 해요.

2 · delete_repo 권한이 없어요

출입증에 레포 지우기 권한이 없어서 GitHub이 거절했어요(403). 칠 명령까지 알려 줘요.

고장이 아니에요. 처음 로그인할 땐 지우기 권한을 일부러 안 받아요.

gh repo delete kim/my-notes를 쳐요. 1번처럼 지울 레포 이름을 한 번 더 쳐서 확인해요. 그런데 HTTP 403 에러가 나요. 403은 요청은 알아들었지만 허락할 수 없다는 뜻이에요. 2번 줄이 이유를 알려 줘요. 이 작업에는 delete_repo 권한(scope)이 필요하고, 받으려면 gh auth refresh -h github.com -s delete_repo를 치라고 해요. 1파트 마지막 status 장에서 본 권한 목록에 delete_repo가 없었죠? 실수로 레포를 지우지 않게 처음 로그인할 때는 이 권한을 빼고 받아요. 출력은 tools/demo.sh에서 실제로 실행한 결과예요.
