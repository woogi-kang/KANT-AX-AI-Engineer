4. 레포 지우기와 권한 추가

처음 gh repo delete는 권한이 없어서 막혀요

~ $ gh repo delete kim/my-notes

 

? Type kim/my-notes to confirm deletion: kim/my-notes

HTTP 403: Must have admin rights to Repository. (https://api.github.com/repos/kim/my-notes)

This API operation needs the "delete_repo" scope. To request it, run:

 gh auth refresh -h github.com -s delete_repo

실수하지 않게 이름을 한 번 더 쳐요

허락할 수 없다는 뜻

칠 명령까지 알려 줘요

출입증 (토큰)

repo

read:org

gist

workflow

delete_repo ?

고장이 아니에요. 처음 로그인할 때는 지우기 권한을 일부러 빼고 받아요.

gh repo delete kim/my-notes를 쳐요. 지울 레포 이름을 한 번 더 쳐서 확인해요. 그런데 HTTP 403 에러가 나요. 403은 요청은 알아들었지만 허락할 수 없다는 뜻이에요. 다음 줄이 이유를 알려 줘요. 이 작업에는 delete_repo 권한(scope)이 필요하고, 받으려면 gh auth refresh -h github.com -s delete_repo를 치라고 해요. 1파트의 권한 목록에 delete_repo가 없었죠? 실수로 레포를 지우지 않게 처음 로그인할 때는 이 권한을 빼고 받아요. 출력은 tools/demo.sh로 실제 gh를 실행한 결과예요.
