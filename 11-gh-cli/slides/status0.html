1. 설치하고 로그인하기

gh auth status로 로그인했는지 물어봐요

~ $ gh auth status

You are not logged into any GitHub hosts. To log in, run: gh auth login

출력 끝에 다음에 칠 명령까지 적혀 있어요.

gh auth status

GitHub CLI

대상: 로그인

할 일: 상태 보기

설치하자마자 gh auth status를 쳐 봐요. 아직 로그인하지 않았다는 출력이 나와요. 출력 끝에 To log in, run: gh auth login이라고 다음에 칠 명령까지 알려 줘요. 번외 터미널 환경에 적응하기에서 본 것처럼 에러와 안내의 마지막 줄을 읽는 습관이 여기서도 통해요. 명령을 나눠 보면 auth는 로그인 관련 묶음이고, status는 상태를 보여 달라는 뜻이에요. 앞 장에서 본 gh 대상 할 일 모양 그대로예요.
