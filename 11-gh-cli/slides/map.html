웹에서 누르던 버튼마다 gh 명령이 하나씩 있어요

GitHub 웹에서

gh

대상

할 일

로그인

gh auth login

Code › 주소 복사 뒤 clone

gh repo clone kim/team-intro

New repository

gh repo create my-notes …

Settings › Delete this repository

gh repo delete kim/my-notes

New issue

gh issue create

Compare & pull request

gh pr create

gh 다음에 대상, 그다음에 할 일을 적어요.

오늘 쓸 명령을 웹 버튼과 나란히 놓았어요. 왼쪽은 GitHub 웹사이트에서 누르던 버튼, 오른쪽은 같은 일을 하는 gh 명령이에요. 1파트에서 로그인, 2파트에서 clone, 3파트에서 레포 만들기, 4파트에서 지우기, 5파트에서 이슈와 PR을 봐요. gh 명령은 모두 gh 다음에 대상(repo, issue, pr)과 할 일(create, list, delete)을 적는 모양이에요. 파란 글자가 대상, 주황 글자가 할 일이에요.
