웹에서 누르던 버튼과 gh 명령

로그인

gh auth login

저장소 받기 (Code › 주소 복사)

gh repo clone kim/team-intro

New repository

gh repo create my-notes --public

Settings › Delete this repository

gh repo delete kim/my-notes

New issue

gh issue create

Compare & pull request

gh pr create

오늘은 이 여섯 줄을 위에서부터 차례로 쳐 봐요.

오늘 쓸 명령을 웹 버튼과 나란히 놓았어요. 왼쪽 보라색은 GitHub 웹사이트에서 누르던 버튼이에요. 오른쪽이 같은 일을 하는 gh 명령이에요. 1파트에서 로그인, 2파트에서 clone, 3파트에서 레포 만들기, 4파트에서 지우기, 5파트에서 이슈와 PR을 봐요. gh 명령은 모두 gh 다음에 대상(repo, issue, pr)과 할 일(create, list, delete)을 적는 모양이에요.
