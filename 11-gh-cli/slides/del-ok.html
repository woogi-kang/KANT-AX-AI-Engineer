4. 레포 지우기와 권한 추가

다시 gh repo delete를 치면 지워져요

~ $ gh repo delete kim/my-notes

 

? Type kim/my-notes to confirm deletion: kim/my-notes

✓ Deleted repository kim/my-notes

 

~ $ gh repo list

Showing 2 of 2 repositories in @kim

 

NAME            DESCRIPTION  INFO    UPDATED

kim/hello-git                public  about 3 minutes ago

kim/team-intro               public  about 3 minutes ago

지워졌어요

my-notes가 없어요

~/kant/my-notes $ git push origin main

fatal: repository

'https://github.com/kim/my-notes.git/'

not found

내 폴더는 남아 있어요. GitHub 쪽이 없어서 push하면 not found가 나요.

폴더도 필요 없으면 01의 rm -r로 지워요.

같은 명령을 다시 쳐요. 이름을 한 번 더 치면 Deleted repository가 나와요. gh repo list에서도 my-notes가 사라졌어요. 내 컴퓨터의 my-notes 폴더는 남아 있어요. 거기서 git push origin main을 치면 GitHub 쪽 레포가 없어서 repository not found가 나요. 폴더가 필요 없으면 01에서 배운 rm -r로 지워요. 레포 지우기는 이름을 다시 치는 확인과 delete_repo 권한 확인, 두 번을 거쳐요. 오른쪽 에러는 화면에 맞추려고 세 줄로 나눴어요. 출력은 tools/demo.sh로 실제 gh를 실행한 결과예요.
