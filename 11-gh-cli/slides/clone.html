2. 이미 있는 레포 연결하기

gh repo clone은 주소 대신 주인/이름만 적어요

git으로 받을 때 (06)

git clone https://github.com/kim/team-intro.git

gh로 받을 때

gh repo clone kim/team-intro

git clone과 같은 출력

06에서 팀 레포 team-intro를 git clone으로 받았어요. gh는 같은 일을 gh repo clone 주인/이름으로 해요. 주소 앞의 https://github.com/와 뒤의 .git을 안 적어도 돼요. 아래 출력의 첫 줄 Cloning into는 git clone과 똑같아요. gh가 속에서 git clone을 부르기 때문이에요. 실습할 땐 kim 자리에 팀장 아이디를 적어요. 출력은 tools/demo.sh로 실제 gh를 실행한 결과예요.
