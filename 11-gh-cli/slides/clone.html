2. 이미 있는 레포 연결하기

gh repo clone · 주소 대신 주인/이름

git으로 받을 때 (02)

~/kant $ git clone https://github.com/kim/team-intro.git

gh로 받을 때

~/kant $ gh repo clone kim/team-intro

~/kant $ gh repo clone kim/team-intro

받는 내용은 같아요. 주소 앞뒤(https://github.com/, .git)를 안 적어도 돼요.

06에서 팀 레포 team-intro를 git clone으로 받았어요. gh는 같은 일을 gh repo clone 주인/이름으로 해요. 주소 전체를 복사해 오지 않아도 kim/team-intro만 적으면 돼요. 아래 출력의 첫 줄 Cloning into는 git clone과 똑같아요. gh가 속에서 git clone을 부르기 때문이에요. 출력은 tools/demo.sh에서 실제로 실행한 결과예요. 실습할 땐 kim 자리에 팀장 아이디를 적어요.
