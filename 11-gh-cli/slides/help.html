5. 자주 쓰는 gh 명령

다른 명령은 gh --help에서 찾아요

~ $ gh --help

Work seamlessly with GitHub from the command line.

 

USAGE

 gh <command> <subcommand> [flags]

 

CORE COMMANDS

 auth:          Authenticate gh and git with GitHub

 browse:        Open repositories, issues, pull requests, and more in the browser

 codespace:     Connect to and manage codespaces

 gist:          Manage gists

 issue:         Manage issues

 org:           Manage organizations

 pr:            Manage pull requests

 project:       Work with GitHub Projects.

 release:       Manage releases

 repo:          Manage repositories

 …

칠한 줄이 오늘 쓴 묶음이에요.

한 단계 더 보려면

~ $ gh repo --help

~ $ gh pr create --help

묶음 뒤에 붙이면 할 일 목록, 할 일 뒤에 붙이면 옵션 목록이 나와요.

gh --help는 gh의 명령 묶음 목록이에요. 칠한 줄이 오늘 쓴 다섯 묶음이에요. 묶음 이름 뒤에 --help를 붙이면 그 안의 할 일 목록이, 할 일 뒤에 붙이면 옵션 목록이 나와요. 번외 터미널 환경에 적응하기의 도움말 읽는 법이 gh에도 그대로 통해요. 출력은 tools/demo.sh에서 실제로 실행한 결과고 아래쪽은 …로 줄였어요.
