3. 새 레포 만들기

웹에서 만들 때와 gh로 만들 때

웹에서 (02)

1

GitHub에서 New 누르기

2

이름 적고 Create

3

주소 복사

4

git remote add origin 주소

gh로

gh repo create my-notes
  --public --source=. --remote=origin

브라우저 없이 한 줄로 레포를 만들고 origin까지 연결해요.

만들고 연결하는 데까지 gh가 해요. push는 지금처럼 git으로 해요.

02에서 레포를 GitHub에 올릴 때 네 단계를 거쳤어요. 웹에서 New를 누르고, 이름을 적고 Create를 누르고, 주소를 복사해서 git remote add origin으로 연결했어요. gh repo create는 이 네 단계를 한 줄로 해요. 다만 push는 하지 않아요. push는 지금까지처럼 git push origin main으로 직접 쳐요.
