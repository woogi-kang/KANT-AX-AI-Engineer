02에서 레포를 GitHub에 올릴 때 네 단계를 거쳤어요. 웹에서 New를 누르고, 이름을 적고 Create repository를 누르고, 주소를 복사해서 git remote add origin으로 연결했어요. gh repo create는 이 네 단계를 한 줄로 해요. 다만 push는 하지 않아요. push는 지금까지처럼 git push origin main으로 직접 쳐요. 오른쪽 명령은 화면에 맞추려고 두 줄로 나눠 적었어요. 실제로는 한 줄로 쳐요.
