1. 설치하고 로그인하기

로그인하면 출입증(토큰)과 열 수 있는 문(권한) 목록이 생겨요

~ $ gh auth status

github.com

 ✓ Logged in to github.com account kim (/home/kim/.config/gh/hosts.yml)

 - Active account: true

 - Git operations protocol: https

 - Token: gho_*********

 - Token scopes: 'gist', 'read:org', 'repo', 'workflow'

출입증(토큰), 앞 네 글자만 보여요

출입증으로 열 수 있는 문(권한)

출입증 (토큰)

repo

read:org

gist

workflow

이 목록에 없는 일은 못 해요. 4파트에서 여기에 한 칸이 늘어요.

로그인한 뒤 gh auth status를 다시 쳐요. 이번에는 kim 계정으로 로그인했다고 나와요. Token 줄은 GitHub이 gh에게 준 출입증이에요. 비밀번호 같은 거라 화면에는 앞 네 글자만 보여 줘요. Token scopes 줄은 이 출입증으로 할 수 있는 일의 목록이에요. repo는 레포 읽고 쓰기, read:org는 조직 보기, gist는 메모 조각, workflow는 Actions 설정이에요. 레포 지우기(delete_repo)는 목록에 없어요. 4파트에서 지우기를 시도하다가 이 목록 때문에 막혀요.
