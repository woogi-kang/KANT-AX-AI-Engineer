1. 설치하고 로그인하기

다시 gh auth status · 토큰과 권한 목록

~ $ gh auth status

github.com

✓ Logged in to github.com account kim (/home/kim/.config/gh/hosts.yml)

- Active account: true

- Git operations protocol: https

- Token: gho_*********1

- Token scopes: 'gist', 'read:org', 'repo', 'workflow'2

1 · 토큰 = 출입증

로그인하면 GitHub이 gh에게 출입증(토큰)을 줘요. 화면에는 앞 네 글자만 보이고 나머지는 *로 가려요.

2 · 권한(scope) = 출입증으로 열 수 있는 문

repo는 레포 읽고 쓰기, read:org는 조직 보기, gist는 메모 조각, workflow는 Actions 설정이에요. 이 목록에 없는 일은 못 해요.

2번 목록을 기억해 둬요. 4파트에서 여기에 한 줄이 늘어요.

로그인한 뒤 gh auth status를 다시 쳐요. 이번에는 kim 계정으로 로그인했다고 나와요. 1번 Token은 GitHub이 준 출입증이에요. 비밀번호 같은 거라 화면에는 앞 네 글자만 보여 줘요. 2번 Token scopes는 이 출입증으로 할 수 있는 일의 목록이에요. 레포 읽고 쓰기(repo)는 있지만 레포 지우기(delete_repo)는 없어요. 4파트에서 지우기를 시도하다가 이 목록 때문에 막혀요.
