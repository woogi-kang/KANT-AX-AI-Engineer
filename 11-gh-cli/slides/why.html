03에서 브랜치를 push한 뒤에는 브라우저로 넘어갔어요. GitHub 레포 화면에 뜬 Compare & pull request 버튼을 눌러서 PR을 열었어요. 레포를 만들 때도, 이슈를 만들 때도 터미널을 두고 브라우저로 갔어요. gh를 쓰면 같은 버튼을 터미널에서 명령으로 눌러요. 브라우저 화면은 버튼 위치만 보이게 단순하게 그렸어요.
