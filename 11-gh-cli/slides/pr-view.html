5. 자주 쓰는 gh 명령

gh pr list, gh pr view로 PR을 터미널에서 봐요

~/kant/team-intro $ gh pr list

Showing 1 of 1 open pull request in kim/team-intro

 

ID  TITLE                BRANCH             CREATED AT

#2  feat: kim 취미 추가  feature/kim-hobby  less than a minute ago

 

~/kant/team-intro $ gh pr view 2

feat: kim 취미 추가 kim/team-intro#2

Open • kim (kim) wants to merge 1 commit into main from feature/kim-hobby • less than a minute ago

+1 -0 • No checks

 

 

 kim.md에 취미를 적었어요

 

 

View this pull request on GitHub: https://github.com/kim/team-intro/pull/2

이슈 #1 다음이라 2번

칠한 줄은 kim이 커밋 1개를 main에 합치고 싶다는 뜻이에요.

gh pr list는 열린 PR 목록이에요. #2가 PR 번호예요. 이슈 #1 다음이라 2번이 됐어요. GitHub은 이슈와 PR 번호를 같이 세요. gh pr view 2는 2번 PR의 제목, 상태, 내용을 보여 줘요. 칠한 줄은 kim이 feature/kim-hobby의 커밋 1개를 main에 합치고 싶어 한다는 뜻이에요. 웹에서 보고 싶으면 gh pr view 2 --web을 쳐요.
