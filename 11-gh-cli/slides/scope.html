4. 레포 지우기와 권한 추가

gh auth refresh로 출입증에 지우기 권한을 더해요

출입증 (토큰)

repo

read:org

gist

workflow

delete_repo

1파트 gh auth status의 Token scopes 줄이에요.

gh auth refresh -h github.com -s delete_repo

출입증을 새로 받아요

어느 GitHub인지
(-h = host, 도움말 아님)

더할 권한(scope)

질문 네 개는 다시 묻지 않고 출입증만 다시 받아요.

1파트에서 토큰을 출입증, 권한(scope)을 출입증으로 열 수 있는 문에 비유했어요. 지금 출입증에는 repo, read:org, gist, workflow 네 칸이 있고 delete_repo 칸이 없어요. 에러가 알려 준 명령을 나눠 읽어 봐요. gh auth refresh는 출입증을 새로 받는 명령이에요. -h github.com은 어느 GitHub인지, -s delete_repo는 더할 권한이에요. -h가 여기서는 도움말이 아니라 host(사이트 주소)의 줄임이라는 점을 짚어 주세요. 번외에서 본 예외와 같은 경우예요.
