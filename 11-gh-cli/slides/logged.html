브라우저 허락 끝

HTTPS로 저장

Mac, Windows에서는 보통 안 나와요

내 GitHub 아이디

브라우저에서 Authorize를 누르면 터미널이 저절로 다음 줄을 출력해요. Authentication complete는 브라우저 허락이 끝났다는 뜻이에요. Configured git protocol은 앞에서 고른 HTTPS를 설정에 저장했다는 뜻이에요. 마지막 Logged in as kim에서 kim 자리에 내 GitHub 아이디가 보이면 성공이에요. 회색 saved in plain text 줄은 로그인 정보를 파일에 저장했다는 안내예요. 이 자료를 만든 환경에는 Mac의 키체인 같은 비밀 보관함이 없어서 나왔어요. Mac과 Windows는 보통 비밀 보관함에 저장해서 이 줄이 안 나와요.
