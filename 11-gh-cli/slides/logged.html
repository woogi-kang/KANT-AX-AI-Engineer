1

브라우저에서 허락 완료

2

git 주소 방식을 HTTPS로 저장

3

kim 계정으로 로그인

브라우저에서 Authorize를 누르면 터미널이 저절로 다음 줄을 출력해요. 1번 Authentication complete는 브라우저 허락이 끝났다는 뜻이에요. 2번은 앞에서 고른 HTTPS를 설정에 저장했다는 뜻이에요. 3번 Logged in as kim에서 kim 자리에 내 GitHub 아이디가 보이면 성공이에요. 가운데 saved in plain text 줄은 로그인 정보를 파일에 저장했다는 안내예요. 이 자료를 만든 환경에는 Mac의 키체인 같은 비밀 보관함이 없어서 나왔어요. Mac과 Windows는 보통 비밀 보관함에 저장해서 이 줄이 안 나와요.
