2. 이미 있는 레포 연결하기

gh repo list는 어느 폴더에서 쳐도 내 레포 목록을 보여 줘요

~ $ gh repo list

 

Showing 2 of 2 repositories in @kim

 

NAME            DESCRIPTION  INFO    UPDATED

kim/hello-git                public  about 3 minutes ago

kim/team-intro               public  about 3 minutes ago

clone, delete에 적을 주인/이름은 이 칸에서 복사해요.

gh repo list는 내 계정의 레포 목록을 보여 줘요. 특정 레포 안에서 쓰는 명령이 아니라서 어느 폴더에서 쳐도 결과가 같아요. kim/hello-git은 02에서 만든 레포, kim/team-intro는 06의 팀 레포예요. INFO 칸의 public은 누구나 볼 수 있는 레포라는 뜻이에요. clone이나 delete에 적을 주인/이름이 헷갈리면 NAME 칸에서 확인해요.
