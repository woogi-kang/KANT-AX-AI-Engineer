gh는 git을 대신하지 않아요. 웹사이트에서 누르던 버튼을 맡아요.

세 도구를 먼저 구분해요. git은 내 컴퓨터에서 기록을 남기고, push와 pull로 GitHub과 주고받아요. GitHub은 웹사이트예요. 레포를 만들거나 PR을 여는 일은 지금까지 브라우저에서 버튼으로 했어요. gh는 그 버튼을 터미널 명령으로 바꾼 도구예요. 그래서 커밋과 push는 계속 git으로 하고, 레포 만들기와 PR 만들기를 gh로 해요. 둘을 같이 써요.

1 · 토큰 = 출입증

로그인하면 GitHub이 gh에게 출입증(토큰)을 줘요. 화면에는 앞 네 글자만 보이고 나머지는 *로 가려요.

repo는 레포 읽고 쓰기, read:org는 조직 보기, gist는 메모 조각, workflow는 Actions 설정이에요. 이 목록에 없는 일은 못 해요.

오늘 쓴 묶음

auth browse
issue pr repo

한 단계 더 보기

gh repo --help
gh pr create --help

gh --help는 gh의 명령 묶음 목록이에요. 노란 줄이 오늘 쓴 다섯 묶음이에요. 출력은 tools/demo.sh에서 실제로 실행한 결과고 아래쪽은 …로 줄였어요. 묶음 이름 뒤에 --help를 붙이면 그 안의 할 일 목록이, 할 일 뒤에 붙이면 옵션 목록이 나와요. 번외 터미널 환경에 적응하기의 도움말 읽는 법이 gh에도 그대로 통해요.

정리

gh에서 막히면

1

gh: command not found

설치 직후 터미널이 gh를 몰라요

터미널 껐다 켜기

2

You are not logged into any GitHub hosts

아직 로그인 전이에요

gh auth login

3

needs the "delete_repo" scope

지우기 권한이 없어요

gh auth refresh -h github.com -s delete_repo

4

failed to run git: fatal: not a git repository

레포 폴더 밖에서 쳤어요

pwd 뒤 cd 레포 폴더

5

Where should we push the 'feature/…' branch?

브랜치를 push하기 전에 PR을 만들었어요

Ctrl+C 뒤 git push origin 브랜치

6

브라우저가 안 열려요

주소를 직접 열어요

github.com/login/device

1번은 설치 직후 자주 나요. 터미널을 껐다 켜면 새로 설치한 gh를 찾아요. 2번은 로그인 전이라는 뜻이에요. 3번은 4파트에서 본 권한 에러예요. 4번은 레포 폴더 밖에서 gh repo view, gh pr list처럼 지금 레포를 쓰는 명령을 쳤을 때예요. pwd로 위치를 보고 레포 폴더로 들어가요. 5번은 브랜치를 push하기 전에 gh pr create를 쳤을 때 나오는 질문이에요. Ctrl+C로 멈추고 git push origin 브랜치이름을 친 뒤 다시 해요. 6번은 브라우저가 저절로 안 열릴 때예요. 터미널의 코드를 보고 주소를 직접 열어요. 4번은 실제로 (or any of the parent directories): .git이 뒤에 더 붙어요. 5번 질문의 선택지 중 Cancel을 골라도 멈춰요.

커밋과 push는 git으로, 웹 버튼은 gh로 해요.

레포 지우기는 되돌릴 수 없어요. 지우기 전에 주인/이름을 한 번 더 확인해요.

오늘 쓴 명령을 세 묶음으로 모았어요. 로그인 세 개, 레포 다섯 개, 이슈와 PR 다섯 개예요. 커밋과 push, pull은 계속 git으로 하고, 웹사이트에서 누르던 버튼은 gh로 해요. 다음 수업부터 팀 레포를 만들 때 gh repo create로 시작해 봐요.
