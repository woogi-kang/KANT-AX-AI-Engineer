from product import Product

from cart import Cart

 

tumbler = Product("텀블러", 15_000, 10)

earphone = Product("무선 이어폰", 89_000, 3)

cart = Cart()

cart.add(tumbler, 1)

cart.add(earphone, 2)

 

total = 0

for p, q in cart.items.items():

total = total + p.price * q

print(total)

 

print(sum([p.price * q for p, q in cart.items.items()]))

print(cart.subtotal())

← [ ] 없는 모양은 제너레이터, 결과는 같아요

장바구니 합계를 세 가지로 구해 봤어요. 첫째는 18에서 배운 대로 total = 0에서 시작해 for로 하나씩 더해요. 둘째는 23의 컴프리헨션으로 금액 리스트를 만들어 sum에 넘겨요. 셋째는 수업 코드의 subtotal() 메서드예요. 셋 다 193000이에요. 아래 cart.py 47번 줄은 sum 안에 대괄호가 없어요. 23에서 이름만 본 제너레이터라는 모양이고, 리스트를 만들지 않을 뿐 결과는 같아요. 수업 예제에서는 대괄호를 넣은 둘째 모양으로 읽어도 돼요. 출력은 tools/demo.sh로 실제로 실행한 결과예요.
