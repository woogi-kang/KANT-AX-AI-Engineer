product.Product(...)

어느 파일에서 온 이름인지 코드에 보여요

점(.)은 '그 안의'라는 뜻이에요. 객체의 메서드를 부를 때와 같아요.

import product는 product.py를 통째로 불러와서 product라는 이름으로 묶어 둬요. 안에 있는 Product를 쓰려면 product.Product처럼 모듈 이름 뒤에 점을 찍고 적어요. 19에서 함수를 부르고 24에서 객체의 메서드를 점으로 불렀던 것처럼, 모듈 안의 이름도 점으로 꺼내요. 코드를 읽는 사람은 Product가 product.py에서 왔다는 걸 바로 알 수 있어요. 출력은 Product의 __str__이 만든 한 줄이에요. 출력은 tools/demo.sh로 실제로 실행한 결과예요.
