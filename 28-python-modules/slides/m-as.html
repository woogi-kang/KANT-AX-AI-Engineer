나중에 데이터 다룰 때 자주 보는 모양이에요

from coupon import *

*는 모든 이름을 가져와요. 무엇이 들어왔는지 안 보여서 쓰지 않아요.

import 뒤에 as를 붙이면 모듈에 별명을 지어 줄 수 있어요. import coupon as cp라고 쓰면 coupon 대신 cp로 불러요. 이름이 길 때 줄이려고 써요. 나중에 데이터를 다룰 때 import pandas as pd 같은 모양을 자주 볼 거예요. 아래 별표 모양은 모듈 안의 모든 이름을 한꺼번에 가져와요. 코드만 보고는 어떤 이름이 들어왔는지 알 수 없고, 내 변수와 이름이 겹치면 덮어써져서 쓰지 않아요. 출력은 tools/demo.sh로 실제로 실행한 결과예요.
