2. 들여쓰기는 상자

칸이 안 맞으면 IndentationError가 나요

터미널

$ uv run cart.py

File "/home/kim/shopping-cart/cart.py", line 43

return len(self.items) == 0

^^^^^^

IndentationError: expected an indented block after function definition on line 42

42번 줄 def 다음 줄이 안으로 안 들어갔어요

43번 줄 앞에 4칸 더 넣어요

터미널

$ uv run cart.py

File "/home/kim/shopping-cart/cart.py", line 39

print(f"{product.name} {qty}개를 뺐습니다.")

^

IndentationError: unindent does not match any outer indentation level

39번 줄만 10칸이라 맞는 상자가 없어요

위 줄과 같은 12칸으로 맞춰요

오류 줄에 적힌 줄 번호부터 가서 위 줄과 칸을 비교해요.

칸이 맞지 않으면 파이썬은 실행하기 전에 IndentationError를 내요. 위는 def is_empty 다음 줄을 안으로 넣지 않았을 때예요. 콜론 다음에는 안으로 들어간 줄이 있어야 한다고 알려 줘요. 아래는 12칸이어야 할 줄을 10칸으로 적었을 때예요. 10칸에서 시작하는 상자가 없어서 어디에 붙일지 모른다는 뜻이에요. 두 오류 모두 메시지에 줄 번호가 있으니 그 줄로 가서 위 줄과 칸을 비교해요. 출력은 tools/demo.sh로 실제로 실행한 결과예요.
