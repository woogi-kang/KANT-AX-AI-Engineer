4. 모듈과 import

모양마다 쓰는 법과 고르는 때가 달라요

모양

쓰는 법

고르는 때

import product

product.Product(...)

어느 모듈 것인지 보이게

from product import Product

Product(...)

하나를 여러 번 쓸 때

from coupon import COUPONS, discount

discount("VIP")

몇 개만 골라 쓸 때

import coupon as cp

cp.discount("VIP")

모듈 이름이 길 때

from coupon import *

쓰지 않아요

무엇이 왔는지 안 보여요

헷갈리면 수업 코드처럼 from 파일 import 이름부터 써요.

import 모양 다섯 가지를 한 표로 모았어요. 어느 모듈 것인지 코드에 드러내고 싶으면 import product, 하나를 여러 번 쓰면 from product import Product예요. 몇 개만 골라 쓰면 쉼표로 이어요. 모듈 이름이 길면 as로 줄여요. 별표는 쓰지 않아요. 오늘 장바구니 프로젝트에서는 수업 코드처럼 from 파일 import 이름 모양을 기본으로 쓰면 돼요.
