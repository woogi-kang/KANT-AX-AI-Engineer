Spaces: 4

VS Code 맨 아래 막대 오른쪽에 보여요. Tab 한 번이 빈칸 4개예요.

스페이스를 하나씩 세지 말고 Tab과 Shift+Tab을 써요.

VS Code에서는 칸을 직접 세지 않아도 돼요. 줄을 고르고 Tab을 누르면 4칸 안으로, Shift+Tab을 누르면 4칸 밖으로 움직여요. 오른쪽처럼 12, 13번 줄을 골라 Shift+Tab을 한 번 누르면 두 줄이 한꺼번에 if 상자 밖으로 나와요. 앞에서 본 return 실수가 이렇게 생기니, 누른 뒤에는 상자를 다시 확인해요. 맥과 윈도우 모두 같은 키예요. 코드 왼쪽의 세로 안내선은 상자의 경계라서 칸을 비교할 때 도움이 돼요. 화면 맨 아래 막대 오른쪽에 Spaces: 4가 보이면 Tab 한 번이 빈칸 네 개로 들어가요. 다른 숫자가 보이면 눌러서 4로 바꿔요.
