수업에서 만든 shopping-cart 폴더를 VS Code로 열어요. product.py에는 상품 틀 Product, cart.py에는 장바구니 틀 Cart가 있어요. main.py는 uv init이 처음 만들어 준 파일이에요. 파일을 실행할 때는 터미널에서 uv run 파일이름을 쳐요. 왼쪽 목록은 오늘 다시 꺼내 쓸 내용이고, 옆 숫자가 배운 챕터예요. 슬라이드의 코드는 수업 레포의 코드 그대로이고, 출력은 tools/demo.sh가 같은 파일을 uv로 실제로 실행한 결과예요.
