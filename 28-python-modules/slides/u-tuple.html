13에서 배운 꺼내 담기예요. 왼쪽 이름 수와 오른쪽 값 수가 같아야 해요.

for p, q를 이해하려면 이 한 줄부터 봐요. a, b = (1, 2)는 오른쪽 튜플의 첫 값을 a에, 두 번째 값을 b에 담아요. 13에서 a, b, c = 튜플로 꺼내 담기를 배웠어요. 오른쪽 그림처럼 값이 순서대로 칸에 들어가요. 두 번째 줄은 장바구니에 어울리게 상품 이름과 수량을 담았어요. 왼쪽 이름 수와 오른쪽 값 수가 같아야 한다는 것만 기억하면 돼요. play.py는 연습용으로 만든 새 파일이에요. 출력은 tools/demo.sh로 실제로 실행한 결과예요.
