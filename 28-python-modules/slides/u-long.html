for pair in cart_items.items(): name = pair[0] qty = pair[1] print(name, qty)

for name, qty in cart_items.items(): print(name, qty)

터미널

$ uv run play.py

출력이 똑같아요. pair[0]이 name, pair[1]이 qty예요.

for 옆에 이름을 두 개 적는 건 긴 방법을 줄인 모양이에요. 긴 방법은 한 쌍을 pair라는 이름 하나로 받고, pair[0]과 pair[1]로 하나씩 꺼내요. 짧은 방법은 for에서 바로 두 칸에 나눠 담아요. 오른쪽 출력처럼 결과는 똑같아요. 수업 코드의 for p, q in self.items.items()도 이 짧은 방법이에요. 13에서 튜플을 번호 두 개로 꺼냈던 것과 a, b = 튜플로 꺼내 담았던 것을 떠올려요. 출력은 tools/demo.sh로 실제로 실행한 결과예요.
