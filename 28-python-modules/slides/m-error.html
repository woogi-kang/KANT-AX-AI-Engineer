4. 모듈과 import

이름이 틀리면 ModuleNotFoundError, ImportError가 나요

터미널

$ uv run main.py

Traceback (most recent call last):

File "/home/kim/shopping-cart/main.py", line 1, in <module>

import prodcut

ModuleNotFoundError: No module named 'prodcut'

prodcut.py라는 파일이 없어요. 파일 이름의 오타예요

import product

터미널

$ uv run main.py

Traceback (most recent call last):

File "/home/kim/shopping-cart/main.py", line 1, in <module>

from product import product

ImportError: cannot import name 'product' from 'product' (/home/kim/shopping-cart/product.py). Did you mean: 'Product'?

product.py 안에 소문자 product가 없어요. 대소문자가 달라요

from product import Product

파일 이름과 대소문자를 먼저 봐요. Did you mean이 보이면 그 이름이 정답 후보예요.

import에서 나는 오류 두 가지예요. 위는 모듈 이름에 오타가 있을 때예요. prodcut이라는 모듈을 못 찾았다는 ModuleNotFoundError가 나요. 아래는 모듈은 찾았는데 그 안에 그런 이름이 없을 때예요. 클래스 이름은 대문자 P로 시작하는데 소문자로 적었어요. 파이썬 3.14는 Did you mean으로 비슷한 이름을 알려 줘요. 오류에 적힌 경로는 실습 폴더라서 수강생 화면에서는 다르게 보여요. 출력은 tools/demo.sh로 실제로 실행한 결과예요.
