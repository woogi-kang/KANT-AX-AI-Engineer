from product import Product

from cart import Cart

 

tumbler = Product("텀블러", 15_000, 10)

earphone = Product("무선 이어폰", 89_000, 3)

pad = Product("마우스패드", 9_000, 0)

 

cart = Cart()

cart.add(tumbler, 2)

cart.add(earphone, 1)

cart.add(pad, 1)

cart.checkout()

 

print(tumbler)

print(earphone)

$ uv run main.py

결제가 완료되었습니다. 감사합니다!

1: 텀블러 15,000 재고 8개

2: 무선 이어폰 89,000 재고 2개

← 두 파일에서 하나씩

← 재고 0이라 품절

← 영수증을 찍어요

텀블러 재고가 10개에서 8개로 줄었어요

상품은 product.py, 장바구니는 cart.py, 주문은 main.py가 맡아요.

이제 main.py에서 두 모듈을 불러 실제로 주문해 봐요. 맨 위 두 줄로 Product와 Cart를 꺼내 와요. 텀블러 2개와 이어폰 1개는 담기고, 재고가 0인 마우스패드는 품절이라 안 담겨요. checkout()이 영수증을 찍고 재고를 줄여서, 마지막에 텀블러 재고가 10개에서 8개가 됐어요. cart.py는 테스트 코드를 if __name__ 안에 넣은 판이라 테스트 출력이 섞이지 않아요. 상품 번호 1, 2는 26에서 배운 클래스 변수 next_id가 매겨 줬어요. 출력은 tools/demo.sh로 실제로 실행한 결과예요.
