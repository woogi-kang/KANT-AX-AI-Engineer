4. 모듈과 import

import product만 하고 Product라고 쓰면 NameError예요

main.py

1

2

3

import product

 

tumbler = Product("텀블러", 15_000, 10)

터미널

$ uv run main.py

Traceback (most recent call last):

File "/home/kim/shopping-cart/main.py", line 3, in <module>

tumbler = Product("텀블러", 15_000, 10)

^^^^^^^

NameError: name 'Product' is not defined. Did you mean: 'product'?

고치기 1: 점을 찍어 써요

✓

product.Product(...)

고치기 2: 맨 위를 바꿔요

✓

from product import Product

import product는 모듈을 product라는 이름으로 불러올 뿐, Product라는 이름을 main.py에 놓아 주지 않아요. 그래서 Product라고만 쓰면 그런 이름이 없다는 NameError가 나요. 파이썬이 Did you mean: 'product'?로 힌트를 줘요. 고치는 방법은 둘이에요. product.Product로 점을 찍어 쓰거나, 맨 위를 from product import Product로 바꿔요. 출력은 tools/demo.sh로 실제로 실행한 결과예요.
