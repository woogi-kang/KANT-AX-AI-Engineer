cart.py가 실행된 방법

cart.py의 __name__

uv run cart.py로 직접 실행

"__main__"

다른 파일이 import로 부름

"cart" (모듈 이름)

파이썬은 파일마다 __name__이라는 이름을 하나씩 만들어 둬요. cart.py 맨 아래에 __name__을 찍는 줄을 넣고 두 번 실행해 봤어요. uv run cart.py로 직접 실행하면 __name__은 "__main__"이에요. uv run main.py로 실행하면 main.py가 "__main__"이 되고, import로 불려 온 cart.py는 자기 모듈 이름 "cart"가 돼요. 이 차이로 직접 실행한 건지, import로 불린 건지 구별할 수 있어요. 출력은 tools/demo.sh로 실제로 실행한 결과예요.
