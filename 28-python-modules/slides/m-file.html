4. 모듈과 import

파일 하나가 모듈 하나예요. 이름은 .py를 뺀 부분이에요

product.py

import product

cart.py

import cart

coupon.py

import coupon

09에서 본 import도 같은 문법이에요

import fastapi

← uv add로 받아 온 남의 모듈

모듈 이름 짓기

영문 소문자와 밑줄(_)로 지어요.

shop_cart.py

띄어쓰기와 -는 쓸 수 없어요.

shop-cart.py

실행한 파일과 같은 폴더에 있는 모듈은 이름만 적으면 찾아요.

파이썬 파일 하나를 모듈이라고 불러요. 모듈 이름은 파일 이름에서 .py를 뺀 부분이에요. product.py는 product 모듈이라서 import product로 불러요. 09에서 uv add fastapi 뒤에 import fastapi를 쳤던 것도 같은 문법이에요. 그때는 남이 만든 모듈을 받아 왔고, 오늘은 내가 만든 파일을 불러요. import 뒤에는 변수 이름처럼 적어야 해서, 파일 이름은 영문 소문자와 밑줄로 지어요. 띄어쓰기나 -가 들어간 파일은 import할 수 없어요.
