2. 들여쓰기는 상자

콜론 뒤를 한 줄에 붙인 if도 같은 상자예요

cart.py 51번 줄

if self.is_empty(): return 0

if self.is_empty(): return 0

← 콜론 뒤 한 줄을 붙여 썼을 뿐이에요

← 두 줄로 풀면 4칸 들어간 if 상자예요

cart.py 52번 줄

return 0 if self.subtotal() >= 30_000 else 3_000

이건 17의 한 줄 if else예요. 둘 중 값 하나를 골라 돌려줘요

상품 합계 (uv run cart.py)

배송비

15,000원

3,000원

193,000원

0원

수업 예제는 두 줄로 적어요. 붙여 쓴 코드를 만나면 두 줄로 풀어 읽어요.

cart.py 51번 줄의 if self.is_empty(): return 0은 두 줄 if를 한 줄에 붙인 모양이에요. 콜론 뒤에 실행할 줄이 하나뿐이면 이렇게 붙여 쓸 수 있어요. 두 줄로 풀면 return 0이 if 상자 안에 4칸 들어간 모양이에요. 52번 줄은 다르게 생겼어요. 17에서 배운 한 줄 if else라서, 조건에 따라 0과 3_000 중 하나를 골라 돌려줘요. 아래 표는 1파트의 uv run cart.py 출력에서 가져온 배송비예요. 상품 합계가 3만 원보다 적으면 3,000원, 많으면 0원이에요.
