if __name__ == "__main__":

테스트 코드를 if __name__ == "__main__": 아래로 4칸 들여 넣었어요. cart.py를 직접 실행하면 __name__이 "__main__"이라 조건이 True가 되고 테스트가 돌아요. main.py가 import하면 __name__이 "cart"라서 False가 되고 건너뛰어요. 오른쪽 위 터미널처럼 main.py의 출력만 깔끔하게 나와요. product.py 26번 줄에는 수업에서 이미 이 줄을 넣어 뒀어요. 파일을 import할 일이 있으면 테스트 코드는 언제나 이 안에 둬요. 슬라이드의 테스트 코드는 담고 보여 주는 부분만 남겨 짧게 줄였어요. 출력은 tools/demo.sh로 실제로 실행한 결과예요.
