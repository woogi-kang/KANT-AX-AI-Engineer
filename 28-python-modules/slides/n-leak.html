← main.py의 첫 출력은 맨 끝

main.py에서 from cart import Cart 한 줄만 적고 실행했어요. 그런데 cart.py 맨 아래의 테스트 코드가 먼저 실행돼서 장바구니 출력이 줄줄이 나와요. import는 그 파일을 위에서부터 한 번 실행해서 이름을 만들어요. 그래서 파일 맨 아래에 그냥 적어 둔 코드도 같이 실행돼요. main.py의 첫 출력은 터미널 맨 끝에 가서야 보여요. 다음 장에서 파이썬이 '직접 실행'과 'import'를 어떻게 구별하는지 봐요. 출력은 tools/demo.sh로 실제로 실행한 결과예요.
