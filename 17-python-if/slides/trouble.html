막히면 오류의 마지막 줄을 봐요

1

SyntaxError: ... Maybe you meant '=='

if 뒤에 = 하나를 썼어요

==

2

SyntaxError: expected ':'

if, elif, else 줄 끝에 콜론이 없어요

끝에 :

3

IndentationError: expected an indented block

if 다음 줄을 들여쓰지 않았어요

4칸 들여쓰기

4

IndentationError: unexpected indent

들여쓰기 칸 수가 서로 달라요

같은 칸에 맞추기

5

TypeError: '>=' not supported ... 'str' and 'int'

글자와 숫자를 비교했어요

int(price)

6

오류는 없는데 조건이 늘 True

or 뒤에 비교 없이 값만 적었어요

o == "a" or o == "b"

7

오류는 없는데 결과가 이상함

elif 순서, 들여쓰기 범위를 봐요

좁은 조건부터

오류가 안 나도 결과가 이상하면 if 안에 print를 넣어 어느 줄이 실행됐는지 봐요.

SyntaxError와 IndentationError는 실행 전에 나서 셀의 어느 줄도 실행되지 않으니, line 숫자로 어느 줄인지 먼저 찾아요. 5번은 글자와 숫자를 비교해서 나요. 6번과 7번은 오류가 없는데 결과가 이상한 경우예요. or 뒤에 비교를 빼먹었거나, elif 순서나 들여쓰기 범위가 틀렸어요. 어느 줄이 실행됐는지 궁금하면 if 안에 print를 하나 넣어 확인해요.
