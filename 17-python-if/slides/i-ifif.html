total = 25000

if total >= 20000:

print("10% 할인")

elif total >= 10000:

print("5% 할인")

else:

print("할인 없음")

if 두 개 · 할인을 두 번 받아요

if, elif · 하나만 받아요

if마다 따로 물어요

if를 두 번 쓰면 갈림길이 두 개예요. 앞에서 True였어도 아래 if를 다시 물어서 둘 다 실행해요.

하나만 고를 땐 elif

따로 따로 확인할 일이면 if를 여러 번 써요.

둘 중 하나만이면 elif, 각각 따로 확인하면 if 여러 개예요.

if를 두 번 쓰면 무엇이 다른지 봐요. 왼쪽은 if를 두 번 썼어요. 첫 if가 True라 10% 할인을 찍고, 둘째 if를 다시 물어요. 25000은 10000 이상이기도 해서 5% 할인도 찍어요. 할인을 두 번 받는 셈이에요. 오른쪽은 elif예요. 처음 True를 만나면 나머지는 보지 않아서 하나만 찍어요. 할인처럼 하나만 골라야 하면 elif를 써요. 회원 쿠폰과 생일 쿠폰처럼 각각 따로 확인할 일이면 if를 여러 번 써요. 오른쪽 셀 [7]은 elif 장에서 total을 25000으로 바꿔 실행한 결과예요. 출력은 실제로 실행한 결과예요.
