2. if, else, elif

if를 따로 쓰면 둘 다 실행될 수 있어요

[10]

total = 25000

if total >= 20000:

print("10% 할인")

if total >= 10000:

print("5% 할인")

Python

10% 할인

5% 할인

[7]

total = 25000

if total >= 20000:

print("10% 할인")

elif total >= 10000:

print("5% 할인")

else:

print("할인 없음")

Python

10% 할인

← 갈림길 하나

← 갈림길 또 하나 · 다시 물어요

← 할인을 두 번 받아요

← elif · 처음 True에서 멈춰요

하나만 고르면 elif, 각각 따로 확인하면 if 여러 개예요.

if를 두 번 쓰면 갈림길이 두 개라서 둘 다 실행될 수 있어요. 위 셀은 첫 if가 True라 10% 할인을 찍고, 둘째 if를 다시 물어요. 25000은 10000 이상이기도 해서 5% 할인도 찍어요. 아래 셀은 elif라서 처음 True를 만나면 나머지는 보지 않아요. 할인처럼 하나만 골라야 하면 elif를 써요. 회원 쿠폰과 생일 쿠폰처럼 각각 따로 확인할 일이면 if를 여러 번 써요. 아래 셀 [7]은 elif 장에서 total을 25000으로 바꿔 실행한 결과예요. 출력은 실제로 실행한 결과예요.
