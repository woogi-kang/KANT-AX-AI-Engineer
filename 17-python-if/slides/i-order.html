2. if, else, elif

조건 순서를 바꾸면 결과가 달라져요

[9]

total = 25000

if total >= 10000:

print("5% 할인")

elif total >= 20000:

print("10% 할인")

else:

print("할인 없음")

Python

5% 할인

먼저 True

물어보지도 않음

25000원인데 5% 할인이 나왔어요

25000은 10000 이상이기도 해서 첫 줄에서 True가 나와요. 그 뒤의 elif는 보지 않아요.

좁은 조건부터 적어요

if total >= 20000: # 좁은 조건

elif total >= 10000: # 넓은 조건

else:

앞 장의 순서예요. 25000을 넣으면 10% 할인이 나와요.

elif는 위에서부터 묻고 처음 True에서 멈춰요. 큰 금액 조건을 위에 둬요.

앞 장의 두 조건을 순서만 바꿨어요. total이 25000이면 첫 조건 10000 이상이 이미 True예요. 그래서 5% 할인을 찍고, 아래의 20000 이상은 묻지도 않아요. 오류가 나지 않아서 틀린 줄 모르고 지나치기 쉬워요. 범위가 겹치는 조건은 좁은 쪽, 여기서는 큰 금액 조건을 위에 둬요. 그러면 25000은 첫 줄에서 10% 할인이 되고, 12000은 둘째 줄에서 5% 할인이 돼요. 출력은 실제로 실행한 결과예요.
