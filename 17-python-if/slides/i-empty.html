if orders:는 "주문이 하나라도 있으면"이라고 읽어요. 헷갈리면 len(orders) > 0으로 적어도 결과가 같아요. 남이 쓴 코드에서 if orders:를 만나면 이 뜻으로 읽어요.

빈 리스트는 False라서 if 리스트:는 "하나라도 있으면"이에요.

앞 장의 규칙을 실제로 쓰는 모양이에요. orders가 빈 리스트면 False로 봐서 else로 가요. 하나라도 들어 있으면 True로 봐서 if 안을 실행해요. 아래 if는 같은 일을 len으로 길게 쓴 거예요. 결과가 같아요. 처음에는 len(orders) > 0이 뜻이 더 잘 보여요. 실제 코드에서는 if orders:를 자주 만나니 읽을 수 있으면 돼요. 6파트 영수증 실습에서 이 모양을 써요. 출력은 실제로 실행한 결과예요.
