오류 없이 결과만 틀려요. 들여쓰기 칸 수가 if의 범위를 정해요.

if 안에 넣을 줄은 모두 같은 칸만큼 들여써요. 위 셀은 두 print를 모두 들여써서 돈이 모자라면 둘 다 건너뛰어요. 아래 셀은 커피 나왔어요를 들여쓰지 않았어요. 그 줄은 if 밖이라 조건과 상관없이 실행해서, 돈이 3000원인데도 커피가 나와요. 파이썬은 오류를 내지 않아서 직접 찾아야 해요. 다른 언어는 중괄호로 범위를 정하지만 파이썬은 들여쓰기로 정해요. 출력은 실제로 실행한 결과예요.
