elif는 else if를 줄인 말이에요. 앞 조건이 False일 때만 다음 조건을 물어요. True를 만나면 그 길만 가고 나머지는 보지 않아요.

if 하나, elif 여러 개, else 하나. 그중 하나만 실행해요.

갈림길이 세 개 이상이면 elif를 써요. else if를 줄인 말이에요. 2만 원 이상이면 10퍼센트, 1만 원 이상이면 5퍼센트, 나머지는 할인 없음이에요. 파이썬은 위에서부터 조건을 하나씩 물어요. total 12000은 20000 이상이 아니라 False라서 elif로 내려가요. 10000 이상은 True라서 5% 할인을 찍고, 아래 else는 보지도 않아요. 오른쪽 아래는 같은 셀을 total만 바꿔 실행한 결과예요. elif는 몇 개든 쓸 수 있고 else는 없어도 돼요. 출력은 실제로 실행한 결과예요.
