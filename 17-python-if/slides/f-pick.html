menu = {"coffee": 4500, "latte": 5000, "cake": 6500}

prices = [4500, 5000, 6500, 4000]

cheap = []

for p in prices:

if p <= 5000:

cheap.append(p)

print(cheap)

빈 리스트, for, if, append가 골라 담기의 기본 모양이에요.

for로 하나씩 꺼내면서 if로 물으면 조건에 맞는 값만 골라 담을 수 있어요. 메뉴 가격 중 5000원 이하만 새 리스트에 담아요. 빈 리스트 cheap을 만들고, for로 가격을 하나씩 꺼내요. 꺼낼 때마다 if로 5000 이하인지 묻고, True면 append해요. 6500은 False라 건너뛰어요. if는 for 안에 있어서 4칸, append는 if 안에 있어서 8칸 들여써요. 첫 줄의 menu는 이 파트의 뒤 셀에서 써요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
