money = 3000

if money >= price:

print("주문할 수 있어요")

print("다음 손님")

Python

다음 손님

실행

건너뜀

5000 >= 4500 → True

3000 >= 4500 → False

오류가 아니에요

False면 들여쓴 줄을 그냥 건너뛰고 if 다음 줄로 가요. 오른쪽 셀은 출력이 한 줄뿐이지만 정상이에요. price는 셀 [1]에서 넣은 4500이 그대로 남아 있어요.

같은 코드라도 값에 따라 실행하는 줄이 달라져요.

같은 if를 money만 바꿔서 두 번 실행해요. 왼쪽은 5000이라 조건이 True고, 들여쓴 print를 실행해요. 오른쪽은 3000이라 조건이 False예요. 들여쓴 print를 건너뛰고 바로 다음 손님을 찍어요. 오류가 난 게 아니라 일부러 건너뛴 거예요. 오른쪽 셀에는 price를 다시 적지 않았어요. 셀 [1]에서 넣은 4500이 그대로 남아 있어요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
