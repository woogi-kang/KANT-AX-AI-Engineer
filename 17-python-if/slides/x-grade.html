scores = [["kim", 92], ["lee", 78], ["park", 85], ["choi", 59]]

for name, score in scores:

if score >= 90:

grade = "A"

elif score >= 80:

grade = "B"

elif score >= 70:

grade = "C"

else:

grade = "F"

print(f"{name:<5}{score:>3} {grade}")

높은 점수 조건부터 내려가요

for 안에 elif 계단을 넣으면 한 명씩 등급이 나와요.

for 안에 elif 계단을 넣으면 한 명씩 등급을 매길 수 있어요. 14에서 이름과 점수를 같이 담은 2차원 리스트를 썼어요. 13의 for a, b in 모양으로 이름과 점수를 한 쌍씩 꺼내고, 점수가 높은 조건부터 elif로 계단을 내려가요. 92는 첫 계단에서 A, 78은 셋째 계단에서 C예요. 조건 순서를 바꾸면 2파트에서 본 것처럼 choi를 뺀 모두가 C가 돼요. if 계단은 for 안이라 4칸, 그 안의 grade는 8칸 들여써요. print는 for 안, if 밖이라 4칸이고 한 명마다 한 줄씩 찍혀요. 출력은 실제로 실행한 결과예요.
