5. 자주 나는 오류

글자와 숫자는 크기를 비교할 수 없어요

[7]

price = "4500"

if price >= 4000:

print("4000원 넘어요")

Python

TypeError: '>=' not supported between instances of 'str' and 'int'

← 따옴표가 있으면 글자(str)예요

비교한 두 값의 종류

[8]

if int(price) >= 4000:

print("4000원 넘어요")

Python

4000원 넘어요

← 12의 int()로 숫자로 바꿔요

== 로 비교하면 오류 없이 False가 나와서 if가 조용히 건너뛰어요. 더 찾기 어려워요.

비교 오류가 나면 type()으로 두 값의 종류부터 봐요.

따옴표로 감싼 4500은 글자라서 숫자와 크기를 비교하면 TypeError가 나요. 오류 끝의 str and int는 비교한 두 값의 종류예요. 12에서 배운 int()로 숫자로 바꾸면 돼요. 조심할 건 ==예요. 글자 4500과 숫자 4500을 ==로 비교하면 오류 없이 False가 나와서 if가 조용히 건너뛰어요. 이상하면 type()으로 두 값의 종류부터 봐요. 출력은 실제로 실행한 결과예요.
