6. 실습

어떤 모양을 쓸지 이렇게 골라요

if

할 일이 한 가지, 조건이 맞을 때만

예: 있으면 알려 주기

if, else

둘 중 하나는 꼭

예: 살 수 있음, 돈이 모자람

if, elif, else

셋 이상 중 하나만

예: 할인율, 등급

if 여러 개

각각 따로 확인

예: 쿠폰 여러 장

and, or, not

조건 여러 개를 하나로

예: 키와 나이, 회원이거나 5만 원

값1 if 조건 else 값2

변수에 둘 중 하나 넣기

예: msg 고르기

처음에는 길게 적고, 같은 모양이 반복되면 줄여 써요.

이번 챕터에서 본 모양을 언제 쓰는지 정리해요. 조건이 맞을 때만 할 일이 있으면 if 하나, 둘 중 하나는 꼭 해야 하면 if와 else예요. 셋 이상 중 하나만 고르면 elif, 각각 따로 확인하면 if를 여러 번 써요. 조건이 여러 개면 and, or, not으로 하나로 묶어요. 변수에 둘 중 하나를 넣을 때는 한 줄 모양도 있어요. 처음에는 길게 적고 결과를 확인한 뒤 줄여요.
