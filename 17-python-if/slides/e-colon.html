IndentationError: unexpected indent

들여쓰기 칸 수가 달라요

같은 칸(4칸)에 맞추기

IndentationError는 들여쓰기 오류예요. 칸 수를 4칸에 맞춰요.

콜론을 빠뜨리면 SyntaxError, 들여쓰기가 틀리면 IndentationError가 나고 둘 다 실행 전에 멈춰요. 1번은 if 줄 끝의 콜론이 없어서 expected 콜론이라고 정확히 알려 줘요. 2번은 if 다음 줄을 들여쓰지 않았어요. if 안에 들여쓴 줄이 하나는 있어야 해요. 3번은 같은 if 안에서 칸 수가 4칸, 6칸으로 달라요. unexpected indent는 생각지 못한 들여쓰기라는 뜻이에요. 오류 위쪽의 Cell In 줄은 빼고 마지막 줄만 옮겼어요. 출력은 실제로 실행한 결과예요.
