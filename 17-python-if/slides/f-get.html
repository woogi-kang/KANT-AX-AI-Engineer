if "cakee" in menu:

price = menu["cakee"]

else:

price = 5000

print(price)

print(menu["cakee"] if "cakee" in menu else 5000)

print(menu.get("cakee", 5000))

get은 위의 if, else를 대신해 주는 메서드예요. 실제로는 get을 써요.

15에서 배운 get은 if와 else 4줄을 대신해 주는 메서드예요. 15에서 get을 배울 때 같은 뜻의 한 줄 if else 코드를 참고 칸에 두고 읽기만 했어요. 이제 그 코드를 풀어서 if와 else 4줄로 쓸 수 있어요. cakee가 메뉴판에 있으면 그 가격, 없으면 5000이에요. 세 방법 모두 5000을 찍어요. 짧을수록 실수할 곳이 줄어서 실제로는 get을 쓰고, 4줄짜리는 get이 무슨 일을 하는지 이해하는 데 써요. 출력은 실제로 실행한 결과예요.
