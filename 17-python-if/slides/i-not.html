menu = {"coffee": 4500, "latte": 5000, "cake": 6500}

order = "tea"

if not order in menu:

print("메뉴판에 없어요")

if order not in menu:

print("메뉴판에 없어요")

결과는 같아요. 문장처럼 읽히는 not in을 더 많이 써요.

없을 때만 할 일이 있으면 else 대신 조건을 뒤집어요. 1파트 처음의 KeyError를 막는 첫 방법이에요.

"없으면"은 not in, "아니면"은 !=로 적어요.

not은 True와 False를 뒤집고, not in은 들어 있지 않은지 물어요. tea in menu는 False라서 not을 붙이면 True가 되고, 메뉴판에 없어요를 찍어요. 14의 not in으로 적어도 결과는 같은데, 영어 문장처럼 읽혀서 실제로는 not in을 많이 써요. 메뉴판에 없을 때만 할 일이 있으면 else를 쓰지 않고 조건을 뒤집어요. 1파트 처음의 KeyError는 이렇게 먼저 물어서 막을 수 있어요. 출력은 실제로 실행한 결과예요.
