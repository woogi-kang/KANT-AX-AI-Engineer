16의 "참고, 읽기만" 칸은 이제 모두 직접 칠 수 있어요.

16에서 읽기만 한 discard와 중복 없애기의 원래 코드를 이제 if로 직접 쳐요. 왼쪽은 discard예요. juice가 들어 있는지 먼저 묻고 있을 때만 remove해요. juice는 없어서 아무 일도 없고, discard 한 줄과 결과가 같아요. 오른쪽은 set(orders)로 중복을 없앤 일을 리스트로 직접 한 거예요. 아직 kinds에 없을 때만 append해요. 리스트는 처음 나온 순서를 지키고 집합은 sorted로 줄 세워서 순서가 다르지만, 담긴 값은 같아요. orders는 셀 [2]의 주문 리스트예요. 16의 교집합, 차집합 긴 코드도 같은 방법으로 직접 쳐 볼 수 있어요. 출력은 실제로 실행한 결과예요.
