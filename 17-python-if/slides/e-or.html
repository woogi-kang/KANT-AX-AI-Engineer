5. 자주 나는 오류

or 뒤에도 비교를 다시 적어요

[5]

order = "cake"

if order == "coffee" or "latte":

print("커피 종류예요")

print(order == "coffee" or "latte")

Python

커피 종류예요

latte

← cake인데 커피 종류래요

앞

order == "coffee"

→

False

or

False or "latte"

결과

"latte"

← 빈 글자가 아니라 True로 봐요

[6]

if order == "coffee" or order == "latte":

print("커피 종류예요")

else:

print("커피 종류가 아니에요")

print(order in ["coffee", "latte"])

Python

커피 종류가 아니에요

False

← 비교를 둘 다 적거나

← in과 리스트로 물어요

말로는 "coffee 또는 latte"지만 코드는 order == 를 두 번 적어요.

or 뒤에 비교 없이 값만 적으면 조건이 늘 True가 돼요. 말로는 주문이 coffee 또는 latte면이라고 하니 그대로 적기 쉬워요. 그런데 cake인데도 커피 종류예요가 찍히고, 오류가 나지 않아서 찾기 어려워요. 파이썬은 order == coffee와 latte를 or로 이은 걸로 읽어요. 앞은 False지만 뒤의 latte는 빈 문자열이 아니라 True로 봐요. print로 찍어 보면 latte가 그대로 나와요. 비교를 둘 다 적거나, 14의 in으로 리스트 안에 있는지 물으면 돼요. 출력은 실제로 실행한 결과예요.
