3. 조건 합치기

and는 두 조건이 모두 True일 때만 True예요

[1]

height = 130

age = 9

if height >= 120 and age >= 7:

print("탈 수 있어요")

else:

print("다음에 타요")

Python

탈 수 있어요

[2]

height = 110

if height >= 120 and age >= 7:

print("탈 수 있어요")

else:

print("다음에 타요")

Python

다음에 타요

키

130 >= 120

→

True

나이

9 >= 7

→

True

and

True and True

→

True

키

110 >= 120

→

False

나이

9 >= 7

→

True

and

False and True

→

False

12의 놀이기구 조건을 if에 넣어 실행할 줄을 골라요.

and로 이은 조건은 둘 다 True일 때만 True예요. 12에서 놀이기구 탑승 조건을 키 120 이상 그리고 7살 이상으로 적었어요. 그때는 True, False를 보기만 했는데, 이제 if에 넣어서 실행할 줄을 골라요. 위 셀은 두 비교가 모두 True라서 탈 수 있어요. 아래 셀은 키만 110으로 바꿨고, age는 앞 셀의 9가 그대로예요. 키가 False라 and 전체가 False고 else로 가요. 비교를 먼저 계산하고 and를 나중에 해서 괄호가 없어도 돼요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
