menu = {"coffee": 4500, "latte": 5000, "cake": 6500}

cart = {"coffee": 2, "cake": 1}

total = 0

for name, qty in cart.items():

total += menu[name] * qty

if total >= 20000:

rate = 10

elif total >= 10000:

rate = 5

else:

rate = 0

sale = total * rate // 100

print(f"합계 {total:>7,}원")

print(f"할인 {sale:>7,}원 ({rate}%)")

print(f"결제 {total - sale:>7,}원")

for로 합계를 내고, elif로 할인율 하나를 골라요.

for로 장바구니 합계를 내고 elif로 할인율 하나를 고르면 할인 영수증이 나와요. 15의 메뉴판과 장바구니 딕셔너리를 써요. items()로 장바구니를 돌며 가격 곱하기 수량을 total에 쌓으면 15500원이에요. 2만 원 이상 10, 1만 원 이상 5, 나머지 0이라 15500은 5퍼센트예요. 할인 금액은 total 곱하기 rate를 100으로 나눈 몫이에요. 12의 // 라서 소수점 없이 775원이 돼요. 출력은 13의 칸 맞추기와 천 단위 콤마예요. cart를 바꿔 2만 원이 넘게 담아 보고 10% 할인이 나오는지 확인해요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
