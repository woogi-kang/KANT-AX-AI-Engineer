Python

문 닫았어요

"사이에 있나요?"는 작은 값 <= 변수 < 큰 값으로 물어요.

가운데에 변수를 두고 양쪽에 경계를 적으면 범위를 한 번에 물을 수 있어요. 가게가 9시부터 18시 전까지 열어요. 파이썬은 수학 부등식처럼 9 <= hour < 18로 이어 적을 수 있고, hour >= 9 and hour < 18과 결과가 같아요. 9는 작거나 같다라서 들어가고, 18은 작다라서 빠져요. 경계 숫자가 들어가는지는 등호가 있는지로 정해요. 20시는 범위 밖이라 else로 가요. 출력은 실제로 실행한 결과예요.
