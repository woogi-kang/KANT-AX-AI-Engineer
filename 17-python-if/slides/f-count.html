orders = ["coffee", "latte", "coffee", "cake", "tea", "coffee"]

n = 0

for o in orders:

if o == "coffee":

n += 1

print(n)

print(orders.count("coffee"))

세기는 n = 0에서 시작해서, 조건이 True일 때 n += 1이에요.

n을 0으로 두고 조건이 True일 때만 1을 더하면 조건에 맞는 개수를 셀 수 있어요. 주문 중 coffee가 몇 잔인지 세요. 오른쪽 표처럼 coffee를 만날 때마다 n이 1, 2, 3으로 늘어요. 같은 값 하나를 셀 때는 13의 count로 한 줄이면 되고 결과도 3으로 같아요. 그래도 for와 if를 알아야 하는 이유는 가격이 5000원 이상인 주문처럼 조건이 붙은 개수는 count로 못 세기 때문이에요. 출력은 실제로 실행한 결과예요.
