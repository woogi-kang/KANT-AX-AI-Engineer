orders = ["coffee", "latte", "coffee", "cake", "tea", "coffee"]

값 하나를 셀 땐 count가 짧아요

같은 값의 개수는 13의 count로 바로 세요. 5000원 이상처럼 조건이 붙으면 count로는 못 세서 for와 if를 써요.

세기는 n = 0에서 시작해 조건이 True일 때 n += 1이에요.

주문 중 coffee가 몇 잔인지 세요. n을 0으로 두고 for로 하나씩 꺼내요. coffee일 때만 n에 1을 더해요. 오른쪽 표처럼 coffee를 만날 때마다 n이 1, 2, 3으로 늘어요. 같은 값 하나를 셀 때는 13의 count로 한 줄이면 돼요. 결과가 3으로 같아요. 그래도 for와 if를 알아야 하는 이유는 가격이 5000원 이상인 주문처럼 조건이 붙은 개수는 count로 못 세기 때문이에요. 출력은 실제로 실행한 결과예요.
