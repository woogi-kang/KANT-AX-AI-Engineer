3. 조건 합치기

if 안의 if는 and 한 줄로 줄일 수 있어요

[3]

height = 130

if height >= 120:

if age >= 7:

print("탈 수 있어요")

Python

탈 수 있어요

← 4칸 · 바깥 if가 True일 때만 물어요

← 8칸 · 둘 다 True일 때만 실행

and로 줄이면

[ ]

if height >= 120:

if age >= 7:

print("탈 수 있어요")

Python

[ ]

if height >= 120 and age >= 7:

print("탈 수 있어요")

Python

탈 수 있어요

← 셀 [3]과 같은 결과, 들여쓰기는 한 번

들여쓰기가 깊어지면 and로 합칠 수 있는지 먼저 봐요.

if 안에 다시 if를 넣을 수 있고, 할 일이 한 군데뿐이면 and 한 줄로 줄일 수 있어요. 바깥 if가 True일 때만 안쪽 if를 물어요. 안쪽 if의 줄은 4칸을 한 번 더 들여써서 8칸이에요. 키가 120 이상이고 나이가 7 이상이어야 실행하니 and로 이은 조건과 같아요. 아래처럼 한 줄로 적으면 들여쓰기가 얕아져서 읽기 쉬워요. 메뉴판에 있으면 먼저 가격을 찍고 그다음 5000원 이하인지 다시 묻는 것처럼, 바깥 조건이 맞은 뒤에 따로 할 일이 있을 때는 안쪽 if가 필요해요. 출력은 실제로 실행한 결과예요.
