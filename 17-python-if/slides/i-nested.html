if height >= 120 and age >= 7:

탈 수 있어요

if 안에도 if를 넣을 수 있어요

바깥 if가 True일 때만 안쪽 if를 물어요. 안쪽 if 안의 줄은 8칸 들여써요. 두 조건이 모두 맞아야 실행하니 and와 같아요.

언제 안쪽 if를 쓰나요

바깥 조건이 맞은 뒤에 따로 할 일이 있을 때예요. 예를 들어 메뉴판에 있으면 먼저 가격을 찍고, 그다음 5000원 이하인지 다시 물어요. 할 일이 한 군데뿐이면 and가 더 읽기 쉬워요.

들여쓰기가 깊어지면 and로 합칠 수 있는지 먼저 봐요.

if 안에 다시 if를 넣을 수 있어요. 바깥 if가 True일 때만 안쪽 if를 물어요. 안쪽 if의 줄은 4칸을 한 번 더 들여써서 8칸이에요. 키가 120 이상이고, 그다음 나이가 7 이상이어야 실행하니 and로 이은 조건과 같아요. 오른쪽처럼 한 줄로 적으면 들여쓰기가 얕아져서 읽기 쉬워요. 바깥 조건이 맞은 뒤에 따로 할 일이 있을 때는 안쪽 if가 필요해요. 출력은 실제로 실행한 결과예요.
