[1]

order = "coffee"

if order = "coffee":

print("커피예요")

← 둘째 줄이 문제예요

"== 를 쓰려던 거 아니에요?" · := 는 배우지 않은 기호예요

if order = "coffee":

✓

if order == "coffee":

= 하나는 넣기, == 두 개는 묻기 (12)

SyntaxError는 실행 전에 문법을 검사하다 나서, 셀의 어느 줄도 실행되지 않아요.

SyntaxError가 나면 line 숫자의 줄부터 봐요.

if 뒤에 = 하나를 쓰면 SyntaxError가 나고, == 두 개로 고쳐요. 12에서 = 하나는 넣기, == 두 개는 묻기라고 배웠어요. 오류 위쪽의 line 2는 둘째 줄이 문제라는 뜻이에요. 마지막 줄은 ==를 쓰려던 거 아니냐고 고칠 곳까지 알려 줘요. :=는 배우지 않은 기호라 신경 쓰지 않아요. SyntaxError는 실행 전에 문법을 검사하다 나서 첫 줄의 order도 만들어지지 않아요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
