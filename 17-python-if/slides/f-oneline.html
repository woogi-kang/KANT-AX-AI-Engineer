4. for와 함께, 줄여 쓰기

if와 else를 한 줄로 줄여 쓸 수 있어요

[4]

total = 12000

if total >= 10000:

msg = "5% 할인"

else:

msg = "할인 없음"

print(msg)

msg = "5% 할인" if total >= 10000 else "할인 없음"

print(msg)

Python

5% 할인

5% 할인

원래 방법 · 4줄

줄인 방법 · 1줄

msg = "5% 할인" if total >= 10000 else "할인 없음"

True일 때 값

조건

False일 때 값

변수에 둘 중 하나를 넣을 때만 줄여요.

값1 if 조건 else 값2는 조건이 True면 값1, 아니면 값2라는 뜻이에요. if와 else로 변수에 둘 중 하나를 넣는 모양은 아주 자주 나와서 한 줄로 줄이는 방법이 있어요. True일 때 값을 먼저 쓰고, if 조건, else False일 때 값 순서로 적어요. 결과는 4줄짜리와 같아요. 실행할 줄이 여러 개이거나 갈림길이 셋 이상이면 원래 모양이 읽기 쉬워요. 처음엔 4줄로 적고, 남의 코드에서 한 줄 모양을 만나면 읽을 수 있으면 돼요. 출력은 실제로 실행한 결과예요.
