4. for와 함께, 줄여 쓰기

if와 else를 한 줄로 줄여 쓸 수 있어요

[4]

total = 12000

if total >= 10000:

msg = "5% 할인"

else:

msg = "할인 없음"

print(msg)

msg = "5% 할인" if total >= 10000 else "할인 없음"

print(msg)

Python

5% 할인

5% 할인

원래 방법 · 4줄

줄인 방법

True일 때 값

"5% 할인"

조건

if total >= 10000

False일 때 값

else "할인 없음"

값 하나를 고를 때만 줄여요

변수에 넣을 값이 둘 중 하나일 때 써요. 실행할 줄이 여러 개이거나 elif가 필요하면 원래 모양으로 적어요.

읽는 순서

"1만 원 이상이면 5% 할인, 아니면 할인 없음"

값1 if 조건 else 값2는 "조건이 True면 값1, 아니면 값2"예요.

if와 else로 변수에 둘 중 하나를 넣는 모양은 아주 자주 나와요. 그래서 한 줄로 줄이는 방법이 있어요. True일 때 값을 먼저 쓰고, if 조건, else False일 때 값 순서로 적어요. 결과는 4줄짜리와 같아요. 줄인 방법은 값 하나를 고를 때만 써요. 실행할 줄이 여러 개이거나 갈림길이 셋 이상이면 원래 모양이 읽기 쉬워요. 처음엔 4줄로 적고, 남의 코드에서 한 줄 모양을 만나면 읽을 수 있으면 돼요. 출력은 실제로 실행한 결과예요.
