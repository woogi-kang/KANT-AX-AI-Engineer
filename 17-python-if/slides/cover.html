제어문 1
조건문 if

조건에 따라
다른 줄을 실행하기

if total >= 20000:

print("10% 할인")

elif total >= 10000:

print("5% 할인")

else:

print("할인 없음")

이번 챕터에서는 조건이 True일 때만 실행하는 if를 직접 써요. 15와 16에서 참고 칸에 두고 읽기만 했던 if 코드를 이번에 직접 쳐요. 12의 비교와 and, or, not, 13의 for를 그대로 가져와요. 같은 카페 예제로 이어 가고, 18에서는 while과 break로 반복을 다뤄요.
