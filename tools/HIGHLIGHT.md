# 강조 기법 고르기

덱을 새로 만들거나 장의 강조를 바꿀 때만 읽어요. 장마다 상황에 맞는 기법을 아래 표에서 골라요. 움직이는 견본은 [강조 기법 견본집](https://claude.ai/artifact/DTBZwHG5jbzezd67No4Xch)에 있어요(견본 번호를 표에 같이 적었어요).

덱 하나에 되도록 여러 기법을 고루 써요. 같은 기법이 장마다 되풀이되면 눈에 안 띄어요. 표의 "한 덱에" 칸은 그 기법을 몇 장까지 쓰는지예요.

## 상황별 기법

### 가리키기

| 상황 | 기법 (견본) | 쓰는 법 | 한 덱에 |
| --- | --- | --- | --- |
| 화면 캡처에서 누를 곳, 표의 한 줄이나 한 칸 | 구멍 스포트라이트 | `spot(순서, x, y, w, h)` 또는 `target="id"`, 끝에 `spot_off(순서)` | 제한 없음 |
| 밝은 화면에서 카드 하나, 어둡게 하면 글이 안 읽힐 때 | 배경 흐리기 (3-4) | `blur(순서, "id")`, 끝에 `blur_off(순서)` | 3장 |
| 무엇을 어떤 순서로 누르는지 | 커서와 클릭 물결 | `cursor(순서, target="id")`, 끝에 `cursor_off(순서)` | 제한 없음 |
| 단축키를 누르는 장 | 키 표시 (3-2) | `keys(순서, x, y, "control+Enter")` | 제한 없음 |
| 오류 메시지, 꼭 볼 한 단어 | 펜 동그라미, 밑줄, 상자 (3-3) | `ring()`, `underline()`, 줄이 붙어 있으면 `box()` | 제한 없음 |
| 앞에 나온 값을 다시 짚기 | 펄스, 커졌다 작아지기 (2-5) | `pulse(순서, "id")`, `grow(순서, "id")` | 4장 |

### 코드

| 상황 | 기법 (견본) | 쓰는 법 | 한 덱에 |
| --- | --- | --- | --- |
| 코드를 한 줄씩 읽어 주기 | 줄 스포트라이트 (4-2) | `lspot(순서, 코드칸 x, y, w, h, 줄 y, 줄 높이, bg=칸 배경)`, 끝에 `lspot_off(순서)` | 제한 없음 |
| 코드 한 줄을 실행/건너뜀/오류로 표시 | 줄 칠하기 | 챕터 `gen.py`의 `hl()` | 제한 없음 |
| 반복문, 함수가 실행되는 순서 | 실행 막대 (4-3) | `run(순서, x, y, w, h)`를 줄마다, 끝에 `run_off(순서)`. 변수 칸은 `text()` | 3장 |
| 칸의 값이 바뀜 | 값 바꾸기 | 칸에 마지막 값과 `data-start="처음 값"`, 바뀔 때마다 `text(순서, "id", "값")` | 제한 없음 |
| 긴 코드를 줄여 쓰기, 코드를 고친 뒤 | 코드 모핑 (4-1) | 앞 코드 `MORPH_FROM()`, 뒤 코드 `MORPH(순서, "앞 id")`, 같은 조각은 `tok("키", 글자)` | 4장 |
| 오타, 고친 글자 | 바뀐 글자만 칠하기 (4-4) | 끝 모습으로 칠한 span에 `MARK(순서)` | 제한 없음 |
| 코드의 이름과 그림의 칸 | 같은 색 짝 맞추기 (4-5) | 짝끼리 같은 색으로 칠한 span에 `MARK(순서)` | 제한 없음 |
| print가 여러 개인 셀 | 코드와 출력 잇기 (4-6) | `link(순서, 코드 x, y, 출력 x, y, 색)` | 4장 |
| 긴 출력에서 한 줄 찾기 | 화면 따라가기 (3-7) | 넘치는 칸 안의 출력에 id, `pan(순서, "id", -이동 px)` | 2장 |

### 목록과 숫자

| 상황 | 기법 (견본) | 쓰는 법 | 한 덱에 |
| --- | --- | --- | --- |
| 목록, 단계가 한꺼번에 나올 때 | 시차 (1-3) | 감싸는 칸에 `STAGGER(순서)` | 제한 없음 |
| 단계를 하나씩 설명하는 목록 | 지난 항목 흐리기 (2-3) | 단계마다 다른 순서의 `rise`와 `DIM("묶음 이름")` | 제한 없음 |
| 표의 줄, 그래프 선 | 마스크 드러내기 (3-5) | `WIPE(순서)` | 제한 없음 |
| 그림에 붙은 라벨 | 여운 (1-7) | 라벨에 같은 순서와 `DELAY(150)` | 제한 없음 |
| 차트, 표에서 하나 | 하나만 색 남기기 (4-7) | 나머지는 회색, 하나만 색. 그 하나에 `MARK(순서)`나 `pulse()` | 제한 없음 |
| 합계, 개수 | 숫자 올라가기 (2-8) | 마지막 숫자를 적은 요소에 `COUNT(순서)` | 2장 |

### 장면과 전환

| 상황 | 기법 (견본) | 쓰는 법 | 한 덱에 |
| --- | --- | --- | --- |
| 그림이 한 단계씩 바뀌는 두 장 | 모핑 (2-1) | 뒤 장에 `transition="magic"`, 같은 물체는 같은 id | 제한 없음 |
| 값이 다른 곳으로 옮겨 감 | 날아오기 | `data-build-in="fly order N" data-from="id"` | 제한 없음 |
| push, 요청처럼 데이터가 길을 따라 감 | 경로 애니메이션 (2-7) | SVG 길에 id, 점에 `PATH(순서, "길 id")`. 점은 길의 끝에 그려 둬요 | 3장 |
| 큰 그림에서 한 칸을 자세히, 화면 캡처의 작은 버튼 | 확대, 펀치인 (2-6, 3-1) | `zoom(순서, x, y, w, h)`, 끝에 `zoom_off(순서)` | 3장, 한 장에 한 번 |
| 명령과 결과 그림을 같이 | 화면 속 화면 (3-6) | 작은 창에 `SLIDE(순서, 400, 300)` | 제한 없음 |
| 파트가 바뀜 | 진행 표시 (2-4) | 파트 첫 장에 목차를 다시 두고 지금 파트만 진하게, `transition="magic"` | 파트마다 |
| 전과 후를 직접 비교 | 전후 비교 슬라이더 (4-8) | `compare("id", x, y, w, h, 전 HTML, 후 HTML)`. 눌러 보기 장이에요 | 2장 |

### 표지와 파트 첫 장에만

읽을 글이 적은 장에서만 써요. 설명하는 장에 쓰면 읽는 동안 글자가 움직여요.

| 상황 | 기법 (견본) | 쓰는 법 | 한 덱에 |
| --- | --- | --- | --- |
| 표지의 한 단어 | 키네틱 타이포그래피 (3-10) | `SLAM(순서)` | 1장 |
| 표지, 파트 첫 장의 버튼이나 배지 | 빛 훑기 (3-8) | `shine(순서, "id")` | 1장 |
| 실패하는 순간 (push 거절 등) | 살짝 흔들기 (3-8) | `shake(순서, "id")` | 2장 |
| 표지 그림 | 켄 번스 (3-9) | `kenburns(순서, "id")` | 1장 |

함수는 모두 `tools/highlight.py`에 있어요. 챕터 `gen.py` 맨 위에서 이렇게 불러요.

```python
sys.path.insert(0, os.path.join(os.path.dirname(os.path.abspath(__file__)), "..", "..", "tools"))
from highlight import *
```

순서는 다른 `data-build-in`과 같은 번호를 써요. 같은 번호끼리는 한 번에 나와요. 대문자 함수(`WIPE`, `STAGGER` 등)는 요소의 여는 태그 안에 넣는 속성이고, 소문자 함수(`spot`, `lspot`, `zoom` 등)는 화면에 안 그려지는 빈 상자를 하나 더해요. 예시는 23 챕터 `tools/gen.py`예요.

## 지킬 것

1. 강조는 한 번에 하나만 둬요. 다음 강조가 나오면 앞의 강조는 꺼요.
2. 색 뜻은 줄 칠하기와 같아요. 초록은 실행, 회색은 건너뜀, 빨강은 오류, 파랑은 표시, 주황은 짚어 볼 곳이에요.
3. 스포트라이트를 켠 채 설명 카드를 띄우지 않아요. 카드가 어두워져서 안 읽혀요. `spot_off`와 카드를 같은 번호로 둬요. 옆 카드를 읽으며 눌러야 하는 장은 `dim=0.5`로 덜 어둡게 해요.
4. 확대처럼 화면 전체가 움직이는 효과는 한 장에 한 번까지만 써요.
5. 클릭을 아껴요. 시차, 여운, 지난 항목 흐리기처럼 클릭이 안 늘어나는 기법을 먼저 골라요. 한 장의 클릭은 다섯 번 안쪽으로 둬요.
6. PDF에는 끝 화면이 들어가요. 스포트라이트, 커서, 줄 스포트라이트, 실행 막대, 확대는 PDF에 안 나오고, 동그라미, 밑줄, 칠한 글자, 연결선, 바뀐 값은 끝 모습으로 나와요. 코드 모핑은 뒤 코드만 나와요. 끝 화면만 봐도 읽히게 만들어요.
7. 애니메이션 끄기(A)를 누르면 모든 강조가 끝 상태로 바로 가요. 따로 처리할 필요는 없어요.

플레이어를 고치면 모든 덱이 영향을 받아요. 한 덱을 다시 만들어 전과 같은지 비교해요.
