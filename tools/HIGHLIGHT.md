# 강조 기법 고르기

덱을 새로 만들거나 장의 강조를 바꿀 때만 읽어요. 장마다 상황에 맞는 기법을 아래 표에서 하나 골라요.

## 상황별 기법

| 상황 | 기법 | 쓰는 법 |
| --- | --- | --- |
| 화면 캡처에서 누를 곳, 표의 한 줄이나 한 칸 | 구멍 스포트라이트 | `spot(순서, x, y, w, h)` 또는 `spot(순서, target="id")`, 끝에 `spot_off(순서)` |
| 무엇을 어떤 순서로 누르는지 | 커서와 클릭 물결 | `cursor(순서, target="id")`, 끝에 `cursor_off(순서)` |
| 오류 메시지, 꼭 볼 한 단어 | 펜으로 동그라미, 밑줄 | `ring(순서, x, y, w, h, 색)`, `underline(순서, x1, x2, y, 색)`. 메뉴 항목처럼 줄이 붙어 있으면 `box()` |
| 코드 한 줄 | 줄 칠하기 | 챕터 `gen.py`의 `hl()` (지금 방식) |
| 값이 다른 곳으로 옮겨 감 | 날아오기 | `data-build-in="fly order N" data-from="id"` |

함수는 모두 `tools/highlight.py`에 있어요. 챕터 `gen.py` 맨 위에서 이렇게 불러요.

```python
sys.path.insert(0, os.path.join(os.path.dirname(os.path.abspath(__file__)), "..", "..", "tools"))
from highlight import spot, spot_off, cursor, cursor_off, ring, box, underline
```

순서는 다른 `data-build-in`과 같은 번호를 써요. 같은 번호끼리는 한 번에 나와요. 예시는 05 챕터 `tools/gen.py`의 `scene()`, 설치 장, 화면 읽기 장이에요.

## 지킬 것

1. 강조는 한 번에 하나만 둬요. 다음 강조가 나오면 앞의 강조는 꺼요.
2. 색 뜻은 줄 칠하기와 같아요. 초록은 실행, 회색은 건너뜀, 빨강은 오류, 파랑은 표시, 주황은 짚어 볼 곳이에요.
3. 스포트라이트를 켠 채 설명 카드를 띄우지 않아요. 카드가 어두워져서 안 읽혀요. `spot_off`와 카드를 같은 번호로 둬요. 옆 카드를 읽으며 눌러야 하는 장은 `dim=0.5`로 덜 어둡게 해요.
4. 확대처럼 화면 전체가 움직이는 효과는 한 장에 한 번까지만 써요.
5. PDF에는 끝 화면이 들어가요. 스포트라이트와 커서는 PDF에 안 나오고, 동그라미와 밑줄은 다 그려진 채로 나와요. 끝 화면만 봐도 읽히게 만들어요.
6. 애니메이션 끄기(A)를 누르면 모든 강조가 끝 상태로 바로 가요. 따로 처리할 필요는 없어요.

## 아직 플레이어에 없는 기법

견본만 만들어 둔 기법이에요. 쓰려면 먼저 `tools/build_player.js`에 넣어요.

- 줄 스포트라이트: 설명하는 줄만 남기고 나머지 줄을 흐리게
- 따라가는 실행 막대: 막대가 줄 사이를 오르내리고 변수 칸이 반짝임
- 확대와 이동: 큰 그림에서 한 칸으로 다가갔다가 빠져나오기
- 말풍선과 연결선, 같은 색 짝 맞추기, 바뀐 글자만 칠하기

플레이어를 고치면 모든 덱이 영향을 받아요. 한 덱을 다시 만들어 전과 같은지 비교해요.
