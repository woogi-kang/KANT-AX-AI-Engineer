# 덱 디자인 규칙과 검수

덱을 새로 만들거나 장을 고칠 때, 그리고 main에 올리기 전에 읽어요. 강조 기법 고르기는 `tools/HIGHLIGHT.md`에 따로 있어요.

## 1. 디자인 규칙

benjitaylor/skills의 Stageshow 규칙 중 우리 덱에 맞는 다섯 가지만 가져왔어요. 그 스킬의 React 키트와 촬영 도구는 쓰지 않아요.

1. 장마다 주인공은 하나예요. 코드, 그림, 화면 캡처 중 하나를 크게 두고 나머지는 작고 조용하게 둬요. 같은 무게의 테두리 카드를 여러 개 나란히 놓지 않아요.
2. 용어 설명은 카드 대신 그림 옆에 직접 붙여요. 코드 줄 옆 짧은 라벨, 선으로 이은 말풍선을 써요.
3. 같은 말은 한 번만 해요. 발표자 노트와 겹치는 카드 문장은 빼고, 장 아래에는 한 문장 캡션만 둬요.
4. 빈 띠를 남기지 않아요. 아래나 옆이 비면 주인공 그림이나 코드 글씨를 키워서 채워요.
5. 바뀌는 값은 갈아 끼우지 말고 움직여서 바꿔요. 날아오기(`fly`), 스포트라이트, 반짝임을 써요.

## 2. 여백과 정렬 검수

자동 점검(`node ../tools/check.js slides 출력폴더`)만으로는 부족해요. 모든 장을 원본 크기(1920x1080)로 한 장씩 열어서 아래를 봐요. 애니메이션이 있는 장은 처음 화면과 끝 화면을 둘 다 봐요.

- 글자가 다른 글자, 선, 테두리와 겹치지 않아요.
- 글자가 상자 밖으로 삐져나오거나 단어 중간에서 줄이 바뀌지 않아요.
- 같은 종류의 상자는 왼쪽 끝, 위쪽 끝, 안쪽 여백이 같아요.
- 나란한 설명 라벨은 같은 세로줄에 있어요.
- 화살표, 라벨, 동그라미가 가리키는 대상이 정확해요. 한 칸 옆을 가리키면 안 돼요.
- 화면 가장자리에서 40px 안쪽에 내용이 있어요.
- 같은 표시(번호 동그라미, ✓, 아이콘)는 크기와 굵기가 장마다 같아요.
- 스포트라이트 구멍과 커서는 대상 위에 정확히 놓여요.

고친 장은 다시 원본 크기로 봐요. 한 장을 고치다 옆 장이 밀리는 일이 많아요.

## 3. AI 티 나는 말 걷어 내기

맨 위 CLAUDE.md의 한국어 글쓰기 지침을 먼저 따르고, 슬라이드에서는 아래를 더 봐요.

| 이런 말이 보이면 | 이렇게 |
| --- | --- |
| "핵심", "강력한", "효율적인", "다양한", "쉽고 빠르게" | 무엇이 몇 개, 몇 초인지 구체적으로 쓰거나 빼요 |
| "~에 대해 알아보겠습니다", "~를 살펴봐요"처럼 무엇을 배우는지 안 알려 주는 제목 | 그 장에서 배우는 사실을 제목으로 써요. 예: "굵은 이름표가 지금 있는 브랜치예요" |
| 그림을 그대로 다시 읽어 주는 캡션 | 그림만으로 모르는 한 가지만 적거나 빼요 |
| "정리하면", "이처럼", "결론적으로"로 시작하는 마무리 | 빼요. 마지막 장은 할 일이나 다음 챕터로 끝내요 |
| "A가 아니라 B예요"를 장마다 반복 | 한 덱에 한두 번까지만 써요 |
| 이모지, 느낌표, 꾸밈용 아이콘 | 빼요. 아이콘은 뜻이 있을 때만 둬요 |
| 같은 문장이 제목, 카드, 노트에 모두 있음 | 한 곳에만 남겨요 |

다 고친 뒤 소리 내어 읽어 봐요. 강사가 수업에서 실제로 할 말처럼 들려야 해요.
