rebase 대신 merge

이미 push한 브랜치에 최신 main을 받을 때는 rebase 대신 내 브랜치에서 git pull origin main으로 합쳐요. PR을 올리고 리뷰를 기다리는 동안 lee가 비밀번호 안내 커밋(F)을 main에 또 올렸어요. 이번엔 브랜치를 이미 push해서 rebase하면 6부의 거절이 나요. 06에서 본 것처럼 내 브랜치에서 pull하면 pull.rebase false 설정대로 합치기 커밋 M이 생겨요. M은 원래 커밋을 바꾸지 않으니 push가 거절 없이 올라가요. From 줄, 파일 목록 줄, To 줄도 나오는데, 그 부분은 빼고 옮겼어요.
