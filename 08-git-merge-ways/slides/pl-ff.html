pull.ff only: 갈라졌으면 받지 않아요

# pull.ff only인 컴퓨터

$ git pull origin main

멈춰서 그림이 그대로예요

pull.ff only면 갈라지지 않았을 때만 fast-forward로 받고, 갈라졌으면 멈춰요. 보기만 하는 장이에요. 그래프가 앞 장과 같은 건 실패해서 바뀐 게 없기 때문이에요. 이 설정이 있는 컴퓨터에서 이 메시지가 나오면 git config --global --unset pull.ff로 지우고 수업 설정만 남겨요. From 줄과 힌트 줄(git merge --no-ff 또는 git rebase)도 나오는데, 그 부분은 빼고 옮겼어요.
