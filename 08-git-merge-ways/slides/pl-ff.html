4. git pull은 무엇을 하나

pull.ff only: 갈라졌으면 받지 않아요

# pull.ff only인 컴퓨터

$ git pull origin main

fatal: Not possible to fast-forward, aborting.

갈라지지 않았을 때만 fast-forward로 받아요. 갈라지면 직접 골라야 해요.

◀ HEAD

보기만 하는 장이에요. 내 main에 새 커밋이 없으면 fast-forward로 받고, 갈라졌으면 아무것도 하지 않고 멈춰요. 그래프가 앞 장과 같은 건 실패해서 바뀐 게 없기 때문이에요. From 줄과 힌트 줄(git merge --no-ff 또는 git rebase)은 뺐어요.
