6. 충돌과 주의

언제 무엇을 쓰나요

git pull 할 때

설정대로 merge

pull.rebase false

PR을 합칠 때

팀이 정한 Merge 버튼 하나

GitHub

push 전, 내 브랜치를 최신 main 뒤로

rebase를 써도 돼요

git rebase main

push한 브랜치, main

rebase하지 않아요

merge만

수업에서 직접 치는 건 첫째 줄과 둘째 줄이에요. 셋째 줄은 개인 브랜치에서 연습할 때만 써요. 넷째 줄은 꼭 지켜요. 헷갈리면 merge를 써요. merge는 기록을 바꾸지 않아서 잘못해도 되돌리기 쉬워요.
