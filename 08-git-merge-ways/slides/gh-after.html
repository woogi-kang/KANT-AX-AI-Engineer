5. GitHub PR의 Merge 버튼

Squash나 Rebase 버튼 뒤에는 -D로 지워요

$ git checkout main

$ git pull origin main

Updating d51d818..d6514f3

Fast-forward

$ git log --oneline

d6514f3 (HEAD -> main, origin/main) feat: 로그인 버튼 추가 (#1)

$ git branch -d feature/login-button

error: the branch 'feature/login-button' is not fully merged.

If you are sure you want to delete it, run 'git branch -D feature/login-button'

GitHub에서 PR이 Merged로 바뀐 걸 확인했으면 지워도 돼요.

git branch -D feature/login-button

03에서 배운 PR 뒤 순서(main으로 가서 pull, 브랜치 지우기) 그대로예요. Create a merge commit으로 합쳤으면 -d로 지워져요. Squash and merge나 Rebase and merge는 GitHub이 새 커밋을 만들어서, 내 컴퓨터의 브랜치 커밋은 main과 이어지지 않아요. 그래서 -d가 거절해요. PR 화면에 보라색 Merged 표시가 있으면 -D로 지워요. From 줄과 파일 목록 줄은 뺐어요.
