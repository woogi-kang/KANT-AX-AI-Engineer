D', E' 해시가 새로 생겨요

그림은 GitHub에서 합친 뒤 GitHub 쪽 main 모양이에요. Create a merge commit 메시지는 03에서 본 Merge pull request #1 from kim/feature/login-button이에요. Squash and merge는 PR 제목 뒤에 (#1)을 붙인 커밋 하나가 생겨요. Rebase and merge는 갈라지지 않았어도 GitHub이 커밋을 새로 만들어서 해시가 바뀌어요. 어느 버튼을 쓸지는 팀이 정해요. 한 팀이 버튼을 섞어 쓰면 기록 모양이 PR마다 달라져서 읽기 어려워요.
