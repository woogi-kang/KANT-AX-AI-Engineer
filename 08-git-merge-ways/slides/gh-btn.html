5. GitHub PR의 Merge 버튼

PR의 Merge 버튼은 세 가지예요

feat: 로그인 버튼 추가 #1

Open

kim wants to merge 2 commits into main from feature/login-button

This branch has no conflicts with the base branch

Merge pull request

▼

Create a merge commit

All commits from this branch will be added to the base branch via a merge commit.

git merge --no-ff

합치기 커밋을 만들어요

Squash and merge

The 2 commits from this branch will be combined into one commit in the base branch.

git merge --squash

커밋 하나로 합쳐요

Rebase and merge

The 2 commits from this branch will be rebased and added to the base branch.

git rebase

옮겨 붙여요

PR 화면의 초록 버튼 오른쪽 ▼를 누르면 합치는 방법 세 가지가 나와요. Create a merge commit은 갈라지지 않았어도 늘 합치기 커밋을 만들어서 --no-ff와 같아요. Squash and merge는 2부의 squash, Rebase and merge는 2부의 rebase 뒤 fast-forward와 같아요. 버튼 아래 회색 글은 GitHub이 보여 주는 설명이에요. 저장소 설정에 따라 일부 버튼만 보일 수 있어요.
