5. GitHub PR의 Merge 버튼

PR의 Merge 버튼은 세 가지예요

feat: 로그인 버튼 추가 #1

Merge pull request

▼

Create a merge commit

합치기 커밋을 만들어요

git merge --no-ff

Squash and merge

커밋 하나로 합쳐요

git merge --squash

Rebase and merge

옮겨 붙여요

git rebase

PR 화면 아래 초록 버튼 오른쪽 ▼를 누르면 세 가지가 나와요. 처음 고른 것이 기본값으로 남아요. Create a merge commit은 갈라지지 않았어도 늘 합치기 커밋을 만들어서 --no-ff와 같아요. Squash and merge는 2부의 squash, Rebase and merge는 2부의 rebase 뒤 fast-forward와 같아요. 저장소 설정에 따라 일부 버튼만 보일 수 있어요.
