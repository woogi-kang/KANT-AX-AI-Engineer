4. git pull은 무엇을 하나

pull도 합치기예요

$ git fetch origin

$ git log --oneline

521bc6f (HEAD -> main) feat: 로그인 버튼 추가

$ git log --oneline origin/main

c4ea069 (origin/main) docs: README 추가

GitHub에는 lee의 C가, 내 main에는 D가 있어요. 둘이 갈라졌어요.

이번엔 브랜치 대신 main끼리 갈라진 상황이에요. lee가 README 추가(C)를 먼저 push했고, 나는 main에서 바로 로그인 버튼(D)을 커밋했어요. push는 06에서 본 것처럼 거절돼요. git pull은 git fetch로 C를 받아 온 뒤 내 main과 합쳐요. 어떻게 합칠지는 pull 설정이 정해요. 실습 저장소가 달라서 C, D 해시가 2부와 달라요. log 출력 아래쪽 줄은 뺐어요.
