4. git pull은 무엇을 하나

pull도 합치기예요

$ git fetch origin

$ git log --oneline

521bc6f (HEAD -> main) feat: 로그인 버튼 추가

$ git log --oneline origin/main

GitHub에만 있는 lee의 C

git pull은 git fetch로 받아 온 커밋을 내 main과 합쳐요. 이번엔 브랜치 대신 main끼리 갈라졌어요. lee가 README 추가(C)를 먼저 push했고, 나는 main에서 바로 로그인 버튼(D)을 커밋했어요. push는 06에서 본 것처럼 거절돼요. 어떻게 합칠지는 pull 설정이 정해요. 실습 저장소가 달라서 C, D 해시가 2부와 달라요. log 출력 아래쪽 줄도 나오는데, 그 부분은 빼고 옮겼어요.
