pull.rebase true: 내 커밋을 C 뒤로 옮겨요

# pull.rebase true인 컴퓨터

$ git pull origin main

보기만 하는 장이에요. 설정을 바꾸지 않아요. pull이 2부의 rebase와 같은 일을 해요. 아직 push하지 않은 D를 옮기는 거라 이 경우엔 문제가 없어요. 대신 충돌이 나면 rebase 충돌로 풀어야 해서 처음 배울 때 헷갈려요(6부). 회사마다 이 설정을 쓰는 팀도 있으니 이름은 알아 둬요.
