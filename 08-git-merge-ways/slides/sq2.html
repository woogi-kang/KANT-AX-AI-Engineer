부모는 C 하나, D, E와 안 이어져요

커밋 두 개(D, E)의 변경이 커밋 하나(S)로 main에 들어갔어요. 버튼을 만들다 고친 과정은 main 기록에 남지 않고 결과만 남아요. 그래서 작은 커밋이 많은 브랜치를 깔끔하게 합칠 때 써요. 메시지는 브랜치에서 한 일을 한 줄로 적어요. 1 file changed 줄도 나오는데, 그 부분은 빼고 옮겼어요.
