6. 충돌과 오류

rebase 중 충돌은 add 뒤 --continue로 이어 가요

$ cat login.md

<<<<<<< HEAD

# 로그인 페이지

=======

# 로그인하기

>>>>>>> bf59624 (feat: 로그인 제목 바꾸기)

아이디

HEAD 쪽이 main 내용

아래쪽이 옮기던 내 커밋

1

표시 세 줄을 지우고 남길 내용으로 고쳐요

2

git add login.md

3

git rebase --continue

헷갈리면 그만두기

git rebase --abort

rebase는 커밋을 하나씩 옮기다 멈춘 상태라서 commit 대신 git rebase --continue로 이어 가요. merge 충돌은 고치고 add 뒤 commit으로 끝냈어요(03). rebase는 main 끝으로 가서 내 커밋을 하나씩 얹기 때문에, 내 브랜치에서 쳤어도 HEAD 쪽이 main 내용이에요. 내 커밋은 아래쪽이에요. --continue 뒤 편집기가 열리면 그대로 저장하고 닫아요. 헷갈리면 git rebase --abort로 rebase 전 모습으로 돌아가요. squash 충돌은 merge처럼 고치고 add, commit 해요.
