$ cat login.md

# 로그인 페이지

아이디

1

표시 세 줄을 지우고 남길 내용으로 고쳐요

2

git add login.md

3

git rebase --continue

그만두기

git rebase --abort

rebase 때 HEAD 쪽은 main이에요. merge 때와 반대로 보여요.

merge 충돌은 고치고 add 뒤 commit으로 끝냈어요(03). rebase는 커밋을 하나씩 옮기다 멈춘 상태라서 commit 대신 git rebase --continue로 다음 커밋을 이어서 옮겨요. 편집기가 열리면 그대로 저장하고 닫아요. 헷갈리면 git rebase --abort로 rebase 전 모습으로 돌아가요. rebase는 main 위에 내 커밋을 얹는 거라 HEAD가 main 쪽이에요. squash 충돌은 merge처럼 고치고 add, commit 해요.
