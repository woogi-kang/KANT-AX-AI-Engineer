$ git checkout main

$ git pull origin main

$ git checkout feature/login-button

$ git rebase main

$ git push origin feature/login-button

push 전이라 rebase해도 돼요

아직 push하지 않은 브랜치는 최신 main 뒤로 rebase한 다음 올려요. 브랜치에서 D, E를 만드는 동안 lee가 README 추가(C)를 GitHub main에 올렸어요. main으로 가서 pull로 C를 받고, 브랜치로 돌아와 rebase해요. 그러면 PR에 C 뒤로 이어진 한 줄 기록이 올라가요. 이 브랜치는 이제 push했으니 다음부터는 rebase하지 않아요. 다음 두 장은 이 PR이 합쳐질 때까지 이어지는 이야기예요. checkout 출력, From 줄, 파일 목록 줄, To 줄도 나오는데, 그 부분은 빼고 옮겼어요.
