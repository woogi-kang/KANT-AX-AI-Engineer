--no-ff: 그래도 합치기 커밋을 만들어요

$ git merge --no-ff feature/login-button

Merge made by the 'ort' strategy.

$ git log --oneline

d847d12 (HEAD -> main) Merge branch 'feature/login-button'

브랜치에서 한 일이 한 덩어리로 보여요. GitHub PR 버튼도 이렇게 합쳐요.

A

9f452aa

B

6d19f01

D

6a9792d

E

3573c9a

M

d847d12

feature/login-button

main

◀ HEAD

앞 장과 같은 상태에서 --no-ff를 붙였어요. no fast-forward, 빨리 감기를 하지 말라는 뜻이에요. fast-forward가 되는 상황에서도 부모가 B와 E 둘인 합치기 커밋 M을 만들어요. 나중에 기록을 보면 D, E가 브랜치에서 온 커밋이라는 게 남아요. 메시지 편집기가 열리면 그대로 저장하고 닫아요. GitHub의 Create a merge commit 버튼이 항상 이 방식이에요(5부).
