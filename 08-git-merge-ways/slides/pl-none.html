4. git pull은 무엇을 하나

설정이 없으면 pull이 멈추고 세 가지를 알려 줘요

$ git pull origin main

hint: You have divergent branches and need to specify how to reconcile them.

hint: You can do so by running one of the following commands sometime before

hint: your next pull:

hint: git config pull.rebase false # merge

hint: git config pull.rebase true # rebase

hint: git config pull.ff only # fast-forward only

fatal: Need to specify how to reconcile divergent branches.

pull.rebase false

merge로 합쳐요

수업 설정

pull.rebase true

rebase로 옮겨 붙여요

보기만 해요

pull.ff only

fast-forward만 받아요

보기만 해요

세 줄이 곧 이 덱에서 본 합치는 방법이에요.

06에서 본 그 메시지예요. 그때는 해결만 봤어요. 힌트 세 줄을 읽어 보면 merge, rebase, fast-forward only 중에서 고르라는 뜻이에요. 우리 과정은 06에서 git config --global pull.rebase false로 첫째 줄을 골랐어요. From 줄, 빈 hint 줄, 힌트 아래쪽 줄은 뺐어요.
