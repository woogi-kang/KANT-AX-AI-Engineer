4. git pull은 무엇을 하나

설정이 없으면 pull이 멈추고 셋 중 고르라고 해요

$ git pull origin main

hint: You have divergent branches and need to specify how to reconcile them.

hint: You can do so by running one of the following commands sometime before

hint: your next pull:

hint: git config pull.rebase false # merge

hint: git config pull.rebase true # rebase

hint: git config pull.ff only # fast-forward only

fatal: Need to specify how to reconcile divergent branches.

merge로 합쳐요 · 수업 설정

rebase로 옮겨 붙여요

fast-forward만 받아요

06에서 git config --global pull.rebase false로 첫째 줄을 골랐어요.

힌트 세 줄은 merge, rebase, fast-forward only 중에서 pull 방법을 고르라는 뜻이에요. 06에서 본 그 메시지예요. 그때는 해결만 봤어요. 우리 과정은 06에서 git config --global pull.rebase false로 첫째 줄을 골랐어요. From 줄, 빈 hint 줄, 힌트 아래쪽 줄도 나오는데, 그 부분은 빼고 옮겼어요.
