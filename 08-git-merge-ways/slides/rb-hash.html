rebase하면 커밋 해시가 바뀌어요

rebase 전

$ git log --oneline

3573c9a (HEAD -> feature/login-button) fix: 버튼 글자 고치기

6a9792d feat: 로그인 버튼 추가

6d19f01 feat: 아이디 입력 추가

9f452aa feat: 로그인 화면 추가

rebase 뒤

$ git log --oneline

6852264 (HEAD -> feature/login-button) fix: 버튼 글자 고치기

a40dc47 feat: 로그인 버튼 추가

d51d818 (main) docs: README 추가

6d19f01 feat: 아이디 입력 추가

메시지와 바뀐 내용은 같아요

메시지와 바뀐 내용은 같아요

D의 부모가 B에서 C로 바뀌어서, 뒤에 붙은 E까지 새 커밋이 돼요.

커밋 해시는 내용, 메시지, 날짜, 부모 커밋으로 정해져요. rebase는 부모를 바꿔 다시 만들기 때문에 해시가 새로 나와요. 내 컴퓨터에만 있는 커밋이면 문제가 없어요. 이미 push해서 팀원이 옛 D, E를 받아 갔다면 팀원 기록과 어긋나요. 6부에서 이 장면을 다시 봐요.
