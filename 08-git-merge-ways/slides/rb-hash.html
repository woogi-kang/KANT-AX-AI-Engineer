부모가 B에서 C로 바뀌어서 해시가 새로 나와요. 메시지와 내용은 그대로예요.

부모 커밋이 바뀌면 해시도 바뀌어요. 커밋 해시는 내용, 메시지, 날짜, 부모 커밋으로 정해져요. rebase는 D의 부모를 B에서 C로 바꿔 다시 만들어서 해시가 새로 나와요. D 뒤에 붙은 E도 부모가 바뀌니까 같이 새 커밋이 돼요. 내 컴퓨터에만 있는 커밋이면 문제가 없어요. 이미 push해서 팀원이 옛 D, E를 받아 갔다면 팀원 기록과 어긋나요. 6부에서 이 장면을 다시 봐요.
