같은 브랜치를 합쳤는데 기록이 달라요

merge로 합친 폴더

$ git log --oneline

8818bb8 (HEAD -> main) Merge branch 'feature/login-button'

d51d818 docs: README 추가

3573c9a (feature/login-button) fix: 버튼 글자 고치기

6a9792d feat: 로그인 버튼 추가

6d19f01 feat: 아이디 입력 추가

9f452aa feat: 로그인 화면 추가

$ cat login.md

# 로그인

아이디

[로그인] 버튼

squash로 합친 폴더

$ git log --oneline

8a6fe21 (HEAD -> main) feat: 로그인 버튼 추가

d51d818 docs: README 추가

6d19f01 feat: 아이디 입력 추가

9f452aa feat: 로그인 화면 추가

$ cat login.md

# 로그인

아이디

[로그인] 버튼

기록은 6줄과 4줄인데, 파일 내용은 똑같아요.

같은 브랜치를 합쳐도 방법에 따라 기록 모양이 달라져요. 두 폴더 모두 같은 출발점에서 feature/login-button을 main에 합쳤어요. 왼쪽은 merge로 합쳐서 합치기 커밋과 브랜치 커밋 D, E가 다 남았어요. 오른쪽은 squash로 합쳐서 커밋 하나만 남았어요. 그런데 login.md 내용은 두 폴더가 똑같아요. 팀 레포나 GitHub에서 이런 다른 모양을 보면 어떻게 합쳤는지 읽을 수 있게 되는 게 오늘 목표예요. 출력은 실제로 실행한 결과예요.
