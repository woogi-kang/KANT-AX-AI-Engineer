# main에서

$ git merge feature/login-title

CONFLICT (content): Merge conflict in login.md

 

# feature/login-title에서

$ git rebase main

CONFLICT (content): Merge conflict in login.md

 

# main에서

$ git merge --squash feature/login-title

CONFLICT (content): Merge conflict in login.md

같은 줄을 다르게 고쳤으면 Git은 방법과 상관없이 물어봐요.

합치는 방법은 기록 모양만 바꾸고, 충돌이 나는지는 바꾸지 않아요. B에서 갈라진 뒤 main은 첫 줄을 # 로그인 페이지로, 브랜치는 # 로그인하기로 고쳤어요. 03의 충돌 시나리오와 같은 상황이에요. merge, rebase, squash 모두 같은 줄에서 CONFLICT가 나요. 푸는 법도 같아요. 표시 줄을 지우고 남길 내용으로 고친 뒤 git add 해요. 다른 점은 그다음 명령 하나예요(다음 장). 출력의 Auto-merging 줄과 아래 안내 줄도 나오는데, 그 부분은 빼고 옮겼어요.
