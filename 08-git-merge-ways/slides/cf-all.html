6. 충돌과 주의

충돌은 어느 방법이든 같은 줄이면 나요

main의 login.md

# 로그인 페이지

아이디

feature/login-title의 login.md

# 로그인하기

아이디

$ git merge feature/login-title

CONFLICT (content): Merge conflict in login.md

$ git rebase main

CONFLICT (content): Merge conflict in login.md

$ git merge --squash feature/login-title

CONFLICT (content): Merge conflict in login.md

합치는 방법은 기록 모양만 바꿔요. 같은 줄을 다르게 고쳤으면 Git은 늘 물어봐요.

B에서 갈라진 뒤 main은 첫 줄을 # 로그인 페이지로, 브랜치는 # 로그인하기로 고쳤어요. 03의 충돌 시나리오와 같은 상황이에요. merge, rebase, squash 모두 같은 줄에서 CONFLICT가 나요. 푸는 법도 같아요. 표시 줄을 지우고 남길 내용으로 고친 뒤 git add 해요. 다른 점은 그다음 명령 하나예요(다음 장). 출력의 Auto-merging 줄과 아래 안내 줄은 뺐어요.
