pull.rebase false면 pull이 2부의 merge와 같은 일을 해요. git config --global pull.rebase처럼 값 없이 치면 지금 설정을 보여 줘요. false가 나오면 수업 설정이 돼 있는 거예요. 합치기 커밋 메시지는 Merge branch 'main' of https://github.com/kim/merge-lab이에요. 이제 git push origin main을 하면 올라가요. From 줄과 파일 목록 줄도 나오는데, 그 부분은 빼고 옮겼어요.
