rebase 뒤에는 브랜치가 C 바로 뒤에 붙어 있어서 1부의 fast-forward와 같은 모양이에요. rebase는 합치기 전에 브랜치를 최신 main 뒤로 옮기는 일이고, 합치는 건 여전히 merge예요. 점선이던 옛 D, E는 이름표가 없어서 그래프에서 보이지 않아요.
