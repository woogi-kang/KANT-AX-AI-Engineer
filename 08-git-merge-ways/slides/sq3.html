2. 갈라졌을 때

squash 뒤에는 브랜치가 -d로 안 지워져요

$ git branch -d feature/login-button

error: the branch 'feature/login-button' is not fully merged.

If you are sure you want to delete it, run 'git branch -D feature/login-button'

Git은 D, E가 main에 없다고 봐요. 내용이 들어간 걸 확인했으면 -D로 지워요.

A

9f452aa

B

6d19f01

D

6a9792d

E

3573c9a

C

d51d818

S

8a6fe21

main

◀ HEAD

feature/login-button

-d는 합쳐진 브랜치만 지워요. Git은 커밋을 선으로 따라가서 합쳐졌는지 봐요. S는 D, E와 이어지지 않아서 합쳐지지 않은 걸로 보여요. git log --oneline이나 파일 내용으로 변경이 main에 있는 걸 확인한 뒤 git branch -D feature/login-button으로 지워요. 대문자 -D는 합쳐졌는지 확인하지 않고 지우니, 변경이 main에 있는 걸 본 뒤에만 써요.
