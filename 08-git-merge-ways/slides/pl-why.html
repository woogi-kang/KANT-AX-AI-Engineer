4. git pull은 무엇을 하나

수업은 pull.rebase false로 통일해요

내 커밋 해시가 그대로예요

push한 커밋과 어긋나지 않아요

합친 자리가 기록에 남아요

합치기 커밋 M이 언제 합쳤는지 보여 줘요

충돌을 푸는 방법이 하나예요

03, 06처럼 고치고 add, commit

$ git config --global pull.rebase false

06에서 처음 한 번 설정했으면 그대로 둬요.

pull.rebase false는 기록을 바꾸지 않는 방법이라 처음 배울 때 가장 안전해요. 기록이 조금 복잡해 보이는 대신, 내가 한 커밋이 사라지거나 해시가 바뀌는 일이 없어요. rebase가 나쁜 방법은 아니에요. push 전 내 커밋에만 쓰는 규칙을 지키면 기록이 깔끔해져요. 익숙해진 뒤 팀이 정한 방법을 따르면 돼요.
