rebase: D, E를 C 뒤로 옮겨 붙여요

$ git checkout feature/login-button

$ git rebase main

Successfully rebased and updated refs/heads/feature/login-button.

옛 D, E는 점선으로 남고, 같은 내용의 새 커밋 D', E'가 생겨요.

다시 7쪽 상태에서 시작해요. rebase는 브랜치에서 쳐요. git rebase main은 내 브랜치 커밋을 main 끝(C) 뒤로 하나씩 다시 만들어 붙여요. 받침(base)을 바꾼다는 뜻이에요. 옛 D, E는 이제 어느 이름표도 가리키지 않아서 점선으로 그렸어요. 진짜 터미널에서는 Rebasing (1/2) 같은 진행 줄이 잠깐 보였다가 지워져요.
