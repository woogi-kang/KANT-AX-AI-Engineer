막힐 때

이런 메시지가 나와요

1

fatal: Need to specify how to reconcile divergent branches.

pull 설정이 없어요

git config --global pull.rebase false

2

fatal: Not possible to fast-forward, aborting.

pull.ff only가 설정돼 있어요

git config --global --unset pull.ff

3

error: the branch '...' is not fully merged.

squash나 rebase로 합쳤어요. 합친 걸 확인하고

git branch -D 브랜치

4

error: could not apply ... (rebase 중 CONFLICT)

고치고 add 뒤 이어 가요. 그만두려면 --abort

git rebase --continue

5

! [rejected] ... (non-fast-forward) rebase 뒤

push한 브랜치를 rebase했어요. pull하지 말고

강사에게 물어봐요

1번은 06에서 본 메시지예요. 2번은 다른 자료를 보고 pull.ff only를 설정한 컴퓨터에서 나요. 설정을 지우고 06처럼 pull.rebase false만 남겨요. 3번은 squash나 Rebase and merge 뒤에 나요. 4번은 rebase 중 충돌이에요. 5번은 push한 브랜치를 rebase한 경우예요. pull로 풀면 같은 커밋이 두 번 들어가니 멈추고 물어봐요.
