명령을 칠 때마다 Git Graph에서 한 곳씩 봐요

확인할 것

Git Graph에서 볼 곳

관련 명령

커밋했는지

맨 위 회색 줄이 사라지고 새 점

git commit

GitHub에 올렸는지

main | origin으로 붙었는지

git push origin main

팀원이 올린 게 있는지

origin/main이 main보다 위

git fetch origin

지금 어느 브랜치인지

굵은 글씨, 색 테두리 이름표

git checkout 브랜치

합쳐졌는지

두 선이 만나는 점

git merge 브랜치

무엇이 바뀌었는지

커밋 줄을 눌러 파일 목록

git show
