터미널 기록으로는 갈라졌다가 합쳐진 모양이 안 보여요. 같은 저장소를 터미널과 Git Graph로 본 화면이라 커밋 순서와 메시지는 같아요. Git Graph에서는 분홍 선으로 바로 보여요. Git Graph는 기록을 보여 주기만 하고 저장소를 바꾸지 않아요.
