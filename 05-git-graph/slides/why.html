같은 기록이에요. 갈라진 길과 합쳐진 곳이 선으로 보여요.

위는 터미널에서 친 git log --oneline, 아래는 같은 저장소를 Git Graph로 연 화면이에요. 커밋 순서와 메시지가 같아요. 터미널에서는 feature/login에서 갈라졌다가 merge로 합쳐진 모양이 안 보이지만, Git Graph에서는 분홍 선으로 바로 보여요. Git Graph는 기록을 보여 주기만 해요. 저장소를 바꾸지 않아요.
