Git Graph는 VS Code에 열린 폴더가 Git 저장소일 때만 동작해요. File > Open Folder(한국어 화면은 파일 > 폴더 열기)로 git init을 했던 hello-git 폴더를 먼저 열어요. 그다음 세 방법 중 아무거나 쓰면 돼요. 열리면 편집기 자리에 Git Graph 탭이 생겨요.
