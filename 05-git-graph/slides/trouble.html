가장 흔한 건 1번이에요. 바탕화면이나 상위 폴더를 열면 Git 저장소를 못 찾아요. git init을 한 바로 그 폴더를 열어요. 2번은 02의 fetch 규칙과 같아요. 3번의 새로고침은 Git Graph 탭 오른쪽 위 둥근 화살표 아이콘이에요.
