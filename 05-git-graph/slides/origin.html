origin/main은 마지막으로 GitHub과 주고받았을 때의 main 위치예요.

팀원이 GitHub에 새로 올린 커밋은 git fetch origin을 쳐야 Git Graph에 나타나요.

02에서 git log --oneline과 git log --oneline origin/main을 따로 쳐서 비교했던 걸 한 화면에서 봐요.

이름표가 main | origin 하나로 붙어 있으면 내 main과 GitHub의 main이 같아요. 내가 커밋하고 아직 push하지 않았으면 main이 origin/main보다 위에 있어요. 팀원이 push한 걸 git fetch origin으로 받아 오면 origin/main이 main보다 위로 올라가요. Git Graph가 GitHub에 직접 물어보는 게 아니라 내 컴퓨터에 받아 둔 기록을 보여 준다는 점을 짚어 주세요.
