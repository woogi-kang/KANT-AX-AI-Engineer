오른쪽 클릭 메뉴로 checkout, merge, reset도 할 수 있어요

수업에서는 메뉴를 쓰지 않아요. 무엇을 쳤는지 터미널에 남아야 오류가 났을 때 읽고 고칠 수 있어요.

오른쪽 위 Fetch 버튼 대신 git fetch origin을 쳐요.

터미널: 명령

Git Graph: 확인

커밋 줄이나 이름표를 오른쪽 클릭하면 이런 메뉴가 나와요. 버튼 한 번에 reset이나 merge가 실행돼서 무엇이 바뀌었는지 놓치기 쉬워요. 그래서 수업에서는 명령을 터미널에 직접 치고, 친 결과가 맞는지 Git Graph로 확인하는 데만 써요. 잘못 눌렀다면 창을 닫지 말고 터미널에서 git status와 git log --oneline부터 봐요.
