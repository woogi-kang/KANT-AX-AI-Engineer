1

Windows Ctrl+Shift+X

설치가 끝나면 Install 자리에
톱니바퀴가 나와요.

확장 탭에서 mhutchie가 만든 Git Graph를 설치해요. VS Code 왼쪽 세로 막대에서 네모 네 개 모양 아이콘이 확장(Extensions)이에요. 검색 결과에 이름이 비슷한 확장이 여러 개 나오니 만든 사람을 꼭 봐요. 설치하고 VS Code를 다시 켤 필요는 없어요. 화면이 한국어로 되어 있으면 Install 대신 설치라고 나와요.
