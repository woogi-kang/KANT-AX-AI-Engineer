feature/login 브랜치를 만들고 커밋 하나를 한 뒤의 화면이에요. 이름표가 두 개 있는데, 지금 있는 feature/login만 굵은 글씨에 색 테두리예요. 맨 위 커밋의 점은 속이 비어 있어요. HEAD가 가리키는 커밋이라는 표시예요. 설명 칸 맨 앞의 작은 빈 동그라미도 같은 뜻이에요. main 이름표 오른쪽의 기울어진 origin은 origin/main도 여기 있다는 뜻이에요.
