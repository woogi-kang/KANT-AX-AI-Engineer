기울어진 origin

터미널

$ git log --oneline

b9f30e5 (HEAD -> feature/login, origin/main, main) docs: README 추가

굵은 글씨에 색 테두리인 이름표가 지금 있는 브랜치예요. 브랜치 feature/login을 막 만든 화면이라 이름표가 두 개인데, feature/login만 굵어요. 터미널의 HEAD -> feature/login과 같은 뜻이에요. 맨 앞의 빈 점은 HEAD가 가리키는 커밋이라는 표시예요. main 옆의 기울어진 origin은 origin/main도 여기 있다는 뜻이에요.
