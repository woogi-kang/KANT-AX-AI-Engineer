git push origin main

Git Graph는 내 컴퓨터의 저장소 기록을 읽어서 그림으로 보여 줘요. 기록을 바꾸는 건 터미널에서 치는 명령이에요. Git Graph는 GitHub에 직접 물어보지 않아요. 팀원이 GitHub에 올린 커밋은 git fetch origin으로 받아 와야 그림에 나타나요. 막히면 지금 하려는 일이 이 그림의 어느 화살표인지 먼저 찾아봐요.
