import psycopg

 

DSN = "host=localhost port=5432 dbname=kant_shop user=postgres password=admin1234"

 

with psycopg.connect(DSN) as conn:

row = conn.execute("SELECT current_database(), current_user").fetchone()

블록이 끝나면 연결이 닫혀요

with는 오늘 처음 보는 문법이에요. with 다음 줄부터 네 칸 들여 쓴 곳이 한 덩어리예요. 17에서 if 아래를 들여 쓴 것과 같은 규칙이에요. 이 덩어리 안에서만 conn으로 데이터베이스에 말을 걸 수 있어요. 들여쓰기가 끝나면 psycopg가 연결을 알아서 닫아요. 아홉째 줄은 블록 밖에서 conn을 다시 썼어요. 실행하면 블록 안의 연결 성공은 찍히고, 아홉째 줄에서 the connection is closed 오류가 나요. 연결이 이미 닫혔다는 뜻이에요. 그래서 SQL을 보내는 코드는 모두 with 블록 안에 둬요. with 블록이 끝날 때 하는 일이 하나 더 있는데, 4파트에서 봐요. 실행 화면은 tools/demo.py로 실제 PostgreSQL 18과 psycopg 3을 실행해서 옮긴 결과예요.
