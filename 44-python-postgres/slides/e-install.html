5. 비교와 오류

설치 오류 두 가지: uv add를 안 했거나 [binary]를 뺐어요

uv add를 안 하고 실행

~/sports-app $ uv run main.py

Traceback (most recent call last):

 File "/home/kim/sports-app/main.py", line 1, in <module>

   import psycopg

ModuleNotFoundError: No module named 'psycopg'

이 프로젝트에 psycopg가 없어요

고치기

uv run main.py

→

uv add "psycopg[binary]"

먼저 넣고 실행해요

uv add psycopg만 했을 때 (부품이 없는 컴퓨터)

~/sports-app $ uv run main.py

Traceback (most recent call last):

 File "/home/kim/sports-app/main.py", line 1, in <module>

   import psycopg

 …

ImportError: no pq wrapper available.

Attempts made:

- couldn't import psycopg 'c' implementation: No module

   named 'psycopg_c'

- couldn't import psycopg 'binary' implementation: No

   module named 'psycopg_binary'

- couldn't import psycopg 'python' implementation: libpq

   library not found

PostgreSQL 접속 부품을 못 찾았어요

고치기

uv add psycopg

→

uv add "psycopg[binary]"

설치에서 나는 오류 두 가지예요. 첫째는 uv add를 하지 않고 실행했을 때예요. import psycopg 줄에서 ModuleNotFoundError가 나요. 그 프로젝트에 psycopg가 없다는 뜻이에요. 가상환경을 켜지 않고 python main.py로 실행해도 같은 오류가 나요. 둘째는 대괄호 binary를 빼고 uv add psycopg만 했을 때예요. psycopg는 PostgreSQL 접속 부품인 libpq가 필요한데, 그 부품이 없는 컴퓨터에서는 no pq wrapper available 오류가 나요. 마지막 줄의 libpq library not found가 이유예요. 이 화면은 libpq가 없는 깨끗한 리눅스 컨테이너에서 같은 uv로 실제로 실행했어요. 둘 다 uv add "psycopg[binary]"로 고쳐요. 실행 화면은 tools/demo.py로 실제 PostgreSQL 18과 psycopg 3을 실행해서 옮긴 결과예요.
