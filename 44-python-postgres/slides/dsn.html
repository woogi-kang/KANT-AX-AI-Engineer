35에서 컨테이너를 켠 명령과 맞춰 봐요

docker run -d --name my-pg -e POSTGRES_PASSWORD=admin1234 -p 5432:5432 postgres:18

CREATE DATABASE kant_shop;

관리자 계정 이름은 따로 정하지 않으면 postgres예요(34). 포트는 -p 5432:5432의 왼쪽 숫자, 내 컴퓨터 쪽 번호를 적어요.

수업 코드는 port=5433이었어요. 컨테이너를 -p 5433:5432로 켰을 때 맞는 값이에요.

DSN은 접속 정보를 한 줄로 적은 글자예요. 칸마다 이름=값이고, 칸 사이는 띄어쓰기예요. host=localhost는 서버가 내 컴퓨터에 있다는 뜻이에요. port=5432는 문 번호예요. dbname=kant_shop은 들어갈 데이터베이스, user=postgres는 계정, password=admin1234는 비밀번호예요. 이 값들은 35에서 컨테이너를 켠 명령과 짝이 맞아요. POSTGRES_PASSWORD에 적은 admin1234가 비밀번호이고, -p 5432:5432의 왼쪽 숫자가 내 컴퓨터 쪽 포트예요. 관리자 이름은 따로 정하지 않아서 postgres예요. 수업 코드에는 port=5433이 적혀 있었어요. 컨테이너를 -p 5433:5432로 켰다면 5433이 맞고, 35처럼 켰다면 5432로 고쳐요. 포트가 틀리면 어떤 오류가 나는지는 오류 장에서 봐요.
