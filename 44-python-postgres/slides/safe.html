3. %s로 값 넣기

%s는 SQL과 값을 따로 보내서 값이 문장을 못 바꿔요

f-string

%s

… WHERE name = 'x' OR '1'='1'

값이 SQL 글자에 녹아서 한 문장이 돼요

PostgreSQL이 읽은 조건 두 개
name = 'x' 또는 '1'='1' (늘 참)

40명 모두

… WHERE name = %s

x' OR '1'='1

SQL 따로

값 따로

이름이 글자 그대로
x' OR '1'='1인 회원

0명

숫자 하나를 넣을 때도 똑같이 %s로 넘겨요.

왜 퍼센트 s는 안전한지 그림으로 봐요. f-string은 값을 SQL 글자 사이에 끼워 넣어서 한 문장을 만들어요. 값 안에 따옴표가 있으면 따옴표가 문장의 일부가 되고, 뒤의 OR가 새 조건이 돼요. PostgreSQL은 이름이 x인 회원 또는 늘 참인 조건으로 읽어서 40명을 다 줘요. 퍼센트 s를 쓰면 psycopg가 SQL 문장과 값을 따로 보내요. PostgreSQL은 문장을 먼저 정해 두고, 따로 온 값은 그 자리에 들어갈 글자 하나로만 써요. 그래서 따옴표가 들어 있어도 문장이 바뀌지 않아요. 값이 숫자 하나여도 같은 습관으로 퍼센트 s를 써요.
