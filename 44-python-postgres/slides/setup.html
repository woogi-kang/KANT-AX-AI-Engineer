[binary]를 꼭 붙여요

PostgreSQL에 접속하는 부품까지 같이 받아요. 빼면 컴퓨터에 따라 import 줄에서 오류가 나요.

준비부터 해요. 35에서 만든 my-pg 컨테이너를 켜 두고, 38에서처럼 kant_shop 데이터베이스에 sports.sql을 넣어 둬요. 그다음 9에서 배운 uv로 프로젝트 폴더를 만들어요. uv init sports-app, cd sports-app, 그리고 uv add로 psycopg를 넣어요. 이름 뒤에 대괄호로 binary를 붙이고, 대괄호가 셸에서 다르게 읽히지 않게 전체를 큰따옴표로 감싸요. binary는 PostgreSQL에 접속하는 부품까지 미리 만들어 둔 묶음이에요. 출력에 psycopg와 psycopg-binary 두 개가 설치됐다고 나와요. pyproject.toml의 dependencies에도 한 줄이 생겼어요. binary를 빼면 컴퓨터에 따라 import 줄에서 오류가 나요. 오류 장에서 봐요. 실행 화면은 tools/demo.py로 실제 PostgreSQL 18과 psycopg 3을 실행해서 옮긴 결과예요.
