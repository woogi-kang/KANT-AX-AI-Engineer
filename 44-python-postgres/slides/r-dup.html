def enroll(conn, member_id, course_id):

row = conn.execute(FEE_SQL, (course_id,)).fetchone()

if not row:

print(f"{course_id}번 강좌는 없어요")

return

if conn.execute(DONE_SQL, (member_id, course_id, MONTH)).fetchone():

print(f"{course_id}번 강좌는 이미 신청했어요")

return

conn.execute(INSERT_SQL, (member_id, course_id, MONTH, row["fee"]))

print(f"{course_id}번 강좌를 신청했어요 ({row['fee']:,}원)")

188번 한 줄만 들어갔어요.

강좌가 없으면 if not row로, 이미 신청했으면 fetchone() 결과로 먼저 막고 return으로 끝내요.

두 번째 실제 상황이에요. 4파트에서 없는 강좌를 신청했다가 TypeError가 났어요. 같은 강좌를 두 번 신청하는 것도 막아야 해요. 신청하기 전에 두 가지를 먼저 물어봐요. 수강료를 꺼낸 fetchone() 결과가 None이면 없는 강좌예요. 17에서 배운 대로 None은 False로 읽혀서 if not row로 쓸 수 있어요. 메시지를 찍고 19에서 배운 return으로 함수를 바로 끝내요. 그다음 같은 회원, 같은 강좌, 같은 달의 신청이 있는지 SELECT해요. 한 줄이라도 있으면 막아요. 30번, 5번, 5번 순서로 세 번 불렀더니 없는 강좌, 신청, 이미 신청 순서로 찍혔고, psql에서는 188번 한 줄만 들어갔어요. 실행 화면은 tools/demo.py로 실제 PostgreSQL 18과 psycopg 3을 실행해서 옮긴 결과예요.
