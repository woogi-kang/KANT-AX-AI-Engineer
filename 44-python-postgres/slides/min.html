import psycopg

 

DSN = "host=localhost port=5432 dbname=kant_shop user=postgres password=admin1234"

 

with psycopg.connect(DSN) as conn:

row = conn.execute("SELECT current_database(), current_user").fetchone()

print("연결 성공:", row)

① import psycopg: PostgreSQL에 접속하는 라이브러리를 불러와요

~/sports-app $ uv run main.py

연결 성공: ('kant_shop', 'postgres')

('데이터베이스 이름', '접속한 계정')

가장 작은 예제예요. 일곱 줄이에요. 첫 줄 import psycopg로 라이브러리를 불러와요. 셋째 줄 DSN은 접속할 주소예요. 다음 장에서 한 칸씩 봐요. 다섯째 줄 with psycopg.connect(DSN) as conn은 그 주소로 접속하고, 연결에 conn이라는 이름을 붙여요. 여섯째 줄에서 conn.execute로 SQL을 보내요. current_database()는 지금 데이터베이스 이름, current_user는 접속한 계정이에요. 뒤에 붙은 fetchone()이 결과 첫 줄을 꺼내요. 실행은 9에서 배운 uv run main.py예요. kant_shop과 postgres가 든 튜플 하나가 찍혔어요. 수업 코드에서 주석으로 막아 둔 연결 확인 코드와 같아요. 실행 화면은 tools/demo.py로 실제 PostgreSQL 18과 psycopg 3을 실행해서 옮긴 결과예요.
