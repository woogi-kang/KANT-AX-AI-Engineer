강좌 이름과 수강료를 사람이 보고 옮겨 적으면, 강좌가 바뀔 때마다 다시 옮겨야 해요.

프로그램이 직접 SELECT를 보내고, 돌아온 줄을 리스트와 딕셔너리로 받아서 화면을 만들어요.

파이썬과 PostgreSQL 사이를 이어 주는 라이브러리가 psycopg예요.

지금까지는 psql 창에 SELECT를 치고 결과 표를 눈으로 읽었어요. 왼쪽 화면이에요. 그런데 우리가 만들려는 건 오른쪽 같은 수강 신청 프로그램이에요. 강좌 이름과 수강료를 보여 주고, 신청 버튼을 누르면 신청 표에 한 줄을 넣어요. 사람이 psql 결과를 보고 파이썬 코드에 옮겨 적으면, 강좌가 하나 늘거나 수강료가 바뀔 때마다 코드를 고쳐야 해요. 그래서 프로그램이 직접 데이터베이스에 SQL을 보내고, 돌아온 줄을 파이썬 값으로 받아서 써야 해요. 이 둘을 이어 주는 라이브러리가 psycopg예요. 오른쪽 신청 화면은 이해를 돕는 예시 그림이고, 강좌 이름과 수강료는 실제 데이터와 같아요. 실행 화면은 tools/demo.py로 실제 PostgreSQL 18과 psycopg 3을 실행해서 옮긴 결과예요.
