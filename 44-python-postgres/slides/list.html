LIST_SQL = """

SELECT c.course_id, s.sport_name, c.course_name, c.fee

FROM courses c

JOIN sports s ON c.sport_id = s.sport_id

ORDER BY c.course_id

"""

 

 

def list_courses(conn):

for c in conn.execute(LIST_SQL):

no = c["course_id"]

fee = f"{c['fee']:,}원"

print(f"{no:>2} | {c['sport_name']} | {fee:>8} | {c['course_name']}")

 

 

with psycopg.connect(DSN, row_factory=dict_row) as conn:

list_courses(conn)

수업 코드에서 고친 두 곳: 열 이름은 표에 맞춰 sport_id, 쓰이지 않던 LEFT JOIN과 DISTINCT는 뺐어요.

배운 것을 모아 강좌 14개를 표처럼 찍어 봐요. 수업에서 만든 list_courses 함수예요. SQL이 길어서 따옴표 세 개로 감쌌어요. 따옴표 세 개 사이에는 여러 줄 글자를 쓸 수 있어요. 40에서 배운 JOIN으로 종목 이름을 붙였어요. 수업 코드에서는 courses 표의 열이 sports_id인데 쿼리에는 sport_id를 써서 서로 맞지 않았어요. 여기서는 38부터 쓰는 데이터에 맞춰 양쪽 다 sport_id예요. 함수 안에서는 for로 한 줄씩 받아서 13에서 배운 f-string 포맷으로 찍어요. 콜론 오른쪽 2는 두 칸 오른쪽 맞춤, 쉼표는 천 단위 콤마예요. 수업 코드의 LEFT JOIN과 DISTINCT는 결과에 쓰이지 않아서 뺐어요. 신청 수를 세는 버전은 실제 상황 1에서 만들어요. 실행 화면은 tools/demo.py로 실제 PostgreSQL 18과 psycopg 3을 실행해서 옮긴 결과예요.
