%s로 넘기면

main.py

name = "x' OR '1'='1"

 

with psycopg.connect(DSN) as conn:

sql = "SELECT name, phone FROM members WHERE name = %s"

print(sql)

rows = conn.execute(sql, (name,)).fetchall()

print(len(rows), "명이 나왔어요")

~/sports-app $ uv run main.py

SELECT name, phone FROM members WHERE name = %s

0 명이 나왔어요

이름 칸에 따옴표와 OR '1'='1'를 넣었더니, 조건이 늘어나서 회원 40명이 다 나왔어요. 이런 공격을 SQL 인젝션이라고 해요.

SQL에 넣는 값은 f-string으로 붙이지 않고 항상 %s로 넘겨요.

이름으로 회원을 찾는 코드를 두 가지로 써 봤어요. 회원이 이름 칸에 x 따옴표 OR 따옴표 1 따옴표 = 따옴표 1처럼 이상한 글자를 넣었다고 해 봐요. 왼쪽은 13에서 배운 f-string으로 이름을 SQL 글자에 바로 붙였어요. 만들어진 SQL을 찍어 보면 따옴표가 중간에 닫히고 OR '1'='1'이라는 조건이 새로 생겼어요. '1'='1'은 언제나 참이라서 회원 40명이 모두 나왔어요. 남의 전화번호가 다 보이는 사고예요. 이렇게 값에 SQL 조각을 섞어 문장을 바꾸는 공격을 SQL 인젝션이라고 해요. 오른쪽은 같은 이름을 퍼센트 s로 넘겼어요. 이상한 글자 전체를 이름 하나로 보고 찾아서 0명이 나왔어요. 그래서 SQL에 넣는 값은 항상 퍼센트 s로 넘겨요. 실행 화면은 tools/demo.py로 실제 PostgreSQL 18과 psycopg 3을 실행해서 옮긴 결과예요.
