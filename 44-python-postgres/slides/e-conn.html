접속에서 나는 오류 두 가지예요. 첫째는 Connection refused예요. 5433번 문을 두드렸는데 받는 서버가 없다는 뜻이에요. 수업 코드처럼 port=5433을 적고 컨테이너는 5432로 켰을 때 나요. 컨테이너가 꺼져 있어도 같은 메시지가 나요. docker ps로 my-pg가 켜져 있는지, -p 왼쪽 숫자가 DSN의 port와 같은지 봐요. 둘째는 password authentication failed예요. 서버는 찾았는데 비밀번호가 틀렸어요. 35에서 POSTGRES_PASSWORD에 적은 값과 맞춰요. 컨테이너를 켤 때 쓴 비밀번호는 볼륨이 남아 있는 동안 바뀌지 않는다는 것도 34에서 봤어요. 실행 화면은 tools/demo.py로 실제 PostgreSQL 18과 psycopg 3을 실행해서 옮긴 결과예요.
