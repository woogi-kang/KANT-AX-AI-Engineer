43에서 직접 친 BEGIN, COMMIT, ROLLBACK을 psycopg가 대신 쳐요. 첫 SQL을 보낼 때 시작하고, 블록이 끝나면 저장하거나 취소해요.

with 블록이 끝날 때 하는 일이 하나 더 있어요. 저장이에요. psycopg는 블록 안에서 첫 SQL을 보낼 때 트랜잭션을 시작해요. 블록 안의 SQL이 끝까지 성공하면, 블록이 끝나는 순간 COMMIT을 보내서 바꾼 것을 한 번에 저장해요. 위쪽 줄이에요. 중간에 오류가 나서 블록을 빠져나가면 COMMIT 대신 ROLLBACK을 보내요. 아래쪽 줄이에요. 이때는 앞에서 성공한 INSERT까지 모두 취소돼요. 43에서 psql에 직접 친 BEGIN, COMMIT, ROLLBACK을 psycopg가 대신 쳐 주는 거예요. 반쯤만 저장되는 일이 없어요.
