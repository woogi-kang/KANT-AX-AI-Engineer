import psycopg

from psycopg.rows import dict_row

 

DSN = "host=localhost port=5432 dbname=kant_shop user=postgres password=admin1234"

SQL = "SELECT course_id, course_name, fee FROM courses LIMIT 3"

 

with psycopg.connect(DSN, row_factory=dict_row) as conn:

rows = conn.execute(SQL).fetchall()

print(rows[0])

for c in rows:

print(c["course_name"], c["fee"])

몇 번째 칸인지 세지 않고, 열 이름을 키로 써요. 15의 딕셔너리예요.

번호로 칸을 고르면 SELECT의 열 순서를 계속 기억해야 해요. 둘째 줄처럼 psycopg.rows에서 dict_row를 불러오고, connect에 row_factory=dict_row를 붙이면 줄 하나가 딕셔너리로 와요. 키는 열 이름이에요. 그래서 row[2] 대신 c["fee"]처럼 15에서 배운 딕셔너리 꺼내기로 써요. 열 순서를 바꿔도 코드를 안 고쳐도 돼요. 출력 첫 줄을 보면 중괄호 안에 열 이름과 값이 짝으로 들어 있어요. 수업 코드도 dict_row를 썼어요. 앞으로는 계속 이 방법으로 써요. 실행 화면은 tools/demo.py로 실제 PostgreSQL 18과 psycopg 3을 실행해서 옮긴 결과예요.
