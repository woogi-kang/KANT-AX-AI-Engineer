SQL = """

SELECT c.course_name, c.fee

FROM courses c

JOIN sports s ON c.sport_id = s.sport_id

WHERE s.sport_name = %s

"""

 

 

def show(conn, sport):

print("종목:", sport)

for c in conn.execute(SQL, (sport,)):

print(" ", c["course_name"], c["fee"])

 

 

with psycopg.connect(DSN, row_factory=dict_row) as conn:

show(conn, "테니스")

show(conn, "요가")

SQL은 그대로 두고, 넘기는 값만 바꿔서 두 번 물었어요.

종목마다 강좌를 보고 싶어요. SQL에서 바뀌는 값 자리에 퍼센트 s를 적어요. 따옴표 없이 퍼센트 s 두 글자만 적어요. 값은 execute의 두 번째 칸에 튜플로 따로 넘겨요. show 함수가 받은 sport가 그 튜플에 들어가요. show(conn, "테니스")를 부르면 테니스가 퍼센트 s 자리에 들어가서 테니스 강좌 세 개가 나와요. 요가로 부르면 요가 강좌 두 개예요. SQL 글자는 한 번만 적고, 넘기는 값만 바꿔서 여러 번 물을 수 있어요. 수업 코드의 LIST_SQL에서 enroll_month = %s, 그리고 (MONTH,)가 바로 이 모양이에요. 실행 화면은 tools/demo.py로 실제 PostgreSQL 18과 psycopg 3을 실행해서 옮긴 결과예요.
