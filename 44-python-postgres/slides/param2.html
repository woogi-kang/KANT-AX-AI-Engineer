3. %s로 값 넣기

%s가 여러 개면 튜플에 적은 순서대로 들어가요

SQL = "SELECT course_name, fee FROM courses WHERE fee BETWEEN %s AND %s ORDER BY fee"

conn.execute(SQL, (60000, 70000))

60000

70000

첫 번째 %s에 튜플의 첫 번째 값, 두 번째 %s에 두 번째 값이 들어가요.

~/sports-app $ uv run main.py

수영 초급 아침반 70000

수영 초급 저녁반 70000

60000 이상 70000 이하

값이 하나여도 튜플로 넘겨요

쉼표가 있어야 튜플이에요

괄호만 있으면 그냥 글자예요(오류 장)

%s 개수와 튜플의 값 개수를 똑같이 맞춰요.

퍼센트 s는 여러 개 써도 돼요. 36에서 배운 BETWEEN에 최소 수강료와 최대 수강료 두 자리를 비워 뒀어요. 튜플에 60000, 70000을 넘기면 첫 번째 퍼센트 s에 60000, 두 번째에 70000이 순서대로 들어가요. 19에서 함수 인자가 순서대로 들어간 것과 같아요. 결과는 6만 원 이상 7만 원 이하인 강좌 네 개예요. 값이 하나일 때도 튜플로 넘겨요. 13에서 배운 대로 값 하나짜리 튜플은 뒤에 쉼표를 붙여야 해요. 쉼표가 없으면 괄호 안의 글자일 뿐이라 오류가 나요. 오류 장에서 실제 메시지를 봐요. 퍼센트 s 개수와 튜플의 값 개수는 항상 같게 맞춰요. 실행 화면은 tools/demo.py로 실제 PostgreSQL 18과 psycopg 3을 실행해서 옮긴 결과예요.
