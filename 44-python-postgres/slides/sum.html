SQL은 그대로, 값은 %s로, 저장은 with 블록 끝에서

이럴 때

이렇게 써요

PostgreSQL에 접속해요

with psycopg.connect(DSN, row_factory=dict_row) as conn:

여러 줄을 받아요

rows = conn.execute(SQL).fetchall()

한 줄, 값 하나를 받아요

row = conn.execute(SQL, (값,)).fetchone()

바뀌는 값을 넣어요

WHERE course_id = %s 와 (course_id,)

바꾼 것을 저장해요

with 블록 끝(오류면 취소), 또는 conn.commit()

다음에는 이 함수들을 웹 서버에 붙여서, 브라우저에서 누른 신청 버튼이 같은 INSERT를 실행하게 만들어요.

오늘 쓴 것을 다섯 줄로 모았어요. 접속은 with 블록과 connect, row_factory=dict_row예요. 여러 줄은 fetchall, 한 줄은 fetchone으로 받아요. 바뀌는 값은 SQL에 퍼센트 s를 적고 튜플로 따로 넘겨요. f-string으로 붙이지 않아요. 바꾼 것은 with 블록이 끝날 때 저장되고, 중간에 오류가 나면 모두 취소돼요. with 없이 쓰면 commit()을 직접 불러요. 다음에는 이 함수들을 웹 서버에 붙여서 브라우저 버튼으로 신청하게 만들어요.
