실행해서 확인해요. 실행 전에 psql에서 신청 표를 세면 187줄이에요. uv run main.py를 치면 10번 회원이 5번 강좌를 신청했다는 메시지가 나와요. 다시 psql에서 번호가 큰 순으로 두 줄을 보면 188번 줄이 새로 생겼어요. 회원 10, 강좌 5, 2026-11, 신청, 60000이에요. 프로그램이 넣은 줄을 psql에서도 보는 건 둘이 같은 데이터베이스에 붙어 있어서예요. 다음 장에서는 이 줄이 언제 저장되는지 봐요. 실행 화면은 tools/demo.py로 실제 PostgreSQL 18과 psycopg 3을 실행해서 옮긴 결과예요.
