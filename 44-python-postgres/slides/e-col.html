5. 비교와 오류

SQL의 열 이름이 표와 다르면 HINT가 맞는 이름을 알려 줘요

~/sports-app $ uv run main.py

Traceback (most recent call last):

 File "/home/kim/sports-app/main.py", line 22, in <module>

   list_courses(conn)

   ~~~~~~~~~~~~^^^^^^

 File "/home/kim/sports-app/main.py", line 15, in list_courses

   for c in conn.execute(LIST_SQL):

            ~~~~~~~~~~~~^^^^^^^^^^

 …

psycopg.errors.UndefinedColumn: column c.sports_id does not exist

LINE 4: JOIN sports s ON c.sports_id = s.sports_id

                        ^

HINT:  Perhaps you meant to reference the column "c.sport_id".

고치기

c.sports_id = s.sports_id

→

c.sport_id = s.sport_id

수업 코드는 표를 sports_id로 만들고 쿼리에는 sport_id를 써서 반대로 어긋났어요. 만든 표의 열 이름에 맞춰요.

SQL 안의 실수는 PostgreSQL이 찾아 줘요. 파이썬 오류 아래에 psql에서 보던 ERROR, LINE, HINT가 그대로 붙어 나와요. 여기서는 열 이름을 sports_id로 적었는데 표의 열은 sport_id라서 UndefinedColumn이 났어요. HINT가 c.sport_id를 쓰려던 것 아니냐고 알려 줘요. 수업 코드에서는 반대로, 표를 sports_id로 만들고 쿼리에 sport_id를 써서 어긋났어요. 어느 쪽이든 실제로 만든 표의 열 이름에 맞춰 고쳐요. psql에서 \d courses로 열 이름을 확인할 수 있어요. 실행 화면은 tools/demo.py로 실제 PostgreSQL 18과 psycopg 3을 실행해서 옮긴 결과예요.
