5. 비교와 오류

psql과 파이썬은 같은 SQL을 다른 손으로 보내요

psql (36~43)

파이썬 psycopg (44)

접속

docker exec -it my-pg psql -U postgres -d kant_shop

psycopg.connect(DSN)

SQL 보내기

치고 Enter

conn.execute(SQL)

결과

화면에 표

fetchall() 리스트, fetchone() 튜플

바뀌는 값

SQL에 직접 적기

%s와 튜플 (값,)

저장

문장마다 바로(자동 커밋)

with 블록 끝, 또는 commit()

끝내기

\q

with 블록 끝, 또는 close()

SQL 문장은 그대로 같아요. 저장되는 때가 가장 크게 달라요.

psql과 파이썬을 나란히 놓아 봤어요. psql은 docker exec로 들어가서 SQL을 치고 Enter를 눌렀어요. 파이썬은 connect로 접속하고 execute로 보내요. psql은 결과를 화면에 표로 그려 주고, 파이썬은 리스트와 튜플로 받아요. 바뀌는 값은 psql에서는 SQL에 직접 적었지만, 파이썬에서는 퍼센트 s와 튜플로 넘겨요. 가장 큰 차이는 저장되는 때예요. psql은 문장마다 바로 저장해요. psycopg는 with 블록이 끝나거나 commit()을 불러야 저장해요. SQL 문장 자체는 36부터 배운 것과 똑같아요.
