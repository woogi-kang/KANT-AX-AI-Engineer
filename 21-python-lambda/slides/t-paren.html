5. 오류와 함정

넘길 함수에 괄호를 붙이면 바로 실행돼요

[6]

def add10(x):

return x + 10

 

print(list(map(add10(), [1, 2, 3])))

Python

TypeError: add10() missing 1 required positional argument: 'x'

← map보다 먼저 x 없이 실행돼요

✕

map(add10(), [1, 2, 3])

map(add10, [1, 2, 3])

함수를 넘길 땐 괄호 없이 이름만 적어요.

map에 넘길 함수에 괄호를 붙이면 map이 돌기 전에 그 자리에서 먼저 실행돼요. 습관처럼 add10()이라고 적으면 add10이 x 없이 불려요. x에 넣을 값이 없으니 19에서 본 missing 1 required positional argument 오류가 나요. 함수를 넘길 때는 괄호 없이 이름만 적어요. 괄호는 map이 값을 하나씩 넣으면서 대신 붙여 줘요. 출력은 실제로 실행한 결과예요.
