2. 함수를 값처럼, lambda

lambda는 다른 함수에 바로 넘길 때 써요

변수에 담아 부르기

[3]

add10 = lambda x: x + 10

print(add10(5))

print(add10)

Python

15

<function <lambda> at 0x7fdb817cf270>

← 이름 자리가 비어 있어요

이름 없이 바로 넘기기

[4]

print(apply(lambda x: x * 3, 5))

Python

15

← 앞 장의 apply에 그 자리에서 만들어 넘겨요

한 번 쓰고 말 짧은 함수는 lambda로 그 자리에 적어요.

lambda는 한 번 쓰고 말 함수를 다른 함수에 바로 넘길 때 가장 많이 써요. lambda로 만든 함수도 변수에 담아 부를 수 있어요. add10(5)는 15예요. print로 찍으면 함수 이름 자리에 lambda가 나와요. 이름 없는 함수라서예요. 아래 셀은 앞 장의 apply에 x를 3배 하는 함수를 이름 없이 적어서 넘겼어요. 한 번 쓰고 말 함수에 def와 이름까지 붙이지 않아도 돼요. 반대로 여러 번 부를 함수라면 add10 = lambda보다 def add10(x):가 읽기 쉬워요. apply는 앞 셀에서 정의했어요. 출력은 실제로 실행한 결과예요.
