5. 오류와 함정

map 결과에는 번호도 len도 못 써요

[1]

doubled = map(lambda x: x * 2, [1, 2, 3])

print(doubled[0])

Python

TypeError: 'map' object is not subscriptable

[2]

print(len(doubled))

Python

TypeError: object of type 'map' has no len()

← filter 결과도 같아요

[3]

doubled = list(map(lambda x: x * 2, [1, 2, 3]))

print(doubled[0])

print(len(doubled))

Python

2

3

← list()로 바꾸면 돼요

번호로 꺼내거나 길이를 재려면 먼저 list()로 바꿔요.

map 결과는 리스트가 아니라서 번호로 꺼내거나 len으로 잴 수 없어요. doubled는 map object예요. 그래서 doubled[0]처럼 번호로 꺼내면 subscriptable이 아니라는 TypeError가 나요. len으로 길이를 재도 map에는 len이 없다는 TypeError가 나요. filter 결과도 똑같아요. 아래처럼 list로 감싸 리스트로 만들어 두면 번호와 len을 쓸 수 있어요. Traceback 위쪽 줄은 빼고 마지막 줄만 옮겼어요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
