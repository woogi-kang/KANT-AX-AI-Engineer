3. map

for 네 줄이 map 한 줄이 돼요

[1]

prices = [4500, 5000, 6500]

 

def add500(p):

return p + 500

 

print(list(map(add500, prices)))

print(list(map(lambda p: p + 500, prices)))

print(prices)

← def로 만든 이름 넘기기

← lambda 바로 넘기기

← 원본은 그대로

1파트의 for도 같은 결과예요

up = []

for p in prices:

up.append(p + 500)

map(함수, 리스트)는 for와 append로 새 리스트를 만드는 일을 한 줄로 줄여요.

for와 append 네 줄, def 넘기기, lambda 넘기기 모두 같은 결과예요. 결과는 셋 다 [5000, 5500, 7000]이에요. def로 넘길 때는 add500에 괄호를 붙이지 않아요. 2파트에서 본 것처럼 함수를 넘기는 거라서예요. map은 새 결과를 만들고 prices는 그대로 둬요. 13의 sorted가 원본을 두고 새 리스트를 준 것과 같아요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
