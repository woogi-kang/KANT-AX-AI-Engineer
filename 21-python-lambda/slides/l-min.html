나온 값을 리스트로 모아요

함수와 리스트를 map에 넘기면 값마다 함수를 써서 결과를 모아 줘요.

가장 짧은 예예요. numbers의 값 1, 2, 3에 10씩 더해요. lambda x: x + 10은 x를 받아 x + 10을 돌려주는 함수예요. 2파트에서 자세히 봐요. map은 이 함수를 numbers의 값마다 써요. 1을 넣으면 11, 2를 넣으면 12, 3을 넣으면 13이 나와요. 마지막으로 list로 감싸서 [11, 12, 13] 리스트로 모아요. list가 왜 필요한지는 3파트에서 봐요. 앞 장의 for 네 줄이 한 줄이 됐어요. 출력은 실제로 실행한 결과예요.
