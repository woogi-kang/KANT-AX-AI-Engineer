5. 오류와 함정

map 결과는 한 번 꺼내면 비어요

[4]

m = map(lambda p: p + 500, [4500, 5000])

print(list(m))

print(list(m))

Python

[5000, 5500]

[]

← 다 꺼낸 뒤라 비었어요

첫 번째 list(m)

5000

5500

두 번째 list(m)

[]

남은 값이 없어요

이렇게 고쳐요

[5]

m = map(lambda p: p + 500, [4500, 5000])

ups = list(m)

print(ups)

print(ups)

Python

[5000, 5500]

[5000, 5500]

두 번 이상 쓸 결과는 list()로 바꿔 변수에 담아 둬요.

map 결과는 한 번 끝까지 꺼내면 비어서, 두 번째부터는 빈 리스트가 나와요. 오류는 안 나서 더 헷갈리는 함정이에요. m에 map을 담고 list(m)을 두 번 찍었어요. 첫 번째는 [5000, 5500]인데 두 번째는 빈 리스트예요. map은 값을 하나씩 꺼내 주는 묶음이라서, 첫 list가 끝까지 꺼내고 나면 남은 값이 없어요. 결과를 두 번 이상 쓸 거라면 오른쪽 아래처럼 list(m)을 한 번만 해서 ups에 담아 두고 ups를 써요. 리스트는 몇 번을 찍어도 그대로예요. 출력은 실제로 실행한 결과예요.
