4. filter

for와 if로 골라 담던 일을 filter 한 줄로

[1]

prices = [4500, 5000, 6500, 3000]

big = []

for p in prices:

if p >= 5000:

big.append(p)

print(big)

print(list(filter(lambda p: p >= 5000, prices)))

Python

[5000, 6500]

[5000, 6500]

for 안의 if로 골라 담는 일은 filter 한 줄로 줄여요.

for 안의 if로 골라 담던 다섯 줄을 filter 한 줄로 바꿀 수 있어요. 17에서 5000원 이상인 가격만 big에 담았어요. filter의 첫째 인자는 조건 함수이고, 둘째는 리스트예요. 조건 함수가 True를 돌려준 값만 남아요. lambda p: p >= 5000은 p가 5000 이상인지 True나 False로 답해요. filter도 map처럼 결과를 꺼내 줄 준비만 하니까 list로 감싸서 봐요. 원본 prices는 그대로예요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
