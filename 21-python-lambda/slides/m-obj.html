3. map

map만 찍으면 <map object>가 나와요

[2]

m = map(lambda p: p + 500, prices)

print(m)

print(list(m))

Python

<map object at 0x7fe9b3214840>

[5000, 5500, 7000]

← 값을 꺼내 줄 준비만 한 묶음이에요

← list()가 끝까지 꺼내 모아요

[3]

for p in map(lambda p: p + 500, prices):

print(p)

Python

5000

5500

7000

← for도 하나씩 꺼내 써요

결과를 리스트로 보려면 list()로 감싸요.

map만 찍으면 결과 대신 값을 꺼내 줄 준비만 한 map object가 나와요. 오류가 아니에요. map은 결과를 바로 다 만들지 않고, 달라고 하면 값을 하나씩 꺼내 주는 묶음을 돌려줘요. list로 감싸면 값을 끝까지 꺼내서 리스트로 모아요. 그래서 지금까지 list(map(...))처럼 적었어요. for도 값을 하나씩 꺼내니까 찍기만 할 때는 list 없이 for로 돌려도 돼요. 0x 뒤 숫자는 메모리 위치라서 화면마다 달라요. 출력은 실제로 실행한 결과예요.
