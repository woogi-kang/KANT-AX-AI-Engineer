5. 오류와 함정

lambda 안에 return을 쓰면 SyntaxError가 나요

[7]

add10 = lambda x: return x + 10

Python

SyntaxError: invalid syntax

return

콜론 뒤에는 값만 와요

return은 값이 아니라 문장이에요. lambda는 콜론 뒤의 값을 알아서 돌려줘요.

이렇게 고쳐요

return 빼기

add10 = lambda x: x + 10

if 문, for 문, =도 못 넣어요

lambda 몸통은 값 하나예요. 줄을 나눠 적어야 하는 일은 def로 만들어요.

오류 끝 괄호는 뺐어요

SyntaxError 끝의 (1234.py, line 1)은 셀마다 달라서 슬라이드에서 뺐어요.

lambda는 콜론 뒤에 돌려줄 값 하나만 적어요.

def에서 return을 쓰던 습관대로 lambda에도 return을 적으면 invalid syntax가 나요. lambda는 콜론 뒤에 적은 값을 알아서 돌려주고, 그 자리에는 값만 올 수 있어요. return, if 문, for 문, 변수에 넣는 =는 값이 아니라서 못 넣어요. return을 빼면 돼요. SyntaxError 메시지 끝에는 셀마다 다른 파일 이름과 줄 번호가 괄호로 붙어요. 슬라이드에서는 그 부분을 뺐어요. 출력은 실제로 실행한 결과예요.
