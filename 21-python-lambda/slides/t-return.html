5. 오류와 함정

lambda 안에 return을 쓰면 SyntaxError가 나요

[7]

add10 = lambda x: return x + 10

Python

SyntaxError: invalid syntax

← 콜론 뒤에는 값만 와요

✕

lambda x: return x + 10

lambda x: x + 10

lambda는 콜론 뒤에 돌려줄 값 하나만 적어요.

lambda 안에 return을 적으면 invalid syntax가 나요. lambda는 콜론 뒤에 적은 값을 알아서 돌려주고, 그 자리에는 값만 올 수 있어요. return, if 문, for 문, 변수에 넣는 =는 값이 아니라서 못 넣어요. return을 빼면 돼요. 줄을 나눠야 하는 일은 다음 장처럼 def로 만들어요. SyntaxError 끝에 붙는 파일 이름과 줄 번호는 셀마다 달라서 그 부분은 빼고 옮겼어요. 출력은 실제로 실행한 결과예요.
