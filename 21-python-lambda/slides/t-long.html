def로 나눠 쓰기

def label(p):

if p >= 6000:

return "비쌈"

elif p >= 4500:

return "보통"

return "쌈"

 

print(label(6500), label(5000), label(3000))

비쌈 보통 쌈

결과는 같아요

조건이 두 개를 넘으면 lambda는 한눈에 안 읽혀요. def로 나누고 map(label, prices)처럼 이름을 넘겨요.

오류는 아니지만 자주 보는 함정이에요. 한 줄 if else를 괄호로 겹치면 lambda 한 줄에 조건 두 개를 넣을 수 있어요. 결과도 맞아요. 그런데 어디까지가 어느 조건인지 읽기 어려워요. 아래 def처럼 if와 elif로 나눠 쓰면 19에서 본 모양이라 금방 읽혀요. map에는 label처럼 이름만 넘기면 돼요. lambda는 한 줄로 바로 읽히는 짧은 일에만 써요. 출력은 실제로 실행한 결과예요.
