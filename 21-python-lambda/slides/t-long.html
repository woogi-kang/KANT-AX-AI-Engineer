def label(p):

if p >= 6000:

return "비쌈"

elif p >= 4500:

return "보통"

return "쌈"

 

print(label(6500), label(5000), label(3000))

Python

비쌈 보통 쌈

← 조건이 한 줄에 하나씩

← label(5000)을 따라가 봐요

← 결과는 같아요

조건이 두 개를 넘으면 lambda 대신 def로 나눠 써요. 한 줄 if else를 괄호로 겹치면 lambda 한 줄에 조건 두 개를 넣을 수 있고 결과도 맞아요. 그런데 어디까지가 어느 조건인지 읽기 어려워요. 아래 def처럼 if와 elif로 나눠 쓰면 19에서 본 모양이라 금방 읽혀요. label(5000)을 따라가면 첫 if는 False라 건너뛰고, elif에서 보통을 돌려줘요. map에는 map(label, prices)처럼 이름만 넘기면 돼요. lambda는 한 줄로 바로 읽히는 짧은 일에만 써요. 출력은 실제로 실행한 결과예요.
