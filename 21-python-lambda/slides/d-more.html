lambda도 매개변수를 쉼표로 여러 개 받을 수 있어요. price_of는 가격과 잔 수를 받아 곱한 값을 돌려줘요. 콜론 뒤에는 값 하나만 올 수 있어서 17의 if 문은 못 넣어요. 대신 17에서 배운 한 줄 if else는 값 하나로 계산되니까 쓸 수 있어요. 아래 표에 def와 lambda를 나란히 정리했어요. 이름이 있는지, 몸통이 몇 줄인지, return을 적는지가 달라요. 여러 번 부를 함수는 def, 다른 함수에 바로 넘길 짧은 함수는 lambda로 만들어요. 출력은 실제로 실행한 결과예요.
