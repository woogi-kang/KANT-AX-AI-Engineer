price_of = lambda price, qty: price * qty

print(price_of(4500, 2))

label = lambda p: "비쌈" if p >= 5000 else "보통"

print(label(6500), label(4500))

lambda도 매개변수를 여러 개 받고, 값 하나로 계산되는 한 줄 if else를 쓸 수 있어요. price_of는 가격과 잔 수를 쉼표로 받아 곱한 값을 돌려줘요. 콜론 뒤에는 값 하나만 올 수 있어서 17의 if 문은 못 넣어요. 대신 17에서 배운 한 줄 if else는 값 하나로 계산되니까 쓸 수 있어요. 아래 표에 def와 lambda를 나란히 정리했어요. 가장 큰 차이는 몸통이에요. def는 여러 줄, lambda는 값 하나예요. 여러 번 부를 함수는 def, 다른 함수에 바로 넘길 짧은 함수는 lambda로 만들어요. 출력은 실제로 실행한 결과예요.
