4. filter

딕셔너리를 넘기면 키가 하나씩 들어가요

[3]

stock = {"coffee": 3, "latte": 0, "cake": 2, "tea": 0}

print(list(filter(lambda m: stock[m] > 0, stock)))

m에는 키가 들어가요

15에서 for m in stock:이 키를 꺼낸 것과 같아요. 값은 stock[m]으로 봐요.

결과는 키 리스트

품절이 아닌 메뉴 이름만 남았어요. 재고 숫자는 들어 있지 않아요.

딕셔너리를 넘기면 키로 골라서, 조건에 맞는 키만 남겨요.

15의 재고 딕셔너리를 filter에 넘겨 봐요. 딕셔너리를 for로 돌면 키가 나왔던 것처럼, filter에도 키가 하나씩 들어가요. 그래서 lambda의 m은 coffee, latte 같은 메뉴 이름이고, 재고는 stock[m]으로 꺼내요. 재고가 0보다 큰 coffee와 cake만 남았어요. 결과는 키만 담은 리스트라서 재고 숫자는 없어요. 재고까지 같이 담은 딕셔너리로 고르는 방법은 23에서 배워요. 출력은 실제로 실행한 결과예요.
