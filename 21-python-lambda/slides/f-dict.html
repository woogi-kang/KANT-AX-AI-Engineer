4. filter

딕셔너리를 넘기면 키가 하나씩 들어가요

[3]

stock = {"coffee": 3, "latte": 0, "cake": 2, "tea": 0}

print(list(filter(lambda m: stock[m] > 0, stock)))

['coffee', 'cake']

딕셔너리를 넘기면 키로 골라서, 조건에 맞는 키만 남겨요.

filter에 딕셔너리를 넘기면 키가 하나씩 들어가고, 조건에 맞는 키만 남아요. 15에서 딕셔너리를 for로 돌면 키가 나왔던 것과 같아요. 그래서 lambda의 m은 coffee, latte 같은 메뉴 이름이고, 재고는 stock[m]으로 꺼내요. 재고가 0인 latte와 tea는 False라서 빠지고 coffee와 cake만 남았어요. 결과는 키만 담은 리스트라서 재고 숫자는 없어요. 재고까지 같이 담은 딕셔너리로 고르는 방법은 23에서 배워요. 출력은 실제로 실행한 결과예요.
