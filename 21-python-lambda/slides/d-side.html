2. 함수를 값처럼, lambda

lambda는 한 줄로 만드는 이름 없는 함수예요

19의 def

def add10(x):

return x + 10

lambda

lambda x: x + 10

lambda

def 대신 써요

x

매개변수, 괄호 없이

:

뒤가 돌려줄 값

x + 10

return 없이 돌려줘요

이름, 괄호, return을 빼고 매개변수와 돌려줄 값만 남긴 모양이에요.

lambda는 def에서 이름, 괄호, return을 빼고 매개변수와 돌려줄 값만 남긴 함수예요. 위는 19에서 배운 def 함수예요. 아래 lambda도 같은 일을 하는 함수예요. def의 x와 x + 10이 그대로 lambda로 옮겨 가요. lambda는 def처럼 함수를 만든다는 표시예요. 그 뒤 x가 매개변수인데 괄호 없이 적어요. 콜론 뒤에는 돌려줄 값을 적어요. return을 쓰지 않아도 이 값이 돌아가요. 함수 이름 자리가 없어서 이름 없는 함수라고 불러요. 몸통에는 값 하나만 적을 수 있어요.
