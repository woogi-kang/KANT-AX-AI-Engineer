2. 함수를 값처럼, lambda

lambda는 한 줄로 만드는 이름 없는 함수예요

def로 만들기

def add10(x):

return x + 10

lambda로 만들기

lambda x: x + 10

lambda

함수를 만든다는 표시예요. def 대신 써요

x

매개변수예요. 괄호 없이 적어요

:

콜론 뒤가 돌려줄 값이에요

x + 10

return 없이도 이 값을 돌려줘요

이름, 괄호, return을 빼고 돌려줄 값 하나만 남긴 모양이에요.

왼쪽은 19에서 배운 def 함수예요. 오른쪽 lambda도 같은 일을 하는 함수예요. 조각을 나눠 봐요. lambda는 def처럼 함수를 만든다는 표시예요. 그 뒤 x가 매개변수인데 괄호 없이 적어요. 콜론 뒤에는 돌려줄 값을 적어요. return을 쓰지 않아도 이 값이 돌아가요. 함수 이름 자리가 없어서 이름 없는 함수라고 불러요. 몸통에는 값 하나, 곧 식 하나만 적을 수 있어요.
