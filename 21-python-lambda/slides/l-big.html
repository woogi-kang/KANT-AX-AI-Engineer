1. 왜 필요한가

map은 하나씩 바꾸고, filter는 골라내요

map: 값마다 바꿔요

4500

5000

6500

p + 500

5000

5500

7000

filter: 조건에 맞는 값만 남겨요

4500

5000

6500

p >= 5000

4500

5000

6500

map(함수, 리스트)

리스트의 값을 하나씩 함수에 넣고, 돌려받은 값을 모아요. 개수는 그대로예요.

filter(함수, 리스트)

함수가 True를 돌려준 값만 남겨요. 값은 그대로이고 개수가 줄어요.

가운데 띠에 넣는 짧은 함수를 lambda로 만들어요.

큰 그림부터 봐요. map은 리스트의 값을 하나씩 가운데 함수에 넣어요. 함수가 돌려준 값을 순서대로 모아서 새 결과를 만들어요. 값이 셋이면 결과도 셋이에요. filter도 값을 하나씩 함수에 넣는데, 함수는 True나 False를 돌려줘요. True인 값만 아래로 내려가고 False인 값은 버려요. 값은 바뀌지 않고 개수만 줄어요. 가운데 띠에 들어가는 p + 500, p >= 5000 같은 짧은 함수를 lambda로 만들어요.
