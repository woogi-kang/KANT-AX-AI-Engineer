[4]

print(sorted(["Latte", "cake", "Tea", "coffee"]))

print(sorted(["라떼", "커피", "녹차"]))

print(sorted(["10", "9", "100"]))

Python

['Latte', 'Tea', 'cake', 'coffee']

['녹차', '라떼', '커피']

['10', '100', '9']

← 크기순이 아니에요

"Tea" < "cake"

True

대문자 A~Z 뒤에 소문자 a~z가 와요

"녹차" < "라떼"

True

한글은 가나다 순이에요

"100" < "9"

True

첫 글자 1과 9를 먼저 비교해요

글자는 사전처럼 첫 글자부터 하나씩 비교해요. 첫째 줄에서 Latte와 Tea가 cake보다 앞에 왔어요. 파이썬은 대문자를 소문자보다 앞에 둬요. 한글은 가나다 순이에요. 셋째 줄은 숫자를 글자로 담았어요. 첫 글자 1과 9를 비교해서 10과 100이 9보다 앞에 와요. 이렇게 크기순이 아닌 결과는 다음 두 장의 key로 고쳐요. 출력은 실제로 실행한 결과예요.
