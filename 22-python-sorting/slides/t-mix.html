5. 오류와 함정

숫자와 글자를 섞으면 비교할 수 없어요

[1]

print(sorted([4500, "5000", 6500]))

Python

TypeError: '<' not supported between instances of 'str' and 'int'

← 글자와 숫자

[2]

print(sorted([4500, "5000", 6500], key=int))

Python

[4500, '5000', 6500]

← 비교할 때만 숫자로

← "5000"은 그대로 글자

✕

[4500, "5000", 6500]

✓

[4500, 5000, 6500]

한 리스트에는 같은 타입을 담아요. 섞였으면 key로 맞춰 비교해요.

숫자와 글자가 섞인 리스트는 크기를 비교할 수 없어서 TypeError가 나요. 가격 하나가 글자 "5000"으로 들어갔어요. sorted가 4500과 "5000"을 비교하려다 str과 int 사이에는 < 를 쓸 수 없다는 오류를 내요. max와 min도 똑같은 오류가 나요. key=int를 주면 비교할 때만 숫자로 바꿔서 줄 세워요. 결과에는 "5000"이 글자로 그대로 남아요. 처음부터 같은 타입으로 담는 게 가장 좋아요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
