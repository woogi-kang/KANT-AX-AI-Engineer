key=len: 길이를 재서 비교해요

[5]

names = ["latte", "tea", "coffee", "mocha"]

print(list(map(len, names)))

print(sorted(names, key=len))

print(sorted(names, key=len, reverse=True))

Python

← 길이가 같으면 처음 적은 순서

key=len은 길이로 비교하고, 길이가 같으면 처음 적은 순서를 지켜요. 21에서 map(len, names)로 뽑은 길이 5, 3, 6, 5가 sorted가 안에서 쓰는 비교 값이에요. 작은 것부터 세우면 tea, latte와 mocha, coffee 순이에요. latte와 mocha는 길이가 같아요. 이럴 땐 처음 적은 순서를 그대로 지켜서 latte가 먼저 와요. reverse=True를 같이 주면 긴 이름부터 세워요. 길이가 같은 둘의 순서는 그대로예요. 출력은 실제로 실행한 결과예요.
