5. 오류와 함정

lambda나 key=를 빠뜨리면 생기는 오류

[5]

print(sorted(sales.items(), key=kv[1]))

Python

NameError: name 'kv' is not defined

[6]

print(sorted(sales, sales.get))

Python

TypeError: sorted expected 1 argument, got 2

lambda kv: 가 빠졌어요

kv는 lambda가 만드는 칸 이름이에요. lambda 없이 쓰면 그런 변수가 없어요.

key= 이름을 빠뜨렸어요

sorted는 줄 세울 값 하나만 위치로 받아요. key는 꼭 key=로 적어요.

이렇게 고쳐요

sorted(sales.items(), key=lambda kv: kv[1])

sorted(sales, key=sales.get)

두 가지 빠뜨리기예요. 첫째는 lambda kv: 를 빼고 kv[1]만 적었어요. kv는 lambda가 만드는 매개변수 이름인데 lambda가 없으니 그런 변수가 없다는 NameError가 나요. 둘째는 key= 없이 sales.get을 둘째 자리에 넣었어요. sorted는 줄 세울 값 하나만 위치로 받고, key와 reverse는 20에서 배운 키워드 인자로만 받아요. 그래서 1개를 받아야 하는데 2개를 받았다는 TypeError가 나요. 출력은 실제로 실행한 결과예요.
