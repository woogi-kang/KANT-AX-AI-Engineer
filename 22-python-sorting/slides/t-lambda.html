5. 오류와 함정

lambda나 key=를 빠뜨리면 생기는 오류

[5]

print(sorted(sales.items(), key=kv[1]))

Python

NameError: name 'kv' is not defined

← lambda kv: 가 빠졌어요

[6]

print(sorted(sales, sales.get))

Python

TypeError: sorted expected 1 argument, got 2

← key= 이름이 빠졌어요

✕

key=kv[1]

✓

key=lambda kv: kv[1]

✕

sorted(sales, sales.get)

✓

sorted(sales, key=sales.get)

key는 꼭 key=로, lambda는 lambda 이름: 까지 적어요.

lambda kv: 를 빠뜨리면 NameError, key= 를 빠뜨리면 TypeError가 나요. 첫째는 lambda kv: 를 빼고 kv[1]만 적었어요. kv는 lambda가 만드는 매개변수 이름인데 lambda가 없으니 그런 변수가 없다는 오류가 나요. 둘째는 key= 없이 sales.get을 둘째 자리에 넣었어요. sorted는 줄 세울 값 하나만 위치로 받고, key와 reverse는 20에서 배운 키워드 인자로만 받아요. 그래서 1개를 받아야 하는데 2개를 받았다는 TypeError가 나요. 출력은 실제로 실행한 결과예요.
