get은 키를 넣으면 값을 줘요

15의 sales.get("latte")예요. 괄호 없이 sales.get만 넘기면 함수 자체가 넘어가요.

lambda로 써도 같아요

key=lambda k: sales[k]도 키마다 판매량을 꺼내요.

키를 값 순서로 세우려면 key에 sales.get을 넘겨요.

결과에 이름만 있으면 될 때는 더 짧게 써요. 15에서 배운 get은 키를 넣으면 값을 주는 메서드예요. 괄호 없이 sales.get만 key에 넘기면 sorted가 키마다 sales.get을 불러 판매량을 꺼내 비교해요. 결과는 키 리스트예요. 21에서 함수를 괄호 없이 넘긴 것과 같아요. lambda k: sales[k]로 적어도 결과는 같아요. 1파트의 max(sales, key=sales.get)도 이 방식이었어요. 출력은 실제로 실행한 결과예요.
