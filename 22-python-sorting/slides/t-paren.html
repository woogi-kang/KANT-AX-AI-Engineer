5. 오류와 함정

key에 괄호를 붙이면 TypeError가 나요

[3]

print(sorted(["latte", "tea"], key=len()))

Python

TypeError: len() takes exactly one argument (0 given)

[4]

sales = {"coffee": 12, "latte": 30, "cake": 8, "tea": 15}

print(sorted(sales, key=sales.get()))

Python

TypeError: get expected at least 1 argument, got 0

← 아무것도 안 넣고 먼저 불렸어요

✕

key=len()

✓

key=len

✕

key=sales.get()

✓

key=sales.get

key에 괄호를 붙이면 함수가 그 자리에서 아무것도 받지 않고 먼저 실행돼요. len()은 재료 없이 불려서 하나를 받아야 하는데 0개를 받았다는 TypeError가 나요. sales.get()도 키 없이 불려서 got 0이라는 오류가 나요. 21에서 map에 add10()을 넘겼을 때와 같은 실수예요. key에는 괄호 없이 함수 이름만 적어요. 괄호는 sorted가 값을 하나씩 넣으면서 대신 붙여 줘요. 출력은 실제로 실행한 결과예요.
