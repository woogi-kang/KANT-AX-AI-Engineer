기준이 둘이면 key가 (첫째 기준, 둘째 기준) 튜플을 돌려주게 해요. 메뉴판 이름을 짧은 것부터 적고 싶어요. key=len만 주면 길이 5인 mocha와 latte는 처음 적은 순서대로 mocha가 먼저예요. 같은 길이끼리 abc 순으로 세우려면 key가 길이와 이름을 묶은 튜플을 돌려주게 해요. 첫 칸 5가 같으니 둘째 칸 이름을 비교해서 latte가 앞으로 와요. 3파트의 판매량 순위와 같은 방법이에요. 이번에는 둘 다 작은 것부터라 -를 붙이지 않아요. 출력은 실제로 실행한 결과예요.
