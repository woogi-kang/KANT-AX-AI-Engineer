pull 하기 전에 설정을 한 줄 쳐요

git config --global pull.rebase false

false는 합칠 때 merge로 하라는 뜻이에요. 셋 다 처음 한 번만 쳐요.

git pull

은 두 단계예요

=

fetch

GitHub 커밋 받아 오기

+

merge

내 main과 합치기

fatal: Need to specify how to reconcile divergent branches.

설정을 안 하면 오늘 실습 중간에 pull이 이 메시지로 멈춰요. 13쪽에서 다시 봐요.

03에서 본 설정이에요. 아직 안 했다면 셋 다 지금 쳐요. 출력은 없어요. --global이라 내 컴퓨터의 모든 저장소에 적용돼서 한 번만 하면 돼요. 이 설정이 없으면 내 main과 GitHub main이 갈라졌을 때 pull이 어떻게 합칠지 물으면서 fatal로 멈춰요. 오늘 실습은 그 상황이 반드시 생겨요. git config --global pull.rebase로 값을 확인할 수 있어요. false가 나오면 된 거예요. rebase는 08에서 다른 합치는 방법과 비교해 봐요.
