브랜치에서 커밋하고 브랜치를 push

상황

lee.md를 만들어 커밋했어요. main이 아니라 feature/lee-intro를 올려요.

lee의 터미널

~/team-intro

$ echo "안녕하세요, lee예요" > lee.md

$ git add lee.md

$ git commit -m "docs: lee 자기소개 추가"

[feature/lee-intro 6fb7cc2] docs: lee 자기소개 추가

1 file changed, 1 insertion(+)

create mode 100644 lee.md

$ git push origin feature/lee-intro

To https://github.com/kim/team-intro.git

* [new branch] feature/lee-intro -> feature/lee-intro

push origin 뒤에 브랜치 이름을 적어요. GitHub에 같은 이름 브랜치가 생겨요.

main 대신 내 브랜치 이름을 적어서 push해요. 브랜치는 내 것이라 거절될 일이 거의 없어요. 실제 GitHub은 이 출력 사이에 remote: Create a pull request for 'feature/lee-intro' on GitHub by visiting: 줄과 주소를 함께 보여 줘요. 그 주소를 열거나 GitHub 레포 화면의 노란 Compare & pull request 버튼을 눌러 PR을 만들어요.
