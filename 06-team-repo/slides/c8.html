main에 커밋했는데 아직 push 전이면 브랜치로 옮겨요

브랜치를 깜빡하고 main에서 커밋했어요. 아직 push는 안 했어요.

kim의 터미널

~/team-intro

$ git commit -m "docs: 다음 모임 날짜 추가"

[main 0af5f5a] docs: 다음 모임 날짜 추가

$ git branch feature/next-meeting

# 지금 커밋에 브랜치 이름표를 하나 더 붙여요

$ git status

Your branch is ahead of 'origin/main' by 1 commit.

nothing to commit, working tree clean

$ git reset --hard HEAD~1

HEAD is now at 1ef2620 Merge pull request #6 from kim/feature/kim-member

$ git checkout feature/next-meeting

$ git log --oneline

0af5f5a (HEAD -> feature/next-meeting) docs: 다음 모임 날짜 추가

1ef2620 (origin/main, origin/HEAD, main) Merge pull request #6 ...

branch로 이름표를 붙이고, main만 한 칸 되돌리고, 그 브랜치로 옮겨요. push한 뒤라면 팀에 먼저 알려요.

커밋은 그대로 두고 이름표만 옮기는 방법이에요. git branch 이름은 지금 커밋에 새 이름표만 붙여요. 그다음 main을 03에서 배운 reset --hard로 한 칸 되돌려요. --hard는 커밋 안 한 변경을 지우니 git status가 깨끗한지 먼저 봐요. 마지막으로 새 브랜치로 옮기면 커밋이 거기 있어요. 이미 push했다면 되돌리지 말고 팀에 말한 뒤 revert를 써요. echo, add 줄과 status의 On branch main 줄, 안내 줄, 마지막 log의 아래 줄들은 뺐어요.
