4부 · 팀 규칙

한 번 작업할 때 이 순서로 돌아요

1

받기

git pull origin main

2

작업

파일 고치기

3

담기

git add 파일

4

저장

git commit -m "..."

5

올리기

git push origin main

push가 거절되면 1번으로

pull에서 CONFLICT가 나면

파일 고치기 → git add 파일 → git commit -m "fix: ..." → git push origin main

하루에 이 순환을 여러 번 돌아요. push가 거절되면 놀라지 말고 다시 1번 pull로 돌아가요. pull에서 충돌이 나면 3부에서 한 것처럼 고치고 add, commit, push해요.
