레포 주소는 GitHub 레포 화면의 초록색 Code 버튼에서 복사해요. 셋이 같은 주소로 clone하면 Initial commit 하나가 든 똑같은 저장소가 세 개 생겨요. 아래 네 칸이 오늘 내내 볼 그림이에요. 점 색은 커밋한 사람이에요. clone한 뒤에는 꼭 cd team-intro로 폴더에 들어가요. git log --oneline 출력은 화면 폭 때문에 두 줄로 나눴어요. 실제로는 한 줄이에요. clone 출력 중 remote: 로 시작하는 진행 줄은 뺐어요.
