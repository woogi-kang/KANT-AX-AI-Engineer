오늘 배우는 명령은 모두 ① 작업 폴더나 ② 대기실을 바꾸고, ③ 내 저장소의 커밋은 건드리지 않아요. 02의 네 칸 그림이에요. git restore는 빨간 화살표처럼 ③의 마지막 커밋 모습을 ①로 가져와요. git restore --staged는 초록 화살표처럼 ②에 올린 것을 내려요. git stash는 ①의 변경을 아래 서랍에 넣었다가 git stash pop으로 다시 꺼내요. 서랍도 내 컴퓨터 안에 있어서 GitHub에는 올라가지 않아요.
