login.md에 로그인 버튼을 붙이고, 내 할 일을 적은 memo.md도 만들었어요. git add . 은 폴더 안 바뀐 파일을 모두 올려서 memo.md까지 대기실에 들어갔어요. 이대로 commit하고 push하면 팀원 모두가 내 메모를 받아요. 초록 글씨 위 안내 줄이 add를 취소하는 방법이에요. unstage는 대기실에서 내린다는 뜻이에요.
