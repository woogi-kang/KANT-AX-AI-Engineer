이대로 commit, push하면
팀원 모두 내 메모를 받아요

$ echo "로그인 버튼" >> login.md

$ echo "내일 할 일: 디자인 묻기" > memo.md

$ git add .

$ git status

On branch main

Changes to be committed:

  (use "git restore --staged <file>..." to unstage)

        modified: login.md

        new file: memo.md

git add . 은 폴더 안 바뀐 파일을 모두 올려서, 개인 메모 memo.md까지 대기실에 들어갔어요. login.md에 로그인 버튼을 붙이고, 내 할 일을 적은 memo.md도 만든 상황이에요. 이대로 commit하고 push하면 팀원 모두가 내 메모를 받아요. 터미널의 노란 줄이 add를 취소하는 방법이에요. unstage는 대기실에서 내린다는 뜻이에요.
