git restore · 주의

restore로 버린 건 되찾을 수 없어요

커밋하지 않은 변경은
Git에 기록이 없어요

reset이나 revert는 커밋을 다뤄서 기록이 남아요. restore로 버린 줄은 휴지통에도 가지 않아요.

git restore . 은 특히 조심

1

git diff 먼저

사라질 줄을 눈으로 확인해요

git diff

2

남길 게 있으면 커밋

커밋해 두면 나중에 되돌릴 수 있어요

git add 파일
git commit -m "..."

3

파일 이름을 꼭 적기

git restore . 은 모든 파일을 한 번에 버려요

git restore login.md

restore는 고친 내용을 지우는 명령이라 되돌릴 수 없어요. 02에서 본 reflog도 커밋만 기억해서 여기엔 소용없어요. 그래서 세 가지를 지켜요. 먼저 git diff로 보고, 남길 줄이 있으면 커밋부터 하고, 파일 이름을 꼭 적어요. git restore . 처럼 점을 쓰면 폴더 안 모든 파일의 변경이 한 번에 사라져요.
