팀에서 쓰기

팀원이 push했대요. 나는 고치던 중이에요

1

git stash

고치던 걸 서랍에

2

git pull origin main

팀원 커밋 받기

3

git stash pop

서랍에서 꺼내 이어서

4

git add login.md
git commit -m "feat: 비밀번호 찾기 추가"

마저 하고 커밋

5

git push origin main

올리기

$ git log --oneline

8eacb89 (HEAD -> main, origin/main) feat: 비밀번호 찾기 추가

0be6431 feat: 로그인 제목 바꾸기

15d92cb feat: 로그인 버튼 추가

e12ffc2 feat: 로그인 화면 추가

merge 커밋 없이
한 줄로 이어졌어요

lee의 커밋 위에 내 커밋이 올라갔어요.

오늘 팀 실습에서 그대로 쓰는 순서예요. 1번부터 3번이 stash, pull, pop이에요. 4번과 5번은 늘 하던 add, commit, push예요. 고치던 걸 먼저 커밋하고 pull해도 돼요. 그러면 03에서 본 merge 커밋이 하나 생겨요. stash를 쓰면 팀원 커밋 위에 내 커밋이 올라가서 git log가 한 줄로 이어져요. 커밋할 만큼 끝났으면 커밋, 덜 끝났으면 stash라고 기억하면 돼요.
