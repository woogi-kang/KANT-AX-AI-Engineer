1

git stash

고치던 걸 서랍에

2

git pull origin main

팀원 커밋 받기

3

git stash pop

꺼내서 이어서

4

git add login.md
git commit -m "..."

5

git push origin main

팀원이 먼저 push했고 나는 고치던 중이면, stash, pull, pop 순서로 받고 나서 커밋해요. 오늘 팀 실습에서 그대로 쓰는 순서예요. 1번부터 3번이 stash, pull, pop이고, 4번과 5번은 늘 하던 add, commit, push예요. 고치던 걸 먼저 커밋하고 pull해도 돼요. 그러면 03에서 본 merge 커밋이 하나 생겨요. stash를 쓰면 팀원 커밋 위에 내 커밋이 올라가서 git log가 한 줄로 이어져요. 커밋할 만큼 끝났으면 커밋, 덜 끝났으면 stash라고 기억해요.
