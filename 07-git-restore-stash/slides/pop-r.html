팀에서 쓰기 · 충돌 풀기

03처럼 풀고, 서랍을 비워요

1

파일을 고쳐요

표시 줄 세 개를 지우고
남길 내용으로

2

git add login.md

다 풀었다고 알려요

3

git stash drop

남아 있던 서랍을 비워요

4

git commit -m "..."
git push origin main

늘 하던 대로

$ cat login.md

# 로그인 페이지

아이디

비밀번호

로그인 버튼

비밀번호 재설정 (이메일)

$ git add login.md

$ git stash drop

Dropped refs/stash@{0} (30ebc16b62d989d22d6cf5dc856d28b138dee3ba)

$ git stash list

$ git commit -m "feat: 비밀번호 재설정에 이메일 안내 추가"

[main dd746b3] feat: 비밀번호 재설정에 이메일 안내 추가

$ git push origin main

365260f..dd746b3 main -> main

푸는 법은 03과 같아요. 표시 줄 세 개를 지우고 남길 내용으로 고친 뒤 git add해요. 여기서는 둘을 합쳐 비밀번호 재설정 (이메일)로 했어요. 그다음이 stash에만 있는 단계예요. 충돌 때문에 서랍에 남은 걸 git stash drop으로 지워요. drop은 꺼내지 않고 버리는 명령이라 이미 파일에 반영한 뒤에만 써요. git stash list에 아무것도 안 나오면 서랍이 빈 거예요. push 출력의 첫 줄 To https://github.com/kim/hello-git.git은 화면 때문에 뺐어요.
