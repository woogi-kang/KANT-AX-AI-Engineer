실습 2 · restore 두 가지

--staged가 붙으면 대기실만 바꿔요

git restore 파일

③ → ①

①의 고친 내용을 버려요

되찾을 수 없어요

git restore --staged 파일

② → ①

②에서 ①로 내려요

고친 내용은 그대로예요

$ echo "아이디 저장" >> login.md

$ git add login.md

$ git restore --staged login.md

$ git diff

--staged를 빼면
이 줄까지 사라져요

--staged가 붙으면 대기실만 고치고, 붙지 않으면 작업 폴더의 파일을 덮어써요. 두 명령은 이름이 비슷해서 헷갈려요. 아래 터미널은 login.md를 add한 뒤 --staged로 내린 장면이에요. git diff에 아이디 저장이 그대로 나와요. 다시 올리려면 git add만 치면 돼요. 확인한 뒤 실습에서는 git restore login.md로 이 줄을 버리고 넘어가요.
