$ echo "아이디 저장" >> login.md

$ git add login.md

$ git restore --staged login.md

$ git diff

--staged를 빼면 이 줄까지 사라져요.

두 명령은 이름이 비슷해서 헷갈려요. --staged가 붙으면 대기실만 고치고 작업 폴더는 건드리지 않아요. 붙지 않으면 작업 폴더의 파일을 덮어써요. 아래 터미널은 login.md를 add한 뒤 --staged로 내린 장면이에요. git diff에 아이디 저장이 그대로 나와요. 다시 올리려면 git add만 치면 돼요. 확인한 뒤 실습에서는 git restore login.md로 이 줄을 버리고 넘어가요.
