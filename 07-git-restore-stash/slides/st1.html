$ git stash

Saved working directory and index state WIP on main: 15d92cb feat: 로그인 버튼 추가

$ git status

On branch main

nothing to commit, working tree clean

$ git stash list

stash@{0}: WIP on main: 15d92cb feat: 로그인 버튼 추가

작업 폴더가 마지막 커밋 모습으로 돌아왔어요

git stash는 고치던 내용을 서랍에 넣고, 작업 폴더를 마지막 커밋 모습으로 돌려놓아요. 비밀번호 찾기 줄이 서랍으로 옮겨 갔어요. git status가 깨끗해져서 이제 pull할 수 있어요. git stash list로 서랍 안을 봐요. 서랍은 내 컴퓨터에만 있어서 push해도 GitHub에 올라가지 않아요. stash는 숨겨 둔다는 뜻이에요.
