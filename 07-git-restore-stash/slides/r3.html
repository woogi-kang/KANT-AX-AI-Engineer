③ 커밋 e12ffc2는 그대로예요

git restore 파일이름은 ③ 마지막 커밋의 모습으로 ① 작업 폴더의 파일을 덮어써요. 아무 출력도 없이 끝나요. cat으로 보면 세 줄이 돌아왔어요. git status도 깨끗해요. 커밋 기록은 하나도 바뀌지 않았어요. 정확히는 ② 대기실의 모습으로 돌아가요. 대기실이 비어 있으면 마지막 커밋과 같은 모습이에요.
