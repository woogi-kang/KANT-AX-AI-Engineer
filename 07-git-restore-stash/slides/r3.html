git restore 파일은 ③ 마지막 커밋의 모습을 ① 작업 폴더에 덮어써요. 아무 출력 없이 끝나요. cat으로 보면 세 줄이 돌아왔고, git status도 깨끗해요. 커밋 기록은 하나도 바뀌지 않았어요. 정확히는 ② 대기실의 모습으로 돌아가요. 대기실이 비어 있으면 마지막 커밋과 같은 모습이에요.
