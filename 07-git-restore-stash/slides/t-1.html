막힐 때

이런 메시지가 나오면 이렇게 해요

1

No local changes to save

고친 게 없거나 새 파일만 있어요. 새 파일은 add해야 서랍에 들어가요

git add 파일
git stash

2

stash list에 여러 줄이 있어요

꺼내는 걸 잊었어요. 맨 위 {0}부터 하나씩 꺼내요

git stash pop

3

CONFLICT ... The stash entry is kept

같은 줄을 둘 다 고쳤어요. 20쪽처럼 풀어요

git add 파일
git stash drop

4

error: pathspec 'signup2.md' did not match

파일 이름이 틀렸어요. status로 이름을 확인해요

git status

5

fatal: Need to specify how to reconcile divergent branches.

pull 설정이 없어요. 06에서 한 설정을 한 번 쳐요

git config --global
pull.rebase false

자주 나오는 메시지 다섯 가지와 고치는 명령이에요. 1번은 새로 만든 파일만 있을 때 나요. Git이 아직 모르는 Untracked 파일은 stash에 들어가지 않아서, git add로 올린 뒤 stash해요. 2번은 pop을 잊고 또 stash했을 때예요. 3번은 19쪽과 20쪽의 장면이에요. 4번은 restore에 없는 파일 이름을 적었을 때예요. 파일 이름은 Tab 키로 자동 완성하면 틀리지 않아요. 5번은 pull 설정을 안 한 컴퓨터에서 내 main과 GitHub main이 갈라졌을 때 나요. 06에서 친 git config --global pull.rebase false를 한 번 치면 돼요.
