필요 없는 변경

git restore 파일

되찾을 수 없어요

잠깐 치우기

덜 끝났는데 pull, checkout 해야 할 때

git stash
git stash pop

내 컴퓨터에만 있어요

남기기

커밋할 만큼 끝났을 때

git add 파일
git commit -m "..."

기록에 남아요

pull이나 checkout이 막혔을 때 고르는 법이에요. 고친 게 필요 없으면 restore로 버려요. 덜 끝났으면 stash로 치웠다가 pop으로 꺼내요. 끝났으면 커밋해요. 어느 쪽인지 모르겠으면 stash가 가장 안전해요. 지우지 않고 서랍에 넣어 두니까요.
