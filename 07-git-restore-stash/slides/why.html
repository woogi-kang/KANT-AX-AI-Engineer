들어가기

이럴 때 쓰는 명령이에요

1

파일을 망쳤어요

$ echo "로그인 버튼" > login.md

>> 대신 > 를 쳐서 세 줄이 사라졌어요

git restore

2

엉뚱한 파일까지 올렸어요

$ git add .

개인 메모 memo.md까지 대기실에 올라갔어요

git restore --staged

3

pull이 막혀요

$ git pull origin main

고치던 게 있는데 팀원이 push했대요

git stash

셋 다 아직 커밋하지 않은 변경을 다뤄요.

셋 다 아직 커밋하지 않은 변경을 다루는 장면이에요. 첫째는 01에서 배운 > 와 >> 를 헷갈린 경우예요. > 는 파일을 새로 덮어쓰고, >> 는 끝에 붙여요. 둘째는 git add . 이 폴더 안 바뀐 파일을 모두 올려서 생겨요. 셋째는 오늘 팀 실습에서 가장 많이 막히는 곳이에요. 커밋한 뒤의 되돌리기는 02와 03에서 배운 reset과 revert가 맡아요.
