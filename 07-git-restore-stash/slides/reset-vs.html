02와 03에서 배운 reset은 브랜치 이름표를 뒤로 옮겨서 커밋을 취소해요. restore는 커밋을 건드리지 않고 파일만 바꿔요. 그래서 커밋하기 전에는 restore, 커밋한 뒤에는 reset이나 revert를 써요. 옛날 자료에는 git reset HEAD 파일이름으로 add를 취소하는 법이 나와요. git restore --staged와 같은 일을 해요. 수업에서는 status가 알려 주는 restore --staged를 써요.
