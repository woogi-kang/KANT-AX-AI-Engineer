stash@{0}: WIP on main: 15d92cb feat: 로그인 버튼 추가

서랍 번호

0이 가장 최근

작업 중

Work In Progress

넣은 브랜치

어디서 넣었나

그때 마지막 커밋

이 커밋 위에서 고치던 것

$ git stash

$ git stash list

stash@{0}: WIP on main: dd746b3 feat: 비밀번호 재설정에 이메일 안내 추가

stash@{1}: WIP on main: dd746b3 feat: 비밀번호 재설정에 이메일 안내 추가

또 넣으면 새 것이 {0}, 예전 것은 {1}로 밀려요. pop은 맨 위 {0}부터 꺼내요.

stash list 한 줄은 서랍 번호, 작업 중 표시, 넣은 브랜치, 그때의 마지막 커밋 네 부분이에요. 맨 앞 stash@{0}이 서랍 번호예요. WIP는 Work In Progress, 작업 중이라는 뜻이에요. 아래 터미널은 실습을 다 끝낸 뒤 stash를 두 번 한 모습이에요. 새로 넣은 게 늘 0번이에요. 여러 개가 쌓이면 무엇이 무엇인지 헷갈리니, 넣으면 바로 꺼내는 습관을 들여요.
