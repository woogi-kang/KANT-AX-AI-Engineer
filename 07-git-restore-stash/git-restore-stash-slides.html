pop은 맨 위 {0}부터 꺼내요. 서랍엔 한 번에 하나만 두는 게 편해요.

stash list 한 줄은 네 부분이에요. 맨 앞 stash@{0}이 서랍 번호예요. WIP는 Work In Progress, 작업 중이라는 뜻이에요. 그 뒤로 어느 브랜치에서 넣었는지, 그때 마지막 커밋이 무엇이었는지 나와요. 아래 터미널은 실습을 다 끝낸 뒤 stash를 두 번 한 모습이에요. 새로 넣은 게 늘 0번이에요. 여러 개가 쌓이면 무엇이 무엇인지 헷갈려서 넣으면 바로 꺼내는 습관을 들여요.
