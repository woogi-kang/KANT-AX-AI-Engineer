이미지 (틀)

nginx

받은 뒤로 바뀌지 않아요

web

web2

컨테이너 (붕어빵)

docker run

이미지

틀, 설계도

docker images

컨테이너

틀로 켠 실행 하나

docker ps

24 클래스에서 클래스는 붕어빵 틀, 객체는 붕어빵이라고 했어요. Docker도 같아요. 이미지는 Docker Hub에서 받아 두는 틀이고, 받은 뒤로는 바뀌지 않아요. docker run으로 틀에서 찍어 낸 것이 컨테이너예요. 틀 하나로 붕어빵을 여러 개 찍듯이, nginx 이미지 하나로 컨테이너 web, web2, test를 따로 켤 수 있어요. 받은 이미지 목록은 docker images, 컨테이너 목록은 docker ps로 봐요.
