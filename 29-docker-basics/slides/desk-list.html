버튼과 명령이 하는 일이 같아요.

수업에서는 터미널 명령으로 하고, 결과는 이 화면으로 확인해요.

Containers 화면에는 컨테이너마다 이름, 이미지, 상태, 포트가 한 줄씩 나와요. 초록 점은 켜짐, 회색 점은 꺼짐이에요. 줄 끝 버튼은 4파트에서 칠 명령과 같은 일을 해요. Stop은 docker stop, Start는 docker start, Delete는 docker rm이에요. 05에서 Git Graph는 결과를 그림으로 확인할 때만 썼죠. Docker Desktop도 같아요. 명령은 터미널에서 치고 결과는 이 화면으로 확인해요. 실제 화면은 버튼이 아이콘으로 나와요. Docker Desktop 화면은 메뉴 위치만 보이게 단순하게 그렸어요. 버전마다 메뉴 이름과 순서가 조금 달라요.
