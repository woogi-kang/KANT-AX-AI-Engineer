정리

한 장 요약

확인

docker --version

설치된 버전

docker run hello-world

설치 확인

이미지 (틀)

docker pull 이름:태그

Hub에서 받기

docker images

받은 이미지 목록

docker rmi 이름

이미지 지우기

컨테이너 (붕어빵)

docker run -d --name 이름 -p 8080:80 이미지

새로 만들어 뒤에서 켜기

docker ps / docker ps -a

켜진 것 / 전부

docker stop 이름 / docker start 이름

끄기 / 다시 켜기

docker rm 이름

지우기 (끈 다음에)

docker logs 이름

남긴 기록 보기

docker run -it --name 이름 이미지 bash

안에 들어가기 (exit로 나오기)

이미지는 Docker Official Image 마크부터 골라요. 명령은 터미널, 확인은 Docker Desktop이에요.

오늘 쓴 명령을 세 묶음으로 모았어요. 설치 확인 두 개, 이미지 세 개, 컨테이너 여섯 줄이에요. 이미지는 Docker Hub에서 Docker Official Image 마크가 붙은 것부터 골라요. 명령은 터미널에서 치고, 결과는 Docker Desktop 화면으로 확인해요. 실습이 끝나면 docker ps -a와 docker images로 남은 것을 확인하고 rm, rmi로 정리해요. 다음 챕터 30에서는 볼륨과 Dockerfile을 배워요.
