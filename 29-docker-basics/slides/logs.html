4. 컨테이너 켜고 끄기

docker logs로 컨테이너가 남긴 기록을 봐요

~ $ docker logs web

/docker-entrypoint.sh: /docker-entrypoint.d/ is not empty, will attempt to perform configuration

…

172.17.0.1 - - [12/Nov/2026:00:33:35 +0000] "GET / HTTP/1.1" 200 896 "-" "curl/8.5.0" "-"

172.17.0.1 - - [12/Nov/2026:00:33:35 +0000] "GET / HTTP/1.1" 200 896 "-" "curl/8.5.0" "-"

localhost:8080에 4번 들어온 기록이에요.

GET /는 첫 화면을 달라는 요청, 200은 잘 보냈다는 뜻이에요. Docker Desktop에서 컨테이너 이름을 누르면 같은 기록이 보여요.

컨테이너는 뒤에서 켜져 있어서 무슨 일이 있었는지 안 보여요. docker logs web은 web 컨테이너가 지금까지 찍은 글을 보여 줘요. 위쪽은 켜질 때 준비 과정이고, 아래 파란 줄은 localhost:8080에 들어올 때마다 nginx가 남긴 기록이에요. GET /는 첫 화면을 달라는 요청, 200은 잘 보냈다는 뜻이에요. 서버가 이상하면 제일 먼저 logs를 봐요. 앞쪽 172.17.0.1은 Docker 안에서 본 내 컴퓨터 주소예요. 출력은 가운데를 …로 줄였어요. 이 출력은 curl로 들어갔을 때라 끝에 curl이 보여요. 브라우저로 들어가면 그 자리에 브라우저 이름이 나와요. 출력은 tools/demo.sh로 Docker 29.9.2를 실제로 실행한 결과예요.
