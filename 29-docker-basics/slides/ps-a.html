4. 컨테이너 켜고 끄기

docker ps -a에는 꺼진 컨테이너도 남아 있어요

~ $ docker ps

CONTAINER ID   IMAGE     COMMAND   CREATED   STATUS    PORTS     NAMES

 

~ $ docker ps -a

CONTAINER ID   IMAGE         COMMAND                  CREATED         STATUS                              PORTS     NAMES

a669a15ddb87   nginx         "/docker-entrypoint.…"   3 seconds ago   Exited (0) Less than a second ago             exciting_mendeleev

ae0d403e2768   hello-world   "/hello"                 6 seconds ago   Exited (0) 6 seconds ago                      flamboyant_thompson

켜진 컨테이너만: 없어요

이름을 안 주면 Docker가 지어 줘요

exciting_mendeleev처럼 형용사와 과학자 이름을 섞어요. 다음 장에서 이름을 직접 붙여요.

Exited는 꺼졌다는 뜻

꺼져도 지우기 전까지 목록에 남아요. Docker Desktop Containers 화면도 같아요.

docker ps는 지금 켜져 있는 컨테이너 목록이에요. 방금 nginx를 Ctrl+C로 멈췄으니 아무것도 없어요. docker ps -a의 a는 all, 꺼진 것까지 전부라는 뜻이에요. hello-world와 nginx 컨테이너가 Exited 상태로 남아 있어요. 컨테이너는 꺼져도 지우기 전까지 남아요. NAMES 칸을 보면 우리가 이름을 준 적이 없는데 이름이 있어요. 이름을 안 주면 Docker가 형용사와 과학자 이름을 섞어서 지어 줘요. 이름은 실행할 때마다 달라요. 출력은 tools/demo.sh로 Docker 29.9.2를 실제로 실행한 결과예요.
