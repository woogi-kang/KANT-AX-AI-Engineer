4. 컨테이너 켜고 끄기

-d로 뒤에서 켜고, --name으로 이름을 붙여요

docker run -d --name web nginx

뒤에서 켜기

이름 붙이기

이미지

~ $ docker run -d --name web nginx

b4a5370848e46a4d81e6fee1eab39198bc963385635943397347efcf4d87cd13

~ $ docker ps

CONTAINER ID   IMAGE     COMMAND                  CREATED                  STATUS                  PORTS     NAMES

b4a5370848e4   nginx     "/docker-entrypoint.…"   Less than a second ago   Up Less than a second   80/tcp    web

컨테이너 ID, 바로 프롬프트가 돌아와요

Up은 켜져 있다는 뜻이에요. 이제 이름 web으로 부를 수 있어요.

서버를 켤 때마다 터미널이 붙잡히면 불편해요. -d는 detach, 뒤에서 켜라는 옵션이에요. 켜자마자 긴 컨테이너 ID 한 줄만 찍고 프롬프트가 돌아와요. --name web은 이 컨테이너 이름을 web으로 정해요. 그다음부터 stop, start, rm, logs에 이 이름을 써요. 이미지 이름은 항상 맨 뒤에 둬요. docker ps의 STATUS가 Up이면 켜져 있는 거예요. 출력은 tools/demo.sh로 Docker 29.9.2를 실제로 실행한 결과예요.
