설치 성공

Windows는 Git Bash, Mac은 터미널에서 쳐요. 버전 숫자는 달라도 괜찮아요.

설치가 끝나면 터미널에서 두 명령으로 확인해요. docker --version은 설치된 Docker 버전을 보여 줘요. 숫자는 설치한 날에 따라 달라도 괜찮아요. docker run hello-world는 확인용 이미지를 받아서 컨테이너로 한 번 켜 봐요. 처음에는 내 컴퓨터에 이미지가 없어서 Unable to find image가 나오고 Hub에서 받아 와요. Hello from Docker!가 보이면 설치 성공이에요. 아래쪽 설명 문장은 …로 줄였어요. 출력은 tools/demo.sh로 Docker 29.9.2를 실제로 실행한 결과예요.
