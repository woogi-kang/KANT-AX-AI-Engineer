다시 켜졌어요

stop은 끄기만 해요. 컨테이너는 목록에 남아서 start로 다시 켤 수 있어요.

docker stop web은 web 컨테이너를 꺼요. 성공하면 이름을 한 번 찍어요. docker ps에는 아무것도 없고, docker ps -a에는 web이 Exited로 남아 있어요. 끄기만 하고 지우지는 않았으니까요. docker start web으로 같은 컨테이너를 다시 켜요. 새로 만드는 게 아니라 꺼 둔 것을 다시 켜는 거라 컨테이너 ID가 그대로예요. 출력은 tools/demo.sh로 Docker 29.9.2를 실제로 실행한 결과예요.
