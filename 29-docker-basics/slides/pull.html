받아 둔 이미지

docker pull 뒤에 이미지 이름을 적으면 Docker Hub에서 받아요. 태그를 안 써서 Using default tag: latest가 나왔어요. 이미지는 여러 층으로 나뉘어 있어서 층마다 받는 줄이 나와요. 가운데 받는 줄은 …로 줄였어요. docker images는 내 컴퓨터에 받아 둔 이미지 목록이에요. 앞에서 받은 hello-world와 방금 받은 nginx가 보여요. DISK USAGE가 내 컴퓨터에서 차지하는 크기예요. Docker Desktop의 Images 화면에도 같은 목록이 나와요. 출력은 tools/demo.sh로 Docker 29.9.2를 실제로 실행한 결과예요.
