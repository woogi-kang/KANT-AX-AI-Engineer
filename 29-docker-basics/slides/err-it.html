5. 자주 나는 오류

pull access denied가 나오면 이미지 이름 자리를 봐요

~ $ docker run -it my-server ubuntu:24.04 bash

Unable to find image 'my-server:latest' locally

docker: Error response from daemon: pull access denied for my-server, repository does not exist or

may require 'docker login'

뜻

--name을 빼서 Docker가 my-server를 이미지 이름으로 읽었어요.

고치기

~ $ docker run -it --name my-server ubuntu:24.04 bash

옵션 다음 첫 단어가 이미지 이름이에요. 이미지 이름 오타도 같은 오류가 나요.

docker run은 옵션 다음에 나오는 첫 단어를 이미지 이름으로 읽어요. --name을 빼먹으면 my-server가 이미지 이름이 돼요. Docker는 내 컴퓨터에서 my-server 이미지를 못 찾고 Docker Hub에서 받으려다가, 그런 저장소가 없다고 pull access denied를 내요. 뒤의 ubuntu:24.04는 컨테이너 안에서 켤 명령으로 넘어가요. --name my-server처럼 옵션 이름을 붙여서 다시 쳐요. ngnix처럼 이미지 이름에 오타가 나도 같은 오류가 나요. 메시지의 docker login은 비공개 이미지를 받을 때 쓰는 로그인인데, 공식 이미지에는 필요 없어요. 출력은 tools/demo.sh로 Docker 29.9.2를 실제로 실행한 결과예요.
