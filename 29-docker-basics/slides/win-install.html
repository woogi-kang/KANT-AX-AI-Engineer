2. 설치하기

Windows는 WSL을 켠 뒤 Docker Desktop을 설치해요

1

관리자 PowerShell

시작 메뉴에서 PowerShell을 오른쪽 클릭, 관리자 권한으로 실행

PS $ wsl --install

끝나면 컴퓨터를 다시 시작해요

2

Git Bash 또는 PowerShell

winget으로 Docker Desktop 설치

~ $ winget install -e --id Docker.DockerDesktop

설치 창이 뜨면 OK, 끝나면 Close

3

다시 시작

컴퓨터를 한 번 더 다시 시작해요

시작 메뉴에서 Docker Desktop을 열어요

Windows 설치는 세 단계예요. 먼저 시작 메뉴에서 PowerShell을 오른쪽 클릭해 관리자 권한으로 열고 wsl --install을 쳐요. WSL과 기본 리눅스가 설치되고, 끝나면 컴퓨터를 다시 시작해요. 다음으로 winget install -e --id Docker.DockerDesktop을 쳐요. 09에서 uv를 winget으로 설치한 것과 같은 방법이에요. 설치 창이 뜨면 OK를 누르고 끝나면 Close를 눌러요. docker.com에서 Download for Windows 버튼으로 설치 파일을 받아도 같아요. 한 번 더 다시 시작한 뒤 시작 메뉴에서 Docker Desktop을 열어요. docker 명령은 01부터 써 온 Git Bash에서 쳐요. Windows 명령의 출력은 이 환경에서 실행할 수 없어서 옮기지 않았어요.
