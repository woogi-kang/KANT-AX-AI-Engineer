4. 컨테이너 켜고 끄기

docker restart는 끄고 켜기를 한 번에 해요

docker restart web = docker stop web + docker start web

~ $ docker ps

CONTAINER ID   IMAGE     COMMAND                  CREATED          STATUS          PORTS     NAMES

315ddf61831a   nginx     "/docker-entrypoint.…"   20 seconds ago   Up 20 seconds   80/tcp    web

~ $ docker restart web

web

~ $ docker ps

CONTAINER ID   IMAGE     COMMAND                  CREATED          STATUS                  PORTS     NAMES

315ddf61831a   nginx     "/docker-entrypoint.…"   21 seconds ago   Up Less than a second   80/tcp    web

끄고 다시 켰어요

STATUS는 처음부터 다시 세고, CREATED는 그대로예요. 새 컨테이너가 아니라 같은 컨테이너를 다시 켠 거예요.

서버가 이상하게 굴거나 설정을 바꿨을 때는 껐다가 다시 켜요. docker stop과 docker start를 차례로 쳐도 되지만, docker restart 한 번이면 둘을 이어서 해 줘요. 다시 켠 뒤 docker ps를 보면 STATUS는 Up Less than a second로 처음부터 다시 세요. CREATED는 그대로예요. 컨테이너를 새로 만든 게 아니라 같은 컨테이너를 다시 켠 거라서 이름도, 남긴 기록도 그대로 있어요. Docker Desktop 앱 자체를 다시 켜는 건 위쪽 고래 아이콘 메뉴의 Restart예요. 이 장은 컨테이너를 다시 켜는 이야기예요. 이 출력은 따로 실행해서 컨테이너 ID가 앞 장과 달라요. 출력은 tools/demo.sh로 Docker 29.9.2를 실제로 실행한 결과예요.
