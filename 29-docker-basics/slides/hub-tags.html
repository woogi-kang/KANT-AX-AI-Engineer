3. Docker Desktop과 Docker Hub

이미지 이름 뒤 콜론 다음이 태그예요. 태그로 버전을 골라요

python:3.12-slim

이미지 이름

태그 (버전)

nginx

태그를 안 쓰면 latest (최신)

python:3.12

파이썬 3.12

python:3.12-slim

필요 없는 것을 뺀 작은 버전

이미지 이름 뒤에 콜론을 찍고 태그를 붙여요. 태그는 버전 이름이에요. python:3.12는 파이썬 3.12가 든 이미지, python:3.12-slim은 그중 필요 없는 것을 빼서 작게 만든 버전이에요. 태그를 안 쓰고 nginx라고만 치면 latest, 가장 최신 태그를 받아요. 오른쪽은 실제 python 이미지의 Tags 탭에서 3.12-slim을 검색한 화면이에요. 태그마다 오른쪽에 docker pull 명령이 적혀 있어서 그대로 복사해 쓰면 돼요.
