3. Docker Desktop과 Docker Hub

hub.docker.com에서 검색하면 같은 이름이 수십만 개 나와요

이름만 보고 고르지 않고, 이름 아래 마크를 봐요.

브라우저에서 hub.docker.com에 들어가 위쪽 검색 칸에 nginx를 쳐 봤어요. 결과가 29만 개가 넘어요. 누구나 이미지를 올릴 수 있어서 이름이 비슷한 이미지가 아주 많아요. 그래서 이름만 보고 고르지 않고, 이름 아래 붙은 마크를 봐요. 가운데 nginx 카드에 Docker Official Image 마크가 있어요. 화면은 실제 Docker Hub 검색 결과를 찍은 거예요. 로고 그림은 찍은 환경에서 안 불러와져서 빈칸이에요.
