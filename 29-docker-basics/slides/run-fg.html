4. 컨테이너 켜고 끄기

docker run nginx는 터미널을 붙잡고 끝나지 않아요

~ $ docker run nginx

/docker-entrypoint.sh: /docker-entrypoint.d/ is not empty, will attempt to perform configuration

/docker-entrypoint.sh: Looking for shell scripts in /docker-entrypoint.d/

/docker-entrypoint.sh: Launching /docker-entrypoint.d/10-listen-on-ipv6-by-default.sh

…

2026/11/12 00:33:29 [notice] 1#1: nginx/1.31.8

2026/11/12 00:33:29 [notice] 1#1: start worker processes

^C   (Ctrl+C)

2026/11/12 00:33:32 [notice] 1#1: signal 2 (SIGINT) received, exiting

…

서버라서 계속 켜져 있어요

Ctrl+C를 받고 꺼져요

Ctrl+C

hello-world는 글을 찍고 바로 끝났지만,
nginx는 웹 서버라서 멈출 때까지 켜져 있어요.

이제 nginx로 컨테이너를 켜 봐요. nginx는 웹 페이지를 보내 주는 서버 프로그램이에요. docker run nginx를 치면 nginx가 켜지면서 준비 과정 글을 쭉 찍어요. 그런데 프롬프트가 돌아오지 않아요. hello-world는 글을 찍고 바로 끝났지만, 서버는 요청을 기다리느라 멈출 때까지 계속 켜져 있어요. 터미널을 쓰려면 Ctrl+C로 멈춰요. 아래 SIGINT 줄이 Ctrl+C를 받았다는 뜻이에요. 출력은 가운데를 …로 줄였어요. 실제 화면에서는 ^C 대신 커서만 보일 수 있어요. 출력은 tools/demo.sh로 Docker 29.9.2를 실제로 실행한 결과예요.
