4. 컨테이너 켜고 끄기

켜져 있는 nginx에 브라우저로 들어가면 안 열려요

localhost:8080

사이트에 연결할 수 없음

localhost에서 연결을 거부했습니다.

ERR_CONNECTION_REFUSED

~ $ curl http://localhost:8080

curl: (7) Failed to connect to localhost port 8080 after 0 ms: Couldn't connect to server

컨테이너 web

nginx :80

닫힌 상자라서 밖에서 들어갈 문이 없어요.

web 컨테이너 안에서 nginx가 켜져 있어요. 그런데 브라우저 주소창에 localhost:8080을 치면 사이트에 연결할 수 없다고 나와요. 터미널에서 curl로 주소에 들어가 봐도 연결이 안 된다고 나와요. 컨테이너는 내 컴퓨터와 분리된 닫힌 상자라서, 안에서 nginx가 80번 문으로 기다려도 밖에서 들어갈 길이 없어요. 다음 장에서 길을 이어요. curl은 주소의 내용을 터미널로 받아 보는 명령이에요. 브라우저 화면은 단순하게 그렸어요.
