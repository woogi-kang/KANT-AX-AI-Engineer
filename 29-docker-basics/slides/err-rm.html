5. 자주 나는 오류

켜진 컨테이너는 rm으로 바로 못 지워요

~ $ docker rm web

Error response from daemon: cannot remove container "web": container is running: stop the container

before removing or force remove

뜻

web이 아직 켜져 있어요. 끄고 나서 지워요.

고치기

~ $ docker stop web

web

~ $ docker rm web

web

지운 컨테이너는 되살릴 수 없어요. 이미지는 남아 있어서 docker run으로 새로 켜면 돼요.

켜진 컨테이너를 docker rm으로 지우려고 하면 container is running이 나와요. 실수로 돌아가는 서버를 지우지 않게 막아 주는 거예요. 메시지 끝의 force remove는 -f 옵션으로 강제로 지우는 방법인데, 수업에서는 docker stop으로 끄고 docker rm으로 지우는 두 단계로 해요. 지운 컨테이너는 되살릴 수 없지만 이미지는 남아 있어서 docker run으로 새로 켜면 돼요. 출력은 tools/demo.sh로 Docker 29.9.2를 실제로 실행한 결과예요.
