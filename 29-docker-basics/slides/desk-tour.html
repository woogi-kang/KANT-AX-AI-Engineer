Engine running이어야 명령이 돼요

Docker Desktop 왼쪽에 메뉴가 여러 개 있어요. 오늘은 두 개만 기억해요. Containers는 내 컴퓨터의 컨테이너 목록이고 터미널의 docker ps -a와 같아요. Images는 받아 둔 이미지 목록이고 docker images와 같아요. Volumes는 30에서 써요. 왼쪽 아래 엔진 상태가 Engine running이어야 터미널 명령도 돼요. Docker Desktop 화면은 메뉴 위치만 보이게 단순하게 그렸어요. 버전마다 메뉴 이름과 순서가 조금 달라요.
