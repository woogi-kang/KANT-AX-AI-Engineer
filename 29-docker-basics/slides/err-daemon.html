5. 자주 나는 오류

failed to connect to the docker API가 나오면 Docker Desktop을 켜요

~ $ docker ps

failed to connect to the docker API at unix:///Users/kim/.docker/run/docker.sock; check if the path

is correct and if the daemon is running: dial unix /Users/kim/.docker/run/docker.sock: connect: no

such file or directory

뜻

Docker Desktop(엔진)이 꺼져 있어서 명령을 받을 곳이 없어요.

고치기

Docker Desktop 열기

왼쪽 아래 Engine running 기다리기

~ $ docker ps

컴퓨터를 다시 켠 뒤에 자주 나요. 엔진이 켜지는 동안 1~2분 기다려요.

제일 자주 만나는 오류예요. docker 명령은 터미널이 Docker Desktop의 엔진에 일을 시키는 구조라서, Docker Desktop이 꺼져 있으면 일을 받을 곳이 없어요. Docker Desktop을 열고 왼쪽 아래가 Engine running이 될 때까지 기다린 뒤 다시 쳐요. 메시지 가운데 경로는 컴퓨터마다 달라요. 화면은 Mac 경로예요. Windows에서는 npipe로 시작하는 경로가 나와요. Docker 버전에 따라 Cannot connect to the Docker daemon으로 시작하는 문장으로 나오기도 해요. 같은 뜻이에요. 출력은 Mac과 같은 경로로 실제 docker를 실행해서 받았어요.
