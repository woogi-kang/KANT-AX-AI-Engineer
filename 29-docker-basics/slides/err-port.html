5. 자주 나는 오류

port is already allocated가 나오면 내 컴퓨터 문이 이미 쓰이고 있어요

~ $ docker run -d --name web2 -p 8080:80 nginx

f637c2dda017f745292be9af113c3e567b511e214ff9de54e4fb5e2bfae5515c

docker: Error response from daemon: failed to set up container networking: driver failed programming

external connectivity on endpoint web2

(60b6f6d0dcc37d67c621705ad7a0fcfbcf22df285eee9b407bbc13b7cbab6784): Bind for 0.0.0.0:8080 failed:

port is already allocated

 

Run 'docker run --help' for more information

뜻

8080번 문은 web이 쓰고 있어요. 한 문에는 하나만 이을 수 있어요.

고치기

~ $ docker rm web2

~ $ docker run -d --name web2 -p 8081:80 nginx

실패해도 web2가 Created 상태로 남아서 먼저 지워요. 그다음 다른 문 번호로 켜요.

web이 내 컴퓨터 8080번 문을 쓰고 있는데 web2도 8080에 이으려고 하면 port is already allocated가 나와요. 내 컴퓨터의 한 문에는 컨테이너 하나만 이을 수 있어요. 첫 줄의 긴 ID를 보면 컨테이너는 만들어졌어요. docker ps -a로 보면 web2가 Created 상태로 남아 있어요. 그래서 docker rm web2로 지우고 8081처럼 다른 문 번호로 다시 켜요. Docker가 아닌 다른 프로그램이 8080을 쓰고 있어도 같은 오류가 나요. 출력은 tools/demo.sh로 Docker 29.9.2를 실제로 실행한 결과예요.
