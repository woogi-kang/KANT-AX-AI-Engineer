5. 자주 나는 오류

Conflict. The container name이 나오면 이름이 겹친 거예요

~ $ docker run -d --name web -p 8080:80 nginx

docker: Error response from daemon: Conflict. The container name "/web" is already in use by

container "ba5cd077165e1aac0f8ca6822ed77da447719a626a1aca498dbb8fa2cec90ae5". You have to remove (or

rename) that container to be able to reuse that name.

 

Run 'docker run --help' for more information

뜻

web이라는 컨테이너가 이미 있어요. 꺼져 있어도 이름은 그대로 차지해요.

고치기

~ $ docker ps -a

web이 있는지 보고

~ $ docker stop web

~ $ docker rm web

지우기 싫으면 --name web3처럼 다른 이름으로 켜요.

같은 이름으로 컨테이너를 또 만들면 Conflict가 나요. web이 켜져 있든 꺼져 있든 docker ps -a 목록에 있으면 이름을 차지하고 있어요. docker ps -a로 확인하고, 필요 없으면 stop과 rm으로 지운 뒤 다시 켜요. 앞의 컨테이너를 남겨 두고 싶으면 다른 이름을 주면 돼요. 메시지 가운데 긴 숫자는 이미 있는 컨테이너의 ID예요. 출력은 tools/demo.sh로 Docker 29.9.2를 실제로 실행한 결과예요.
