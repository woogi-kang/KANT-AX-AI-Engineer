brew 없이 설치할 때

앞 장 버튼으로 Docker.dmg를 받아 열고, Docker 아이콘을 Applications 폴더로 끌어 놓아요.

Mac은 09에서 uv를 설치한 것처럼 brew로 설치해요. brew install --cask docker-desktop을 쳐요. --cask는 터미널 명령이 아니라 창이 있는 앱을 설치한다는 뜻이에요. 설치가 끝나면 Finder의 Applications 폴더에서 Docker를 두 번 눌러 열어요. brew를 쓰지 않으면 앞 장의 버튼으로 Docker.dmg를 받고, 열린 창에서 Docker 아이콘을 Applications 폴더로 끌어 놓아요. brew 설치 출력은 이 환경에서 실행할 수 없어서 옮기지 않았어요.
