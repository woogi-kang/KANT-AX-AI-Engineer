4. 컨테이너 켜고 끄기

컨테이너는 켜짐과 꺼짐을 오가다가 rm으로 사라져요

이미지 nginx

켜짐 Up

꺼짐 Exited

없어짐

docker run

docker stop

docker start

docker rm

run은 새 컨테이너를 만들어서 켜요.
start는 꺼 둔 컨테이너를 다시 켜요.

rm은 꺼진 컨테이너만 지워요.
이미지를 지우는 명령은 docker rmi예요.

지금까지 본 명령을 한 그림에 모았어요. docker run은 이미지로 새 컨테이너를 만들어서 켜요. docker stop은 끄고, docker start는 꺼 둔 같은 컨테이너를 다시 켜요. docker rm은 꺼진 컨테이너를 지워요. 켜진 컨테이너는 바로 못 지우고 먼저 stop해야 해요. 5파트 오류에서 다시 봐요. 이미지는 컨테이너와 따로 남아 있고, 이미지까지 지울 때는 docker rmi를 써요. rmi의 i는 image예요.
