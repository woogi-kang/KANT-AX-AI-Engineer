사용 안 함이면

컴퓨터를 켤 때 BIOS(UEFI) 설정에서 가상화를 켜야 해요. 메뉴가 회사마다 달라서 강사와 같이 해요.

Docker Desktop은 Windows 안에 작은 리눅스를 켜요. 그러려면 CPU의 가상화 기능이 켜져 있어야 해요. Ctrl+Shift+Esc로 작업 관리자를 열고 왼쪽 성능, 위의 CPU를 눌러요. 오른쪽 아래 가상화 줄이 사용이면 준비된 거예요. 사용 안 함이면 컴퓨터를 켤 때 BIOS(UEFI) 설정 화면에서 켜야 해요. Intel은 VT-x, AMD는 SVM이라는 이름이 많아요. 메뉴가 제조사마다 달라서 수업 시간에 같이 봐요. Windows 10은 22H2, Windows 11은 23H2 이상이고 메모리는 8GB 이상이어야 해요. 작업 관리자는 실제 화면이 아니라 위치만 보이게 그렸어요.
