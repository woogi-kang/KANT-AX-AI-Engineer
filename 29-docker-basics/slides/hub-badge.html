3. Docker Desktop과 Docker Hub

Docker Official Image 마크가 붙은 이미지부터 골라요

Docker Official Image

Docker가 직접 관리하는 기본 이미지

nginx, python, ubuntu

Verified Publisher

회사가 직접 올린 이미지

nginx/nginx-ingress (NGINX Inc.)

Sponsored OSS

Docker가 후원하는 오픈소스 프로젝트

Docker Hardened Image

보안을 더 다듬은 이미지

마크 없음

누구나 올린 이미지, 안에 무엇이 있는지 몰라요

nginx

공식 이미지는 이름에 / 가 없어요.

회사/이름

다른 이미지는 앞에 올린 곳이 붙어요.

Docker Hub는 믿을 수 있는 이미지에 마크를 붙여요. 수업에서는 Docker Official Image부터 골라요. Docker가 직접 관리하고 보안 업데이트를 꾸준히 해요. nginx, python, ubuntu가 여기에 들어요. Verified Publisher는 그 소프트웨어를 만든 회사가 직접 올린 이미지예요. Sponsored OSS는 Docker가 후원하는 오픈소스 프로젝트, Docker Hardened Image는 보안을 더 다듬은 이미지예요. 마크가 없으면 누구나 올린 이미지라서 안에 무엇이 있는지 알 수 없어요. 연습할 때는 받지 않아요. 이름으로도 구별돼요. 공식 이미지는 nginx처럼 이름만 있고, 나머지는 nginx/nginx-ingress처럼 앞에 올린 곳이 붙어요. 마크 이름은 Docker Hub 검색 화면 왼쪽 Trusted content 칸에 있는 그대로 옮겼어요.
