내 컴퓨터

~ $ docker pull nginx

~ $ docker run nginx

오늘 쓰는 세 곳을 그림으로 봐요. 오른쪽 Docker Hub는 이미지를 모아 둔 인터넷 저장소예요. 코드를 GitHub에 모아 두듯이 이미지는 Docker Hub에 모여 있어요. 왼쪽 내 컴퓨터에는 Docker Desktop을 설치해요. 터미널에서 docker pull을 치면 Docker Desktop이 Hub에서 이미지를 받아 와요. docker run을 치면 받은 이미지로 컨테이너를 켜요. 같은 이미지로 컨테이너를 여러 개 켤 수도 있어요.
