Windows와 Mac 모두 Docker Desktop을 처음 열면 약관 창이 떠요. Accept를 누르면 Docker Desktop이 켜져요. 계정 로그인이나 설문 화면이 나오면 건너뛰어도 돼요. 오늘 받는 공식 이미지는 로그인 없이 받을 수 있어요. 창 왼쪽 아래가 Engine running으로 바뀌면 준비된 거예요. 처음에는 작은 리눅스를 켜느라 1~2분 걸리기도 해요. Docker Desktop 창을 닫아도 엔진은 뒤에서 계속 돌아요. Windows는 화면 오른쪽 아래 알림 영역, Mac은 화면 위 메뉴 막대에 고래 아이콘이 보여요. Docker Desktop 화면은 메뉴 위치만 보이게 단순하게 그렸어요. 버전마다 메뉴 이름과 순서가 조금 달라요.
