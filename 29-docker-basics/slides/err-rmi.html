5. 자주 나는 오류

이미지를 쓰는 컨테이너가 남아 있으면 rmi가 안 돼요

~ $ docker rmi nginx

Error response from daemon: conflict: unable to delete nginx:latest (must be forced) - container

a669a15ddb87 is using its referenced image 165ddde8751e

뜻

꺼진 컨테이너라도 이 이미지로 만든 것이 남아 있어요.

고치기

~ $ docker ps -a

nginx로 만든 컨테이너 이름 찾기

~ $ docker rm exciting_mendeleev

~ $ docker rmi nginx

4파트 처음에 Ctrl+C로 멈춘 nginx 컨테이너가 남아 있었어요.

web과 web2를 다 지웠는데도 docker rmi nginx가 안 돼요. 메시지를 보면 a669a15ddb87 컨테이너가 이 이미지를 쓰고 있대요. 4파트 처음에 Ctrl+C로 멈춘 nginx 컨테이너가 꺼진 채로 남아 있었어요. 틀로 찍은 붕어빵이 하나라도 남아 있으면 틀을 버릴 수 없는 셈이에요. docker ps -a로 이름을 찾아 docker rm으로 지운 뒤 rmi를 다시 쳐요. 메시지의 must be forced는 -f로 강제로 지우는 방법인데 수업에서는 쓰지 않아요. 컨테이너 이름은 실행할 때마다 달라요. 출력은 tools/demo.sh로 Docker 29.9.2를 실제로 실행한 결과예요.
