4. 컨테이너 켜고 끄기

-it로 우분투 컨테이너 안에 들어가서 명령을 쳐요

docker run -it --name my-server ubuntu:24.04 bash

키보드로 치고 화면으로 보기

이름 붙이기

이미지:태그

안에서 켤 프로그램

~ $ docker run -it --name my-server ubuntu:24.04 bash

Unable to find image 'ubuntu:24.04' locally

…

root@ab7c906af182:/# cat /etc/os-release | head -2

PRETTY_NAME="Ubuntu 24.04.5 LTS"

NAME="Ubuntu"

root@ab7c906af182:/# whoami

root

root@ab7c906af182:/# exit

exit

root@로 바뀌면 컨테이너 안이에요

exit로 나오면 컨테이너도 꺼져요

내 컴퓨터가 Windows나 Mac이어도 01에서 배운 리눅스 명령을 바로 쳐 볼 수 있어요.

nginx는 뒤에서 켜 두는 서버였어요. 이번에는 컨테이너 안에 들어가서 직접 명령을 쳐 봐요. -it는 -i와 -t를 합친 옵션이에요. -i는 내 키보드 입력을 컨테이너에 보내고, -t는 터미널 화면을 붙여 줘요. --name my-server로 이름을 붙이고, 이미지 ubuntu:24.04 뒤에 안에서 켤 프로그램 bash를 적어요. 순서는 옵션, 이미지, 안에서 켤 프로그램이에요. 프롬프트가 root@ID:/#로 바뀌면 컨테이너 안이에요. 여기는 작은 우분투 리눅스라서 01에서 배운 ls, cd, cat을 그대로 쓸 수 있어요. exit로 나오면 bash가 끝나면서 컨테이너도 꺼져요. docker ps -a에 Exited로 남아요. 켜 둔 컨테이너에 다시 들어가는 docker exec는 다음 챕터 30에서 배워요. 가운데 받는 줄과 ls 출력은 줄였어요. 프롬프트의 ID는 컨테이너마다 달라요. 출력은 tools/demo.sh로 Docker 29.9.2를 실제로 실행한 결과예요.
