kim 컴퓨터에선 되는 코드가 lee 컴퓨터에선 SyntaxError가 나요

main.py

menu = {"latte": 4500}

print(f"라떼: {menu["latte"]}원")

K

kim의 컴퓨터

Python 3.12

라떼: 4500원

L

lee의 컴퓨터

Python 3.11

 File "<string>", line 1

   menu = {"latte": 4500}; print(f"라떼: {menu["latte"]}원")

                                              ^^^^^

SyntaxError: f-string: unmatched '['

같은 코드인데 컴퓨터마다 설치된 파이썬 버전이 달라요.

팀 프로젝트에서 자주 듣는 말이 "제 컴퓨터에선 되는데요"예요. kim은 파이썬 3.12, lee는 3.11을 설치해 두었어요. f-string 중괄호 안에서 같은 큰따옴표를 다시 쓰는 문법은 3.12부터 돼요. 그래서 같은 main.py가 kim 컴퓨터에서는 돌고 lee 컴퓨터에서는 SyntaxError가 나요. 패키지 버전, 운영체제가 달라도 같은 일이 생겨요. 출력은 tools/demo.sh에서 python:3.11, python:3.12 이미지로 실제로 실행한 결과예요. 이 비교는 6파트 실습에서 직접 해 봐요.
