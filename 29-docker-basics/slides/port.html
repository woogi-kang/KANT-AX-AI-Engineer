4. 컨테이너 켜고 끄기

-p 8080:80은 내 컴퓨터 8080번 문을 컨테이너 80번 문에 이어요

docker run -d --name web -p 8080:80 nginx

내 컴퓨터 문

컨테이너 문

내 컴퓨터

8080

컨테이너 web

nginx :80

localhost:8080

PORTS                  NAMES

0.0.0.0:8080->80/tcp   web

-p는 publish, 문을 연다는 옵션이에요. 콜론 왼쪽이 내 컴퓨터의 문 번호, 오른쪽이 컨테이너 안의 문 번호예요. nginx는 컨테이너 안에서 80번 문으로 기다려요. -p 8080:80을 붙여 켜면 내 컴퓨터 8080번으로 들어온 요청이 컨테이너 80번으로 넘어가요. 그래서 브라우저에서 localhost:8080을 열면 Welcome to nginx! 화면이 나와요. docker ps의 PORTS 칸에도 0.0.0.0:8080->80/tcp가 생겼어요. 앞에서 -p 없이 만든 web은 지우고 새로 켰어요. 지우는 과정은 5파트에서 봐요. 브라우저 안 화면은 실제로 localhost:8080을 연 결과예요. docker ps 출력은 PORTS와 NAMES 칸만 남겼어요.
