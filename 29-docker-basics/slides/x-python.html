6. 실습

파이썬을 설치하지 않고 3.11과 3.12를 바로 비교해요

~ $ docker run python:3.11 python -c 'menu = {"latte": 4500}; print(f"라떼: {menu["latte"]}원")'

Unable to find image 'python:3.11' locally

…

 File "<string>", line 1

   menu = {"latte": 4500}; print(f"라떼: {menu["latte"]}원")

                                              ^^^^^

SyntaxError: f-string: unmatched '['

 

~ $ docker run python:3.12 python -c 'menu = {"latte": 4500}; print(f"라떼: {menu["latte"]}원")'

Unable to find image 'python:3.12' locally

…

라떼: 4500원

3.11은 이 문법을 몰라요

3.12는 돼요

~ $ docker images

IMAGE         ID             DISK USAGE   CONTENT SIZE   EXTRA

python:3.11   731670a425de       1.62GB          428MB   U

python:3.12   cad37dd20c7c       1.62GB          430MB   U

1파트의 kim과 lee 문제를 내 컴퓨터 하나에서 다시 봤어요.

이미지가 1GB가 넘어요. 다 쓰면 docker rmi로 지워요.

1파트 첫 장의 문제를 직접 풀어 봐요. 내 컴퓨터에 파이썬 3.11이나 3.12를 따로 설치하지 않아도, Docker Hub의 공식 python 이미지로 두 버전을 바로 켤 수 있어요. docker run 이미지 뒤에 적은 python -c '코드'는 컨테이너 안에서 실행할 명령이에요. 3.11에서는 SyntaxError, 3.12에서는 라떼: 4500원이 나와요. 팀원 모두 같은 이미지를 쓰면 "제 컴퓨터에선 되는데요"가 없어져요. python 이미지는 1GB가 넘으니 다 쓰면 컨테이너를 rm으로 지우고 docker rmi python:3.11 python:3.12로 지워요. 받는 줄은 …로 줄였어요. 따옴표가 많으니 복사 버튼으로 복사해서 붙여 넣어요. 출력은 tools/demo.sh로 Docker 29.9.2를 실제로 실행한 결과예요.
