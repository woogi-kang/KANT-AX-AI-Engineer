1파트 끝에서 Windows와 Mac은 컨테이너를 돌릴 작은 리눅스가 필요하다고 했어요. Windows에서 그 리눅스를 켜는 방법이 두 가지예요. WSL 2는 Windows 안에서 리눅스를 켜는 기능이에요. Windows Home에서도 되고 Docker Desktop이 기본으로 골라요. Hyper-V는 가상 컴퓨터를 켜는 Windows 기능인데 Pro, Enterprise, Education에만 있어요. 수업에서는 WSL 2로 통일해요. 설치 창의 Use WSL 2 instead of Hyper-V 칸이 보이면 켠 채로 두면 돼요.
