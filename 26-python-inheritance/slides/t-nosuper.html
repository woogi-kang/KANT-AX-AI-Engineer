5. 오류와 함정

super().__init__을 빼먹으면 부모 칸이 없어요

[1]

class Animal:

def __init__(self, name):

self.name = name

 

def eat(self):

print(f"{self.name}가 밥을 먹어요")

 

def speak(self):

print(f"{self.name}가 소리를 내요")

 

class Dog(Animal):

def __init__(self, name, breed):

self.breed = breed

 

d = Dog("초코", "푸들")

d.eat()

AttributeError: 'Dog' object has no attribute 'name'

← super().__init__ 줄이 없어요

자식 __init__ 첫 줄에 적어요

✓

super().__init__(name)

자식 클래스에 __init__을 새로 적으면 부모의 __init__은 저절로 불리지 않아요. 3파트의 덮어쓰기와 같아요. Dog의 __init__에서 breed만 붙이고 super().__init__을 빼먹어서, name 칸이 없는 객체가 만들어졌어요. 만들 때는 아무 말이 없다가 eat에서 self.name을 꺼낼 때 AttributeError가 나요. 자식 __init__의 첫 줄에 super().__init__을 적어요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
