5. 오류와 함정

super().__init__을 빼먹으면 부모 칸이 없어요

[1]

class Bread:

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

 

def intro(self):

print(self.flavor, "붕어빵", self.price, "원")

 

class CreamBread(Bread):

def __init__(self, flavor, price, cream):

self.cream = cream

 

c = CreamBread("슈크림", 1200, "많이")

c.intro()

AttributeError: 'CreamBread' object has no attribute 'flavor'

← super().__init__ 줄이 없어요

자식 __init__ 첫 줄에 적어요

✓

super().__init__(flavor, price)

자식 틀에 __init__을 새로 적으면 부모의 __init__은 저절로 불리지 않아요. 3파트의 덮어쓰기와 같아요. 자식 __init__에서 cream만 붙이고 super().__init__을 빼먹어서, 맛과 가격 칸이 없는 붕어빵이 찍혔어요. 찍을 때는 아무 말이 없다가 intro에서 self.flavor를 꺼낼 때 AttributeError가 나요. 자식 __init__의 첫 줄에 super().__init__을 적어요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
