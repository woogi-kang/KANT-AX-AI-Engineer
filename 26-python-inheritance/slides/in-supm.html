class Dog(Animal):

def eat(self):

super().eat()

print(f"{self.name}가 꼬리를 흔들어요")

 

d = Dog("초코")

d.eat()

부모의 __init__ 부르기 (다음 장)

앞 장처럼 메서드를 통째로 다시 적으면 부모 것은 안 쓰여요. 부모의 eat를 그대로 쓰고 한 줄만 더하고 싶을 땐 super().eat()를 써요. super()는 부모 클래스를 가리켜요. 이렇게 하면 밥 먹는 문구는 Animal에만 있어서, Animal을 고치면 Dog도 같이 바뀌어요. 1파트에서 본 두 군데 고치기 문제가 풀려요. 같은 모양으로 __init__도 부를 수 있어요. 다음 장에서 봐요. 출력은 실제로 실행한 결과예요.
