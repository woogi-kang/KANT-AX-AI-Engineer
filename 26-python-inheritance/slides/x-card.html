도장 카드 ①: 틀에 가게와 목표, VIP는 두 배로

[1]

class Card:

shop = "KANT 카페"

goal = 10

 

def __init__(self, name):

self.name = name

self.stamps = 0

 

def add(self):

self.stamps = self.stamps + 1

 

def __str__(self):

left = Card.goal - self.stamps

return f"[{Card.shop}] {self.name}: 도장 {self.stamps}개, {left}개 남음"

 

class VipCard(Card):

def add(self):

self.stamps = self.stamps + 2

Python

클래스 변수

__str__ (25)

add만 덮어쓰기

출력이 없는 셀이에요. 틀만 만들었어요.

24에서 만든 도장 카드를 이어서 만들어요. 가게 이름과 목표 도장 수는 모든 카드가 같아서 클래스 변수로 틀에 적었어요. __str__은 25에서 배운 대로 남은 도장 수까지 글자로 돌려줘요. VIP 카드는 도장 카드의 한 종류라서 Card를 물려받고, add만 두 개씩 찍도록 덮어썼어요. __init__과 __str__은 그대로 물려받아요. 이 셀은 틀만 만들어서 출력이 없어요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
