class Bread:

shop = "붕어빵 1호점"

 

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

 

a = Bread("팥", 1000)

b = Bread("슈크림", 1200)

print(a.shop)

print(b.shop)

print(Bread.shop)

a에는 shop 칸이 없어요. a.shop을 꺼내면 파이썬이 a의 틀 Bread에서 찾아요.

class 바로 아래, def 밖에 shop을 적었어요. self.이 없어요. 이렇게 틀에 적은 값을 클래스 변수라고 해요. 붕어빵 a와 b에는 shop 칸이 없지만 a.shop을 꺼내면 붕어빵 1호점이 나와요. 파이썬은 붕어빵에서 먼저 찾고, 없으면 그 붕어빵을 찍은 틀에서 찾아요. 틀 이름으로 Bread.shop이라고 꺼내도 같은 값이에요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
