2. 클래스 변수

찍을 때마다 틀에 개수를 세요

[3]

class Bread:

count = 0

 

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

Bread.count = Bread.count + 1

 

a = Bread("팥", 1000)

b = Bread("슈크림", 1200)

c = Bread("피자", 1500)

print(Bread.count)

3

← 틀에 +1

Bread.count

3

a = Bread("팥", 1000)

+1 → 1

b = Bread("슈크림", 1200)

+1 → 2

c = Bread("피자", 1500)

+1 → 3

가게 이름, 전체 개수처럼 틀 전체에 하나만 있으면 되는 값에 써요.

클래스 변수로 지금까지 찍은 붕어빵 수를 세요. count는 틀에 0으로 시작하고, __init__ 안에서 Bread.count에 1을 더해요. 24에서 본 것처럼 __init__은 찍을 때마다 불리니까, 세 번 찍으면 3이 돼요. 붕어빵 하나하나가 아니라 틀 전체에 하나만 있으면 되는 값에 클래스 변수를 써요. 더할 때도 self.count가 아니라 Bread.count로 적은 걸 보세요. 이유는 5파트에서 봐요. 출력은 실제로 실행한 결과예요.
