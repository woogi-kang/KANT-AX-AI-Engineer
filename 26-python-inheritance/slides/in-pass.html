3. 상속

괄호에 부모 클래스를 적으면 전부 물려받아요

[1]

class Animal:

def __init__(self, name):

self.name = name

 

def eat(self):

print(f"{self.name}가 밥을 먹어요")

 

def speak(self):

print(f"{self.name}가 소리를 내요")

← 모두 같이 쓰는 것

[2]

class Dog(Animal):

pass

 

d = Dog("초코")

d.eat()

d.speak()

초코가 밥을 먹어요

초코가 소리를 내요

상속은 class 이름 뒤 괄호에 물려받을 클래스를 적으면 돼요. 먼저 모든 동물이 같이 쓰는 Animal 클래스를 만들었어요. Dog 안에는 pass만 있어서 아무것도 적지 않았어요. 그런데도 이름을 넣어 만들 수 있고, eat와 speak도 불러져요. 부모 클래스 Animal의 __init__, eat, speak를 그대로 물려받았기 때문이에요. 물려주는 클래스를 부모 클래스, 물려받는 클래스를 자식 클래스라고 불러요. 개가 "소리를 내요"라고 하는 건 어색하죠. 두 장 뒤에서 멍멍으로 바꿔요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
