class Bread:

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

 

def intro(self):

print(self.flavor, "붕어빵", self.price, "원")

 

class CreamBread(Bread):

pass

 

c = CreamBread("슈크림", 1200)

c.intro()

print(c.flavor)

부모와 자식

물려주는 Bread를 부모 클래스, 물려받는 CreamBread를 자식 클래스라고 불러요.

상속은 class 이름 뒤 괄호에 물려받을 틀을 적으면 돼요. CreamBread 안에는 pass만 있어서 아무것도 적지 않았어요. 그런데도 슈크림과 1200을 넣어 찍을 수 있고, intro도 불러져요. 부모 틀 Bread의 __init__과 intro를 그대로 물려받았기 때문이에요. 물려주는 틀을 부모 클래스, 물려받는 틀을 자식 클래스라고 불러요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
