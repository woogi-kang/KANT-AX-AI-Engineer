같은 이름의 메서드를 다시 적으면 자식 것이 쓰여요

[5]

class CreamBread(Bread):

def __init__(self, flavor, price, cream):

super().__init__(flavor, price)

self.cream = cream

 

def intro(self):

print(self.flavor, "붕어빵", self.price, "원, 크림", self.cream)

 

a = Bread("팥", 1000)

c = CreamBread("슈크림", 1200, "많이")

a.intro()

c.intro()

Python

팥 붕어빵 1000 원

슈크림 붕어빵 1200 원, 크림 많이

덮어쓰기

자식부터 찾아요

c.intro()는 CreamBread에 intro가 있어서 그걸 써요.

없으면 부모에서

a는 Bread로 찍었으니 원래 intro예요.

부모에게 물려받은 메서드와 같은 이름으로 자식 틀에 다시 적으면, 자식 것이 쓰여요. 이걸 덮어쓰기라고 해요. 슈크림 붕어빵은 크림 양까지 소개하도록 intro를 다시 적었어요. 파이썬은 메서드를 찾을 때 자식 틀부터 보고, 없으면 부모 틀로 올라가요. c는 자식 틀에 intro가 있어서 그걸 쓰고, a는 부모 틀로 찍었으니 원래 intro를 써요. 출력은 실제로 실행한 결과예요.
