3. 상속

같은 이름의 메서드를 다시 적으면 자식 것이 쓰여요

[5]

class Dog(Animal):

def speak(self):

print(f"{self.name}가 멍멍 짖어요")

 

d = Dog("초코")

d.speak()

초코가 멍멍 짖어요

← 부모에도 있는 이름

← Dog의 speak

[6]

class Cat(Animal):

def speak(self):

print(f"{self.name}가 야옹 울어요")

 

c = Cat("나비")

c.speak()

나비가 야옹 울어요

← 부모에도 있는 이름

← Cat의 speak

[7]

a.speak()

하마가 소리를 내요

← Animal의 speak 그대로

d.speak()

Dog에서 찾았어요

Animal은 안 봐요

a.speak()

Animal에서 찾았어요

메서드는 자식 클래스에서 먼저 찾고, 없으면 부모 클래스로 올라가요.

부모에게 물려받은 메서드와 같은 이름으로 자식 클래스에 다시 적으면, 자식 것이 쓰여요. 이걸 덮어쓰기라고 해요. 개는 멍멍, 고양이는 야옹으로 speak를 다시 적었어요. 파이썬은 메서드를 찾을 때 자식 클래스부터 보고, 없으면 부모 클래스로 올라가요. d는 Dog에 speak가 있어서 그걸 쓰고 Animal까지 가지 않아요. 하마 a는 Animal로 만들었으니 원래 speak를 써요. 출력은 실제로 실행한 결과예요.
