1. 왜 필요한가

개와 고양이 클래스를 따로 만들면 같은 코드를 두 번 적어요

[1]

class Dog:

def __init__(self, name):

self.name = name

 

def eat(self):

print(f"{self.name}가 밥을 먹어요")

 

def speak(self):

print(f"{self.name}가 멍멍 짖어요")

 

d = Dog("초코")

d.speak()

초코가 멍멍 짖어요

← 두 클래스가 똑같아요

← 다른 건 여기뿐

[2]

class Cat:

def __init__(self, name):

self.name = name

 

def eat(self):

print(f"{self.name}가 밥을 먹어요")

 

def speak(self):

print(f"{self.name}가 야옹 울어요")

 

c = Cat("나비")

c.speak()

나비가 야옹 울어요

← 두 클래스가 똑같아요

← 다른 건 여기뿐

동물이 늘수록 같은 코드도 늘어나요

class Dog

__init__, eat 또 적기

class Cat

__init__, eat 또 적기

class Rabbit

__init__, eat 또 적기

class Duck

__init__, eat 또 적기

class Cow

__init__, eat 또 적기

지금까지 배운 방법만으로 개와 고양이 클래스를 만들면 같은 코드를 두 번 적게 돼요. 이름을 붙이는 __init__과 밥 먹는 eat는 두 클래스가 한 글자도 다르지 않아요. 다른 건 우는 소리를 내는 speak뿐이에요. 밥 먹는 문구를 고치려면 두 클래스를 다 고쳐야 하고, 하나를 빼먹으면 서로 달라져요. 토끼, 오리, 소를 더하면 같은 코드를 그만큼 또 복사해요. 3파트의 상속이 이 문제를 풀어요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
