슈크림 붕어빵 틀을 새로 만들면 거의 다 복사예요

원래 붕어빵 틀

class Bread:

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

self.shop = "붕어빵 1호점"

 

def intro(self):

print(self.flavor, "붕어빵", self.price, "원")

새로 만든 슈크림 붕어빵 틀

class CreamBread:

def __init__(self, flavor, price, cream):

self.flavor = flavor

self.price = price

self.shop = "붕어빵 1호점"

self.cream = cream

 

def intro(self):

print(self.flavor, "붕어빵", self.price, "원")

 

c = CreamBread("슈크림", 1200, "많이")

c.intro()

슈크림 붕어빵 1200 원

다른 건 cream 한 줄뿐이에요

나머지는 그대로 복사했어요. intro를 고치면 두 군데를 다 고쳐야 해요.

가게 이름도 붕어빵마다 따로 들고 있어요

슈크림 붕어빵은 크림 양이라는 칸이 하나 더 있어요. 24에서 배운 방법만으로 만들면 붕어빵 틀을 통째로 복사하고 cream 한 줄을 더해야 해요. 이 셀은 실제로 실행해서 슈크림 붕어빵이 잘 소개됐어요. 문제는 고칠 때예요. 소개 문구를 바꾸려면 두 틀을 다 고쳐야 하고, 하나를 빼먹으면 서로 달라져요. 가게 이름도 붕어빵마다 같은 값을 따로 들고 있어요. 이번 챕터의 두 가지가 이 두 문제를 풀어요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
