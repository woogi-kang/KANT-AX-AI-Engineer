4. 복사와 상속 비교

복사해서 만든 클래스와 물려받은 클래스

복사 (1파트)

상속 (3파트)

class Cat:

def __init__(self, name):

self.name = name

 

def eat(self):

print(f"{self.name}가 밥을 먹어요")

 

def speak(self):

print(f"{self.name}가 야옹 울어요")

class Cat(Animal):

def speak(self):

print(f"{self.name}가 야옹 울어요")

← Dog에도 똑같이 적음

__init__과 eat는 Animal에게 맡겼어요. 다른 점인 speak만 적어요.

복사

상속

eat를 고치면

Dog, Cat 다 고쳐야 해요

Animal 한 곳만 고쳐요

적는 것

모든 줄

다른 점만

상속하면 다른 점만 적어서 코드가 짧고, 고칠 곳이 한 군데예요. 1파트에서 복사해 만든 Cat과 3파트에서 물려받은 Cat을 나란히 놓았어요. 복사한 Cat은 __init__과 eat를 Dog와 똑같이 다시 적었어요. 물려받은 Cat은 speak만 적고 나머지는 Animal에게 맡겼어요. 밥 먹는 문구를 바꾸면 Animal 한 곳만 고치면 돼요.
