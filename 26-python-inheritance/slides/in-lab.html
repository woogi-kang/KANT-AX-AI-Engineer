눌러 보기: 파이썬은 어디서부터 찾을까요

클래스

class Animal

__init__(self, name)

eat(self)

speak(self) # 소리를 내요

물려받기

클래스

class Dog(Animal)

__init__(self, name, breed)

speak(self) # 멍멍

fetch(self)

a

Animal

name "하마"

d

Dog

name "초코"

breed "푸들"

Animal로 만들었어요

Dog로 만들었어요

누구에게

무엇을

d.eat()

찾는 길이 여기에 한 줄씩 나와요.

출력

누구에게 무엇을 물을지 고르고 찾아보기를 눌러요. 브라우저로 슬라이드를 열면 눌러져요.

메서드와 값을 어디서 찾는지 직접 눌러 보는 장이에요. 브라우저로 슬라이드를 열면 버튼이 눌러져요. 객체와 물을 것을 고르고 찾아보기를 누르면 파이썬이 찾는 순서대로 불이 들어와요. 먼저 객체 자신, 다음은 그 객체를 만든 클래스, 그다음은 부모 클래스예요. d.speak()는 Dog에서 찾아서 멍멍이 나와요. d.eat()는 Dog에 없어서 Animal까지 올라가 찾아요. a.fetch()는 Animal에서 끝나서 AttributeError가 나요. 자식 클래스는 보지 않기 때문이에요. 처음 세 번 넘기면 커서가 누를 곳을 d, eat, 찾아보기 순서로 짚어 줘요. 누르기 전에 어디서 찾을지 수강생에게 먼저 물어보세요. 출력은 tools/demo.sh로 실제로 실행한 결과예요.
