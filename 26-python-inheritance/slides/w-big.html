1. 왜 필요한가

틀에 새기는 값, 그리고 물려받는 클래스

틀

class Bread

shop = "붕어빵 1호점"

__init__(flavor, price)

intro()

← 클래스 변수

a

Bread

flavor

"팥"

price

1000

b

Bread

flavor

"피자"

price

1500

a도 b도 틀의 shop을 같이 봐요

클래스

class Animal

__init__(name), eat(), speak()

클래스

class Dog(Animal)

speak() 멍멍

클래스

class Cat(Animal)

speak() 야옹

물려받기 = 상속

Dog와 Cat에는 speak만 적어요. __init__과 eat는 Animal에게서 물려받아요.

그림으로 먼저 봐요. 위는 2파트의 클래스 변수예요. 붕어빵 틀에 가게 이름을 새겨 두면, 찍은 붕어빵마다 따로 들고 있지 않아도 모두 틀에서 같이 봐요. 아래는 3파트의 상속이에요. Animal 클래스에 모든 동물이 같이 쓰는 __init__과 eat를 한 번만 적어요. Dog와 Cat은 Animal을 물려받아서, 다른 점인 speak만 적어요. 이렇게 물려받는 걸 상속이라고 해요. 화살표는 자식에서 부모 쪽을 가리켜요.
