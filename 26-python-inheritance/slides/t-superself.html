5. 오류와 함정

super().__init__에 self를 넣으면 4 were given

[2]

class CreamBread(Bread):

def __init__(self, flavor, price, cream):

super().__init__(self, flavor, price)

self.cream = cream

 

c = CreamBread("슈크림", 1200, "많이")

Python

TypeError: Bread.__init__() takes 3 positional arguments but 4 were given

self가 두 번

읽는 법

부모 __init__은 칸이 3개(self, flavor, price)인데 4개가 들어왔어요. self를 파이썬이 이미 넣었어요.

고치기

super().__init__(flavor, price). a.intro()에 self를 안 적는 것과 같아요.

super().__init__ 괄호에 self를 같이 적었어요. 부모의 __init__은 self, flavor, price 세 칸인데 네 개가 들어왔다는 TypeError예요. super()로 부를 때도 a.intro()처럼 파이썬이 self를 알아서 넣어 줘요. 그래서 우리가 적은 self까지 합쳐 네 개가 됐어요. super().__init__(flavor, price)처럼 self 없이 적어요. 출력은 실제로 실행한 결과예요.
