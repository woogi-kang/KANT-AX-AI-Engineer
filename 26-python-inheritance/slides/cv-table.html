누구 것인가요

몇 개 있나요

꺼내기

a.flavor

a.shop, Bread.shop

바꾸기

a.flavor = ...

Bread.shop = ...

예

맛, 가격, 도장 수

가게 이름, 전체 개수

인스턴스는 객체와 같은 말이에요. 붕어빵마다 다르면 self.이름, 모두 같으면 틀에 적어요.

두 가지 변수를 표로 비교해요. 24에서 self.flavor처럼 붕어빵에 붙인 값은 인스턴스 변수예요. 인스턴스는 객체와 같은 말로, 틀로 찍은 붕어빵 하나를 뜻해요. 붕어빵 수만큼 따로 있어요. 틀에 바로 적은 shop은 클래스 변수예요. 틀에 하나만 있고 모두가 같이 봐요. 20의 지역 변수, 전역 변수와 비슷하게 보이지만, 클래스 변수는 틀 안에 묶여 있어요. 붕어빵마다 다른 값이면 self.이름으로, 모두 같은 값이면 틀에 적어요.
