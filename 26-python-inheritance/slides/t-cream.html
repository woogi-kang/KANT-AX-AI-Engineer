5. 오류와 함정

자식 틀은 재료가 하나 더 필요해요

[3]

class CreamBread(Bread):

def __init__(self, flavor, price, cream):

super().__init__(flavor, price)

self.cream = cream

 

c = CreamBread("슈크림", 1200)

Python

TypeError: CreamBread.__init__() missing 1 required positional argument: 'cream'

cream이 없어요

읽는 법

찍을 때 불리는 건 자식의 __init__이에요. 자식은 cream까지 3개가 필요해요.

고치기

CreamBread("슈크림", 1200, "많이")처럼 자식 __init__의 칸 수에 맞춰요. 기본값(20)으로 cream="보통"을 둘 수도 있어요.

부모 틀처럼 맛과 가격만 넣어 찍었더니 cream이 모자라다는 TypeError가 나요. 자식 틀에 __init__을 새로 적었으니 찍을 때 불리는 건 자식의 __init__이에요. 자식 __init__의 칸 수에 맞춰 재료를 넣어요. 크림을 자주 안 적는다면 20에서 배운 기본값으로 cream="보통"을 둘 수도 있어요. 출력은 실제로 실행한 결과예요.
