class CreamBread(Bread):

def __init__(self, flavor, price, cream):

self.cream = cream

 

def intro(self):

super().intro()

같은 문구를 두 번 안 적어요

소개 문구는 부모 intro에만 있어요. 부모를 고치면 자식도 같이 바뀌어요.

__init__과 같은 모양

super().__init__처럼 super().intro()로 부모 메서드를 불러요.

앞 장처럼 intro를 통째로 다시 적으면 소개 문구가 두 군데에 생겨요. 부모의 intro를 그대로 부르고 한 줄만 더하고 싶을 땐 super().intro()를 써요. __init__에서 super().__init__을 부른 것과 같은 모양이에요. 이렇게 하면 소개 문구는 부모 틀에만 있어서, 부모를 고치면 자식도 같이 바뀌어요. 1파트에서 본 두 군데 고치기 문제가 풀려요. 출력은 실제로 실행한 결과예요.
