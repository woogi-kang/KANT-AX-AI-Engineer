칸을 더할 땐 super().__init__으로 부모에게 맡겨요

[9]

class Dog(Animal):

def __init__(self, name, breed):

super().__init__(name)

self.breed = breed

 

def speak(self):

print(f"{self.name}가 멍멍 짖어요")

 

d = Dog("초코", "푸들")

print(d.name, d.breed)

d.speak()

name은 부모가, breed는 자식이 붙여요.

개는 견종(breed) 칸이 하나 더 있어요. 그래서 Dog에 __init__을 새로 적어야 해요. 이름을 붙이는 일은 부모의 __init__이 이미 하고 있으니 다시 적지 않고 맡겨요. 앞 장의 super().eat()처럼, super().__init__(name)은 부모의 __init__에 이름을 넣어 부르는 줄이에요. self는 적지 않아요. 부모가 name을 붙인 뒤, 자식은 breed만 직접 붙여요. speak는 앞에서 본 멍멍을 그대로 다시 적었어요. 출력은 실제로 실행한 결과예요.
