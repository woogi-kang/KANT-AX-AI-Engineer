class Bread:

count = 0

 

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

self.count = self.count + 1

 

a = Bread("팥", 1000)

b = Bread("슈크림", 1200)

print(a.count, b.count)

왼쪽과 오른쪽이 달라요

오른쪽 self.count는 틀의 0을 읽어요. 왼쪽 self.count =은 붕어빵에 새 칸을 붙여요. 그래서 붕어빵마다 1이에요.

고치기

Bread.count = Bread.count + 1처럼 틀 이름으로 적어요.

2파트의 개수 세기를 self.count로 적었어요. 오류는 없는데 Bread.count는 0이고, 붕어빵마다 1이에요. 오른쪽 self.count는 붕어빵에 count 칸이 없으니 틀의 0을 읽어요. 왼쪽 self.count =은 앞 장처럼 붕어빵에 새 칸을 붙여요. 그래서 틀의 값은 한 번도 안 바뀌어요. 20의 전역 변수에서 같은 이름에 넣으면 새 지역 변수가 생기던 것과 비슷해요. 틀의 값을 바꿀 땐 Bread.count처럼 틀 이름으로 적어요. 출력은 실제로 실행한 결과예요.
