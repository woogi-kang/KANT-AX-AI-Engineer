AttributeError: 'Animal' object has no attribute 'fetch'

← a는 Animal로 만들었어요

물려받기는 부모에서 자식 쪽으로만 일어나요. 모든 동물이 공을 물어 오지는 않아요.

자식 클래스에 새 메서드를 더해요. 공을 물어 오는 건 개만 하니까 Dog에 fetch를 적었어요. d는 부모에게서 물려받은 eat와 자기 클래스의 fetch를 둘 다 쓸 수 있어요. 앞 셀의 Animal을 그대로 쓰고 있어요. 반대로 하마 a는 부모 클래스 Animal로 만들어서 fetch가 없어요. 물려받기는 부모에서 자식 쪽으로만 일어나요. 출력은 실제로 실행한 결과예요.
