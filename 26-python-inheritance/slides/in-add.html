def keep(self):

자식 틀에만 있는 메서드

a.keep()

AttributeError: 'Bread' object has no attribute 'keep'

← a는 부모 틀 Bread로 찍었어요

물려받기는 부모에서 자식 쪽으로만 일어나요.

자식 틀에 새 메서드를 더해요. 슈크림 붕어빵만 차갑게 보관하라는 안내가 필요해서 keep을 적었어요. c는 부모에게 물려받은 intro와 자기 틀의 keep을 둘 다 쓸 수 있어요. 앞 셀의 Bread 틀을 그대로 쓰고 있어요. 반대로 팥 붕어빵 a는 부모 틀 Bread로 찍어서 keep이 없어요. 물려받기는 부모에서 자식 쪽으로만 일어나요. 출력은 실제로 실행한 결과예요.
