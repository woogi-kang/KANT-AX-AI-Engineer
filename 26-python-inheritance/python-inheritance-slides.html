6. 실습

붕어빵 메뉴판 ①: 미니 붕어빵 틀을 물려받기

[3]

class Bread:

count = 0

 

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

Bread.count = Bread.count + 1

 

def __str__(self):

return f"{self.flavor} 붕어빵 {self.price:,}원"

 

class MiniBread(Bread):

def __init__(self, flavor, price, qty):

super().__init__(flavor, price)

self.qty = qty

 

def __str__(self):

return f"미니 {self.flavor} {self.qty}개 {self.price * self.qty:,}원"

← 찍을 때마다 개수 세기

← 미니 붕어빵도 붕어빵의 한 종류

← 맛과 가격은 부모에게 맡겨요

← 묶음 가격이 보이게 덮어쓰기

이 셀도 출력이 없어요

미니 붕어빵은 한 개 가격과 묶음 개수가 있어요. 미니 붕어빵도 붕어빵의 한 종류라서 Bread를 물려받았어요. 자식 __init__은 맛과 가격을 super().__init__에 맡기고 개수만 붙여요. 부모 __init__ 안에서 Bread.count가 늘어나니까 미니 붕어빵을 찍어도 개수가 세져요. __str__은 묶음 가격을 보여 주도록 덮어썼어요. 이 셀도 틀만 만들어서 출력이 없어요.
