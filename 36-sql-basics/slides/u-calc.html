SET에 계산식을 쓰면 지금 값에서 더하고 빼요. audio 상품을 5천 원 할인하고 재고를 10개씩 채웠어요. price = price - 5000에서 등호 오른쪽 price는 지금 값이에요. 12에서 x = x + 1로 값을 늘린 것과 같아요. 열 여러 개를 바꿀 때는 쉼표로 이어요. WHERE category = 'audio'에 맞는 줄이 두 개라서 UPDATE 2가 나왔어요. 아래 표는 바꾸기 전 값에서 바뀐 값으로 넘어가는 모습이에요. 바뀐 뒤 값은 SELECT로 확인한 실제 결과예요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
