5. 자주 나는 오류

글자 값은 작은따옴표로 감싸요. 큰따옴표는 열 이름으로 읽어요

kant_shop=# SELECT * FROM product WHERE name = "웹캠";

ERROR:  column "웹캠" does not exist

LINE 1: SELECT * FROM product WHERE name = "웹캠";

                                          ^

HINT:  Perhaps you meant to reference the column "product.id".

 

kant_shop=# SELECT * FROM product WHERE name = '웹캠;

kant_shop'# ^C

kant_shop=#  

kant_shop=# SELECT * FROM product WHERE name = '웹캠';

id | name | category | price | stock

----+------+----------+-------+-------

 8 | 웹캠 | display  | 52000 |    12

(1 row)

따옴표가 열린 채예요

큰따옴표 안은 열 이름이에요. 그래서 웹캠이라는 열을 찾다가 없다고 해요.

프롬프트가 '#로 바뀌면 작은따옴표 하나를 안 닫은 거예요. Ctrl+C로 지우고 다시 쳐요.

글자 값은 작은따옴표로 감싸요. 큰따옴표는 열 이름으로 읽어요. 웹캠을 큰따옴표로 감싸면 column 웹캠 does not exist, 웹캠이라는 열이 없다는 오류가 나요. 32에서 본 것처럼 MySQL은 큰따옴표도 받아 주지만 PostgreSQL은 열 이름으로 읽어요. HINT 줄은 비슷한 열 이름을 추천하는데 여기서는 상관없어요. 아래는 닫는 작은따옴표를 빼먹은 장면이에요. 엔터를 쳐도 실행되지 않고 프롬프트가 작은따옴표 샵으로 바뀌어요. 문장이 아직 글자 값 안에 있다는 뜻이에요. Ctrl+C를 누르면 쓰던 문장이 지워지고 원래 프롬프트로 돌아와요. 다시 바르게 치면 웹캠 한 줄이 나와요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
