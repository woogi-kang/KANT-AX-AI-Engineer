3. 넣고 골라 보기

비어 있는 값(NULL)은 = 대신 IS NULL로 찾아요

kant_shop=# SELECT name, price FROM product WHERE price = NULL;

name | price

------+-------

(0 rows)

 

kant_shop=# SELECT name, price FROM product WHERE price IS NULL;

   name     | price

-------------+-------

무선 충전기 |

(1 row)

 

kant_shop=# SELECT name, price FROM product WHERE price IS NOT NULL AND stock < 10;

     name       | price

-----------------+-------

노트북 거치대   | 24000

블루투스 스피커 | 45000

(2 rows)

오류도 없이 0줄

?

NULL은 모르는 값이에요. 모르는 값과 같은지 물으면 답도 모름이라 어떤 줄도 안 골라요.

그래서 비어 있는지는 IS NULL, 값이 있는지는 IS NOT NULL로 물어요.

파이썬에서 None을 is None으로 확인한 것과 같아요.

비어 있는 값은 등호 대신 IS NULL로 찾아요. 가격이 없는 상품을 찾으려고 price = NULL을 치면 오류도 안 나고 0줄이 나와요. 이게 함정이에요. NULL은 모르는 값이라서, 모르는 값과 같은지 물으면 답도 모름이 되고 어떤 줄도 골라지지 않아요. 비어 있는지 물을 때는 IS NULL을 써요. 그러면 무선 충전기가 나와요. 반대로 값이 있는 줄만 고를 때는 IS NOT NULL이에요. 마지막 문장은 가격이 있고 재고가 10개 안 남은 상품이에요. AND로 두 조건을 이었어요. 파이썬에서 None을 is None으로 확인한 것과 같아요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
