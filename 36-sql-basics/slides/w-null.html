3. 넣고 골라 보기

비어 있는 값(NULL)은 = 대신 IS NULL로 찾아요

kant_shop=# SELECT name, price FROM product WHERE price = NULL;

name | price

------+-------

(0 rows)

 

kant_shop=# SELECT name, price FROM product WHERE price IS NULL;

   name     | price

-------------+-------

무선 충전기 |

(1 row)

 

kant_shop=# SELECT COUNT(*) AS "가격 미정" FROM product WHERE price IS NULL;

가격 미정

-----------

        1

(1 row)

오류도 없이 0줄

맞는 줄이 몇 개인지만

?

NULL은 모르는 값이에요. 모르는 값과 같은지 물으면 답도 모름이라 어떤 줄도 안 골라요.

그래서 비어 있는지는 IS NULL, 값이 있는지는 IS NOT NULL로 물어요.

COUNT(*)는 줄 수를 세는 함수예요. 합계와 평균 같은 다른 함수는 다음 SQL 챕터에서 배워요.

비어 있는 값은 등호 대신 IS NULL로 찾아요. 가격이 없는 상품을 찾으려고 price = NULL을 치면 오류도 안 나고 0줄이 나와요. 이게 함정이에요. NULL은 모르는 값이라서, 모르는 값과 같은지 물으면 답도 모름이 되고 어떤 줄도 골라지지 않아요. 비어 있는지 물을 때는 IS NULL을 써요. 그러면 무선 충전기가 나와요. 반대로 값이 있는 줄만 고를 때는 IS NOT NULL이에요. 파이썬에서 None을 is None으로 확인한 것과 같아요. 마지막 문장은 줄을 보여 주지 않고 몇 줄인지만 세요. COUNT 괄호 별표는 맞는 줄의 개수를 돌려줘요. 앞 장에서 배운 AS로 가격 미정이라는 이름을 붙였어요. 띄어쓰기가 있어서 큰따옴표로 감쌌어요. 오늘은 줄 수 세기만 보고, 합계나 평균은 다음 SQL 챕터에서 배워요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
