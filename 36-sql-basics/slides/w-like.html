LIKE는 % 자리에 아무 글자나 와도 맞아요. ILIKE는 대소문자를 안 가려요

kant_shop=# SELECT name FROM product WHERE name LIKE '%마우스%';

% 대신 _를 쓰면 딱 한 글자 자리예요.

LIKE는 퍼센트 자리에 아무 글자나 와도 맞아요. 이름에 마우스가 들어 있는 상품을 찾을 때 등호를 쓰면 이름 전체가 같아야 해서 못 찾아요. LIKE 뒤에 퍼센트 마우스 퍼센트를 적으면 앞뒤에 무엇이 있어도 마우스만 들어 있으면 골라요. 무선 퍼센트는 무선으로 시작하는 이름이에요. 퍼센트를 빼고 LIKE 무선만 적으면 0줄이에요. 퍼센트가 없으면 이름 전체가 딱 무선이어야 해서 등호와 같아요. 김씨 회원을 찾을 때도 김이 아니라 김 퍼센트로 적어요. 그런데 소문자로 usb 퍼센트를 찾으면 0줄이에요. LIKE는 대문자와 소문자를 다르게 보기 때문이에요. ILIKE를 쓰면 대소문자를 가리지 않아서 USB-C 허브가 나와요. 퍼센트 대신 밑줄을 쓰면 딱 한 글자 자리라는 뜻이에요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
