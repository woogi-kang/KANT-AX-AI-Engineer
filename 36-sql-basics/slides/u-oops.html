8줄 모두 0원

표가 텅 비었어요

바꾸기 전에 같은 WHERE로 먼저 봐요

1

SELECT * FROM product WHERE id = 3;

몇 줄이 나오는지 봐요

2

UPDATE product SET price = 250000

WHERE id = 3;

지운 데이터는 다시 INSERT해야 해요. 실습은 연습 데이터로만 해요.

WHERE를 빼면 모든 줄이 바뀌고, 되돌리는 명령은 없어요. 모니터 가격만 바꾸려다 WHERE를 빼먹었어요. UPDATE 8, 여덟 줄 모두 0원이 됐어요. DELETE FROM product에서 WHERE를 빼면 표가 텅 비어요. psql은 정말 바꿀 거냐고 묻지 않아요. 지운 데이터는 다시 INSERT하는 수밖에 없어요. 그래서 UPDATE와 DELETE 전에는 같은 WHERE로 SELECT를 먼저 쳐서 몇 줄이 나오는지 봐요. 원하는 줄만 나오면 SELECT 별표 FROM 부분을 UPDATE나 DELETE로 바꿔서 실행해요. 6파트 예제에서 이 순서로 해요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
