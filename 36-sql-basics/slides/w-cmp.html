WHERE 뒤에 조건을 적으면 맞는 줄만 나와요

=

같다

<>

다르다

<

작다

>

크다

<=

작거나 같다

>=

크거나 같다

kant_shop=# SELECT name, price FROM product WHERE price >= 50000;

    name      | price

---------------+--------

27인치 모니터 | 259000

기계식 키보드 |  89000

웹캠          |  52000

(3 rows)

 

kant_shop=# SELECT name, category FROM product WHERE category <> 'acc';

     name       | category

-----------------+----------

무선 이어폰     | audio

게이밍 마우스   | input

27인치 모니터   | display

기계식 키보드   | input

블루투스 스피커 | audio

웹캠            | display

(6 rows)

파이썬의 != 자리에 <>를 써요. !=를 써도 돼요.

글자 값은 작은따옴표로 감싸요.

WHERE 뒤에 조건을 적으면 맞는 줄만 나와요. 32에서 WHERE와 등호, 작다를 읽어 봤어요. 오늘은 비교 기호 여섯 개를 다 써요. 같다는 등호 하나예요. 파이썬처럼 두 개를 쓰지 않아요. 다르다는 꺾쇠 두 개를 붙여 쓰고, 파이썬처럼 느낌표 등호를 써도 돼요. 가격이 5만 원 이상인 상품은 price >= 50000으로 골라서 세 개가 나와요. 분류가 acc가 아닌 상품은 category <> 'acc'로 골라요. 글자 값은 작은따옴표로 감싸요. SELECT 뒤에 열 이름을 적으면 그 열만 보여 줘요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
