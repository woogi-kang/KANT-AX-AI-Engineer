4. 고치고 지우기

DROP TABLE IF EXISTS는 표가 없어도 오류 없이 넘어가요

kant_shop=# DROP TABLE type_text;

DROP TABLE

kant_shop=# DROP TABLE type_text;

ERROR:  table "type_text" does not exist

kant_shop=# DROP TABLE IF EXISTS type_text;

NOTICE:  table "type_text" does not exist, skipping

DROP TABLE

kant_shop=# DROP TABLE type_int, type_num, type_real, type_rate, type_bool, type_time;

DROP TABLE

kant_shop=# \dt

          List of tables

Schema |  Name   | Type  |  Owner

--------+---------+-------+----------

public | product | table | postgres

(1 row)

한 번 더 지우면

알림만 하고 넘어가요

쉼표로 여러 표를 한 번에

postgres=# DROP DATABASE IF EXISTS test;

NOTICE:  database "test" does not exist, skipping

DROP DATABASE

postgres=# DROP DATABASE test;

ERROR:  database "test" does not exist

35 수업 파일의 첫 줄 DROP DATABASE IF EXISTS kant_shop;도 같은 뜻이에요. 처음 실행해도 오류 없이 지나가요.

DROP TABLE IF EXISTS는 표가 없어도 오류 없이 넘어가요. 자료형 연습 표 type_text를 지웠어요. 한 번 더 지우려고 하면 표가 없다는 ERROR가 나요. IF EXISTS를 붙이면 없으면 넘어간다는 NOTICE 알림만 나오고 오류가 아니에요. SQL 파일을 처음부터 다시 실행할 때 첫 줄에서 멈추지 않게 이렇게 써요. 표 여러 개는 쉼표로 이어 한 번에 지워요. 데이터베이스도 같아요. 35 수업 파일 첫 줄 DROP DATABASE IF EXISTS kant_shop이 이 뜻이었어요. DROP도 되돌릴 수 없으니 이름을 잘 보고 쳐요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
