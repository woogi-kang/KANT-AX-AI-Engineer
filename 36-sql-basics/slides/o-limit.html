3. 넣고 골라 보기

LIMIT은 앞에서 몇 줄만 자르고, OFFSET은 그만큼 건너뛰어요

kant_shop=# SELECT name, price FROM product WHERE price IS NOT NULL ORDER BY price DESC LIMIT 3;

    name      | price

---------------+--------

27인치 모니터 | 259000

기계식 키보드 |  89000

웹캠          |  52000

(3 rows)

NULL을 빼야 비싼 3개가 맞게 나와요

kant_shop=# SELECT id, name FROM product ORDER BY id LIMIT 3;

id |     name

----+---------------

 1 | 무선 이어폰

 2 | 게이밍 마우스

 3 | 27인치 모니터

(3 rows)

kant_shop=# SELECT id, name FROM product ORDER BY id LIMIT 3 OFFSET 3;

id |     name

----+---------------

 5 | 노트북 거치대

 6 | 기계식 키보드

1쪽은 LIMIT 3, 2쪽은 OFFSET 3을 더해요. 게시판의 쪽 넘기기예요.

LIMIT은 앞에서 몇 줄만 자르고, OFFSET은 그만큼 건너뛰어요. 가장 비싼 상품 3개는 가격이 비싼 순으로 세우고 LIMIT 3으로 앞의 세 줄만 잘라요. 앞 장에서 본 것처럼 DESC로 세우면 가격이 NULL인 충전기가 맨 앞에 와요. 그래서 WHERE price IS NOT NULL로 빼고 세웠어요. 13에서 리스트를 대괄호 콜론 3으로 자른 것과 같아요. 아래는 id 순서로 세 줄씩 보는 장면이에요. LIMIT 3은 1번부터 3번, LIMIT 3 OFFSET 3은 앞의 세 줄을 건너뛰고 4번부터 6번이에요. 게시판에서 쪽을 넘길 때 이렇게 해요. LIMIT을 쓸 때는 ORDER BY를 같이 써야 매번 같은 줄이 나와요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
