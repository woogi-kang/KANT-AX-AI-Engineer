숫자나 날짜 칸에 형식이 다른 글자를 넣으면 invalid input이에요

숫자만 있으면 따옴표가 있어도 들어가요

2월 30일은 없어요

숫자나 날짜 칸에 형식이 다른 글자를 넣으면 invalid input 오류가 나요. 가격을 24,000처럼 쉼표를 넣어 적으면 INTEGER 칸이 읽지 못해서 오류가 나요. 숫자 칸과 글자를 비교해도 같은 오류예요. 그런데 따옴표 안에 숫자만 있는 '24000'은 PostgreSQL이 숫자로 바꿔서 넣어 줘요. 날짜 칸은 연도 네 자리, 월, 일을 빼기로 이어 적어요. 2월 30일처럼 없는 날짜는 out of range 오류가 나요. 오류 아래 LINE 줄과 화살표가 막힌 값을 가리켜요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
