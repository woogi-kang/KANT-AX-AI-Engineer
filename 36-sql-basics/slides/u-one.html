4. 고치고 지우기

UPDATE ... SET으로 값을 바꾸고, WHERE로 바꿀 줄을 골라요

UPDATE product SET price = 32000 WHERE id = 9;

바꿀 표

바꿀 열 = 새 값

바꿀 줄

kant_shop=# SELECT id, name, price FROM product WHERE id = 9;

id |    name     | price

----+-------------+-------

 9 | 무선 충전기 |

(1 row)

 

kant_shop=# UPDATE product SET price = 32000 WHERE id = 9;

UPDATE 1

kant_shop=# SELECT id, name, price FROM product WHERE id = 9;

id |    name     | price

----+-------------+-------

 9 | 무선 충전기 | 32000

(1 row)

바꾸기 전과 후에 같은 WHERE로 SELECT해서 확인했어요.

UPDATE SET으로 값을 바꾸고, WHERE로 바꿀 줄을 골라요. 문장은 세 조각이에요. UPDATE 뒤에 표 이름, SET 뒤에 바꿀 열과 새 값, WHERE 뒤에 바꿀 줄의 조건을 적어요. 가격이 비어 있던 9번 무선 충전기의 가격을 3만 2천 원으로 정했어요. 실행하면 UPDATE 1, 한 줄이 바뀌었다는 뜻이 나와요. 바꾸기 전과 후에 같은 WHERE로 SELECT해서 비어 있던 칸이 32000으로 바뀐 걸 확인했어요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
