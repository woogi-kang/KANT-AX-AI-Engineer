NULL은 맨 뒤

DESC면 맨 앞

ORDER BY 열

작은 것부터 (ASC, 안 적어도 돼요)

ORDER BY 열 DESC

큰 것부터. 22의 sorted(..., reverse=True)와 같아요

ORDER BY로 줄을 세워요. DESC를 붙이면 큰 것부터예요. ORDER BY price는 가격이 싼 것부터 세워요. 작은 것부터 세우는 게 기본이라 ASC는 안 적어도 돼요. 뒤에 DESC를 붙이면 비싼 것부터 세워요. 22에서 배운 sorted에 reverse=True를 준 것과 같아요. 가격이 NULL인 무선 충전기를 봐요. 작은 것부터 세우면 맨 뒤에 오고, DESC로 세우면 맨 앞에 와요. PostgreSQL은 NULL을 가장 큰 값처럼 다뤄요. 비싼 상품을 찾을 때 이게 문제가 되는데, 두 장 뒤에서 풀어요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
