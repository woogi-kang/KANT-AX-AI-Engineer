6. 실제 상황 예제

포인트 3만 이상 회원의 등급을 gold로 올려요. SELECT로 먼저 봐요

kant_shop=# SELECT name, grade, points FROM member WHERE points >= 30000 AND grade <> 'gold';

 name  | grade  | points

--------+--------+--------

김하늘 | silver |  42000

박서연 | basic  |  31500

(2 rows)

 

kant_shop=# UPDATE member SET grade = 'gold' WHERE points >= 30000 AND grade <> 'gold' RETURNING name, grade, points;

 name  | grade | points

--------+-------+--------

김하늘 | gold  |  42000

박서연 | gold  |  31500

(2 rows)

 

UPDATE 2

2명이 맞아요

같은 2명이 gold로

1. 같은 WHERE로 SELECT해서 몇 명인지 보고 2. SELECT * FROM을 UPDATE ... SET으로 바꿔 실행하고 3. RETURNING으로 바뀐 줄을 확인해요.

포인트 3만 이상 회원의 등급을 gold로 올려요. 4파트에서 본 사고를 막는 순서로 해요. 먼저 같은 WHERE로 SELECT를 쳐요. 포인트가 3만 이상이고 아직 gold가 아닌 회원은 김하늘과 박서연 두 명이에요. 정우진은 이미 gold라서 빠졌어요. 원하는 사람만 나왔으니 같은 WHERE를 그대로 두고 UPDATE로 바꿔요. RETURNING을 붙여서 바뀐 두 줄을 바로 확인해요. UPDATE 2, SELECT에서 본 숫자와 같아요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
