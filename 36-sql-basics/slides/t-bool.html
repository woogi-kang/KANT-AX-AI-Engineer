2. 자료형 고르기

BOOLEAN은 true와 false를 담고, psql은 t와 f로 보여 줘요

kant_shop=# CREATE TABLE type_bool (name VARCHAR(20), on_sale BOOLEAN);

CREATE TABLE

kant_shop=# INSERT INTO type_bool VALUES ('mouse', true), ('keyboard', false);

INSERT 0 2

kant_shop=# SELECT * FROM type_bool;

  name   | on_sale

----------+---------

mouse    | t

keyboard | f

(2 rows)

 

kant_shop=# SELECT * FROM type_bool WHERE on_sale = true;

name  | on_sale

-------+---------

mouse | t

(1 row)

true

false

이름만 알아 둘 자료형

UUID

겹치지 않는 긴 아이디

a0eebc99-9c0b-4ef8-…

JSON

15의 딕셔너리 모양을 그대로

{"color": "black"}

자동으로 늘어나는 번호(SERIAL, IDENTITY)는 37에서 배워요.

BOOLEAN은 true와 false를 담고, psql은 t와 f로 보여 줘요. 상품이 지금 할인 중인지처럼 예, 아니요로 답하는 값에 써요. 넣을 때는 따옴표 없이 true, false로 적어요. 꺼내 보면 psql은 짧게 t와 f로 보여 줘요. WHERE on_sale = true로 할인 중인 상품만 고를 수 있어요. WHERE는 3파트에서 자세히 배워요. 오른쪽 두 가지는 이름만 알아 둬요. UUID는 겹치지 않게 만든 긴 아이디이고, JSON은 15에서 배운 딕셔너리 모양 데이터를 그대로 담는 자료형이에요. 자동으로 1, 2, 3 늘어나는 번호는 37 챕터에서 배워요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
