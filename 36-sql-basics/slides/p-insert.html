3. 넣고 골라 보기

여러 줄을 한 번에 넣고, 안 적은 열은 NULL(모름)로 비워 둬요

kant_shop=# INSERT INTO product (id, name, category, price, stock) VALUES

kant_shop-# (1, '무선 이어폰', 'audio', 35000, 100),

kant_shop-# (2, '게이밍 마우스', 'input', 28000, 85),

…

kant_shop-# (8, '웹캠', 'display', 52000, 12);

INSERT 0 8

kant_shop=# INSERT INTO product (id, name, category, stock) VALUES (9, '무선 충전기', 'acc', 40);

INSERT 0 1

8줄이 들어갔어요

괄호 묶음을 쉼표로 잇고 맨 끝에만 ;를 붙여요.

price를 적지 않아서 NULL이 들어갔어요. 값이 아직 없다, 모른다는 뜻이고 psql은 빈칸으로 보여 줘요.

여러 줄을 한 번에 넣고, 안 적은 열은 NULL로 비워 둬요. INSERT INTO 뒤에 열 이름을 괄호로 적고, VALUES 뒤에 한 줄씩 괄호로 묶어 쉼표로 이어요. 마지막 줄 끝에만 세미콜론을 붙여요. 실제로는 여덟 줄을 다 쳤는데, 화면에서는 가운데를 …로 줄였어요. INSERT 0 8은 여덟 줄이 들어갔다는 뜻이에요. 무선 충전기는 가격이 아직 정해지지 않아서 열 이름에서 price를 뺐어요. 그러면 price 칸에 NULL이 들어가요. NULL은 0도 아니고 빈 글자도 아닌, 값을 모른다는 표시예요. 15의 파이썬 None과 비슷해요. psql은 NULL을 빈칸으로 보여 줘요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
