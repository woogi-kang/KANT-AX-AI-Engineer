6. 실제 상황 예제

DISTINCT를 붙이면 겹치는 줄을 하나만 남겨요

kant_shop=# SELECT region FROM member;

region

--------

마포구

강남구

마포구

송파구

강남구

마포구

(6 rows)

 

kant_shop=# SELECT DISTINCT region FROM member;

region

--------

송파구

마포구

강남구

(3 rows)

 

kant_shop=# SELECT DISTINCT region, grade FROM member;

region | grade

--------+--------

송파구 | basic

강남구 | gold

마포구 | silver

마포구 | basic

강남구 | basic

(5 rows)

박서연, 강민서 두 줄이 하나로

열을 두 개 적으면 두 값의 짝이 겹칠 때만 하나로 합쳐요. 순서는 정해져 있지 않으니 줄을 세우려면 ORDER BY를 붙여요.

DISTINCT를 붙이면 겹치는 줄을 하나만 남겨요. 회원 표에 사는 구 region 열을 더했어요. 그냥 SELECT하면 여섯 줄에 마포구가 세 번 나와요. SELECT 바로 뒤에 DISTINCT를 붙이면 겹치는 값을 하나만 남겨서 세 줄이 돼요. 이벤트를 어느 구에서 열지 정할 때처럼 어떤 값들이 있는지만 볼 때 써요. 열을 두 개 적으면 구와 등급의 짝이 같을 때만 합쳐요. 마포구 basic은 박서연과 강민서 두 명이라 한 줄이 됐고, 마포구 silver는 따로 남아서 다섯 줄이에요. DISTINCT 결과의 순서는 정해져 있지 않아요. 순서가 필요하면 ORDER BY를 붙여요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
