파이썬 (딕셔너리 리스트 products)

SQL (표 product)

넣기

products.append({"id": 10, ...})

INSERT INTO product VALUES (10, ...);

고르기

[p for p in products if p["price"] >= 50000]

SELECT * FROM product WHERE price >= 50000;

줄 세우기

sorted(products, key=lambda p: p["price"], reverse=True)

ORDER BY price DESC

앞에서 3개

결과[:3]

LIMIT 3

고치기

p["price"] = 32000

UPDATE product SET price = 32000 WHERE id = 9;

지우기

products.remove(p)

DELETE FROM product WHERE id = 8;

None, is None

파이썬 리스트는 프로그램이 끝나면 사라지지만, 표는 볼륨에 남아서 다음 날에도 그대로예요.

15, 22, 23에서 파이썬으로 하던 일을 SQL 한 문장으로 해요. 왼쪽은 상품을 딕셔너리 리스트로 담았을 때 쓰던 코드예요. 넣기는 append, 고르기는 23의 컴프리헨션에 if, 줄 세우기는 22의 sorted와 key, reverse예요. 앞에서 세 개는 슬라이싱이에요. 고치기는 딕셔너리 칸에 새 값을 넣었고, 지우기는 remove였어요. 비어 있음은 None이었어요. SQL에서는 같은 일을 표 이름과 조건만 적어서 해요. 가장 큰 차이는 남느냐예요. 파이썬 리스트는 프로그램이 끝나면 사라지지만, 표는 34에서 붙인 볼륨에 남아서 다음 날에도 그대로예요.
