3. 넣고 골라 보기

AS로 결과 열에 새 이름을 붙이고, 계산한 값도 열로 꺼내요

kant_shop=# SELECT name AS 상품명, price AS 가격 FROM product WHERE id <= 3;

   상품명     |  가격

---------------+--------

무선 이어폰   |  35000

게이밍 마우스 |  28000

27인치 모니터 | 259000

(3 rows)

 

kant_shop=# SELECT name, price, price * 3 FROM product WHERE id <= 3;

    name      | price  | ?column?

---------------+--------+----------

무선 이어폰   |  35000 |   105000

게이밍 마우스 |  28000 |    84000

27인치 모니터 | 259000 |   777000

(3 rows)

kant_shop=# SELECT name AS 상품명, price * 3 AS "3개 가격" FROM product WHERE id <= 3;

   상품명     | 3개 가격

---------------+----------

무선 이어폰   |   105000

게이밍 마우스 |    84000

27인치 모니터 |   777000

(3 rows)

AS 상품명

한글 이름도 그냥 써요

price * 3

+ - * / 로 계산한 값을 열로

AS "3개 가격"

숫자로 시작하거나 띄어 쓰면 큰따옴표

글자 값은 작은따옴표, 열 이름은 큰따옴표예요. 5파트에서 다시 봐요.

AS로 결과 열에 새 이름을 붙이고, 계산한 값도 열로 꺼내요. 첫 문장은 name을 상품명, price를 가격이라는 이름으로 보여 줘요. 표의 열 이름이 바뀌는 게 아니라 이번 결과에서만 바뀌어요. 한글 이름은 따옴표 없이 써도 돼요. 두 번째 문장처럼 price 곱하기 3을 적으면 세 개 살 때 가격을 계산해서 보여 줘요. 계산한 열은 이름이 없어서 psql이 물음표 column 물음표로 보여 줘요. 이름을 3개가격처럼 숫자로 시작하게 적으면 trailing junk 오류가 나요. 숫자 뒤에 쓸데없는 글자가 붙었다고 읽기 때문이에요. 숫자로 시작하거나 띄어쓰기가 있는 이름은 큰따옴표로 감싸요. WHERE id <= 3은 id가 3 이하인 줄만 고른다는 뜻이고, 다음 장에서 자세히 봐요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
