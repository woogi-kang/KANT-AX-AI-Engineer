5. 자주 나는 오류

열 이름 오타는 HINT가 알려 주고, 빠진 쉼표는 오류 없이 이름을 바꿔요

kant_shop=# SELECT nmae, price FROM product;

ERROR:  column "nmae" does not exist

LINE 1: SELECT nmae, price FROM product;

              ^

HINT:  Perhaps you meant to reference the column "product.name".

kant_shop=# SELECT name price FROM product WHERE id < 4;

    price

열 이름이 price로 바뀌었어요

SELECT name, price처럼 쉼표를 넣어야 두 열이 나와요. 쉼표가 빠지면 뒤 단어를 앞 열의 새 이름으로 읽어요.

열 이름 오타는 HINT가 알려 주고, 빠진 쉼표는 오류 없이 이름을 바꿔요. name을 nmae로 잘못 치면 column nmae does not exist 오류가 나고, HINT 줄에서 혹시 product.name이냐고 물어봐 줘요. 오류 아래 화살표는 문장의 어디서 막혔는지 가리켜요. 더 무서운 건 오류가 안 나는 실수예요. name과 price 사이 쉼표를 빼먹으면 두 열이 나오지 않고, 상품 이름이 price라는 이름표를 달고 한 열만 나와요. 오류가 없으니 그냥 넘어가기 쉬워요. 결과의 열 이름이 내가 적은 것과 같은지 꼭 봐요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
