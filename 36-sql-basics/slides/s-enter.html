1. kant_shop에 들어가기

35의 my-pg에 들어가서 kant_shop을 새로 만들어요

~ $ docker run -d --name my-pg -e POSTGRES_PASSWORD=admin1234 -p 5432:5432 -v pgdata:/var/lib/postgresql postgres:18

f9414cfb48db…

~ $ docker exec -it my-pg psql -U postgres

postgres=# DROP DATABASE IF EXISTS kant_shop;

NOTICE:  database "kant_shop" does not exist, skipping

DROP DATABASE

postgres=# CREATE DATABASE kant_shop;

CREATE DATABASE

postgres=# \c kant_shop

You are now connected to database "kant_shop" as user "postgres".

kant_shop=#  

35 수업 파일 첫 줄과 같아요

다른 데이터베이스로 옮겨요

다음부터는 -d로 바로 들어가요

$ docker exec -it my-pg psql -U postgres -d kant_shop

my-pg가 꺼져 있으면 docker start my-pg로 켜요. 컨테이너가 아예 없으면 위의 docker run부터 쳐요.

35의 my-pg에 들어가서 kant_shop을 새로 만들어요. 35 수업에서 켠 my-pg 컨테이너를 그대로 써요. 컨테이너가 없으면 첫 줄 docker run으로 켜요. 비밀번호는 admin1234이고, pgdata 볼륨을 붙여서 지워도 데이터가 남아요. docker exec로 psql을 열고, 수업 파일 첫 줄처럼 DROP DATABASE IF EXISTS로 예전 kant_shop을 지운 뒤 새로 만들어요. 처음이라 없으면 does not exist, skipping이라는 알림만 나와요. IF EXISTS는 4파트에서 자세히 봐요. 백슬래시 c로 kant_shop에 옮겨 가면 프롬프트 앞 이름이 kant_shop으로 바뀌어요. 다음부터는 -d kant_shop을 붙여서 바로 들어가요. 터미널 출력은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
