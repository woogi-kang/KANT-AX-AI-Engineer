3. GROUP BY로 묶기

달마다 매출을 보려면 WHERE를 바꿔 세 번 쳐야 해요

kant_shop=# SELECT COUNT(*), SUM(pay_amount) FROM enrollments WHERE enroll_month = '2026-09';

count |   sum

-------+---------

   64 | 5265000

(1 row)

kant_shop=# SELECT COUNT(*), SUM(pay_amount) FROM enrollments WHERE enroll_month = '2026-10';

count |   sum

-------+---------

   60 | 4565000

(1 row)

kant_shop=# SELECT COUNT(*), SUM(pay_amount) FROM enrollments WHERE enroll_month = '2026-11';

count |   sum

-------+---------

   63 | 4950000

(1 row)

달이 12개면 12번이에요. 같은 달끼리 묶어서 한 번에 세는 방법이 GROUP BY예요.

3파트는 GROUP BY예요. 9월, 10월, 11월 매출을 따로 보고 싶어요. 지금까지 배운 것으로는 WHERE의 달만 바꿔서 세 번 쳐야 해요. 결과도 세 군데에 흩어져요. 1년치를 보려면 열두 번이에요. 같은 달끼리 묶어서 묶음마다 한 번에 세는 방법이 GROUP BY예요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
