2. COUNT 세 가지와 NULL

취소한 0원도 평균에 들어가요

kant_shop=# SELECT COUNT(*), ROUND(AVG(pay_amount)) AS 평균결제

kant_shop-# FROM enrollments

kant_shop-# WHERE enroll_month = '2026-11';

count | 평균결제

-------+----------

   63 |    78571

(1 row)

kant_shop=# SELECT COUNT(*), ROUND(AVG(pay_amount)) AS 평균결제

kant_shop-# FROM enrollments

kant_shop-# WHERE enroll_month = '2026-11' AND status <> '취소';

count | 평균결제

-------+----------

   57 |    86842

(1 row)

11월 결제 63건

빨간 막대 6개가 취소 건이에요. 금액은 0원이에요.

0원까지 넣어 나누면

4950000 ÷ 63 = 78571

취소를 WHERE로 빼고 나누면

4950000 ÷ 57 = 86842

집계 함수는 NULL만 건너뛰어요. 0은 값이라서 개수에 들어가요.

평균에서 자주 하는 실수예요. 이 데이터는 신청을 취소하면 결제 금액을 0원으로 적어요. 11월 63건 가운데 6건이 0원이에요. AVG는 NULL만 건너뛰고, 0은 값이라서 그대로 개수에 넣어요. 그래서 합계 4950000을 63으로 나눠서 78571이 나와요. 실제로 낸 사람의 평균 결제 금액을 알고 싶으면 WHERE로 취소를 빼요. 57건으로 나눠서 86842가 나와요. 합계는 둘 다 같아요. 0을 더해도 합은 그대로니까요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
