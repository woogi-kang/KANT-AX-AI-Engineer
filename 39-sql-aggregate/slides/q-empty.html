2. COUNT 세 가지와 NULL

고른 줄이 없으면 COUNT는 0, SUM과 MAX는 빈칸이에요

kant_shop=# SELECT COUNT(*), SUM(pay_amount), MAX(pay_amount)

kant_shop-# FROM enrollments

kant_shop-# WHERE enroll_month = '2026-12';

count | sum | max

-------+-----+-----

    0 |     |

(1 row)

COUNT는 0

12월 신청 0줄

더할 값도, 비교할 값도 없어요

COUNT(*)

0

센 줄이 0개라서 0

SUM(pay_amount)

NULL

더할 값이 없어서 빈칸

MAX(pay_amount)

NULL

비교할 값이 없어서 빈칸

psql은 NULL을 빈칸으로 보여 줘요. 매출이 빈칸으로 나오면 먼저 WHERE 조건을 확인해요.

WHERE로 고른 줄이 하나도 없으면 어떻게 될까요. 12월 신청은 아직 없어요. COUNT 별표는 0을 돌려줘요. SUM과 MAX는 더하거나 비교할 값이 없어서 NULL을 돌려줘요. psql은 NULL을 빈칸으로 보여 줘요. 결과가 0줄이 아니라 빈칸이 든 한 줄이라는 점도 봐 둬요. 집계 함수는 줄이 없어도 한 줄을 돌려줘요. 매출이 빈칸으로 나오면 먼저 WHERE 조건이 맞는지 확인해요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
