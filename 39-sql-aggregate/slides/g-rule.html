3. GROUP BY로 묶기

묶지 않은 열은 SELECT에 그냥 적을 수 없어요

kant_shop=# SELECT enroll_month, member_id, COUNT(*)

kant_shop-# FROM enrollments

kant_shop-# GROUP BY enroll_month;

ERROR:  column "enrollments.member_id" must appear in the GROUP BY clause or be used in an aggregate function

LINE 1: SELECT enroll_month, member_id, COUNT(*)

묶음 하나에 member_id가 여러 개라서 한 칸에 무엇을 적을지 정할 수 없어요.

고치는 법: 묶을 열이면 GROUP BY enroll_month, member_id, 세고 싶으면 COUNT(DISTINCT member_id)처럼 집계 함수로 감싸요.

GROUP BY에서 가장 자주 만나는 오류예요. 달로 묶었는데 SELECT에 member_id를 같이 적었어요. 오류 메시지는 member_id가 GROUP BY에 있거나 집계 함수 안에 있어야 한다는 뜻이에요. 그림으로 보면 이유가 보여요. 9월 바구니에는 회원 25번과 10번처럼 여러 회원이 같이 들어 있어요. 결과는 바구니마다 한 줄인데, member_id 칸에 25와 10 중 무엇을 적을지 정할 수 없어요. 그래서 묶지 않은 열은 GROUP BY에 더 적거나, COUNT 같은 집계 함수로 감싸요. 다음 장에 고친 결과가 있어요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
