4. HAVING으로 묶음 고르기

18건 넘는 강좌만 보려고 WHERE에 COUNT를 넣으면 오류가 나요

kant_shop=# SELECT course_id, COUNT(*) AS 누적신청

kant_shop-# FROM enrollments

kant_shop-# WHERE status <> '취소'

kant_shop-# GROUP BY course_id

kant_shop-# ORDER BY 누적신청 DESC, course_id;

18건 이상은 2개

kant_shop=# SELECT course_id, COUNT(*) AS 누적신청

kant_shop-# FROM enrollments

kant_shop-# WHERE status <> '취소' AND COUNT(*) >= 18

kant_shop-# GROUP BY course_id;

ERROR:  aggregate functions are not allowed in WHERE

LINE 3: WHERE status <> '취소' AND COUNT(*) >= 18

                                  ^

WHERE는 줄을 하나씩 볼 때 실행돼요. 그때는 아직 묶음이 없어서 COUNT(*)를 셀 수 없어요.

4파트는 HAVING이에요. 왼쪽은 강좌별로 취소를 뺀 신청 건수예요. 이 중에서 18건 넘는 인기 강좌만 보고 싶어요. 조건이니까 WHERE에 COUNT 별표 18 이상을 적어 봤어요. 오류가 나요. 집계 함수는 WHERE에 쓸 수 없다는 뜻이에요. WHERE는 표의 줄을 하나씩 보면서 거를 때 실행돼요. 그 순간에는 아직 묶음이 없어서 강좌마다 몇 건인지 셀 수 없어요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
