3. GROUP BY로 묶기

SELECT에는 묶은 열과 집계 함수만 적어요

kant_shop=# SELECT enroll_month, COUNT(DISTINCT member_id) AS 회원수

kant_shop-# FROM enrollments

kant_shop-# GROUP BY enroll_month

kant_shop-# ORDER BY enroll_month;

enroll_month | 회원수

--------------+--------

2026-09      |     34

2026-10      |     29

2026-11      |     32

(3 rows)

집계 함수로 감싸기

9월에 신청한 회원 34명

kant_shop=# SELECT enroll_month, COUNT(*) FROM enrollments;

ERROR:  column "enrollments.enroll_month" must appear in the GROUP BY clause or be used in an aggregate function

LINE 1: SELECT enroll_month, COUNT(*) FROM enrollments;

              ^

GROUP BY를 빼먹어도 같은 오류예요

member_id를 COUNT DISTINCT로 감쌌어요. 이제 바구니마다 한 값이 정해져요. 9월에 신청한 회원은 34명이에요. 신청 건수는 64건이었으니 한 사람이 여러 강좌를 신청했다는 뜻이에요. 규칙을 한 줄로 적으면, GROUP BY를 쓴 SELECT에는 묶은 열과 집계 함수만 적어요. 아래처럼 집계 함수 옆에 열을 적고 GROUP BY를 빼먹어도 같은 오류가 나요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
