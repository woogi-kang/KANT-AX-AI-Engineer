집계 SELECT 한 장

report.sql

SELECT

course_id, -- 묶은 열

COUNT(*) AS 신청수, -- 집계 함수

SUM(pay_amount) AS 매출

FROM enrollments

WHERE status <> '취소' -- 줄 거르기

GROUP BY course_id -- 묶기

HAVING COUNT(*) >= 18 -- 묶음 거르기

ORDER BY 신청수 DESC -- 줄 세우기

LIMIT 3;

COUNT(*) COUNT(열) COUNT(DISTINCT 열)

줄 수, NULL 아닌 칸 수, 겹치지 않는 값 수

SUM(열) AVG(열)

합계, 평균. 숫자 열만

MIN(열) MAX(열)

가장 작은 값, 가장 큰 값

ROUND(값, 2) ROUND(값)

소수 둘째 자리까지, 정수로

GROUP BY a, b

a와 b가 모두 같은 줄끼리 묶기

SELECT에는 묶은 열과 집계 함수만 적어요. 집계 함수 조건은 HAVING, 줄 조건은 WHERE예요.

실습할 때 옆에 열어 둘 한 장이에요. 왼쪽은 오늘 배운 절을 다 넣은 SELECT예요. 주석은 절마다 하는 일이에요. WHERE로 줄을 거르고, GROUP BY로 묶고, HAVING으로 묶음을 거르고, ORDER BY로 줄을 세워요. 오른쪽은 집계 함수와 ROUND, 열 두 개로 묶기예요. SELECT에는 묶은 열과 집계 함수만 적는다는 규칙을 기억해요.
