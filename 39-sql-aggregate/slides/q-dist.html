DISTINCT는 36에서 겹친 줄을 지울 때 썼어요. COUNT(DISTINCT region)은 지우고 남은 개수를 세요.

COUNT 괄호 region은 region 칸이 빈 줄만 빼고 세니까 40이에요. 같은 구가 여러 번 나와도 다 세요. 몇 개 구에 회원이 사는지 알고 싶으면 COUNT 괄호 DISTINCT region이에요. 36에서 DISTINCT로 겹친 줄을 지웠어요. 지우고 남은 구가 4개라서 4예요. 오른쪽 위 SELECT DISTINCT 결과의 줄 수와 같아요. 수업 코드에는 COUNT 괄호 DISTINCT 괄호 region처럼 괄호가 하나 더 있었는데, 결과는 같아요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
