4. HAVING으로 묶음 고르기

HAVING에 AS 이름을 적으면 없는 열이라고 나와요

kant_shop=# SELECT course_id, COUNT(*) AS 누적신청

kant_shop-# FROM enrollments

kant_shop-# GROUP BY course_id

kant_shop-# HAVING 누적신청 >= 18;

ERROR:  column "누적신청" does not exist

LINE 4: HAVING 누적신청 >= 18;

              ^

kant_shop-# HAVING COUNT(*) >= 18

kant_shop-# ORDER BY 누적신청 DESC, course_id;

고친 줄 (수업 코드)

HAVING에는 함수를 다시 적어요

ORDER BY는 이름으로 돼요

앞 장의 순서를 실제 오류로 확인해요. HAVING에 AS로 붙인 이름 누적신청을 적었더니 그런 열이 없다고 나와요. HAVING이 실행될 때는 아직 SELECT가 실행되지 않아서 이름이 없어요. HAVING에는 COUNT 별표를 다시 적어요. 수업 코드도 HAVING COUNT 별표 18 이상, ORDER BY 누적신청 DESC로 적었어요. ORDER BY는 SELECT 다음에 실행돼서 이름을 쓸 수 있어요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
