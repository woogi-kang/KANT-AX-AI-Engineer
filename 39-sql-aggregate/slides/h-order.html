그래서

WHERE에는 집계 함수를 못 써요. 아직 안 묶었어요.

HAVING에는 AS 이름을 못 써요. 이름은 그다음 SELECT에서 생겨요.

ORDER BY에는 AS 이름을 써도 돼요. SELECT 다음이에요.

지금까지 나온 절을 모아서 순서를 봐요. 왼쪽은 우리가 적는 순서예요. SELECT가 맨 앞이에요. 그런데 PostgreSQL은 오른쪽 순서로 실행해요. 먼저 FROM으로 표를 고르고, WHERE로 줄을 거르고, GROUP BY로 묶고, HAVING으로 묶음을 거른 다음에야 SELECT로 칸을 골라요. 마지막이 ORDER BY와 LIMIT이에요. 이 순서를 알면 오류 두 가지가 풀려요. WHERE는 묶기 전이라 집계 함수를 못 써요. AS로 붙인 이름은 SELECT에서 생기니까 그 앞의 HAVING에서는 못 쓰고, 뒤의 ORDER BY에서는 써요.
