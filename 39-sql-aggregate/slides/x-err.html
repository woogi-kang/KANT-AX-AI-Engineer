6. 오류와 실제 상황

집계와 GROUP BY에서 나는 오류 네 가지

ERROR 뒤에 나오는 말

왜

고치는 법

must appear in the GROUP BY clause
or be used in an aggregate function

묶지 않은 열을 SELECT에 적었어요

GROUP BY에 더하거나 집계 함수로 감싸요

aggregate functions are not
allowed in WHERE

WHERE에 COUNT, SUM을 적었어요

그 조건은 HAVING으로 옮겨요

column "누적신청" does not exist

HAVING에 AS 이름을 적었어요

HAVING에는 함수를 다시 적어요

function sum(character varying)
does not exist

글자 열을 SUM, AVG에 넣었어요

숫자 열인지 확인해요. 글자는 COUNT, MIN, MAX만

6파트는 오류와 실제 상황 예제예요. 오늘 나온 오류 네 가지를 모았어요. 첫째, 묶지 않은 열을 SELECT에 적으면 GROUP BY에 있거나 집계 함수 안에 있어야 한다고 나와요. 둘째, WHERE에 집계 함수를 적으면 WHERE에서는 못 쓴다고 나와요. HAVING으로 옮겨요. 셋째, HAVING에 AS 이름을 적으면 그런 열이 없다고 나와요. 넷째, 글자 열을 SUM이나 AVG에 넣으면 그런 함수가 없다고 나와요. 다음 장에서 넷째 오류를 직접 봐요.
