6. 오류와 실제 상황

글자 열은 COUNT, MIN, MAX만 돼요. SUM과 AVG는 숫자 열만

kant_shop=# SELECT COUNT(name), MIN(name), MAX(name) FROM members;

count |  min   |  max

-------+--------+--------

   40 | 강시우 | 황민서

(1 row)

kant_shop=# SELECT SUM(name) FROM members;

ERROR:  function sum(character varying) does not exist

LINE 1: SELECT SUM(name) FROM members;

              ^

HINT:  No function matches the given name and argument types. You might need to add explicit type casts.

글자 순서로 가장 앞, 가장 뒤

character varying은 VARCHAR예요(36). 이름을 더하는 함수는 없다는 뜻이에요. HINT는 타입을 바꾸라고 하지만, 이름은 더할 값이 아니니 열을 다시 골라요.

글자 열에도 집계 함수를 쓸 수 있을까요. COUNT 괄호 name은 이름이 있는 회원 수라서 40이에요. MIN과 MAX는 글자 순서로 비교해서 가장 앞인 강시우, 가장 뒤인 황민서를 돌려줘요. SUM 괄호 name은 오류가 나요. character varying은 36에서 배운 VARCHAR예요. VARCHAR를 더하는 SUM 함수는 없다는 뜻이에요. HINT는 타입을 바꿔 보라고 하지만, 이름은 더할 값이 아니에요. 열을 잘못 골랐는지 확인해요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
