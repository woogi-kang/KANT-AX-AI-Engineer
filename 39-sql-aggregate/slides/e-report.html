6. 오류와 실제 상황

실제 상황 1: 취소를 뺀 월별 매출 보고서를 만들어요

kant_shop=# SELECT

kant_shop-#    enroll_month           AS 신청월,

kant_shop-#    COUNT(*)               AS 건수,

kant_shop-#    SUM(pay_amount)        AS 매출,

kant_shop-#    ROUND(AVG(pay_amount)) AS 평균결제

kant_shop-# FROM enrollments

kant_shop-# WHERE status <> '취소'

kant_shop-# GROUP BY enroll_month

kant_shop-# ORDER BY enroll_month;

여기부터는 실제 상황 예제예요. 센터장이 월별 매출 보고서를 달라고 했어요. 취소한 신청은 빼야 해요. WHERE로 취소를 빼고, GROUP BY로 달마다 묶고, 건수, 매출, 평균 결제를 냈어요. 평균은 ROUND로 정수로 줄였어요. 9월은 58건, 매출 5265000원이에요. 앞에서 본 9월 64건 가운데 취소 6건이 빠졌어요. 매출은 그대로예요. 취소는 0원이었으니까요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
