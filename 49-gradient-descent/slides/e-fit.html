5. 오류와 함정

반복문 안에서 fit을 부르면 매번 처음부터 다시 배워요

[3]

sgd = SGDRegressor(loss="squared_error", learning_rate="constant", eta0=0.01,

max_iter=1000, shuffle=False, random_state=42)

for epoch in range(3):

sgd.fit(X, y)

print(epoch + 1, "| w =", round(sgd.coef_[0], 2), "| b =", round(sgd.intercept_[0], 2), "| n_iter_ =", sgd.n_iter_)

[4]

sgd = SGDRegressor(loss="squared_error", learning_rate="constant", eta0=0.01,

max_iter=1, shuffle=False, random_state=42)

for epoch in range(3):

sgd.fit(X, y)

print(epoch + 1, "| w =", round(sgd.coef_[0], 2), "| b =", round(sgd.intercept_[0], 2))

Python

1 | w = 8.46 | b = 2.73

2 | w = 8.46 | b = 2.73

3 | w = 8.46 | b = 2.73

ConvergenceWarning: Maximum number of iteration reached before convergence. Consider increasing max_iter to improve the fit.

← 세 번 다 똑같아요: 427 epoch를 돌고 멈췄다가 다시 처음부터

← 한 바퀴짜리를 세 번 해도 첫 바퀴 값 그대로

더 돌아야 한다는 경고가 fit마다 나와요 (3번)

epoch마다 기록하려면 반복문 안에 partial_fit을 써요.

partial_fit 자리에 fit을 쓰면 어떻게 될까요. 위 셀은 max_iter를 1000으로 두고 fit을 세 번 불렀어요. fit은 부를 때마다 w와 b를 처음 값으로 되돌리고 다시 배워요. 그래서 세 번 모두 427 epoch를 돌고 멈춘 같은 결과예요. n_iter_는 실제로 돈 바퀴 수예요. 427에서 멈춘 건 더 돌아도 손실이 거의 안 줄면 스스로 멈추는 기능 때문인데, 이 수업에서는 다루지 않아요. 아래 셀처럼 max_iter를 1로 두고 fit을 반복하면 한 바퀴짜리를 처음부터 세 번 하는 셈이라 첫 바퀴 값 8.46, 2.73에 머물러요. 바퀴가 모자란다는 ConvergenceWarning도 fit마다 나와요. 경고 앞의 파일 경로는 줄였어요. 출력은 실제로 실행한 결과예요.
