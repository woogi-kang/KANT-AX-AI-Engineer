3. 학습률

SGDRegressor에서는 학습률을 eta0라고 불러요: 0.5면 숫자가 터져요

학습률만 바꿔서 1000 epoch 학습하는 함수예요. 안의 코드는 4파트에서 한 줄씩 봐요.

eta는 그리스 문자 η(에타)예요. 학습률을 적을 때 자주 쓰는 글자이고, 0은 처음 값이라는 뜻이에요.

[4]

def train(eta, epochs=1000):

model = SGDRegressor(loss="squared_error", learning_rate="constant",

eta0=eta, shuffle=False, random_state=42)

losses = []

for epoch in range(epochs):

model.partial_fit(X, y)

losses.append(mean_squared_error(y, model.predict(X)))

return model, losses

for eta in [0.001, 0.01, 0.1, 0.5]:

print("eta0 =", eta, "| w =", round(m.coef_[0], 2), "| b =", round(m.intercept_[0], 2), "| MSE =", round(losses[-1], 2))

오류가 안 나도 MSE가 줄지 않거나 터지면 eta0부터 바꿔 봐요.

이번에는 진짜 SGDRegressor로 학습률을 바꿔 봐요. 위 셀은 19의 함수로, 학습률 eta를 받아 1000 epoch 학습한 모델과 epoch마다의 MSE 리스트를 돌려줘요. SGDRegressor에서는 학습률을 eta0라는 이름으로 넣어요. 0.001은 1000번을 돌아도 MSE가 33이라 아직 내려가는 중이에요. 0.01은 3.25로 LinearRegression의 3.2와 거의 같아요. 0.1은 54에서 멈춰서 더 줄지 않아요. 보폭이 커서 바닥 근처를 계속 넘나드는 거예요. 0.5는 w가 1222억, MSE가 e 플러스 24, 곧 0이 24개 붙은 숫자가 돼요. 오류 메시지는 하나도 안 나와요. 그래서 MSE를 꼭 찍어 봐야 해요. 이 비교는 수업 노트북에 없어서 새 노트북에서 import, 글꼴, 데이터 셀 다음에 실행했어요. 출력은 실제로 실행한 결과예요.
