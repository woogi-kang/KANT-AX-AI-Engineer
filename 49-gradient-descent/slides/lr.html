3. 학습률

학습률은 한 걸음의 크기예요: 0.002, 0.01, 0.1로 다섯 걸음

[12]

for lr in [0.002, 0.01, 0.1]:

w = 8

path = [w]

for step in range(5):

slope = (loss(w + 0.001) - loss(w)) / 0.001

w = w - lr * slope

path.append(round(w, 2))

print("학습률", lr, ":", path)

Python

학습률 0.002 : [8, 8.09, 8.17, 8.25, 8.33, 8.4]

학습률 0.01 : [8, 8.44, 8.78, 9.05, 9.26, 9.42]

학습률 0.1 : [8, 12.4, 7.12, 13.45, 5.85, 14.97]

보폭

← 너무 느려요: 다섯 걸음에 8.4

← 알맞아요: 9.42까지

← 바닥을 넘어 왔다 갔다 해요

0.002: 너무 느려요

0.01: 알맞아요

0.1: 너무 커요

보폭이 작으면 오래 걸리고, 크면 바닥을 넘어가요. 알맞은 크기를 골라야 해요.

새 w는 w 빼기 학습률 곱하기 경사였어요. 학습률은 한 번에 얼마나 크게 걸을지 정하는 숫자, 곧 보폭이에요. 앞 장의 다섯 걸음을 학습률만 바꿔서 다시 걸어 봐요. 0.002는 다섯 걸음에 8.4까지밖에 못 가서 너무 느려요. 0.01은 9.42까지 차근차근 내려가요. 0.1은 첫 걸음에 바닥 10을 지나 12.4까지 가고, 다음에는 7.12로 돌아오며 왔다 갔다 해요. 아래 그림의 주황 선이 다섯 걸음의 길이에요. 보폭이 너무 작으면 오래 걸리고, 너무 크면 바닥을 넘어가서 오히려 멀어져요. 이 셀도 이해를 돕는 연습이에요. 출력은 실제로 실행한 결과예요. 그림의 점과 선은 같은 5명 데이터로 계산해서 그렸어요.
