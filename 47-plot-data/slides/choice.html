4. 연습 데이터 만들기

choice(n, 5, replace=False): 0~199 중 겹치지 않게 5개

special = rng.choice(n, 5, replace=False)

n0부터 n-1까지 번호 중에서 (0~199)

55개를 뽑아요

replace=False뽑은 번호는 다시 안 넣어요

[8]

rng = np.random.default_rng(1)

print(rng.choice(10, 5, replace=False))

print(rng.choice(10, 5, replace=True))

Python

[3 0 6 8 2]

[3 8 4 2 8]

← True면 8이 두 번 나올 수 있어요

← False는 모두 달라요

수업 셀의 결과

[ 17 134 178 172 122]

특이 매물이 될 행 번호 5개예요. 같은 집을 두 번 고르면 4건만 되니 False로 막았어요.

choice는 번호 중에서 몇 개를 뽑아요. 첫째 자리에 숫자 n을 넣으면 0부터 n-1까지의 번호 중에서 뽑아요. n이 200이라 0번부터 199번 행 중에서예요. 둘째 자리는 뽑을 개수예요. replace는 뽑은 번호를 다시 넣을지예요. 공을 뽑고 다시 상자에 넣으면 같은 공이 또 나올 수 있어요. 왼쪽 아래 셀에서 True로 뽑으니 8이 두 번 나왔어요. 특이 매물은 서로 다른 집 다섯 채여야 해서 False로 뽑았어요. 수업 셀에서는 17, 134, 178, 172, 122번이 뽑혔어요. 출력은 실제로 실행한 결과예요.
