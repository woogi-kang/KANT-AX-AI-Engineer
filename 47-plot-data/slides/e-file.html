FileNotFoundError: [Errno 2] No such file or directory: 'usa_housing.csv'

No such file or directory: 그런 파일이나 폴더가 없대요. 노트북 옆에서 usa_housing.csv를 찾았어요.

✕

pd.read_csv("usa_housing.csv")

✓

pd.read_csv("datasets/usa_housing.csv")

파일 경로를 틀리면 FileNotFoundError가 나요. 경로에 파일 이름만 적으면 노트북 파일이 있는 폴더에서 찾아요. 실제 파일은 그 안의 datasets 폴더에 있어서 못 찾은 거예요. 폴더 이름까지 datasets/usa_housing.csv로 적으면 돼요. 파일을 다운로드 폴더에 그대로 두었거나 폴더 이름의 철자가 다를 때도 같은 오류가 나요. VS Code 왼쪽 탐색기에서 파일 위치를 먼저 확인해요. 이 셀만 새 노트북에서 실행해서 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
