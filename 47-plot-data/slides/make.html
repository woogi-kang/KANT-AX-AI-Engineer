4. 연습 데이터 만들기

연습 데이터를 만드는 셀 하나를 줄마다 봐요

[7]

rng = np.random.default_rng(42)

 

n = 200

area = rng.uniform(20, 85, n)

price = area * 450 + 5000 + rng.normal(0, 2500, n).round(-1)

 

special = rng.choice(n, 5, replace=False)

price[special] += rng.uniform(15000, 25000, 5).round(-1)

 

office = pd.DataFrame({"area": area, "price": price})

office.describe().round(1)

← 20~85 사이 면적 200개

← 정답 규칙 + 흔들림

← 특이 매물 5건 값 올리기

← 표로 묶고 요약

같은 시드 42면 이 숫자가 그대로 나와요.
결과 표는 29쪽에서 읽어요. 다음 장부터 한 줄씩 봐요.

수업에서 연습 데이터를 만든 셀 전체예요. 다음 장부터 한 줄씩 자세히 보니까 여기서는 흐름만 봐요. 첫 줄은 난수를 만드는 기계를 시드 42로 만들어요. 면적 200개를 20부터 85 사이에서 뽑고, 가격은 정답 규칙에 흔들림을 더해 계산해요. 그다음 다섯 건을 골라 값을 크게 올려 특이 매물을 만들어요. 마지막으로 두 배열을 DataFrame으로 묶고 describe로 요약해요. 셀 번호 [7]은 앞의 산점도 셀 다음이라서예요. 출력은 실제로 실행한 결과예요.
