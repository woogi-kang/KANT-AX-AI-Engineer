4. 연습 데이터 만들기

uniform(20, 85, n): 20부터 85 사이에서 고르게 n개

area = rng.uniform(20, 85, n)

20 가장 작은 값 (low)

85 이 값 바로 아래까지 (high)

n 몇 개 뽑을지 (size). n = 200

실제로 뽑은 면적 200개예요. 가장 작은 값 20.5, 가장 큰 값 84.5로 20~85 사이에 고르게 퍼졌어요.

점의 높이는 겹치지 않게 흩어 놓은 것이고 뜻은 없어요.

uniform은 정해진 범위 안에서 어느 값이나 똑같은 확률로 뽑는 함수예요. 첫째 자리 20은 가장 작은 값, 둘째 자리 85는 가장 큰 쪽 끝이고, 85 자체는 나오지 않고 바로 아래까지예요. 셋째 자리는 몇 개를 뽑을지예요. 위에서 n = 200으로 정해 둬서 200개가 나와요. 개수를 변수로 두면 나중에 데이터 크기를 바꿀 때 한 곳만 고치면 돼요. 오피스텔 면적이 20제곱미터에서 85제곱미터 사이라고 보고 이 범위를 골랐어요. 아래 점은 실제로 뽑은 200개이고 고르게 퍼져 있어요.
