한 장으로 보는 오늘의 코드

불러오기

from sklearn.linear_model import LinearRegression

빈 모델

model = LinearRegression()

문제와 정답

X = df[["열"]] y = df["정답 열"]

학습

model.fit(X, y)

배운 값

model.coef_[0] model.intercept_

예측

model.predict(pd.DataFrame({"열": [값]}))

채점 불러오기

from sklearn.metrics import mean_absolute_error, ...

평균 오차

mean_absolute_error(y, y_pred)

설명 정도

r2_score(y, y_pred) 0 ~ 1

줄 고르기

mask = np.ones(n, dtype=bool)

만들고, fit(문제, 정답), predict(같은 모양 표), 채점(정답, 예측).
다음: 학습용과 채점용 데이터를 나누고, 입력 열을 늘려 봐요.

오늘 쓴 코드를 한 장에 모았어요. 왼쪽은 학습과 예측, 오른쪽은 채점이에요. 순서는 네 박자예요. 모델을 만들고, fit에 문제와 정답을 넣고, predict에 학습 때와 같은 모양의 표를 넣고, 채점 함수에 정답과 예측을 넣어요. 다음 수업에서는 학습에 쓴 데이터와 채점에 쓰는 데이터를 나누고, 면적 말고 다른 열도 입력으로 넣어 봐요.
