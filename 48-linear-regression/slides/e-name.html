5. 오류와 함정

열 이름이 다르면: The feature names should match

[7]

model.predict(pd.DataFrame({"size": [33, 59]}))

Python

ValueError: The feature names should match those that were passed during fit.

Feature names unseen at fit time:

- size

Feature names seen at fit time, yet now missing:

- area

fit 때 못 본 이름 size가 있고, fit 때 본 이름 area가 없다고 알려 줘요.

[6]

model.predict([[33], [59]])

Python

UserWarning: X does not have valid feature names, ...

array([20095.21121907, 32202.72370413])

리스트를 두 겹으로 넣으면 계산은 되지만 경고가 나와요. 수업처럼 열 이름이 같은 DataFrame으로 넣어요.

표를 넣었는데 열 이름을 area가 아닌 size로 적으면 또 오류가 나요. 메시지가 친절해요. fit 때 못 본 이름 size가 있고, fit 때 본 이름 area가 없다고 나란히 알려 줘요. 모델은 열 이름으로 어느 값이 면적인지 알아보기 때문이에요. 아래 셀처럼 리스트를 두 겹으로 감싸 넣으면 표 모양이라 계산은 돼요. 그래도 이름이 없다는 경고가 나와요. 열이 여러 개가 되면 순서가 섞여도 모르니, 수업처럼 같은 열 이름의 DataFrame으로 넣는 습관을 들여요. 경고 줄은 줄여 적었어요. 출력은 실제로 실행한 결과예요.
