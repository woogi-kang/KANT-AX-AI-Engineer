from 패키지.모듈 import 클래스: 서랍에서 설계도를 꺼내요

from sklearn.linear_model import LinearRegression

sklearn

패키지

scikit-learn을 코드에서 부르는 이름

linear_model

모듈 (서랍)

직선으로 예측하는 모델을 모아 둔 파일

LinearRegression

클래스 (설계도)

선형 회귀 모델을 만드는 틀. 대문자로 시작해요(24)

28에서 배운 모양

from cart import Cart

점 하나만 더 붙었어요. 패키지 안 모듈이라서예요.

첫 줄을 조각으로 나눠 봐요. sklearn은 패키지 이름이에요. 점 뒤의 linear_model은 그 안의 모듈로, 직선으로 예측하는 모델을 모아 둔 서랍이에요. import 뒤의 LinearRegression이 실제로 쓸 클래스, 곧 모델의 설계도예요. 24에서 클래스 이름은 대문자로 시작한다고 배웠죠. 28의 from 모듈 import 이름과 같은 모양이고, 패키지 안의 모듈이라 점이 하나 더 붙었어요. 영어 뜻 그대로 Linear는 직선, Regression은 숫자를 예측하는 일이에요.
