fit 전에 predict하면: is not fitted yet

[3]

from sklearn.linear_model import LinearRegression

 

model = LinearRegression()

new = pd.DataFrame({"area": [33, 59]})

model.predict(new)

Python

NotFittedError: This LinearRegression instance is not fitted yet. Call 'fit' with

appropriate arguments before using this estimator.

아직 학습(fit)하지 않은 모델이에요. 빈 모델에는 w와 b가 없어서 예측할 수 없어요.

✕

model.predict(new)

✓

model.fit(X, y) # 먼저

노트북을 다시 열면 모델도 처음부터예요. 맨 위 셀부터 차례로 실행해요.

모델을 만들자마자 predict하면 NotFittedError가 나요. 이 LinearRegression 객체는 아직 학습되지 않았으니 fit을 먼저 부르라는 뜻이에요. 2파트에서 본 빈 모델 그림처럼 기울기와 절편 자리가 비어 있어서 계산할 수 없어요. 노트북을 껐다 켜거나 커널을 다시 시작하면 변수가 모두 사라지니 모델도 다시 학습해야 해요. 맨 위 셀부터 차례로 실행하면 돼요. 이 셀만 새 노트북에서 실행해서 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
