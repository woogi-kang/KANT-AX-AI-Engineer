3. 채점하기

채점 함수는 모두 (정답, 예측) 순서로 넣어요

mean_absolute_error(y, y_pred)

첫째: 정답 (y_true)

둘째: 예측 (y_pred)

[7]

print("MAE", mean_absolute_error(y, y_pred), mean_absolute_error(y_pred, y))

print("R2 ", r2_score(y, y_pred), r2_score(y_pred, y))

MAE, MSE, RMSE는 순서를 바꿔도 같지만 R²는 달라져요. 오류가 안 나서 틀린 줄 모르니 늘 정답부터 적어요.

import 줄 하나에 쉼표로 넷을 불러와요(28). 수업 셀의 :,.0f는 13에서 배운 천 단위 쉼표와 소수 0자리예요.

채점 함수 넷은 괄호 안 순서가 같아요. 첫째 자리에 정답 y, 둘째 자리에 예측 y_pred를 넣어요. scikit-learn 설명서에도 y_true, y_pred 순서로 적혀 있어요. 순서를 바꾸면 어떻게 될까요? 이 셀은 일부러 바꿔서 둘을 나란히 찍었어요. MAE는 절댓값이라 같지만, R제곱은 0.804가 0.756으로 바뀌어요. 오류 메시지가 없어서 틀린 줄도 모르게 돼요. 그러니 늘 정답부터 적어요. 수업 셀의 콜론 쉼표 점 0 f는 13에서 배운 천 단위 쉼표와 소수점 아래 0자리 포맷이에요. 출력은 실제로 실행한 결과예요.
