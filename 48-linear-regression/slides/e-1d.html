5. 오류와 함정

fit에 X를 한 줄로 넣으면: Expected a 2-dimensional container

[5]

model.fit(office["area"], office["price"])

Python

ValueError: Expected a 2-dimensional container but got <class 'pandas.Series'>

instead. Pass a DataFrame containing a single row (i.e. single sample) or a

single column (i.e. single feature) instead.

2차원(표)이 와야 하는데 Series(한 줄)가 왔다는 뜻이에요. 열 하나짜리 DataFrame을 넣으래요.

✕

model.fit(office["area"], ...)

✓

model.fit(office[["area"]], ...)

fit(y, X)처럼 순서를 바꿔도 첫째 자리에 한 줄이 들어가서 같은 오류가 나요.

가장 자주 나는 오류예요. fit 첫째 자리에 대괄호 한 겹으로 꺼낸 Series를 넣었어요. 메시지의 첫 줄을 읽으면 2차원 컨테이너, 곧 표가 와야 하는데 pandas Series가 왔다고 해요. 뒤에는 열 하나짜리 DataFrame을 넣으라고 알려 줘요. 고치는 법은 대괄호를 두 겹으로 바꾸는 거예요. fit의 X와 y 순서를 바꿔 적어도 첫째 자리에 한 줄이 들어가서 같은 오류가 나요. 메시지가 길면 첫 줄의 Expected 뒤만 읽어도 돼요. 오류 메시지는 화면 폭에 맞춰 세 줄로 나눠 적었어요. 출력은 실제로 실행한 결과예요.
