6. 실제 상황

미국 집값 300채는 면적만으로 R²가 0.007, 거의 설명하지 못해요

[4]

from sklearn.linear_model import LinearRegression

from sklearn.metrics import r2_score

 

hm = LinearRegression()

hm.fit(house[["SquareFeet"]], house["Price"])

p300 = hm.predict(house[["SquareFeet"]])

print("300채 R2:", round(r2_score(house["Price"], p300), 3))

Python

300채 R2: 0.007

[5]

sm = LinearRegression()

sm.fit(small[["SquareFeet"]], small["Price"])

p10 = sm.predict(small[["SquareFeet"]])

print("10채 R2:", round(r2_score(small["Price"], p10), 2))

p_all = sm.predict(house[["SquareFeet"]])

print("10채 직선으로 300채:", round(r2_score(house["Price"], p_all), 2))

Python

10채 R2: 0.8

10채 직선으로 300채: -0.85

세로축 1e6은 ×1,000,000이에요. 1.0이 100만 달러예요.

47의 상관계수 0.08과 0.89를 제곱한 것과 같은 이야기예요. 골라낸 10채로 배운 빨간 직선은 300채에서 평균보다도 못해요.

47에서 본 미국 집값 300채로도 학습해 봐요. 면적으로 가격을 예측하면 R제곱이 0.007이에요. 47에서 상관계수가 0.08이었으니 제곱하면 거의 0이죠. 파란 직선이 거의 누워 있어요. 이 데이터는 면적만으로는 가격을 설명할 수 없어요. 2015년 이후에 지은 10채만 골라서 학습하면 R제곱이 0.8로 좋아 보여요. 그런데 그 빨간 직선으로 300채 전체를 예측하면 마이너스 0.85, 평균만 찍는 것보다 못해요. 일부만 골라서 배운 모델은 전체에서 맞지 않을 수 있어요. 그래서 다음 수업에서는 학습용과 채점용 데이터를 나눠요. 이 노트북은 house와 small을 47처럼 먼저 만들었어요. 출력은 실제로 실행한 결과예요. 그래프는 리눅스 커널이 그려서 맑은 고딕 대신 나눔고딕으로 나왔어요.
