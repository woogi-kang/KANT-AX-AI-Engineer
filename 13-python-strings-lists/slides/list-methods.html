cart.append("cake")

cart.insert(0, "tea")

cart.remove("latte")

last = cart.pop()

first = cart.pop(0)

print(cart, last, first)

리스트 이름 뒤에 점을 찍고 쓰는 함수를 메서드라고 불러요. append는 맨 뒤에 더하고, insert(0, "tea")는 0번 자리에 끼워요. 끼운 자리 뒤의 값은 한 칸씩 밀려요. remove는 값을 찾아 지워요. pop()은 맨 뒤를, pop(0)은 0번을 빼서 돌려줘요. 돌려준 값은 last, first처럼 변수에 담을 수 있어요. 오른쪽 칸은 줄마다 cart에 담긴 값이에요.
