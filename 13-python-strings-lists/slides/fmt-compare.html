f-string은 이름을 적어요

세 방식 모두 콜론 뒤에 적는 모양은 같아요. format()은 콜론 앞에 번호를, f-string은 변수 이름을 적어요. % 방식은 %5d처럼 % 뒤에 바로 모양을 적고, 콤마 옵션이 없어요. 새 코드는 f-string 칸만 기억하면 돼요. 아래 셀은 format()으로 실제로 실행한 결과예요.
