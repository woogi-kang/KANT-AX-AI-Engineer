1파트 문자열과 같은 문법

word[0]

↔

menus[0]

word[-1]

↔

menus[-1]

word[0:2]

↔

menus[0:2]

리스트도 문자열처럼 번호로 꺼내고 콜론으로 잘라요. 번호는 0부터예요. menus[0]은 coffee, menus[-1]은 맨 뒤 cake예요. menus[0:2]는 0번 선부터 2번 선까지라 coffee와 latte예요. 리스트를 자르면 결과도 리스트라서 대괄호에 담겨 나와요. 1파트의 word[0], word[0:2]와 같은 문법이에요.
