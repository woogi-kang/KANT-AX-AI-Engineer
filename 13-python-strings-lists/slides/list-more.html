2. 리스트와 튜플

리스트를 잇고, 뒤집고, 복사하고, 비워요

[9]

a = [3, 1, 2]

b = [5, 4]

print(a + b, a * 2)

a.extend(b)

print(a)

print(sorted(a), a)

a.reverse()

print(a)

c = a.copy()

c.clear()

print(a, c)

a + b a * 2

두 리스트를 이은 새 리스트, 두 번 반복한 새 리스트

a.extend(b)

a 뒤에 b를 이어 붙여요. a가 바뀌어요

sorted(a)

정렬한 새 리스트를 돌려줘요. a는 그대로

a.reverse()

a를 거꾸로 뒤집어요. 정렬이 아니라 순서만 뒤집기

a.copy() c.clear()

복사본을 만들고, 복사본만 비워요. a는 그대로

리스트를 다룰 때 자주 쓰는 것들을 더 봐요. + 는 두 리스트를 이어 붙인 새 리스트를, * 는 반복한 새 리스트를 만들어요. 12의 3파트에서 본 글자의 + 와 * 와 같은 모양이에요. extend는 a 자체에 b를 이어 붙여서 a가 바뀌어요. sorted는 sort와 달리 정렬한 새 리스트를 돌려주고 a는 그대로 둬요. 그래서 print(sorted(a), a)의 뒤쪽 a는 정렬 전 모양이에요. reverse는 크기와 상관없이 순서만 거꾸로 뒤집어요. copy는 복사본을 만들어요. 복사본 c를 clear로 비워도 a는 그대로 남아요. 출력은 실제로 실행한 결과예요.
