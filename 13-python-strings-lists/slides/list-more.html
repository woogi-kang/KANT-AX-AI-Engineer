2. 리스트, 튜플, for

새 리스트를 만드는 것과 원래 리스트를 바꾸는 것

[8]

a = [3, 1, 2]

b = [5, 4]

print(a + b, a * 2)

print(sorted(a), a)

a.extend(b)

a.reverse()

c = a.copy()

c.clear()

print(a, c)

[1, 2, 3] [3, 1, 2]

새 리스트

a + b a * 2 이어 붙이기

새 리스트

sorted(a) 정렬, a는 그대로

원래 것이 바뀜

a.extend(b) a 뒤에 b를

원래 것이 바뀜

a.reverse() 순서만 거꾸로

새 리스트

a.copy() 복사본

원래 것이 바뀜

c.clear() 전부 비우기

괄호에 넣는 함수와 +, *는 새 리스트를 만들고, 점으로 부르는 메서드는 원래 리스트를 바꿔요. a + b는 두 리스트를 이은 새 리스트, a * 2는 두 번 반복한 새 리스트예요. sorted(a)는 정렬한 새 리스트를 돌려주고 a는 그대로예요. a.sort()는 a 자체를 바꿔요. extend는 a 뒤에 b를 이어 붙이고, reverse는 순서만 거꾸로 해요. copy는 복사본을 만들어서 c를 비워도 a는 그대로예요.
