중간 세대예요

파이썬 3.6부터 (2016년)

요즘 표준. 새 코드는 이걸로 써요

세 줄 모두 결과가 같아요. 이 챕터는 % 와 f-string을 나란히 봐요.

문자열 안에 변수 값을 끼워 넣는 방법은 세 가지예요. 셀의 세 줄은 실제로 실행하면 똑같은 문장을 출력해요. % 포맷팅은 C 언어에서 가져온 가장 오래된 방식이라 옛 코드, 오래된 책, 블로그에서 많이 보여요. format()은 파이썬 3.0에서 나온 중간 세대예요. f-string은 파이썬 3.6에서 나왔고 지금 표준이에요. 따옴표 앞에 f를 붙이고 중괄호 안에 변수 이름을 바로 적어서 가장 읽기 쉬워요. 새로 짜는 코드는 f-string으로 쓰고, % 는 남의 코드를 읽을 수 있을 만큼 알아 둬요. 다음 장부터 모든 예시를 % 와 f-string으로 나란히 실행해요.
