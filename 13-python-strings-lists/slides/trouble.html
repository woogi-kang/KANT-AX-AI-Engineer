막히면 오류의 마지막 줄을 봐요

1

IndexError: list index out of range

없는 번호를 꺼냈어요

마지막은 len() - 1

2

TypeError: not enough arguments for format string

% 자리 수와 값 수가 달라요

f-string으로

3

ValueError: list.remove(x): x not in list

리스트에 없는 값을 지우려 했어요

in 으로 먼저 확인

4

TypeError: 'tuple' object does not support item assignment

튜플은 담은 뒤 바꿀 수 없어요

바꿀 값은 리스트로

5

SyntaxError: expected ':'

for 줄 끝에 콜론이 없어요

for x in xs:

6

IndentationError: expected an indented block after 'for' statement on line 1

for 안쪽 줄을 들여 쓰지 않았어요

네 칸 들여쓰기

오류가 나면 위쪽 Traceback보다 맨 아래 줄부터 읽어요.

오류 메시지는 길어도 맨 아래 한 줄에 원인이 있어요. 1번은 리스트나 문자열에서 없는 번호를 꺼냈을 때예요. 값이 세 개면 마지막 번호는 2예요. 2번은 % 포맷팅의 자리 수와 값 수가 다를 때예요. f-string으로 쓰면 이 오류가 없어요. 3번은 remove로 없는 값을 지울 때, 4번은 튜플 값을 바꾸려 할 때예요. 5번과 6번은 for 줄의 콜론과 들여쓰기예요. 오류 메시지 뒤 괄호 안의 위치 표시는 빼고 옮겼어요. 위 출력은 모두 hello-uv 커널에서 실제로 실행한 결과의 마지막 줄이에요.
