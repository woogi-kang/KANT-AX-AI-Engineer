정리

막히면 오류의 마지막 줄부터 읽어요

IndexError: ... index out of range

없는 번호예요. 마지막 번호는 len() - 1

TypeError: not enough arguments for format string

% 자리 수와 값 수가 달라요. f-string으로

ValueError: unsupported format character ','

% 에는 콤마가 없어요. f"{price:,}"

ValueError: list.remove(x): x not in list

없는 값을 지우려 했어요. in으로 먼저 확인

TypeError: 'tuple' object does not support item assignment

튜플과 문자열은 못 바꿔요. 리스트에 담아요

SyntaxError: expected ':'

for 줄 끝에 콜론

IndentationError: expected an indented block ...

되풀이할 줄을 네 칸 들여 쓰기

오류가 나면 위쪽 Traceback보다 맨 아래 줄을 먼저 읽어요. 마지막 줄에 오류 이름과 이유가 있어요. IndexError는 없는 번호, TypeError는 타입이 안 맞거나 바꿀 수 없는 값을 바꾸려 할 때예요. ValueError는 값이 안 맞을 때예요. SyntaxError와 IndentationError는 문법과 들여쓰기 문제예요.
