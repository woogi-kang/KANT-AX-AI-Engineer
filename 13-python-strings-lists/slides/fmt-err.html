1. 문자열과 출력

자리와 값이 안 맞으면 오류가 나요

[14]

"%d개" % "kim"

TypeError: %d format: a real number is required, not str

%d 자리에 글자를 넣었어요

%s 로 바꾸거나 f-string으로

[15]

"%s %d개" % cake

TypeError: not enough arguments for format string

자리는 둘인데 값은 하나예요

% (cake, qty) 처럼 값을 다 적어요

[16]

f"{cake:d}"

ValueError: Unknown format code 'd' for object of type 'str'

글자에 정수 모양 d를 줬어요

{cake} 만 적어요

[17]

"%,d" % price

ValueError: unsupported format character ',' (0x2c) at index 1

% 방식에는 콤마 옵션이 없어요

f"{price:,}" 로 써요

% 방식은 자리 수와 값 수, 자리 모양과 값의 타입이 맞아야 해요. %d 자리에 글자를 넣으면 TypeError가 나요. 자리는 둘인데 값이 하나여도 TypeError예요. f-string도 글자에 d 모양을 주면 ValueError가 나요. % 방식에는 콤마 옵션이 없어서 %,d는 ValueError예요. 오류가 나면 마지막 줄을 먼저 읽어요. 출력은 실제로 실행한 결과에서 Traceback의 마지막 줄만 옮겼어요.
