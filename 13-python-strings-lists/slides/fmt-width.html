글자 오른쪽 맞춤. f-string은 > 를 붙여요

f-string에서 글자는 기본이 왼쪽 맞춤이에요. {'kim':5}는 [kim ]이 돼요.

% 와 d 사이, 또는 f-string의 콜론 뒤에 숫자를 넣으면 그만큼 칸을 확보해요. 대괄호는 칸이 보이게 일부러 붙였어요. 42는 두 글자라서 다섯 칸을 채우려고 빈칸 세 개가 붙어요. 왼쪽 맞춤은 % 에서는 - 를, f-string에서는 < 를 붙여요. 0을 붙이면 빈칸을 0으로 채워 00042처럼 번호표 모양이 돼요. 한 가지 다른 점이 있어요. % 방식은 글자도 오른쪽 맞춤인데, f-string은 글자가 기본으로 왼쪽 맞춤이라서 {'kim':5}는 [kim ]이 돼요. 오른쪽으로 보내려면 > 를 붙여요. f-string 안에서 글자를 쓸 땐 바깥 큰따옴표와 겹치지 않게 작은따옴표로 감쌌어요. 모두 실제로 실행한 결과예요.
