2. 리스트, 튜플, for

튜플은 ( )에 묶고, 만든 뒤에는 못 바꿔요

[11]

order = ("coffee", 4500, 2)

print(order[0])

print(order[1] * order[2])

print(order[1:])

print(type(order))

coffee

(4500, 2)

<class 'tuple'>

꺼내고 자르는 건 리스트와 같아요

order

'coffee'

4500

2

[12]

order[1] = 5000

TypeError: 'tuple' object does not support item assignment

바꾸기는 안 돼요

주문 한 건, 날짜처럼 묶어 두고 바꾸지 않을 값은 튜플에 담아요.

튜플은 소괄호로 값 여러 개를 묶고, 만든 뒤에는 바꿀 수 없어요. 꺼내기, 자르기, 계산은 리스트와 똑같아요. order[1] = 5000처럼 바꾸려 하면 TypeError가 나요. 주문 한 건의 메뉴, 가격, 수량처럼 한 묶음으로 두고 바꾸지 않을 값에 써요. 1파트의 % (cake, qty)에서 괄호로 묶은 것도 튜플이었어요.
