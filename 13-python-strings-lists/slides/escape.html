Windows 키보드에서는 \ 가 ₩ 로 보여요. 같은 키예요.

따옴표 안에서 역슬래시 \ 뒤의 글자는 특별한 뜻이 돼요. \n은 줄바꿈이라 print 한 번으로 두 줄이 나와요. \t는 탭이라 칸을 띄워요. 역슬래시 자체를 쓰려면 \\처럼 두 번 적어요. Windows 경로를 적을 때 자주 만나요. 한글 Windows 키보드와 글꼴에서는 역슬래시가 원화 표시로 보이는데, 같은 키예요. 출력은 실제로 실행한 결과예요.
