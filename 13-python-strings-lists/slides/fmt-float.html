전체 칸 수

.2

소수점 아래 자리

f

실수

0은 최소 칸 수라 영향이 없어서 0.2f 와 .2f 는 결과가 같아요.

실수는 소수점 아래 자리 수를 정해서 보여 줄 수 있어요. % 방식은 %.2f, f-string은 {pi:.2f}처럼 적어요. 둘 다 점 뒤 숫자가 소수점 아래 자리 수예요. %f 하나만 쓰면 여섯 자리까지 나와요. .4f는 다섯째 자리에서 반올림해 3.1416이 돼요. %0.2f에서 점 앞의 0은 앞 장의 전체 칸 수예요. 최소 0칸이라 영향이 없어서 .2f와 결과가 같아요. 8.2f는 여덟 칸을 확보하고 소수점 아래 두 자리를 보여 줘요. 점도 한 칸으로 세요. 원래 pi 값은 바뀌지 않고 보여 주는 모양만 바뀌어요. 2.675를 .2f로 보이면 2.67이 나오는 것처럼 반올림이 가끔 어긋나는 건 컴퓨터가 소수를 저장하는 방식 때문이에요.
