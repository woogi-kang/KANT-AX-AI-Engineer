1. 문자열과 출력

format()은 {0} {1} {2} 번호로 값을 넣어요

[11]

cake = "치즈케이크"

price = 5000

qty = 2

print("주문내역은 : {0}, {1}, {2}".format(cake, price, qty))

print("주문내역은 : {}, {}, {}".format(cake, price, qty))

print("{0} {2}개, 하나에 {1}원".format(cake, price, qty))

print("{0}, {0}, {0}".format(cake))

{0}

cake

0번째 값 → 치즈케이크

{1}

price

1번째 값 → 5000

{2}

qty

2번째 값 → 2

번호는 0부터 세요. 번호를 비우면 순서대로, 번호를 쓰면 순서를 바꾸거나 여러 번 쓸 수 있어요.

가운데 세대인 format() 방식이에요. 문자열 안에 중괄호와 번호로 빈자리를 만들고, 뒤에 .format(괄호)를 붙여 값을 순서대로 적어요. 번호는 0부터 세요. cake가 0번, price가 1번, qty가 2번이라서 {0}, {1}, {2}에 차례로 들어가요. 둘째 줄처럼 번호를 비우면 적은 순서대로 들어가요. 셋째 줄은 번호로 순서를 바꿨어요. 넷째 줄은 {0}을 세 번 써서 같은 값을 여러 번 넣었어요. % 방식은 자리 순서와 값 순서가 꼭 같아야 해서 이렇게 못 해요. 모두 실제로 실행한 결과예요.
