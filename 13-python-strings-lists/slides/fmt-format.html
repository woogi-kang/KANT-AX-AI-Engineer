format()은 중괄호 안 번호로 괄호 안의 값을 골라요. 번호는 0부터 세요. {0}은 cake, {1}은 price, {2}는 qty예요. 번호를 바꾸면 값의 순서를 바꿀 수 있어요. {0}을 여러 번 쓰면 같은 값이 여러 번 들어가요. 번호를 비우고 {}만 쓰면 순서대로 들어가요. 옛 코드에서 자주 보이니 읽을 수 있을 만큼 알아 둬요.
