%-6s

{:<6}

여섯 칸 왼쪽 맞춤 (이름)

%5d

{:5d}

다섯 칸 오른쪽 맞춤 (점수)

%%

%

% 글자 그대로. % 방식만 두 번 적어요

성적표, 영수증처럼 줄을 맞춰 보여 줄 때 칸 수를 써요.

칸 수 확보를 표에 써 봐요. 이름은 여섯 칸 왼쪽 맞춤, 점수는 다섯 칸 오른쪽 맞춤이에요. 이름 길이와 점수 자리 수가 달라도 점수 끝자리가 한 줄로 서요. 사람 이름은 팀 실습의 kim, lee, park을 썼어요. % 방식에서 % 글자 자체를 보이려면 %%처럼 두 번 적어요. 한 번만 적으면 끼워 넣을 자리로 읽어요. f-string은 % 를 그냥 적으면 돼요. 대신 f-string에서 중괄호 자체를 보이려면 {{ }}처럼 두 번 적어요. 출력은 두 셀을 실제로 실행한 결과예요.
