1. 문자열과 출력

print의 sep, end와 \n, \t로 출력 모양을 바꿔요

[5]

print("kim", "lee")

print("kim", "lee", sep="-")

print("2026", "11", "02", sep=".")

print("hello", end=" ")

print("world")

print("첫째 줄\n둘째 줄")

print("이름\tkim")

kim lee

kim-lee

2026.11.02

hello world

첫째 줄

둘째 줄

이름 kim

sep 값 사이에 넣을 글자. 기본은 빈칸

end 줄 끝에 붙일 글자. 기본은 줄바꿈

\n 줄바꿈

\t 탭, 칸 띄우기

print의 sep은 값 사이에, end는 줄 끝에 붙는 글자예요. sep의 기본값은 빈칸이에요. 12에서 print("설명", 값)이 빈칸으로 이어진 이유예요. sep="-"면 kim-lee가 돼요. end의 기본값은 줄바꿈이에요. end=" "로 바꾸면 다음 print가 같은 줄에 이어져요. 따옴표 안의 \n은 줄바꿈, \t는 탭이에요. Windows 키보드에서는 역슬래시가 원화 기호로 보여요. 같은 키예요.
