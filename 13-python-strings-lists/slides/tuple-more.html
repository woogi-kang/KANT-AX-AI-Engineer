튜플의 메서드는 둘뿐이에요. 바꾸는 메서드가 없어요

year, month, day = date

튜플 값을 변수 여러 개에 한 번에 꺼내 담아요

a, b = b, a

두 변수의 값을 맞바꿔요. lee kim

list(date) tuple(cart)

튜플을 리스트로, 리스트를 튜플로 바꿔요

날짜, 좌표, 주문 한 건처럼 바뀌지 않는 한 묶음은 튜플에 담아요.

튜플은 바꿀 수 없어서 메서드가 count와 index 둘뿐이에요. append, remove, sort 같은 바꾸는 메서드는 없어요. 튜플 값은 year, month, day = date처럼 이름을 나란히 적어 한 번에 꺼내 담아요. 이 모양으로 a, b = b, a를 쓰면 두 변수 값을 맞바꿀 수 있어요. 오른쪽 b, a가 먼저 ('lee', 'kim') 묶음이 되고, 그 값이 왼쪽 a, b에 나눠 들어가요. 튜플 값을 고쳐야 하면 list()로 바꿔서 고쳐요. 반대로 tuple()은 리스트를 튜플로 바꿔요. tuple(cart)의 cart는 앞 장에서 pop까지 한 장바구니예요. 출력은 실제로 실행한 결과예요.
