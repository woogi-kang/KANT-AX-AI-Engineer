"%s" % name

f"{name}"

문자열 자리

"%d" % age

f"{age}"

정수 자리. f-string은 타입을 안 적어도 돼요

"%s %d" % (name, age)

f"{name} {age}"

여러 개면 % 는 괄호로 묶어 순서대로

f-string은 따옴표 앞에 f, 중괄호 안에 이름이나 계산식을 바로 적어요.

왼쪽은 % 방식이에요. 문자열 안에 %s(문자열), %d(정수), %f(실수) 같은 빈자리를 만들고, 문자열 뒤 % 다음에 값을 적어요. 자리가 둘 이상이면 값을 괄호로 묶어 순서대로 적어요. 이 묶음은 튜플이라고 부르는데 뒤에서 배워요. 여기서 % 는 12의 3파트의 나머지가 아니라 끼워 넣기예요. 오른쪽은 f-string이에요. 따옴표 앞에 f를 붙이고, 값이 들어갈 자리에 중괄호와 변수 이름을 바로 적어요. 타입을 따로 적지 않아도 되고, {age + 1}처럼 계산식도 넣을 수 있어요. 출력은 두 셀을 실제로 실행한 결과예요.
