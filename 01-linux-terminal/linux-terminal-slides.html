Finder나 파일 탐색기에서 보던 폴더를 글자로 보는 창이 터미널이에요. Mac은 터미널 앱, Windows는 Git을 설치할 때 같이 깔린 Git Bash를 열어요. 둘 다 오늘 배우는 명령이 똑같이 동작해요.

프롬프트는 명령을 기다리는 줄이에요. 컴퓨터마다 모양은 달라도 현재 위치가 꼭 들어 있어요. $ 뒤에 명령을 쳐요. 이 자료에서는 화면을 아끼려고 현재 위치와 $ 만 남긴 짧은 모양으로 보여 줘요. Mac은 맨 끝이 $ 대신 % 예요. 자료의 명령을 따라 칠 때 $ 는 치지 않아요.

폴더는 나무를 거꾸로 세운 모양이에요. 맨 위 / 에서 가지가 아래로 뻗어요. 이 자료는 Linux 기준이라 홈 폴더가 /home/kim이에요. Mac이나 Windows에서는 주소만 다르고 명령은 똑같이 동작해요. 오른쪽 폴더 지도와 파란 현재 위치 표시는 뒤의 모든 실습 장면에 계속 나와요.

현재 위치

-a는 all이에요. 맨 앞의 . 과 .. 은 지금 폴더와 한 칸 위 폴더를 뜻하는 기호예요. git init은 다음 단원에서 배울 Git 명령이에요. 여기서는 숨김 폴더를 하나 만드는 데만 써요. git init이 만든 .git 폴더는 숨김이라 그냥 ls로는 안 보여요.
