실습 17 · 숨김 파일

ls -a

~/kant $ git init

Initialized empty Git repository in /home/kim/kant/.git/

~/kant $ ls

# 아무것도 안 보여요

~/kant $ ls -a

.  ..  .git

점(.)으로 시작하는 이름은 숨겨져요

ls -a를 쳐야 보여요. Git의 .git 폴더도 숨김이에요.

폴더 지도

/

맨 위 폴더

home/

kim/

~ 내 홈 폴더

Desktop/

Documents/

kant/

현재 위치

.git/

← 숨김 폴더

-a는 all이에요. 맨 앞의 . 과 .. 은 지금 폴더와 한 칸 위 폴더를 뜻하는 기호예요. git init은 다음 단원에서 배울 Git 명령이에요. 여기서는 숨김 폴더를 하나 만드는 데만 써요. git init이 만든 .git 폴더는 숨김이라 그냥 ls로는 안 보여요.
