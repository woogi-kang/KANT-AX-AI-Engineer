실습 6 · 파일 만들기

echo "# hello" > memo.md

~/kant $ echo "# hello" > memo.md

~/kant $ cat memo.md

# hello

파일에 글자를 쓰고 읽어요

> 는 파일 내용을 지우고 새로 써요. cat은 내용을 화면에 보여 줘요.

echo는 글자를 화면에 그대로 출력하는 명령이에요. 뒤에 > 파일이름을 붙이면 화면 대신 파일로 보내요. > 는 기존 내용을 덮어쓰니 중요한 파일에는 쓰지 않아요. # 은 마크다운에서 제목을 뜻하는 기호예요. 다음 장에서 봐요. 실제 수업에서는 파일 내용을 VS Code 같은 에디터로 고치는 일이 더 많아요.
