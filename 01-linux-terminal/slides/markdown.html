.md 파일은 글자만 든 텍스트 파일이에요. 폴더마다 있는 README.md도 마크다운이에요.

md는 Markdown의 줄임말이에요. 왼쪽처럼 기호를 섞어 쓰면 GitHub이나 VS Code 미리보기에서 오른쪽처럼 보여요. # 하나는 큰 제목, ## 두 개는 작은 제목이에요. - 로 시작하면 목록, 별표 두 개로 감싸면 굵게, 백틱으로 감싸면 코드예요. 기호 뒤에 띄어쓰기를 한 칸 꼭 넣어요. 앞 장에서 memo.md에 쓴 # hello도 hello라는 제목이에요.
