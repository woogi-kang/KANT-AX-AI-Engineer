2. 2차원 리스트

[[0] * 3] * 3은 같은 행 하나를 세 번 담아요

[11]

board = [[0] * 3] * 3

board[0][0] = 9

print(board)

행 리스트 하나를 셋이 같이 봐요

board[0]

행이 세 개 따로 있어요

board[0]

board[1]

board[2]

[9, 0, 0]

[0, 0, 0]

[0, 0, 0]

빈 표는 행을 하나씩 직접 적어서 만들어요.

13에서 a * 2처럼 리스트에 곱하기를 하면 값이 되풀이된다고 했어요. 그래서 [[0] * 3] * 3으로 0이 가득 찬 3행 3열 표를 만들고 싶어져요. 그런데 이렇게 만들면 행 리스트 하나를 세 번 담은 거라서, 세 행이 사실 같은 리스트예요. 0행 0열만 9로 바꿨는데 모든 행이 바뀌어요. 오류는 안 나지만 결과가 틀려요. 빈 표는 행을 하나씩 직접 적어서 만들면 행마다 따로 있어서 괜찮아요. 출력은 실제로 실행한 결과예요.
