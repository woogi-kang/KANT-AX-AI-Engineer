3. 실제로 써 보기

이름을 넣은 성적표를 칸 맞춰 찍어요

[1]

students = [["kim", 90, 85, 77],

["lee", 70, 95, 88],

["park", 60, 75, 99]]

print(f"{'name':<6}{'kor':>5}{'eng':>5}{'math':>5}")

print("-" * 21)

for name, kor, eng, math in students:

print(f"{name:<6}{kor:>5}{eng:>5}{math:>5}")

Python

name kor eng math

---------------------

kim 90 85 77

lee 70 95 88

park 60 75 99

← 행 맨 앞에 이름을 넣었어요

← 한 행의 값 네 개를 변수 네 개에

← :>5 는 오른쪽 맞춤 다섯 칸 (13)

학생이 늘어도 for 두 줄은 그대로예요

for 뒤 변수 개수가 행의 값 개수와 같아야 해요. 다르면 ValueError예요.

첫 번째 예제는 성적표예요. 행마다 맨 앞에 이름을 넣었어요. 한 리스트 안에 글자와 숫자를 섞어도 된다는 건 13에서 봤어요. for 뒤에 변수를 네 개 적으면 행 하나의 값 네 개가 차례로 나뉘어 담겨요. 13의 영수증에서 쓴 for menu, price, qty in orders:와 같은 모양이에요. 머리글과 칸 맞추기는 13의 f-string이에요. 영어 머리글이라 한글 폭 문제가 없어요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
