2. 2차원 리스트

2차원 리스트에서 자주 나는 오류

[14]

scores[5][0]

Python

IndexError: list index out of range

행은 0~3번까지 네 개예요

[15]

scores[0][9]

Python

IndexError: list index out of range

0행 안의 칸은 0~3번까지예요

[16]

kor, eng, math = students[0]

Python

ValueError: too many values to unpack (expected 3)

행에는 이름까지 값이 네 개예요

행 수는 len(scores), 열 수는 len(scores[0])로 확인해요.

2차원 리스트에서 자주 나는 오류예요. 행을 하나 더해서 scores는 이제 4행 4열이에요. scores[5][0]은 없는 5행을 꺼내서 IndexError예요. scores[0][9]는 0행은 있지만 그 안에 9열이 없어서 같은 IndexError예요. 메시지가 같아서 앞 번호와 뒤 번호 중 어느 쪽이 넘쳤는지 len으로 확인해요. students의 행에는 이름까지 값이 네 개인데 변수를 세 개만 적으면 ValueError가 나요. 변수 개수를 값 개수에 맞춰요. 출력은 실제로 실행한 결과예요.
