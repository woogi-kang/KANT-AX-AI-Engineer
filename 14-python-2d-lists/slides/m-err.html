2. 2차원 리스트

번호가 넘치면 IndexError, 개수가 다르면 ValueError예요

[13]

scores[5][0]

Python

IndexError: list index out of range

← 행은 0~3번, 네 개뿐이에요

[14]

scores[0][9]

Python

IndexError: list index out of range

← 0행 안의 칸도 0~3번이에요

[15]

kor, eng, math = scores[0]

Python

ValueError: too many values to unpack (expected 3)

← 한 행에 값이 네 개예요

확인하기

len(scores)

행 수 4

len(scores[0])

열 수 4

두 IndexError는 메시지가 같아요. 앞 번호와 뒤 번호 중 어느 쪽이 넘쳤는지 len으로 봐요.

2차원 리스트에서 자주 나는 오류예요. 행과 열을 하나씩 더해서 scores는 이제 4행 4열이에요. scores[5][0]은 없는 5행을 꺼내서 IndexError예요. scores[0][9]는 0행은 있지만 그 안에 9열이 없어서 같은 IndexError예요. 메시지가 같으니까 앞 번호와 뒤 번호 중 어느 쪽이 넘쳤는지 len으로 확인해요. 한 행에 값이 네 개인데 변수를 세 개만 적어서 꺼내 담으면 ValueError가 나요. 변수 개수를 값 개수에 맞춰요. 출력은 실제로 실행한 결과예요.
