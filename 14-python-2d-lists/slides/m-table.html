for menu, price, qty in orders:

13의 영수증 for와 같은 모양이에요

{kor:>5}

오른쪽 맞춤 다섯 칸. 13의 1파트 칸 수 맞추기

행 안의 값 개수와 for 뒤의 변수 개수가 같아야 해요.

행마다 맨 앞에 이름을 넣으면 성적표가 돼요. 한 리스트 안에 글자와 숫자를 섞어도 된다는 건 13에서 봤어요. for 뒤에 변수를 네 개 적으면 행 하나의 값 네 개가 차례로 나뉘어 담겨요. 13의 영수증에서 쓴 for menu, price, qty in orders:와 같은 모양이에요. 머리글과 칸 수 맞추기는 13의 1파트 f-string이에요. 영어 머리글이라 한글 폭 문제가 없어요. 변수 개수가 행의 값 개수와 다르면 ValueError가 나요. 오류 장에서 봐요. 출력은 실제로 실행한 결과예요.
