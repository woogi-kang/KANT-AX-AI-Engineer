리스트, 튜플, 문자열 모두 in과 not in을 같은 모양으로 써요.

in은 튜플에도 그대로 써요. 4500은 order 안에 있어서 True예요. 글자 "4500"은 숫자 4500과 다른 값이라 False예요. 12의 2파트에서 본 타입 차이가 여기서도 나와요. 문자열에 in을 쓰면 글자 조각이 붙어 있는지 찾아요. th는 python 안에 붙어 있어서 True고, p와 t는 떨어져 있어서 pt는 False예요. 대문자 P는 python에 없어서 False예요. 문자열에 숫자 3을 물으면 TypeError가 나는데, 정리 장에서 봐요. 출력은 실제로 실행한 결과예요.
