에러 2 · add 없이 commit

commit 했는데 아무 일도 없어요

$ git commit -m "feat: 새 파일"

Untracked files:

        new.md

nothing added to commit but untracked files present

 

$ git commit -m "fix: 오타 수정"

Changes not staged for commit:

        modified: hello.md

no changes added to commit

② 대기실이
비어 있어요

commit은 대기실에 있는 것만 기록해요.

이렇게 고쳐요

git add 파일

git commit -m "..."

빨간 글씨가 보이면 아직 대기실 밖이라는 뜻이니 add부터 해요. 출력 끝의 (use "git add" to track) 같은 안내 문구는 화면 폭 때문에 줄였어요.
