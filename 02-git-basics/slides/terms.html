용어 ① 파일의 상태

git status 글씨 색으로 상태를 알아요

상태

뜻

git status에 보이는 말

Untracked

처음 보는 새 파일

Untracked files:

Modified

고쳤지만 add 전

Changes not staged for commit:

Staged

대기실에 올라감

Changes to be committed:

Committed

마지막 커밋과 같음

working tree clean

빨간 글씨는 대기실 밖, 초록 글씨는 대기실 안이에요.

Untracked와 Modified는 둘 다 빨간색이지만 달라요. Untracked는 Git이 처음 보는 파일, Modified는 이미 아는 파일이 바뀐 거예요. 둘 다 git add로 대기실에 올려요. 한 번이라도 커밋된 파일을 Tracked(추적 중)라고 불러요.
