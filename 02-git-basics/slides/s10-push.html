push 뒤에 어디로(origin), 무엇을(main) 보낼지 적어요. 우리 과정에서는 -u를 쓰지 않고 매번 git push origin main처럼 둘 다 적어요. origin/main 이름표는 내 컴퓨터가 기억하는 GitHub의 main 위치예요. 처음 push 할 때 GitHub 로그인이나 토큰 입력 창이 뜰 수 있어요.
