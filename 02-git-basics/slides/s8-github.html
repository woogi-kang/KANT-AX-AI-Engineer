④ 주소를 복사해 다음 장에서 써요

github.com에 로그인하고 오른쪽 위 + 버튼에서 New repository를 눌러요. 이름만 hello-git으로 적고 README는 체크하지 않아요. README를 체크하면 GitHub에 커밋이 하나 생겨서, 내 컴퓨터의 커밋과 서로 모르는 기록이 돼요. 그러면 첫 push가 거절돼요(42쪽). GitHub 화면이 바뀌어 README가 토글로 보이면 꺼진(Off) 채로 둬요. 만든 뒤 나오는 Quick setup에서 HTTPS 주소를 복사해요. 화면은 간단히 다시 그린 모습이라 실제와 조금 달라요.
