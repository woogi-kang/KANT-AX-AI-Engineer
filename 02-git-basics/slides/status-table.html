막히면 git status부터

이 문장이 보이면지금 상태다음 할 일
No commits yet커밋 0개add → commit
Untracked files:① 새 파일git add
Changes not staged for commit:① 고쳤지만 add 전git add
Changes to be committed:② 커밋 대기git commit
nothing to commit, working tree clean모두 커밋됨push 했는지 확인

GitHub과 비교는 log로

git fetch origin → git log --oneline --graph --all

main이 위 → push origin main

origin/main이 위 → pull origin main

우리 과정은 -u를 쓰지 않아서 git status가 GitHub과 비교한 결과(ahead, behind)를 보여주지 않아요. 그래서 마지막 줄이 clean이어도 push를 안 했을 수 있어요. GitHub과의 차이는 fetch한 뒤 log 그래프에서 main과 origin/main 꼬리표 위치로 확인해요.
