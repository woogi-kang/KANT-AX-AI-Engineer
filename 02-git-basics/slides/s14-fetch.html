origin/main만 올라갔어요

작업 폴더는 그대로예요

$ git fetch origin

From https://github.com/kim/hello-git

   3f9a2c1..e73617d main -> origin/main

$ git log --oneline origin/main

e73617d (origin/main) docs: README 추가

3f9a2c1 (HEAD -> main) feat: 끝인사 추가

a7c21f4 feat: 인사말 추가

538dd06 feat: 인사 파일 추가

fetch는 GitHub의 새 소식을 받아 origin/main 이름표만 옮겨요. 내 main보다 앞선 커밋은 git log --oneline origin/main으로 봐요. 그냥 git log --oneline에는 내 main까지만 나와요. 점선 커밋은 받아 왔지만 아직 내 main에 합치지 않은 커밋이에요. 작업 폴더에는 README.md가 아직 없어요.
