← vim이 열리면 :wq 치고 Enter

pull.rebase 설정이 없으면 내 main과 GitHub main이 갈라졌을 때 Git이 어떻게 합칠지 물으면서 fatal로 멈춰요. 멈춘 pull은 커밋도 파일도 바꾸지 않아요. hint 첫 줄에 나온 pull.rebase false가 우리가 고르는 merge예요. --global을 붙여 한 번 설정하고 같은 pull을 다시 치면 두 커밋이 합쳐진 merge 커밋이 생겨요. 이때 커밋 메시지를 적는 vim이 열리면 그대로 :wq, Enter로 닫아요. 합친 뒤에는 push가 돼요. merge 커밋 모양은 03에서 자세히 봐요. hint 줄은 앞부분만 옮겼고, 해시는 사람마다 달라요.
