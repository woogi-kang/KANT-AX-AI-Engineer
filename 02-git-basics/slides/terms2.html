용어 ② 저장소와 이름표

origin은 명령어가 아니라 주소의 별명이에요

용어

한 줄 뜻

Repository

커밋 기록 보관함 (.git, GitHub)

Index

대기실의 정식 이름

Commit, 해시

저장된 한 시점과 그 고유 번호

branch (브랜치)

커밋에 붙이는 이름표. 03에서 자세히 봐요

main

기본 브랜치. 최신 커밋에 붙은 이름표

HEAD

내가 지금 서 있는 곳

origin

GitHub 주소의 별명

origin/main

내 컴퓨터가 기억하는 GitHub main 위치

origin은 명령어가 아니라 주소의 별명이에요. origin/main은 마지막으로 push하거나 fetch한 시점의 GitHub 모습이라, 최신 상태를 보려면 git fetch origin으로 다시 확인해요. index는 뒤에서 나올 index.lock 에러의 그 index예요.
