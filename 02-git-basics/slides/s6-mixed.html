같은 파일이 두 칸에 있어요.
지금 commit 하면 more는 빠져요.

$ git add hello.md

$ echo "more" >> hello.md

$ git status

Changes to be committed:

        modified: hello.md

Changes not staged for commit:

        modified: hello.md

# 안내 문구(use ...)는 생략

초록 줄과 빨간 줄에 같은 파일이 동시에 나오는 장면이에요. add는 그 순간의 사진이라는 걸 다시 짚어 주세요. 커밋 직전에 git status를 보고 빨간 글씨가 남아 있으면 add부터 해요.
