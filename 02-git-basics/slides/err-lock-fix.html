에러 1 · index.lock

이 메시지가 보이면 팻말만 떼요

$ git add hello.md

fatal: Unable to create '/Users/kim/hello-git/.git/index.lock': File exists.

Another git process seems to be running in this repository, ...

1

다른 git 작업이 끝났는지 봐요

커밋 에디터, 다른 터미널 창, VS Code

2

팻말을 떼요

rm .git/index.lock

3

아까 명령을 다시 쳐요

git add hello.md

Mac 터미널, Windows Git Bash 똑같아요

지우는 건 index.lock 하나뿐이에요. index나 .git 폴더는 지우지 않아요.

1번은 열려 있는 커밋 에디터, 다른 터미널 창, VS Code의 Git 작업을 확인하는 단계예요. 이걸 건너뛰고 지우면 실제로 돌던 작업과 부딪힐 수 있어요. 명령은 .git 폴더가 있는 저장소 맨 위에서 쳐요. 우리 과정은 Windows에서도 Git Bash를 쓰니 rm 명령이 똑같이 돼요. 메시지 원문 뒷부분은 "다른 git이 실행 중인 것 같다, 예전에 비정상 종료됐다면 파일을 직접 지워라"라는 뜻이에요.
