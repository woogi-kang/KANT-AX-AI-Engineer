반대로 고친 c4e9a07을 더했어요

# b81d4e2(실수한 커밋)을 이미 push한 상태

$ git revert HEAD

[main c4e9a07] Revert "feat: 실수한 커밋"

 1 file changed, 1 deletion(-)

$ git push origin main

To https://github.com/kim/hello-git.git

   b81d4e2..c4e9a07 main -> main

이미 GitHub에 올라간 커밋은 팀원이 받아 갔을 수 있어서 reset으로 지우면 안 돼요. revert는 실수한 커밋의 반대 내용을 담은 새 커밋을 만들어요. 기록은 그대로 남고 내용만 원래대로 돌아가요. 팀원 기록을 망치지 않아요. 맨 아래 538dd06은 공간 때문에 생략했어요.
