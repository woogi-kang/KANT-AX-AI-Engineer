명령 시작

팻말 걸기

작업 중

다른 명령은 기다려요

명령 끝

팻말 떼기

끝나기 전에 멈추면 팻말이 남아요

터미널 창을 강제로 닫았을 때

커밋 메시지 에디터를 닫지 않았을 때

VS Code가 같은 저장소에서 git을 실행 중일 때

index는 대기실의 정식 이름이에요. add, commit, pull처럼 대기실을 고치는 명령이 일하는 동안 다른 명령이 끼어들지 못하게 Git이 스스로 잠가 둬요. 정상이라면 명령이 끝날 때 저절로 사라지고, 비정상 종료됐을 때만 남아서 에러를 내요.
