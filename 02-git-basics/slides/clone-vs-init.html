init과 clone

GitHub에 저장소가 있으면 clone, 없으면 init

GitHub에 아직 없음

git init

git remote add origin 주소

add → commit

git push origin main

GitHub에 이미 있음

git clone 주소

cd 폴더이름

add → commit

git push origin main

둘 중 하나로 시작해요. 시작한 뒤에는 똑같아요.

판단 기준은 하나예요. GitHub에 저장소가 이미 있나? 있으면 clone, 없으면 init. 과제 템플릿이나 팀 프로젝트는 대부분 clone이에요. 왼쪽에서 remote add는 commit 뒤에 해도 돼요(실습에서는 커밋 두 개 뒤에 했어요). clone한 폴더에서 init이나 remote add를 또 하면 error: remote origin already exists. 가 나요.
