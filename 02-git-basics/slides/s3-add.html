add는 파일을 옮기는 게 아니라 그 순간의 사진을 대기실에 올리는 거예요. 그래서 작업 폴더 원본은 그대로 있어요. 초록 글씨는 커밋할 준비가 끝났다는 뜻이에요. 여러 파일을 한 번에 올릴 땐 git add . 을 써요.
