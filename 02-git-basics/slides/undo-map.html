되돌리기

커밋을 되돌릴 땐 push 했는지부터 봐요

이 커밋, push 했나요?

아니요 · 내 저장소에만 있어요

git reset HEAD~1

커밋을 없던 일로 해요

잘못 지웠다면 git reflog로 다시 찾아요

네 · GitHub에도 올라갔어요

git revert 커밋

반대로 고친 커밋을 더해요

팀원 기록은 그대로 둬요

이번 파트는 커밋한 뒤의 실수만 다뤄요. 기준은 하나, push 했는지예요. 나만 가진 커밋은 reset으로 없던 일로 만들고, 이미 GitHub에 올린 커밋은 revert로 반대 커밋을 하나 더 쌓아요. 이어지는 실습에서 둘을 그림으로 봐요.
