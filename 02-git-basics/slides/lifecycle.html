Modified

add

commit

파일 수정

add (다시)

고치고, add, commit.
파일은 이 고리를 계속 돌아요.

새 파일은 Untracked로 시작해요. add 하면 Staged, commit 하면 Committed. 책에 따라 Committed를 Unmodified라고 부르기도 하지만, git status에는 어느 단어도 나오지 않고 working tree clean으로만 보여요. 그 뒤로 파일을 고치면 Modified가 되고 다시 add, commit을 반복해요. 이 고리가 Git 작업의 기본 리듬이에요.
