에러 3 · origin 설정

origin이 이미 있대요, 혹은 없대요

두 번 등록했어요

error: remote origin already exists.

remote add를 두 번 쳤거나
clone한 폴더에서 또 등록했어요

이렇게 고쳐요

git remote -v

git remote set-url origin 새주소

등록하지 않았어요

fatal: 'origin' does not appear
to be a git repository

init으로 시작하고
remote add를 빠뜨렸어요

이렇게 고쳐요

git remote add origin 주소

git push origin main

어느 쪽이든 git remote -v로 지금 등록된 주소를 먼저 확인하세요. 주소를 잘못 넣었으면 set-url로 고쳐요.
