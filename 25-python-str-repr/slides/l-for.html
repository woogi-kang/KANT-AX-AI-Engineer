4. 붕어빵 여러 개 다루기

붕어빵 여러 개를 리스트에 담아 하나씩 찍어요

[1]

class Bread:

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

 

def __str__(self):

return f"{self.flavor} 붕어빵 {self.price:,}원"

 

def __repr__(self):

return f"Bread('{self.flavor}', {self.price})"

 

breads = [Bread("팥", 1000), Bread("슈크림", 1200), Bread("피자", 1500)]

for b in breads:

print(b)

Python

팥 붕어빵 1,000원

슈크림 붕어빵 1,200원

피자 붕어빵 1,500원

← 하나씩 꺼내 print

← b는 붕어빵 하나라서 __str__을 써요

이제 __str__과 __repr__이 모두 있는 틀로 붕어빵 세 개를 리스트에 담아요. for로 하나씩 꺼내 print하면 b는 붕어빵 하나라서 __str__의 메뉴판 글씨가 나와요. 24의 실습에서는 b.intro()를 불렀는데, 이제는 print(b)만 쳐도 돼요. 이 셀의 breads를 다음 두 장에서 계속 써요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
