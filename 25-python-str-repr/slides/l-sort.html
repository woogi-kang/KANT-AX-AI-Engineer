4. 붕어빵 여러 개 다루기

22의 key=lambda로 가격순 정렬과 가장 비싼 붕어빵

[3]

print(sorted(breads, key=lambda b: b.price, reverse=True))

print(max(breads, key=lambda b: b.price))

Python

[Bread('피자', 1500), Bread('슈크림', 1200), Bread('팥', 1000)]

피자 붕어빵 1,500원

[4]

print(sorted(breads))

Python

TypeError: '<' not supported between instances of 'Bread' and 'Bread'

key가 꼭 필요해요

붕어빵끼리는 무엇으로 크기를 비교할지 몰라요. key로 가격을 비교하라고 알려 줘요.

max는 붕어빵 하나

max가 돌려준 건 리스트가 아니라 붕어빵 하나라서 print가 __str__을 써요.

22에서 배운 key=lambda를 붕어빵에 써요. 가격 칸으로 비교하라고 알려 주면 비싼 순으로 정렬되고, max로 가장 비싼 붕어빵을 고를 수 있어요. key 없이 sorted를 부르면 TypeError가 나요. 숫자끼리는 크기를 비교할 수 있지만 붕어빵끼리는 맛으로 비교할지 가격으로 비교할지 몰라서예요. max가 돌려준 값은 붕어빵 하나라서 print가 __str__의 메뉴판 글씨를 찍었어요. 출력은 실제로 실행한 결과예요.
