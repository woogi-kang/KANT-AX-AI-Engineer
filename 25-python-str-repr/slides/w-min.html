붕어빵이에요

← print하지 않고 return해요

← __str__이 돌려준 글자를 print가 찍어요

가장 짧은 __str__을 만들어요. 틀 안에 def __str__(self)를 적고 글자 하나를 return했어요. print(a)를 쳤더니 낯선 글자 대신 붕어빵이에요가 나왔어요. print가 a를 찍기 전에 a의 틀에서 __str__을 찾아 부르고, 돌려받은 글자를 찍은 거예요. __str__ 안에서 print하지 않고 return해요. 19에서 배운 것처럼 return한 글자를 print가 받아서 찍어요. 지금은 어떤 붕어빵이든 같은 글자가 나와요. 다음 파트에서 맛과 가격이 들어가게 바꿔요. 출력은 실제로 실행한 결과예요.
