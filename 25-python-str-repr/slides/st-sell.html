4. 붕어빵 여러 개 다루기

메서드로 재고와 판매 개수를 바꿔요

[5]

class Stall:

def __init__(self, name, stock):

self.name = name

self.stock = stock

self.sold = 0

 

def sell(self, qty):

self.stock = self.stock - qty

self.sold = self.sold + qty

 

def __str__(self):

return f"{self.name}: 남은 {self.stock}개, 판매 {self.sold}개"

 

s = Stall("팥", 10)

print(s)

s.sell(3)

print(s)

상태가 남아요

sell을 부를 때마다 self의 칸이 바뀌고, 바뀐 값은 다음에 부를 때까지 남아요. print(s)는 지금 상태를 보여 줘요.

붕어빵 노점 하나를 틀로 만들어요. 재고는 재료로 받고, 판매 개수는 24에서 본 것처럼 0에서 시작해요. sell 메서드는 판 개수만큼 재고를 빼고 판매 개수를 더해요. sell을 부를 때마다 칸의 값이 바뀌고, 바뀐 값은 다음에 부를 때까지 노점에 남아 있어요. 이렇게 객체가 지금 들고 있는 값을 상태라고 불러요. __str__이 있어서 print(s)만 쳐도 지금 상태가 보여요. 출력은 실제로 실행한 결과예요.
