5. 오류와 함정

글자에 붕어빵을 바로 더하면 can only concatenate

[4]

class Bread:

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

 

def __str__(self):

return f"{self.flavor} 붕어빵 {self.price:,}원"

 

a = Bread("팥", 1000)

b = Bread("슈크림", 1200)

print("주문: " + a)

Python

TypeError: can only concatenate str (not "Bread") to str

← 더하기는 __str__을 부르지 않아요

✕

"주문: " + a

✓

"주문: " + str(a)

f"주문: {a}"나 print("주문:", a)처럼 적어도 __str__이 불려요.

__str__을 만들었으니 글자에 바로 더해도 될 것 같지만 TypeError가 나요. 글자에는 글자만 더할 수 있다는 뜻이에요. 더하기는 붕어빵을 글자로 바꿔 주지 않아요. 2파트에서 본 것처럼 str(a)로 먼저 바꾸거나, f-string 중괄호에 넣거나, print에 쉼표로 넘기면 __str__이 불려요. 12에서 숫자와 글자를 더할 때 난 오류와 같은 원리예요. 출력은 실제로 실행한 결과예요.
