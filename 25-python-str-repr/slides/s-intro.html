a.intro()

__str__

def __str__(self):

return f"{self.flavor} 붕어빵"

 

print(a)

f"주문: {a}"

print, str, f-string이 알아서

무엇을 하나요

글자를 return

f-string, 더하기로 이어요

24에서 만든 intro도 붕어빵을 소개했어요. 그런데 __str__을 쓰는 이유가 있어요. intro는 우리가 직접 a.intro()로 불러야 하고, 안에서 바로 print해 버려요. 그래서 print(a)는 여전히 낯선 글자가 나오고, 소개 글자를 주문서나 영수증에 이어 붙일 수도 없어요. __str__은 print, str, f-string이 알아서 부르고 글자를 돌려줘요. 돌려받은 글자는 어디에든 다시 쓸 수 있어요. 파이썬이 원래 쓰던 방법에 우리 붕어빵이 끼어드는 거예요.
