3. __repr__

__str__을 만들었는데도 낯선 글자가 남아요

[1]

class Bread:

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

 

def __str__(self):

return f"{self.flavor} 붕어빵 {self.price:,}원"

 

a = Bread("팥", 1000)

b = Bread("슈크림", 1200)

← __str__을 쓰지 않아요

← 리스트 안의 붕어빵도 __str__을 쓰지 않아요

__str__을 만들었는데도 낯선 글자가 남는 곳이 두 군데 있어요. 하나는 셀 마지막 줄에 print 없이 이름만 적었을 때예요. 10에서 배운 대로 셀 마지막 줄의 값은 저절로 보이는데, 이때는 __str__이 아닌 다른 메서드를 써요. 노트북은 object라는 말을 빼고 보여 줘서 모양이 조금 달라요. 다른 하나는 붕어빵을 리스트에 담아 print했을 때예요. 리스트는 __str__로 찍지만, 리스트 안의 값은 __repr__이라는 메서드로 보여 줘요. 다음 장에서 이 차이를 이미 본 적이 있다는 걸 확인해요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
