재고가 모자라면 팔지 않게 if로 막아요

[6]

class Stall:

def __init__(self, name, stock):

self.name = name

self.stock = stock

self.sold = 0

 

def sell(self, qty):

if qty > self.stock:

return "재고가 모자라요"

self.stock = self.stock - qty

self.sold = self.sold + qty

return "판매 완료"

 

s = Stall("팥", 5)

print(s.sell(3))

print(s.sell(4))

print(s.stock, s.sold)

← 남은 2개, 판매 3개 그대로

재고보다 많이 팔면 재고가 마이너스가 돼요. sell 안에 17의 if를 넣어서, 재고가 모자라면 글자를 return하고 바로 끝나게 했어요. 19에서 배운 대로 return을 만나면 아래 줄은 실행하지 않아서 재고와 판매 개수가 바뀌지 않아요. 3개를 판 뒤 남은 2개는 그대로예요. 메서드 안에 값을 지키는 규칙을 둘 수 있어서 재고가 마이너스가 되는 일을 막아요. 출력은 실제로 실행한 결과예요.
