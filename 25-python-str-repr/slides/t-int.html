5. 오류와 함정

숫자를 돌려줘도 returned non-string

[2]

class Bread:

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

 

def __str__(self):

return self.price

 

a = Bread("팥", 1000)

b = Bread("슈크림", 1200)

print(a)

Python

TypeError: __str__ returned non-string (type int)

← 가격 숫자를 그대로

← int = 숫자

✕return self.price

✓

return f"{self.price}원"

이번엔 return은 했는데 가격 숫자를 그대로 돌려줬어요. 오류 끝의 type int가 숫자를 돌려줬다는 뜻이에요. __str__과 __repr__은 이름 그대로 글자를 돌려줘야 해요. 12에서 배운 str()로 바꿔 return str(self.price)라고 적거나, 화면처럼 f-string으로 감싸서 돌려줘요. 출력은 실제로 실행한 결과예요.
