2. __str__

__str__에 self의 값을 넣어 붕어빵마다 다르게

[1]

class Bread:

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

 

def __str__(self):

return f"{self.flavor} 붕어빵 {self.price:,}원"

 

a = Bread("팥", 1000)

b = Bread("슈크림", 1200)

print(a)

print(b)

손님에게 보여 주는 글씨

__str__은 메뉴판처럼 사람이 읽기 좋은 글자를 돌려줘요.

__str__ 안에서 self를 쓰면 붕어빵마다 다른 글자를 돌려줄 수 있어요. 13의 f-string에 self.flavor와 self.price를 넣고, 가격에는 천 단위 콤마를 붙였어요. print(a)에서는 self가 a라서 팥 붕어빵 1,000원이, print(b)에서는 슈크림 붕어빵 1,200원이 나와요. __str__은 손님에게 보여 주는 메뉴판 글씨라고 생각하면 돼요. 사람이 읽기 좋은 글자로 적어요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
