3. __repr__

눌러 보기: 지금 누가 불릴까요

class Bread:

def __init__(self, flavor, price): ...

def __str__(self):

return f"{self.flavor} 붕어빵 {self.price:,}원"

def __repr__(self):

return f"Bread('{self.flavor}', {self.price})"

 

a = Bread("팥", 1000)

b = Bread("슈크림", 1200)

틀에

버튼으로 메서드를 빼거나 다시 넣어요.
뺀 메서드는 위 코드에 줄이 그어져요.

이렇게 보여 달라고 하면

파이썬이 틀에서 찾는 순서

__str__

__repr__

기본 모양

출력

오른쪽 위 버튼을 눌러 보세요. 브라우저로 슬라이드를 열면 눌러져요.

앞 장의 표를 직접 눌러 보는 장이에요. 브라우저로 슬라이드를 열면 버튼이 눌러져요. 오른쪽 위에서 보여 주는 방법을 하나 고르면, 파이썬이 틀에서 어떤 메서드를 어떤 순서로 찾는지 상자에 불이 들어오고 출력이 나와요. print와 f-string은 __str__부터 찾고, 없으면 __repr__, 그것도 없으면 기본 모양을 써요. 셀 마지막 줄과 리스트 안은 __str__을 보지 않고 __repr__부터 찾아요. 왼쪽 아래 버튼으로 __str__이나 __repr__을 빼고 다시 눌러 보세요. 누르기 전에 무엇이 나올지 수강생에게 먼저 물어보면 좋아요. 출력은 데모에서 실제로 나온 글자예요. 주소는 실행할 때마다 달라요.
