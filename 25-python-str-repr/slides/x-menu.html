class Drink:

def __init__(self, name, price):

self.name = name

self.price = price

 

def __str__(self):

return f"{self.name:<7}{self.price:>6,}원"

 

def __repr__(self):

return f"Drink('{self.name}', {self.price})"

 

menu = [Drink("latte", 5000), Drink("tea", 4000), Drink("coffee", 4500)]

for d in sorted(menu, key=lambda d: d.price):

print(d)

print([d for d in menu if d.price < 5000])

메뉴판은 __str__

13의 칸 맞추기로 줄을 맞춰 찍어요.

확인은 __repr__

5000원 미만을 골라 담은 리스트는 주문표 모양으로 보여요.

카페 메뉴판을 만들어요. __str__은 13의 칸 맞추기로 이름은 왼쪽 7칸, 가격은 오른쪽 6칸에 맞춰 손님용 줄을 만들어요. __repr__은 개발자가 확인할 때 쓰는 주문표 모양이에요. 22의 sorted와 key로 가격순 정렬해 하나씩 print하면 메뉴판 줄이 나오고, 23의 컴프리헨션으로 골라 담은 리스트를 print하면 주문표 모양이 나와요. 한 틀에 두 메서드를 다 두면 어디서 찍어도 알아보기 쉬워요. 출력은 실제로 실행한 결과예요.
