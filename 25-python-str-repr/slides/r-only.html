3. __repr__

하나만 만든다면 __repr__이에요

[7]

class Bread:

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

 

def __repr__(self):

return f"Bread('{self.flavor}', {self.price})"

 

a = Bread("팥", 1000)

b = Bread("슈크림", 1200)

print(a)

print([a, b])

Python

Bread('팥', 1000)

[Bread('팥', 1000), Bread('슈크림', 1200)]

← __str__ 없이 __repr__만

← print도 __repr__을 빌려 써요

영수증, 메뉴판처럼 손님용 글씨가 따로 필요할 때 __str__을 더해요.

이번엔 __str__ 없이 __repr__만 만들었어요. print(a)도 __repr__의 글자를 찍었어요. __str__이 없으면 print는 __repr__을 빌려 써요. 반대로 __str__만 있으면 리스트 안이나 셀 마지막 줄에서는 빌려 쓰지 않아서 3파트 첫 장처럼 낯선 글자가 남아요. 그래서 하나만 만든다면 __repr__이 더 많은 곳을 해결해요. 영수증이나 메뉴판처럼 손님에게 보여 줄 글씨가 따로 필요할 때 __str__을 더해요. 출력은 실제로 실행한 결과예요.
