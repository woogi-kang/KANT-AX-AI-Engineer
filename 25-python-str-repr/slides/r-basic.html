3. __repr__

__repr__까지 만들면 어디서나 보여요

[5]

class Bread:

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

 

def __str__(self):

return f"{self.flavor} 붕어빵 {self.price:,}원"

 

def __repr__(self):

return f"Bread('{self.flavor}', {self.price})"

 

a = Bread("팥", 1000)

b = Bread("슈크림", 1200)

a

Python

Bread('팥', 1000)

← 만든 사람이 보는 주문표 글씨

다시 찍는 코드 모양으로 적어요

← 셀 마지막 줄도 이제 보여요

print(a)

print([a, b])

Python

팥 붕어빵 1,000원

[Bread('팥', 1000), Bread('슈크림', 1200)]

← print는 여전히 __str__

← 리스트 안은 __repr__

__repr__을 더 만들어요. __repr__은 만든 사람이 보는 주문표 글씨예요. 보통 그 붕어빵을 다시 찍는 코드 모양으로 적어요. Bread('팥', 1000)을 그대로 복사해서 셀에 붙여 넣으면 같은 붕어빵이 다시 만들어져요. 맛 글자에는 따옴표를 직접 넣었어요. 이제 셀 마지막 줄에서도, 리스트 안에서도 낯선 글자 대신 Bread('팥', 1000)이 보여요. print(a)는 여전히 __str__의 메뉴판 글씨를 써요. 출력은 실제로 실행한 결과예요.
