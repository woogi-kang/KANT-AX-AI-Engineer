[2]

print(str(a))

print(f"주문: {a}")

print("오늘의 빵:", b)

Python

팥 붕어빵 1,000원

오늘의 빵: 슈크림 붕어빵 1,200원

← 12의 타입 바꾸기 str()에 넣어도

← f-string 중괄호 안에 넣어도

← print에 쉼표로 넘겨도

[3]

msg = "포장할게요: " + str(a)

print(msg)

Python

포장할게요: 팥 붕어빵 1,000원

← 바꾼 글자는 더하기로 이을 수 있어요

파이썬이 붕어빵을 글자로 바꿔야 할 때마다 __str__을 불러요.

__str__은 print할 때만 불리는 게 아니에요. 12에서 숫자를 글자로 바꾸던 str()에 붕어빵을 넣어도, f-string 중괄호 안에 넣어도, print에 쉼표로 여러 개를 넘겨도 불려요. 공통점은 파이썬이 붕어빵을 글자로 바꿔야 하는 순간이라는 거예요. str(a)로 바꾼 글자는 더하기로 다른 글자와 이을 수도 있어요. 출력은 실제로 실행한 결과예요.
