__str__ 안에서 print하면 returned non-string

[1]

class Bread:

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

 

def __str__(self):

print(self.flavor, "붕어빵")

 

a = Bread("팥", 1000)

b = Bread("슈크림", 1200)

print(a)

Python

팥 붕어빵

TypeError: __str__ returned non-string (type NoneType)

return이 없어요

읽는 법

__str__이 글자 대신 None을 돌려줬어요. return이 없으면 None이에요(19).

고치기

print 대신 return f"{self.flavor} 붕어빵"

가장 많이 하는 실수예요. __str__ 안에서 return 대신 print를 썼어요. 출력을 보면 팥 붕어빵이 먼저 찍히고 바로 TypeError가 나요. __str__이 불려서 안의 print가 실행된 뒤, 돌려준 값이 글자가 아니라 None이었기 때문이에요. 19에서 배운 대로 return이 없는 함수는 None을 돌려줘요. __str__과 __repr__은 꼭 글자를 return해요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
