class Bread:

def __init__(self, flavor, price):

self.flavor = flavor

self.price = price

 

def _str_(self):

return f"{self.flavor} 붕어빵"

밑줄을 하나씩만 적었어요. 24의 __init__ 때는 TypeError가 났는데, 이번에는 오류가 안 나요. 파이썬이 print할 때 __str__을 찾았는데 없어서 그냥 기본 모양을 쓴 거예요. _str_은 이름이 비슷한 평범한 메서드일 뿐이에요. 오류가 없어서 오히려 찾기 어려우니, 낯선 글자가 그대로 나오면 밑줄 개수부터 봐요. 출력은 실제로 실행한 결과예요.
