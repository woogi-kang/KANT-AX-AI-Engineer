def는 기억해 두기만 하고, 실행은 이름()을 부를 때 해요.

def 셀은 실행해도 아무것도 찍히지 않고, 이름()을 불러야 몸통이 실행돼요. def 셀을 실행하면 파이썬은 hello라는 이름에 몸통 두 줄을 기억해 두기만 해요. 레시피 카드에 만드는 법을 적어 둔 것과 같아요. 다음 셀에서 hello()를 실행하면 그제야 기억한 몸통을 실행해서 두 줄이 찍혀요. 노트북에서는 def 셀을 한 번 실행해 두면 아래 셀 어디서든 부를 수 있어요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
