def can_order(stock, name):

if stock[name] > 0:

return True

return False

 

stock = {"coffee": 3, "latte": 0, "cake": 2}

for o in ["coffee", "latte", "cake"]:

if can_order(stock, o):

print(o, "주문 받았어요")

else:

print(o, "품절이에요")

if can_order(stock, o):는 "주문할 수 있나요?"로 읽혀요. 조건이 길어져도 함수 안에만 적으면 돼요.

True, False를 돌려주는 함수는 if 뒤에 바로 써요.

15의 재고 딕셔너리로 주문할 수 있는지 묻는 함수를 만들었어요. 재고가 0보다 크면 True를 돌려주고 끝내요. 아니면 아래 return False까지 가요. 반복에서는 if can_order(stock, o):처럼 if 뒤에 함수를 바로 써요. 돌려준 True나 False가 if 조건이 돼요. 함수 이름 덕분에 이 줄이 주문할 수 있나요라는 질문처럼 읽혀요. 출력은 실제로 실행한 결과예요.
