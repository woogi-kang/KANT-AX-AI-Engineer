3. 매개변수와 인자

재료 칸은 쉼표로 여러 개 만들어요

[2]

def order(menu_name, qty):

print(f"{menu_name} {qty}잔 주문 받았어요")

 

order("latte", 2)

order("coffee", 1)

Python

latte 2잔 주문 받았어요

coffee 1잔 주문 받았어요

order("latte", 2)

menu_name

"latte"

qty

2

첫째는 첫째 칸, 둘째는 둘째 칸

"latte"는 menu_name에, 2는 qty에 들어가요. 적은 순서대로 짝을 지어요.

왜 menu가 아니라 menu_name인가요

15의 menu 딕셔너리와 헷갈리지 않게 이름을 다르게 지었어요. 매개변수 이름도 하는 일이 보이게 지어요.

재료가 두 개 필요하면 괄호 안에 쉼표로 칸을 두 개 만들어요. order는 메뉴 이름과 잔 수를 받아요. order("latte", 2)로 부르면 첫째 인자 "latte"가 첫째 칸 menu_name에, 둘째 인자 2가 둘째 칸 qty에 담겨요. 매개변수 이름을 menu가 아니라 menu_name으로 지은 건 15의 menu 딕셔너리와 헷갈리지 않게 하려는 거예요. 출력은 실제로 실행한 결과예요.
