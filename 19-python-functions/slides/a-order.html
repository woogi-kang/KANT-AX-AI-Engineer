3. 매개변수와 인자

인자는 적은 순서대로 칸에 들어가요

[3]

order(2, "latte")

Python

2 latte잔 주문 받았어요

order(2, "latte")

menu_name

2

qty

"latte"

오류 없이 이상하게 찍혀요

파이썬은 값의 뜻을 몰라요. 첫째 값을 첫째 칸에 넣을 뿐이에요. 2가 메뉴 이름이 됐어요.

def 줄을 보고 순서를 맞춰요

order(menu_name, qty)이니 메뉴, 잔 수 순서로 넣어요. 20에서 칸 이름을 적어 넣는 키워드 인자를 배워요.

칸 순서를 바꿔 넣으면 값도 바뀌어 들어가요.

같은 order에 순서를 바꿔 2, "latte"로 넣었어요. 파이썬은 값의 뜻을 따지지 않고 첫째 값을 첫째 칸에 넣어요. 그래서 menu_name이 2, qty가 latte가 되어 2 latte잔이라고 찍혀요. 오류가 나지 않아서 더 알아채기 어려워요. 부를 때는 def 줄을 보고 칸 순서대로 넣어요. 칸 이름을 직접 적어서 순서를 신경 쓰지 않는 방법은 20에서 배워요. 출력은 실제로 실행한 결과예요.
