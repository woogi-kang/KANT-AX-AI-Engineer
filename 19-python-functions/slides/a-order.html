✕

order(2, "latte")

✓

order("latte", 2)

칸 순서를 바꿔 넣으면 값도 바뀌어 들어가요.

인자는 뜻이 아니라 적은 순서대로 칸에 들어가요. 같은 order에 순서를 바꿔 2, "latte"로 넣었어요. 파이썬은 첫째 값을 첫째 칸에 넣어서 menu_name이 2, qty가 latte가 되어 2 latte잔이라고 찍혀요. 오류가 나지 않아서 더 알아채기 어려워요. 부를 때는 def 줄을 보고 칸 순서대로 넣어요. 칸 이름을 직접 적어서 순서를 신경 쓰지 않는 방법은 20에서 배워요. 출력은 실제로 실행한 결과예요.
