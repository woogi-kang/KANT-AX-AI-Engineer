def discount_rate(total):

if total >= 20000:

return 10

elif total >= 10000:

return 5

return 0

 

def pay(total):

rate = discount_rate(total)

sale = total * rate // 100

return total - sale

 

print(pay(8000))

print(pay(15500))

print(pay(22000))

함수 안에서 다른 함수를 불러서 일을 나눌 수 있어요. 17에서 합계에 따라 할인율을 정했던 규칙을 함수 두 개로 나눴어요. discount_rate는 합계를 받아 할인율을 돌려줘요. pay는 그 함수를 불러서 할인율을 받고, 할인 금액을 뺀 결제 금액을 돌려줘요. 오른쪽 표처럼 15500원은 5% 할인으로 775원이 빠져 14725원이에요. 작은 함수로 나누면 하나씩 고치고 확인하기 쉬워요. 출력은 실제로 실행한 결과예요.
