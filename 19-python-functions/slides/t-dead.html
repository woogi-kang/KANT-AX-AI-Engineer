5. 오류와 함정

return 아래에 적은 줄은 실행되지 않아요

[5]

def calc(qty):

total = 4500 * qty

return total

print("계산 끝")

 

print(calc(2))

Python

9000

여기서 나감

안 찍힘

계산 끝이 안 보여요

return에서 함수를 나갔기 때문이에요. 오류도 나지 않아서 빠진 줄을 알아채기 어려워요.

이렇게 고쳐요

print를 return 위로

def calc(qty):

total = 4500 * qty

print("계산 끝")

return total

함수에서 할 일을 다 적고 return은 마지막에 둬요.

return 아래에 print를 적었어요. 실행하면 9000만 나오고 계산 끝은 찍히지 않아요. return을 만나서 함수를 이미 나갔기 때문이에요. 오류가 나지 않아서 빠진 줄을 알아채기 어려워요. 함수 안에서 할 일을 다 적은 뒤 return을 마지막에 둬요. 앞 장처럼 if 안의 return은 괜찮아요. 그 return을 만났을 때만 나가요. 출력은 실제로 실행한 결과예요.
