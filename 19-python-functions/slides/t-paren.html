5. 오류와 함정

괄호를 빼면 실행하지 않고 함수 자체가 나와요

[1]

def hello():

print("어서 오세요")

 

hello

Python

<function __main__.hello()>

← 실행하지 않고 함수만 보여 줘요

[2]

print(hello)

Python

<function hello at 0x7efc68143530>

← 0x 뒤 숫자는 실행마다 달라요

hello

hello()

← 괄호를 붙여야 실행돼요

부를 때는 재료가 없어도 괄호 ()를 꼭 붙여요.

괄호를 빼고 이름만 적으면 함수를 실행하지 않고 함수 자체를 보여 줘요. 셀 마지막 줄에 hello만 적으면 노트북이 함수 자체를 보여 주고, print(hello)로 찍으면 function hello at 뒤에 숫자가 나와요. 그 숫자는 함수가 저장된 메모리 위치라서 실행할 때마다 달라져요. 수강생 화면과 슬라이드 숫자가 달라도 괜찮아요. 함수를 실행하려면 재료가 없어도 괄호를 붙여요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
