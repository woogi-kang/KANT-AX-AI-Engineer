5. 오류와 함정

괄호를 빼면 실행하지 않고 함수 자체가 나와요

[1]

def hello():

print("어서 오세요")

 

hello

Python

<function __main__.hello()>

[2]

print(hello)

Python

<function hello at 0x7efc68143530>

어서 오세요가 안 찍혀요

hello만 적으면 "hello라는 함수가 있어요"라고 보여 줄 뿐이에요. 실행하려면 괄호를 붙여요.

0x로 시작하는 숫자는 달라요

함수가 저장된 메모리 위치예요. 실행할 때마다 바뀌어서 화면이 슬라이드와 달라도 괜찮아요.

hello

hello()

부를 때는 재료가 없어도 괄호 ()를 꼭 붙여요.

괄호를 빼고 hello만 적으면 함수를 실행하지 않아요. 셀 마지막 줄에 적으면 노트북이 함수 자체를 보여 주고, print(hello)로 찍으면 function hello at 뒤에 숫자가 나와요. 그 숫자는 함수가 저장된 메모리 위치라서 실행할 때마다 달라져요. 수강생 화면과 슬라이드 숫자가 달라도 괜찮아요. 함수를 실행하려면 재료가 없어도 괄호를 붙여요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
