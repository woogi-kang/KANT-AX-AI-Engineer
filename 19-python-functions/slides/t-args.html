5. 오류와 함정

칸 수와 인자 수가 다르면 TypeError가 나요

[3]

def order(menu_name, qty):

print(f"{menu_name} {qty}잔 주문 받았어요")

 

order("latte")

Python

TypeError: order() missing 1 required positional argument: 'qty'

[4]

order("latte", 2, "L")

Python

TypeError: order() takes 2 positional arguments but 3 were given

missing 1 ... 'qty'

칸 qty가 비었어요. 인자를 하나 덜 넣었어요.

takes 2 ... but 3 were given

칸은 2개인데 인자를 3개 넣었어요.

def 줄의 칸 수만큼 인자를 넣어요.

칸이 두 개인 order에 인자를 하나만 넣으면 TypeError가 나요. 마지막 줄의 missing 1 required positional argument: 'qty'는 qty 칸에 들어갈 값이 없다는 뜻이에요. 반대로 세 개를 넣으면 takes 2 positional arguments but 3 were given이 나요. 칸은 2개인데 3개를 받았다는 뜻이에요. 오류가 나면 def 줄을 보고 칸 수를 세어 봐요. Traceback 위쪽 줄은 빼고 마지막 줄만 옮겼어요. 출력은 실제로 실행한 결과예요.
