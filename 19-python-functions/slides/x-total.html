menu = {"coffee": 4500, "latte": 5000, "cake": 6500}

 

def calc_total(cart, menu):

total = 0

for m in cart:

total += menu[m]

return total

 

cart1 = ["coffee", "cake"]

cart2 = ["latte", "latte", "cake"]

print(f"합계 {calc_total(cart1, menu):,}원")

print(f"합계 {calc_total(cart2, menu):,}원")

합계 11,000원

합계 16,500원

← 1파트에서 복사하던 4줄

← 손님마다 한 줄

← 할인이 생기면 여기만 고쳐요

반복해서 쓰는 계산은 함수로 묶고, return으로 결과를 돌려받아요.

1파트에서 손님마다 복사했던 합계 계산을 calc_total 함수 하나로 바꿨어요. calc_total은 장바구니와 메뉴판을 받아서 합계를 돌려줘요. 함수 안의 4줄은 1파트와 같고, 마지막에 return total을 붙였어요. 부를 때는 f-string 안에서 바로 불러서 13의 천 단위 콤마로 찍었어요. 손님이 늘어도 한 줄씩만 더하면 되고, 할인이 생기면 calc_total만 고치면 돼요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
