5. 오류와 함정

찍기만 하는 함수로 계산하면 TypeError가 나요

[6]

def show(qty):

print(4500 * qty)

 

show(2) + 1000

Python

9000

 

TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'

None + 1000

← show(2)가 돌려준 None으로 바뀌어요

print(4500 * qty)

return 4500 * qty

← 계산에 쓸 값은 return으로

NoneType이 보이면 return이 빠진 함수를 찾아요.

찍기만 하는 함수는 None을 돌려줘서, 그 값으로 계산하면 TypeError가 나요. show(2)는 9000을 찍지만 돌려주는 값은 None이에요. 그래서 show(2) + 1000은 None + 1000이 되고, None과 정수는 더할 수 없다는 오류가 나요. print와 return을 비교한 장의 a와 같아요. 오류 메시지에 NoneType이 보이면 return이 빠진 함수가 있는지 찾아요. 계산에 쓸 값은 print 대신 return으로 돌려줘요. 출력은 실제로 실행한 결과예요.
