5. 오류와 함정

찍기만 하는 함수로 계산하면 TypeError가 나요

[6]

def show(qty):

print(4500 * qty)

 

show(2) + 1000

Python

9000

 

TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'

show(2) + 1000

None + 1000

None에는 더할 수 없어요

9000은 찍혔는데

화면에 찍힌 것일 뿐 돌려준 값은 None이에요. print와 return을 비교한 장의 a와 같아요.

이렇게 고쳐요

print 대신 return

def show(qty):

return 4500 * qty

NoneType이 보이면 return이 빠진 함수를 찾아요.

show(2)는 9000을 찍지만 돌려주는 값은 None이에요. 그래서 show(2) + 1000은 None + 1000이 되고, None과 정수는 더할 수 없다는 TypeError가 나요. 오류 메시지에 NoneType이 보이면 return이 빠진 함수가 있는지 찾아요. 계산에 쓸 값은 print 대신 return으로 돌려줘요. 출력은 실제로 실행한 결과예요.
