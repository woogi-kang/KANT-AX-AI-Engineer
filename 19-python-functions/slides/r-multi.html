def summary(prices):

return sum(prices), len(prices)

 

print(summary([4500, 5000, 6500]))

total, n = summary([4500, 5000, 6500])

print(total, n)

13의 꺼내 담기와 같아요

왼쪽 이름 수 = 돌려준 값 수

return a, b는 튜플로 돌려주고, x, y = 함수()로 나눠 받아요.

return 뒤에 쉼표로 값을 이어 적으면 튜플 하나로 돌려줘요. 합계와 개수를 같이 알고 싶을 때 써요. 그대로 찍으면 괄호로 묶인 (16000, 3)이 나와요. 13에서 배운 튜플이에요. 받을 때는 13의 꺼내 담기처럼 total, n = summary(...)로 적으면 두 변수에 하나씩 담겨요. 이 장은 가볍게 보고 넘어가도 돼요. 출력은 실제로 실행한 결과예요.
