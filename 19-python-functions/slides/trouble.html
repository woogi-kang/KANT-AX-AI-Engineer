1

<function hello at 0x...>가 나와요

괄호를 빼서 실행하지 않았어요

hello()

2

TypeError: ... missing 1 required positional argument

인자를 덜 넣었어요

def 줄 칸 수 세기

3

TypeError: ... takes 2 positional arguments but 3 were given

인자를 더 넣었어요

def 줄 칸 수 세기

4

NameError: name 'welcome' is not defined

def 셀보다 먼저 불렀어요

def 셀 먼저 실행

5

돌려받은 값이 None이에요

함수에 return이 없어요

print 대신 return

6

TypeError: ... 'NoneType' and 'int'

None으로 계산했어요

return 넣기

7

return 아래 print가 안 찍혀요

return에서 함수가 끝났어요

return 위로 옮기기

결과가 이상하면 함수 안에 print를 넣어 받은 값과 돌려줄 값을 찍어 봐요.

함수에서 자주 만나는 일을 모았어요. 1번은 괄호를 빼서 함수를 실행하지 않은 경우예요. 2번과 3번은 칸 수와 인자 수가 맞지 않아요. def 줄을 보고 칸을 세어 봐요. 4번은 노트북에서 셀 순서가 꼬였을 때 자주 나요. 5번과 6번은 return이 빠진 함수예요. 7번은 오류 없이 줄이 빠지는 경우예요. 결과가 이상하면 함수 안에 print를 넣어 매개변수에 무엇이 들어왔는지 찍어 보면 원인이 보여요.
