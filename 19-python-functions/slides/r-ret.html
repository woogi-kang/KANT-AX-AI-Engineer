[1]

def price_of(qty):

return 4500 * qty

 

x = price_of(2)

print(x)

print(price_of(3) + 1000)

return 뒤의 값이 함수를 부른 자리에 들어가요.

return은 계산한 값을 들고 함수를 나가서, 함수를 부른 자리에 그 값을 놓아요. 지금까지 만든 함수는 print로 찍기만 했어요. price_of는 잔 수를 받아 4500을 곱한 값을 돌려줘요. x = price_of(2)는 부른 자리가 9000으로 바뀌어서 x = 9000이 돼요. price_of(3) + 1000도 13500 + 1000으로 바뀐 뒤 14500이 돼요. 13의 len과 sum이 값을 돌려준 것과 같은 방식이에요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
