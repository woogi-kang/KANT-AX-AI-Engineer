4. return

return은 결과를 부른 자리로 돌려줘요

[1]

def price_of(qty):

return 4500 * qty

 

x = price_of(2)

print(x)

print(price_of(3) + 1000)

Python

9000

14500

돌려줄 값

x = price_of(2)

x = 9000

price_of(3) + 1000

13500 + 1000

13500 + 1000

14500

부른 자리가 값으로 바뀌어요

price_of(2)를 9000으로 바꿔 읽으면 돼요. 변수에 담을 수도 있고, 바로 더하기에 쓸 수도 있어요.

return 뒤에 돌려줄 값을 적어요

return 4500 * qty는 계산한 값을 들고 함수를 나가요. len, sum도 이렇게 값을 돌려줘요.

return 뒤의 값이 함수를 부른 자리에 들어가요.

지금까지 만든 함수는 print로 찍기만 했어요. 결과를 받아서 다시 쓰려면 return을 써요. price_of는 잔 수를 받아 4500을 곱한 값을 돌려줘요. x = price_of(2)는 함수를 부른 자리가 9000으로 바뀌어서 x = 9000이 돼요. price_of(3) + 1000도 13500 + 1000으로 바뀐 뒤 14500이 돼요. 13의 len과 sum이 값을 돌려준 것과 같은 방식이에요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
