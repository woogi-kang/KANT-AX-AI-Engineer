5. 오류와 함정

정의보다 먼저 부르면 NameError가 나요

[1]

welcome()

 

def welcome():

print("어서 오세요")

Python

NameError: name 'welcome' is not defined

아직 모르는 이름

[2]

welcome()

Python

NameError: name 'welcome' is not defined

위에서부터 실행해요

첫 줄에서 welcome을 찾았는데 아직 def를 만나지 않았어요. 오류가 나서 아래 def도 실행되지 않았어요.

다시 불러도 같아요

def가 한 번도 실행되지 않았으니까요. def 셀을 먼저 실행하고, 부르는 셀을 아래에 둬요.

노트북에서 더 조심해요

def 셀을 지운 뒤에도 커널은 함수를 기억해요. Restart 뒤 위에서부터 실행하면 그제야 오류가 드러나요.

파이썬은 위에서부터 한 줄씩 실행해요. 첫 줄에서 welcome을 찾았는데 아직 def를 만나지 않아서 그런 이름이 없다는 NameError가 나요. 오류에서 셀이 멈춰서 아래 def도 실행되지 않았어요. 그래서 다음 셀에서 다시 불러도 같은 오류가 나요. def 셀을 먼저 실행하고 부르는 셀을 아래에 둬요. 노트북에서는 def 셀을 지워도 커널이 함수를 기억하고 있어서 괜찮아 보이다가, 10에서 배운 Restart 뒤에 위에서부터 실행하면 오류가 드러나요. 이 두 셀은 따로 띄운 새 커널에서 실행했어요. 출력은 실제로 실행한 결과예요.
