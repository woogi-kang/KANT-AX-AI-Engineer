4. return

print는 화면에 찍기만, return은 값을 돌려줘요

print로 찍는 함수

[2]

def show(qty):

print(4500 * qty)

 

a = show(2)

print("a:", a)

Python

9000

a: None

9000은 찍혔을 뿐, a에는 None

return으로 돌려주는 함수

[3]

def calc(qty):

return 4500 * qty

 

b = calc(2)

print("b:", b)

print(b + 1000)

Python

b: 9000

10000

b에 9000이 담겨서 더할 수 있어요

사람이 볼 값은 print, 다음 계산에 쓸 값은 return이에요.

print는 화면에 찍기만 하고, return은 값을 돌려줘서 변수에 담을 수 있어요. 가장 많이 헷갈리는 부분이라 두 함수를 한 줄만 다르게 나란히 놓았어요. 왼쪽 show는 9000을 찍지만 돌려준 값이 없어서 a에는 None이 담겨요. 오른쪽 calc는 화면에 찍지 않지만 b에 9000이 담겨서 1000을 더할 수 있어요. 화면에 보이는 것과 변수에 담기는 것은 달라요. 출력은 실제로 실행한 결과예요.
