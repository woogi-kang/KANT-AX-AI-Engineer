4. return

print는 화면에 찍기만, return은 값을 돌려줘요

print로 찍는 함수

[2]

def show(qty):

print(4500 * qty)

 

a = show(2)

print("a:", a)

Python

9000

a: None

return으로 돌려주는 함수

[3]

def calc(qty):

return 4500 * qty

 

b = calc(2)

print("b:", b)

print(b + 1000)

Python

b: 9000

10000

a에 남은 건 None

9000은 화면에 찍혔을 뿐이에요. 함수가 돌려준 값이 없어서 a에는 None만 남았어요.

b에 9000이 담겼어요

돌려받은 값이라 b + 1000처럼 다음 계산에 쓸 수 있어요.

사람이 볼 값은 print, 다음 계산에 쓸 값은 return이에요.

가장 많이 헷갈리는 부분이에요. 왼쪽 show는 계산한 값을 print로 찍기만 해요. 화면에 9000이 보이지만 함수가 돌려준 값은 없어서 a에는 None이 담겨요. 오른쪽 calc는 return으로 값을 돌려줘요. 화면에는 아무것도 안 찍히지만 b에 9000이 담겨서 1000을 더할 수 있어요. 화면에 보이는 것과 변수에 담기는 것은 달라요. 결과를 다른 계산에 쓰려면 return을 써요. 출력은 실제로 실행한 결과예요.
