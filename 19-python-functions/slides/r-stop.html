return은 값을 돌려주면서 함수를 끝내요. 그래서 else가 없어도 돼요.

return은 값을 돌려주는 동시에 함수를 끝내요. 18에서 break가 반복을 끝낸 것처럼요. check(0)은 if가 True라서 return "품절"을 만나고 바로 나가요. 그 아래 return "주문 가능"까지 가지 않아요. check(3)은 if가 False라서 아래로 내려가 주문 가능을 돌려줘요. 그래서 else를 쓰지 않아도 돼요. 17처럼 if, else로 나눠 써도 결과는 같아요. 출력은 실제로 실행한 결과예요.
