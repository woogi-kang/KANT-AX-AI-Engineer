def grade(score):

if score >= 90:

return "A"

elif score >= 80:

return "B"

elif score >= 70:

return "C"

return "F"

 

scores = [["kim", 92], ["lee", 78], ["park", 85], ["choi", 59]]

for name, score in scores:

print(f"{name:<5}{score:>3} {grade(score)}")

등급만 정해요

17에서는

반복 안에

if score >= 90:

grade = "A"

elif score >= 80:

grade = "B"

...

print(... grade)

반복이 짧아졌어요

for 안에는 찍는 줄 하나만 남았어요.

17에서 성적표를 찍을 때 for 안에 if, elif를 길게 적고 grade 변수에 등급을 담았어요. 이번에는 등급을 정하는 부분만 grade 함수로 뺐어요. 조건마다 바로 return해서 grade 변수가 필요 없어요. for 안에는 찍는 줄 하나만 남아서 무엇을 하는지 한눈에 보여요. 점수 기준이 바뀌면 grade 함수만 고쳐요. 출력은 실제로 실행한 결과예요.
