17의 등급 계산을 함수로 바꿔요

[3]

def grade(score):

if score >= 90:

return "A"

elif score >= 80:

return "B"

elif score >= 70:

return "C"

return "F"

 

scores = [["kim", 92], ["lee", 78], ["park", 85], ["choi", 59]]

for name, score in scores:

print(f"{name:<5}{score:>3} {grade(score)}")

← 등급 정하기만 함수로 뺐어요

17에서는 for 안에 이만큼 있었어요

for name, score in scores:

if score >= 90:

grade = "A"

elif score >= 80:

grade = "B"

...

print(... grade)

← for 안에는 찍는 줄 하나만 남았어요

17의 성적표에서 등급을 정하는 부분만 grade 함수로 뺐어요. 17에서는 for 안에 if, elif를 길게 적고 grade 변수에 등급을 담았어요. 이번에는 조건마다 바로 return해서 grade 변수가 필요 없어요. for 안에는 찍는 줄 하나만 남아서 무엇을 하는지 한눈에 보여요. 점수 기준이 바뀌면 grade 함수만 고쳐요. 출력은 실제로 실행한 결과예요.
