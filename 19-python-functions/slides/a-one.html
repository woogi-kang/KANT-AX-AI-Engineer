매개변수. def 괄호 안에 적은 칸 이름이에요

"kim"

인자. 부를 때 괄호에 넣는 값이에요

부를 때 넣은 값이 매개변수 칸에 담겨서 몸통에서 쓰여요.

괄호 안에 name을 적으면 재료를 받는 칸이 생겨요. 이 칸을 매개변수라고 해요. greet("kim")처럼 부를 때 넣는 값은 인자라고 해요. 부르면 "kim"이 name 칸에 담기고, 몸통의 f-string이 name 자리에 kim을 넣어 찍어요. 다음에 greet("lee")로 부르면 name에 lee가 담겨요. 함수는 하나인데 넣는 값에 따라 결과가 달라져요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
