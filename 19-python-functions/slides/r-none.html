4. return

return이 없으면 None을 돌려줘요

[4]

result = print("안녕")

print(result)

print(type(result))

Python

안녕

None

<class 'NoneType'>

← print도 돌려주는 값이 없어요

← None은 '값이 없음', 15의 get과 같아요

[5]

def hi():

print("안녕")

print(hi())

Python

안녕

None

← 직접 만든 함수도 return이 없으면 None

몸통 끝까지 return을 만나지 않으면 파이썬이 None을 대신 돌려줘요. print도 함수라서 결과를 변수에 담아 볼 수 있어요. 안녕은 화면에 찍히고, result에는 None이 담겨요. type으로 보면 NoneType이에요. 15에서 get이 없는 키를 만났을 때 돌려준 그 None이에요. 5번 셀의 hi도 return이 없어서 print(hi())가 None을 찍어요. 돌려받은 값이 None이면 함수에 return이 있는지 먼저 봐요. 출력은 실제로 실행한 결과예요.
