CHECK는 괄호 안 조건이 맞는 값만 받아요

ERROR:  new row for relation "product" violates check constraint "product_price_check"

kant_shop=# INSERT INTO product VALUES (1, 'earphone', 89000, -1);

0원은 안 돼요

재고는 0개까지 돼요

둘 다 맞으면 들어가요

조건에는 WHERE에서 쓴 > >= <> AND를 그대로 써요.

CHECK는 괄호 안 조건이 참인 값만 받는 규칙이에요. price는 0보다 커야 하고, stock은 0 이상이어야 해요. 가격 0원을 넣으면 product_price_check에 걸려요. 재고 -1개를 넣으면 product_stock_check에 걸려요. 하나의 표에 CHECK를 여러 개 붙일 수 있고, ERROR에 어느 것에 걸렸는지 이름이 나와요. 둘 다 맞으면 들어가요. 조건에는 WHERE에서 쓴 비교와 AND를 그대로 써요. 예를 들어 가격을 1만 원에서 10만 원 사이로 묶으려면 CHECK (price >= 10000 AND price <= 100000)처럼 적어요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
