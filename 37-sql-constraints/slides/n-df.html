1. 빈칸과 기본값

DEFAULT는 값을 안 적은 칸을 채워 줘요

kant_shop=# CREATE TABLE member (

kant_shop(#  id INTEGER,

kant_shop(#  name VARCHAR(20) NOT NULL,

kant_shop(#  points INTEGER DEFAULT 0,

kant_shop(#  joined_at TIMESTAMPTZ DEFAULT now()

kant_shop(# );

CREATE TABLE

kant_shop=# INSERT INTO member (id, name) VALUES (1, 'kim');

INSERT 0 1

kant_shop=# INSERT INTO member (id, name, points) VALUES (2, 'lee', 500);

INSERT 0 1

kant_shop=# SELECT * FROM member;

id | name | points |           joined_at

----+------+--------+-------------------------------

 1 | kim  |      0 | 2026-11-17 00:48:50.624892+00

 2 | lee  |    500 | 2026-11-17 00:48:51.847456+00

(2 rows)

안 적으면 0

안 적으면 지금 시각

TIMESTAMPTZ 끝의 +00은 세계 표준시(UTC)예요. 컨테이너의 시간대가 UTC라서 그래요. 한국 시간은 9시간 더해요.

DEFAULT는 INSERT에서 그 열을 안 적었을 때 넣을 값이에요. points는 안 적으면 0, joined_at은 안 적으면 now(), 지금 시각이에요. kim은 id와 name만 적었어요. SELECT로 보면 points에 0, joined_at에 넣은 순간의 시각이 들어 있어요. lee는 points를 500으로 직접 적었어요. 적은 값이 있으면 DEFAULT는 쓰이지 않아요. 가입 시각, 포인트, 재고처럼 처음 값이 정해져 있는 열에 DEFAULT를 붙여요. joined_at 끝의 +00은 36에서 본 TIMESTAMPTZ의 시간대예요. 컨테이너가 세계 표준시로 돌고 있어서 +00으로 나와요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
