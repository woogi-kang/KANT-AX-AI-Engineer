규칙을 붙인 CREATE TABLE 한 장

schema.sql

CREATE TABLE member (

id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,

name VARCHAR(20) NOT NULL,

email VARCHAR(50) NOT NULL UNIQUE,

points INTEGER NOT NULL DEFAULT 0 CHECK (points >= 0),

joined_at TIMESTAMPTZ DEFAULT now()

);

-- product는 35쪽과 같아요

CREATE TABLE cart_item (

member_id INTEGER REFERENCES member (id) ON DELETE CASCADE,

product_id INTEGER REFERENCES product (id),

qty INTEGER NOT NULL CHECK (qty > 0),

PRIMARY KEY (member_id, product_id),

CONSTRAINT qty_limit CHECK (qty <= 99)

);

ALTER TABLE member ADD CONSTRAINT 이름 UNIQUE (email);

규칙 더하기

ALTER TABLE member DROP CONSTRAINT 이름;

규칙 지우기

ALTER TABLE member ALTER COLUMN name SET NOT NULL;

NOT NULL 붙이기 (DROP으로 빼기)

ALTER TABLE member ALTER COLUMN points SET DEFAULT 100;

기본값 바꾸기

TRUNCATE cart_item, member RESTART IDENTITY;

같이 비우고 번호는 1부터

\d member

붙은 규칙 보기

만들 때는 부모 표(member, product)부터, 지울 때는 자식 표(cart_item)부터예요.

실습할 때 옆에 열어 둘 한 장이에요. 왼쪽은 오늘 배운 규칙을 다 붙인 CREATE TABLE이에요. 번호 열, NOT NULL, UNIQUE, DEFAULT, CHECK, 외래 키와 ON DELETE, 복합 기본 키, 이름을 붙인 규칙이 다 들어 있어요. 오른쪽은 만든 표를 고치는 ALTER TABLE 명령이에요. 규칙이 잘 붙었는지는 백슬래시 d로 봐요. 표를 만들 때는 부모 표부터, 지울 때는 자식 표부터예요.
