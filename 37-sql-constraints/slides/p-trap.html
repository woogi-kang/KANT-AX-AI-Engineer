3. 기본 키와 자동 번호

SERIAL 열에 번호를 직접 넣으면 나중에 겹쳐요

kant_shop=# INSERT INTO member VALUES (3, 'park');

INSERT 0 1

kant_shop=# INSERT INTO member (name) VALUES ('choi');

ERROR:  duplicate key value violates unique constraint "member_pkey"

DETAIL:  Key (id)=(3) already exists.

kant_shop=# INSERT INTO member (name) VALUES ('choi');

INSERT 0 1

kant_shop=# SELECT * FROM member;

id | name

----+------

 1 | kim

 2 | lee

 3 | park

 4 | choi

(4 rows)

3을 직접 넣었어요

다음 번호 4로 들어가요

번호표 기계

다음에 줄 번호

5

기계는 3이 이미 쓰인 줄 몰라요. 직접 넣은 번호는 기계를 지나지 않기 때문이에요.

SERIAL 열에는 번호를 직접 넣지 말고 비워 둬요.

SERIAL에는 함정이 하나 있어요. 번호를 직접 넣어도 막지 않아요. park을 id 3으로 직접 넣었어요. 그런데 번호표 기계는 이걸 몰라요. 기계를 거치지 않았으니까요. 다음에 choi를 id 없이 넣으면 기계가 3을 꺼내고, 이미 있는 3과 겹쳐서 member_pkey 오류가 나요. 같은 INSERT를 한 번 더 치면 기계가 4를 꺼내서 들어가요. 실패한 번호 3은 다시 쓰지 않아요. 그래서 SERIAL 열에는 번호를 직접 넣지 않아요. 다음 장의 IDENTITY는 이 실수를 처음부터 막아요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
