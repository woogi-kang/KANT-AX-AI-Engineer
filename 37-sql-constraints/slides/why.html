규칙 없는 표는 무엇이든 받아요

kant_shop=# CREATE TABLE member (id INTEGER, name VARCHAR(20), email VARCHAR(50), age INTEGER);

CREATE TABLE

kant_shop=# INSERT INTO member VALUES (1, 'kim', 'kim@mail.com', 25);

INSERT 0 1

kant_shop=# INSERT INTO member VALUES (1, 'lee', 'kim@mail.com', -3);

INSERT 0 1

kant_shop=# INSERT INTO member VALUES (2, NULL, NULL, 30);

INSERT 0 1

kant_shop=# SELECT * FROM member;

id | name |    email     | age

----+------+--------------+-----

 1 | kim  | kim@mail.com |  25

 1 | lee  | kim@mail.com |  -3

 2 |      |              |  30

(3 rows)

id 1이 두 번, 이메일도 겹쳐요, 나이 -3

이름과 이메일이 비었어요

세 INSERT가 모두 INSERT 0 1로 들어갔어요. 막아 줄 규칙이 없었기 때문이에요.

36에서 만든 것처럼 규칙 없는 회원 표를 만들고 행 세 개를 넣었어요. 첫 행은 정상이에요. 두 번째 행은 id가 1로 첫 행과 겹치고, 이메일도 kim@mail.com으로 같아요. 나이는 -3이에요. 세 번째 행은 이름과 이메일이 비어 있어요. 그런데 세 INSERT 모두 INSERT 0 1, 잘 들어갔다고 나와요. 표는 타입만 맞으면 받아요. 이런 행이 쌓이면 회원 1번을 찾을 때 두 명이 나오고, 이메일로 로그인할 때 누구인지 모르게 돼요. 오늘은 이런 행을 표가 처음부터 거절하게 만들어요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
