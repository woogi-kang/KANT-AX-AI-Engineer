3. 기본 키와 자동 번호

열 두 개를 묶어 기본 키 하나로 만들 수 있어요

kant_shop=# CREATE TABLE order_item (

kant_shop(#  order_id INTEGER,

kant_shop(#  product_id INTEGER,

kant_shop(#  qty INTEGER NOT NULL,

kant_shop(#  PRIMARY KEY (order_id, product_id)

kant_shop(# );

CREATE TABLE

kant_shop=# INSERT INTO order_item VALUES (1, 1, 1), (1, 2, 2), (2, 1, 1);

INSERT 0 3

kant_shop=# INSERT INTO order_item VALUES (1, 1, 5);

ERROR:  duplicate key value violates unique constraint "order_item_pkey"

DETAIL:  Key (order_id, product_id)=(1, 1) already exists.

kant_shop=# SELECT * FROM order_item;

order_id | product_id | qty

----------+------------+-----

       1 |          1 |   1

       1 |          2 |   2

       2 |          1 |   1

(3 rows)

주문 번호와 상품 번호를 한 쌍으로 봐요

(1, 1)

1번 주문의 1번 상품

(1, 2)

1번 주문의 2번 상품

(2, 1)

2번 주문의 1번 상품

(1, 1)

이미 있는 쌍이에요

order_id 1도, product_id 1도 여러 번 나와요. 겹치면 안 되는 건 두 값의 쌍이에요.

주문 하나에는 상품이 여러 개 담겨요. order_item 표는 몇 번 주문에 몇 번 상품을 몇 개 담았는지 적는 표예요. 여기서는 order_id만으로도, product_id만으로도 행을 가려낼 수 없어요. 1번 주문에 상품이 둘이고, 1번 상품은 주문 둘에 들어 있으니까요. 그래서 PRIMARY KEY를 열 뒤가 아니라 표 끝에 적고 괄호 안에 열 두 개를 넣었어요. 복합 기본 키라고 불러요. 이제 겹치면 안 되는 건 두 값의 쌍이에요. 1번 주문에 1번 상품을 또 넣으면 쌍 (1, 1)이 겹쳐서 order_item_pkey 오류가 나요. 같은 상품을 더 사면 행을 새로 넣지 말고 qty를 늘려요. 6파트 장바구니에서 해 봐요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
