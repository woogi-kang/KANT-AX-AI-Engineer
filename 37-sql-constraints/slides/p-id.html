번호는 늘 PostgreSQL이

꼭 넣어야 할 때 쓰는 방법, 수업에서는 안 써요

\d product의 id 줄

id | integer | | not null | generated always as identity

SERIAL 대신 GENERATED ALWAYS AS IDENTITY를 쓰면 번호를 직접 넣는 실수를 막아요. 길지만 끊어 읽으면 쉬워요. 늘, ALWAYS, PostgreSQL이 번호를 만든다는 뜻이에요. 표준 SQL 문법이라 다른 데이터베이스에서도 비슷하게 써요. 이름만 빼고 넣으면 1, 2가 차례로 들어가요. 3을 직접 넣으려고 하면 ERROR가 나요. non-DEFAULT, 기본값이 아닌 값은 넣을 수 없다는 뜻이에요. HINT의 OVERRIDING SYSTEM VALUE는 다른 데이터베이스에서 옮겨 올 때처럼 꼭 넣어야 할 때 쓰는 방법이에요. 수업에서는 쓰지 않아요. 아래 백슬래시 d의 id 줄에는 generated always as identity가 보여요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
