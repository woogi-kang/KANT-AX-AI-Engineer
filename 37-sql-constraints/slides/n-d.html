1. 빈칸과 기본값

\d 표 이름으로 붙은 규칙을 확인해요

kant_shop=# \d member

                        Table "public.member"

 Column   |           Type           | Collation | Nullable | Default

-----------+--------------------------+-----------+----------+---------

id        | integer                  |           |          |

name      | character varying(20)    |           | not null |

points    | integer                  |           |          | 0

joined_at | timestamp with time zone |           |          | now()

Nullable 칸에 not null

NOT NULL을 붙인 열이에요.

Default 칸에 기본값

안 적었을 때 들어갈 값이에요.

표에 어떤 규칙이 붙었는지는 백슬래시 d 뒤에 표 이름을 쳐서 봐요. 34에서 표 구조를 볼 때 쓴 명령이에요. Nullable 칸에 not null이 적힌 열이 NOT NULL을 붙인 열이에요. name 하나예요. Default 칸에는 기본값이 나와요. points는 0, joined_at은 now()예요. 표를 만든 뒤 규칙을 제대로 적었는지, 남이 만든 표에 어떤 규칙이 있는지 볼 때 이 명령부터 쳐요. 백슬래시 명령이라 끝에 세미콜론을 안 붙여요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
