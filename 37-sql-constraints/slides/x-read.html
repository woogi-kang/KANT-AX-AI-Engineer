6. 오류와 실제 상황

ERROR 줄의 앞부분으로 어느 규칙인지 알아봐요

ERROR 줄

걸린 규칙

고치는 법

null value in column ...

NOT NULL

비운 열에 값을 넣어요

duplicate key value ... unique

UNIQUE, PRIMARY KEY

DETAIL의 겹친 값을 바꿔요

violates check constraint

CHECK

조건에 맞게 값을 고쳐요

violates foreign key constraint

FOREIGN KEY

부모 행을 먼저 넣거나, 자식 행부터 지워요

cannot insert a non-DEFAULT value

ALWAYS AS IDENTITY

번호 열을 INSERT에서 빼요

could not create unique index

ALTER TABLE ADD

어긋난 행을 UPDATE로 고친 뒤 다시

cannot drop table ...

DROP 순서

자식 표부터 지워요

DETAIL 줄에는 막힌 행이나 겹친 값이 그대로 나와요. 고칠 값은 거기서 찾아요.

오늘 본 오류를 한 표에 모았어요. 영어 문장이 길어도 앞부분만 읽으면 어느 규칙에 걸렸는지 알 수 있어요. null value는 NOT NULL, duplicate key는 UNIQUE나 기본 키, check constraint는 CHECK, foreign key constraint는 외래 키예요. 그 뒤의 따옴표 안이 규칙 이름이에요. DETAIL 줄에는 막힌 행이나 겹친 값이 그대로 나와요. 고칠 값은 거기서 찾아요. 외래 키 오류는 넣을 때와 지울 때 둘 다 나요. 넣을 때는 부모 행을 먼저 넣고, 지울 때는 자식 행부터 지워요.
