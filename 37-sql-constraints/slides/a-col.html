5. 나중에 규칙 바꾸기

NOT NULL과 DEFAULT는 ALTER COLUMN으로 바꿔요

kant_shop=# ALTER TABLE member ALTER COLUMN name SET NOT NULL;

ERROR:  column "name" of relation "member" contains null values

kant_shop=# UPDATE member SET name = 'park' WHERE id = 3;

UPDATE 1

kant_shop=# ALTER TABLE member ALTER COLUMN name SET NOT NULL;

ALTER TABLE

kant_shop=# ALTER TABLE member ADD PRIMARY KEY (id);

ALTER TABLE

kant_shop=# ALTER TABLE member ADD COLUMN points INTEGER DEFAULT 0;

ALTER TABLE

비어 있던 이름부터 채워요

기본 키도 나중에 붙여요

열을 더하면서 기본값까지

kant_shop=# \d member

                     Table "public.member"

Column |         Type          | Collation | Nullable | Default

--------+-----------------------+-----------+----------+---------

id     | integer               |           | not null |

name   | character varying(20) |           | not null |

email  | character varying(50) |           |          |

points | integer               |           |          | 0

열 하나에 붙는 NOT NULL과 DEFAULT는 ALTER COLUMN으로 바꿔요. name에 SET NOT NULL을 하려니 ERROR가 나요. 3번 회원의 이름이 비어 있어서예요. 앞 장처럼 UPDATE로 이름부터 채우면 붙어요. 기본 키도 ADD PRIMARY KEY로 나중에 붙일 수 있어요. ADD COLUMN으로 열을 새로 더하면서 DEFAULT를 같이 적으면, 이미 있던 행의 points에도 0이 채워져요. 아래 백슬래시 d에 바뀐 결과가 모였어요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
