4. 표끼리 잇기

외래 키로 이어진 표는 한 줄에 같이 적어서 비워요

kant_shop=# TRUNCATE member RESTART IDENTITY;

ERROR:  cannot truncate a table referenced in a foreign key constraint

DETAIL:  Table "orders" references "member".

HINT:  Truncate table "orders" at the same time, or use TRUNCATE ... CASCADE.

kant_shop=# TRUNCATE orders, member RESTART IDENTITY;

TRUNCATE TABLE

kant_shop=# SELECT * FROM member;

id | name

----+------

(0 rows)

자식 표와 같이 적으면 돼요

kant_shop=# TRUNCATE member RESTART IDENTITY CASCADE;

NOTICE:  truncate cascades to table "orders"

TRUNCATE TABLE

kant_shop=# SELECT * FROM orders;

id | member_id | total

----+-----------+-------

(0 rows)

CASCADE는 이어진 표도 비워요

수업 예시: 표 여섯 개를 한 줄로 비우고 번호도 1부터

TRUNCATE enrollments, lockers, courses, instructors, sports, members RESTART IDENTITY;

외래 키로 이어진 표는 부모만 따로 비울 수 없어요. member만 TRUNCATE하면 orders가 member를 가리킨다고 ERROR가 나요. HINT는 orders도 같이 비우거나 CASCADE를 쓰라고 해요. 쉼표로 표 이름을 이어 적으면 한 번에 비워져요. 같이 비우니 적는 순서는 상관없어요. member, orders 순서로 적어도 돼요. CASCADE를 붙이면 이어진 자식 표까지 알아서 비우고, NOTICE로 어느 표를 비웠는지 알려 줘요. 어디까지 지워질지 헷갈리면 CASCADE 대신 표 이름을 다 적어요. 수업에서 쓴 줄도 같은 모양이에요. 연결된 표 여섯 개를 한 줄에 적고 RESTART IDENTITY로 번호까지 1부터 다시 세요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
