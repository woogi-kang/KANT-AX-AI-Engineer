제약 조건은 표 앞에 선 문지기예요

들어오는 행

(1, 'kim', 'kim@mail.com')

(1, 'lee', 'kim@mail.com')

문지기 (제약 조건)

NOT NULL

비우면 안 돼요

DEFAULT

안 적으면 채워요

UNIQUE

겹치면 안 돼요

CHECK

조건에 맞아야 해요

PRIMARY KEY

행마다 다른 번호

FOREIGN KEY

다른 표에 있어야 해요

member 표

규칙에 맞는 행만

INSERT 0 1

ERROR: duplicate key value violates unique constraint "member_pkey"

DETAIL: Key (id)=(1) already exists.

걸린 행은 표에 한 칸도 안 들어가요. 어느 규칙에 걸렸는지는 ERROR 줄에 나와요.

제약 조건은 표 앞에 선 문지기예요. INSERT로 들어오는 행, UPDATE로 바뀌는 행은 모두 문지기를 지나요. 가운데 문지기가 오늘 배울 여섯 가지 규칙이에요. NOT NULL과 DEFAULT는 1파트, UNIQUE와 CHECK는 2파트, PRIMARY KEY는 3파트, FOREIGN KEY는 4파트에서 봐요. 규칙에 맞는 행은 표에 들어가고 INSERT 0 1이 나와요. 규칙에 걸린 행은 한 칸도 들어가지 않아요. 아래처럼 ERROR 줄에 걸린 규칙의 이름이, DETAIL 줄에 무엇이 문제인지가 나와요. 표를 만들 때 규칙을 같이 적어 두면, 누가 넣든 잘못된 행은 표에 못 들어와요.
