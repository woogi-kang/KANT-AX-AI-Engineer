BY DEFAULT도 SERIAL처럼 겹쳐요

번호를 자동으로 채우는 방법 세 가지를 나란히 놓았어요. 셋 다 id를 빼고 넣으면 1, 2, 3이 차례로 들어가요. 다른 점은 번호를 직접 넣을 때예요. SERIAL과 GENERATED BY DEFAULT AS IDENTITY는 직접 넣은 번호를 받아요. 그래서 앞 장처럼 나중에 자동 번호와 겹쳐요. 아래 화면이 BY DEFAULT로 만든 표에 2를 직접 넣은 뒤 자동 번호를 받은 결과예요. 키 2가 겹친다는 오류가 나요. ALWAYS는 직접 넣는 것부터 막아서 겹칠 일이 없어요. 새로 만드는 표는 ALWAYS로 만들고, SERIAL은 남이 만든 표나 예전 자료에서 읽을 수 있으면 돼요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
