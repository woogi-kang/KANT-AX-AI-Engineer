5. 나중에 규칙 바꾸기

DROP CONSTRAINT 이름으로 규칙을 지워요

kant_shop=# ALTER TABLE member DROP CONSTRAINT member_email_key;

ALTER TABLE

kant_shop=# ALTER TABLE member ALTER COLUMN name DROP NOT NULL;

ALTER TABLE

kant_shop=# ALTER TABLE member ALTER COLUMN points SET DEFAULT 100;

ALTER TABLE

kant_shop=# \d member

                     Table "public.member"

name   | character varying(20) |           |          |

email  | character varying(50) |           |          |

points | integer               |           |          | 100

Indexes:

   "member_pkey" PRIMARY KEY, btree (id)

규칙 이름으로 지워요

NOT NULL 빼기

기본값 바꾸기

member_email_key가 없어졌어요

규칙을 지울 때는 DROP CONSTRAINT 뒤에 규칙 이름을 적어요. 2파트에서 본 이름이 여기서 쓰여요. 이름을 모르면 먼저 백슬래시 d로 봐요. NOT NULL은 이름이 없어서 ALTER COLUMN name DROP NOT NULL로 빼요. 기본값은 SET DEFAULT로 바꿔요. 바꾼 기본값은 앞으로 넣는 행에만 쓰이고, 이미 있는 행의 값은 그대로예요. 백슬래시 d로 보면 Indexes에 member_pkey만 남고 member_email_key가 없어졌어요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
