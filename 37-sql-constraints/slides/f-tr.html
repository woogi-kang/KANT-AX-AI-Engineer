4. 표끼리 잇기

TRUNCATE로 비우고 RESTART IDENTITY로 번호를 1부터 세요

kant_shop=# DELETE FROM member;

DELETE 2

kant_shop=# INSERT INTO member (name) VALUES ('park');

INSERT 0 1

kant_shop=# SELECT * FROM member;

id | name

----+------

 3 | park

(1 row)

kant_shop=# TRUNCATE member;

TRUNCATE TABLE

kant_shop=# INSERT INTO member (name) VALUES ('choi');

INSERT 0 1

kant_shop=# SELECT * FROM member;

id | name

----+------

 4 | choi

(1 row)

kant_shop=# TRUNCATE member RESTART IDENTITY;

TRUNCATE TABLE

kant_shop=# INSERT INTO member (name) VALUES ('choi');

INSERT 0 1

kant_shop=# SELECT * FROM member;

id | name

----+------

 1 | choi

(1 row)

DELETE 뒤에도 3번부터

TRUNCATE만으로는 4번

RESTART IDENTITY면 1번

DELETE FROM 표;

행을 하나씩 지워요. WHERE로 골라 지울 수 있어요. 번호는 이어서 써요.

TRUNCATE 표;

WHERE 없이 표를 통째로 비워요. 표 모양과 규칙은 남아요.

TRUNCATE 표
RESTART IDENTITY;

비우면서 자동 번호도 1로 돌려요. 연습 데이터를 처음부터 다시 넣을 때 써요.

표의 행을 모두 지우는 방법은 두 가지예요. 36에서 배운 DELETE는 행을 하나씩 지우고, WHERE로 고를 수도 있어요. DELETE로 다 지운 뒤 새로 넣으면 번호는 3번이에요. 번호표 기계는 지운 번호를 다시 주지 않아요. TRUNCATE는 WHERE 없이 표를 통째로 비워요. 결과도 DELETE 2가 아니라 TRUNCATE TABLE로 나와요. TRUNCATE만 쓰면 번호는 여전히 이어져서 4번이에요. 뒤에 RESTART IDENTITY를 붙이면 번호도 1부터 다시 세요. 실습 데이터를 깨끗이 지우고 다시 넣을 때 이 모양을 써요. 표 자체와 규칙은 남아요. 표까지 없애는 건 DROP TABLE이에요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
