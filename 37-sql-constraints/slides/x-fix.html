email이 비면 막아요

points에 NULL을 적어도 막아요

points를 빼면 DEFAULT 0

NOT NULL UNIQUE, NOT NULL DEFAULT 0 CHECK (...)처럼 한 열에 규칙 여러 개를 이어 적어요.

앞 장의 구멍은 NOT NULL로 막아요. email은 NOT NULL UNIQUE, points는 NOT NULL DEFAULT 0 CHECK로 바꿨어요. 한 열에 규칙을 여러 개 띄어서 이어 적으면 돼요. 이제 email이 비면 not-null 오류가 나요. points에 NULL을 직접 적어도 막아요. points를 아예 빼면 DEFAULT 0이 들어가요. 그래서 비어 있으면 안 되는 열에는 UNIQUE, CHECK, DEFAULT를 붙일 때 NOT NULL을 같이 붙여요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
