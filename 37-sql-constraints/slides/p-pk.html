32에서 기본 키는 겹치지 않고 비울 수 없는 번호라고 했어요. 진동벨 번호처럼 행 하나를 가리키는 번호예요. id 뒤에 PRIMARY KEY를 붙이고 실제로 확인해 봐요. id 1을 두 번 넣으면 member_pkey에 걸려요. 오류 문장이 UNIQUE와 똑같은 duplicate key예요. id를 NULL로 넣으면 not-null 오류가 나요. NOT NULL과 같아요. 그래서 기본 키는 NOT NULL과 UNIQUE를 합친 규칙이에요. 백슬래시 d로 보면 id의 Nullable에 not null이 저절로 붙었고, 아래 Indexes에 member_pkey가 있어요. 기본 키는 표에 하나만 둘 수 있어요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
