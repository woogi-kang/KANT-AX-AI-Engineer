4. 표끼리 잇기

주문이 남은 회원은 지울 수 없어요

kant_shop=# DELETE FROM member WHERE id = 1;

ERROR:  update or delete on table "member" violates foreign key constraint

       "orders_member_id_fkey" on table "orders"

DETAIL:  Key (id)=(1) is still referenced from table "orders".

kant_shop=# DELETE FROM member WHERE id = 2;

DELETE 1

kant_shop=# SELECT * FROM member;

id | name

----+------

 1 | kim

(1 row)

lee는 주문이 없어서 지워져요

지우면 orders에 주인 없는 주문이 생기니, PostgreSQL이 부모 쪽 DELETE도 막아요.

외래 키는 자식 표에 넣을 때만 막는 게 아니에요. 부모 표에서 지울 때도 막아요. kim은 주문이 하나 있어요. kim을 지우려고 하면 ERROR가 나요. DETAIL은 키 1이 아직 orders 표에서 쓰이고 있다는 뜻이에요. kim을 지우면 orders에 주인 없는 주문이 남으니까 막는 거예요. lee는 주문이 없어서 DELETE 1로 지워져요. 회원이 탈퇴할 때 주문을 어떻게 할지 정하는 방법이 다음 장이에요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
