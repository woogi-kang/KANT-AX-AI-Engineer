5. 나중에 규칙 바꾸기

ALTER TABLE ... ADD CONSTRAINT로 만든 표에 규칙을 더해요

kant_shop=# SELECT * FROM member;

id | name |     email

----+------+---------------

 1 | kim  | kim@mail.com

 2 | lee  | kim@mail.com

 3 |      | park@mail.com

(3 rows)

kant_shop=# ALTER TABLE member ADD CONSTRAINT member_email_key UNIQUE (email);

ERROR:  could not create unique index "member_email_key"

DETAIL:  Key (email)=(kim@mail.com) is duplicated.

kant_shop=# UPDATE member SET email = 'lee@mail.com' WHERE id = 2;

UPDATE 1

kant_shop=# ALTER TABLE member ADD CONSTRAINT member_email_key UNIQUE (email);

ALTER TABLE

이미 겹친 이메일

36의 UPDATE로 먼저 고쳐요

이제 붙어요

규칙은 지금 들어 있는 행까지 검사해요. 어긋난 행부터 고쳐야 붙어요.

표를 다 만든 뒤에 규칙이 필요해질 때가 많아요. 들어가기의 규칙 없는 회원 표처럼요. ALTER TABLE 표 이름 ADD CONSTRAINT 이름 다음에 규칙을 적으면 나중에 더할 수 있어요. 그런데 email에 UNIQUE를 더하려고 하니 ERROR가 나요. kim@mail.com이 이미 두 번 들어 있어서예요. 규칙은 새로 들어올 행뿐 아니라 지금 있는 행까지 검사해요. 36에서 배운 UPDATE로 lee의 이메일을 고친 뒤 다시 치면 ALTER TABLE이 나오고 규칙이 붙어요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
