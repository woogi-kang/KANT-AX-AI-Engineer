붙이는 말

언제

(안 적음)

자식이 있으면 DELETE를 막아요

기본값, 주문 기록

ON DELETE RESTRICT

자식이 있으면 DELETE를 막아요

막는다는 뜻을 적어 두고 싶을 때

ON DELETE CASCADE

자식 행도 같이 지워요

장바구니, 회원의 설정

ON DELETE SET NULL

자식의 외래 키 칸을 NULL로 바꿔요

탈퇴해도 주문은 남길 때

kant_shop=# DELETE FROM member WHERE id = 1;

ERROR:  update or delete on table "member" violates RESTRICT setting of

       foreign key constraint "orders_member_id_fkey" on table "orders"

DETAIL:  Key (id)=(1) is referenced from table "orders".

kant_shop=# SELECT * FROM orders;

id | member_id | total

----+-----------+--------

 1 |           | 104000

(1 row)

RESTRICT로 만든 표에서 kim 지우기

SET NULL로 만든 표, kim을 지운 뒤

부모 행을 지울 때 자식 행을 어떻게 할지는 ON DELETE 뒤에 적어요. 아무것도 안 적으면 앞 장처럼 DELETE를 막아요. RESTRICT도 막아요. 아래 왼쪽처럼 오류 문장에 RESTRICT setting이 들어가는 것만 달라요. 막는다는 뜻을 표 설계에 적어 두고 싶을 때 써요. CASCADE는 자식 행도 같이 지워요. SET NULL은 자식 행은 남기고 외래 키 칸만 NULL로 바꿔요. 아래 오른쪽처럼 kim의 주문이 남고 member_id 칸이 비었어요. 매출 기록은 남겨야 하니 이런 경우에 써요. 이때 그 열에는 NOT NULL을 붙이면 안 돼요. psql 화면은 tools/demo.py로 실제 postgres:18 컨테이너에서 실행한 결과예요.
