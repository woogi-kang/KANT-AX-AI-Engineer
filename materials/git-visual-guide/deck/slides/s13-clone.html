GitHub 저장소를
통째로 복사

init + remote add + 받기를 한 번에

팀원이 이 저장소에 합류하는 장면입니다. clone은 폴더 만들기, git init, remote add origin, 커밋 받기를 한 번에 해요. clone한 폴더에서 init이나 remote add를 다시 하지 않아요. 팀원은 이어서 README.md를 만들고 add → commit → push 합니다(docs: README 추가).
