$ git commit -m "feat: 새 파일"

$ git commit -m "fix: 오타 수정"

② 대기실이 비어 있어요

git add 파일

git commit -m "..."

commit은 대기실에 있는 것만 기록해요. 빨간 글씨가 보이면 아직 대기실 밖이라는 뜻이니 add부터. 출력 끝의 (use "git add" to track) 같은 안내 문구는 화면 폭 때문에 줄였습니다.
