init으로 시작? clone으로 시작?

GitHub에 아직 없음

git init

add → commit

git remote add origin 주소

git push origin main

GitHub에 이미 있음

git clone 주소

cd 폴더이름

add → commit

git push origin main

둘 중 하나만. 시작한 뒤에는 똑같아요.

판단 기준은 하나예요. GitHub에 저장소가 이미 있나? 있으면 clone, 없으면 init. 과제 템플릿이나 팀 프로젝트는 대부분 clone입니다. clone한 폴더에서 init이나 remote add를 또 하면 error: remote origin already exists. 가 나요.
