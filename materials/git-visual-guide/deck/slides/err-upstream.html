에러 4 · 어디로 보낼지 안 적음

git push만 쳤더니 거절돼요

$ git push

fatal: The current branch main has no upstream branch.

$ git pull

There is no tracking information for the current branch.

우리 과정 규칙: 어디로, 무엇을 항상 적기

git push

origin

main

git pull

origin

main

--set-upstream(-u) 안내가 떠도 쓰지 않아요

-u로 짝을 지어 두지 않았기 때문에 git push, git pull만 치면 Git이 어디로 보낼지 몰라서 멈춥니다. 우리 과정에서는 -u를 쓰지 않기로 했으니, 에러 메시지가 git push --set-upstream origin main을 권해도 따르지 말고 git push origin main처럼 끝까지 적어요.
