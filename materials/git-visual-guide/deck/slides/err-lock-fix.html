지우는 건 index.lock 하나만. index나 .git 폴더는 절대 지우지 않아요.

1번은 열려 있는 커밋 에디터, 다른 터미널 창, VS Code의 Git 작업을 확인하는 단계예요. 이걸 건너뛰고 지우면 실제로 돌던 작업과 부딪힐 수 있어요. 명령은 .git 폴더가 있는 저장소 맨 위에서 실행합니다. 메시지 원문 뒷부분은 "다른 git이 실행 중인 것 같다, 예전에 비정상 종료됐다면 파일을 직접 지워라"라는 뜻이에요.
