팀원 커밋

서로 모르는 커밋이 생겼어요

1. git pull origin main

2. git push origin main

--force는 쓰지 않아요

Git은 팀원의 커밋을 지우지 않으려고 push를 막아요. 먼저 받아서 합친 뒤 다시 보내면 됩니다. GitHub에서 README를 체크해 저장소를 만들었거나 웹에서 파일을 고친 경우 혼자 작업해도 이 에러가 나요. 같은 줄을 고쳤다면 pull 할 때 충돌이 나고, 해결한 뒤 add, commit, push 순서로 마무리합니다. --force는 팀원 커밋을 지워 버려요.
