처음부터 순서대로 읽는 덱이 아니에요. 수업 중에 모르는 말이 나오면 2쪽 목차나 맨 뒤 38–39쪽 찾아보기에서 쪽을 찾아 펴 봐요. 그림은 대부분 03_ml 노트북의 공부 시간 5명 데이터(1~5시간, 47·53·65·73·87점)로 그렸어요.

## 이런 분께 맞아요

- 같은 X를 피쳐, 특성, 독립변수로 불러서 같은 건지 헷갈려요.
- `coef_` 옆의 기울기와 경사 하강법의 기울기가 같은 말인지 모르겠어요.
- 2차함수, 미분, 학습률, epoch가 코드 어디에 나오는지 짚지 못하겠어요.
- MSE 3.2를 "3.2점 틀렸다"로 읽어도 되는지, R²가 마이너스일 수 있는지 궁금해요.

## 핵심 개념

### 같은 것, 다른 이름

| 이 덱에서 부르는 말 | 같은 말 | 코드 |
| --- | --- | --- |
| 특성 | 문제, feature, 피쳐, 독립변수 | `X = df[["hours"]]` |
| 타깃 | 정답, target, 종속변수 | `y = df["scores"]` |
| 기울기 w | coef_, weight, 가중치 | `model.coef_[0]` |
| 절편 b | intercept_, bias, 편향 | `model.intercept_` |
| 손실 | loss, 비용 | `loss="squared_error"` |
| 학습률 | learning rate, η(에타), 보폭 | `eta0=0.01` |

### 기울기는 두 개예요

| | 직선의 기울기 w | 손실의 기울기(경사) |
| --- | --- | --- |
| 어느 그래프? | 공부 시간과 점수 | w와 손실 MSE |
| 뜻 | 1시간에 오르는 점수 | w를 늘리면 손실이 변하는 양 |
| 예 | 10 | w가 8일 때 −44 |
| 누가 쓰나? | 모델이 배워서 갖는 값 | w를 고칠 방향을 정하는 값 |

### 공부 시간 5명으로 본 숫자

| 용어 | 값 | 쪽 |
| --- | --- | :---: |
| 기울기 w, 절편 b | 10, 35 | 12 |
| MAE | 1.6점 | 14 |
| MSE, RMSE | 3.2(점수²), 1.79점 | 15 |
| R² | 0.98 | 16 |
| w를 8~12로 바꾼 손실 | 47.2, 14.2, 3.2, 14.2, 47.2 | 19 |
| w가 8일 때 경사 | −44 | 21 |
| 학습률 0.001, 0.01, 0.3으로 1000 epoch | 33.13, 3.25, 3.24e+24 | 23 |

## 문제 해결

| 이럴 때 | 보는 쪽 |
| --- | --- |
| `coef_`가 왜 배열이고 `[0]`을 붙이는지 모르겠어요 | 12, 29 |
| R²가 마이너스로 나왔어요 | 16, 33 |
| 학습률을 키웠더니 손실이 `e+24`처럼 커졌어요 | 23, 34 |
| `max_iter`를 바꿔도 `partial_fit` 결과가 그대로예요 | 24, 35 |
| 50에서 공부 시간 계수가 혼자일 때보다 작아졌어요 | 29 |

## 강사용

- 그림의 숫자와 코드 출력은 `tools/demo.sh`가 45~49처럼 uv 프로젝트(`numpy pandas`, `--dev ipykernel`, `seaborn matplotlib`, `scikit-learn`)를 만든 뒤 `tools/terms.py`의 셀을 노트북처럼 실행해서 얻었어요. 결과는 `tools/data.json`, 실행 기록은 `tools/demo.log`예요.
- 다시 만들 때: `CSV=47의 usa_housing.csv 경로 bash tools/demo.sh /tmp/새폴더 > tools/demo.log 2>&1` 뒤 `python3 tools/gen.py slides`, `node ../../tools/build_player.js slides ml-terms-slides.html`.
- 학습률 장의 세 그림은 w만 움직인 계산이고(b는 35로 고정), 아래 출력은 실제 `SGDRegressor`를 1000번 학습한 값이에요. 수업에서 쓴 0.01과 비교하려고 0.001과 0.3을 골랐어요.
- 50 쪽의 혼자 학습한 공부 시간 기울기 8.9는 50 챕터 작업에서 실행한 값이에요.
- 수업 노트북 마크다운의 6시간 예측 96점은 실제 실행에서 95.0점이라 37쪽 노트에 밝혔어요.
