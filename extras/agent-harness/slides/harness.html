그래서 2026년에는 규칙, 도구, 권한, 검사를 묶어 설계하는 일을 하네스 엔지니어링이라고 불러요.

다음 파트부터 Claude Code의 하네스를 한 칸씩 뜯어 봐요.

하네스 엔지니어링은 모델을 그대로 두고 모델이 일하는 환경을 바꾸는 일이에요. 왼쪽 그림처럼 프롬프트, 컨텍스트, 루프, 그래프가 차례로 바깥을 감싸고, 맨 바깥이 하네스예요. 2026년 LangChain은 코딩 에이전트 시험인 Terminal Bench 2.0에서 모델은 바꾸지 않고 하네스만 고쳐서 52.8%를 66.5%로 올렸다고 발표했어요. 이 말은 2026년 초 미첼 하시모토, OpenAI 같은 곳에서 쓰기 시작해 널리 퍼졌어요. 다음 파트부터 Claude Code의 하네스를 한 칸씩 뜯어 봐요. 숫자는 LangChain 블로그 글 Improving Deep Agents with harness engineering에서 옮겼어요.
