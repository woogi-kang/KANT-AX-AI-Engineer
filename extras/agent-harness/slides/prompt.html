main.py를 실행하면 합계가 이상해. 고쳐 줘.

너는 파이썬 강사야.

아래 코드에서 합계가 틀린 줄을 찾아

고친 줄만 보여 줘.

for item in order: total = prices[item] print("합계:", total)

부딪힌 벽

코드를 직접 붙여 넣지 않으면 모델은 main.py를 볼 수 없어요. 다른 파일, 실행 결과, 팀의 규칙도 몰라요.

잘 묻는 기술은 지금도 쓸모 있어요. 다만 그것만으로는 모자라요.

프롬프트 엔지니어링은 질문 한 문장을 다듬는 일이에요. 짧은 부탁을 역할, 할 일, 답 모양이 분명한 부탁으로 바꾸면 답이 좋아져요. 코드를 붙여 넣으면 더 좋아져요. 그런데 붙여 넣은 것 말고는 모델이 아무것도 몰라요. 프로젝트의 다른 파일도, 실행 결과도, 팀이 정한 규칙도 모르죠. 앞에서 도구 없이 부탁했을 때 명령을 글로만 적고 끝난 것도 같은 벽이에요. 이 벽 때문에 무엇을 보여 줄지를 다듬는 쪽으로 관심이 옮겨 갔어요.
