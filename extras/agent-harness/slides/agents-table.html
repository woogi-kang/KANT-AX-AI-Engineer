AGENTS.md는 Linux Foundation 산하 Agentic AI Foundation이 관리하는 공개 형식이에요.
Antigravity CLI는 2026년에 Gemini CLI 자리를 이어받은 도구예요.

이름만 다르고 규칙 파일, 스킬, MCP라는 뼈대는 같아요.

다른 에이전트 도구도 같은 부품을 써요. OpenAI의 Codex CLI는 AGENTS.md를 읽고, Google의 Antigravity CLI는 GEMINI.md와 AGENTS.md를 읽어요. Claude Code는 CLAUDE.md를 읽고, CLAUDE.md가 없으면 AGENTS.md를 읽어요. 스킬도 같은 SKILL.md 형식이라 폴더만 달라요. 외부 서비스는 셋 다 MCP로 붙여요. AGENTS.md는 OpenAI가 내놓은 형식인데, 지금은 Linux Foundation 산하 Agentic AI Foundation이 관리해요. Gemini CLI는 2026년부터 Antigravity CLI로 옮겨 가는 중이에요. 도구 이름과 폴더는 자주 바뀌니 쓰기 전에 각 도구의 문서를 한 번 확인해요. 표의 내용은 2026년 11월 기준이에요.
