지금 보는 이 덱도 이 하네스를 거쳐 만들었어요.

첫 번째 실제 예는 지금 보는 수업 자료 레포예요. CLAUDE.md에 수업 규칙과 덱 만들기 다섯 단계를 적어 두었어요. 덱 디자인처럼 긴 절차는 tools 폴더의 문서로 떼어 내고 덱을 만들 때만 읽어요. 글자가 넘치는지는 boxcheck, 모든 장의 모습은 playshots 스크린샷으로 검사해요. README 표는 curriculum.json 한 곳에서만 고치고 --check로 어긋남을 찾아요. 여러 챕터는 작업을 나눠 동시에 만들어요. 마지막에는 강사가 전후 미리보기를 본 뒤에 main에 올려요. 사람이 확인하는 단계도 하네스의 한 칸이에요.
