block_rm.py

Bash

실제 실행

종료 코드 2면 여기서 멈추고
이유가 모델에게 전달돼요

.claude/hooks/block_rm.py

import json

import sys

 

data = json.load(sys.stdin)

command = data["tool_input"].get("command", "")

 

if "rm -rf" in command:

print("rm -rf는 막아 두었어요. ...", file=sys.stderr)

sys.exit(2)

.claude/settings.json

"hooks": {

"PreToolUse": [{

"matcher": "Bash",

"hooks": [{

"type": "command",

"command":

"python3 .claude/hooks/block_rm.py"

}]

}]

}

훅은 모델이 잊어도 코드로 늘 돌아요. 규칙 파일과 다른 점이에요.

훅은 도구가 돌기 직전이나 직후에 끼어드는 검문소예요. PreToolUse 훅은 모델이 도구를 부른 뒤, 실제로 실행되기 전에 돌아요. 훅에는 도구 이름과 입력이 JSON으로 들어와요. 이 파이썬 파일은 명령에 rm -rf가 있으면 이유를 적고 종료 코드 2로 끝내요. 종료 코드 2를 받으면 Claude Code는 도구를 실행하지 않고, 그 이유를 모델에게 전해요. 연결은 settings.json의 hooks에 적어요. matcher가 Bash라서 Bash를 부를 때만 이 훅이 돌아요. 규칙 파일은 모델이 잊을 수 있지만 훅은 코드라서 매번 돌아요. 파일을 고친 뒤 검사를 돌리는 PostToolUse 훅도 같은 방식이에요.
