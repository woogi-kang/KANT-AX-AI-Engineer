## Claude Code에서만

- 훅은 .claude/settings.json에 있어요.

← AGENTS.md 내용을 그대로 불러와요

읽는 방식은 /config의 Project instructions에서 바꿀 수 있어요. 기본값은 CLAUDE.md가 없을 때만 AGENTS.md를 읽어요.

공통 규칙은 AGENTS.md에, Claude Code만의 설정은 CLAUDE.md에 둬요.

AGENTS.md 하나를 여러 도구가 같이 읽을 수 있어요. CLAUDE.md를 지우고 같은 다섯 줄을 AGENTS.md에만 둔 뒤 같은 부탁을 했더니, Claude Code가 AGENTS.md를 읽고 규칙대로 고쳐서 14,500원을 확인했어요. 주의할 점이 있어요. 두 파일이 모두 있으면 기본값에서는 CLAUDE.md만 읽고 AGENTS.md는 건너뛰어요. 그래서 CLAUDE.md 첫 줄에 @AGENTS.md를 적어 AGENTS.md 내용을 불러오고, 그 아래에 Claude Code만의 내용을 적어요. 읽는 방식은 /config의 Project instructions에서 바꿀 수 있어요. AGENTS.md를 읽는 기능은 2026년 9월에 들어왔어요. 화면의 대화와 출력은 Claude Code로 실제로 실행한 결과예요. 긴 임시 폴더 경로는 줄였어요.
