.claude/skills/menu-update/SKILL.md

---

name: menu-update

description: 메뉴나 가격을 바꿀 때 써요.

prices와 README 가격표를 같이 고쳐요.

---

 

1. main.py의 prices 딕셔너리를 고쳐요.

2. README.md 가격표도 같은 값으로 고쳐요.

3. uv run main.py로 합계를 확인해요.

처음엔 이 두 줄만 창에 들어가요

menu-update

메뉴나 가격을 바꿀 때 써요.

release-note

학생 공지를 쓸 때 써요.

deck-check

덱 검수할 때 써요.

"라떼를 5500원으로 바꿔 줘" 같은 부탁이 오면 그때 본문을 읽어요. 직접 /menu-update로 불러도 돼요.

같은 SKILL.md 형식을 Codex CLI와 Antigravity CLI도 .agents/skills 폴더에서 읽어요 (공개 형식 agentskills.io).

CLAUDE.md는 늘 들어가고, 스킬은 필요할 때만 들어가요.

스킬은 필요할 때 펴 보는 레시피 카드예요. 폴더 하나에 SKILL.md를 두고, 맨 위에 이름과 언제 쓰는지를 적어요. Claude Code는 처음에 모든 스킬의 이름과 설명만 창에 넣어요. 그러다 설명과 맞는 부탁이 오면 그 스킬의 본문을 읽고 순서대로 해요. 그래서 스킬이 많아도 창을 많이 차지하지 않아요. 슬래시 명령처럼 이름으로 직접 불러도 돼요. CLAUDE.md가 늘 지킬 약속이라면, 스킬은 가끔 하는 긴 절차를 담아요. 같은 형식을 Codex CLI와 Antigravity CLI도 읽어요.
