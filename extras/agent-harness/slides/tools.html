도구는 이름, 설명, 입력 칸으로 생겼어요. 모델은 도구를 직접 만지지 않고, 도구 설명을 읽은 뒤 어떤 도구를 어떤 값으로 부를지 글로 적어요. 그러면 하네스가 그 도구를 대신 실행하고 결과를 돌려줘요. 오른쪽은 3파트 실행에서 모델이 실제로 적은 호출이에요. command 칸에 uv run main.py를 넣었고, 결과로 합계 14,500원이 돌아왔어요. Claude Code에는 파일 읽기, 고치기, 명령 실행 같은 기본 도구가 있어요. MCP로 도구를 직접 붙일 때는 설명을 구체적으로 써야 모델이 제때 골라요. 화면의 대화와 출력은 Claude Code로 실제로 실행한 결과예요. 긴 임시 폴더 경로는 줄였어요.
