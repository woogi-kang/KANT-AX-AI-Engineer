JSON을 넣어 주면 이유를 출력하고 종료 코드 2로 끝나요. 아래는 Claude Code에 같은 부탁을 한 실제 기록이에요. 첫 명령에 rm -rf가 들어 있어서 훅이 막았어요. 모델은 막힌 이유를 읽고 폴더 안을 먼저 확인했어요. 그다음 파일 하나를 rm으로 지우고 빈 폴더를 rmdir로 지웠어요. 훅이 알려 준 대로 파일을 하나씩 지운 거예요. 훅 메시지는 일부만 옮겼어요. 화면의 대화와 출력은 Claude Code로 실제로 실행한 결과예요. 긴 임시 폴더 경로는 줄였어요.
