MCP는 에이전트와 외부 서비스를 잇는 공통 규격이에요. 노트북의 USB-C 포트처럼, 서비스가 MCP 서버를 하나 만들어 두면 어떤 에이전트든 같은 방식으로 꽂아 써요. GitHub 서버를 붙이면 이슈와 PR을 읽고 쓰는 도구가 생기고, PostgreSQL 서버를 붙이면 44에서 파이썬으로 하던 조회를 에이전트가 해요. Anthropic이 2024년 11월에 공개했고, 지금은 AGENTS.md와 같은 Agentic AI Foundation이 관리해요. 아래 명령은 Claude Code에 GitHub의 공식 MCP 서버를 붙이는 예예요. 실제로 붙이려면 GitHub 로그인이 더 필요해요.
