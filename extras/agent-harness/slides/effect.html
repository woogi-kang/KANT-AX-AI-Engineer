python3 main.py

uv run main.py

출력 모양

print("합계:", total)

확인한 결과

승인이 없어 못 돌렸어요

합계: 14,500원

두 번 모두 같은 모델, 같은 부탁이에요. 달라진 건 폴더에 둔 파일 하나예요.

규칙 몇 줄로 결과가 달라졌어요. 왼쪽은 1파트에서 본 규칙 없는 실행이고, 오른쪽은 앞 장의 CLAUDE.md를 둔 뒤 같은 부탁을 한 실행이에요. CLAUDE.md에 실행 명령을 적어 두니 모델이 uv run main.py로 확인했어요. 허락해 둔 명령이라 막히지 않았죠. 출력도 규칙대로 천 단위 콤마와 원을 붙였어요. 마지막에 다시 실행해서 합계 14,500원을 직접 확인한 뒤 답했어요. 모델도 부탁도 같고, 달라진 건 폴더에 둔 파일 하나예요. 화면의 대화와 출력은 Claude Code로 실제로 실행한 결과예요. 긴 임시 폴더 경로는 줄였어요.
