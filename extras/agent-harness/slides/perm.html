4 · 도구와 권한

권한: 무엇을 묻고 무엇을 바로 할지 정해요

manual

도구를 쓸 때마다 물어요

acceptEdits

파일 고치기는 바로, 명령은 물어요

plan

읽기만 하고 계획을 세워 보여 줘요

auto

안전해 보이는 일은 바로, 위험하면 멈춰요

bypassPermissions

묻지 않아요. 격리된 곳에서만 써요

Shift+Tab

으로 대화 중에 모드를 바꿔요

.claude/settings.json

{

"permissions": {

"allow": ["Bash(uv run *)"],

"deny": ["Read(./.env)", "Bash(rm -rf *)"]

}

}

← 묻지 않고 실행

deny에 적은 일은 모드와 상관없이 막혀요. 1파트에서 본 "승인이 필요해요"는 allow에 없던 python3 main.py가 걸린 거예요.

권한은 무엇을 묻고 무엇을 바로 할지 정하는 장치예요. 처음엔 도구를 쓸 때마다 물어요. 파일 고치기를 믿을 만하면 acceptEdits로, 먼저 계획만 보고 싶으면 plan으로 바꿔요. auto는 안전해 보이는 일은 바로 하고 위험해 보이면 멈춰요. bypassPermissions는 아무것도 묻지 않아서 컨테이너처럼 격리된 곳에서만 써요. 대화 중에는 Shift+Tab으로 모드를 바꿔요. 자주 쓰는 명령은 settings.json의 allow에, 절대 안 될 일은 deny에 적어요. 1파트 실행이 막힌 것도 allow에 uv run만 있어서였어요.
