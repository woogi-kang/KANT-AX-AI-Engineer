3. 이름에 담긴 관례

git push origin main을 도움말로 읽어 봐요

git push -h 첫 줄

usage: git push [<options>] [<repository> [<refspec>...]]

git push origin main

어디로 · 원격 이름

무엇을 · 브랜치 이름

도움말의 <repository> 자리에 origin, <refspec> 자리에 main을 넣었어요. git pull origin main도 같은 순서예요.

우리 과정은 이 두 칸을 매번 끝까지 적어요.

git push origin main은 도움말 첫 줄의 두 자리에 origin과 main을 넣은 거예요. git push -h를 치면 맨 위에 사용법 한 줄이 나와요. 꺾쇠 안의 repository는 원격 저장소 이름, refspec은 보낼 브랜치를 가리키는 자리예요. 대괄호는 다음 파트에서 봐요. 우리 과정에서는 이 두 칸을 생략하지 않고 매번 적어요. 그래야 어디로 무엇을 보내는지 눈으로 확인할 수 있어요. 옵션 목록은 길어서 첫 줄만 옮겼어요.
