2. 위치가 맞아야 명령이 동작해요

같은 uv run main.py, 폴더에 따라 결과가 달라요

kant에서 · main.py가 없어요

~/kant $ pwd

/home/kim/kant

~/kant $ uv run main.py

error: Failed to spawn: `main.py`

Caused by: No such file or directory (os error 2)

hello-uv에서 · main.py가 있어요

~/kant/hello-uv $ ls

README.md main.py pyproject.toml

~/kant/hello-uv $ uv run main.py

Hello from hello-uv!

명령 뒤의 파일 이름은 지금 폴더에서 찾아요

main.py는 hello-uv 안에 있어요. kant에서 치면 uv가 main.py를 못 찾아요.
No such file or directory가 보이면 먼저 pwd와 ls를 쳐요.

명령이 틀린 게 아니라 서 있는 폴더가 틀렸어요.

같은 명령을 두 폴더에서 쳤어요. kant에는 main.py가 없어서 uv가 Failed to spawn, No such file or directory를 보여 줘요. hello-uv로 들어가서 치면 09에서 본 Hello from hello-uv!가 나와요. 출력은 tools/demo.sh에서 실제로 실행한 결과예요. 이런 에러를 보면 명령을 고치기 전에 pwd와 ls로 위치부터 봐요.
