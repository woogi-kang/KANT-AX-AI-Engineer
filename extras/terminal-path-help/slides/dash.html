3. 이름에 담긴 관례

대시 하나는 한 글자, 대시 둘은 단어

짧은 이름

긴 이름

--help에 적힌 줄

ls -a

ls --all

-a, --all

uv -h

uv --help

-h, --help

git commit -m

git commit --message

-m, --[no-]message

한 글자 옵션은 붙여 써요

ls -al

=

ls -a -l

01에서 쓴 ls -al이 이 모양이에요

짧은 이름은 치기 편하고, 긴 이름은 읽기 쉬워요. 뜻은 같아요.

옵션은 명령 뒤에 붙어서 동작을 조금 바꾸는 말이에요. 대시 하나 뒤에는 한 글자, 대시 둘 뒤에는 단어 전체를 적는 것이 오래된 약속이에요. 오른쪽은 각 도구의 도움말에 실제로 적힌 줄이에요. 짧은 이름과 긴 이름을 쉼표로 나란히 적어 둬요. git의 --[no-]message는 --message와 --no-message를 같이 적은 표기예요. 한 글자 옵션은 ls -al처럼 대시 하나 뒤에 여러 개를 붙일 수 있어요. 긴 이름은 붙일 수 없어요.
