4. 도움말로 스스로 찾기

git은 도움말을 세 가지로 보여 줘요

명령

보여 주는 것

이럴 때

열리는 곳

git --help

자주 쓰는 명령 목록

명령 이름이 기억나지 않을 때

터미널에 바로

git 명령 -h

그 명령의 짧은 옵션표

옵션 글자가 기억나지 않을 때

터미널에 바로

git 명령 --help

그 명령의 설명서 전체

자세한 설명과 예시가 필요할 때

Mac은 설명서 화면
Windows는 브라우저

예

git commit -h짧게  git commit --help자세히  git help commit--help와 같아요

git에서는 -h와 --help가 달라요. 처음엔 -h부터 쳐요.

git은 -h와 --help를 다르게 써요. git 명령 -h는 터미널에 옵션표를 짧게 바로 보여 줘요. git 명령 --help는 그 명령의 설명서 전체를 열어요. Mac과 Linux는 터미널 안에 설명서 화면이 열리고, Windows Git Bash는 브라우저에 설명서 웹 페이지가 열려요. git help commit은 git commit --help와 같아요. 명령 이름 자체가 기억나지 않으면 git --help로 목록부터 봐요.
