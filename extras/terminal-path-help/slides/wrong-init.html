VS Code에 바뀐 파일이 수천 개 떠요

02에서 git init은 프로젝트 폴더 안에서 쳤어요. 실수로 홈 폴더에서 치면 홈 폴더 전체가 저장소가 돼요. git status를 치면 Desktop, Documents까지 모두 Untracked로 나와요. 출력은 tools/demo.sh가 만든 연습용 홈 폴더에서 실제로 실행한 결과라 목록이 짧아요. 실제 컴퓨터에서는 훨씬 길어요. 그 아래 모든 폴더에서 git status가 동작해서, 저장소가 아닌 폴더인데도 에러가 안 나요. Windows Git Bash는 저장소 안이면 프롬프트에 (main)을 붙여서 홈 폴더에 (main)이 보이면 이 경우예요. 다음 장에서 되돌려요.
