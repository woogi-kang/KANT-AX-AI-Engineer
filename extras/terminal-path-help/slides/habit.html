2. 위치가 맞아야 명령이 동작해요

치기 전에 보고, 친 뒤에 다시 봐요

1

어디?

프롬프트, pwd

2

무엇이?

ls

3

명령 치기

cd, uv run, git add

4

잘 됐나?

ls, git status

다음 명령도 1부터

명령이 바꾼 것은 화면에 안 보여요. 그래서 친 뒤에 한 번 더 봐요.

터미널 작업은 이 네 단계를 돌아요. 1번 프롬프트나 pwd로 어디에 있는지 보고, 2번 ls로 안에 무엇이 있는지 봐요. 3번 명령을 치고, 4번 ls나 git status로 결과가 내가 바란 대로인지 봐요. 탐색기는 파일이 생기면 바로 보이지만 터미널은 아무 말도 안 하는 명령이 많아요. cd, mkdir, git add는 성공해도 출력이 없어요. 그래서 4번에서 확인하는 습관이 필요해요. 4번을 마치면 다음 명령도 다시 1번부터 돌아요.
