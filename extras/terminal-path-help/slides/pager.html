GIT-COMMIT(1) Git Manual GIT-COMMIT(1)

 

NAME

git-commit - Record changes to the repository

 

SYNOPSIS

git commit [-a | --interactive | --patch] [-s] [-v] [-u<mode>]

…

 

DESCRIPTION

Create a new commit containing the current contents of the

index and the given log message describing the changes. …

git log가 길 때도 이 화면이 나와요.
맨 아래에 : 이나 (END)가 보이면 q예요.

Mac과 Linux에서 git commit --help나 man ls를 치면 터미널 전체가 설명서 화면으로 바뀌고, q로 나와요. 명령을 쳐도 반응이 없어서 멈춘 것처럼 보여요. 이 화면에서는 Space로 다음 쪽, b로 앞 쪽, 슬래시 뒤에 단어를 치고 Enter로 찾아요. 왼쪽 그림은 설명서 화면을 줄여 그린 거예요. 설명서 화면은 이 자료를 만든 환경에서 열 수 없어서 실제 출력을 옮기지 않았어요. Windows Git Bash는 --help가 브라우저로 열려서 이 화면이 나오지 않아요. 02에서 git log 기록이 길 때도 같은 화면이 나와요. 그때도 q예요.
