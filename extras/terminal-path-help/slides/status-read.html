git status는 지금 상태와 다음에 칠 명령을 같이 알려 줘요. 06에서 clone한 team-intro에 kim.md를 하나 만들고 git status를 쳤어요. 1번 On branch main은 지금 main 이름표에 있다는 뜻이에요. 2번은 내 컴퓨터가 기억하는 origin/main과 비교한 결과예요. GitHub의 최신 상태는 git fetch origin을 해야 반영돼요. 3번 Untracked는 02에서 본 새 파일 상태예요. 4번 괄호 안은 다음에 칠 명령 힌트예요. 마지막 줄은 화면 폭 때문에 두 줄로 나눠 적었어요. git status는 아무것도 바꾸지 않으니 몇 번을 쳐도 괜찮아요. 출력은 tools/demo.sh에서 실제로 실행한 결과예요.
