3. 이름에 담긴 관례

관례는 약속일 뿐이라 예외가 있어요

~/kant/hello-uv $ ls -h

README.md pyproject.toml

main.py uv.lock

~ $ git -v

git version 2.43.0

~ $ uv -V

uv 0.11.32 (x86_64-unknown-linux-gnu)

ls -h는 help가 아니에요

크기를 읽기 쉽게 보여 주는 옵션이에요

버전 글자가 달라요

git은 -v, uv는 대문자 -V

Mac 기본 ls는 --help를 몰라요. man ls로 설명서를 열고 q로 나와요.

헷갈리면 긴 이름 --help부터 쳐 봐요. 가장 많이 통해요.

ls -h는 도움말이 아니라 human-readable 옵션이라 그냥 목록이 나와요. ls -lh처럼 -l과 같이 쓸 때 파일 크기를 4.0K처럼 보여 줘요. 버전 글자도 도구마다 달라요. git은 -v와 --version이 같고, uv는 대문자 -V와 --version이 같아요. uv의 소문자 -v는 verbose예요. Mac 기본 ls, cp, mv는 --help를 몰라서 에러와 짧은 사용법만 보여 줘요. 이때는 man(manual, 설명서) 명령으로 설명서를 열어요. Windows Git Bash는 ls --help가 돼요. ls -h는 좁은 터미널(ls -C -w 40)에서 실행한 모양이에요. Mac 출력은 이 자료를 만든 환경에서 실행할 수 없어서 옮기지 않았어요. 출력은 tools/demo.sh에서 실제로 실행한 결과예요.
