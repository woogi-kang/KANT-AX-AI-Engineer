4. 도움말로 스스로 찾기

오타를 내면 도구가 먼저 알려 줘요

git stauts

~/kant/team-intro $ git stauts

git: 'stauts' is not a git command.

See 'git --help'.

 

The most similar command is

status

uv ad fastapi

~/kant/hello-uv $ uv ad fastapi

error: unrecognized subcommand 'ad'

 

tip: some similar subcommands

exist: 'audit', 'add'

 

Usage: uv [OPTIONS] <COMMAND>

 

For more information, try '--help'.

에러 메시지는 맨 아래 몇 줄을 읽어요. 노란 줄만 읽어도 고칠 수 있어요.

명령 이름을 잘못 치면 git과 uv 모두 비슷한 이름을 찾아 줘요. git stauts에는 status를, uv ad에는 audit과 add를 권해요. 끝에는 --help를 쳐 보라는 안내도 있어요. 에러가 나면 지우고 다시 치기 전에 맨 아래 몇 줄을 소리 내어 읽어 봐요. 위 화살표로 앞 명령을 불러와 고치면 빨라요. 화면 폭 때문에 긴 줄은 나눠 적었어요. 출력은 tools/demo.sh에서 실제로 실행한 결과예요.
