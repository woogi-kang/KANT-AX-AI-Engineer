오늘 본 내용을 세 묶음으로 모았어요. 어디에 있는지는 pwd, ls, git status로 보고, cd 네 가지로 옮겨 다녀요. 막히면 --help나 -h로 도움말을 봐요. 설명서 화면이 열리면 q로 나와요. 수업 중에 터미널이 이상하면 이 장을 띄워 두고 위에서부터 하나씩 쳐 봐요.
