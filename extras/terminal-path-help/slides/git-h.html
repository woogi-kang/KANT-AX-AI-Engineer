4. 도움말로 스스로 찾기

git commit -h는 옵션 글자가 기억나지 않을 때 봐요

~/kant/team-intro $ git commit -h

usage: git commit [-a | --interactive | --patch] [-s] [-v] [-u<mode>] [--amend]

…

 

-q, --[no-]quiet suppress summary after successful commit

-v, --[no-]verbose show diff in commit message template

 

Commit message options

-F, --[no-]file <file>

read message from file

--[no-]author <author>

override author for commit

--[no-]date <date> override date for commit

-m, --[no-]message <message>

commit message

…

찾던 줄

-m <message>

<message>가 붙어 있으니
메시지를 꼭 적어요

목록이 70줄쯤 돼요.
지금 찾는 한 줄만 봐요.

커밋 메시지 옵션이 기억나지 않으면 git commit -h를 쳐요. 사용법 줄과 뒤쪽 목록은 …로 줄였어요. Commit message options 묶음 안에 -m, --[no-]message <message>가 있어요. 꺾쇠가 붙어 있으니 -m 뒤에 메시지를 적어야 해요. 그래서 git commit -m "docs: 소개 추가"처럼 써요. 위가 잘리면 터미널을 위로 스크롤해요. 출력은 tools/demo.sh에서 실제로 실행한 결과예요.
