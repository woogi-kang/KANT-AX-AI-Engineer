3. 이름에 담긴 관례

origin과 main도 관례로 붙인 이름이에요

origin

원래(origin) 가져온 곳

~/kant/team-intro $ git remote -v

origin https://github.com/kim/team-intro.git (fetch)

origin https://github.com/kim/team-intro.git (push)

• 02 · git remote add origin 주소로 직접 붙였어요

• 06 · clone하면 git이 origin으로 붙여 줘요

main

주된 줄기, 첫 브랜치 이름

~/kant/team-intro $ git branch

* main

• 02 · init.defaultBranch main으로 정했어요

• 예전 기본 이름은 master, 지금 GitHub은 main

바꿀 수 있는 이름이지만 모두 같은 이름을 써요

그래서 검색한 글, 에러 메시지, 팀원의 명령을 그대로 따라 칠 수 있어요.

git이 정한 명령이 아니라 사람들이 맞춘 이름이에요.

origin은 영어로 출처, 원래 온 곳이라는 뜻이에요. 02에서는 git remote add origin 주소로 이 이름을 직접 붙였고, 06에서 clone할 때는 git이 자동으로 origin이라고 붙였어요. main은 첫 브랜치의 이름이에요. git의 예전 기본 이름은 master였고, GitHub은 2020년부터 새 저장소의 기본 이름을 main으로 바꿨어요. 02에서 init.defaultBranch main을 설정한 이유예요. 출력은 tools/demo.sh의 team-intro에서 실제로 실행한 결과예요. 이름을 바꿀 수는 있지만, 모두 같은 이름을 쓰면 자료와 에러 메시지를 그대로 따라 할 수 있어요.
