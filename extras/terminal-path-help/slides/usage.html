4. 도움말로 스스로 찾기

Usage 줄의 기호 네 가지

[ ]

넣어도 되고 빼도 돼요

< >

내 값으로 바꿔 적어요

...

여러 개 적을 수 있어요

|

둘 중 하나만 골라요

ls --help

Usage: ls [OPTION]... [FILE]...

이렇게 쳐요

lsls -als -a -l notes

옵션도 파일도 없어도 돼요

uv add -h

Usage: uv add [OPTIONS] <PACKAGES|--requirements <REQUIREMENTS>>

이렇게 쳐요

uv add fastapi

패키지 이름은 꼭 넣어요

도움말 맨 위의 Usage(사용법) 줄은 명령을 어떤 순서로 적는지 보여 줘요. 대괄호는 생략할 수 있는 자리, 꺾쇠는 내 값으로 바꾸는 자리예요. 점 세 개는 여러 개를 적을 수 있다는 뜻이고, 세로 막대는 둘 중 하나예요. 대문자 OPTION, FILE은 그 자리에 무엇이 들어가는지 이름만 적은 거예요. ls의 사용법은 전부 대괄호라서 ls만 쳐도 돼요. uv add는 꺾쇠라서 패키지 이름을 꼭 적어요. 두 Usage 줄은 tools/demo.sh에서 실제로 실행한 출력이에요. 앞 장의 git push 사용법도 같은 기호예요.
