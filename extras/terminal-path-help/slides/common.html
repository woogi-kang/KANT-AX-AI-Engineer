3. 이름에 담긴 관례

여러 도구에서 자주 만나는 옵션

-h --help

help

도움말 보기

--version

version

버전 보기

-m

message

메시지 적기

예: git commit -m

-r

recursive

폴더 안까지 전부

예: rm -r

-f

force

묻지 않고 강제로

예: rm -rf

-a

all

숨긴 것까지 전부

예: ls -a

-q

quiet

출력 줄이기

-v

verbose

출력 자세히

대부분 이 뜻이지만 도구마다 다를 수 있어요. 다음 장에서 예외를 봐요.

여러 도구가 같은 글자에 같은 뜻을 붙이는 경우가 많아요. 그래서 처음 보는 도구도 --help, --version은 거의 다 통해요. -m은 git commit -m의 message, -r은 rm -r의 recursive(안쪽까지 되풀이), -f는 rm -rf의 force예요. -q는 quiet(조용히), -v는 verbose(자세히)예요. 이 표는 외울 표가 아니라 이런 약속이 있다는 것만 알면 돼요.
