4. 도움말로 스스로 찾기

모르는 기능을 도움말로 찾아가기

하고 싶은 일

설치한 패키지를 나무 모양으로 보고 싶어요

1

uv --help

tree Display the project's dependency tree

명령 목록에서 tree를 찾았어요

2

uv tree -h

Display the project's dependency tree

 

Usage: uv tree [OPTIONS]

옵션이 다 대괄호라 그냥 쳐도 돼요

3

uv tree

Resolved 1 package in 2ms

hello-uv v0.1.0

패키지를 넣으면 아래로 가지가 늘어요

목록에서 이름 찾기, -h로 쓰는 법 보기, 쳐 보기. 이 세 단계면 돼요.

09에서 uv tree를 배웠지만 이름을 잊었다고 해 볼게요. 1번 uv --help 목록에서 dependency tree라는 설명을 보고 tree를 찾아요. 2번 uv tree -h로 사용법을 보면 [OPTIONS]만 있어서 옵션 없이 쳐도 돼요. 3번 실제로 쳐요. 출력은 tools/demo.sh의 hello-uv에서 실제로 실행한 결과예요. 아직 패키지가 없어서 한 줄이에요. 09처럼 fastapi를 넣었다면 그 아래로 패키지가 줄줄이 나와요. git도 같은 순서로 git --help, git 명령 -h를 보면 돼요.
