3. 이름에 담긴 관례

명령 이름은 영어 단어를 줄인 거예요

pwd

print working directory

ls

list

cd

change directory

mkdir

make directory

mv

move

cp

copy

rm

remove

cat

concatenate

뜻을 알면 외우지 않아도 떠올라요. 처음 보는 명령도 뜻부터 찾아봐요.

01에서 쓴 명령 이름은 모두 영어 단어의 앞 글자나 줄임말이에요. 보라색 글자를 이어 읽으면 명령 이름이 돼요. pwd는 print working directory, 지금 작업 중인 폴더를 출력한다는 뜻이에요. 디렉터리(directory)는 폴더를 부르는 다른 이름이에요. cat은 원래 여러 파일을 이어 붙여 보여 주는 명령이라 이런 이름이 붙었어요. git과 uv도 git add, uv add처럼 영어 동사를 명령 이름으로 써요.
