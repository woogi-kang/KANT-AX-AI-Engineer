1. 탐색기와 터미널 맞춰 보기

탐색기와 터미널을 같은 폴더에서 열어요

터미널에서 지금 폴더를 탐색기로

Mac

~/kant $ open .

Windows Git Bash

~/kant $ explorer .

점(.)은 지금 폴더예요

탐색기에서 터미널로

Mac

폴더 오른쪽 클릭 › 서비스 › 폴더에서 새로운 터미널 열기

Windows

폴더 빈 곳 오른쪽 클릭 › Open Git Bash here

VS Code에서

Windows / Mac

폴더를 열고 Ctrl+` / control+` · 그 폴더에서 터미널이 시작돼요

둘을 나란히 띄우고, 터미널에서 만든 파일이 탐색기에 생기는지 봐요.

탐색기와 터미널을 같은 폴더에 띄워 두면 위치를 덜 헷갈려요. open .은 Mac에서, explorer .은 Windows Git Bash에서 지금 폴더를 탐색기 창으로 열어요. 점은 01에서 배운 지금 폴더예요. 반대로 탐색기에서 보던 폴더에서 터미널을 바로 열 수도 있어요. Mac은 Finder에서 폴더를 오른쪽 클릭하고 서비스 메뉴를 봐요. 메뉴가 없으면 시스템 설정의 키보드 단축키에서 켜요. Windows는 Git을 설치할 때 Open Git Bash here 메뉴가 같이 생겨요. Windows 11은 추가 옵션 표시를 먼저 눌러요. VS Code의 백틱(`)은 숫자 1 왼쪽 키예요. 이 명령들은 출력이 없고 창만 열려요.
