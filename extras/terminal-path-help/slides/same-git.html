2. 위치가 맞아야 명령이 동작해요

git status도 저장소 폴더 안에서만 동작해요

kant에서 · 저장소 밖

~/kant $ git status

fatal: not a git repository

(or any of the parent directories): .git

team-intro에서 · 저장소 안

~/kant/team-intro $ git status

On branch main

Your branch is up to date with 'origin/main'.

 

nothing to commit, working tree clean

git이 .git 폴더를 찾는 길

kant/

.git 없음

kim/

.git 없음

home/

.git 없음

/

.git 없음

team-intro/.git

clone한 폴더 안에는 숨김 폴더 .git이 있어요. 그 안이나 그 아래 폴더에서는 git 명령이 동작해요.

parent directories는 위 폴더들이에요. 끝까지 올라가도 .git이 없다는 뜻이에요.

git은 지금 폴더에서 .git이라는 숨김 폴더를 찾고, 없으면 한 칸씩 위로 올라가며 찾아요. 맨 위 / 까지 가도 없으면 not a git repository (or any of the parent directories)라고 말해요. 화면 폭 때문에 에러를 두 줄로 나눠 적었어요. 실제로는 한 줄이에요. team-intro는 06에서 clone해서 .git이 있어요. 그래서 team-intro 안이나 그 아래 폴더에서 git status가 동작해요. 에러가 나면 cd로 저장소 폴더에 들어가요.
