어디에 있든 cd ~ 한 번이면 홈 폴더로 돌아와요.

어디에 있든 cd ~ 한 번이면 홈 폴더로 돌아와요. Mac Finder 사이드바의 홈, Windows 탐색기 주소 줄의 사용자 이름 폴더가 cd ~와 같아요. 01에서 배운 명령이에요. 길을 잃으면 cd ~로 홈에 돌아온 뒤 다시 cd로 들어가요.
