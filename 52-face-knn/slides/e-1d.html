model.predict(new_photo)

ValueError: Expected 2D array, got 1D array instead:

array=[0.17355372 0.1322314 0.11157025 ... 0.3264463 0.30165288 0.24380165].

Reshape your data either using array.reshape(-1, 1) if your data

has a single feature or array.reshape(1, -1) if it contains a single sample.

2D(두 겹)를 달라는데 1D(한 겹)가 들어왔어요. 모델은 사진 여러 장을 받는 자리라 사진 1장도 한 겹 더 감싸요.

✕

model.predict(new_photo)

✓

model.predict([new_photo])

오류 아래 HINT의 reshape(1, -1)도 같은 일을 해요. 수업에서는 대괄호로 써요.

가장 자주 나는 오류예요. 사진 한 장 new_photo는 숫자 4096개짜리 한 겹 배열이에요. 모델은 사진 여러 장, 곧 두 겹을 받게 만들어져 있어서 Expected 2D array, got 1D array라고 해요. 48에서 predict(33)을 넣었을 때와 같은 오류예요. 대괄호로 한 겹 더 감싸서 사진 1장짜리 묶음으로 넣으면 돼요. 오류 메시지가 알려 주는 reshape(1, -1)도 같은 일을 하지만, 수업에서는 대괄호로 써요. 출력은 실제로 실행한 결과예요.
