4. KNN 학습하고 채점하기

score는 채점용 100장 중 맞힌 비율이에요

[19]

K = 5

model = KNeighborsClassifier(n_neighbors=K)

model.fit(X_train, y_train)

 

accuracy = model.score(X_test, y_test)

print(f"예측 정확도: {accuracy:.2%}")

Python

예측 정확도: 87.00%

← 학습용 300장 외우기

← 채점용 100장

0.87을 100 곱하고 % 붙여 소수 둘째 자리까지

정확도 (accuracy)

87.00%

회귀의 R²(48) 대신, 분류는 맞힌 비율로 채점해요.

처음 보는 사진 100장 중 87장의 사람을 맞혔어요.

이번에는 K를 5로 정하고 학습용 300장으로 fit해요. score에 채점용 사진과 정답을 넣으면 100장을 모두 predict해서 정답과 비교하고, 맞힌 비율을 돌려줘요. 이 비율을 정확도, accuracy라고 해요. 48의 회귀 모델 score는 R제곱이었는데, 분류 모델 score는 정확도예요. f-string의 :.2%는 13의 :.2f처럼 소수 자리를 정하는데, 100을 곱하고 % 기호를 붙여 줘요. 0.87이 87.00%가 돼요. 출력은 실제로 실행한 결과예요.
