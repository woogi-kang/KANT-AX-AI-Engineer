4. KNN 학습하고 채점하기

87.00%는 맞힌 장수를 세서 나눈 값이에요

[20]

pred = model.predict(X_test)

print("정답:", y_test[:8])

print("예측:", pred[:8])

print("맞았나:", (pred == y_test)[:8])

print("맞힌 장수:", (pred == y_test).sum(), "/", len(y_test))

print("비율:", (pred == y_test).mean())

Python

정답: [24 5 15 30 37 15 36 4]

예측: [24 5 0 30 37 0 36 4]

맞았나: [ True True False True True False True True]

맞힌 장수: 87 / 100

비율: 0.87

← 15번 사람을 0번으로 두 번 (6파트)

← True는 1, False는 0으로 세요

← sum: True 개수

← mean: 87 ÷ 100

score 한 줄이 이 계산을 대신해요.

score가 하는 일을 직접 따라가요. predict로 채점용 100장을 모두 맞히고, 앞 8장만 정답과 나란히 찍었어요. 셋째와 여섯째 사진은 15번 사람인데 0번으로 틀렸어요. pred == y_test는 칸마다 같은지 물어서 True, False 100개를 만들어요. 파이썬은 True를 1, False를 0으로 세서 sum은 맞힌 장수 87이 되고, mean은 87을 100으로 나눈 0.87이 돼요. score가 돌려준 87.00%와 같아요. 출력은 실제로 실행한 결과예요.
