5. 비교와 오류

열 이름이 틀리거나 대괄호가 한 겹이면 KeyError

[35]

spend["amout"]

Python

KeyError: 'amout'

[36]

spend["shop", "amount"]

Python

KeyError: ('shop', 'amount')

왼쪽: 열 이름 amount에서 n이 빠졌어요.

오른쪽: 이름 두 개를 한 열 이름으로 찾았어요.

✕

spend["amout"]

✓

spend["amount"]

✕

spend["shop", "amount"]

✓

spend[["shop", "amount"]]

열 이름이 헷갈리면 spend.head()로 머리글부터 봐요.

없는 열 이름을 찾으면 KeyError가 나요. 15에서 딕셔너리에 없는 키를 찾을 때와 같은 오류예요. 왼쪽은 amount를 amout으로 잘못 적었어요. 오른쪽은 대괄호를 한 겹만 써서, pandas가 shop과 amount 둘을 묶은 이름 하나를 찾았어요. 열 두 개를 고르려면 3파트처럼 이름 리스트를 넣어 대괄호를 두 겹으로 써요. 머리글은 spend.head()로 확인해요. 출력은 실제로 실행한 결과예요.
