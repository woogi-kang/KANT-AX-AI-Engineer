2. NumPy 배열

합계, 평균, 최소, 최대를 배열에 바로 물어요

[8]

arr = np.array(amounts)

print(arr)

Python

[ 3200 1500 15000 6500 32000 4800 10900 1500 2700 3000 18500 7000]

[9]

print("합계:", arr.sum())

print("평균:", round(arr.mean()))

print("최소:", arr.min())

print("최대:", arr.max())

Python

합계: 106600

평균: 8883

최소: 1500

최대: 32000

← round()로 반올림했어요

← sum(amounts)와 같은 값

← 8883.33…을 반올림

← 13의 min(), max()처럼 물어요

배열 뒤에 점을 찍고 sum, mean, min, max를 부르면 합계, 평균, 최소, 최대가 나와요. 지출 12개를 배열 arr로 만들었어요. 13에서 리스트는 sum(amounts)처럼 함수에 넣었는데, 배열은 arr.sum()처럼 배열에게 물어요. 평균은 8883.33…이라 round로 반올림해서 8883이에요. 수업 코드에서는 평균 줄의 이름표가 합계로 적혀 있어서 평균으로 고쳤어요. 리스트에는 mean이 없어서 오류가 나요. 5파트에서 봐요. 출력은 실제로 실행한 결과예요.
