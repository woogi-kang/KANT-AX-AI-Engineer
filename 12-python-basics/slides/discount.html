3. 비교와 논리연산

할인 조건을 or로 적어요

조건 · 회원이거나 또는 5만 원 이상 샀으면 할인

[10]

is_member = False

total = 60000

is_member or total >= 50000

Python

True

is_member

False

60000 >= 50000

True

False or True

True

회원이 아니어도 할인돼요

[11]

not is_member

Python

True

not is_member

not False

True

회원이 아닌가요?

not을 붙이면 뜻도 반대로 읽어요.

둘 중 하나만 만족해도 되면 or예요.

회원이거나 5만 원 이상 사면 할인해 주는 가게예요. 둘 중 하나만 맞아도 되니까 or로 이어요. is_member는 False지만 60000 >= 50000이 True라서 False or True는 True예요. 오른쪽 셀의 not is_member는 '회원이 아닌가요?'라는 질문이에요. is_member가 False라서 뒤집으면 True예요. total은 2파트에서 쓴 이름이지만 여기서 60000을 다시 넣었어요.
