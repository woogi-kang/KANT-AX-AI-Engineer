NameError: name 'Age' is not defined

대문자와 소문자는 다른 이름이에요

age

넣은 이름

Age

한 번도 넣은 적 없는 이름

이럴 때도 같은 오류가 나요

• 철자를 틀렸어요 (agee)
• 넣는 셀을 아직 실행하지 않았어요
• Restart 뒤에 아래 셀만 실행했어요

NameError가 나면 철자부터 보고, 넣는 셀을 실행했는지 봐요.

NameError는 파이썬이 모르는 이름을 썼다는 뜻이에요. 파이썬은 대문자와 소문자를 다른 글자로 봐서, age에 값을 넣었어도 Age는 모르는 이름이에요. 철자를 하나 틀려도 같은 오류가 나요. 10에서 본 것처럼 Restart 뒤에 넣는 셀을 건너뛰고 아래 셀만 실행해도 나요. 그럴 땐 Run All로 위에서부터 다시 실행해요. 출력은 Traceback 위쪽 줄을 빼고 마지막 줄만 옮겼어요.
