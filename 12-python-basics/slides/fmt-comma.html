5. 문자열과 출력

가격은 {price:,} 로 천 단위 콤마를 찍어요

[17]

price = 1234567

print(f"{price:,}")

print(f"{price:,}원")

print(f"{1234567.891:,.2f}")

fee = 35000

print(f"[{fee:8,}]")

Python

1,234,567

1,234,567원

1,234,567.89

[ 35,000]

{price:,}

→ 1,234,567

콤마만

{x:,.2f}

→ 1,234,567.89

콤마와 소수점 두 자리

{fee:8,}

→ 35,000

여덟 칸 확보 + 콤마

[18]

print("%,d" % price)

Python

ValueError: unsupported format character ',' (0x2c) at index 1

% 방식에는 콤마 옵션이 없어요. 콤마가 필요하면 f-string을 써요.

콤마는 보여 주는 모양만 바꿔요. price 값은 그대로 1234567이에요.

가격이나 인원처럼 큰 수는 천 단위마다 콤마를 찍어야 읽기 쉬워요. f-string에서 콜론 뒤에 쉼표를 적으면 1,234,567처럼 찍혀요. 뒤에 원을 붙여 가격처럼 보일 수도 있어요. 소수점 자리와 같이 쓰려면 ,.2f처럼 쉼표를 먼저 적어요. 칸 수와 함께 쓰면 8,처럼 칸 수 뒤에 쉼표를 붙여요. 35,000은 여섯 글자라서 앞에 빈칸 두 개가 붙었어요. 콤마까지 넣은 길이가 칸 수보다 길면 칸을 무시하고 다 보여 줘요. % 방식에는 콤마 옵션이 없어서 %,d 는 ValueError가 나요. 모두 실제로 실행한 결과예요. format()으로는 "{:,}".format(price)처럼 같은 결과를 얻어요.
