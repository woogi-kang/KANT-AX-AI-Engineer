5. 문자열과 출력

자리와 값이 안 맞으면 오류가 나요

[22]

"%d살" % "kim"

Python

TypeError: %d format: a real number is required, not str

% 방식

%d 자리에 글자를 넣었어요

[23]

"%s 님은 %d살" % name

Python

TypeError: not enough arguments for format string

% 방식

자리는 둘, 값은 하나예요

[24]

"%s" % (name, age)

Python

TypeError: not all arguments converted during string formatting

% 방식

자리는 하나, 값은 둘이에요

[25]

f"{name:d}"

Python

ValueError: Unknown format code 'd' for object of type 'str'

f-string

글자에 정수 모양 d를 줬어요

% 는 자리 수와 값 수를, f-string은 콜론 뒤 모양과 타입을 먼저 봐요.

포맷팅에서 자주 나는 오류예요. 위 세 개는 % 방식이에요. %d는 숫자 자리라서 글자 kim을 넣으면 TypeError가 나요. 반대로 %d에 3.141592 같은 실수를 넣으면 오류 없이 소수점 아래를 버린 3이 나와요. 자리가 두 개인데 값을 하나만 주면 값이 모자란다는 오류, 자리는 하나인데 값을 두 개 주면 남는 값이 있다는 오류가 나요. f-string은 자리와 값이 한곳에 있어서 개수 오류가 없어요. 대신 콜론 뒤 모양이 값의 타입과 안 맞으면 ValueError가 나요. 글자 name에 정수 모양 d를 준 경우예요. 모두 실제로 실행한 결과의 마지막 줄이에요.
