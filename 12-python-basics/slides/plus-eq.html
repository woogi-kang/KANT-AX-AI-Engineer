[14]

score = 0

score += 10

score += 5

같은 모양

-=

*=

/=

도 있어요

점수나 합계처럼 값을 쌓아 갈 때 써요.

+= 는 지금 값에 오른쪽 값을 더해서 같은 이름에 다시 넣어요. 앞에서 본 age = age + 1을 짧게 적는 방법이에요. score는 0에서 시작해서 10을 더해 10, 5를 더해 15가 돼요. 빼기는 -=, 곱하기는 *=, 나누기는 /= 처럼 기호 뒤에 =를 붙여요. + 와 = 사이는 띄우지 않고 붙여 적어요.
