-2 ** 2는 -4예요. 음수를 거듭제곱하려면 (-2)처럼 괄호로 묶어요.

거듭제곱은 곱하기와 몫보다 한 단계 위라서 먼저 풀어요. 2 ** 3 // 3은 2 ** 3 = 8을 먼저 하고 8 // 3 = 2예요. 왼쪽부터 3 // 3을 먼저 한다고 생각하면 1이 나와서 틀려요. 2 * 3 ** 2도 3 ** 2 = 9가 먼저라서 18이에요. -2 ** 2는 많이 헷갈려요. 앞의 빼기 기호보다 ** 가 먼저라서 -(2 ** 2) = -4가 돼요. -2를 제곱하고 싶으면 (-2) ** 2처럼 괄호로 묶어서 4를 얻어요. 출력은 같은 셀을 실제로 실행한 결과예요.
