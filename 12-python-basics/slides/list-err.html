6. 리스트와 튜플

없는 번호를 꺼내면 IndexError가 나요

[12]

menus[3]

Python

IndexError: list index out of range

menus는 0, 1, 2번까지

[13]

orders[3]

Python

IndexError: list index out of range

주문은 세 건, 마지막은 2번

[14]

orders[0][3]

Python

IndexError: tuple index out of range

튜플 안은 0, 1, 2번까지

[5]

order[1] = 5000

Python

TypeError: 'tuple' object does not support item assignment

튜플은 바꿀 수 없어요

마지막 번호는 len() - 1이에요. 메시지에 list인지 tuple인지 나와요.

리스트와 튜플에서 자주 나는 오류예요. 번호는 0부터 세서, 값이 세 개면 마지막 번호는 2예요. menus[3]이나 orders[3]처럼 없는 번호를 쓰면 IndexError가 나요. 메시지의 list는 바깥 리스트에서, tuple은 안쪽 튜플에서 번호가 넘쳤다는 뜻이에요. orders[0][3]은 주문 튜플 안에 3번 값이 없어서 tuple index out of range예요. 마지막 줄은 튜플 장에서 본 오류예요. 튜플은 바꿀 수 없어서 바꿔야 하는 값은 리스트에 담아요. 셀 번호 [5]는 튜플 장의 셀이에요. 출력은 실제로 실행한 결과예요.
