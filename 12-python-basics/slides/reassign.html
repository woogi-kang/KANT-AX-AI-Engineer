1. 변수에 값 넣기

다시 넣으면 새 값으로 바뀌어요

[4]

age = 26

age

Python

26

← 같은 이름에 새 값

age

25

26

예전 값

25

셀

넣은 순서

[1]
age = 25
처음 넣은 값
[4]
age = 26
지금 남은 값

상자 하나에는 값이 하나만 들어가요. 마지막에 넣은 값만 남아요.

같은 이름에 다시 값을 넣으면 예전 값을 지우고 새 값을 넣어요. 변수라는 이름도 값이 변할 수 있어서 붙었어요. age에 26을 넣고 마지막 줄에 age를 적어서 26이 보여요. 예전 값 25는 더 이상 꺼낼 수 없어요. 셀 번호가 [4]인 건 앞 장의 두 셀 [2], [3]을 실행한 다음이라서예요.
