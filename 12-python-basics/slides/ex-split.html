5. 카페 주문으로 풀어 보기

글자로 온 수량을 숫자로 바꿔 나눠 내요

[3]

qty = "3"

total = 4500 * int(qty) + 5000

people = 3

print("합계:", total)

print("한 사람:", total // people)

print("남는 돈:", total % people)

Python

합계: 18500

한 사람: 6166

남는 돈: 2

← 주문서에서 읽은 수량은 글자예요

← int()로 바꿔서 곱해요 (2파트)

← 몫 // 로 한 사람 몫

← 나머지 % 로 남는 돈

[4]

qty = "3"

print(5000 + qty)

Python

TypeError: unsupported operand type(s) for +: 'int' and 'str'

← int()를 빼면 이렇게 돼요

주문서 파일에서 읽어 온 수량은 숫자처럼 보여도 글자인 경우가 많아요. 그래서 qty에 따옴표로 감싼 "3"을 넣었어요. 계산하려면 2파트의 int()로 정수로 바꿔요. 아메리카노 세 잔과 라떼 한 잔이라 4500 * 3 + 5000 = 18500이에요. 세 사람이 나눠 내면 3파트의 몫 // 로 한 사람이 낼 6166원, 나머지 % 로 남는 2원을 구해요. 아래 셀처럼 int() 없이 숫자와 글자를 더하면 TypeError가 나요. 메시지는 + 의 양쪽이 int와 str이라 더할 수 없다는 뜻이에요. 출력은 hello-uv 커널에서 실제로 실행한 결과예요.
