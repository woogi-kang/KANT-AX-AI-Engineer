= 는 오른쪽 값을 왼쪽 이름에 넣어요

[1]

age = 25

Python

넣기만 해서 출력은 없어요. 값은 커널이 기억해요.

age

오른쪽에서 왼쪽으로 읽어요

수학의 '같다'가 아니에요. 25를 age라는 이름에 넣어요.

변수는 값에 붙인 이름이에요. 오른쪽 상자 그림처럼 age라는 이름의 상자에 25를 넣는다고 생각해요. 등호 = 는 수학처럼 양쪽이 같다는 뜻이 아니에요. 오른쪽 값을 왼쪽 이름에 넣으라는 명령이에요. 그래서 오른쪽에서 왼쪽으로 읽어요. 이름은 10에서 정한 대로 스네이크 표기법으로 적어요. 이 셀은 넣기만 해서 출력이 없고, 실행 번호 [1]만 생겨요.
