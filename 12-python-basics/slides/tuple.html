리스트

값을 바꾸고 더할 수 있어요. 장바구니처럼 늘어나는 것

( )

튜플

만든 뒤 못 바꿔요. 주문 한 건처럼 한 묶음인 것

5파트의 "%s %d" % (name, age)에서 괄호로 묶은 것도 튜플이었어요.

튜플은 소괄호로 감싸요. 꺼내는 법은 리스트와 같아서 order[0]은 coffee예요. order[1] * order[2]처럼 꺼낸 값으로 계산도 해요. 다른 점은 한 번 만들면 바꿀 수 없다는 거예요. order[1] = 5000을 하면 TypeError가 나요. 메뉴, 가격, 수량처럼 한 묶음으로 같이 다니는 값은 튜플에 담고, 장바구니처럼 늘었다 줄었다 하는 건 리스트에 담아요. 5파트에서 % 뒤에 괄호로 묶어 넣은 (name, age)가 바로 튜플이었어요. 출력은 실제로 실행한 결과예요.
