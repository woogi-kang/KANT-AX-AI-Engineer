6. 리스트와 튜플

for 는 콜론과 들여쓰기를 꼭 지켜요

[19]

for menu in menus

print(menu)

Python

SyntaxError: expected ':'

for 줄 끝에 콜론을 빠뜨렸어요

[20]

for menu in menus:

print(menu)

Python

IndentationError: expected an indented block after 'for' statement on line 1

되풀이할 줄을 들여 쓰지 않았어요

Tab

VS Code에서 콜론 뒤 Enter를 치면 네 칸이 자동으로 들어가요. 직접 넣을 땐 Tab 한 번이에요.

for에서 처음에 자주 나는 오류 두 가지예요. for 줄 끝의 콜론을 빠뜨리면 SyntaxError: expected ':'가 나요. 되풀이할 줄을 들여 쓰지 않으면 IndentationError가 나요. 파이썬은 들여쓰기로 어디까지가 for 안쪽인지 알아봐요. VS Code 노트북에서는 콜론 뒤에 Enter를 치면 다음 줄이 네 칸 들어간 채로 시작해요. 오류 메시지 뒤의 괄호 안 위치 표시는 빼고 옮겼어요. 실제로 실행한 결과예요.
