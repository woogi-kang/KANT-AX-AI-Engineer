5. 문자열과 출력

같은 주문내역을 세 방식으로 적어 봐요

[12]

print("주문내역은 : %s, %d, %d" % (cake, price, qty))

print("주문내역은 : {0}, {1}, {2}".format(cake, price, qty))

print(f"주문내역은 : {cake}, {price}, {qty}")

print(f"{cake} {qty}개, 하나에 {price}원")

print(f"{cake} {qty}개, 합계 {price * qty:,}원")

Python

주문내역은 : 치즈케이크, 5000, 2

주문내역은 : 치즈케이크, 5000, 2

주문내역은 : 치즈케이크, 5000, 2

치즈케이크 2개, 하나에 5000원

치즈케이크 2개, 합계 10,000원

% 방식

%s, %d, %d

자리 순서 = 값 순서

format()

{0}, {1}, {2}

번호로 값을 골라요

f-string

{cake}, {price}, {qty}

이름을 바로 적어요

f-string은 { } 안에 계산식과 모양도 넣어요. {price * qty:,} 는 합계에 콤마를 찍어요.

앞 장의 주문내역을 세 방식으로 나란히 적었어요. 첫 줄은 % 방식이에요. %s, %d, %d 자리에 괄호 안 값이 순서대로 들어가요. 둘째 줄은 format() 방식이라 번호로 값을 골라요. 셋째 줄은 f-string이에요. 중괄호 안에 cake, price, qty 이름을 바로 적어서 어떤 값이 어디 들어가는지 한눈에 보여요. 넷째 줄은 순서를 바꿔도 이름만 옮기면 돼요. 다섯째 줄처럼 중괄호 안에서 price * qty를 계산하고 콜론 뒤에 쉼표를 붙여 합계 10,000원을 바로 찍을 수도 있어요. 세 줄 모두 결과가 같고, 실제로 실행한 결과예요.
