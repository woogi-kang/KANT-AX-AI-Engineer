5. 카페 주문으로 풀어 보기

가격에 이름을 붙이면 한 줄만 고쳐요

[1]

americano = 4500

latte = 5000

total = americano * 2 + latte

paid = 20000

print("합계:", total)

print("잔돈:", paid - total)

Python

합계: 14000

잔돈: 6000

[2]

americano = 4800

total = americano * 2 + latte

print("합계:", total)

print("잔돈:", paid - total)

Python

합계: 14600

잔돈: 5400

← 가격은 맨 위에 한 번만

← 이름으로 읽히는 식

← 앞의 숫자 식과 같은 답

← 가격이 오르면 이 줄만

← 합계와 잔돈이 같이 바뀌어요

처음 장에서 숫자로만 적었던 카페 계산을 변수로 다시 적었어요. 아메리카노와 라떼 가격을 맨 위에서 한 번만 넣고, 합계는 americano * 2 + latte처럼 이름으로 계산해요. 3파트의 계산 순서대로 곱하기를 먼저 해서 9000에 5000을 더해 14000이에요. 잔돈은 낸 돈 paid에서 합계를 빼요. 아메리카노가 4800원으로 오르면 2번 셀처럼 가격 줄만 다시 넣고 합계 식을 다시 실행해요. latte와 paid는 1번 셀에서 넣은 값이 그대로 남아 있어요. 이 파트는 새 커널이라 셀 번호가 [1]부터예요. 출력은 hello-uv 커널에서 실제로 실행한 결과예요.
