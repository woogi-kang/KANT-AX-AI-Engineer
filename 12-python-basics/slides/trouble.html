막히면 오류의 마지막 줄을 봐요

1

NameError: name 'Age' is not defined

대문자와 소문자를 다르게 적었거나 넣는 셀을 안 돌렸어요

철자 확인, Run All

2

NameError: name 'true' is not defined

True, False는 첫 글자가 대문자예요

True False

3

TypeError: can only concatenate str (not "int") to str

따옴표 글자와 숫자를 더했어요

int("3") + 3

4

ValueError: invalid literal for int() with base 10: '삼'

int()가 숫자로 못 읽는 글자예요

소수 글자는 float()

5

ZeroDivisionError: division by zero

0으로 나눴어요

나누는 수 확인

6

TypeError: not enough arguments for format string

% 자리 수와 값 수가 달라요

f-string으로

7

비교했는데 값이 바뀌었어요

= 를 하나만 썼어요

== 두 개

오류가 나면 위쪽 Traceback보다 맨 아래 줄부터 읽어요.

오류 메시지는 길어도 맨 아래 한 줄에 원인이 있어요. 1번과 2번은 NameError예요. 이름 철자, 대소문자, True와 False의 첫 글자를 봐요. 3번은 따옴표로 감싼 글자와 숫자를 더했을 때예요. int()로 타입을 맞춰요. 4번은 int()가 숫자로 못 읽는 글자를 받았을 때예요. 5번은 0으로 나눴을 때예요. 10 / 0을 실제로 실행한 결과예요. 6번은 % 포맷팅의 자리 수와 값 수가 다를 때예요. f-string으로 쓰면 이 오류가 없어요. 7번은 오류 없이 값만 바뀌어서 알아채기 어려워요. 6 / 2가 3.0으로 나오는 건 3파트의 나누기 장을 봐요. 위 출력은 모두 hello-uv 커널에서 실제로 실행한 결과의 마지막 줄이에요.
