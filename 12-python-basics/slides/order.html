3. 사칙연산

곱하기를 더하기보다 먼저 계산해요

[4]

2 + 3 * 4

Python

14

2 + 3 * 4

3 * 4 먼저

2 + 12

그다음 더하기

14

[5]

(2 + 3) * 4

Python

20

(2 + 3) * 4

괄호 먼저

5 * 4

그다음 곱하기

20

먼저 하는 순서

( )

**

* / // %

+ -

헷갈리면 먼저 할 계산을 괄호로 묶어요.

파이썬도 수학처럼 곱하기와 나누기를 더하기와 빼기보다 먼저 계산해요. 2 + 3 * 4는 3 * 4를 먼저 해서 12, 거기에 2를 더해 14예요. 더하기를 먼저 하고 싶으면 괄호로 묶어요. (2 + 3) * 4는 5 * 4라서 20이에요. 아래 줄은 먼저 하는 순서예요. 괄호가 가장 먼저, 그다음 거듭제곱, 곱하기 무리, 더하기 무리 순서예요. 순서를 외우기보다 헷갈릴 때 괄호를 치는 게 안전해요.
