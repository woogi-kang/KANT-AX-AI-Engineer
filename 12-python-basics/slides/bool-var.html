'~인가요?'로 읽혀요. 10의 is_alive처럼요.

= 오른쪽을 먼저 계산한다는 규칙은 비교에서도 같아요.

비교한 결과 True, False도 값이라서 변수에 넣을 수 있어요. is_adult = age >= 20은 1파트의 규칙대로 = 오른쪽을 먼저 계산해요. 25 >= 20은 True라서 is_adult에 True가 들어가요. type()으로 보면 bool이에요. True와 False를 담는 변수는 is_로 시작하면 '~인가요?'라고 읽혀서 뜻이 잘 보여요. age를 다시 25로 넣은 건 앞 장에서 30으로 바꿨기 때문이에요.
