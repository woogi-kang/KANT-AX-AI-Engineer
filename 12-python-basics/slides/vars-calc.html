3. 사칙연산

숫자에 이름을 붙여 계산해요

장보기 합계

[12]

price = 3000

count = 2

total = price * count

print("합계:", total)

Python

합계: 6000

세 사람이 나눠 내기

[13]

total = 10000

people = 3

print("한 사람:", total // people)

print("남는 돈:", total % people)

Python

한 사람: 3333

남는 돈: 1

3000 * 2

무슨 숫자인지 몰라요

price * count

가격 곱하기 개수

price만 바꾸고 다시 실행하면 합계도 새로 계산돼요.

숫자를 그대로 적어도 계산은 되지만, 변수에 이름을 붙여 두면 무슨 계산인지 읽혀요. 왼쪽은 3000원짜리를 2개 산 합계예요. total = price * count도 = 오른쪽을 먼저 계산해서 6000을 total에 넣어요. 오른쪽은 만 원을 세 사람이 나눠 내는 계산이에요. 몫 // 로 한 사람이 낼 돈 3333원, 나머지 % 로 남는 1원을 구했어요. 오른쪽 셀이 total에 10000을 다시 넣어서 왼쪽의 6000은 사라졌어요.
