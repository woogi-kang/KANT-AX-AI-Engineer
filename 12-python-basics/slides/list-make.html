변수 하나에 값 하나였다면, 리스트는 변수 하나에 값 여러 개예요.

지금까지 변수 하나에는 값 하나만 넣었어요. 메뉴 가격 세 개를 넣으려면 변수 세 개가 필요했어요. 리스트는 값 여러 개를 대괄호로 감싸 한 변수에 담아요. 값 사이는 쉼표로 나눠요. len()은 5파트에서 글자 수를 셌던 함수인데, 리스트에 쓰면 담긴 값의 개수를 세요. type()으로 보면 list예요. 이 파트도 새 커널이라 셀 번호가 [1]부터예요. 출력은 실제로 실행한 결과예요.
