4. 비교와 논리연산

= 하나는 넣기, == 두 개는 묻기

== 묻기

[2]

age == 30

Python

False

← age가 30이냐고 물어요

age

25

그대로예요

= 넣기

[3]

age = 30

age

Python

30

← 30을 넣어요

age

30

값이 바뀌었어요

비교하려고 = 를 하나만 쓰면 오류 없이 값이 바뀌어요.

= 하나와 == 두 개는 뜻이 완전히 달라서 가장 많이 헷갈려요. = 하나는 1파트에서 본 넣기예요. == 두 개는 같으냐고 묻는 비교예요. 왼쪽 셀은 age가 30인지 물어서 False가 나왔고, age는 25 그대로예요. 오른쪽 셀은 age에 30을 넣어서 값이 바뀌었어요. 비교하려다 = 하나만 적으면 오류 없이 값이 바뀌어서 알아채기 어려워요. 다음 장부터 다시 age를 25로 넣고 시작해요.
