결과는 10에서 본 불리언(bool)이에요. 같다는 = 를 두 번 써요.

비교 연산자 여섯 가지예요. 비교한 결과는 맞으면 True, 틀리면 False로 나와요. 10에서 본 불리언 자료형이에요. 같다는 = 를 두 번 써서 == 로, 다르다는 느낌표와 = 를 붙여 != 로 적어요. 크거나 같다는 >= 처럼 = 를 뒤에 붙여요. => 처럼 순서를 바꾸면 SyntaxError가 나요. 기호 두 개 사이는 띄우지 않아요. age는 25로 넣었어요.
