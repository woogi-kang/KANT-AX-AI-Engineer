2. 변수 타입

숫자로 못 읽는 글자는 ValueError가 나요

[5]

int("삼")

Python

ValueError: invalid literal for int() with base 10: '삼'

[6]

int("3.5")

Python

ValueError: invalid literal for int() with base 10: '3.5'

← 한글 숫자는 못 읽어요

← 소수점 글자도 못 읽어요

✕

int("3.5")

✓

float("3.5")

3.5

ValueError는 타입은 맞는데 그 값으로는 바꿀 수 없다는 뜻이에요.

int()에 숫자로 읽을 수 없는 글자를 넣으면 ValueError가 나요. 메시지의 base 10은 10진수로 읽으려 했다는 뜻이에요. 한글 "삼"은 사람에게는 숫자지만 파이썬은 못 읽어요. "3.5"처럼 소수점이 있는 글자도 int()는 바로 못 읽어요. 그럴 땐 float("3.5")로 바꿔요. 앞 장의 int(3.9)는 실수를 넣어서 오류 없이 3이 됐어요. 출력은 Traceback의 마지막 줄만 옮겼어요.
