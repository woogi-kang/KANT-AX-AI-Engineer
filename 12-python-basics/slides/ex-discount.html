5. 카페 주문으로 풀어 보기

사이즈 업과 할인 조건을 and, or로 적어요

사이즈 업 · 15000원 이상 그리고 쿠폰 있음   |   할인 · 회원 또는 50000원 이상

[5]

is_member = False

has_coupon = True

total = 18500

size_up = total >= 15000 and has_coupon

discount = is_member or total >= 50000

print("사이즈 업:", size_up)

print("할인:", discount)

print("비회원:", not is_member)

Python

사이즈 업: True

할인: False

비회원: True

← True and True

← 둘 다 맞아서 True

← False or False

← 하나도 안 맞아서 False

← not False · 회원이 아닌가요?

카페의 두 가지 혜택을 조건으로 적었어요. 사이즈 업은 15000원 이상이고 쿠폰도 있어야 해서 and로 이어요. 18500 >= 15000이 True, has_coupon이 True라서 True and True는 True예요. 할인은 회원이거나 50000원 이상이면 돼서 or로 이어요. 회원이 아니고 18500원이라 False or False는 False예요. 4파트의 순서대로 비교를 먼저 하고 and, or를 나중에 해서 괄호가 없어도 돼요. not is_member는 '회원이 아닌가요?'라는 질문이라 True예요. True, False를 담는 이름은 is_, has_로 시작하면 질문처럼 읽혀요. 출력은 hello-uv 커널에서 실제로 실행한 결과예요.
