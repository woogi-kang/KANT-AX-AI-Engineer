3. 사칙연산

몫 //, 나머지 %, 거듭제곱 **

사탕 7개를 3개씩 나누면

몫 2 (묶음 수)

나머지 1

[2]

print(7 // 3)

print(7 % 3)

print(2 ** 3)

Python

2

1

8

//
몫
7 // 3 → 2
나누고 소수점 아래는 버려요
%
나머지
7 % 3 → 1
나누고 남은 수. 퍼센트가 아니에요
**
거듭제곱
2 ** 3 → 8
2 × 2 × 2
사칙연산 말고 자주 쓰는 연산 세 가지예요. 사탕 7개를 3개씩 묶으면 두 묶음이 되고 하나가 남아요. 묶음 수 2가 몫이고, 남은 1개가 나머지예요. // 는 빗금 두 개로 몫만 구해요. 소수점 아래를 버리니까 결과가 정수예요. % 는 나머지예요. 퍼센트 기호지만 파이썬에서는 나머지를 구해요. 짝수인지 볼 때 숫자 % 2가 0인지 확인하는 식으로 많이 써요. ** 는 별표 두 개로 거듭제곱이에요. 2 ** 3은 2를 세 번 곱한 8이에요.
