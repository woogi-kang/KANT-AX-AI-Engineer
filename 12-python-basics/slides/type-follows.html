2. 변수 타입

타입은 이름이 아니라 값을 따라가요

[2]

x = 10

print(type(x))

x = "ten"

print(type(x))

Python

<class 'int'>

<class 'str'>

x

10

"ten"

int

str

이름 x는 그대로예요. 넣은 값이 바뀌니 타입도 바뀌었어요.

파이썬은 변수를 만들 때 타입을 따로 적지 않아요. 넣은 값을 보고 타입이 정해져요. 그래서 같은 x에 10을 넣으면 int, "ten"을 넣으면 str이 돼요. 다른 언어 중에는 변수마다 타입을 정해 두고 다른 값을 못 넣게 하는 언어도 있어요. 파이썬은 자유로운 대신 실수하기 쉬워요. 나이를 넣던 이름에 갑자기 글자를 넣는 일은 피하고, 헷갈리면 type()으로 확인해요.
