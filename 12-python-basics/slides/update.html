10에서 실행한 x = x + 1도 같은 순서로 계산했어요.

수학이라면 age = age + 1은 말이 안 되는 식이에요. 파이썬은 = 오른쪽을 먼저 계산해요. 1단계에서 지금 age에 든 26을 읽고, 2단계에서 1을 더해 27을 만들고, 3단계에서 그 27을 다시 age에 넣어요. 10의 실행 번호 장에서 x = x + 1을 두 번 실행했을 때 11, 12로 바뀐 것도 같은 원리예요. 이 셀도 실행할 때마다 1씩 커져요.
