2. 사칙연산

글자에도 + 와 * 를 써요

이어 붙여요

"kim" + "lee"

'kimlee'

3번 반복해요

"ha" * 3

'hahaha'

따옴표가 있으면 숫자도 글자예요

"3" + "3"

'33'

글자와 숫자는 더할 수 없어요

"3" + 3

TypeError: can only concatenate str (not "int") to str

따옴표가 있으면 글자예요. 숫자와 섞어서 더하면 TypeError가 나요.

문자열에도 + 와 * 를 쓸 수 있어요. + 는 두 글자를 이어 붙이고, * 는 정수만큼 반복해요. 셀 마지막 줄의 값이라서 출력에 따옴표가 붙었어요. 셋째 칸이 헷갈리기 쉬워요. 따옴표로 감싼 "3"은 숫자가 아니라 글자라서 "3" + "3"은 6이 아니라 '33'이에요. 넷째 칸처럼 글자와 숫자를 더하면 TypeError가 나요. 메시지는 str(문자열)에는 int(정수)를 이어 붙일 수 없다는 뜻이에요. 계산하려면 따옴표 없이 숫자로 적어요. 출력은 Traceback의 마지막 줄만 옮겼어요.
