4. 리스트와 섞기

딕셔너리에서 자주 나는 오류

[6]

menu[0]

Python

KeyError: 0

딕셔너리에는 번호가 없어요. 0이라는 키를 찾았어요

[7]

menu["Latte"]

Python

KeyError: 'Latte'

키는 대문자와 소문자를 구분해요

[8]

orders["menu"]

Python

TypeError: list indices must be integers or slices, not str

orders는 리스트예요. orders[0]["menu"]처럼 번호부터 적어요

KeyError 뒤에는 찾던 키가 나와요. 그 키가 정말 있는지 봐요.

딕셔너리에서 자주 나는 오류예요. menu[0]은 리스트처럼 번호로 꺼낸 경우예요. 딕셔너리에는 번호가 없어서 0이라는 키를 찾다가 KeyError가 나요. menu["Latte"]는 대문자 L로 적어서 latte와 다른 키예요. orders["menu"]는 리스트에 키를 넣은 경우예요. orders는 바깥이 리스트라 번호부터 적고, 그다음에 키를 적어요. 출력은 실제로 실행한 결과예요.
