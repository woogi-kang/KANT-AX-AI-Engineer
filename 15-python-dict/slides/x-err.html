5. 실제로 써 보기

딕셔너리에서 자주 나는 오류 세 가지

[4]

scores[0]

Python

KeyError: 0

고치기

scores["kim"]

딕셔너리에는 번호가 없어요

[5]

scores["Lee"]

Python

KeyError: 'Lee'

고치기

scores["lee"]

키는 대문자와 소문자를 구분해요

[6]

orders["menu"]

Python

TypeError: list indices must be integers or slices, not str

고치기

orders[0]["menu"]

orders는 리스트예요. 번호부터 적어요

오류 마지막 줄의 KeyError 뒤에는 찾던 키가 나와요. scores[0]은 리스트처럼 번호로 꺼낸 경우예요. 딕셔너리에는 번호가 없어서 0이라는 키를 찾다가 KeyError가 나요. scores["Lee"]는 대문자 L로 적어서 lee와 다른 키예요. orders["menu"]는 리스트에 키를 넣은 경우예요. orders는 바깥이 리스트라 번호부터 적고, 그다음에 키를 적어요. scores와 orders는 4파트에서 만든 것을 그대로 써서 셀 번호가 이어져요. 출력은 실제로 실행한 결과예요.
