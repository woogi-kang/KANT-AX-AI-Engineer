중괄호 { }는 딕셔너리, 대괄호 [ ]는 리스트예요.

딕셔너리는 중괄호 안에 키: 값을 적고, 쌍과 쌍 사이를 쉼표로 이어요. menu는 메뉴 이름이 키, 가격이 값이에요. print로 찍으면 적은 순서대로 나와요. type은 dict라고 알려 주는데, dictionary(사전)의 줄임말이에요. 사전에서 단어를 찾으면 뜻이 나오듯 키로 값을 찾아요. len은 쌍의 개수라 3이에요. 빈 중괄호는 빈 딕셔너리예요. 출력은 실제로 실행한 결과예요.
