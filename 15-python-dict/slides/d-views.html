3. 둘러보기

keys, values, items로 모아 봐요

[1]

menu = {"coffee": 4500, "latte": 5000, "cake": 6500}

print(menu.keys())

print(menu.values())

print(menu.items())

print(list(menu.keys()))

Python

dict_keys(['coffee', 'latte', 'cake'])

dict_values([4500, 5000, 6500])

dict_items([('coffee', 4500), ('latte', 5000), ('cake', 6500)])

['coffee', 'latte', 'cake']

리스트가 필요하면

list(menu.keys())

13의 list()로 감싸면 보통 리스트가 돼요. 다음 장에서 번호로 꺼내 봐요

menu.keys()

키만

"coffee"

4500

"latte"

5000

"cake"

6500

menu.values()

값만

"coffee"

4500

"latte"

5000

"cake"

6500

menu.items()

(키, 값) 쌍

"coffee"

4500

"latte"

5000

"cake"

6500

items()는 (키, 값) 튜플을 하나씩 담아요.

딕셔너리에서 키만, 값만, 쌍을 따로 모아 볼 수 있어요. keys는 키만, values는 값만 모아요. items는 키와 값을 튜플 하나로 묶어서 모아요. 출력의 dict_keys, dict_values, dict_items는 딕셔너리에서 꺼내 보여 주는 모양이라는 뜻이에요. 보통 리스트가 필요하면 13에서 배운 list()로 감싸요. 이 파트도 새 커널이라 menu를 다시 만들어요. 출력은 실제로 실행한 결과예요.
