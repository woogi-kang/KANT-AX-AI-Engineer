1. 만들고 꺼내기

get은 긴 코드를 한 줄로 줄인 거예요

회색 줄은 참고, 읽기만 해요. if는 17에서 배워요.

[7]

print(menu["cakee"] if "cakee" in menu else 5000)

print(menu.get("cakee", 5000))

print(menu["cake"] if "cake" in menu else 5000)

print(menu.get("cake", 5000))

Python

5000

5000

6500

6500

cakee는 키가 없어서 둘 다 5000

cake는 키가 있어서 둘 다 6500

[8]

sale = {"cake": None}

print(sale.get("cake", 5000))

print(sale.get("cakee", 5000))

Python

None

5000

← cake 키는 있어요. 값 None을 그대로 줘요

← 기본값은 키가 없을 때만 써요

get(키, 기본값)은 '키가 있으면 꺼내고, 없으면 기본값'을 한 줄로 줄인 메서드예요. 원래는 키가 menu에 있는지 in으로 묻고, 있으면 대괄호로 꺼내고, 없으면 5000을 쓰는 코드를 써야 해요. if와 else는 17에서 배우니 지금은 이런 뜻이라고 읽기만 해요. cakee는 오타라 키가 없어서 두 줄 모두 5000, cake는 키가 있어서 두 줄 모두 6500이에요. 주의할 점이 하나 있어요. 기본값은 키가 없을 때만 써요. sale처럼 cake 키가 있고 값이 None이면 None이 그대로 나와요. 출력은 실제로 실행한 결과예요.
