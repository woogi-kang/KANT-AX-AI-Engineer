1. 만들고 꺼내기

get은 긴 코드를 한 줄로 줄인 거예요

[7]

print(menu["cakee"] if "cakee" in menu else 5000)

print(menu.get("cakee", 5000))

print(menu["cake"] if "cake" in menu else 5000)

print(menu.get("cake", 5000))

Python

5000

5000

6500

6500

같은 뜻이에요

참고 · 원래 긴 방법

menu["cakee"] if "cakee" in menu else 5000

줄인 방법

menu.get("cakee", 5000)

if는 나중에 배워요. 지금은 읽기만 해요

[8]

sale = {"cake": None}

print(sale.get("cake", 5000))

print(sale.get("cakee", 5000))

Python

None

5000

기본값은 키가 없을 때만 써요

sale.get("cake", 5000)

None

키는 있어요. 값이 None이어도 그대로 줘요

sale.get("cakee", 5000)

5000

키가 없을 때만 기본값을 줘요

get은 '키가 있으면 꺼내고, 없으면 기본값'을 한 줄로 줄인 거예요.

파이썬에는 자주 쓰는 긴 코드를 줄여 둔 메서드가 많아요. get도 그중 하나예요. 원래는 키가 menu에 있는지 in으로 묻고, 있으면 대괄호로 꺼내고, 없으면 5000을 쓰는 코드를 써야 해요. if와 else는 나중에 배우니 지금은 이런 뜻이라고 읽기만 해요. cakee는 오타라 키가 없어서 두 줄 모두 5000, cake는 키가 있어서 두 줄 모두 6500이에요. 주의할 점이 하나 있어요. get의 기본값은 키가 없을 때만 써요. sale처럼 cake 키가 있고 값이 None이면 None이 그대로 나와요. 출력은 실제로 실행한 결과예요.
