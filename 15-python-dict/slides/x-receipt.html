total = 0

count = 0

for order in orders:

amount = order["price"] * order["qty"]

print(f"{order['menu']:<10}{order['price']:>8,}{order['qty']:>5}{amount:>10,}")

total += amount

count += order["qty"]

print("-" * 33)

print(f"{'수량':<6}{count:>15}")

print(f"{'합계':<6}{total:>25,}")

Python

13은 for menu, price, qty in orders:, 이번에는 order["price"]처럼 키로 꺼내요

13에서 찍은 KANT 카페 영수증을 딕셔너리 리스트로 다시 찍어요. 머리글과 구분선은 13과 같고, 바뀐 곳은 for 안쪽이에요. 13에서는 for menu, price, qty in orders:로 튜플을 나눠 담았어요. 이번에는 order 하나에 딕셔너리가 통째로 들어가서 order["price"]처럼 키로 꺼내요. f-string 중괄호 안에서 키를 적을 때는 바깥 큰따옴표와 겹치지 않게 작은따옴표로 적어요. 결과는 13과 같은 영수증이에요. 영수증의 한글은 영어 두 칸 너비로 그렸어요. 출력은 실제로 실행한 결과예요.
