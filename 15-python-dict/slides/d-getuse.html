3. 둘러보기

get은 없을 수도 있는 키에 써요

[7]

settings = {"name": "kim"}

print(settings.get("name", "guest"))

print(settings.get("lang", "ko"))

print(settings.get("theme", "light"))

print(settings)

Python

kim

ko

light

{'name': 'kim'}

← lang이 없어서 기본값

← settings는 그대로예요

[8]

cart = {"coffee": 2, "tea": 1}

total = 0

for name, qty in cart.items():

price = menu.get(name, 0)

print(name, qty, price * qty)

total += price * qty

print("합계:", total)

Python

coffee 2 9000

tea 1 0

합계: 9000

← 메뉴판에 없으면 0원

price = menu[name]

price = menu.get(name, 0)

tea에서 KeyError로 멈추지 않아요

get은 키가 없을 수도 있는 곳에 써요. 첫째는 설정값이에요. 사용자가 이름만 적고 언어와 테마는 적지 않았으면, get의 두 번째 값으로 정해 둔 기본값을 써요. get은 꺼내기만 해서 settings는 바뀌지 않아요. 둘째는 장바구니예요. 메뉴판에 없는 tea가 들어와도 menu.get(name, 0)은 0을 줘서 for가 끝까지 돌아요. menu[name]으로 꺼냈다면 tea에서 KeyError가 나고 셀이 멈춰요. 출력은 실제로 실행한 결과예요.
