AS로 붙인 이름이 열 이름이 돼요

40에서 '강사' AS 구분으로 구분 열을 붙인 것과 같아요. INSERT 전에 SELECT만 먼저 쳐서 들어갈 줄을 확인해요.

FROM에 적은 표에 없는 글자를 SELECT하면 모든 줄에 같은 값이 붙어요. 이 SELECT는 INSERT 없이 SELECT 부분만 쳐 본 거예요. reason 칸은 9줄 모두 이메일 미등록이고, request_date도 모두 같은 날짜예요. AS로 열 이름을 붙이면 넣을 열과 이름이 맞아서 읽기 쉬워요. INSERT는 이름이 아니라 순서로 짝을 지으니 AS는 없어도 돼요. 40에서 UNION으로 강사와 회원을 합칠 때 구분 열을 붙인 것과 같은 방법이에요. INSERT 앞에 SELECT만 먼저 쳐 보면 어떤 줄이 들어갈지 미리 볼 수 있어요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
