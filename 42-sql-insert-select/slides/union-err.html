1. 다른 표에서 골라 넣기

UNION으로 합친 날짜 글자는 text가 돼서 DATE 열에 못 들어가요

kant_shop=# INSERT INTO contact_lists (member_id, name, reason, request_date)

kant_shop-# SELECT member_id, name, '이메일 미등록', '2026-11-19' FROM members WHERE email IS NULL

kant_shop-# UNION

kant_shop-# SELECT member_id, name, '전화번호 미등록', '2026-11-19' FROM members WHERE phone IS NULL;

ERROR:  column "request_date" is of type date but expression is of type text

request_date

DATE 열이라 거절

SELECT가 하나일 때는 PostgreSQL이 열에 맞춰 DATE로 읽어서 괜찮았어요.

두 조건의 회원을 UNION으로 합쳐서 넣으면 날짜 글자가 text가 돼서 오류가 나요. 이메일이 없는 회원과 전화번호가 없는 회원을 한 번에 명단에 넣으려고 40에서 배운 UNION을 썼어요. 그런데 ERROR가 났어요. request_date 열은 DATE인데 들어오는 값은 text라는 뜻이에요. 따옴표로 감싼 2026-11-19는 아직 자료형이 정해지지 않은 글자예요. SELECT 하나만 INSERT할 때는 PostgreSQL이 넣을 열을 보고 DATE로 읽어 줬어요. UNION은 넣기 전에 두 SELECT를 먼저 합치면서 이 칸을 text로 정해 버려요. 그래서 날짜라고 직접 알려 줘야 해요. HINT도 rewrite or cast, 다시 쓰거나 자료형을 바꾸라고 말해요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
