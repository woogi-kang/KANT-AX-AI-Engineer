CAST(값 AS DATE)와 값::DATE는 같은 뜻이에요

kant_shop=# SELECT '2026-11-19' + 7;

ERROR:  invalid input syntax for type integer: "2026-11-19"

LINE 1: SELECT '2026-11-19' + 7;

              ^

kant_shop=# SELECT CAST('2026-11-19' AS DATE) + 7 AS 일주일뒤, '2026-11-19'::DATE + 7 AS 같은값;

 일주일뒤  |   같은값

------------+------------

2026-11-26 | 2026-11-26

(1 row)

kant_shop=# SELECT '120'::INTEGER + 1 AS 숫자로;

숫자로

--------

   121

(1 row)

그냥 글자라 날짜 계산이 안 돼요

짧아서 psql에서 자주 써요

CAST 값 AS DATE와 값 콜론 콜론 DATE는 같은 뜻이에요. 자료형을 바꾼다고 해서 형 변환이라고 불러요. 첫 줄처럼 따옴표 글자에 7을 더하면 ERROR가 나요. 날짜가 아니라 글자로 읽어서 계산할 수 없어요. 둘째 줄은 두 가지 방법으로 DATE로 바꾼 다음 7을 더했어요. 둘 다 일주일 뒤인 11월 26일이 나와요. CAST는 SQL 표준 문법이라 MySQL 같은 다른 데이터베이스에서도 써요. 콜론 두 개는 PostgreSQL에서 쓰는 줄임 표현이에요. 숫자 글자 120도 INTEGER로 바꾸면 1을 더할 수 있어요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
