2. 여러 열과 계산으로 고치기

ALTER TABLE ... ADD COLUMN으로 있는 표에 열을 더해요

kant_shop=# ALTER TABLE courses ADD COLUMN class_days VARCHAR(10);

ALTER TABLE

kant_shop=# ALTER TABLE courses ADD COLUMN is_open BOOLEAN NOT NULL DEFAULT true;

ALTER TABLE

kant_shop=# SELECT course_id, course_name, class_days, is_open FROM courses WHERE course_id <= 4;

course_id |   course_name    | class_days | is_open

-----------+------------------+------------+---------

        1 | 수영 초급 아침반 |            | t

        2 | 수영 초급 저녁반 |            | t

        3 | 수영 중급 새벽반 |            | t

        4 | 수영 고급반      |            | t

(4 rows)

더한 열

있던 14줄에 들어간 값

class_days VARCHAR(10)

모두 NULL (빈칸으로 보여요)

is_open BOOLEAN NOT NULL DEFAULT true

모두 DEFAULT 값 t

ALTER TABLE 표 ADD COLUMN으로 이미 있는 표에 열을 더해요. 강좌 표에 수업 요일 칸이 없어서 class_days 열을 더했어요. 37에서는 ALTER TABLE로 규칙을 붙였고, 오늘은 열을 붙여요. 이미 있던 강좌 14줄의 새 칸에는 아무것도 안 들어 있어서 NULL이에요. psql은 NULL을 빈칸으로 보여 줘요. 둘째 줄처럼 DEFAULT를 붙여서 열을 더하면 있던 줄에도 기본값이 들어가요. is_open은 모두 t, 참이에요. 새 칸을 채우는 방법은 다음 장의 UPDATE예요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
