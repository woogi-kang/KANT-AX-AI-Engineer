4. 지우기와 표 비우기

명단 표에 세 명령을 차례로 쳐 보면 줄 수가 9, 0, 표 없음이 돼요

kant_shop=# DELETE FROM contact_lists WHERE reason = '전화번호 미등록';

DELETE 7

kant_shop=# SELECT COUNT(*) FROM contact_lists;

count

-------

    9

(1 row)

kant_shop=# TRUNCATE contact_lists RESTART IDENTITY;

TRUNCATE TABLE

kant_shop=# SELECT COUNT(*) FROM contact_lists;

count

-------

    0

(1 row)

kant_shop=# DROP TABLE contact_lists;

DROP TABLE

kant_shop=# SELECT COUNT(*) FROM contact_lists;

ERROR:  relation "contact_lists" does not exist

LINE 1: SELECT COUNT(*) FROM contact_lists;

                            ^

DELETE 7

전화번호 미등록 7줄만 지워서 9줄 남아요

TRUNCATE TABLE

모두 비워서 0줄

relation … does not exist

표가 없어졌어요

명단 표에 세 명령을 차례로 쳐 보면 줄 수가 9, 0, 그다음엔 표가 없다는 오류로 바뀌어요. 명단 표에는 16줄이 들어 있었어요. 먼저 DELETE로 전화번호 미등록 7줄만 지웠어요. 9줄이 남아요. 다음 TRUNCATE로 남은 줄을 다 비웠어요. COUNT가 0이에요. 표는 남아 있어서 COUNT를 칠 수 있어요. 마지막으로 DROP TABLE로 표를 없앴어요. 이제 COUNT를 치면 relation does not exist, 그런 표가 없다는 ERROR가 나요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
