INSERT 뒤에 VALUES 대신 SELECT 문을 붙이면 SELECT가 고른 줄이 다 들어가요. 첫 줄은 36처럼 어느 표의 어느 열에 넣을지 적어요. 그 아래 VALUES 자리에 SELECT 문을 그대로 붙였어요. 색칠한 부분이 앞 장에서 친 SELECT와 같은 문장이에요. 이메일 미등록과 날짜는 모든 줄에 같은 글자를 넣었어요. 결과 INSERT 0 9는 9줄이 들어갔다는 뜻이에요. 명단을 SELECT해 보면 request_id가 1부터 9까지 붙어 있어요. 손으로 옮겨 적은 9줄과 같은 결과를 네 줄로 만들었어요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
