다른 표를 보고 할 일마다 쓰는 모양이 정해져 있어요

이럴 때

이렇게 써요

다른 표에서 골라 넣어요

INSERT INTO 표 (열, …) SELECT 칸, … FROM … WHERE …

UNION 결과에 날짜 글자가 있어요

CAST('2026-11-19' AS DATE) 또는 '2026-11-19'::DATE

있는 표에 열을 더해요

ALTER TABLE 표 ADD COLUMN 열 자료형 [DEFAULT 값]

여러 열을 한 번에, 다른 표를 보고 고쳐요

UPDATE … SET a = …, b = … WHERE id IN (SELECT …)

다른 표에 있는(없는) 줄만 골라요

WHERE [NOT] EXISTS (SELECT 1 FROM … WHERE 잇는 조건)

지워요, 비워요, 없애요

DELETE … WHERE / TRUNCATE 표 / DROP TABLE 표

다음 43 챕터: 넣고 지우는 여러 문장을 한 묶음으로 처리하고, 잘못 친 UPDATE를 되돌리는 트랜잭션(BEGIN, COMMIT, ROLLBACK)

다른 표를 보고 넣고, 고치고, 지울 때 쓰는 모양을 한 표로 모았어요. 다른 표에서 골라 넣을 때는 INSERT 뒤에 SELECT를 붙여요. UNION으로 합친 결과에 날짜 글자가 있으면 CAST나 콜론 두 개로 DATE로 바꿔요. 있는 표에 열을 더할 때는 ALTER TABLE ADD COLUMN이에요. 여러 열은 SET 뒤에 쉼표로 잇고, 다른 표를 보고 고를 때는 WHERE에 서브쿼리를 넣어요. 다른 표에 있는지 없는지만 물을 때는 EXISTS와 NOT EXISTS예요. 지울 때는 DELETE, 모두 비울 때는 TRUNCATE, 표를 없앨 때는 DROP TABLE이에요. 오늘 본 명령은 치는 순간 저장돼요. 다음 43 챕터에서는 여러 문장을 한 묶음으로 처리하고 되돌리는 트랜잭션을 배워요.
