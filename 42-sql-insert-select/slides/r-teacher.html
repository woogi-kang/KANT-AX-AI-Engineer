6. 실제 상황

강좌가 없는 강사를 강사가 없는 강좌에 맡겨요

kant_shop=# SELECT i.instructor_id, i.name, i.sport_id FROM instructors i

kant_shop-# WHERE NOT EXISTS (SELECT 1 FROM courses c WHERE c.instructor_id = i.instructor_id);

instructor_id |  name  | sport_id

---------------+--------+----------

            8 | 윤태호 |        1

(1 row)

kant_shop=# SELECT course_id, course_name, sport_id FROM courses WHERE instructor_id IS NULL;

course_id | course_name | sport_id

-----------+-------------+----------

        5 | 아쿠아로빅  |        1

(1 row)

kant_shop=# UPDATE courses

kant_shop-# SET instructor_id = (SELECT instructor_id FROM instructors WHERE name = '윤태호')

kant_shop-# WHERE course_id = 5

kant_shop-# RETURNING course_id, course_name, instructor_id;

course_id | course_name | instructor_id

-----------+-------------+---------------

        5 | 아쿠아로빅  |             8

(1 row)

UPDATE 1

① NOT EXISTS: 맡은 강좌가 없는 수영 강사

② IS NULL: 강사가 없는 수영 강좌

값 하나

번호를 손으로 안 적었어요

강좌가 없는 강사를 강사가 없는 강좌에 맡겨요. 먼저 NOT EXISTS로 맡은 강좌가 하나도 없는 강사를 찾아요. 8번 윤태호 강사예요. 종목 번호 1, 수영 강사예요. 다음으로 강사 칸이 비어 있는 강좌를 찾아요. 5번 아쿠아로빅, 역시 수영 강좌예요. 그래서 UPDATE로 아쿠아로빅의 강사를 정해요. SET의 값 자리에 41에서 배운 값 하나가 나오는 서브쿼리를 넣었어요. 이름이 윤태호인 강사의 번호를 PostgreSQL이 찾아서 넣어 줘요. RETURNING을 보면 강사 번호 8이 들어갔어요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
