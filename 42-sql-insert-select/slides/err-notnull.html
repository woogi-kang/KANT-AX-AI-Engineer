5. 오류와 함정

줄이 있는 표에 NOT NULL 열만 더하면 막혀요. DEFAULT를 같이 줘요

kant_shop=# ALTER TABLE courses ADD COLUMN class_days VARCHAR(10) NOT NULL;

ERROR:  column "class_days" of relation "courses" contains null values

kant_shop=# ALTER TABLE courses ADD COLUMN class_days VARCHAR(10) NOT NULL DEFAULT '미정';

ALTER TABLE

kant_shop=# SELECT course_id, class_days FROM courses WHERE course_id <= 3;

course_id | class_days

-----------+------------

        1 | 미정

        2 | 미정

        3 | 미정

(3 rows)

있던 14줄의 새 칸이 비어요

빈 표라면 NOT NULL 열을 그냥 더해도 돼요. 채울 줄이 없어서 비는 칸이 없기 때문이에요.

줄이 이미 있는 표에 NOT NULL 열만 더하면 ERROR가 나고, DEFAULT를 같이 주면 들어가요. 강좌 표에는 14줄이 있어요. 새 열 class_days를 비울 수 없게 NOT NULL로 더하면, 있던 14줄의 새 칸이 모두 비어서 규칙에 맞지 않아요. ERROR는 class_days 열에 NULL 값이 있다는 뜻이에요. DEFAULT 미정을 같이 적으면 있던 줄에도 미정이 들어가서 NOT NULL을 지킬 수 있어요. 37에서 ALTER TABLE로 규칙을 붙일 때 이미 맞지 않는 줄이 있으면 막혔던 것과 같은 이유예요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
