열은 4개, 칸은 3개

이름을 숫자 칸에 넣으려 했어요

고칠 때는 첫 줄 괄호의 열을 하나씩 읽으면서 SELECT 칸을 같은 순서로 맞춰요.

넣을 열과 SELECT 칸은 개수도 순서도 맞아야 해요. 위는 넣을 열은 네 개인데 SELECT 칸을 세 개만 적었어요. 날짜를 빠뜨렸어요. ERROR는 넣을 열이 값보다 많다는 뜻이에요. 아래는 개수는 맞는데 name과 member_id의 순서를 바꿔 적었어요. 이름이 첫 번째 열인 member_id에 들어가려다가 숫자 열에 글자를 넣을 수 없다는 ERROR가 났어요. INSERT는 열 이름이 아니라 순서로 짝을 지어서 생긴 오류예요. 자료형이 같은 두 열을 바꿔 적으면 오류 없이 틀린 값이 들어가니 더 조심해요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
