다른 표에서 골라 올 때

같은 9줄을 넣을 때 VALUES는 열 줄, SELECT는 세 줄이에요. 위 카드는 36에서 배운 VALUES 방식이에요. 한 줄에 회원 한 명씩 손으로 적었어요. 넘기면 VALUES부터 아래가 SELECT 세 줄로 바뀌어요. 첫 줄 INSERT INTO는 그대로 남아요. SELECT는 조건을 한 번 적어 두면 실행하는 날의 회원을 골라 와요. 새 상품 하나를 넣을 때처럼 넣을 값을 이미 알면 VALUES를 써요. 다른 표에 있는 줄을 골라 와야 하면 SELECT를 써요.
