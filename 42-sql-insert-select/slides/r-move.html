kant_shop(#    enrollment_id INTEGER PRIMARY KEY,

kant_shop(#    course_id     INTEGER,

kant_shop(#    enroll_month  VARCHAR(7)

kant_shop(# );

CREATE TABLE

kant_shop=# INSERT INTO cancelled

kant_shop-# SELECT enrollment_id, member_id, course_id, enroll_month

보관 표의 열 순서 그대로 SELECT 칸을 맞춰요. 네 칸 모두 같은 순서예요.

둘 중 하나만 되면?

INSERT 뒤에 컴퓨터가 꺼지면 같은 줄이 두 표에 다 남아요. 둘을 한 묶음으로 처리하는 법은 43 트랜잭션에서 배워요.

취소한 신청을 보관 표로 옮겨 볼게요. 옮기기는 같은 WHERE로 넣고 지우는 두 문장이에요. 먼저 보관할 cancelled 표를 만들어요. INSERT 뒤에 넣을 열 괄호를 적지 않으면 표의 모든 열을 만든 순서대로 채워요. 그래서 SELECT 칸도 같은 순서로 네 개를 적었어요. 취소 20줄이 들어갔어요. 그다음 같은 WHERE로 신청 표에서 지웠어요. DELETE 20, 넣은 줄 수와 같아요. 신청 표는 187줄에서 167줄이 됐어요. 그런데 INSERT만 되고 DELETE 전에 문제가 생기면 같은 줄이 두 표에 다 남아요. 두 문장을 한 묶음으로 처리하는 방법은 다음 43 챕터의 트랜잭션에서 배워요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
