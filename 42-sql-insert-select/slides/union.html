kant_shop=# INSERT INTO contact_lists (member_id, name, reason, request_date)

kant_shop-# SELECT member_id, name, '이메일 미등록' AS reason, CAST('2026-11-19' AS DATE) AS request_date

kant_shop-# FROM members WHERE email IS NULL

kant_shop-# UNION

kant_shop-# SELECT member_id, name, '전화번호 미등록', '2026-11-19'::DATE

kant_shop-# FROM members WHERE phone IS NULL

kant_shop-# ORDER BY member_id, reason

kant_shop-# RETURNING request_id, member_id, name, reason;

둘 다 없는 회원이에요. UNION은 완전히 같은 줄만 하나로 합쳐요. reason이 달라서 두 줄이 남아요.

회원 번호 순서로 request_id가 붙어요.

두 SELECT의 날짜를 DATE로 맞추면 UNION 결과 16줄이 한 번에 들어가요. 수업 코드처럼 첫 SELECT는 CAST, 둘째 SELECT는 콜론 두 개로 바꿨어요. 이메일이 없는 회원 9명과 전화번호가 없는 회원 7명, 모두 16줄이 들어갔어요. RETURNING은 36에서 배운 대로 방금 들어간 줄을 바로 보여 줘요. 임준서와 황민서는 이메일도 전화번호도 없어서 두 번 나와요. UNION은 중복을 지우지만 완전히 같은 줄만 하나로 합쳐요. 두 줄은 reason이 달라서 둘 다 남아요. 40에서 배운 대로 ORDER BY는 맨 끝에 한 번 적어요. 그래서 request_id가 회원 번호 순서로 붙었어요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
