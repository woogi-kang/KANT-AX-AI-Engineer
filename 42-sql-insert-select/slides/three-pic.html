4. 지우기와 표 비우기

DELETE는 고른 줄, TRUNCATE는 모든 줄, DROP은 표까지 없애요

DELETE FROM 표 WHERE …

request_id | name …

고른 줄만 지워요

표와 다른 줄은 남아요
WHERE를 빼면 모든 줄

TRUNCATE 표

request_id | name …

모든 줄을 한 번에 비워요

빈 표는 남아요
RESTART IDENTITY로 번호 다시 1부터 (37)

DROP TABLE 표

표가 없어요

표를 통째로 없애요

표도 열도 남지 않아요
다시 쓰려면 CREATE TABLE부터

세 명령 모두 되돌릴 수 없어요. 무엇을 지우는지 먼저 확인해요.

DELETE는 고른 줄만, TRUNCATE는 모든 줄을, DROP TABLE은 표까지 없애요. 왼쪽 DELETE는 WHERE에 맞는 줄만 지우고 나머지 줄과 표는 그대로 둬요. WHERE를 빼면 모든 줄을 지워요. 가운데 TRUNCATE는 모든 줄을 한 번에 비워요. 열과 규칙이 있는 빈 표는 남아요. 37에서 본 RESTART IDENTITY를 붙이면 SERIAL 번호도 다시 1부터 세요. 오른쪽 DROP TABLE은 표를 통째로 없애요. 다시 쓰려면 CREATE TABLE부터 해야 해요. 세 명령 모두 실행하면 바로 저장돼서 되돌릴 수 없어요.
