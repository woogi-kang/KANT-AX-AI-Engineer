2. 여러 열과 계산으로 고치기

INTEGER 열에 계산한 값을 넣으면 소수점 아래는 반올림돼요

kant_shop=# SELECT course_name, fee, fee / 1.1 AS 공급가 FROM courses WHERE course_id IN (1, 8);

  course_name    |  fee  |       공급가

------------------+-------+--------------------

수영 초급 아침반 | 70000 | 63636.363636363636

아침 요가        | 65000 | 59090.909090909091

(2 rows)

kant_shop=# ALTER TABLE courses ADD COLUMN supply INTEGER;

ALTER TABLE

kant_shop=# UPDATE courses SET supply = fee / 1.1 WHERE course_id IN (1, 8)

kant_shop-# RETURNING course_name, fee, supply;

  course_name    |  fee  | supply

------------------+-------+--------

수영 초급 아침반 | 70000 |  63636

아침 요가        | 65000 |  59091

(2 rows)

UPDATE 2

계산하면 소수가 나와요

0.36…은 버리고 0.90…은 올려요

36에서 친 fee = fee * 1.05도 fee가 INTEGER라서 같은 규칙으로 저장돼요. 소수까지 남기려면 열을 NUMERIC으로 만들어요.

INTEGER 열에 계산한 값을 넣으면 소수점 아래는 반올림돼서 저장돼요. 수강료에서 부가세 10퍼센트를 뺀 공급가를 구하려고 fee를 1.1로 나눴어요. SELECT로 계산만 해 보면 63636.36과 59090.90처럼 소수가 나와요. 공급가를 담을 supply 열을 INTEGER로 더하고 UPDATE로 계산한 값을 넣었어요. 63636.36은 63636으로, 59090.90은 59091로 들어갔어요. 잘라 버리는 게 아니라 반올림이에요. 36에서 친 fee = fee * 1.05도 fee가 INTEGER라서 소수가 생기면 이렇게 반올림돼요. 원 단위 아래까지 남겨야 하면 36에서 본 NUMERIC으로 열을 만들어요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
