member_id와 name은 members 표에 있어요. reason과 request_date는 members에 없어서 INSERT할 때 직접 적어요.

SERIAL과 NOT NULL은 37에서 배운 규칙이에요.

연락할 회원을 모아 둘 명단 표부터 만들어요. 수업에서 만든 contact_lists 표예요. request_id는 37에서 배운 SERIAL이라서 번호를 안 적어도 1부터 저절로 붙어요. member_id와 name은 회원 표에 이미 있는 열이에요. reason은 왜 연락하는지, request_date는 연락을 요청한 날이에요. 이 두 열은 회원 표에 없어서 넣을 때 직접 적어 줘야 해요. 다섯 열 모두 NOT NULL이라 비워 둘 수 없어요. 아직 아무 줄도 없어서 SELECT하면 0 rows가 나와요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
