2. 여러 열과 계산으로 고치기

SET 뒤에 쉼표로 이어 적으면 여러 열을 한 번에 고쳐요

kant_shop=# SELECT course_id, course_name, class_days, start_time FROM courses WHERE course_id = 9;

course_id | course_name | class_days | start_time

-----------+-------------+------------+------------

        9 | 요가 중급   |            | 19:30:00

(1 row)

kant_shop=# UPDATE courses

kant_shop-# SET class_days = '월수금', start_time = '20:00'

kant_shop-# WHERE course_id = 9

kant_shop-# RETURNING course_id, course_name, class_days, start_time;

course_id | course_name | class_days | start_time

-----------+-------------+------------+------------

        9 | 요가 중급   | 월수금     | 20:00:00

(1 row)

UPDATE 1

쉼표로 이어요

9번 강좌 한 줄

course_name

요가 중급

class_days

월수금

start_time

20:00:00

UPDATE 1, 한 줄의 두 칸이 같이 바뀌었어요.

SET 뒤에 열 = 값을 쉼표로 이어 적으면 여러 열을 한 번에 고쳐요. 요가 중급반의 요일을 월수금으로 정하고 시작 시간을 저녁 8시로 옮겨요. 먼저 SELECT로 9번 강좌를 보면 요일은 빈칸, 시작 시간은 7시 반이에요. UPDATE의 SET 뒤에 두 열을 쉼표로 이어 적었어요. WHERE로 9번 강좌만 골랐으니 UPDATE 1, 한 줄이 바뀌었어요. RETURNING으로 바뀐 두 칸을 바로 확인했어요. UPDATE를 두 번 쳐도 되지만, 한 번에 쓰면 한 줄의 두 칸이 같이 바뀌어요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
