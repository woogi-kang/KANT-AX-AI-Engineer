3. 있는지 묻기 (EXISTS)

EXISTS는 괄호 안에 줄이 하나라도 있으면 t, 없으면 f예요

kant_shop=# SELECT 1 FROM enrollments WHERE member_id = 10;

?column?

----------

       1

       1

       1

       1

       1

(5 rows)

kant_shop=# SELECT EXISTS (SELECT 1 FROM enrollments WHERE member_id = 10);

exists

--------

t

(1 row)

kant_shop=# SELECT EXISTS (SELECT 1 FROM enrollments WHERE member_id = 40);

exists

--------

f

(1 row)

10번 회원 신청 5건, 칸에는 1만 찍혀요

있어요

40번 회원은 신청이 없어요

왜 SELECT 1?

EXISTS는 칸에 무엇이 있는지 보지 않고 줄이 있는지만 봐요. 그래서 안쪽은 짧게 SELECT 1로 적어요.

EXISTS는 괄호 안 SELECT에 줄이 하나라도 있으면 t, 하나도 없으면 f예요. 첫 쿼리는 10번 회원의 신청 줄을 고르면서 칸에는 숫자 1만 적었어요. 줄이 5개라 1이 다섯 번 찍혀요. 두 번째는 같은 SELECT를 EXISTS 괄호로 감쌌어요. 줄이 있으니 t, 참이에요. 40번 회원은 신청이 하나도 없어서 f, 거짓이에요. EXISTS는 칸에 들어 있는 값은 보지 않아요. 줄이 있는지만 봐요. 그래서 열 이름 대신 아무 값이나 적어도 되고, 짧게 SELECT 1로 쓰는 게 관례예요. SELECT 별표를 적어도 결과는 같아요. psql 화면은 tools/demo.py로 실제 Docker와 PostgreSQL 18을 실행한 결과예요.
