5. 오류와 함정

AppleGothic만 적으면 Windows에서 한글이 네모로 나와요

[2]

plt.rcParams["font.family"] = "AppleGothic"

Python

findfont: Font family 'AppleGothic' not found.

AppleGothic은 Mac에만 있는 글꼴이에요. 없으면 matplotlib 기본 글꼴로 그리는데, 기본 글꼴에는 한글이 없어요.

46의 글꼴 셀처럼 platform.system()으로 운영체제를 보고 고르면 Windows, Mac 모두 돼요.

수업 노트북의 첫 셀은 AppleGothic을 바로 적고 Windows 줄은 주석으로 막아 뒀어요. Mac에서는 잘 되지만 Windows에서 그대로 실행하면 그런 글꼴이 없다는 메시지가 여러 번 나와요. 그러면 matplotlib이 기본 글꼴로 그리는데 기본 글꼴에는 한글이 없어서 제목과 축 이름이 네모로 나와요. 46에서 배운 글꼴 셀을 쓰면 운영체제를 보고 알맞은 글꼴을 골라요. 이 장의 그림은 리눅스에서 같은 셀을 실행한 결과예요. 메시지는 같은 줄이 여러 번 나와서 한 줄만 적었어요. 출력은 실제로 실행한 결과예요.
