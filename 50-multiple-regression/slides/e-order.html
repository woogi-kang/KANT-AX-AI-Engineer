5. 오류와 함정

predict 표의 열 순서가 다르거나 빠지면 ValueError가 나요

[7]

model.predict(pd.DataFrame({"sleep_hours": [7], "study_hours": [3], "practice_count": [20]}))

Python

ValueError: The feature names should match those that were passed during fit.

Feature names must be in the same order as they were in fit.

[8]

model.predict(pd.DataFrame({"study_hours": [3], "practice_count": [20]}))

Python

ValueError: The feature names should match those that were passed during fit.

Feature names seen at fit time, yet now missing:

- sleep_hours

위는 순서가 다르고, 아래는 sleep_hours가 빠졌다는 뜻이에요. 학습 때 X와 같은 열을 같은 순서로 넣어요.

✕

{"sleep_hours": [7], "study_hours": [3], ...}

✓

{"study_hours": [3], "sleep_hours": [7], ...}

열이 여러 개면 predict에서 오류가 자주 나요. 위 셀은 열 세 개를 다 적었지만 수면을 먼저 적었어요. 메시지 둘째 줄에 열 이름이 fit 때와 같은 순서여야 한다고 나와요. 아래 셀은 sleep_hours를 빼먹었어요. fit 때 본 열 이름 중 sleep_hours가 없다고 알려 줘요. 모델은 열 이름으로 어느 값이 어느 열인지 알아보고, 순서까지 맞춰야 해요. 학습 때 X와 같은 열을 같은 순서로 적으면 둘 다 풀려요. 48의 e-name 장에서 본 메시지와 첫 줄이 같아요. 출력은 실제로 실행한 결과예요.
