sns는 seaborn을 줄여 부르는 이름이에요. 28의 import 모듈 as 별명이에요.

seaborn은 matplotlib 위에서 돌아가는 그래프 패키지예요. 47에서는 plt.scatter 괄호 안에 df 대괄호로 꺼낸 열 두 개를 넣었어요. seaborn은 data에 표를 통째로 주고, x와 y에는 열 이름을 글자로 적어요. 그러면 seaborn이 표에서 열을 꺼내서 matplotlib에게 그리라고 넘겨요. 두 줄 다 같은 산점도가 나와요. 열 이름만 적으면 되니 그래프 여러 개를 그릴 때 코드가 짧아지고, 축 이름도 열 이름으로 자동으로 붙어요. seaborn은 46에서 데이터를 불러올 때 이미 썼고, 그래프 함수는 오늘 처음 써요. 그래프는 리눅스 커널이 그려서 맑은 고딕 대신 나눔고딕으로 나왔어요.
