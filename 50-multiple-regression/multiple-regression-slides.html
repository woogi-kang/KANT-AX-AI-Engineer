45부터 오늘까지 배운 머신러닝 기초를 한 장에 모았어요. 45에서 pandas로 표를 만들고 조건으로 골랐어요. 46에서 빈칸을 채우고 튀는 값과 겹친 행을 찾았어요. 47에서 그래프를 그리고 정답을 아는 연습 데이터를 만들었어요. 48에서 선형 회귀로 학습하고, 예측하고, 채점했어요. 49에서는 모델이 손실을 조금씩 줄여 가며 기울기와 절편을 찾는 경사 하강법을 봤어요. 오늘 50에서 입력 열을 셋으로 늘렸어요. 순서로 보면 데이터를 준비하고, 그래프로 보고, 학습하고, 채점하는 네 박자예요. 다음에는 학습에 쓰지 않은 데이터로 채점하는 방법과 다른 모델을 배워요.

한 장으로 보는 오늘의 코드

그림판을 칸 셋으로

fig, axes = plt.subplots(1, 3, figsize=(16, 5))

열 이름으로 점 그래프

sns.scatterplot(data=df, x="열", y="열", ax=axes[0])

모든 열 짝 상관계수

corr = df.corr()

색 칸 그림

sns.heatmap(corr, annot=True, vmin=-1, vmax=1, fmt=".2f")

마이너스 깨짐 막기

plt.rcParams["axes.unicode_minus"] = False

문제 열 셋

X = df[["a", "b", "c"]]

학습

model.fit(X, y)

기울기 셋, 절편 하나

model.coef_ model.intercept_

예측

model.predict(pd.DataFrame({"a": [..], "b": [..], "c": [..]}))

채점

r2_score(y, y_pred)

그래프로 열마다 보고, 세 열을 X에 넣고, 기울기는 '나머지는 그대로, 이 열만 1'로 읽어요.
predict 표는 학습 때와 같은 열, 같은 순서예요.

오늘 쓴 코드를 한 장에 모았어요. 왼쪽은 그래프, 오른쪽은 학습과 예측이에요. 열이 여러 개면 먼저 산점도와 히트맵으로 열마다 점수와 어떤 사이인지 봐요. 그다음 문제 열을 모두 X에 넣고 48과 같은 세 줄로 학습하고 예측해요. 기울기는 나머지 열은 그대로 두고 그 열만 1 늘렸을 때 바뀌는 점수로 읽어요.
